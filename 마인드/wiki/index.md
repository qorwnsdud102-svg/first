# 위키 인덱스 — 마인드

> 사장님의 **삶을 어떻게 살아갈지**에 대한 위키.
> 마케팅 전술·프로그램 개발이 아니라 **사고방식·태도·삶의 운영**에 대한 노드들이 모이는 자리.

## 자주 가는 곳

- [[자본주의적 사고]] — M군의 100억까지 모은 사고법. 부자 추월 공식·월요병=노예·결핍 컨트롤.
- [[몰입]] — 한계까지 부딪힘 + 배제·결핍·멘탈
- [[역접부사 안쓰기]] — 마에 vs 플러스 에너지
- [[어떻게 살아갈 것인가]] — 필터 3가지 장치
- [[가난냄새]] — 반골기질 + 자아비대 + 무시 깊이
- [[주체성]] — 가족이 가장 큰 가해자 / 자본주의 혁명
- [[등가교환]] — 양파 거지의 저주: input 없는 output은 저주 + 딸깍지수 (22기)
- [[골포커싱]] — 배제된 목표: 비우고, 현실적 최대치로, 하나만 + 무의식 조종 (22기)
- [[플러스 에너지]] — 양극·순환·프레 3종·한영키 (22기 2주차 주제의 토대)
- [[인정]] — 예양과 지백: 사람은 자신을 알아준 이를 위해 목숨을 다한다 (22기 2주차 주제)
- [[레이어-궤도-패턴]] — 습관으로 퉁치면 못 바꾼다: 정체성 부정으로 레이어 깨기 (22기)
- [[각성]] — 양보할 수 없는 계기 + "너 좀 이상하다"가 진짜 각성의 신호 (22기 3주차 테마)
- [[무의식 조종]] — 의식 5%로 무의식 95% 조종: 환경 배치·트릭·자기최면 (22기)

## 책 (편별 색인 + raw 줄앵커)

- [[세이노의 가르침]] — 천억 자산가의 독설 130편 색인. 좁은 문·신뢰도×고객 수·추천도서 34권 (2026-08 ingest)
- [[부자를 훔치다]] — M군 인터뷰집. 자기 폭행·자아 5분리·패턴과 관성 (기존 4개념 보강)
- [[아메바 경영]] — 이나모리 가즈오. 조직을 5~10명 독립채산으로 쪼개고 **시간당 채산**으로 재는 법. JAL 2년 회생. ⚠️ 필로소피 없이 시스템만 도입하면 이기심 증폭 장치가 된다 (신규 개념 0장, 2026-08 ingest)

> 세 책에서 파킹된 개념 후보는 [[마케팅/개념-후보-대기열]]에 마케팅 도메인 후보와 함께 모여 있다 (도메인 무관 단일 대기열).

## cross-domain 참조 (마케팅 도메인의 마인드 결)

- [[마케팅/설득의 심리학]] — 치알디니 6원칙. 마인드 결: 고정행동유형·가스라이팅 4단계·미래 자아 (전부 파킹, 2패스 대기)
- [[마케팅/인간관계론]] — 카네기 30원칙. 마인드 결: **중요한 사람이 되고 싶은 욕구** → [[인정]] 보강
- [[마케팅/넛지]] — 탈러·선스타인. 마인드 결: 자동뇌/수동뇌 → [[무의식 조종]] 5%/95%와 같은 것 · 디스인센티브>인센티브 (2패스 대기)
- [[마케팅/엠타트업]] — 강의의 마인드 부분 추출 (M군 어록·결핍 컨트롤)
- [[마케팅/근육돌이]] — 사업 마인드·AI 시대 자세 (28개 글)
- [[마케팅/자각]] — 마케팅의 자관인간 1단계 = 마인드의 자기 인식 출발점
