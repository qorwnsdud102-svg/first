# wiki/ — 정리된 위키 (제2의 뇌 본체)

이 폴더가 진짜 "제2의 뇌"다. 모든 페이지는 **하나의 엔티티** (개념·사람·책·사건·질문)에 집중한다.
"잡다한 메모"는 wiki에 들어오면 안 된다 — 그건 raw거나, 아직 정리 안 된 초안.

## 진입점

- [[index]] — 위키 전체의 텍스트 진입 페이지. 자주 가는 곳·미해결 질문·분류별 링크.
- [[log]] — 일자별 활동 로그 (append-only). 한 줄 = 한 액션. **고정 포맷**으로 grep 가능하게:

  형식: `## [YYYY-MM-DD] <action> | <대상> → <영향>`

  - `<action>` ∈ `ingest` · `lint` · `query` · `restructure` · `merge` · `split`
  - `<대상>` — 입력 raw 파일명 / 페이지 이름 / 변경된 폴더
  - `<영향>` — `[[엔티티A]]·[[엔티티B]] (n신, m갱신)` 식 wikilink 누적

  예:

  ```
  ## [2026-05-09] ingest | 2026-05-04_근육돌이_AI-활용-성숙도-자가진단.md → [[근육돌이]]·[[AI-활용-성숙도]] (1신, 1갱신)
  ## [2026-05-10] lint | wiki/sources/iboss-근육돌이/ → 6 stub 발견, 2 orphan 정리
  ## [2026-05-11] restructure | wiki/concepts/RAG.md → [[검색-증강]] 로 통합
  ```

## 하위 폴더 — 어디에 새 페이지를 두는가

새 페이지는 다음 4곳 중 하나에 들어간다. `type:` frontmatter와 폴더는 보통 일치한다.

- `sources/<출처>/` — raw 파일 1개당 페이지 1개. **출처별 sub-folder로 분류** (`sources/엠타트업/` · `sources/iboss-근육돌이/` · `sources/기타/` — `raw/`의 출처 폴더와 미러). 출처·요지·어느 엔티티에 영향을 줬는지 추적.
  - **다파일 세트 예외**: 한 회차/주차로 묶이는 다수 raw 파일(예: 강의 전사 4강 + 요약댓글 + 미션)은 **묶음 단위 1페이지** 허용. frontmatter `sources:`에 묶인 raw 파일 전체를 나열. (2026-06, 엠타트업 22기 ingest에서 도입)
- `concepts/` — 추상 개념. (예: [[어텐션]], [[RAG]], [[제2의 뇌]])  → `type: 개념`
- `entities/` — named: 사람·책·조직·구체 작품. (예: [[Karpathy]], [[Attention Is All You Need]])  → `type: 사람` · `책` 등
  - **책 예외**: `type: 책` 페이지는 source 페이지를 겸한다 (편별 색인 + raw 줄앵커). `sources/책/`에 별도 페이지 X. 규칙: `핵심-맥락.md` §4 책 ingest 규칙.
- `syntheses/` — 여러 페이지를 가로지르는 내 종합·비교·가설. wiki의 부가가치.  → `type: 질문` 또는 신규 `종합` 타입

## 신뢰 등급 — 1·2·3등급 (2026-08-20 개편)

같은 출처 묶음 안에서도 내용의 신뢰 수준을 **숫자 등급**으로 구분한다. **1등급이 최상** (한우·신용등급 관용과 동일).
등급은 **출처의 신뢰도**를 뜻한다. 정보의 완결성(미확인·추정 여부)은 별개 축이므로 등급과 무관하게 따로 표시한다.

| 등급 | 정의 | 표기 |
|---|---|---|
| **1등급** | 강사 본강의·공식 자료의 원칙, **학술·통제실험 근거**, **사장님 본인 실전으로 재현된 것** | 표시 없음 (개념 페이지 일반 섹션) |
| **2등급** | **성과가 입증된 실전가**(매출·자산·실적으로 확인되는 사람)의 경험·노하우. 두 경로 — ⓐ사장님이 **직접 채록**(대면·통화) ⓑ그 사람의 **저서**. 통제실험은 아니지만 **출처가 검증됨** | 섹션 제목에 `2등급 —` 접두 + 출처의 성과 명시. frontmatter `confidence: 2등급` |
| **3등급** | **출처의 성과가 확인되지 않은** 실전 주장 (익명 수강생·제3자·검증 전 본인 가설). 자칭 인증이 있어도 재현성·일반성 미검증 | 섹션 제목에 `3등급 —` 접두 + ⚠️ 마커 + 출처(작성자 번호·sources 페이지). frontmatter `confidence: 3등급` |

- 3등급 내부 상위: 강사진이 **bb**(인정)를 단 것 → "(bb)" 표기.
- **승격 경로**: 3등급 → (사장님이 성과 검증된 출처에게서 직접 채록) → 2등급 → (사장님 본인 실전 재현 / 강사 본강의 채택) → 1등급. 승격 시 log에 기록.
- **인용 어조**: 1등급은 단정 가능. 2등급은 단정하되 출처를 밝힌다 ("~한다 — 출처: 연매출 100억 DA 사업자"). 3등급은 단정 금지 ("~라는 실전 주장이 있다").
- 등급이 충돌하면 **숫자가 낮은 쪽 우선** + 충돌 사실 명시.

> **옛 표기 대응** — 2026-08-20 이전 기록·git 히스토리에는 역사 비유(正史/野史)를 썼다. 그 표기를 만나면: 앞 글자가 '정'인 쪽 = **1등급**, '야'인 쪽 = **3등급**. **2등급은 이번 개편으로 신설** — 이전엔 담을 칸이 없어 3등급에 뭉뚱그려져 있었다 (예: 세이노·M군·이나모리 같은 성과 검증된 저자도 3등급 취급).
>
> 숫자로 바꾼 이유: 등급 층이 더 생길 수 있는데 2단 역사 비유로는 확장이 안 된다.

## 페이지 형식 (템플릿)

````markdown
---
type: 개념 | 사람 | 책 | 사건 | 질문
aliases: [별칭1, 별칭2]
status: stub | growing | stable
sources: [raw/파일명.md, raw/다른파일.md]
updated: 2026-05-09
---

# 엔티티 이름

## 한 줄 정의

<!-- 14살 친척에게 설명 가능한 한 문장. 이게 안 써지면 아직 이해 못 한 것. -->

## 핵심 주장 / 속성

- ...
- ...

## 다른 엔티티와의 관계

- [[다른 엔티티]] — 어떻게 연결되는가 (한 줄로)
- [[또 다른 엔티티]] — ...

## 내 생각 / 미해결 질문

<!-- 객관적 정리와 분리. 시간이 지나면 답이 바뀔 수 있는 자리. -->

## 출처

- `raw/파일명.md` — 무엇을 가져왔는가
````

## 새 페이지 만들기 전에 (중복 방지)

- 같거나 유사한 엔티티가 이미 있는가? Obsidian 전역 검색·그래프뷰로 먼저 확인.
- 있으면 합친다. 별칭이 다르면 frontmatter `aliases:`에 추가하고 페이지는 하나로 유지.
- "비슷한데 다르다"는 판단이 들면, 두 페이지를 만들고 `[[A]] vs [[B]]` 같은 비교 페이지를 따로 만든다.

## status 전이 규칙

`status:` frontmatter는 페이지 성숙도 표시. 전이는 **수동**, ingest·lint 시 검토.

- **stub** — 출처 0~1개. 한 줄 정의 미작성 또는 한 줄 정의만.
- **growing** — 출처 2개 이상 OR (한 줄 정의 + 핵심 주장 1개 이상). 다른 엔티티 관계 작성 시작.
- **stable** — 핵심 주장 + 다른 엔티티 관계 + 미해결 질문 모두 작성. 14일 이상 큰 변경 없음.

전이 트리거:
- 새 raw ingest로 출처 추가 → status 재평가.
- lint 시 `stub` 14일 초과 → 합치거나 raw로 강등.
- `stable`에 새 raw 들어와도 자동 강등 없음 (오히려 보강).

## Lint — 주기적으로 확인

- [ ] 출처 0개인 페이지 → `status: stub`로 강등 또는 삭제.
- [ ] orphan (어디서도 링크되지 않은 페이지) → 의도적인지 확인, 아니면 연결.
- [ ] 모순되는 주장 → 삭제하지 말고 페이지 안에 `## 미해결 충돌` 섹션으로 보존.
- [ ] 14일 이상 `stub` → 합치거나 raw로 강등.
- [ ] `updated`가 오래된 핵심 페이지 → 최신 raw로 재검토.

## Query — wiki를 읽어 답할 때

- 1차 출처는 wiki, raw는 보조.
- 답이 wiki에 없으면 **추측 금지**. "wiki에 없음 — raw `XYZ`에는 있을 수 있음" 형식으로 보고.
- 답이 여러 페이지에 걸쳐 있으면 출처 페이지 모두 인용.
- **3등급 인용 규칙**: 3등급 섹션의 내용으로 답할 때는 반드시 "(3등급 — 수강생 N번 주장)" 라벨을 붙인다. 1등급과 3등급이 충돌하면 **1등급을 우선**하고 충돌 사실을 명시한다. 3등급만으로 단정 어조 금지 ("~이다" 대신 "~라는 실전 주장이 있다").
