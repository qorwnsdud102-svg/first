### 리뷰 작업 운영 디테일

- **좋은 리뷰 상단 배치 = 10% 전환율** vs 부정 리뷰 상단 = 2.5% — **4배 격차**
- 리뷰 최신성 = 밴드웨건 효과 (줄 서 있는 맛집)
- 1-2점 리뷰도 작업 (제품 만족 + 배송 불만 같은 혼합형 — 순수해 보이며 신뢰도↑)
- **스마트스토어**: 매달 2-3개씩 주간 단위. 한꺼번에 수백 개 X (스토어 정지). **디지터/솔리샵** (에이베러 7년 운영) 같은 검증된 체험단 추천
- **쿠팡**: 로켓 배송 = 전환율 3배 (윙 3% → 판매자 로켓 9-10%). 3일~1주일 주기로 최신순/추천순 밀어내기
- **자사몰**: DB 주체 = 판매자 본인. 가격은 최저가 (네이버페이 클릭 바로 결제). **회원가입 강제 X** (전환율 급락)

> 자사몰 vs 쿠팡 ROAS: 쿠팡 광고 100만 → 자사몰 150% ROAS. **+ 브랜드 키워드 검색 → 쿠팡 로켓 70% 전환율 추가** → 전체 200% 달성. 쿠팡과 자사몰을 적대 X, 시너지 O.

### 네이버 쇼핑 SEO 디테일

> 네이버 쇼핑 섹션(이미지·블로그·카페·지식·쇼핑) 순서를 키워드별로 먼저 확인 후 역배치.

- 인트로 정형: Pain Point → 공감 → 기대감 설정. **But** 경쟁사 1등은 연예인 협찬 / 제품 리뉴얼 안내를 먼저 배치. 최상단 요소 일주일 단위 A/B 테스트 → 2개월이면 최적값. 도입부 에너지 집중: Pain Point + 숫자 + 호기심 필수
- "지금 놓치면 못 산다" 메시지 = 전환율 **0.23%p 상승** (e-commerce 평균 2% 대비 **10% 증가** 효과). 한정 수량 = 실제 한정 여부와 무관 (누룩밤도 "몇 명 함께 보는 중" 표시). 당장 구매 버튼 위에 한정 수량·한정 세트 + 환불 보장. "무조건 환불" X → **"제품 효과에 자신 → 환불 보장"** 근거 추가
- **GIF 남발 X** (사이트 속도↓ → 3초 이탈) — USP 핵심 1-2곳만. **영상 = 텍스트로 설명 불가능한 부분만** (조작 과정·성분 작용). **Before/After = AI 생성(제미나이) 허용** — 실제 촬영 불필요. 다양한 모델 무제한 제작

### 메시지 삼위일체 (광고·상페·바이럴)

같은 메시지(예: "피부과 전문의 93% 추천")를 3개 채널 화자로 반복: 광고 = 판매자 메시지 (강한 후킹) / 상페 = 판매자 + 전문가 (상세 근거) / 바이럴 = 블로거·유튜버 (경험 화자). → 본질 동일, 화자만 다름 = 자연스러움 + 설득력↑. 원칙 자체는 [[2025_그로스짐_부록1-상세페이지-특성-및-설계]] §삼위일체.

### 고객 의심 심리 4가지 (선제 해결)

1. **"정말 효과적?"** — 임상·리뷰·전문가 권위
2. **"합리적 가격?"** — 비교 가격·할인·세트
3. **"나도 맞나?"** — Persona 구체 사례·비포/애프터
4. **"지금 안 사면?"** — FOMO·한정 수량·환불 보장

→ 경쟁사·커뮤니티 리뷰 스캔으로 사전 발굴 후 페이지에 선제 답변. 주: [[2025_그로스짐_7주차-다시보기-2강]] §의심 4종의 4번은 "다른 사람도 만족했나?" — 이 표의 4번과 다름, 강별 source 우선.

## 종합 (구 syntheses/그로스짐_8주차_마무리_종합에서 흡수)

8주 코칭 마무리. **퍼포먼스 캔버스 = 나침반** 재강조 + 상세페이지 3 flow 무한 변주 + AI 자동화 워크플로우 (Claude Code + Gemini + Photoshop) + 권위 재정의 + 사례.

강별 상세: [[2025_그로스짐_8주차-다시보기-1강]] (캔버스 종합·유세라블·Claude Code 터미널 스킬) · [[2025_그로스짐_8주차-다시보기-2강]] (상페 3 flow·헤어리듬) · [[2025_그로스짐_8주차-다시보기-3강]] (AI 자동화·권위 재정의·종합 명제)

### 퍼포먼스 캔버스 = 나침반

> "건망증 많은 인간이 제품 세부 내용을 다 기억할 수 없으므로, 캔버스가 그 기억을 대신함."

- 제품 정체성 = 강점 + 타겟 누구인지에 대한 방향성
- 정체성 맞는 것만이 고객들이 실제로 구매하게 만드는 콘텐츠 생산 가능
- 캔버스 없이는 매주 광고·콘텐츠 갱신 시 일관성 깨짐

### 상세페이지 3 flow 무한 변주

> 반복 구조: **문제 제기 → 문제 해결 → 근거 제시** (순서 가변, 화자·이미지만 바꿈)

- 광고에서 제시한 무의식·의식이 그대로 상세페이지에 투영
- 리뷰 개수·주문 수량 = 사회적 근거 + 숫자적 증거 (오프라인 "줄 서 있는" 장면의 온라인 대체)
- 리뷰 후기는 전문가/판매자가 아닌 "고객" 화자로 신뢰도 극대화

### 상세페이지 완전 자동화 (3단계 통합)

Claude Code 터미널 스킬(경쟁사 자동 분석)은 → [[2025_그로스짐_8주차-다시보기-1강]].

**기존**: Claude가 텍스트만
**확장**: Gemini로 이미지 생성 → Upscaling AI로 고화질화 → Photoshop API로 텍스트·강조색 삽입

1. 경쟁사 레퍼런스 + 우리 퍼포먼스 캔버스 → Claude가 기획서 작성
2. 기획서의 각 섹션(도입·문제·해결·근거·이미지 배경)을 Gemini에 개별 입력 → 이미지 생성
3. 각 이미지를 "새 채팅창"에서 단계적 수정 (배경·인물·색감 분리) → 일관성 유지
4. 최종 이미지 + 텍스트 → 디자이너에게 넘기면 "70-80% 완성 상태" → 외주 비용 절감

→ **한 장 생성 = 30분 → 비용 효율 3배 증대**.

### 권위 재정의 (연예인 외 모든 권위)

> "돈 있으면 좋지만, 없으면 **뉘앙스·무의식**으로도 권위 만들 수 있다"

| 권위 유형 | 비용 | 사례 |
|---|---|---|
| **연예인 (A급)** | 비쌈, 운 의존적 | IU 5억 투입 → 8배 성장 (운 80%) |
| **B급 연예인** | 2-3천만원 + 6개월 계약 | 촬영팀 + 스튜디오 직접 (퍼포먼스 필름) |
| **일반인 권위** | 0원 | 엄마·아빠·본인 스토리 |
| **스토리텔링 권위** | 0원 | "10년 고민 끝에 2만 6700시간 투입해 개발" |
| **제조사 권위** | 자료비 | 논문·박사·임상자료 (법적 테두리 먼저 설정) |

→ [[상징재]] · [[상징성과 당위성]] 권위 4분할 보강 자료. 주: [[2025_그로스짐_8주차-다시보기-3강]]은 IU 사례를 "매출 5배"로 기록 — 표의 "8배"와 어긋남, 강별 source 우선.

### 사례 — 아이크림 유세라블

> 원 synthesis는 이 사례를 "사장님 사업 사례"로 적었으나, [[2025_그로스짐_8주차-다시보기-1강]]·[[그로스짐]] §강사 사례 사전은 **강사 자체 브랜드**로 기록. 아래 "사장님" 표현은 원문 그대로 두되 강사로 읽는 게 맞을 가능성이 높다.

- **시장 지위**: 온라인에서 **AHC와 어깨를 나란히 함** (AHC 오프라인·홈쇼핑 3천억 vs 자사 온라인 메인)
- **성장 동기**: 경쟁사 신고 다수 → 콘텐츠 "덜어내고 빼면서" 노멀화 → 그럼에도 판매 유지 이유 = **콘텐츠·홍보량 누적**
- **원가 절감 + 유통 명함**: 판매 규모 커지니 원가 싸지고, 유통처(올리브영 등)가 우리를 인정
- **확장 효과**: 홈쇼핑 진출 이유 = 매출이 아니라 **"노출" 목적** (검색량·인식도 상승)

→ 교훈: "매출만 보지 말고, 노출의 브랜드 시그널 효과를 함께 계산하라"

→ (원문) 사장님 SKU 중 하나 = **아이크림 (유세라블 카테)**. 자사몰 + 메타·GFA·구글 운영 추정. 향후 [[사업 카테고리별 적합 진영]] synthesis 갱신 시 활용. — 위 주석 참조, 미확인.

### 다른 수강생 사례 — 아기세제 카테고리 확장

- 문제: 아기세제 카테고리 급상승 브랜드 찾기 어려움
- 해결: **"같은 카테고리가 아니라 기전이 비슷한 류를 찾아라"** (예: 염색약·다이어트 식품)
- 실행: 30대 엄마들 문제 해결 구조 = 다른 카테고리도 동일 가능
- AB 테스트: 자사몰에서만 페이지 2개 (리뷰 많은 버전 vs 썸네일만 다른 버전) 비교

### 8주 종합 체크리스트

1. 퍼포먼스 캔버스 작성 완료 (정체성·페르소나·욕구·USP·근거)
2. 경쟁사 3개 분석 완료 (도입부~CTA 흐름 정리)
3. 자사 상세페이지 레이아웃 기획서 작성 (섹션별 목적 명시)
4. 권위 섭외 계획 (연예인 아니어도 OK — 엄마·아빠·본인 스토리도 권위)
5. AI 활용 workflow 숙달 (Claude·Gemini 단계별 생성 프롬프팅)
