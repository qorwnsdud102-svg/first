# AI에게 세컨드 브레인이 필요한 5가지 이유

- AI는 컨텍스트 창에 기억이 갇혀 대화창을 닫으면 리셋되므로, 외부에 지식 저장소("두 번째 뇌"=AI Wiki)를 만들어 매번 주입해야 한다(메모리 기능은 요약본이라 상세 기준은 못 담음). 카파시의 세컨드 브레인 개념을 AI에 적용한 것.
- 운영 도구로 Git(문서 타임머신·버전관리·팀 공유), 옵시디언(마크다운+링크), Graphify(지식 관계 시각화)를 조합하고, 주입은 복붙·프로젝트/커스텀 인스트럭션·Claude Code SKILL.md 순으로 자동화 가능. 숏폼 영상 제작이 Wiki 없으면 30분·수정 4회 → Wiki 있으면 5분·수정 0회로 줄어든 비교 제시.
- 검증된 성공 경험·성공 방정식·실패 기록만 엄선해 넣어야 함(아무거나 넣으면 "쓰레기 뇌"), 공통 원리(후킹·가독성·신뢰장치)는 상위 문서로 묶어 한 번 수정에 전체 반영. 프로젝트마다 업데이트하는 "러닝스 시스템"으로 Wiki가 복리처럼 똑똑해진다.
