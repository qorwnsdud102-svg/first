# SNS 마케팅으로 과연 브랜딩에 성공 할 수 있을까?

- SNS 마케팅만으로는 브랜딩이 불가능하다는 주장 — 좋아요·검색량·조회수 등 단기 수치는 광고를 끄면 곤두박질침
- 브랜딩의 중심은 제품 — (중심)제품 → (관심)컨텐츠 → (연결)광고 → 사용자 → 경험으로 이어지는 흐름
- 브랜딩의 척도: 광고를 안 해도 고객이 자발적으로 찾아주고 재구매하는 단골파워 (틱톡의 단기 노출 사례로 대비)
