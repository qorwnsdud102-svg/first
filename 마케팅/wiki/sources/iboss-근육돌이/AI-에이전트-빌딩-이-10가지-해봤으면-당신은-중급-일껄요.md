# AI 에이전트 빌딩 , 이 10가지 해봤으면 당신은 중급 일껄요?

- AI 바이브코딩 실무 레벨을 가르는 10가지 체크리스트(4부 구성): 도구(①CLI 사용 ②맥/윈도우 환경 세팅 ③월 100~200달러 토큰 일주일 소진), 설계(④SDD·DDD 스펙 중심 ⑤클로드 스킬 ⑥하네스+검증 서브에이전트), 실전(⑦MECE 분해 ⑧기술 스펙 이해 ⑨API 문서 읽고 적용), 한계(⑩제미나이 이미지/영상 생성의 꼼수).
- CLI(클로드 코드)는 GUI 대비 체감속도 10배·작업량 100배이고 실제 파일을 읽어 더 정확하며, "그냥 만들어줘"는 초보·스펙 문서부터 만드는 게 중급이라는 점, 독립 검증 서브에이전트로 결과물이 3~4배 좋아진다는 점을 강조.
- 도구별 숨은 특성 노하우: 클로드는 CLI에서 더 정확, 제미나이는 대화창이 API보다 이미지 퀄리티가 좋아 대화창 호출로 우회, 일레븐랩스는 API 문서의 음성 파라미터를 MD로 정리해 클로드에 줘야 진짜 성능이 나온다. 점수표(0~10개)로 자가진단 제공.
