# AI 와 이커머스 성과 10배 올리는 10가지 방법

raw: `마케팅/raw/iboss-근육돌이/2026-07-28_근육돌이_AI-와-이커머스-성과-10배-올리는-10가지-방법__71348.md` — 줄번호가 영구 앵커.

- **폴더 핸드오프 4단계**: 입력 폴더 → 단계 분리(수집·정리·판정·출력) → 각 단계는 앞 단계 결과 폴더를 보고 미처리만 → 완료 폴더로 이동. "각 단계가 서로를 몰라도 폴더 규칙만 맞으면 돌아간다"
- **사람 게이트는 비싼 작업 직전에** — "5분 보면 뒤에서 몇 시간 아낀다". 중간 검문소 개념
- **"예상 대 실제" 자체 검증** — 컷 12개면 결과 파일에 12개 있는지 기계적으로 센다. 실제 자막 누락 사고에서 나온 규약
- 검증 2단계: 기계적 확인 + **다른 시선의 검토**("만든 주체가 자기 걸 검토하면 잘 안 보인다 — 사람이나 AI나")
- **지시문은 재작성이 아니라 재사용**, 한 번에 한 변수만 / 팀 폴더에 모아두니 신입 교육 시간이 확 줄었다
- **양을 늘리기 전에 한 사이클을 손으로 완주** / 개인 검색환경은 결과를 왜곡하니 별도 환경에서 확인
- ⚠️ AI 대량 생성으로 **메인 도메인을 통째로 잃는 경우**가 실제로 있다 — 실험은 버려도 되는 테스트 사이트로
