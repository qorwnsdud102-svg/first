# 광고 성과 정확하게 판단하고 운영법 10가지

raw: `마케팅/raw/iboss-근육돌이/2026-07-17_근육돌이_광고-성과-정확하게-판단하고-운영법-10가지__71221.md` — 줄번호가 영구 앵커.

- **지표 위계**: CPM(선행) → CTR → CPC → CVR(후행). 어떤 지표든 **앞 단계와 쌍으로**. CTR 33% 개선인데 CPM이 8만→12만이면 CPC는 오히려 12% 상승 = 실질 후퇴
- **ROAS 30초 암산**: 노출 1,000회로 끊기. `ROAS = (1,000×CTR×CVR×객단가) ÷ CPM`
- **목표 CPA = 객단가 ÷ 목표 ROAS** → CPA = CPC ÷ CVR로 한 단계 더 역산
- ⚠️ **똔똔 ROAS 134%는 공헌이익 0 지점이지 손익분기가 아니다** — 고정비가 안 빠졌다. 실질 목표는 200%+
- **전환율 기준은 매체가 아니라 사이트 전체** — 이커머스 평균 2%대(연평균 2.7%), 3~4%면 레전드
- **OFF 전 6점검** / 노출 1만 미만은 판단 보류 / 리타겟 비중 30~40%는 위험 신호
- **증액 = 목표 CPA × 필요 전환수**(주 50전환) / 보고 기본형 = 결론 + 기준 + 다음 액션
