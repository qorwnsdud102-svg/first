# 60초, GFA 반려 소재 수정 앱 만들었습니다?

- 네이버 GFA 반려 소재를 60초 안에 자동 수정해주는 앱을 만들어 수요 조사 차원에서 공개. API 호출 방식이며, 단순 바이브코딩 앱이 아니라 7년치 GFA 성과형 노하우·수정 프로세스를 녹였다고 설명.
- 사용법은 반려 소재·반려 사유·수정 포인트(네거티브 프롬프트)를 입력하면 수정해주고, 문제되는 카피는 가이드에 맞는 대안 카피도 제안. 디자이너가 없거나 즉시 수정이 어려운 사람에게 유용.
- 가격 투표 진행(1장 실행당 비용): 800원 이하 73.6%, 1000원 이하 15.7%, 1200원 이하 5.2% (총 19표, 투표 종료).
