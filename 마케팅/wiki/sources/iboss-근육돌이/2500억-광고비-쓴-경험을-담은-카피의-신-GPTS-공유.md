# 2500억 광고비 쓴 경험을 담은 "카피의 신" GPTS 공유

- 2500억 광고비 경험의 베스트 카피와 책의 카피 법칙을 학습시킨 "카피라이팅의 신" GPTS를 무료 공개
- 사용 흐름: 상품 데이터 입력 → 봇이 어울리는 카피 법칙 3가지 추천 → 선택한 법칙으로 카피 생성 → 마음에 안 들면 예시 제공해 재생성
- 생성된 카피를 클로드에 다시 먹여 더 자연스럽고 위트 있게 2~10배 후킹되게 다듬기, 배달앱·스마트스토어 리뷰를 예시로 줍줍해 활용
- AI와 마케터가 공존하는 시대 — 어떤 카피를 어떻게 필터링해 쓸지는 마케터의 몫
