# [source] 사장님 구술 — 퍼믹 마킹글 느낀점 (2026-09-14)

## 출처

퍼믹 마킹글 2종(`sources/경쟁사/2026-09-14_경쟁사_퍼믹-마킹글-표본-2종-묶음.md`) 해부 직후 사장님이 직접 구술한 "왜 이 글이 광고로 안 읽히나". 1등급(본인 판단). 스크린샷 5장 첨부 — ①~③은 1·2탄, ④⑤는 **다른 퍼믹 제품 마킹글**(여드름 트러블 타임라인, 원본 미확보).

## 요지 — 광고로 안 읽히는 이유 6가지

1. **MZ 일상글 말투 = 사람 티**: "모공이에요;;"(빨간 기울임·큰 폰트) / "초고화질 모드 켜짐.. ㅋㅋ"(노란 형광펜). 업자 광고글이 아니라 **요즘 젊은 여성이 블로그에 일상글 쓰는 유행**의 말투·꾸밈. 색·기울임·형광펜이 "직접 썼다"는 신호.
2. **제품 소개가 신박하고 자연스러움**: 제품명을 잘 모르는 척("뭔 콘크리트??") + 친구한테나 쓸 거친 표현("쌉흑우쉑") — 광고글에선 절대 안 나올 말.
3. **1탄·2탄 시간 분할** → 진짜 사람이 시간 들여 실제 써본 것 같아 신뢰.
4. **한발 물러난 광고**: 100% 칭찬("주름 싹 사라져")은 '에이 광고네' 반감. 2탄 FAQ①처럼 **궁금한 것 짚기 → 부인(완전 삭제 아님) → 그래도 쓰는 이유 → 조건(1~2주 기대면 쓰지 마라, 1~2달) → 사진 증명** 순으로 단점을 까면서 실사용자 후기 느낌.
5. **가독성** (③ 플로우차트: 처음→한달차→8개월차 형광펜 + 화살표 + 손실회피 핑크 + 결론 인용구 박스).
6. **AI 사진을 진짜같이 티 안 나게** (④⑤ 여드름 타임라인 — 날짜 라벨·셀피·거울샷·클로즈업) → 신뢰감. *사장님 판단이며 AI 생성 여부는 미검증.*
