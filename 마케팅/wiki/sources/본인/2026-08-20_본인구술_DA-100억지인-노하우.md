# DA 운영 노하우 — 100억+ 사업자 채록 (2026-08-20)

## 출처 성격

사장님이 **연매출 100억+ 이커머스 DA 사업자 또래 모임에서 직접 듣고 정리**한 기록. 지인 중 실명 언급은 비토리(Veo3→캡컷 연동) 1인.

**2등급 근거**: 출처가 매출로 성과 입증 + 사장님 직접 대면 채록. 익명 수강생 주장(3등급)과 구분한다. 다만 통제실험이 아니고 사장님 본인 재현 전이라 1등급은 아니다.

## 채록 11건

| # | 내용 |
|---|---|
| 1 | **채널 파이**: 매출 100억이면 구글 50 / 나머지 채널 50. 구글이 최대 채널 |
| 2 | **구글 진입장벽**: 영상 최적화·효율 테스트에만 ~1천만원. 메타는 기회비용 적고 알고리즘 정확해 시작용으로 적합 |
| 3 | **소재 자동화 비율**: 이미지 **80% AI + 20% 사람**(처음·마무리 검수) / 영상 **50:50**. 100% AI는 어색해서 불가 |
| 4 | **영상 소스**: 샤오홍슈·도우인에서 수급. 링크 넣으면 컷별로 분할 저장하는 프로그램으로 편집 보조. 또는 AI로 재료만 만들고 편집은 직접. Veo3→캡컷 자동 연동 (비토리) |
| 5 | **운영 자동화**: 30분 주기로 룰 판정(예: CPA 9만원↑ OFF) → 확실한 건 자동 ON/OFF, **애매한 건 사람에게 노티**. 클로드 + 슬랙 |
| 6 | **시간대·요일 감액**: 00시 -20% → 09시 롤백. 주말·공휴일 -20% 상시 (밤·휴일 효율 저하) |
| 7 | **위닝소재 확장**: 테스트로 위닝소재 발굴 → 변주·바리에이션으로 확장 (애니·오십견·의사 등 잘 먹힌 결을 반복) |
| 8 | **위닝멘트**: 후킹되는 정형 문구. '뼈말라'(다이어트) · '모공흉터가 차오른다' · '방광염을 소변으로 배출한다' · '여드름을 뿌리째 뽑아준다' · '쥐젖을 얼린다' |
| 9 | **결핍별 랜딩 분리**: 한 제품이 여러 결핍을 커버할 때, 소재 결핍과 랜딩 결핍을 **일치**시킨다. 오십견 소재 → 오십견 전용 페이지(썸네일·상단후기·상페 상단 교체)로 랜딩 → 고객이 "오십견 전용 제품"으로 인식 |
| 10 | **소셜 프루프 선적재**: 댓글·좋아요 있는 소재가 효율 높음. 자동으로 찍거나, 최소한 위닝소재엔 달아둘 것 |
| 11 | **틱톡**: 전환율 약함. **트래픽·리타겟 모수 수집용**으로 볼 것 |

## 확정 사항 (Q&A로 해소)

- 원문의 "클로그" = **클로드(Claude)** 오타.
- 결핍별 전용 페이지는 **자사몰**에서 진행. "DA 제품은 모두 자사몰로 랜딩 설정 — 네이버·쿠팡은 픽셀 설치도 안 되니까." → 스마트스토어 상품 복제가 아니므로 후기 분산·어뷰징 리스크 해당 없음.

## 위키와의 충돌 1건

**#6(시간대 상시 ±20%) ↔ [[메타 광고]]의 박영현 3등급 주장("테스트 캠은 일 20~30%만, 급변하면 다음날 구매 0·회복 불가")**

- 등급이 다르다 — 이쪽이 2등급, 박영현이 3등급. 규칙상 낮은 숫자 우선이나 **전제가 다를 가능성**이 커서 단정하지 않고 병기한다.
- **해소 가설(미검증)**: 학습이 끝난 스케일업(CBO) 캠페인은 예산 변동을 견디고, 학습 중인 테스트 캠페인은 못 견딘다 → 둘이 서로 다른 캠페인을 말하는 것일 수 있다.
- 검증법: 우리 계정에서 스케일업 캠에만 시간대 감액을 걸어보고 다음날 회복 여부 확인.
