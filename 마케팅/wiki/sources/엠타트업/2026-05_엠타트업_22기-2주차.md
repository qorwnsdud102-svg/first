## 요지

- **1강**: 플러스 에너지 본론 (양극·순환·플에거지·회초리도 플에·한영키·손흥민 사례·신문 테스트) → 프레 3종 (성과공유 1+10·인정·부족인식) + 제약 선포 → 인정 (예양과 지백 고사·직원 칭찬법) → 자기소개 발표 릴레이 (오일남·보라색뼈·폭풍의시·양파도둑놈·예양).
- **2강**: 선택제어 미션 리뷰 — **주도권 정련** (이지선다 = 주도권 無·안좋vs좋 / 더블바인드 = 주도권 有·좋vs더좋, 상페는 전부 더블바인드) · 역피라미드 본질 = 좁아지기 (비커형 안티패턴) · 무당형 = 역피의 최종 압축 · 손해보지 않는 이지선다(후불제) · 마녀2 상위 프레임 탈출 → 등가교환 미션 리뷰 (딸깍지수·윈도우 정품·대물림·부모 3유형).
- **3강**: 골포커싱 디테일·무의식 조종(쭈꾸미) → 가두리 카페명 세분화 첨삭 (원룸의 모든 것·졸피뎀 단약·약수키·외모정병) → 팬덤 다루기 (한국인 클로징 못함·홀덤 VIP방·덕질거리·산후조리원 959명 사례) → DB 훼손 6단계 → 어그로 밸런스 → DB 관리 (3축 분류·부분 발송·명분/혜택 비율·후기 DB·타이밍 캘린더).
- **4강**: 부활 = 스팸이 아니라 편지 (명분+혜택 표본 다수) → 사고력 미션 (자동차 CV — M군 차량 이력·구매편익 4재·소득 역설) → 가1등급 프레임 깨기 3법 실전 → **레이어·궤도·패턴** (정체성 변화론) → **CV(코어밸류) 본강의** (생선뼈·진짜 왜?·배제법·연예인 코어·재회 컨설팅) → 구매편익·왜 파는가 3축 → 엠타 관람차 채널 구조.
