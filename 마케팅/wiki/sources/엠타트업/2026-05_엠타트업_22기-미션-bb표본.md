# [source] 엠타트업 22기 미션 색인 + bb 표본

## 이 페이지의 목적

미션 = 개념의 실습 — **bb(강사진 인정) 받은 답변 = 개념을 제대로 적용한 표본**. 신뢰 등급: 미션 과제·강사 교정 = **1등급** / bb 받은 수강생 답변 = **3등급 상위 (bb)**.

## bb 받은 표본 (미션별 백미)

### 1주차 1. 선택제어 — bb 4박자: 타겟 특정 → 증상 정조준 → R 귀결 → 구멍 차단

- **75번 무당형 (라온 bb + 코멘트 "이런 소리를 들은 타겟은 빠져나가지 못할 듯")**: "비 오면 무릎관절 뚝뚝 소리 나지? 관절윤활세포 노화로 연골 부딪히는 소리야. 지금 관리 안 하면 인공관절 해야 돼."
- 17번 무당 (m군 "무당만 b"): 다이어트 "언제까지 식단·운동 가스라이팅 당할래, 결국 체질 문제였던 거 몰랐지? 리뷰 키빼몸 보이지?"
- 20번 4기법+R (m군): 리딩방 "벼락거지 된 기분이죠?"(역피) / 대행사 "ROAS 박살나셨죠?"(무당) / R "1년짜리로 또 실패할래, 3개월짜리로 작은 성공 경험할래?"
- 1조 3번 임산부 손목보호대 (m군): "애기 무게는 점점 무거워지는데 지금이라도 관리할래?" + 산후 골든타임.
- 99번 (솔대표가 **직접 모범답안 작성**): 아동 상담 — "1:1로 차근 시작할래? (소그룹이라 자세히 봐주는) 목요일 그룹 들어볼래?"
- 78번 자취방 이지선다 자각 (솔대표): 허름한 반지하 먼저 → 멀쩡한 방 계약 — "낮은 사고력의 대가."
- 그 외: 47번 관절(캐리아)·1번 성장판(라온)·11번 위고비 비교(캐리아)·86번 왁싱(라온)·24번 아토피(라온)·87번 유산균(라온)·50번 이어폰 재미션(라온)·60번 노묘 검진 역피(솔대표)·27번 반려동물.

### 1주차 3. 등가교환 저울 수리 — 솔직 자백 + "자기구속 장치"

- bb 패턴: 부끄러운 자백(코인 풀배팅·뉴토끼·넷플 무단공유·배달쓰레기 투척·답지 패턴) + 재발 방지를 추상 다짐이 아닌 **장치**로 — 37번 "등가교환 없이 정신병 걸릴래 vs 고통 받아들이고 100억 모을래" 셀프 더블바인드(라온 bb) / 가산세 1.5배 기부 / "공짜로 받은 것" 라벨 부착 / 전 과정 아날로그 강제(캐리아 bb).

### 1주차 5. 가두리 카페 — 카페명 세계관 + 손실회피 유입 문자

- bb 패턴: 카페명에 타겟 정체성 (코뮤니티[비염]·차방전[차]·몰랩[흑채]·성회연[재수술 방지]) + 문자는 "도착 확인" 명분 → "**~하면 안 되는 실수 N가지**" 손실회피 후킹으로 링크 (전부 라온 bb. m군 bb는 "혜택 vs 제로마케팅 비교 사고 과정"을 쓴 표본).

### 1주차 7+2주차 3. 부활 편지 — "욕심은 숨기고 헤아려라" (m군 새벽 가이드 = 1등급)

- m군 교정 가이드: 가짜 말고 **진짜 사연** / 가족·친구한테 쓰듯 / 타겟이 왜 샀는지·지금 상태·뭘 알면 좋은지로 접근 / 욕심은 숨겨라.
- **64번 (m군 bb)**: "1년 전 깔창 구매자께 — 덕분에 세 가족이 원룸에서 이사 갈 수 있었습니다. 보답으로 26분께 50% 교체" (진짜 사연+한정).
- **68번 (라온+m군 bb)**: 리뷰 4점↑ 고객에 "선크림 병행" 걱정 명분 + 샘플 — 신청폼은 공개·댓글 차단으로 문자 고객은 혜택, 카페 회원은 자발 신청 = **죽은 DB와 신규 DB를 동시에 갱신하는 더블바인드**.
- 39번 (솔대표+m군): 방문요양 자녀 타겟 — 어르신 호전 영상 + "병원이 당부한 사항" 링크.
- 그 외: 트리거 명분 다이어리(20번)·노령견 "하지 않은 것 5가지"(27번)·상위 5.7% 학습 리포트(78번)·"성범죄자랑 같이 뛸래" 발목보호대(63번)·"촬영 요청 못 드린 미안함" 피부샵(솔대표 bb).

### 1주차 8. 사고력 테스트 — 심층 동인까지 + 광고 해부 후 재작성

- bb 패턴 (거의 전부 m군): 차 = 비교·계급·"공간을 공유하기 싫음(공간=권력)"·"몸이 아니라 위치를 지키는 시대"·결국 **사랑받고 싶은 마음** / 광고는 비판이 아니라 타겟·결핍·프레임·이득 구조(차품딜 더블바인드: 고리로 팔아도 이득, 차 뺏어도 이득)까지 해부 + 직접 재작성(82번 등드름 "땀 한 바가지 흘린 날도 남는 건 오직 향기뿐").

### 2주차 2. 무의식 조종 — "의식이 닿지 않는 동선"에 목표 심기

- 라온 줌 교정 (1등급): "립밤은 약함 — **운전 중 백미러**처럼 의식 못 할 동선에" (8번 재미션 bb). bb 표본: 비밀번호=목표 자산(68번 솔대표)·가족 연락처 이름=목표 순익(59번 솔대표)·화장실 천장 딸 사진(20번 라온)·미래의 나에게 예약문자.

### 2주차 5. 팬덤 관람차 — 코어 플랫폼 수렴 설계

- **19번 (솔대표 bb)**: 옵챗 코어 → 미구매자로 카페 먼저 키움(1,000명) → 활성화 후 구매자 합류 "구매자는 저렇게 이득 보네" 연출 → 카페로 코어 전환. CV가두리/맞추기/다루기 3정의 포함.
- **88번 (솔대표 bb)**: 두피염 샴푸 — 원인별 "00단"(새벽단·과몰입단·습기단) 분류 + "나만 이래?" 한풀이 코너 = 가두리 먹이 + 원인 교차로 다른 R 관람차 환승.

### 3주차 1. 3의 전략 — 단계 서사 + 등급·매몰비용

- bb 패턴: ①제품·변화를 1·2·3단계로 쪼개 "순서 안 지키면 효과 반감" (라온 본인 표본: 유산균 적응형→체질형→안정형, 2단계는 1단계 구매자만) ②등급 호칭 (무수리→황후[26번 m군]·숭덩이→촘촘이→풍성이[91번 캐리아]·도전자→시민권자[20번 m군]) + 마일리지·유효기간 클로징 ③"공짜로 줘도 레퍼런스·DB로 이득" 손익 재해석 (사두증 헬멧 20회 100%[35번 라온]).

### 3주차 2. 이상적 R — 욕구의 근원 결핍을 마법처럼

- bb 패턴: 표면 기능이 아니라 근원 결핍을 단번에 (부작용 없는 스테로이드[8번]·3대 욕구 마비약[93번]·영화 주인공 껌 "형상을 빌려 주체성을 갖고 싶다"·러브 렌즈·드림컨트롤러·반려견 수명 연장).

### 3주차 3. 내맘대로 재구매R — 교체주기 시각화 + 개연성

- **m군 교정 (1등급)**: 59번 드라이기 변색센서에 "bb **다만 개연성은 조금 부족**" — 제로마케팅은 공포가 아니라 **납득 가능한 개연성**이 핵심.
- bb 표본: 풍수지리 절기·삼재 주기화 (15번 — 실판매까지) / 내솥 "세이프링" 코팅 마모 시각화 (77번) / 젖병 Replace-time 패턴 (72번) / 제빙기 정기관리 B2B "얼음에도 노로바이러스" (102번) / 액막이 부적 3~6개월 자동 변색 (30번) / m군 본인 예시: 공구의 소모품화·산후조리원 재입소화.

## bb 종합 패턴 (전 미션 관통)

1. **타겟을 좁히고 그 타겟만 아는 디테일을 찍는다** (무당의 본질).
2. **개념을 내 R에 실제 적용한 편이 인정받는다** — 일상 사례 나열만으로는 부족.
3. **장치로 묶는다** — 다짐이 아니라 더블바인드·등급·시각화 장치·동선 설계.
4. **공포·욕심이 아니라 개연성·진짜 사연** — "납득 범위"를 벗어나면 교정당함.

## 강사진 분담 관찰

m군=사고력·심층 꿰 전담 / 라온=가두리·부활·재미션 다수 / 캐리아=등가교환·생활 패턴 / 솔대표=설계형(관람차·무의식)+직접 모범답안 작성. "작형"은 미션 bb에 미등장.
