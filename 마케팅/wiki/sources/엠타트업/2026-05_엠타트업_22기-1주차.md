## 요지

22기(기수명 "안녕", 테마 "부활", 슬로건 "100억 100개")의 개막 주. **재구매·팬덤·가두리로의 대전환** 선언 — "한 번 팔 거면 안 팔아."

- **1강**: 캐리아 오프닝(멘탈·선택과 집중·감시캠) → M군: 자본주의 서열 게임(돈·힘·뇌) → 11개의 약속 → 부활(낙차 이론) → [[선택제어]] 시작 (양자택일: 이지선다·더블바인드).
- **2강**: 소거법(역피라미드형·무당형) → 배제된 목표(비우기·노력 총량·양파 거지의 저주) → [[코어 벤치마킹]](JYP 패턴) → 소비자 vs [[팬덤]] → [[가두리]] 채널 7종 선언.
- **3강**: 4번의 메시지 → 타겟 맞추기(치킨집 73,000팀 후회·베이커리 실패 사례·코치 제품 3종) → 가두리 카페·오픈톡방 설계 → 판매·모으기·맞추기·다루기·문화 5단계 + 코어(CV).
- **4강**: [[부활]] 프로젝트(명분+혜택·리콜형/안내형·DB는 신이다·개인정보법 경계) → DB 게임(운동·질병·다이어트) → 재구매 RCS → [[사고력]](점선면·꿰뚫기·프레임 깨기 3법·오늘만 만원).
