# [source] 카페 외부 상위노출 로직 강의 (2026)

## 출처

사장님이 수강한 "카페 외부 상위노출 로직" 강의 자료(카카오톡 수신, OneDrive 보관). 원본 파일은 위키 repo 밖(OneDrive)에 있으며 raw로 복사하지 않음.

## 반영 범위 — 경계

이 자료는 두 층으로 나뉜다.

- **① 네이버 노출 로직** (반영함 → [[바이럴]] "노출 면 3종 / 글 최적화 기준") — 노출 면 3종(카페탭·인기글·신규통검), 아이디 연식(4차) 영향, 본문 자수·키워드·댓글·사진, 과장/홍보 단어 회피, 씨랭크, 반영 타이밍, 위험키워드=실명. 검색 노출 원리(SEO) 지식.
- **② 자동화·계정운영·적발회피·신고 인프라** (**미반영**) — 안티캡차(캡차 우회), 비실명 계정 농장·가상PC·서버컴퓨터·IP 로테이션 대량 자동발행, '침투'(운영진 탐지 회피), 경쟁사 신고 takedown, 의료기기·건기식 가짜 후기 대량 생성. **플랫폼 탐지 회피 + 대량 기만 후기(규제 카테고리) 운영 매뉴얼에 해당하여 위키에 정리하지 않음.**

②가 필요하면 원본 파일(OneDrive)을 직접 참조. AI는 ②의 체계화·운영화는 지원하지 않음.
