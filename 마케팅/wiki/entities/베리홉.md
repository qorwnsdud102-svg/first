# 베리홉

## 한 줄 정의

**퍼포먼스 브랜드를 만든 대표**가 운영하는 퍼포먼스·DA 광고 강의(자사몰 복붙강의·트렌드헌터·연봉상승바이블). "**광고 세팅은 스킬이 아니다 — 제품·기획·소구점 발굴과 소비자 테스트가 퍼포먼스의 핵심**"이 일관된 명제. (기존 [[그로스짐]]에 강사 사례로 언급되던 엔티티의 본체)

## 브랜드 정체

[[그로스짐]] 기록상 베리홉(Verihop) = **비타민C 앰플 브랜드** — 15ml 49,800원, **원가 6%**, **월 40억**, 그로스짐 강사와 0매출부터 함께. (강의의 "미백앰플 시장분석"이 이 제품군) → 고마진·고객단가 구조의 표본.

## 핵심 명제 — 세팅이 아니라 소구점·테스트

> "광고 세팅은 의외로 스킬의 영역이 아닙니다. 제품/기획/소구점을 발굴하고 이미지·영상으로 표현한 **소비자 테스트**가 퍼포먼스 광고의 핵심."

- 퍼포먼스 광고 = **이미지·영상으로 소구점을 표현**하는 광고.
- **핵심 메시지는 한 문장으로**, **소구점은 여러 갈래로**. (어떤 소구점이 매출로 이어질지는 이론적 판단 불가 → 다양화해서 테스트)
  - 예: 호박차("1팩 30리터 붓기차" + 티소믈리에·임산부 가능·원료효능), 탈모 샴푸, 셰프 닭발.
- **일매출 50~100만원까지는 이 세팅법**으로 충분.

## 메타 광고 운영 규칙 (실무)

- **구조**: 1캠페인 → 4~5 광고세트 → 4~5 소재. **ABO**(광고세트 예산조절) / **CBO**(캠페인 예산조절).
- **예약 설정**: 시작 = 현재 + 12~18시간.
- **증액 기준**(전환캠페인): 하루 지나 2~3건↑ 구매 시 / 브랜드 **손익 ROAS보다 50%↑** 시 / 일 30만원 넘으면 **20%씩 증액**. (CPM 기반 — 2배 증액은 노출 급증, 20%는 완만)
- **OFF 기준**: 하루 지나 구매 0 / 손익 ROAS보다 20%↓ / **1000회 노출 무구매**(세트) / **CPC 2~3,000원 초과**.
- **기본 용어 4개면 충분**: CPC·CPM·CTR·ROAS.

## ROAS는 실제보다 더 기여한다 (낙수 = 통합 로아스)

> "**ROAS 200% → 실제로는 220~230% 기여.**"

광고가 만든 수요가 페이스북·블로그·인스타·유튜브 검색·쇼핑몰 후기를 거쳐 구매로 이어지므로, 표시 ROAS보다 실제 기여가 큼. → [[통합 로아스]](자사몰 직접 + 쿠팡·네이버 낙수)의 강사 측 근거. "광고비는 소비(X) 투자(O)."

## 퍼포먼스 믹스 5대 이해 (연봉상승바이블 — 300억 소진 마케터)

제품 · 소비자 · **퍼널 구조** · 광고 지면 플랫폼 · 광고 목적/상호작용.

- **퍼널 7단계**: 인지→고려→방문→재방문→구매→추천→재구매(+이탈 시나리오). 단계별 적합 매체 다름(인지=확산, 재방문=저렴한 리타겟, 구매=접객).
- **광고 추적 3종**: 쿠키 / AD ID / 파라미터(UTM). 여러 방식 교차 검증.
- **데이터 통찰 루프**: 문제파악 → 데이터 확인 → 가설 → **2주 검증** → 개선. "분석은 심플, 개선안은 고객관점, 검증은 데이터로."
- **원가 구조가 좋아야 퍼포먼스 지속** — 판매가 −(원가+고정/변동비+광고비)=순익. 객단가↑(세트·옵션 2+1·5+2).
- **시장분석 12종**: 판매 성수기·키워드 검색량/변동·경쟁사 5곳(가격·구성·혜택·USP)·리뷰/Q&A·썸트렌드 긍부정어·경쟁사 브랜드검색량·1위 상품 판매량·인플루언서 동향·경쟁사 솔루션 등.

## 실험 사례 (사이트의 모든 요소 = 실험 대상)

| 브랜드 | 핵심 포인트 |
|---|---|
| **세남자바스켓(마리모)** | "살아있는 마리모" USP + DIY 어항 구성, 인스타 명함 인증 바이럴(1개월 400만 조회), 매출 10배 |
| **모그라미(스킨이즘)** | "피부같은 팬티 얇다" USP, 연상되는 네이밍, 페북 검증→GFA 확장, 시그니처 자세 브랜딩, 옵션 2+1/5+2 |
| **한우(조은장터)** | DA 실패 → 검색광고·스마트스토어 상위노출 집중, 농협 신뢰 메시지, 효율 3배 |
| **착한구두** | 페북 3계정 컨셉, 세트상품·재입고알람, 상페 A/B, 지그재그 베스트 이미지 전 매체 적용 CTR 50%↑ |

→ 공통: **컨셉 전환이 ROAS·볼륨을 바꾼다**(보습→향기, EMS마사지기→다이어트 EMS, 여드름토너→4050 좁쌀여드름 토너). "수정·측정 가능하면 전부 실험."

## 마케터 3년 성장 로드맵

1년차(용어·매체 세팅·제품/매체 본질·퍼널 기본) → 2~3년차(데이터 통찰·믹스 전략·리포지셔닝·CRM 설계) → 3년차+(퍼널~전략~콘텐츠 총괄·즉각 개선). 커뮤니케이션: 경청·정확·신속·복명복창.

## 다른 엔티티와의 관계

- [[통합 로아스]] — "ROAS 200%→230% 기여"가 낙수 개념의 근거.
- [[DA 광고]] — 소구점을 이미지·영상으로 표현 + 소비자 테스트.
- [[그로스짐]] — 같은 퍼포먼스 진영. ABO/CBO·퍼널·객단가·시장분석 등 메소드 상당 부분 공명(중복 시 교차 참조).
- [[상페 구조]] · [[접촉지점]] — 퍼널 단계·매체 믹스와 연결.
- [[결핍 상품 소싱]] — "원가 구조·USP·컨셉"이 결핍 상품 선택과 같은 결.
