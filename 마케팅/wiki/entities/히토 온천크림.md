# 히토 온천크림

## 한 줄 정의

사장님 자사 제품. **관절통 치료 크림** — 온열감 마사지 크림이 아니라 병원 연골주사·물리치료를 집으로 가져온 포지션. `hito.kr` 자사몰.

## 기획 구조 (마케팅 캔버스)

**포지션**: 온열감만 주는 마사지 크림 X → **관절염 치료크림** (세분화 확장 카테고리)

### 상징재 4겹

| 목적 | 장치 | [[상징재]] 분류 |
|---|---|---|
| 일본에서 유명한 제품처럼 | **동전파스 외형** | ③외형 따라하기 |
| 관절에 좋은 일본 온천 | **홋카이도 카루루스 온천수** | ①국가 사대주의 ②국가적 특장점 |
| 기능 좋음 | 스피큘(빠른 흡수)·보스웰리아·MSM | (당위성 부품) |
| 병원에서 쓰는 제품 | **일본산 PDRN**(연골주사 성분)·물리치료용 | ⑦의학 상징성 ⑥트렌드 차용 |

### 타겟

50대 전업주부 / 10년 이상 손가락마디통증 / 병원 주사·진통제로 차도 없음 / 집안일 많음
→ **"설거지·집안일 할 때마다 욱신거리는 통증을 없애고 싶다"**

### 차별점

- 파스 냄새 제거 (멘톨향 X)
- 보스웰리아를 **먹는 영양제가 아니라 바르는 것**으로
- 온열감이 보스웰리아 흡수를 돕는다는 당위 (따뜻한 기운에서 잘 흡수)
- 스피큘로 빠른 흡수

### 권위 근거

후기 2,086 · 개발 3년/개발비 10억 · **일본 라쿠텐 역수출템** · 약국 입점 · 프로골퍼 사용 · 일본 인플루언서 리뷰

- **한 제품 = 여러 결핍** — 오십견·무릎·엘보·손가락마디로 갈라짐

## 내 생각 / 미해결

- **상페가 "부위 무지정"이다.** 캔버스 페르소나는 손가락마디 50대 주부로 뾰족한데 상단은 성분 중심. 검색량도 상위 4개가 3만 내외로 촘촘해 어느 하나를 메인으로 잡을 근거가 약하다 → **부위별 랜딩 분리**가 데이터에 더 맞음.
- **상세가 이미지 34장이라 부위별 랜딩 분리 시 디자인 재작업이 통째로 든다** — 실행 최대 병목.
- **동전파스 외형이 [[상징재]] 경고에 걸린다.** 동전파스 7,470 / 일본동전파스 7,790으로 검색량이 작고 저가 이미지. 35,900원 제품이 빌리기엔 상징성이 약하고 가격 저항을 만들 수 있음. 반면 **콘드로이친 144,800**은 압도적인데 안 쓰고 있다.
