# 히토 온천크림

사장님 자사 제품. **관절통 치료 크림** — 온열감 마사지 크림이 아니라 병원 연골주사·물리치료를 집으로 가져온 포지션. `hito.kr` 자사몰.

## 제품 카드

- **무엇**: 바르는 관절 크림 — 홋카이도 카루루스 온천수 + 일본산 PDRN(연골주사 성분) + 스피큘(빠른 흡수)·보스웰리아·MSM
- **가격**: 35,900원 (정가 52,900) · 세트 4단 6개월 26,930 ~ 단품 35,900 (2026-08-20 자사몰 기준)
- **포지션**: 온열감만 주는 마사지 크림 X → **관절염 치료크림** (세분화 확장 카테고리)
- **타겟**: 50대 전업주부·10년 이상 손가락마디통증 — "설거지·집안일 할 때마다 욱신거리는 통증을 없애고 싶다"
- **핵심가치**: [[상징재]] 4겹 (동전파스 외형 / 일본 온천수 / 기능 성분 / 병원 성분 PDRN) · 파스 냄새 없음 · 보스웰리아를 먹지 않고 바름 · 권위 = 후기 2,086 · 일본 라쿠텐 역수출 · 약국 입점

→ 상세(기획 캔버스·검색량·자사몰 실측·상페 구조·상페 개선 메모): `마케팅/프로젝트/히토-온천크림-제품카드/기획캔버스-이관.md`
