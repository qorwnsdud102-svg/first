# 엠타트업

## 한 줄 정의

대한민국 이커머스 강의·교육 프로그램. 사장님 학습의 **주된 1차 출처**. 마케팅 전술뿐 아니라 마인드·삶의 운영까지 가르치는 종합 교육.

## 사장님 수강 정보

- 수강 시점: **2025년 10월** (21기 자료) → **2026년 4~6월 22기 본수강**
- 수강 차수: **21기** (본강의 21기: 2025-08-09 ~ 2025-09-27, 8주간) — 자료로 학습
- **22기** (본강의: 2026-04말~2026-06-06, 매주 토요일 6주 — 1주차 2026-05-02 추정) — 직접 수강

## 22기 — 기수 정보

- 기수명 **"안녕"** → 3주차에 **"지백"**으로 변경 ("여러분이 저의 지백입니다" — [[마인드/인정]]) · 주차 테마: 1주 "부활" → 2주 "인정" → 3주 "각성" → 4주 "프레임" → 5주 "욕구" → 6주 "클로징" · 슬로건 **"100억 100개"** · 기수명 지백 = 예양과 지백(인정) + **지(0)→백(100)** 이중 의미 · 정규 6주 후 7주차(수료식)·8주차(비대면) 연장
- 구성: 105명 + 깍두기 3명. 75명이 월 1천만원 이상, 45명이 월 3천만원 이상
- 메인 테마: **[[사고력]]** (21기 "자관인간"의 후속 어휘) + **재구매·[[팬덤]]·[[가두리]] 대전환** ("한 번 팔 거면 안 팔아")
- 11개의 약속: ①마이너스 감정 버리기(플러스 에너지) ②6주 올인 ③진짜 욕구 ④주인공 ⑤비우기 ⑥환경 설정 ⑦올바른 프레임(수익 vs 더 큰 수익) ⑧초월 ⑨미션=돈(GPT 금지) ⑩제로 심리(100억 본전) ⑪기회(6주가 마지막)
- 강사: M군(본강의 — 음성전사 표기 "앵구님"도 동일인) + 캐리아(멘탈 오프닝, "위기엔 캐리아") + 라온(미션 피드백)
