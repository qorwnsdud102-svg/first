# 접촉지점

## 한 줄 정의

타겟이 R을 만나는 지점. **거리(가까운가/먼가)** 에 따라 채널·키워드 전략이 갈린다.

## 접촉지점 거리 = 채널 전략

- 멀어도 OK인 R → **레드 전략** (노출 위주, 키워드 검색 잡기)
- 가까워야 하는 R → **블루 전략** (해당 타겟 플랫폼에서 데리고 옴)

> "타겟 좁히면 레드도 블루 됨."

## 키워드 깊이 = 욕구 깊이

순위 낮은 연관검색어일수록 더 구체화 / 범위 좁아짐 / 욕구 깊음.

| 키워드 | 검색자 심리 |
|---|---|
| 키크는법 | 그냥 욕구를 가진 사람 |
| 키크는영양제 | 욕구를 가볍게 해소하고 싶은 사람 |
| 키크는 운동기구 | 영양제보단 욕구 깊음 |
| 성장판자극기 | 욕구 해소 마음이 큰 사람 |

→ 정보키워드 vs 구매키워드 구분 후, 검색자 심리에 맞춘 스토리라인.

> "광고는 클로징이 90%."

## 플랫폼별 R 매칭

| 플랫폼 | 적합 R | 사용자 행태 |
|---|---|---|
| **네이버** | 메인느낌의 사이드 R | 꼼꼼히 비교, 키워드 노출 중요 |
| **쿠팡** | 메인인데 조금 이상한 R | 빠른 결정 — 썸네일·디자인·상페로 시선만 끌면 구매 |

## 사이드의 사이드 (사사)

> 추석 1차원 R: 홍삼·선물세트
> 2차원: 용돈박스·장거리 차에서 쓰는 거
> 3차원: 추석에 길게 쉬니까 여행 → 비행기 목배게

→ R 후보 발굴은 시즌 키워드의 3차원까지 파고들기.

## 키워드 접촉지점 분류 (차수) — 실전 (허리견인기)

타겟이 검색할 키워드를 **구매 의도와의 거리(접촉지점)로 1차~5.5차** 분류. 가까울수록(1차) 전환↑·풀 좁음, 멀수록(5차) 풀 크지만 인지 단계.

| 차수 | 성격 | 예시 키워드 (월 검색량) |
|---|---|---|
| **1차** | 제품 직결(구매 임박) | 허리보호대(30,840)·허리견인기(3,770)·견인치료·허리지지대 |
| **2차** | 치료·병원 | 허리디스크치료·허리통증병원·허리신경주사 |
| **2.5차** | 시술·검사 | 프롤로주사·MRI가격·신경차단술 |
| **3차** | 증상·질환 | 허리통증(29,770)·허리디스크·좌골신경통·허리삐끗 |
| **3.5차** | 세부 질환·약 | 협착증·체외충격파·리리카캡슐·스테로이드주사 |
| **4차** | 먼 질환·세부 | 요추위치·전방전위증·척추측만증교정기 |
| **4.5차** | 치료법·비용 | 도수치료(44,710)·물리치료·추나요법 |
| **5·5.5차** | 가장 먼 연관 | 강직성척추염·다리저림·근골격계질환 |

(전체 키워드·검색량·입찰가 목록은 실무 데이터 — 사장님 파일.)

### 차수별 무기 + 구좌 장악 (SERP 도배)

- **가까운 차수(1~2차, 높은 의도)** → 파워링크·쇼핑탭·[[허브키워드]]로 직접 전환.
- **먼 차수(3차+, 증상 검색)** → [[파워컨텐츠]]·[[바이럴]]로 인지→설득→낙수([[통합 로아스]]).
- **한 키워드 = 모든 구좌 장악** — 예: "허리보호대"에서 **파워링크 1자리 + 쇼핑탭 상위 + 파워컨텐츠 구좌 + 스마트블럭·인기글의 카페 구좌·블로그 구좌**까지 동시 점유. CPC 감당되는 선에서 "내 글·광고를 최대한 노출"하는 도배 방식.

## 허브키워드 기법 (물길) → [[허브키워드]]

광고 아닌 척 카페·지식인에 글 깔기. (상세는 [[허브키워드]]·마킹 참조)

- 같은 R이 비교당하지 않도록 키워드 장악
- 상위노출 쉽게 (허브키워드 검색 시 내 제품만)
- 상표 등록 가능한 키워드면 더 좋음 (예: 바이오트효소 샴푸, 키크는 운동기구)
- 고관여 제품이면 글 길게, **복붙 금지** (글 상황에 맞춰서)
- "브랜드명 노출" 보다 "입덧관리제품 먹었어요~" 같은 표현이 광고 느낌 덜 남

### AB셔플 기법

결핍 해소 위해 여러 가지 썼다고 하면서 그중 하나가 내 제품. 다른 제품은 유명하면 좋음 (신뢰 ↑).

## 다른 엔티티와의 관계

- [[RCS]] — C(채널) 결정 변수.
- [[마케팅 축]] — 7축의 하나.
- [[욕구와 결핍]] — 키워드 깊이로 욕구 깊이 측정.
- [[허브키워드]] · [[파워컨텐츠]] · [[바이럴]] — 차수별로 키워드 구좌를 점유하는 무기.
- [[결핍 상품 소싱]] — 차수 분류로 결핍 상품의 타겟 키워드 지형을 그림.
- [[통합 로아스]] — 먼 차수 검색자를 낙수로 회수.

## 본강의 21기 사례

### 블루베리 농장 침대 250만원 — 비교 차단된 접촉지점

> "M군님 어머니 → 역에서 전단지 받음 → 만원만 내면 블루베리 체험 → 블루베리 체험 농장(매출액 200억) → **녹용·침대 강매**."

타겟이 가격 비교를 못하는 곳으로 몰아넣기. 어르신 = 자금력 있고 항의 못함, 가격 비교 지능 적음.

### 모으기 전략 — 3개입

| 개입 | 행위 |
|---|---|
| 1개입 | 관광버스 (모으기) |
| 2개입 | 블루베리 체험 농장 (분위기·신뢰) |
| 3개입 | 제품 판매 (강매) |

→ 접촉지점은 **단일이 아니라 단계화**될 수 있다.

### 핵심 명제

> "우리의 타겟이 가장 많이 모여 있고 **잘 설득되는 곳**."

→ 단순히 타겟이 많은 곳이 아니라 **설득이 잘 되는 곳**이 핵심.
