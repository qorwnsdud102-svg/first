# 허브키워드

## 한 줄 정의

**내가 처음 만들어 점유한 검색 키워드**, 그리고 그 키워드의 **네이버 검색결과 전체를 통째로 내 설득 깔때기(개미지옥)로 만드는** 기법. 모든 광고·바이럴이 이 키워드 검색으로 모이게 해서 "허브".

## 왜 허브키워드인가 — 광고티 회피 + 검색결과 통제

직접 브랜드명을 밀면 광고로 들킨다. 한 단계 꼬아 **내가 만든 일반명사**로 유도한다.

- ❌ "일상곡선 견인기 써보세요~" → '아 광고네' 바로 들킴.
- ✅ "**곡선견인기** 중에 싼 거 쓰세요~" → 견인기 종류 중 하나인 줄 알지만,
- → 네이버에 '곡선견인기' 검색하면 **내가 처음 만든 키워드라 내 제품만 나온다.**
- → 검색결과 = 내 제품 + 그 밑에 깔린 블로그·카페 글(= [마킹](#마킹)).

→ [[프레임 분리]]의 "**누가 만든 일반명사는 단어를 점유하는 자가 시장**"(짭제니·발톱 앰플·마리오네트 주름)을 **검색 점유**로 실행한 형태.

## 역-광고 신뢰 전략 (counter-signal)

사람들은 요즘 네이버가 광고판인 걸 알아서 **광고글 특유의 패턴을 경계**한다.

| 광고글 패턴 (경계 대상) | 마킹 글 (의도적 반대) |
|---|---|
| 과하게 장점만 나열 | "뭐 나쁘지 않네" 정도의 미지근한 평 |
| 상위노출용 글자수 2,000자 꽉 채움 | **500자 대충** |
| 제품사진 이쁘게 연출 | **흔들리는 사진 1장** |

→ 잘 만든 광고보다 **허술한 내돈내산 톤이 신뢰감을 훨씬 더 준다.** 신호를 일부러 낮춰서 진정성을 위장.

## 개미지옥 — "스스로 검색했다"는 착각

- 모든 광고를 굳이 **제품페이지로 직결시키지 않는다.**
- 대신 '곡선견인기'라는 **검색결과로 사람을 모은다.**
- 사람들은 **자기가 스스로 검색했다고 생각**하지만, 사실 내가 깔아둔 개미지옥에 들어와 **한 번 더 설득당하는** 것.
- → 자발적 탐색처럼 보이는 경로가 사실은 설계된 깔때기. [[자각]]을 안 하게 만드는 게 핵심.

## 야사 — 네이밍 다타겟 판매 (수강생 14번, "매출 3배" 주장)

> ⚠️ 야사: 수강생 실전 주장 — 재현성 미검증. 출처: `sources/엠타트업/2026-06_엠타트업_22기-수강생노하우.md`

한 제품을 **네이밍만 바꿔 여러 욕구·타겟에** 판다 — 네이밍이 곧 허브키워드:

- 조건: 검색 시 제품이 특정 안 되는 단순 제품명(사과즙·넥밴드선풍기)이거나 영어 혼합 표기일 것. 예: 넥선풍기→넥에어컨·넥쿨러 / 공기청정기→신생아 전용·비염환자 전용 / 미스트→피부진정제·스킨디톡스.
- 적용 전 무조건 검색 — 겹침·유사글 없이 **내 글만 노출 가능한 환경**인지 확인. 쇼핑탭 안 떠도 파워링크로 가능, 쇼핑탭 원하면 '네이밍+카테고리어(미스트)' 결합.
- **카페24 노출 제어**: 상품분류관리 → 대분류 추가 → 메인분류 표시상태 '표시안함' = **네이버쇼핑엔 노출, 자사몰엔 미노출** — 허브키워드 검색자만 그 상품을 본다 (타겟·플랫폼별 가격 차등 가능).
- 활용: 타겟 쪼개기(연령·부위·결핍 깊이) / 플랫폼별 가격 차등 / 재고를 욕구 전환으로 처분.

## 마킹

> "보통 이런 허브키워드에 블로그·카페글을 진짜 내돈내산같이 올리는 걸 **마킹**이라고 해. '허브키워드 마킹하시구요' 이런 식으로."

- **마킹 = 허브키워드 검색결과에 내돈내산처럼 글을 심는 작업.**
- 심는 글의 형식이 곧 [[파워컨텐츠]] 골격(소비자 위장·고생담·대안 까기). 즉 **마킹 글 = 파컨 형식 글**.
- 허브키워드(자리) + 마킹(까는 행위) + 파컨 형식(글 내용)이 한 세트로 도는 퍼널.

### 마킹 글의 3형식 (표본)

| 형식 | 표본 | 특징 |
|---|---|---|
| **블로그 1인칭 후기** | 곡선견인기 "아빠 허리디스크 늘려준 후기" (여르미) | 803자·이미지 9·링크 0. 가족 화자(딸→아빠). "검색하다 알게 됨" |
| **카페 Q&A + 댓글 유도** | 릴랙스넛 "써보신 분 계신가요?ㅠㅠ" → 댓글 "저 써봤는데 괜찮아요" | 질문글로 던지고 댓글에서 자연 유도. [[프레임 분리]] 다이어트 댓글 예시와 같은 결 |
| **카페 내돈내산 게시판** | 릴랙스넛 "조카 선물준 환도마사지기" (구매처·가격·장단점·총평 양식) | 게시판 정형 양식. "이모가 사줘서 단점 못 말함" 식 허술함이 진정성 |

### 핵심 관찰

- **화자 = 가족·지인** (딸·이모) — 직접 사용자보다 광고티가 더 옅다. "내가 아픈" 게 아니라 "아빠/조카가 아파서 찾아줌".
- **"검색하다 알게 됐다" 장치** — 글 안에서 자가검색을 한 번 더 연출 → 독자의 [개미지옥](#개미지옥--스스로-검색했다는-착각) 진입을 정당화.
- **경량 변주** — 마킹 후기는 [[파워컨텐츠]] 본글(4,000자·비교표·기준·링크)의 **라이트 버전**: 고생담·대안 까기·자가발견은 살리고 기준표·구매 링크는 빼서 "그냥 후기"처럼 보이게. 본글(설득) ↔ 마킹(신뢰 깔기) 역할 분담.

## 다른 엔티티와의 관계

- [[프레임 분리]] — "누가 만든 일반명사 점유"(그로스짐 4주차 중간 허브 키워드)의 검색 실행판. 허브키워드 = 창작한 컨셉 단어를 검색에서 독점.
- [[파워컨텐츠]] — 마킹 글의 형식이 곧 파컨. 허브키워드 검색결과가 파컨 글의 유입 목적지.
- [[선택제어]] — "곡선견인기 중에 싼 거" = 카테고리 안에서 선택지를 내 제품으로 좁히는 소거.
- [[프레임 조종]] / [[자각]] — 자발적 검색이라는 착각으로 광고 자각을 차단.
- [[상페 구조]] — 검색결과(물 아래) → 설득 → 제품링크로 이어지는 깔때기의 상류.
- [[바이럴]] — 허브키워드 마킹 = 바이럴의 한 형태(내가 만든 검색 자리에 거는 바이럴).
