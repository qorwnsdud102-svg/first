# 파워컨텐츠

## 한 줄 정의

네이버 검색광고 구좌의 한 종류이자, 그 구좌에서 **소비자인 척 1인칭 경험담을 써서 설득하는 글 유형**. 클릭하면 제품페이지가 아니라 **카페·블로그 콘텐츠로 유입**시켜 글·이미지로 설득한다.

## 두 가지 의미 (구좌 ↔ 글 유형)

- **구좌(원래 뜻)** — 네이버 검색광고 상품명. = 브랜드컨텐츠. 클릭 시 제품페이지가 아닌 카페·블로그로 보냄.
- **글 유형(파생 뜻)** — 그 구좌에 위 양식으로 글을 많이 올리면서, **소비자인 척 써서 광고하는 글** 자체를 "파컨/파워컨텐츠"라 부르게 됨.

→ 본질은 [[상페 구조]]의 **"물 아래/바이럴 콘텐츠" 레이어를 유료 구좌로 산 것**. 광고처럼 안 보이게 하는 게 핵심.

## vs 파워링크 — 난이도가 덜 치열한 구좌

|           | 파워링크                          | 파워컨텐츠                        |
| --------- | ----------------------------- | ---------------------------- |
| 대중성       | 매우 높음 (마케팅 모르는 오프라인 가게도 많이 함) | 낮음                           |
| 가능 키워드    | 광범위                           | **한정적**                      |
| 광고등록 검토   | 느슨                            | **까다로움**                     |
| 진입장벽      | 낮음                            | **높음** (검토·키워드 제약 = 곧 기회)    |
| 키워드당 구좌 수 | 많음                            | **2~3개뿐** → 들어가면 그 안에서 경쟁 치열 |
| 클릭 후 도착지  | 제품페이지(랜딩)                     | 카페·블로그 콘텐츠                   |

→ 검토·키워드 제약이 **진입장벽**이라 아무나 못 들어오지만, 일단 들어가면 **구좌가 2~3개뿐**이라 그 안에서 경쟁이 치열해진다.

### 전환율 우위 (핵심 장점)

파워컨텐츠는 **설득력 높게 글을 쓰는 방식**이라, 글만 잘 쓰면 **클릭하면 바로 제품페이지로 유입되는 광고보다 전환율이 훨씬 높다.** 이 전환율 우위가 아래 "구좌를 초월한 이식"의 동기.

## CPC 경제 구조 — 객단가로 적자 방어

- 요즘 CPC 단가 많이 올라 **비싼 키워드는 1,000~2,000원** 넘기도 함.
- 그래서 파워컨텐츠로 광고할 땐:
  1. **비싼 제품**을 팔거나
  2. **객단가를 높일 추가상품을 묶어** 판다 (예: 허리견인기 + 허리베개)
- → 객단가를 올려서 **높은 CPC를 내도 적자가 안 나는 구조**를 먼저 만들어야 한다.

## "파컨 형식" = 구좌를 초월한 설득 자산

파워컨텐츠의 **글 유형(파컨 형식)은 구좌와 독립적**이다 — 전환율이 좋으니 다른 구좌로도 이식한다.

- **파워링크 구좌 + 파컨 형식 랜딩** — 파워링크는 원래 제품페이지로 바로 보내지만, **랜딩페이지를 파컨 형식 글로 바꿔** 거기서 설득한 뒤 제품링크로 넘긴다.
- 동기: 파컨 형식 글의 **효율·전환율이 좋고**, 파워링크는 구좌도 더 많다.
- → 파워컨텐츠는 "구좌"이기 전에 **이식 가능한 설득 글쓰기 포맷**으로 보는 게 실전 관점. (랜딩에 이식 = [[상페 구조]]의 6종 형식 중 "블로그형 상페"와 같은 결)

## 미해결 충돌 — M군의 파컨 비추천 입장 (22기 꿰뚫기 대회, 1등급)

> "파컨은 결핍은 깊지만 **사고력이 많이 낮은 사람(욕심 7 이상·사고력 2 이하)을 타겟팅하는 방식 — 기만성이 높아서 추천하지 않음. 등가교환의 저울을 망가뜨린다**고 생각함." (그 타겟은 맨 위에 광고라고 써 있어도 광고인지 인지 못 하고, 본문에서 지칠 만큼 설득돼 출구만 마련하면 되는 의존적 타겟.)

→ 사장님 실전(이 페이지의 본문 — 파컨 형식의 전환율 우위 활용)과 M군의 윤리적 입장이 충돌. 22번 보안관 글(어뷰징과 리스크 1등급 섹션)도 "파컨=사용자 사칭이라 신고 빌미 → 판매자 시점 스토리텔링으로"라고 같은 방향. **판단 보류 — 활용하되 기만성·신고 리스크를 인지하고 판매자 시점 전환을 장기 방향으로.**

## 3등급 — 파컨 풀 프로세스 (수강생 73번, 본인 0.2개+ 유지 주장)

> ⚠️ 3등급: 수강생 실전 워크플로 — 재현성 미검증. 출처: `sources/엠타트업/2026-06_엠타트업_22기-수강생노하우.md`

기획→작성→배포 전 과정: 1688 샘플 주문 → 욕구·판매기획 → 키워드 추출 (**네이버 파컨 키워드 엑셀** = "경쟁사는 있지만 파컨 안 하는 시장" 발굴 / 아이템스카우트 필터 절차 / 마피아넷 조합) → **화자 설정** (욕구와 가장 맞닿는 인물: 입술건조=수영강사·거북목=웹디자이너·이갈이=대치동 영어강사·키성장=놀림받은 자녀 둔 엄마) → 연결고리 (욕구의 원인·원리 → R의 핵심 CV로) → **대안 제거 빌드업** (1순위 필러·수술→부작용으로 제거 → 2순위 마사지·도수→비용·귀찮음으로 제거 → 3순위=우리 제품) → 물길구도 (효율: 카페>블로그>웹사이트 / 소재 흐름: 메타→파컨, DA→파컨).

- 작성 룰: 말투 ~다/~이다 · 이미지는 날것+자극적 · 한 블록 = 사진+간단명료 글 · 모바일 가독성.
- 원가율 30% 이하로 잡아 멀티플랫폼 노출용 마진룸 확보.

## 글 작성 템플릿 (핵심 암묵지) — 7단 골격

소비자인 척하며 신뢰성을 높이는 게 전제. 아래 골격은 [표본 3종](#3표본-같은-골격의-반복)에서 그대로 반복된다.

| # | 단계 | 하는 일 | 매핑 |
|---|---|---|---|
| 1 | **소비자 위장** | "내가 실제 사용자다" 1인칭. 직업·일상까지 구체적으로 | 화자 위장 → 신뢰성 ([[상징성과 당위성]]) |
| 2 | **고생담** | N년간 이 병으로 얼마나 고통받았는지. 삶의 질 하락 | [[스토리텔링]] — 감정·공감 먼저 |
| 3 | **대안 까기** | "치료하려고 돈 엄청 썼는데 안 나았다." 다른 대안(병원·수술·네일샵·한약·수면제 등)을 깐다 → 독자가 **다른 대안으로 안 빠지게** | [[매몰비용]] + [[선택제어]] 소거법 진입 |
| 4 | **원인 규명 + 권위** | 진짜 원인을 짚고 (서울대·논문·교수·학회 인용) | 권위 사회적 증거 |
| 5 | **전문가의 해결책 → 내 카테고리로** | "의사/원장이 말한 해결책" = 내가 파는 **제품 종류**로 끌어옴 | [[프레임 조종]] |
| 6 | **N가지 구매 기준 = 내 제품만 충족** | "그냥 사면 안 되고 N가지 기준으로 사야 한다." 말은 되는 기준이지만 **그 기준을 다 맞추는 건 내 제품뿐** | [[선택제어]] 소거법 (핵심) |
| 7 | **어쩔 수 없이 링크 공개** | "광고 오해 싫지만, 도움 주려 단기간만 공개"로 제품 링크. 비추천 프레임 위장 + 포모 | 비추천의 추천 / 희소성 |

### 반복되는 보조 장치

- **목차 + "바쁘면 결론(3번)만 읽어라"** — 정독 부담 낮추고 결론으로 직행.
- **제품 비교표** → "내가 말한 기준 모두 충족한 곳은 B사/I사/M사가 **유일**" (소거법 시각화). 판매사는 영어 약자(B사·M사·T사)로 표기해 광고 오인 회피.
- **명시적 광고 부인** — "이 글은 광고가 아니다 / 제품 추천 글이 아니라 브랜드명 언급 안 한다 / 링크 3일 후 삭제."
- **사회적 증거** — "건강 베스트/카페 인기글 선정", "댓글·문의 쏟아져 닫았다", "주변에 알려주니 다 도움받았다 → 누구나 효과."
- **'내 병은 내가 고친다' 전환점** — 무책임한 병원에 분노 → 직접 논문 공부 → '이 방법' 발견. 자가발견 서사로 신뢰↑.

## 파컨 2축 — 설득력 × 신뢰성 (2026-09-01 사장님 구술)

파컨의 품질은 두 축이 결정한다.

- **설득력** = 질병의 원인 규명 → "낫으려면 N가지 조건 제품" → 그건 내 제품뿐 — 타겟이 실제로 납득하는 논리 구조 (7단 골격의 4~6단).
- **신뢰성** = 광고로 안 보이게 하는 장치 전부. GIF로 화자 생동감, 얼굴 무모자이크, **전형적 파컨 구조에서 일부러 이탈**하기(카페 단문·그림판·댓글 티키타카)도 신뢰 장치다.
- 파컨 암묵지는 수백 개 — 단순 전수 불가. 표본 전문 박제 + [[강화학습 루프]]로 축적한다.

## 채널별 4형 분화 (2026-09-01, 21표본 실측)

같은 7단 골격이 채널에 따라 4형으로 변형된다. 근거·수치: `프로젝트/파컨-히토온천크림/벤치마킹-해부-21표본.md`.

| 형 | 채널 | 분량 | 핵심 문법 | 표본 |
|---|---|---|---|---|
| **메타랜딩형** | 메타 광고→네이버 블로그 랜딩 | 3.0~5.6천자 | 라이트함의 본질은 자수가 아니라 **텍스트 밀도 ~100자/이미지 + 문단 2~4줄** (릴스 이탈 방지). 목차 없이 선형, 밈 톤 허용 | 덴바디×2·셀로비스·리페아(자사) |
| **네이버 장문형** | 네이버 블로그 (검색 유입) | 4.2~8.7천자 | 논문·법령·비교표 밀도 300~450자/이미지. "공부하러 온" 독자 전제. 기준 역설계 + 익명 비교표 | 바디슈·유랄·큐보젠·가디브 등 8종 |
| **카페형** | 자체 개설 카페 (사업자 소유) | 0.6~3.5천자 | 단문(카페에서 장문 안 씀)·그림판 그림·**댓글 연극이 설득 엔진**. 극단형 = 질문글(본문 제품 0, 댓글 100%) | 머슬아머(경험담)·바이러셋(질문글)·피지스랩(매니저 베스트글) |
| **계정형 연재** | 네이버 블로그 (장기 운영) | 회당 0.1~4.4천자 | 1탄·2탄 연재로 **계정 자체가 신뢰 자산**. 회차별 역할 분담(권위 FAQ/절망 일기/솔루션 등장/가족 확산/완치+링크). 제품명은 최종화 말미까지 은폐, 타 제품만 실명 | 리더뮨 비염일기 6편 |

- 사장님 평: 카페형(머슬아머)·질문글형(바이러셋) = "가볍게 잘 쓴 파컨". 계정형(비염) = "빌드업이 많아 진짜 사람이 오랜 기간 쓴 느낌".
- 제품 도달 경로 2형: **연역형**(기준→유일 통과 — 장문형)과 **우연형**(생활 사건→발견한 척 — 메타형·라이트형에 적합).

## 1코어 + N인트로 양산 패턴 (덴바디 실측)

한 코어 논리로 여러 결핍(부위)을 관통시키고, **관여도 맞춤은 인트로만 교체**한다. 덴바디 손가락/무릎 쌍에서 법의학 수준으로 확인 (코어는 문장 단위 동일, 5일 간격·다른 계정 발행).

- **교체 슬롯 6개**: ①직업 증빙 컷 ②결핍 장면 2개 ③진단명 ④실패 치료 3종 ⑤부위 전용 비주얼 ⑥증언 카톡 호칭
- 공용 코어: 증상 트리오(욱신·뻣뻣·시큰)→사직서→의사 인용→변형 공포→일본 전수 씬→원리부→구매 조건→쪽지 폭주→한시 링크
- **양산 결함 주의**: 덴바디 무릎 편에 "손가락" 잔존 2건 — 슬롯 치환 후 전수 검수 필수.

## 신뢰 장치 카탈로그 7군 (21표본 종합)

- **A. 화자 자격**: 직업 증빙 컷 / 전문가 위장(자격증·의사 FAQ 이중화자) / 무해 위장(평범한 아줌마) / 계정 이력 자산. 권위 위장 ↔ 무해 위장은 정반대 전략 (쥐젖 대조쌍) — 근거 형식도 화자에 맞춰야 함 (전문가=문서 증거, 아줌마=의사 전언).
- **B. 광고 부인**: 명시 부인 / 고지 달고도 순수후기 화법 / 한시 공개("일주일만") / 제품명 은폐 연기·모자이크 / 타 제품만 실명·자사 익명.
- **C. 박해·희소**: 게시중단·N차 재업 서사 / 쪽지함 폭주 캡처 / 품절·쟁여두기 / "어쩔 수 없이 공개".
- **D. 증거 연출**: 카톡 캡처(타임스탬프·호칭) / 검사 수치 아크 / 영수증 / 비포애프터·GIF / **그림판 그림**(촬영 불가 알리바이) / 열화상 / 약국 진열대 POP를 우연히 본 듯 촬영(퍼믹) / AI 생성 사진을 날짜 라벨 타임라인으로 배치(퍼믹 여드름 — 사장님 판단, 미검증. 사실이면 [[어뷰징과 리스크]] 가짜 후기 행).
- **E. 겸손·자인**: 단점 자백 / 교란변수 자인("마스크 덕일 수도") / "플라시보일 수도" / 한계 인정 / 오타 방치.
- **F. 댓글 연극**: 역할 분담(소개·희소성·잔소리·격하·사회적 증거) / **링크는 작성자 본인이 게시**(추천자는 제품명만 — 신고 회피) / 댓글 차단(연출 붕괴 방지). 장문 정성글은 개방, 단문 위장글은 차단.
- **G. 형식 위장**: 카페 단문 / 질문글 / 반말 일기 / 무관 잡담 삽입(광고 밀도 희석) / **MZ 일상글 말투**(빨간 기울임·노란 형광펜·ㅋㅋ·";;"·제품명 모르는 척·친구한테나 쓸 거친 말 — 퍼믹 마킹, 사장님 09-14: "업자 광고글이 아니라 요즘 젊은 여성 일상글 유행의 느낌") / 2탄 연재로 시간 경과 증명([[허브키워드]] 마킹 표본 2).

## 3표본 — 같은 골격의 반복

세 글 모두 위 7단 골격 + "원인 = ○○에 가해지는 압력/부족" → "기준 N가지" → "유일하게 충족한 1곳" 구조가 동일. (제품·스토어명은 실무 데이터 — raw 참조)

| 표본 | 통증 | 원인 프레임 | 구매 기준(소거법) | 객단가 묶음 |
|---|---|---|---|---|
| 내성발톱 교정기 | 내성발톱 | 발톱에 가해지는 **압력** | ① 양방향 교정 ② 간편 착용 → B사 유일 | 보호 튜브·테이프 |
| 허리견인기 | 허리디스크 | 허리에 가해지는 **압력** (275kg) | ① 공기주입 견인 ② 곡선 에어지지대 ③ 의료기기 → I사 유일 | 허리베개·맥켄지운동 |
| 불면증 멜라토닌 | 불면증 | 멜라토닌 부족 + 여성호르몬 감소 | ① 5mg 고함량 ② 단일성분 ③ 석류(E2) → M사 유일 | (석류+멜라토닌 결합 제품) |

→ **카테고리·통증만 바꿔 끼우는 양산 가능한 템플릿.** "원인은 단 하나" → "그 하나를 잡는 기준 N개" → "다 충족하는 건 내 제품뿐"이 엔진.

## 다른 엔티티와의 관계

- [[바이럴]] — 파워컨텐츠가 깔리는 상위 우산. "타겟이 있는 곳에 내 글 노출"의 글 내용 층.
- [[상페 구조]] — 파워컨텐츠 = 그로스짐의 "바이럴 콘텐츠"·환사장의 "물 아래(블로그·카페 깔기)" 레이어를 **유료 구좌로 집행**한 형태. 톤은 자연스럽게, CTA·포모는 약하게.
- [[선택제어]] — 6단계 "N가지 기준 = 내 제품만 충족"이 곧 **소거법**. "꼼꼼히 따져도 대안은 우리뿐."
- [[매몰비용]] / [[스토리텔링]] — 3단계 대안 까기 + 2단계 고생담의 짝.
- [[상징성과 당위성]] — 화자 위장(소비자)·권위(논문·교수)·인기글 = 사회적 증거.
- [[프레임 조종]] / [[프레임 분리]] — "그냥 사면 안 됨 → 기준 프레임"으로 인식 전환.
- [[허브키워드]] — 파컨/마킹 글이 깔리는 **자리(검색결과 깔때기)**. 허브키워드(검색 점유) + 마킹(까는 행위) + 파컨 형식(글 내용)이 한 세트.
