# 사이드 R

## 한 줄 정의

타겟의 메인 물길(프레임)을 **꺾지 않고 그대로 둔 채**, 거기서 파생되는 보완·강화 R로 먹는 전략. [[엠타트업]] 22기 4주차 "프레임" 4축 중 하나 — "**타겟은 못 말려. 말리지 말고 플러스 알파만 팔아라.**"

## 핵심 명제

> "메인이 있고 나는 오케이. **이게 엉망일수록 더 좋아 — 엉망일수록 사이드가 많이 풀리거든.**"

- **저관여에서는 프레임을 절대 깨지 마라** — 기본 심리에 플러스 알파만 (선풍기 모양 바꾸지 마). **고관여만 꺾는다.**
- 노력 없이 쾌락에 빠진 R(술·도박·담배)은 못 돌아온다 — 끊게 하려는 시도 자체가 무의미. 관람차에서 내리게 하지 말고 옆에서 팔아라.

## 두 갈래 — 보완 / 강화

| 메인 (못 말림) | 보완 사이드 (부작용 달래기) | 강화 사이드 (더 잘되게) |
|---|---|---|
| 마운자로 다이어트 | 메스꺼움·졸림·요요 케어 | 효소·올리브유 병행 |
| 엽떡(밀가루) | 글루텐 분해효소·매실식초(흡수 방해)·연어오일 | — |
| 탈모약 (40대는 못 끊음) | 성욕 저하 보완 — 대추야자 | 두피 지압 |
| 클럽 가는 유부녀 | 무향 향수 | — |
| 알코올 중독 | 안주·숙취 케어 ("끊는 법" X) | — |
| 딸깍(AI 자동화) 환상 | — | "업무 효율이 높아진다"로 강화해 도구 판매 |

> "교육(진짜)은 적게 벌고 딸깍(가짜)은 많이 번다 — 메인 물길을 안 꺾고 잔챙이를 먹어라."

## 라온 코치 4주차 미션 피드백 (수강생 전사 — 1등급에 준함)

> 코치 발화의 수강생 전사본 (39·93번 정리) — 강사진 발언이라 1등급으로 취급하되 전사 왜곡 가능성만 유의.

- **보완 vs 강화의 선택 기준 = 내 이득이 큰 쪽**: 임신부 음주 → 무알콜이 아니라 **진짜 술 + 30분 전 중화 영양제** / 임산부 흡연(산후 재흡연 80%) → 무니코틴 전자담배 + "스트레스가 더 안 좋다" 명분 / 베란다 흡연 → 흡입기+부스 / 다이어트 중 빵 → 분해 커피 / 공부 안 하는 아이 → "2시간만 집중하고 2시간 놀아" + 집중력 영양제.
- 지역 키워드 미션의 의도: 오프라인의 좋은 경험을 "집에서 10~20% 재현"하게 — 단순 'R+지역'은 X, 프레임 분리 포인트(호텔 납품 드라이기 "신라호텔과 같은 모터")가 있어야. 검색 타겟과 R 타겟의 일치 확인 (서울대 도서관은 PC 검색 위주 → 연결 난이도↑).
- 프레임 분리 네이밍 사례: 유산균→'장내흡수균'(저체중 남성) / 다크 세제·화이트 세제 분리 / 아이 전용 손톱영양제. "프레임 분리는 기억에 남기는 데서 멈추지 말고 타겟에게 +가치까지."
