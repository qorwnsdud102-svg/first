# 상징재

## 한 줄 정의

제품의 [[상징성과 당위성]]을 외부에서 빌려오는 도구. [[엠타트업]]의 고유 용어이자 **[[재 분류]] 4가지 중 하나**.

## [[재 분류]] 안에서의 위치

상징재는 [[재 분류]]의 4가지 중 하나 (기능재 · 경험재 · **상징재** · 경제재).
**진입 순서로는 기능재 → 경험재 → 상징재**. 처음부터 상징재로 가지 않는다.

## 온라인의 상징재 — 상위노출 = 상징

오프라인의 명품·연예인 같은 상징재가 온라인에서는 다음으로 변환된다:

- 상위노출 / 자주 보이는 것 / 광고 많이 하는 것
- 키워드 1위·대상 받음
- 많이 팔린 것 ("유명하고 많이 팔린 거 사면 손해는 안 보겠지" 심리)
- 구매로 사회적 인정·과시 가능한 것

→ DA 광고의 7도구가 "상징성을 입히는 방법"이라면, **검색·노출 자체도 또 하나의 상징재 입히기**.

## 3등급 — 상징재 제작·게릴라 실무 (21기 수강생 2조 11번)

> ⚠️ 3등급: 수강생 실전 주장 — 재현성 미검증. 출처: `sources/엠타트업/2025-09_엠타트업_21기-수강생노하우.md`

- **언론사 수상 인증서**: "내가 자랑 말고 남이 자랑하게" — 언론사 브랜드 대상류는 수상부문·연도·회사명 임의 지정 가능. 크리스탈 상패·시상식 빼고 인증서 PDF만 받으면 200만→50만, 공동 10명이면 **40만원** (국민일보 300만 < 중앙 400만 순 가격대).
- **유튜브 후원계좌 줄세우기**: 수익창출 금지 대형 채널(정치 등 100만 구독)의 후원 읽어주기 화면을 광고판으로 — 1만원씩 5~6건 쪼개 입금자명을 내 R 카피로 ("애국보수 우파의 에너지 ○○ 1만원") → MC가 브랜드명 또박또박 낭독. **5만원에 7만 조회 = CPV 0.7원** (평균 30~50원 대비). 각인 후 입금을 끊으면 MC·구독자가 먼저 찾는 밀당. 타겟 = 메타인지 약한 50대+ 한정, 브랜드 확장형 R엔 부적합.

## 7가지 도구

### 1. 국가 사대주의 (신뢰성 ↑)

선진국 이름을 제품에 붙이면 신뢰성 자동 상승. 개발도상국은 X.

- 햄버거 → 유러피안 햄버거
- 베이글 → 런던 베이글

### 2. 국가적 특장점 (당위성 ↑)

각 나라의 클리셰를 제품 효능과 연결.

| 국가 | 클리셰 |
|---|---|
| 독일 | 기술력 |
| 핀란드 | 치아 (자일리톨) |
| 네덜란드 | 키 |
| 일본 | 고령화 → 역노화 |
| 북유럽 | 대자연·청정 |

> 예: "전세계 고령화율 1위 일본 도쿄연구소에서 개발한 역노화 주름앰플"
> "북유럽 대자연의 침엽수로 만든 피톤치드 스프레이"
> "독일 맥주공장 노동자들이 탈모에 안 걸리는 이유는?"

### 3. 외형 따라하기

프리미엄 제품의 외형만 닮아도 그 상징성이 일부 묻어옴.

- 메디큐브 PDRN ↔ 메라블 PDRN
- 쏜리서치 ↔ 뉴벨라
- 다이슨 ↔ 차이슨
- 오쏘몰 ↔ 오쏘몰 짭

**관건**: **프리미엄 + 특징이 확실한** 외형의 제품을 따라할 것. 아이허브 같은 저렴이는 신뢰는 있어도 가져올 상징성이 약함. "다이슨 짭" 같은 프레임 씌워지지 않게. 디자인·상표권 주의.

### 4. UI/UX 합치기

뻔한 두 제품을 합치면 새로워 보임.

> "새로운 건 없다, 새로워 보이는 것만 있다."

- 네리티아 **세럼파데** — 세럼 + 파운데이션. "생얼 같지만 발랐다"는 욕구.
- 그라인더 + 레이저 → 무좀 시장에서 차별화.

### 5. 인물/전문가 상징재

연예인은 기본적으로 신뢰도 ↑. 제품 이미지에 맞는 연예인을 쓰면 효과 배가.

| 연예인 | 매칭 제품 | 매칭 이유 |
|---|---|---|
| 쯔양 | 다이어트·소화제 | 잘 먹고 소화 잘 시키는 이미지 |
| 이덕화 | 가발 | 본인 이슈 |
| 남보라 (5남매) | 생활용품 | 대가족 = 알뜰·다용도 |
| 성시경 | 주방 | 요리·깐깐 이미지 |
| 김종국 | 헬스 | 운동 이미지 |
| 노라조 | 파티 플랫폼 | 흥·분위기 |
| 하하 와이프 | 밀키즈 (별의 엄마) | 양육 |
| 음향감독 | 이명 | 직업 매칭 |
| 스튜어디스 | 다리 붓기·편한 구두 | 직업 매칭 |

### 6. 트렌드 차용

이미 떠오르는 다른 트렌드의 상징성을 내 제품에 입히기.

- NMN(노화 영양제 트렌드) → 'NMN 주름 앰플'
- 올레샷(올리브+레몬, 다이어트 식단) → '바르는 올레놀샷' 주름앰플
- 독도토너, 누룩밤 — 같은 패턴
- 오쏘몰의 상징성을 아이크림에 차용

### 7. 의학 상징성

피부과·병원 시술의 인식을 제품에 입힘.

- 메라블 **유쎄라블 리프팅샷 900 아이크림** = "바르는 울쎄라"
- 약국·병원 입점 표기 자체가 상징재. (실제 신뢰성보다 '있어 보임' 효과가 큼)

## 적용 체크리스트 — 좋은 상징재의 조건

자료의 '바르는 울쎄라' 분석에서 추출:

- [ ] **결핍이 명확한가** (스킨부스터처럼 효능이 분산되면 약함, 울쎄라처럼 "리프팅"으로 명확하면 강함)
- [ ] **제품과의 결 일치도** (60% 이상 권장. 100% 못 맞춰도 됨)
- [ ] **직관적으로 무슨 효과인지 1초에 인지 가능**
- [ ] **제품명에 상징재가 연상되게 박혀 있는가** ('유쎄라블', '900샷')
- [ ] **창의적 수습** (미세열감처럼 화장품에서 본 적 없는 디테일로 시술 느낌 부여)

## 여행지 맛집 패턴

> 중요도 낮고 고민도 좀 높은 곳에서 상징재가 결정적 — 후기 수·1위·인기 표시가 강하게 작동.

## 본강의 21기 추가 사례 (직업 권위·숫자·인물)

### 직업 권위 — 가운 입은 사람

> "AI 재미나이 후기 모으기 어려워. **상징성 이용 — 가운 입은 사람 신뢰도 올라간다.** 옥외 광고도 같은 결."

흰 가운(의사·약사·연구원) = 즉각적 권위. 광고 소재의 상징재로 직업 옷차림 활용.

### 숫자 상징성

> "수현 CV — 노래·음색이 아니라 **못생김(미워할 요소가 없는)** vs 카리나·에일리. 우리가 장점이라 생각한 게 시장에선 안 좋을 수도."

숫자(키워드 1위·검색량·후기 수)는 그 자체로 상징재. M군 본인의 "6"·"오멘"·"7전" 같은 숫자 스토리텔링도 상징재 역할.

### 존 내쉬 = 코어 운동기구

> "**존 내쉬 — 상징재 이용. 현존하는 가장 완벽한 코어 운동기구.**"

학자·천재·노벨상 권위를 상품에 입힘 (의학·과학 권위 차용 — 의학 상징성의 변형).

## 퍼포먼스 시각의 상징재 — 권위 입점·연예인

[[환사장]] 강의의 4주차 명제 4: **권위의 힘**.

| 권위 종류 | 사례 |
|---|---|
| 채널 입점 | 올리브영·29CM·무신사 |
| 연예인 후기 | 협찬 링크·릴스 |
| 인플루언서 협찬 | 글로브·오늘룩 플랫폼 |

→ 네이버바이럴의 "광고 많이·많이 팔린 것"과 결은 같지만, 퍼포먼스에선 **유료 권위 구매**가 핵심 도구.

## [[그로스짐]] — 권위 분류 + 가성비·가짜권위·운빨

### 표면 권위 vs 공감 권위 (1주차 우선피드백 2)

| 종류 | 정의 | 사례 |
|---|---|---|
| **표면 권위** | 학력·자격·기관 | 석사·박사·강남 피부과 |
| **공감 권위** | 같은 입장의 진짜 사람 | 진짜 엄마·트러블 전문 인플루언서 |

→ 같은 카테고리의 상징재라도 두 결을 동시에 깔면 매출 차이.

### B급 연예인 가성비 (2주차 5강)

> 한가인·박한별 = 2~3천만원. 강사 추천 코스트 효율.

- 본인 촬영팀 6컷 = **컷당 500만원** (퍼포먼스 필름).
- A급 연예인 (광고비 수억)보다 B급 + 다컷 전략이 ROAS ↑.

### 도마 10억 = 가짜 권위 (2주차 5강)

> 도마(나무 도마) 카테고리에 "10억 매출" 표기 → 실제론 부풀려진 숫자. 가짜 권위 사례.

→ 숫자 권위는 **사실 검증 없이도 통한다** (실제로 작동). 단, 들킬 위험은 별개.

### IU 폭로 운빨 (8주차 3강)

> IU가 SNS에서 어떤 제품을 폭로 → 검색량 30만 → 380만 → 매출 5배.

→ 인물 권위는 **운빨**. 우연히 빅 스타가 언급하면 폭발. 의도해서 짠다고 되는 게 아님.

### "딱 봐도 의사상" — 학습된 무의식 통념

> 의사 가운 단속 → "딱 봐도 의사상" 무의식 통념으로 우회.

식약처가 가운을 단속해도 머릿속에 "의사상"이라는 학습된 이미지가 있어 컨셉으로 작동.

### 헤어리듬 루트너 — 통념(탈락수·혈행) + 미상(MFDS) 결합 (8주차 2강)

광고 카피 = 상페 카피 단어/비율 일치 + 통념 + 인증 결합한 풀스택 사례.

## 실전 적용 패턴 — "용도 변경 + 상징재 입히기"

영양제(먹는 것)를 크림(바르는 것)으로 용도 변경하면서 기존 성분의 상징성을 가져오는 패턴. 사장님 기획 사고 과정에서 반복 등장:

- **침구청소기 + 일본 료칸** — 국가적 특장점(일본=고온다습+진드기+깐깐한 위생) + 장소 권위(료칸 오카미상)
- **바르는 블랙마카** — 트렌드(블랙마카=정력 상징성) + 용도 변경(영양제→크림, 흡수율 당위성)
- **바르는 연골 3대장** — 기존 상징성(콘드로이친·MSM·보스웰리아) 3개 합치기 + 발열크림으로 즉각 피드백
- **바르는 백옥주사** — 의학 상징성(백옥주사=글루타치온) + 용도 변경(주사→앰플)

> 이 기획안들은 사고 과정의 예시일 뿐, 확정된 제품이 아님.

## 22기 4주차 — 상징 미개론: "상징에 속지 말고, 타겟을 상징으로 가둬라"

> 중세 검은 이(설탕 부의 상징)·일본 백분(독)·전족 10cm·긴 손톱·코르셋·조선 양반의 노동 기피·로로피아나 무지 티 — "**미래에서 보면 지금도 미개의 시대다.** 누군가 만든 이미지·프레임·환상에 휘둘리지 말자."

- 휘둘리는 쪽의 신호: K5에 브렌톤 로고·마이바흐 뱃지·투톤 도색 = 가진 것보다 도드라지려는 욕구 = [[마인드/등가교환|저울 고장]]. "진짜는 치장하지 않는다."
- **판매자의 결론**: 나는 상징에 안 속되, **팬덤은 상징으로 가둔다** (등급·네이밍·인증 — 역이용).

## 22기 — 자동차 = 상징재의 교과서 사례

> "자동차는 이미 이동수단의 가치를 넘어섰다 — 비교당하지 않으려고, 우월해지고 싶어서, 나만 달라 보이고 싶어서 탄다." (사고력 테스트 미션)

비교 → 불안 → 안정 확보 → 열등감 보상 → 과시로 이어지는 심리 흐름의 결과물. M군 본인도 "M 들어간 차만 탈 것 — 의미부여(상징성) 때문에 차를 타는 것".

## 주의

너무 일찍 "법적으로 안 됨", "소송 들어올 수 있음" 생각하면 후킹이 안 나온다.
**먼저 창의로 최대치 후킹을 짜고, 현실 반영은 그 다음.**

## [[근육돌이]] 보강 — 비교 대상은 검색량으로 검증한다 (신규 11편)

이 페이지의 7도구는 **무엇을 빌려올까**를 다룬다. 근육돌이는 **그 빌린 것이 실제로 인지되고 있는가**를 검증하는 단계를 하나 더 요구한다.

### ⚠️ 실패 사례 — 우리끼리 유명한 것

한 광고주가 **"저희 제품은 OOO급"**이라며 해외 명품 브랜드를 비교 대상으로 카피를 쓰고 있었다. 그 브랜드의 **국내 검색량을 열어보니 처참했다** — 업계 사람끼리는 다 아는 브랜드였지만, 정작 타겟인 40대 여성은 그 이름을 검색한 적이 없었다. **비교 대상을 고객이 모르면 "OOO급"은 아무 정보도 전달하지 못한다. 빌려올 인지도가 애초에 없는 것.** (71199:250-257)

> 점검 질문 하나: **"그 비교 대상을 지금, 우리 고객이 될 사람들이 실제로 많이 찾고 인지하고 있는가."** 이건 감이 아니라 **검색량으로** 확인한다. **우리끼리 유명한 것과 고객에게 유명한 것은 다르다.**

### 카테고리 밖에서 빌려오기 — 분모자 팬티

마라탕 검색량이 오르던 시기에, 마라탕에 들어가는 **분모자의 쫄깃한 식감을 팬티에 입혀** 판 사례. "분모자처럼 쫄깃한 팬티" — 속옷과 마라탕은 아무 관련이 없지만 **쫄깃한 식감이라는 연결고리 하나**로 지금 가장 뜨거운 키워드의 검색량과 인지도를 빌려 썼다. (71199:259-262)

→ 빌려올 연결고리는 카테고리가 아니라 **질감·모양·상황·감각**에서 찾는다.

### ⚠️ 반짝 유행은 빌리지 마라 — 흐름의 허리에 타라

- **문화는 장기 / 트렌드는 중기 / 유행은 단기.** 유행은 1~2달짜리 파도라 **소재 만들고 세팅하고 학습 돌리는 사이에 부서진다.** 몇 달~몇 년 단위로 올라가는 **트렌드는 지금 타도 늦지 않고, 오히려 올라가는 중간(허리)에 타는 게 제일 좋다.** (71199:293-296)
- 성공 사례: **이마 필러**가 유행하던 시기에 **이마 크림**을 만들어 광고 → 큰 성과. 시술이 뜨면서 "이마 볼륨"이라는 **욕망 자체가 커졌는데 시술은 비싸고 무섭다** → 그 커진 욕망에 **"크림"이라는 낮은 문턱**을 갖다 댄 것. (71199:298-301)
- **지속 기간 확인법**: 데이터랩에서 그 키워드 그래프를 **1~2년 치로 길게** 펼쳐 본다. 작년에도 이맘때 올랐다 유지됐는지, 한 번 솟았다 바로 꺼졌는지가 한눈에 보인다. **두 달 전에 갑자기 태어난 키워드는 아직 유행인지 흐름인지 판정이 안 된 것** → 예산 일부만 태워 테스트하고 본 예산은 검증된 레이어에. (71199:280-282)
- 흐름 잡는 두 가지: ①데이터랩 쇼핑인사이트 급상승 키워드를 주·월 단위 추적 ②**업계 1위 말고 최근 2~3개월 급성장한 2~3위 브랜드를 관찰**한다 — 1위 전략은 이미 완성된 브랜드의 전략(재구매·추천 구조)이라 초기 브랜드에 안 맞고, **급성장 중인 2~3위가 "지금 시장에서 먹히는 방식"**을 보여준다. (71199:305-313) → [[코어 벤치마킹]]
- **매크로 흐름은 개인의 노력으로 못 이긴다** — 코로나 때 패션이 얼어붙고 리빙·자동차로 수요가 넘어갔을 때, 패션 소재를 아무리 갈아도 답이 없었다. **꺼지는 시장에서는 소재를 잘 만들어도 안 팔리고, 뜨는 흐름 위에서는 팔린다.** (71199:315-317)
