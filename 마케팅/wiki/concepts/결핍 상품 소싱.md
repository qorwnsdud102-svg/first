# 결핍 상품 소싱

## 한 줄 정의

무엇을 팔지의 철학 — 누구나 소싱 가능한 **단순유통 공산품**(레드오션·저마진) 대신, 타겟의 **결핍을 푸는 "찾아오게 만드는 고마진 결핍 상품"**을 기획해 판다. 핵심 마인드: **제품이 아니라 욕구와 돈을 교환한다.**

## 단순유통의 함정 (쿠팡 경험)

사장님이 과거 쿠팡에서 중국 공산품 단순유통을 하며 겪은 한계:

- **누구나 소싱 가능 + 원가 노출 + 가져오기 쉬움** → 가격경쟁 불가피.
- 잘 팔려도 **고객이 내 제품을 원한 게 아니라** "검색하다 앞에 보여서 그냥 산 것" → **지속가능성 없음**(브랜드·재구매 없음).
- 마진율 **20~30%**로 낮음.

→ 쿠팡은 [[접촉지점]]상 "빠른 결정·썸네일로 시선만 끌면 구매"라 진입 쉬운 만큼 차별화가 안 됨.

## 결핍 상품의 조건

1. **타겟이 능동적으로 찾아온다** (검색 수요 존재).
2. **고마진** (체급을 올릴 수 있음 — cf. 스틸 2~4만 vs 에어 5~20만).
3. 타겟에게 **"가장 그럴듯한 + 나에게 돈이 되는 대안"**.
4. **논리적으로 실제 우월**한 제품 (근본 해결).
5. **당시 아무도 안 팔던** 카테고리 ([[프레임 분리]]·선점).

## 도출 방법 (worked example — 허리견인기)

> 타겟(허리디스크 환자) → 기존 대안 전부 검토·소거(수술·주사·물리치료의 한계) → **근본 원인**(굽은 자세·디스크 압력) → **근본 해결**(요추전만 유지·견인) → 그걸 구현하는 제품(**공기주입형 곡선 허리보호대**) → 일자·스틸 지지대 소거([[선택제어]]) → **내 제품만 남음.**

- 이 도출 논리가 그대로 [[파워컨텐츠]] 7단 골격(대안 까기 → 원인 → 근본 해결 → N가지 기준=내 제품만)의 **원천**.
- "당시 아무도 안 팜 + 논리적으로 진짜 좋은 제품"이 결핍 상품의 이상형.

## 채널 전환 — 쿠팡 → 네이버

가격경쟁(쿠팡) → **결핍·검색·바이럴로 고마진**(네이버). 고마진이라야 [[통합 로아스]](직접 본전 + 낙수)가 성립.

## 다른 엔티티와의 관계

- [[욕구와 결핍]] — "욕구를 판다"의 뿌리. 결핍이 클수록 고마진 가능.
- [[프레임 분리]] — 아무도 안 파는 카테고리 선점 = 컨셉 단어 점유.
- [[선택제어]] — 대안 소거로 내 제품만 남기기.
- [[파워컨텐츠]] — 결핍 상품의 도출 논리 = 파컨 설득 구조.
- [[접촉지점]] — 타겟 키워드를 차수로 분류해 공략.
- [[통합 로아스]] — 고마진 결핍 상품이라야 낙수 포함 수익 구조 성립.
