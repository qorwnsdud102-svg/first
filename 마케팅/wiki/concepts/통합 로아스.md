# 통합 로아스

## 한 줄 정의

자사몰 DA 퍼포먼스의 **직접 ROAS는 본전 수준**(130~150%, 반품 빼면 또이또이/약적자)으로만 맞추고, 진짜 엣지는 **그 광고가 만든 수요가 쿠팡·네이버로 흘러 발생하는 낙수 매출**에서 낸다. 이를 포함한 **통합 ROAS 200%+** 달성이 목표. (그로스짐 강의에서도 등장)

## 메커니즘 — 자사몰은 미끼, 낙수가 마진

1. DA(메타 등) 퍼포먼스로 **자사몰 유입**.
2. 일부는 자사몰에서 바로 구매(**직접 전환**, ROAS 130~150%).
3. **다수는 "자기가 찾아보고" 쿠팡·네이버에서 구매**(**간접/낙수 전환**) — 광고로 인지·욕구가 생긴 고객이 익숙한 마켓에서 결제.
   - 이 행동이 곧 [[상페 구조]] 환사장 5단계의 **"4. 평가/확인 — 블로그·카페·유튜브·마켓 내돈내산 검색"**.

### 예시 경제 (사장님 기준)

| 항목 | 값 |
|---|---|
| 메타 광고비 | 50만원 |
| 자사몰 매출(직접) | 70만원 → 직접 ROAS 140% (반품 빼면 본전) |
| 쿠팡·네이버 매출 증가(낙수) | +50~100만원 |
| **통합 매출 / 광고비** | 120~170 / 50 = **240~340%** → 목표 **통합 200%+** |

→ 직접만 보면 본전이라 "광고 왜 하냐" 싶지만, **낙수까지 합치면 흑자**. 통합 200%가 나오면 **하루 광고비를 키울수록(1천~5천*) 절대 이익이 커짐** → "엄청 남는 구조".

\* 하루 광고비 "1천~5천" 단위 확인 필요(예시 맥락상 만원 단위 추정 = 1,000만~5,000만원).

## 성립 전제 (이번 세션 전체와 연결)

낙수를 실제로 잡으려면, 광고로 욕구가 생긴 고객이 쿠팡·네이버에서 검색했을 때 **상위노출·신뢰가 이미 깔려 있어야** 한다:

- [[허브키워드]]·마킹 — 검색 자리 점유 + 내돈내산 신뢰
- [[네이버 쇼핑검색 SEO]] — 쇼핑탭 상위(판매량·클릭·리뷰)
- [[바이럴]] — 카페·블로그 노출

→ **DA가 수요를 만들고, 바이럴·SEO가 그 수요를 낙수에서 회수**. 이번 세션 개념들이 하나의 매출 루프로 닫힘.

## 제품 조건

- **엔드로아스(달성 가능 ROAS) ~130% 제품**으로 시작 — 직접 본전이 가능한 손익 구조. (그로스짐 BEP ROAS·KPI 역산과 연결 → [[그로스짐]])

## 다른 엔티티와의 관계

- [[DA 광고]] — 이 목표를 달성하는 광고 수단(기획=상징). 본 페이지는 그 **퍼포먼스 목표/경제** 측.
- [[상페 구조]] — 낙수 행동 = 환사장 5단계 "평가/확인"(다른 채널 내돈내산 검색).
- [[허브키워드]] · [[네이버 쇼핑검색 SEO]] · [[바이럴]] — 낙수 회수 장치.
- [[그로스짐]] — BEP ROAS·KPI 역산(객단가→CPA→CPC) 정립처.

## 내 생각 / 미해결 질문

- **낙수 기여 측정** — 자사몰 광고가 만든 쿠팡·네이버 매출 증가분을 어떻게 어트리뷰션? (광고 on/off 기간 매출 델타? UTM? 실무 = 프로젝트 폴더)
- 하루 광고비 단위 확정(만원 추정).
