# 부활

## 한 줄 정의

죽은 DB(과거 고객 전화번호)를 **명분 + 혜택** 메시지로 되살려 재구매·[[팬덤]]으로 전환하는 전략. [[엠타트업]] 22기의 기수 테마이기도 (기수명 "안녕", 테마 "부활" — 죽었다 다시 살아남).

## 핵심 명제 — DB는 신이다

> "DB는 신이다. 이게 100억의 시작점."

- 3년 전 고객도 부활 가능. "한 번 산 사람을 놓아주면 안 되네? 구매가 아니라 팬덤 모집이잖아?"
- DB 거래 시세 (불법 시장 기준 가치 참고): 대출 3만/창업(푸차) 5만/보험 2만. 추정: 운동용품 2만·기능성화장품 5만·질병 3만·다이어트 5만.
- **다이어트 DB = 안 긁은 복권** — 종결치 없는 결핍이라 평생 고객. → [[팬덤]] 결핍 관람차
- DB 보관: 쿠팡은 DB 안 줌(아마존 모델 — 판매자는 경쟁자). 스스는 구매확정까지 제공(즉시 저장), 자사몰 카페24 기준 6개월, 3PL 메일 기록은 1년까지 유효. **지금부터 무조건 저장.**

## 부활 메시지 — 명분 + 혜택

받았을 때 기분 나쁘지 않으려면 둘 다 필요. **최대 300바이트** ("더보기" 생기면 이탈). **내 이득(판매 유도)을 절대 넣지 않는다** — 혜택과 정보만.

| 유형 | 패턴 | 예 (엠타트업 자체 적용) |
|---|---|---|
| **리콜형** | 리콜처럼 챙겨주는 안내 + 추가 혜택 | "기존 정규멤버인데 카페 3단계가 아니어서 최근 영상 못 본 분들이 있었습니다(명분). 50만원에 판매한 3시간 영상을 볼 수 있게 올려뒀습니다(혜택)" |
| **안내형** | 무료 공개 + 시간 클로징 | "지난번 50만원짜리 영상 무료 공개 — 이번 주 일요일까지만" |

린넨셔츠 사례: "3년 전 구매 덕분에 브랜드 런칭(명분) + 동일 제품 50% / 구매 안 해도 3년 전 구매 인증 시 봄철 올코디 타입 증정(혜택)".

표면적 사고 금지 — "얘가 왜 3년 전에 샀을까? 지금은 뭘 입을까? 무슨 불만이 있을까?"를 심층적으로. → [[사고력]]

## 법적 경계 — 사고력 낮으면 징역

- 개인정보보호법 처벌 수위 = **징역** (서민대출 DB 건당 2만원 × 4천건 = 8천만원 → 징역 8개월).
- **DB 공유·교차 발송 = 불법, 100% 감옥.** 내 고객에게 지인 제품을 **내가 사서 보내는 벤더 구조 = 합법** (같은 카테고리여야 의미). → [[어뷰징과 리스크]]
- 사고력 낮으면 부활 시도 말고 지금부터 구매한 고객만 [[가두리]].

## DB 게임 — 카테고리별 사고력 트레이닝 (22기 1주차 4강)

| DB | 타겟 파악 → 부활 연결 |
|---|---|
| 문틀철봉 (운동) | 가성비 R 접근·몸 안 좋을 가능성 → 굳은살 방지 턱걸이 그립(원가 1~1.2달러→7천원 클로징) |
| 관절영양제 (질병) | 고령 → 유튜브 제로마케팅("영양제 먹어도 이런 동작 하면 소용없다 — 7가지 최악의 자세"), 카페보다 **밴드** |
| 탈모 (질병) | "탈모 암행어사" 카페 — 업계 고발("적발된 탈모업체 27곳")로 '내 편' 포지션 → 팬덤 |
| 다이어트 | **온라인 단식원** — 방법이 아니라 의지의 문제 → 의지·동기부여 커뮤니티 + 오프라인 세미나 |

## 2주차 보강 — 스팸이 아니라 편지 + DB 관리

### 스팸 vs 편지

> "받아본 것 같은 메시지면 그건 편지가 아니라 스팸." — "안녕하세요 OO 대표입니다 + 링크 + 할인코드"는 전부 스팸. **친구한테 쓰듯 쓰고 그 후에 명분을 택하라.**

- 명분 으뜸 = **제로마케팅형** (경고·문제점·"고객 제보가 있었다"). 잇몸치약 표본: "구매하신 치약, 가그린처럼 쓰면 안 됩니다(명분·식약처 확인) + 현재 품절, 재구매 고객만 할인 예약(혜택)".
- 진심 어린 사과 + 전액 환불도 강력한 명분 (쓰레드 저격당한 치킨집 사장 — 환불 취소 10건·오픈채팅 100명).
- "구매" 워딩 대신 **"선물"**. 정확한 수치("26분 한정")는 허접해 보임 → "그 기간쯤 사신 분"으로 모호화. 가족사진은 "적당한 가정집" 톤. 명절·생일 타이밍은 물린다. 스토리텔링 명분은 **반드시 진짜**여야.
- **욕심이 관람차를 부순다**: 한 메시지에 카페+오픈톡 다 넣으면 DB 이탈 — 다이렉트는 하나씩.
- 첫 발송 날린 DB의 두 번째 기회(다른 번호)는 마지막 — 두 번 기분 나쁘면 항의. 팔자마자 1~2달은 DB가 살아있다 — **재구매를 못 만든 건 내 탓**.

### DB 훼손 매트릭스 (신을 죽이지 마라)

| 순위 | 조합 |
|---|---|
| 최고 | 훼손 X + 판매 O (차단 0·고전환) |
| | 훼손 X + 플랫폼 연결 O |
| 나쁨 | 훼손 O + 판매 O (2차 없음) |
| 최악 | 훼손 O + 판매 X / 연결 X (350명 보내 6명 — 나머지 DB도 버린 것) |

"왜 안 하세요?" 같은 화법 = 훼손성 ("지가 뭔데" 표정 나옴).

### DB 관리 실무

- 분류 3축: **기간 · 구매 개수 · 구매 간격**.
- 한 번에 다 쏘지 않는다: **30→30→30 부분 발송** 후 반응 좋은 메시지로 100·100·100 확장. 명분/혜택 비율 다른 **메시지 3종 A/B**.
- 명분 vs 혜택: 오래된 DB는 혜택 없으면 안 돌아옴 / 최근 구매자는 명분만 커도 재구매 (명분형이 마진·가치성 보존에 유리).
- **후기 작성자 DB 별도 보관** (작성률 50% 미만) — 신제품은 이들에게 먼저.
- 도둑심보 활용: A 안 산 사람에게 "A 사주셔서 감사" 발송 (거스름돈 심리 — 도덕적 면죄+귀찮음), "정규 멤버에게만 무료 공개". 단 신제품엔 가짜 말고 진짜 할인.
- **타이밍 설계 — 타겟별 1년치 캘린더**: 중고생=시험·방학 전후 / 주부·가전=명절 전후 / 업소 종사자=저녁·출근 시간 / 가전=구매 1달 후 사용법. **스트레스 高 시점 = 구매전환 高.**

## 3주차 보강 — 부활 편지의 사람 적용 (재회 사례)

부활 편지 미션의 백미 = 헤어진 연인 부활 (고객 살리기와 동일 구조):

- 39번 사례: 타겟 특성 분석(회피형·도파민형 → 다가가면 안 됨, 궁금하게) → 패턴 분석(내 블로그를 염탐 중) → 첨부파일 비밀번호를 **3번 틀린 뒤에 맞출 수 있게** 설계(도파민 자극) → 여운만 남기고 끝 → 상대 블로그에 답장. "모든 말이 선택제어."
- 손편지 컨설팅 룰: **자기방어(해명)를 빼라** — 받아들이고 나아갈 것만.
- 타겟별 차이: 여자 타겟 = 혜택 필수 / **남자 타겟 = 손편지 불필요, 섹시한 프사 변경이면 충분** (남자는 단순).
