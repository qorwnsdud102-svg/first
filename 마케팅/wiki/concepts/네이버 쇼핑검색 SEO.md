# 네이버 쇼핑검색 SEO

## 한 줄 정의

네이버 쇼핑검색 랭킹은 **적합도·인기도·신뢰도** 3요소로 결정된다. 상품정보를 공식 가이드대로 제공해 노출을 최적화하는 것. (출처: 네이버 쇼핑검색 SEO & 상품정보 제공 가이드, 2017-04)

## 랭킹 3요소

| 요소 | 무엇 |
|---|---|
| **적합도** | 검색어가 어떤 **필드**(상품명·카테고리·브랜드·속성/태그)와 연관 높은지 + **카테고리 선호도**. 예: "나이키"는 상품명보다 **브랜드 필드 매칭**이 우선 노출. |
| **인기도** | **클릭수**(최근 7일) · **판매실적**(2/7/30일 수량·금액) · **구매평수** · **최신성**. **카테고리별로 다르게** 구성. |
| **신뢰도** | 네이버쇼핑페널티 · 혜택 · 상품명 SEO · 이미지 SEO. |

- **판매지수**(네이버페이 자동 연동)는 랭킹의 비중 큰 핵심 요소(특히 베스트100). **부정 거래 어뷰징 = 페널티.**
- **어뷰즈 로직 비공개** — 알려지면 우회 공격이 생겨 선의 이용자 피해. 가짜 클릭·구매평·부정거래는 정밀 필터링·제재.

## 쇼핑탭 상위노출 = 매출 (판매전략에서의 위치)

[[바이럴]]의 "타겟 있는 곳에 내 글 노출"을 **쇼핑탭**으로 확장한 것. 키워드 검색 시 카페·블로그·파컨·파워링크 노출에 더해, **쇼핑탭 상위 점유**가 직접 매출을 만든다.

- "발받침대" 검색 → **쇼핑탭에 랭킹순 3~6개** 노출, 그 이하는 **"더보기"**를 눌러야 보임 → **상위 3~6위 안에 들어야 매출**.
- 상위노출 레버 = **판매량 + 클릭수**(= 인기도 핵심 요소). 둘을 올리는 게 실전 목표.

> ⚠️ **어뷰징 경계** — 판매량·클릭수를 인위적으로 부풀리는 수단(가구매 = 판매지수 조작, 리워드 클릭 = 클릭수 조작)이 현장에 존재하나, **공식 가이드상 "부정 거래·어뷰즈 = 페널티/서비스 중지" 대상**(§랭킹 3요소·판매정보 참조). 본 위키는 해당 수단을 운영 방법으로 다루지 않음 — 리스크 사실만 표시. → [[어뷰징과 리스크]]

## 상품명 가이드 (핵심)

- **50자 내외 권장**(최대 100자). 50자↑은 어뷰즈 확률↑.
- **기입 순서**: 브랜드/제조사 → 시리즈 → 모델명(코드) → 유형 → 색상 → 소재 → 수량 → 사이즈 → 성별/나이 → 속성.
- **금지**: 중복 단어/동의어 반복, 수식어(예쁜·신상·고급·A급), 판매조건(무료배송·할인·시즌오프·사은품), 셀러/쇼핑몰명, 특수문자(`( ) - = [ ] / &` 외), 한/영 외 언어, 관련 없는 키워드 나열.
- 동의어/유의어는 네이버가 자동 처리 → **중복 기재 불필요**(대표 키워드 하나).
- 판매조건·이벤트는 **이벤트 필드**(150자)에 별도 입력.

## 이미지 SEO

- 300×300px↑(500 권장, 패션 1000↑), JPG, 4MB 미만, 기본 1 + 추가 2장↑.
- **텍스트·워터마크·도형 과다 금지**, 단일 상품·정면·흰 배경 권장, 과도 보정·연출 컷 금지(= 저품질 어뷰징).

## 기타 필드

- **카테고리** — 성격에 맞는 **세부 카테고리**일수록 노출 기회↑. 무관 매칭 = 제재.
- **속성/태그** — 정확히 빠짐없이. 감성 태그(하늘하늘 원피스) OK. 무관·이슈성·타사 IP 침해 태그 금지.
- **가격비교** — 공식 상품명·모델코드 기입 시 자동 매칭, 가격경쟁력 있으면 상위.
- **SEO 스코어** — 무관 정보·데이터 변경/어뷰즈 시 **강력한 랭킹 페널티**.

## 다른 엔티티와의 관계

- [[네이버 검색 SEO]] — 웹/사이트 검색과 별개 로직이나 "어뷰즈는 페널티" 철학 공유.
- [[파워컨텐츠]] — 객단가 묶음·구매평 등 판매 전환 전략과 맞물림(스마트스토어 판매).
- [[상페 구조]] — 상품명·이미지·리뷰가 곧 상페 전환 요소.

## 내 생각 / 미해결 질문
