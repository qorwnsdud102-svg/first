# 안드로메다 (메타 광고 후보 추리기 엔진)

> 상위: [[메타 광고]] · [[DA 광고]]. 메타 광고 운영의 **전제 조건**이 바뀐 것이라 별도 페이지로 둔다.

## 한 줄 정의

**메타가 2024-12에 공개한, 수천만 개 광고 중 "이 사람에게 보여 줄 후보 수천 개"를 먼저 추리는 엔진.** 광고주가 켜는 기능이 아니라 이미 돌고 있고, 이 엔진이 **소재 자체를 읽어 누구에게 보낼지 정하기** 때문에 광고주가 만질 변수가 **타깃 → 소재**로 옮겨 갔다.

> "크리에이티브가 새로운 타깃팅이다." — 메타 코리아, 맥스서밋 2026-08-04

## 엔진 사실 (1등급 — 메타 공식)

메타 광고 추천은 3단계:

| 단계 | 담당 | 하는 일 |
|---|---|---|
| ① 후보 추리기 (retrieval) | **안드로메다** (2024-12 공개) | 수천만 개 → 수천 개 |
| ② 순위 매기기 (ranking) | GEM(2025 공개)·Lattice 등 | 추린 후보에 점수 |
| ③ 경매·노출 | 입찰가 + 예상 행동률 + 광고 품질 | **이 단계는 안 바뀌었다** |

- 메타가 밝힌 숫자: 후보 추리기 **재현율 +6%**, 선택 구간 **광고 품질 +8%**, 모델 복잡도 **1만 배**(엔지니어링 블로그 2024-12-02 · Meta for Business 2025-03-27). GEM: 인스타 전환 +5%, 페북 피드 +3%(2025 2분기).
- 메타가 광고주에게 한 말(요지): **광고주가 소재를 다양하게 올릴수록 안드로메다가 그 사람에게 맞는 소재를 골라 더 개인화된 광고를 낸다.**

## 광고주에게 바뀐 3가지 (1등급 — 메타 공식)

1. **"누구에게"를 소재가 정한다.** 가격을 말하는 소재와 사용 장면을 보여 주는 소재는 **다른 사람에게 간다.** 타깃을 안 바꿨는데 소재를 바꾸니 반응 연령대가 달라지는 이유.
2. **세트를 쪼개는 방식이 힘을 잃었다.** 연령·관심사별로 세트를 다섯 개 만들면 데이터만 나뉘어 학습이 느려진다. 메타 코리아: 인구통계가 같은 세트 다섯 개는 "사실상 세트 하나와 똑같다". → 세트는 합치고 안에 서로 다른 소재.
3. **비슷한 소재는 하나로 묶여 센다.** 메타는 세트 안 이미지·영상 썸네일끼리 닮은 정도를 본다. 배경색·문구만 바꾼 변형 10개 = **메타 눈엔 소재 1개.** 비슷한 것만 있으면 고를 게 없어 한 소재에 노출이 몰리고 피로가 빨리 온다. **기준은 개수가 아니라 서로 얼마나 다르게 생겼나.**

헷갈리기 쉬운 것:
- ✕ "안드로메다 켜기/최적화" 메뉴 — 없다.
- ✕ "세트당 소재 N개가 정답" — 메타 공식 숫자 없다. 도는 수치는 대행사 경험치.
- ○ 메타 공식 방향은 하나: **소재를 다양하게, Advantage+에 선택지를 많이.**

## 광고관리자 체크리스트 (2026-10 기준)

| # | 할 일 | 근거 |
|---|---|---|
| 1 | 같은 타깃의 광고세트 여러 개 → **하나로 합친다** (세트는 줄이고 소재는 늘린다) | 공식 (도움말 "비슷한 세트를 합쳐 타깃을 넓히면 더 효율적으로 기회를 찾는다") |
| 2 | 타깃 넓게 + **Advantage+ 세부 타깃팅·노출 위치·캠페인 예산**. 손으로 거는 건 기존 구매자 제외처럼 꼭 필요한 제외만 | 공식 (도움말 "결과당 비용 낮추는 법") |
| 3 | 한 세트 안에 **형식 섞기**: 이미지 + 영상 + 9:16 세로. 피드 1:1 또는 4:5(페북 피드 단일 이미지 4:5 권장·인스타 피드 1:1), 스토리·릴스 9:16, 캐러셀은 비율 통일 | 공식 |
| 4 | 소재는 **소구점 × 연출**로 다르게 — 색·문구만 바꾸지 않는다 (아래 격자) | CCFM |
| 5 | **게재 열 경고**를 보고 교체: 「크리에이티브 제한」= 결과당 비용이 과거보다 높음 / 「크리에이티브 피로도」= 과거의 **2배 이상**. 원본을 끄지 말고 **눈에 띄게 다른** 새 광고를 추가. ※ 이 경고는 **소재 1개짜리 세트에서만** 뜬다 | 공식 |
| 6 | 성과 판단은 세트가 아니라 **광고(소재) 단위**. 지는 소재 빼고 새 소구점 채우기 | CCFM |
| 7 | **광고와 상세페이지가 같은 말을 하는지** — 소재가 타깃을 정하니 소재의 약속을 상페가 지켜야 전환 | CCFM (자료 #07과 같은 얘기) |

**하지 말 것**: 같은 소재 배경색만 바꿔 10개 / 세트를 연령대별로 쪼개 "타깃 테스트" / 세부 관심사 10개 겹쳐 걸기 / 잘 나온 소재 하나만 남기고 나머지 전부 끄기 — 전부 엔진의 선택지를 줄이는 행동.

## 2등급 — 소재 다양성 격자: 소구점 7 × 연출 8 (출처: CCFM EDU — 근육돌이 대행사, 누적 집행 2,500억+)

켜져 있는 소재를 한 칸에 하나씩 번호로 적는다. **같은 칸에 몰려 있으면 메타 눈엔 소재 하나. 빈칸이 다음에 만들 소재.**

| 연출 ↓ / 소구점 → | 문제 제기 | 후기·리뷰 | 비교 | 가성비 | 효능·효과 | 신뢰·인증 | 한정·긴급 |
|---|---|---|---|---|---|---|---|
| 시연 | | | | | | | |
| 언박싱 | | | | | | | |
| 비포·애프터 | | | | | | | |
| UGC | | | | | | | |
| 인터뷰 | | | | | | | |
| 텍스트 훅 | | | | | | | |
| 챌린지 | | | | | | | |
| ASMR | | | | | | | |

- 56칸을 다 채우라는 게 아니다 — **처음엔 소구점 2~3 × 연출 3~4, 8~12개가 서로 다른 칸**이면 충분.
- 읽는 법: ① **한 열에 몰림** → 같은 말을 여러 번 한다 → 다른 소구점 열 ② **한 행에 몰림** → 같은 형식뿐 → 이미지만이면 9:16 영상 행, 영상만이면 텍스트 훅 행 ③ **흩어져 있는데 성과 없음** → 다양성 문제가 아니다 → 소재의 약속과 상세페이지를 대조.
- 예시(보습 크림, 다섯 칸에 흩어진 다섯 소재): 문제 제기×텍스트 훅("오후 3시만 되면 당기는 피부" 자막) / 후기×UGC(구매자가 찍은 사용 영상) / 비교×시연(손등 반반 발라 흡수 속도) / 가성비×비포·애프터(용량 대비 가격 자막 + 2주 전후) / 신뢰×인터뷰(개발자가 성분 선택 이유). 효능 표현은 광고 심의 기준대로.
- 출처: CCFM EDU 블로그 「2026년 메타가 통째로 바꾼 광고 엔진」(2026-07-13).

## 일부러 안 넣은 숫자 — 업계에 도는데 1차 출처 없는 것

이 숫자들을 들으면 **출처를 먼저 묻는다** (CCFM이 메타 1차 출처를 못 찾아 뺀 것):

- ✕ "세트 하나에 소재 25개가 세트 다섯 개보다 전환 17% 높다" — "메타 내부 테스트"라고 인용되지만 1차 출처 없음.
- ✕ "소재 유사도 60% 넘으면 묶인다" — 메타가 계산 방식을 공개한 적 없음.
- ✕ "세트당 6개 이상, 15~20개가 적정" — 대행사 경험치.

## 공명과 미해결 충돌 — 기존 위키와

**공명** (출처가 다른데 결론이 같음):
- [[메타 광고]] §진영 합의 1 "소재가 꽃, 광고 관리는 물 주기"(환사장) = "세팅은 스킬이 아니다"(베리홉) = "컨텐츠가 10배 중요"(근육돌이) → 메타 공식이 같은 결론을 엔진 수준에서 확인해 줬다.
- [[근육돌이]] 운영 판단 "1그룹에 소재 10개 내외로 시작 · **그룹을 10개씩 벌리는 건 대체로 무의미**" ≈ 격자의 "8~12개가 서로 다른 칸" · 세트 합치기.
- 근육돌이 DCO 비판 "무엇이 이겼는지가 안 남는다" ↔ 격자는 **칸(소구점·연출)으로 이긴 이유를 남기는** 장치.

**충돌** — 다른 출처끼리는 삭제하지 않고 병기, **같은 출처(근육돌이·CCFM)의 시점 차이는 최신 주장을 따른다**(`핵심-맥락.md` §신뢰 등급). 상세는 [[메타 광고]] §메타 공식 — 안드로메다 이후.

|---|---|---|---|

## 우리 쪽 적용 (원칙)

- **소재 기획의 단위를 "변형 N개"에서 "격자의 빈칸"으로.** 새 상품 런칭 소재는 소구점 2~3 × 연출 3~4로 처음부터 칸을 나눠 기획한다. 소구점 열은 [[DA 기획 판정 룰]]·[[상징재]]의 결과(무엇을 말하나), 연출 행은 촬영 가능 여부(어떻게 보여 주나).
- 소재마다 **(소구점, 연출) 꼬리표**를 붙여 두면, 끈 이유를 기록하라는 근육돌이 원칙("이 각도는 우리 계정에서 두 번 죽었다")이 칸 단위 자산이 된다.
- 전체 순서(경쟁사 영상 → 고객 리뷰 → 격자 → 소재 브리프)는 [[소재 기획 흐름]].
- 소구점 열의 재료는 **실제 고객 표현**에서 — [[프로그램/ccfm-review-messages]](리뷰 → 메시지) · 경쟁사 쪽은 [[프로그램/ccfm-video-appeal]](경쟁사 영상의 소구점·연출 해부).
- 흩어져 있는데 안 팔리면 **[[상페 구조]] 대조**가 먼저다.
