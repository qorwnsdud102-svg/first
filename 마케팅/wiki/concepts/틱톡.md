# 틱톡

## 한 줄 정의

10대(12~19세) 타겟의 핵심 물길 채널 — "**틱톡 운영 ≠ 틱톡 수익화**" (작형 코치, 광고비 0원으로 2억 2천). 조회수가 터져도 판매가 따라오지 않는다 — 판매로 잇는 콘텐츠 요소가 따로 있다.

> 이하 본문 = **정사** (작형 코치 틱톡 강의 3주 과정, 2025-10 — 전사 4,124줄 전체 추출). 야사는 하단 섹션.

## 채널의 성질

- **선(先)플랫폼 후(後)알 소싱**: "여러분이 가진 R은 95% 틱톡에 안 맞는다 — 다시 소싱해야 한다." 플랫폼 선정 3기준: ①사람이 많이 모여 있나 ②경쟁자(엠타)가 없나 — "**엠타가 있냐 없냐가 블루오션을 가르는 유일한 기준**" ③직원도 가능한 시스템인가 (유튜브 탈락=내가 계속 들러붙어야, 구글 탈락=돈).
- **턴제 게임**: R 수명 보수적 3개월, 최대 4개월 (조회수 누적 400~500만이면 판매 급락). "내 턴을 나눠 먹거나, 기다리거나, 만들거나." 타겟(10대 459만)은 한정이지만 **욕구는 안 사라진다** — 그럴듯한 대안을 타이밍 맞게 찔러주면 된다. → **기동력(엉덩이 가벼움)이 핵심**: R을 일주일에 3~4개씩 테스트, 네이버처럼 R을 소중히 여기지 말 것. **한 번 턴 돈 R은 버린다** (타겟이 제품명을 기억해 재판매 불가).
- 노출 = 검색(비중 낮음) + **추천 알고리즘(핵심)**. 반드시 모바일로 확인 (PC는 알고리즘 안 돎). "내가 틱톡 운영자라면 어떤 영상을 퍼트릴까"로 생각.
- 무료 (광고비 0) — "올리면 나간다": 자사몰 결제 11/5 → 첫 콘텐츠 11/11 = 첫 매출 당일 (그 몰 1.2억).

## R 선정 기준

- **메인 타겟 = 12~19세 여성** (사고력 1.5 — "1.5라서 속는 게 아니라, 1.5라서 우리가 맞춰줘야 한다"). 부수 타겟 40대+.
- **욕구 1티어 (욕구깡패)**: 다이어트 · 키 · 미백 · 가슴 · 여드름 — 외모·이성에게 보여지는 욕구 (남자는 외모에 돈 안 씀 → 난이도↑). **파생 욕구를 노려라**: 여드름→착색·흉터 / 다이어트→허벅지·팔뚝·종아리·젖살 / 생리통·입냄새·골반·속눈썹·셀룰라이트.
- **그럴듯한 R (당위성 필수)**: 괄사로 눈 커지기 = 66만 조회에 5개 (실패). 석류"즙"→석류"**정**" (알약이 더 그럴듯+단가↓). "타겟이 정신 차리게 만들면 안 된다."
- **직관적 제품 우선**: 착색 크림·블랙헤드 오일·압박 스타킹 — 누가 봐도 효과 날 것 같은 알.
- **타겟≠결제자**: 가슴·키·여드름·생리통 등 유전 영향·죄책감 욕구는 **부모가 60~70% 결제** → 마킹에 부모 시점 일부 ("아이가 사달라 해서 사줬더니").
- **단가 5천원 이하 (작형은 3천 이하)** · 판매가 적정선 3만 2천원 (3만 9천 = "비싸요" 댓글. 천원씩 올려 "비싸다" 댓글 나오는 기점 = 한계가격). **욕구가 높을수록 틱톡에선 가격을 낮춰야** (바깥세상과 반대 — 10대는 돈이 한정, 영끌 우선순위 싸움). 번들 할인 (2개 20%/3개 30%)로 객단가. 재구매율 2.5% — "왔을 때 잡아라."
- **검색 결과 없는 네이밍 필수** (틱톡 링크 불가 = 100% 검색 기반 구매). 제조는 단가가 유일한 이유 — 위탁 3천원이면 제조 불필요. 작형 변칙: 콘텐츠 먼저 → 팔리면 제조.

## 수익화 콘텐츠 — 조회수→판매 연결

**체크리스트 (모니터 옆에 붙여라)**: **핵심 가치 · 스토리라인 · 오프닝 · 메리트 · 클로징** — "이것만 들어가면 말이 된다."

- **핵심 가치 = 제품을 꿰뚫는 한 문장** — 콘텐츠·상페·구매평·마킹 **전 채널 통일** (120명 중 80명이 못 잡음). → [[코어밸류]]
- **제목 가두리 3단계** (전환율 도구 — 순서 지킬 것): ①**직관형** ("~하는 법", "방학 때 8kg 빼는 법") — 욕구 막 인지한 타겟, 전환·조회 최대 (단계당 100~200만) → ②**겁주기형** ("지금 안 없애면 성인 돼서도 못 지워") — 인지했으나 미구매자 → ③**썰형** — 접촉지점 최대 확장, 전환↓ "마지막까지 뽑아먹기."
- **조회수 3요소**: 제목 (첫 3~4초: 제목 1.5초+비포 1.5초+애프터 1.5초) / **시청 시간 (가장 셈)** — 끝까지 보게 하는 3단: 공감("너 까매서 힘들었지")→꿰뚫기("A·B 다 해봤는데 효과 없었지")→메리트("난 이거 해봤더니") / 상상하게 하라 (비포-애프터 — "나도 예뻐질 수 있을까").
- **오프닝 10초 룰**: 10초 안에 "이런 일이 있었고, 알아낸 방법 알려줄게"까지. 제품이 25초에 나오면 이탈 (블로그 2,000자 습관 금지).
- **메리트 = 영상에서 60~70% 설득**: 제품 모습·제형·사용법·원리·당위성(여성호르몬·혈액순환 등 근거)이 안 나오면 "랜덤 박스."
- **프레임블리(프레임 분리) = 판매 연결의 본체**: 미백크림↔**착색크림** 분리 ("착색엔 착색크림"), 멜라토닌→"깊은 수면", 발목 크림→"발목 두꺼우면 다리 못 얇아짐". 이전 제품 비방 금지 — 프레임만 분리 ("나도 미백비누 써봤는데 효과 없더라"). "프레임블리+선플랫폼 후알소싱으로 수익 3~4배 — **5억 번 프레임 분리법**."
- **틱깡 금지 6**: ①타겟이 싫어하는 알 ②셔플 3개 이상 (최대 2 — 뭘 사야 할지 모름) ③똑같이 베끼기 ④"무조건 터진다" 확신 ⑤**아저씨·아줌마 말투** (10대 말투는 네이트판 10대 이야기·속닥에서 학습) ⑥댓글로 싸우기. + 과도한 어그로(전환 X)·허브키워드(10대는 못 건너뜀)·당위성 없는 스토리.
- **댓글 = 정신 차리게 하면 안 됨**: 경쟁사·대안 언급 댓글 무조건 삭제. "도움 되셨다니 다행이에요" 금지 (판매자 들통). **댓글·틱메로 유도 = 전환율 극한 하락** (기다리는 동안 딴 데로 샘).
- **새로운 포맷 = 무조건 조회수**: 같은 내용도 새 포맷이면 터짐 (AI 애니메이션 48만·DM 형식 12만·동영상 리뷰 10만). 포맷들: 네이트판 형식(120만)·사진 4~5장·날먹식(13초 침대 위 제품 17만)·비포애프터·나레이션(94만)·에이블리형. **콘텐츠 공장(하루 20~30개) 반대** — 창작 영역, 관여도가 품질 (생계 vs 월급).
- **스토리라인 2~3개를 소싱 단계에서 미리** 짜놓기 (대여섯 줄 틀 — 콘텐츠는 앞뒤 살만 붙임). 셔플(실행 항목)은 학생이 할 수 있는 것만 ("하루 1시간 조깅"❌ "야식만 안 먹었어"⭕).
- GPT 활용: **개념+예시를 전부 넣어** 기획·네이밍(검색 결과 없는 네이밍 20개 자동 생성)에 사용 — 콘텐츠 자체는 GPT로 못 만든다.

## 계정 운영

- **생성**: PC 구글로 생성 (모바일 생성 금지) → 모바일 로그인. 하루 1개만. 생성 후 10~120분 스크롤+좋아요 = 워밍업 ("선량한 사람" 신호). **0락 판정**: 첫 글 3~5분 내 조회 1~2라도 오르면 정상, 30분~1시간 0이면 폐기 (오래된 구글 계정은 0락 안 걸림).
- **나이대 고정** (작형 독점 노하우): 계정 생성 직후 건강상식 3~4개 올리면 40대+, 뷰티·10대 정보면 10대로 고정 — 이후 다른 나이대로 안 퍼짐. 일상 콘텐츠는 타겟 나이대에 맞는 것만 (유머·웃긴 영상 = 타겟 오염).
- **개수·업로드**: 한 욕구당 계정 3개면 충분 (작년 월 8천은 **계정 1개**로). 한 계정 **12시간 간격 (하루 2개)** — 많이 올리면 확률↓. 새 R은 새 계정 (기존 팔로워가 반응 안 해 나쁜 계정 판정). 팔로워 많으면 오히려 불리 → 주기적 계정 갈이.
- **업로드 시간**: 하교 15시·학원 후 19시·자기 전 22시. **주말 오전 10시 베스트**. 밤 11시 이후 급락.
- **재업로드 룰**: 1시간 100 이상이면 두고 보기, 700 이하면 가망 없음 → 삭제 후 10~15분 뒤 재업로드 (하루 3번, 총 5번까지). 안 되면 사진↔영상 포맷 전환.
- **유사 문서 단속 (2025-03~ 강화)**: 같은 콘텐츠 그대로 재업로드 = 가이드 위반 → 편집 추가 후 업로드.
- **마킹** (검색 기반 구매라 필수): 블로그·카페 최소 5~6개 (1페이지). 같은 날·같은 글자수·사진 없음 = 들통 → 정렬·말투·사진 수 전부 다르게. 안 팔리는 제품은 새 글 대신 **기존 글 수정 발행** (옛날 후기처럼).
- 협찬: 팔로워 123에도 컨택 옴. 화장품 리뷰어 협찬이 최고 효율 (100만→유명세 후 500~600만 호가). **유명 인플루언서는 효과 없음** ("팬은 얼굴 보러 오지 제품 보러 안 옴" — 500만·1,500만 실패). 필름메이커스 배우 12~15만원.

## 핵심 수치 (작형 실적)

석류정: 단가 ~2,200원·판매 3만 2천원·1개 순익 ~2.8만원 — 한 제품으로 월 8천만원 (계정 1개) / "허벅지 얇아지는 필승 2주 루틴" 110만 조회 (제품 녹임) / 블랙헤드 오일 110만 조회 (메타라면 17만 노출에 천만원) / 위탁 쇼핑몰 1월 1.2억 / 36만 조회에 10개 판매 = R 문제, 50만 조회에 3~4개 = 콘텐츠 문제 (진단 공식).

## 야사 — 22기·21기 수강생 플레이북

> ⚠️ 야사: 수강생 실전 주장 — 재현성 미검증. 작형 정사와 대체로 일치 (파생 욕구·타겟≠결제자·마킹).

- **59번**: 비포애프터는 "긁은 복권 1억 당첨" 수준으로 (AI 얼굴 교체 → 1천→85만 조회). 클로징 "**한 달 반**" (한 달=거짓말 티·두 달=김샘). 터진 소재는 복붙 아닌 "응용".
- **11번**: 10대 이해 3법 (딸 반응·타겟 자작 콘텐츠 관찰·자기 10대 회상). 필름메이커스 5만원 후기 영상. 자연적 R(키)은 고가도 먹힘.
- **89번**: R 프레임분리 용도변경 (다이어트 영양제→코르셋·키성장 젤리→깔창) → 280만 조회. 공구 계정 분리 + 편의점 묶음 발송 (집 택배 못 받는 아이들).
- 21기 12번 (⏰ 2025-08~09 로직): 폰 1대 8계정·rednote 소재 소싱·틱메 복붙 남발 시 차단.
