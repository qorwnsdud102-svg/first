# 상페 구조 (오메클 + 자사몰 5단계 + 그로스짐 3축)

## 한 줄 정의

상세페이지·자사몰의 판매 플로우. **세 가지 모델 공존**:

- **[[엠타트업]] 모델** — 오프닝-메리트-클로징 (오메클). "오프닝이 전부다 90%."
- **[[환사장]] 모델** — 자사몰 5단계 플로우 (인지·고려·탐색·평가·재구매). 자사몰 + 메타광고 단일 라인.
- **[[그로스짐]] 모델** — USP + Pain Point + 손실·손해 3축 + **콘텐츠 3종 분리** (광고·랜딩·바이럴).

세 모델은 상충하지 않고 **다른 채널·관여도·시점에 적용**.

## [[환사장]] 자사몰 5단계 플로우

> 우리가 광고를 보고 제품을 사는 과정 = 자사몰 판매 플로우

| 단계 | 행동 | 핵심 도구 |
|---|---|---|
| **1. 인지** | 광고로 사이트 OR 검색 유입 | 메타 광고 ([[환사장]] 4 캠페인) |
| **2. 고려** | 상페·리뷰 본다 | 상위 5개 리뷰 + 비포·에프터 / 저관여(5만원↓) 충동구매 vs 고관여(추가 검증) |
| **3. 탐색** | 타사 비교 | 상페 차별점 + 권위 |
| **4. 평가/확인** | **블로그·카페·유튜브 내돈내산** 검색 | 물 아래 작업 (블로그·기사·지식인 깔기) |
| **5. 구매·재구매** | CRM (카카오톡 채널) | 신상·기획전 안내 |

### 물 아래 vs 물 위

| 구분 | 작업 | 초반 중요도 |
|---|---|---|
| **물 아래** (깔기) | 리뷰 500-1000개 (상위 5개+포토·영상이 핵심) | 상 |
| 물 아래 | 블로그·카페 체험단·기사·지식인 | 하 |
| **물 위** (광고) | 메타 광고 (초반 집중) | 상 |
| 물 위 | 협력광고 (인플루언서) | 중 |

→ **물 아래 먼저 깔린 후 광고 시작**. 광고로 유입돼도 상페·리뷰 약하면 전환 X.

## [[엠타트업]] 오메클 (기존)

## 3단 구조

| 단계 | 목적 | 도구 |
|---|---|---|
| **오프닝** | 경계심 해소 + 신뢰도 = 공감 + 집중 | 첫 5초 (첫인사·분위기·농담·말투·표정·색·폰트·이미지) |
| **메리트** | 오프닝에서 받은 인상 강화 | [[가치더하기]] · [[상징재]] |
| **클로징** | 결정 강요 | [[선택제어]] (소거법·더블바인드) · [[매몰비용]] |

## 핵심 명제 — 오프닝이 전부

> "**오프닝이 전부다.** 첫 5초를 잡아라. 1초면 결정된다.
> **이게 내 상페의 전부다. 90% 이상이다.**
> 메리트·클로징은 오프닝에서 느낀 감정을 강화할 뿐이다."

> "**제품보다 중요한 건 분위기.**"

## 오프닝의 골든타임

- **첫 1-2분의 긍정 경험이 쌓이면 이후 정보는 긍정 필터로 알아서 걸러진다.**
- 분량: 첫 스크롤 한 번.
- 후기 수가 매우 중요 (개수). 쿠팡에서 못 채울 바엔 자사몰로.

## 오프닝 카피 — 사례

- 재떨이를 비흡연자에게 팔 때 → "**당신은 매너 있는 사람입니다.**"
- 마인드맵의 [[매몰비용]] 카피 패턴:
  - "기존의 전기방석들 ***인 거 알고 계셨나요?" (제로 — 결핍 낮추기)
  - "안전하지 않은 건 ***가 아닙니다" (제로 — 결핍 채우기)
  - "그럼 안전하기만 하면 다 좋은 걸까?" (가치더하기 진입)

## 마인드맵의 3단계와의 매핑

마인드맵에서는 같은 구조를 다른 명명:

| 본강의 (오메클) | 마인드맵 |
|---|---|
| 오프닝 | 1단계 — 이벤트·신뢰 (프로모션·100% 환불·키워드 1위·사은품) |
| 오프닝 끝 ~ 메리트 시작 | 2단계 — 제로마케팅 (첫 카피의 중요성) |
| 메리트 | (가치더하기 단계 통합) |
| 클로징 | 3단계 — 배제설득 (소거법) |

→ 같은 구조를 본강의에서는 "오프닝 90%"로 강조점을 옮긴 표현.

## 오프닝 후 흐름

> "**오프닝에서 받은 인상 + 그 후로는 그걸 증명하기 위한 근거들.**"

오프닝이 약하면 메리트·클로징 아무리 잘 만들어도 무용. 메리트·클로징은 오프닝에서 형성된 감정을 강화하는 보조.

## 22기 — 역피라미드 골조 + AI 커스터마이징 전망

- 상페 = [[선택제어]] 역피라미드형의 지면 버전: **넓은 범위 YES 축적 → 좁힘 → "구매하시겠습니까?" YES.** "개연성을 한 번에 짜야지 오래 고민하면 이탈" — 옛 엠타 멤버들이 A4 한 장에 이어서 쓴 이유. 좁혀가는 중간에 NO(이탈 지점)가 없어야.
- 전망: AI가 타겟을 데이터화해 **보는 사람마다 다른 커스터마이징 상세페이지**를 노출하는 시대 → 무당형(단번에 꿰뚫는 카피)이 미래 트렌드. 통찰력으로 선점.

## [[그로스짐]] 모델 — USP + Pain + 손실 3축

> "광고 콘텐츠와 상페·랜딩의 본질은 같다. 화자만 바꿔서 무한 변주."

### 요약 포인트 3축 (가장 위)

1. **USP** — 우리만의 강점
2. **Pain Point** — 고객의 고통
3. **고객의 손실·손해** — 안 사면 잃는 것

### 콘텐츠 5요소 흐름 (광고 콘텐츠)

| 요소 | 정의 |
|---|---|
| 후킹 | 콘텐츠를 볼 이유 (썸네일·첫 1초) |
| 스토리텔링 | 고객 공감 |
| 설득 | 4가지 사회적 증거 ([[상징성과 당위성]]) |
| 프로모션 / 포모 | 랜딩에서만 (네이티브 광고 보호) |
| 행동요구 (CTA) | 셀링 광고 강하게, 네이티브 약하게 |

### 화자 4종 (상페·광고 공통)

- **고객** (리뷰)
- **전문가** (임상·근거)
- **판매자** (셀링 영업톤)
- **제3자** (연예인·인플루언서·외부 전문가)

→ 같은 메시지를 화자만 바꿔 다양한 섹션에 변주. 연예인 위 vs 리뷰 위 = 광고 데이터로 자주 갱신.

### 3 flow (구성 순서)

> 문제 제기 → 문제 해결 → 근거 제시.

순서 가변 — 근거 제시 → 문제 해결 → 문제 도출도 가능. 3 flow가 본질, 순서는 데이터로.

### 콘텐츠 3종 분리

| 종류 | 프로모션·포모·CTA |
|---|---|
| **광고 콘텐츠** (SNS·DA) | 약하게 — 후킹·스토리 우선 |
| **랜딩 페이지** | 강하게 OK — 한정 수량·임박감·CTA |
| **바이럴 콘텐츠** (블로그·카페·지식인·유튜브·인스타) | 자연스러운 톤 — 환사장의 "물 아래"와 같은 결 |

### 디테일

- **GIF는 USP 핵심 1-2곳에만**. 남발 시 사이트 느려짐 → 3초 이탈.
- 문장 짧고 간결, 쉬운 단어. 컬러·톤은 2~3개로 제한.

### 부록 1 (상페 설계) — 5단 설득 + 삼위일체

> 그로스짐의 심화 모델. 부록 1에서 정립된 흐름.

#### 5단 설득

**공포 → 배경 → 해결 → 불안 → CTA.**

| 단계 | 역할 |
|---|---|
| 공포 | 안 사면 잃는 미래 |
| 배경 | 왜 이 문제가 생겼는지 |
| 해결 | 우리 제품이 어떻게 해결 |
| 불안 | 지금 안 사면 못 사는 이유 |
| CTA | 행동 유도 |

#### 삼위일체

**광고 = 상페 = 외부(바이럴)** — 메시지·단어·비율 일치. 헤어리듬 루트너 사례: 광고 카피 = 상페 카피 단어 일치.

#### 상페 11구성 요소 (가변 순서)

이미지·카피·인트로·상세 내용·회원 혜택·프로모션·가격·고객 리뷰·근거·기능적 특징·페르소나 연출.

### 그로스짐 7주차 — 상페 = 랜딩 전체

> "상세페이지 = 본 이미지 상페 X. **썸네일·포토리뷰가 본 이미지 상페보다 우선.**"

- 포토리뷰만 잘 바꿔 **전환율 2배**.
- 이탈률 50~95% (유저 행동 정량).
- **상페 6종 형식**: 기본·블로그·만화·대표스토리·Q&A·텍스트형.
- PC/모바일 분리 (자사몰 한정).

### 그로스짐 7주차 — 카피·디자인 디테일

- 메인 카피 **10~15자**.
- 인트로 4역할: pain · 고통 · 공감 · 기대.
- **설득 4단계 = 문제제기 → 심화 → 해결 → 근거 무한 반복** (3 flow의 확장형).
- 컬러 무드 한끗 (일본 약국·미국 첨단 병원풍).
- **회원가입 강제 = 전환율 추락** (실험 데이터).
- **한정수량 단독 = +0.23%p (= +10% 상대치).**
- 메시지 7유형 3~4종 조합 룰.
- 모바일 폰트 30~40pt·이미지 500KB·가로스크롤 금지·컬러 2~3·폰트 2종.
- 1~2주 빠른 트래킹 루프.

### 그로스짐 8주차 — 한 페이지 6요소 적층

> **문제 · 해결 · 근거 · 통념 · 권위 · 숫자.** 순서·반복 자유, 적층이 본질.

3 flow와 5단 설득의 통합 — 6요소가 한 페이지 안에 다중 적층되어 있으면 어떤 순서·반복도 OK.

## 학술 근거 — 초전설득이 "오프닝이 전부"의 원리 ([[설득의 심리학]], 정사)

세 모델이 공통으로 말하는 **"앞이 뒤를 지배한다"**를 치알디니 2권(초전설득)이 정면으로 다룬다.

- **초전설득(Pre-Suasion)**(04:49-79): 동의를 좌우하는 건 메시지 자체가 아니라 **메시지를 듣기 직전에 주의가 어디에 가 있었는가**다. 프랑스 음악을 배경에 깔면 프랑스 와인을 고르고, 검증 안 된 제품을 써보게 하려면 먼저 "스스로 모험심이 강한 사람이라고 여기는지" 묻는다. → **오프닝은 정보를 전달하는 자리가 아니라 아래 전체를 읽는 렌즈를 끼워주는 자리.** "첫 1-2분의 긍정 경험이 쌓이면 이후 정보는 긍정 필터로 걸러진다"는 관찰의 학술판.
- **권위도 초전설득 대상**(04:67-79): 메시지 내용에 권위를 넣는 것보다 **메시지 전에 권위를 먼저 강조**하는 편이 낫다. 상단에서 권위 신호를 먼저 세우면 하단의 주장 전체가 권위의 필터를 통과한다.
- **왜 "1초"인가**(01:103-130, 01:409): 사람은 정보 과잉일수록 전부 검토하는 대신 **단편적 지름길**에 의존하는 원시적 의사결정으로 되돌아간다. 터키석 가게에서 가격을 ½ 대신 **2배로 잘못** 매기자 오히려 매진된 사례 — "비싼 것 = 좋은 것" 지름길이 유발 기제로 작동한 것. 오프닝은 이 유발 기제를 심는 자리다.

### 신규 — 신뢰를 만드는 순서: 약점 먼저 (04:295-365)

상세페이지가 **강점만 나열**하도록 짜여 있다면 이 대목이 반례다. 치알디니는 **자기 약점을 먼저 인정한 뒤 강점으로 넘어가면 신뢰가 단번에 생긴다**고 본다. 조건 두 가지:

1. 청중이 **이미 아는** 약점일수록 좋다 (인정해도 추가 손실이 없고, 정직 신호만 남는다).
2. **약점 → 강점** 순서여야 한다. 순서가 바뀌면 효과가 없다. 엘리자베스 1세가 "연약한 여자의 몸"을 먼저 인정한 뒤 "왕의 심장"으로 뒤집은 구조(04:319-335).

→ 상페 적용: "이 제품은 ○○는 안 됩니다. 대신 ●●는…" 블록을 **메리트 앞**에 배치. 반품·부작용·사이즈 한계를 먼저 밝히는 것이 신뢰 비용이 아니라 **신뢰 생성 장치**다. → [[클로징]] 4번(보장)과 같은 원리.

### 신규 — ⚠️ 요소를 더할수록 상페가 약해질 수 있다 (06:222-272)

**평균효과(희석)**: 제안자는 특징을 더하면 매력이 더해진다고 믿지만, 평가자는 **전체를 평균 낸다**.

- 아이팟 터치 + 무료 다운로드 → 제안자 92%가 이쪽을 골랐으나 **구매자의 지불의사는 오히려 하락**.
- 5성급 호텔에 **3성급** 레스토랑이 있다는 정보만으로 지불의사 **-15%**.
- 벌금 750달러보다 "벌금 750달러 + 사회봉사 2시간"이 **덜 가혹하게** 느껴졌다(06:259).

→ 강한 인증·강한 사은품 옆에 **약한 인증·약한 사은품**을 나란히 두면 상페 전체 인상이 내려간다. 처방은 "모두에게 약한 덤" 대신 **"소수에게 의미 있는 덤"**(06:265-272). 배지·구성품·수상내역을 **줄이는** 방향의 A/B가 필요한 지점 — [[가치더하기]]와 긴장 관계.
