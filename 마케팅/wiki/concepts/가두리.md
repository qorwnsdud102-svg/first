# 가두리

## 한 줄 정의

한 번 구매한 고객을 채널(문자·카톡·카페 등)로 가둬 빠져나가지 못하게 잡아두는 락인 구조. [[엠타트업]] 22기 신규 용어 (어업 가두리 양식장 비유). **"이 차이 하나로 1억·10억·100억이 갈린다."**

## 핵심 명제

> "한 번 팔 거면 안 팔아." — 1개를 팔아서 1개의 마진을 남겼다(X) / 1개를 팔아서 1개의 **팬**을 확보했다(O)

- 1번이라도 구매했다는 건 나와 내 R을 믿었다는 것 → 이미 나를 믿은 사람을 설득하는 게 훨씬 쉽다.
- 재구매 없는 사업 = 계속 돈 쓰면서 버티는 구조 (밑 빠진 독). **재구매 없이 100억은 불가능.**
- "세상의 모든 가게는 내 가두리 시스템을 만들기 위한 NPC" — 모든 현상을 가두리 재료로 본다.
- 자체 플랫폼(카페 등)은 **규제 회피 메리트** — 상페와 달리 자발적 참여라 표현 제약·신고에서 자유롭다.

## 시작점 — 4번의 메시지 (고객과의 첫 접촉)

판매 후 표준 4회 문자. 각각이 **다음 플랫폼으로 넘기는 채널**이 된다. 일반 제품은 4번이 기본 (제품 특성 따라 그 이상도).

| 시점 | 메시지 패턴 |
|---|---|
| 주문 시 | "경로 이벤트 — 어떤 경로로 주문하셨는지 입력하면 사은품" + 카페 링크 |
| 도착 시 | "사용법/이런 제품과 같이 쓰면 안 됩니다" + 링크 |
| 1주일 뒤 (예약) | 안내장처럼 — "A처럼 사용 시 문제가 됩니다, 꼭 아래 영상처럼" + 링크 |
| 한 달 뒤 (예약) | "카페에 한 달 후기 남기면 100% 당첨 사은품" + 링크 |

원칙: **메시지에서 내 이득을 취하지 않는다** — 타겟이 원하는 정보·혜택만 ([[팬덤]] 맞추기 단계). 문자는 300바이트 이내 ("더보기" 생기면 이탈).

## 채널 해부 (7종)

| 채널 | 특성 |
|---|---|
| **문자** | 거부감 X · 4번의 기회 · 링크 허용 — **가장 잘 써야 하는 채널** |
| **카페** | 접근성·신뢰도 높음. 가입 진입장벽은 혜택 or 제로마케팅으로 돌파 (사용법·체질별 후기·부작용 사례·고장 시 처방·"같이 쓰면 위험") |
| **카톡 오픈톡** | 전환율 최고·공지용. **구매했거나 구매할 사람만** — 불순물(비구매·의심자)은 짙은 얘기로 알아서 나가게. 관리자만 글쓰기 (독재) |
| 인스타 | 공지·메타광고·DM·1인 브랜드·일상 참여 |
| 유튜브 | 설치법·추가 강의·후기·후케어. 난이도 높아 당장 불필요 |
| 스레드 | 국내 최대 트래픽, 양날의 검 (트위터 음지 유입). 질문형 바이럴로 초반 트래픽용 |
| 전화 | 고객케어·기간 알림·감사 인사 (부재중→문자 후속) |

**기본 3각**: 문자 ↔ 카페 ↔ 카톡 선순환 → "이 3개만 잘 돌려도 100억 간다." 흐름 추천: 문자→카페 or 카톡 (가장 추천) / 스레드→카페→카톡 (스레드→카톡 직행은 유입만 되고 결제 안 됨).

## 어그로-메리트 밸런스 (6주차 — 채널 운영 원리)

> "채널은 어그로(주목·트래픽)와 메리트(만족·전환) 두 개를 **동시에 끌어올리려 하지 말고 시소처럼** 맞추는 것."

- 유튜브·사이버레커는 트래픽 자체가 수익이지만, 우리는 **전환까지 한 단계 더** 가야 한다 — "10만 조회 2개 판매"는 실패가 아니라 밸런스 신호. 광고주가 안 보이는 광고(삼성카드 맥주 광고)는 "바보 광고" — 읽은 사람과 플랫폼만 이득.
- 어그로 과잉 → 모으기 중지하고 메리트 강화 / 메리트 과잉(엠타트업 상태 — 만족도만 높음) → 신규 어그로 추가. **적당한 어그로는 콘텐츠 생존에 필수** (조회수 24~29 = 콘텐츠 죽음).
- 욕먹음 처리: "나를 꿰뚫고 하는 욕은 개선점, 나를 모르고 하는 욕은 주워 담을 필요 없음."
- 도파민 포인트의 이해: 트래픽은 야한 것·망하는 것·싸우는 것(타인의 불행=비교 프레임)에서 나온다 — "인간은 타인의 고통을 즐긴다. 이 포인트를 (휘둘리지 말고) 이용해야 한다." 내 광고·물길·상페에도 도파민 요소가 있어야.

## 운영 룰

- **타이밍이 메시지보다 중요** — 같은 메시지도 타이밍 어긋나면 스팸 (이성과 손잡기: 그날 바로=무례, 한 달 뒤=스윗). 필요할 때 딱딱 보내서 다음 가두리장으로 넘긴다.
- 카페: 유입 시 기본 혜택·증정 주기·지속 활동 장치 (질문 게시판·이달의 모델·before/after 게시판).
- 카톡: 수시 깜짝세일·깜짝정보·라이브. 인원 제한(예: 700명)으로 "나가면 못 들어온다" 주도권.
- 혜택은 초반에 크게 (최소 2만원 상당) — 컬러명함 500매 4,500원 = **장당 10원으로 팬덤 모집**.
- 교차 DB: DB 공유는 불법(징역), **내 고객에게 지인 제품을 내가 사서 보내는 벤더 구조는 합법**. 같은 카테고리여야 의미. → [[어뷰징과 리스크]]

## 2주차 보강 — 카페명 세분화·통제된 카페

카페 성립 3조건: ①가입 이유(관여도) ②지속 활동 이유 ③내 이득으로 회수 가능성. **일회성 상품은 가두리 불가** → 프레임을 타겟·욕구로 전환.

| 원래 (실패형) | 세분화 (M군 첨삭) |
|---|---|
| 창문형 에어컨 설치의 모든 것 (일회성) | **"원룸의 모든 것 / 원룸 생존기"** — 이걸 사는 사람의 상황(원룸)으로 프레임 전환 |
| 수면환경연구소 (기존 강자 못 이김) | **"졸피뎀 단약하는 사람들의 모임"** — 수면 끝판왕 약을 건드려 뾰족하게 |
| 키성장연구소 (경쟁 치열) | **"약수키"** (약X 수술X 자연요법 최대 성장) — 대안 포지션 |
| 남몰래 예뻐지기 (핵포화) | **"외모정병 모여라"** (코정병·키정병) / 트랜스뷰티 — 제로마케팅으로 콤플렉스 집착층만 |
| 썸남썸녀학과 (디젤매니아 못 이김) | **"카리나 꼬시기"** — 1일차 헬스, 2일차 피부과… 인증 커뮤 |

- **통제된 카페가 오래 간다**: 자유글 금지, 공지·후기만 (세력 싸움 방지 — 엠타 카페가 표본). 활성화시켜 광고로 벌든, 통제하고 나만 말해서 이득 취하든 둘 중 하나.
- 어그로 밸런스·맞추기(함께 싸워주기)는 [[팬덤]] 참조.

## 실전 사례 (22기 1주차)

- M군 치킨·맥줏집 5년: 매일 35~40팀 × 5년 = 73,000팀을 다 놓침. "맥주의맛 카페 가입 시 꾸이맨 2장(원가 260원)"이면 팀당 260원에 팬덤 확보 가능했다 — 매일 맥주 라인 청소·전일 제조 케그만 취급한 디테일이 카페 문화가 될 수 있었음.
- 보정복대 "보모네모"(보정된 모습이 진짜 내 모습) 카페: 키빼몸 + 3사이즈 자체 명명(타사 구매 불가 락인) + before/after 게시판 + 스레드 질문형("이거 티나?") 유입.
- M군 오픈톡방: 외부 홍보 0, 구매 고객만으로 하루 700명. 같은 OT 링크로 즉시 판매 전환.
- 치과 문자 사고력 트레이닝: 정기검진 안내 대신 ①충치 7개+지금이면 간단(제로마케팅) ②진료비 인상 예정(클로징) ③올바른 양치법 유튜브(팬덤 구축+칫솔·치약 추가 판매) → 방문 환자 2배.

## 4주차 보강 — CRM 실무 (작형 코치 발표)

CRM(고객관계관리) = 가두리·팬덤의 실무 시스템. 워시비 착색크림 — 매출 1.1억/광고비 0.2억(ROAS 500%)의 비결.

- **구매 여정을 전부 체크하고 트리거 메시지**: 회원가입→결제 시작→배송 시작→배송 완료 각 지점. **채널톡 7원 vs 카카오 기본 20원** — 상세페이지 7초 체류자·결제 이탈 후 복귀자 등 디테일 트리거 가능.
- **회원가입 = 고객의 첫 매몰비용** — 기본 메시지 방치는 "성수동 불친절 매장". 스레드에서 스토리텔링으로 데려와 놓고 가입 메시지가 양아치면 단절 — **CV(스토리)와 일치하는 메시지**로 이어져야 ("아버지가 30년 몰두해 만든 제품을…").
- 우편 DM도 유효: 구매 고객에게 3단 팜플릿 ("덕분에 임상 결과가 잘 나왔어요 + 5천원 쿠폰") → 239건 발송 중 172건 사용, 수익 700~900만.
- **설문조사(구매 7일)** = 혜택과 함께 — 접한 경로(불신: 스레드 보고도 "네이버"라 답함)·부위·연령·불편점 → "튜브로 바꿔달라" 반영 후 "너네 덕분" 쿠폰 (쿠폰 1장으로 용기 단가 차액 회수).
- **사후관리(애프터케어)**: 7일 후 사용법(쿠폰 X — 명분만) → 4주차(소진 시점) 쿠폰 → 재구매.
- **쿠폰 인플레 경고**: 2천→3천→5천→20~30% 올리면 길들여져 효율 추락 — DB 2.5만명이 사장된 실패담 (10대 영끌 구매자는 재구매 불가). 중심을 잡아라.

## 3주차 보강 — 타겟 무의식 침투 (알-궤도 사은품 각인)

메인 R(알)의 궤도에서 도는 사은품·로고로 타겟 무의식에 스며들기: 배달음식(알)의 배달딱지·냉장고 자석·병따개 (친구 집 구구족 딱지 → 무의식적으로 구구족 주문) / 제약사가 의사에게 주는 펜·메모장. **접촉지점이 가까운 곳에 슬쩍슬쩍 보이면 무의식이 작동.** → [[마인드/무의식 조종]]

## 3등급 — 3일 10억 톡방 해부 (수강생 21번) + DB 발송 인증

> ⚠️ 3등급: 수강생 실전 관찰·주장 — 재현성 미검증, 1등급(본강의)와 결이 다를 수 있음. 출처: `sources/엠타트업/2026-06_엠타트업_22기-수강생노하우.md`

화장품 공구 톡방의 가두리·팬덤 완성형이라는 관찰 (객단가 100만~400만):

1. **카테고리 재정의**: 화장품 → "피부 치료제/힐링" (프레임 전환)
2. **탈출 못 하는 4장치**: 비밀 링크(공지에만 10% 상시할인) · 정보 독점(공구 링크는 톡방 최우선) · 압도적 CS 속도(본사보다 빠름+대표 직접 소통) · 끊임없는 보상(후기·챌린지 → 고가 스파 이용권까지)
3. **소비속도 강제 챌린지**: "로션 한 통 1주일에 다 쓰기" — "허브 성분은 계속 밀어넣어야" 명분으로 3개월치를 1주에 소진 = **재구매 주기 10배** ("아껴 써라"❌ "쏟아부어야 효과"⭕)
4. **선배가 후배를 가르치는 자생 생태계** (운영 리소스↓·유대감↑) + **위기를 폐쇄성·결속으로 전환** (방 폭파 후 선별 재입장 → '가두리부심')

**DB 발송 인증 (1주차 미션)**: 27번 — 톡톡+카플친 메시지 1건, **명분+고객이득**(히든 상세페이지)으로 1,000만원 / 5번 — **블랙홀 전략** (카페24 킵그로우 = 가입 시 플친 자동화 + 문자나라 = 주문일 4문자 예약) → 3,300명 발송 1시간에 100개 / 18번 — **실패 복기**: 맞추기 없이 다루기만 하면 발송 대비 구매 2% ("맞추기에 2~3배 더 신경썼어야").
