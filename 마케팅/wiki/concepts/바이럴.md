# 바이럴

## 한 줄 정의

**소문을 내는 것.** 네이버 바이럴 = **카페·지식인·블로그**에서 검색 유입을 설득으로 전환하는 작업. ([[파워컨텐츠]]·[[허브키워드]]·마킹이 모두 이 우산 아래의 도구.)

## 본질 (한 문장)

> **"내 타겟이 있는 곳에서 내 글을 노출시켜, 내 제품으로 물길(트래픽)을 유입시킨다."**

채널이 무엇이든 본질은 같다 — 타겟이 모여 있는 자리에 내 글을 끼워 넣어 물길을 끌어온다. 외부/내부 구분도 결국 **"타겟이 어디 있느냐"의 차이**일 뿐 (검색하러 오는 사람 vs 카페에 모여 있는 회원).

### 플랫폼 무관 — 네이버에 국한되지 않는다

> "굳이 네이버가 아니라, 허리견인기 파는 거면 **유튜브 허리디스크 설명 의사 영상 댓글**에도 '곡선 견인기 쓰고 나았다'고 쓰는 것도 **유튜브 댓글 바이럴**인 거지."

- 네이버(카페·지식인·블로그)는 바이럴의 **한 무대**일 뿐.
- **유튜브 댓글 바이럴** — 타겟이 모이는 관련 영상(예: 의사의 허리디스크 설명) 댓글에 사용 후기처럼 제품을 흘림.
- 원리: 타겟이 이미 모인 **남의 콘텐츠**에 무임승차해 물길을 내 제품으로 튼다.

> ⚠️ frontmatter의 `school: 네이버바이럴`(엠타트업 진영 라벨)과 이 개념 "바이럴"(실전 전술)은 이름이 겹치지만 다른 층위.

## 외부 바이럴 vs 내부 바이럴

- **외부 바이럴** — **검색결과 상위 구좌**(남이 검색해서 들어오는 자리)를 글로 점유. 검색 유입자가 타겟. ↓ 아래 상술.
- **내부 바이럴** — **카페 회원**이 타겟. 카페 안에서 회원들에게 교묘하게 소문낸다.
  - **들키지 않는 게 포인트** (광고로 들키면 끝).
  - 자주 못 하지만 **한번 잘 터지면 화력이 좋아 큰 매출** 발생. (저빈도·고폭발)
  - 외부(검색 유입)와 달리 이미 모인 커뮤니티의 신뢰·관계망을 탄다.

## 카페 외부 바이럴 — 검색결과 구좌 점유

> "허리견인기를 네이버에 검색하면 검색결과에 **카페 구좌 2개, 블로그 구좌 2개**가 상위노출돼. 이 카페 2자리를 노리고 글을 쓰는 거지."

흐름:

1. 타겟 키워드(예: 허리견인기) 검색 시 뜨는 **카페 2 / 블로그 2 구좌**를 파악.
2. 그 자리에 들어갈 글을 써서 **상위노출로 자리를 점유**.
3. 검색한 사람이 내 카페·블로그 글을 클릭 → **설득 글([[파워컨텐츠]] 형식)** 을 봄 → 구매.

→ [[상페 구조]]의 "물 아래(블로그·카페 깔기)" 레이어를 **검색결과 구좌 단위로 공략**한 것.

### 실행 조건 (상위노출)

> "카페 외부 바이럴을 위해선 **최적화 카페**에서 **최적화 카페아이디**로 **상위노출 로직**에 맞게 글을 써야 해."

- **최적화 카페** — 검색 상위에 잘 걸리는, 권위 있는 대형 카페 (예: 척추질환 환우모임).
- **최적화 아이디** — 활동 이력으로 신뢰 점수가 쌓인 카페 계정.
- **상위노출 로직** — 네이버 검색 알고리즘에 맞춘 글자수·키워드·구조. ↓

### 노출 면 3종 (카페 외부 상위노출 로직)

> 출처: 카페 외부 상위노출 로직 강의 (2026, OneDrive). *자동화·계정운영·적발회피·신고 등 운영 인프라 부분은 정책상 위키 미반영 — 리스크 지형은 [[어뷰징과 리스크]], 출처는 [source 메타]( ../sources/기타/2026_카페외부-상위노출-로직-강의.md ) 참조.*

| 노출 면 | 무엇 | 아이디 연식 영향 |
|---|---|---|
| **카페탭** | 카페 검색 탭 순위 | 평준화 (신규 최적아이디도 가능) |
| **인기글** (구통검) | 통합검색 인기글 영역 | **큼 — 오래된(4차) 아이디 우위** |
| **신규통검** (약 6개월 전 신설) | 대표카페 위주 카페·블로그·지식인·웹 혼합형 | 작음 (최적 아님도 뜸, 대표카페 위주) |

- **4차 아이디** = 2018년 이전 생성된 오래된 최적 계정. **인기글·카페탭에서만 상위노출 우위**(특히 인기글에서 압도). 신규통검은 아이디 연식 영향이 적음.

### 글 최적화 기준 (콘텐츠 SEO)

- **본문 300~700자**, 핵심 키워드 **약 5회 반복**. 제목은 **짧게**. (1등글이 길다고 따라 늘리면 오히려 하락)
- **댓글 6개 이상**(경쟁 셀 때), 댓글에도 키워드. 댓글 2개부터 본문 하단 노출 — 반영되려면 20자↑.
- **사진 1장이면 노출 점수는 동일**(여러 장은 구매자 후킹용).
- **과장·홍보성 단어 회피** (25년 8월 이후 강화) — "너무·아주·진짜·1등·최고·유일"(과장), "추천·후기·효과·효능"(홍보성)이 들어가면 인기글 노출 저하. **블로그 글처럼** 써야 함.
- **연관·자동완성 키워드**를 본문에 자연스럽게 누적.
- **씨랭크(C-Rank)** — 주제 일관된 글이 **카페 단위**로 누적될수록 점수↑. 글밥 **2천 개 체감 임계**, **2만 개+ 안정화**. 누적되면 대형카페도 이김.
- **반영 타이밍** — 1차 10~30분, 2차(최종) 1시간, 인기글(통합) 2~10시간. 1등글은 평균 3일 뒤 하락 시작 → 3일 지난 글을 공략.
- **전체발행 후 72시간 절대 대기** — 전체발행 글이 관련도순에 잡히려면 **72시간이라는 절대 시간**이 필요(요일은 무관, 72h가 핵심).
- **위험키워드 = 실명 강제** — 병원·의료기기·의약품·건강기능식품·법률·부동산·다이어트·탈모 등은 실명 계정 아니면 미노출/삭제(30분 컷). (→ 규제 카테고리)
- **블로그 구좌**는 [[블로그 지수]](일반→준최→최적)가 높을수록 상위노출 — 카페의 최적아이디에 대응.

## 자문자답 댓글 유도 (sock puppet)

질문글로 시작해 댓글에서 자연스럽게 특정 제품으로 끌고 가는 패턴.

**표본 — "약국 허리보호대 써보다가 놀란게요;;"** (척추 카페):

- 본문: "약국 허리보호대 효과 있을까요?" 질문 + "허리 편한 **토퍼** 정보도 부탁" (← 화제 유도 포석).
- 댓글: A "약국 보호대 다 비슷하지 않나요?" → B "유명한 거 쓰는데 탄탄하고 부담 덜해요" → A "어떤 제품?" → B "**레,이브토퍼**요" (콤마로 필터 회피) → 여러 ID 동조("탄탄한 게 중요", "계란판 비추").
- → 질문 키워드(약국 허리보호대)와 **다른 카테고리(토퍼) 특정 제품**으로 자문자답 유도. [[프레임 분리]]의 다이어트 댓글 예시와 같은 결.

## 전체 지도 — 바이럴 안에서 도구들의 위치

| 층위 | 개념 | 역할 |
|---|---|---|
| 우산(어디서) | **바이럴** | 카페·지식인·블로그에 소문내기. 외부(검색 구좌)/내부 |
| 자리(어느 키워드) | [[허브키워드]] | 내가 만든 키워드 검색결과를 통째 깔때기로. (일반 키워드 구좌 점유의 자기제작 버전) |
| 행위(까는 것) | 마킹 | 그 자리에 내돈내산처럼 글 심기 ([[허브키워드]]#마킹) |
| 내용(무슨 글) | [[파워컨텐츠]] | 까는 글의 형식 = 소비자 위장 7단 설득 골격 |

→ "**바이럴(어디서) → 허브키워드(어느 자리) → 마킹(까는 행위) → 파컨(글 내용)**"이 한 줄로 꿰지는 시스템.

## 야사 — 스레드 플레이북 (수강생 7번, 2일 5천만원 주장)

> ⚠️ 야사: 수강생 실전 주장 — 재현성 미검증, 정사(본강의)와 결이 다를 수 있음. 출처: `sources/엠타트업/2026-06_엠타트업_22기-수강생노하우.md`

- **스레드의 성질**: "30~40대 텃세 많은 아줌마 캐릭터". 후킹 제품의 유통기한 2주 (학습되면 안 속음). 저격은 "무조건 당함" — 당위적이면 용서해주는 성질을 이용해 저격 댓글에 전원 답글 (타겟+관전자 동시 겨냥).
- **콘텐츠 두 축**: 후기성(단발·저격 표적) vs **판매자 시점**(팬덤용) — 장기전은 판매자 시점만.
- **R 기획 3기준**: ①찐후기 ×10이 댓글에 붙는 진짜 좋은 R (조회 14만에 매출 0인 글도 있다) ②나만 파는 R (위탁은 "10배 싼 데 있음" 즉시 저격) ③실제 이야기 — **AI 글 금지 주장** (AI가 AI를 판별, 팬덤 기회 박탈. ⚠️ 단 59번은 틱톡에서 AI 활용 성공 — 채널별 충돌, sources 페이지 참조).
- **멘트 분해 벤치마킹** (감자탕 표본): "국내산"=신뢰+타겟 특정 / "오늘 매출 0, 펑펑 울었어"=동정 어그로 / "스레드에서만 라면사리"=특혜감 / "하트라도 눌러줘"=문턱 최소화 클로징.
- 알고리즘 신봉 X — "터지는 글은 그냥 터진다. 많이 던져 확률을 높여라. 안 터지면 100% 글 퀄 문제."
- 외주 운영 결: 17번 — 외주는 "무한발행"이 아니라 **키워드 지분 확대** 수단. 선행조건 = 혼자 최대치(일발행 100개)를 먼저 경험.
- **별풍선 2차 바이럴 (31번)**: 구매자에게 게시글로 공개 감사("스치니 고마워ㅠㅠ 치니UP~") → "나도 샀다" 댓글 폭주 → 인게이지먼트 지수↑ → 알고리즘 탑승. 글 3개로 죽은 스토어(일 방문 20명)를 2,659명·80건으로.
- **인플루언서 공동구매 (77번, 150회+)**: 탐색=인포크딜+알고리즘 확장, 진성 지표=댓글률 1%↑ (팔로워 수 무관 — 4천 팔로워로 4일 7천만원), 성과형 수수료 제안, "일잘하는 직원" 포지션. 상세 절차·수수료율 표는 `sources/엠타트업/2026-06_엠타트업_22기-수강생노하우.md` 3권.

## 다른 엔티티와의 관계

- [[파워컨텐츠]] — 바이럴 구좌에 까는 글의 형식·전환 엔진.
- [[허브키워드]] — 검색결과 점유를 "내가 만든 키워드"로 극대화한 형태. 마킹 = 허브키워드에 거는 바이럴.
- [[상페 구조]] — 환사장 "물 아래"·그로스짐 "바이럴 콘텐츠" 레이어 = 이 바이럴.
- [[프레임 분리]] — 자문자답 댓글로 타겟을 분리·유도.
- [[네이버 검색 SEO]] — 카페·블로그 노출의 바탕 원리(신뢰도·활성도·웹표준). 공식 가이드 관점.
- [[네이버 쇼핑검색 SEO]] — 유입 후 스마트스토어 상품 노출(적합도·인기도·신뢰도).
- [[접촉지점]] — 키워드를 차수로 나눠 **한 키워드의 모든 구좌(파워링크·쇼핑탭·파워컨텐츠·카페·블로그)를 장악**하는 SERP 도배.
