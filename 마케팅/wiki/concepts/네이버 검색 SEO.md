# 네이버 검색 SEO

## 한 줄 정의

네이버 검색로봇(**Yeti**)이 웹사이트를 **발견 → 수집 → 노출**하는 원리에 맞춰, 내 사이트·콘텐츠가 검색에 잘 잡히게 만드는 것. (출처: 네이버 공식 웹마스터 가이드)

## 수집~노출 3단계

1. **발견** — 로봇이 웹의 사이트를 인지. **신뢰도**(뉴스·백과 등 권위 페이지에 인용됨) + **활성도**(사용자가 많이 검색·방문)가 높을수록 빨리 발견.
2. **수집** — 방문해 정보 수집. **웹 표준 준수**가 핵심(아래).
3. **노출** — 검색어 입력 시 로직(적합도 등)에 따라 순위 매겨 노출.

## 수집 조건 — 웹 표준 (체크리스트)

- **로봇 접근 허용** — 방화벽/서버에서 Yeti 허용. `robots.txt`에 `Allow`. (User-Agent: `Mozilla/5.0 (compatible; Yeti/1.1; +http://naver.me/spd)`)
- **노출 메타** — `<meta name="robots" content="index">` (noindex면 수집돼도 노출 X). **robots.txt + 로봇메타 둘 다 허용**해야 노출.
- **HTML 마크업** — `title`·`description`·`og` 메타 제공. head 정보가 body에 있으면 안 됨.
- **canonical** — 중복 URL은 대표 URL 지정(`<link rel="canonical">`).
- **redirect** — JS·meta refresh보다 **HTTP redirect**.
- **링크** — JS 링크·`<frame>`은 해석 어려움. 앵커 텍스트는 대표 키워드, 이미지엔 `alt`.
- **sitemap.xml / RSS 제출** — 웹마스터도구 `요청 > 사이트맵/RSS 제출`로 누락 없이 수집.
- **수집 요청** — 정보 변경 시 `요청 > 페이지 수집`으로 재방문 유도. 확인: `site:내사이트` 검색.

## 노출 잘 되는 법 (공식 TIP)

- **고유 브랜드명·고유 사이트 주소** — 일반명사·흔한 주소는 낚시성 오해·이력 문제. (cf. [[프레임 분리]] 컨셉 단어)
- **제목 15자 이내 / 설명 45자 이내** — 길거나 키워드 반복·무관 키워드 나열은 불리.
- **신뢰도·활성도 = 양질 콘텐츠 꾸준히** — 권위 사이트 인용↑ → 방문↑ → 활성도↑. 방치돼 스팸 변질 X.
- **외부 인용** — 같은 사이트 내 10링크보다 **외부 10개 사이트 인용**이 신뢰도에 유리(= 백링크).
- **일관성** — 메인과 다른 주제로 채널 운영(예: 공기청정기 사이트가 연예뉴스 도배)은 오히려 불리.
- **구조화 데이터(schema.org)** — Person/Organization·평점 등 JSON-LD/Microdata → 스니펫·연관채널 노출(일부 시험).
- **반영 주기** — 최소 1일~수 주(신뢰도·활성도에 따라 다름). 수집요청 시 1~2일.

## 다른 엔티티와의 관계

- [[바이럴]] — 블로그·사이트 외부 바이럴의 노출이 이 "신뢰도·활성도·웹표준" 원리 위에서 작동. [[블로그 지수]]도 같은 맥락.
- [[네이버 쇼핑검색 SEO]] — 쇼핑검색은 별도 랭킹 로직(적합도·인기도·신뢰도). 같은 "어뷰즈는 페널티" 철학.
- [[프레임 분리]] — "고유 브랜드명" 권장 = 컨셉 단어 점유와 통함.
