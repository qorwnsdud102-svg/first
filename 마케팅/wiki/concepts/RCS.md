# RCS / NRCS

## 한 줄 정의

[[엠타트업]] 강의의 메인 프레임. 마인드맵에선 **RCS** (R리소스·C채널·S시스템). 본강의 21기에서 **NRCS** (N욕구·R대안·C채널·S시스템)으로 진화 — 욕구가 R 앞으로 빠져나와 별도 축이 됨.

## 진화 — RCS → NRCS (21기에서 정련)

| 마인드맵 | 본강의 21기 | 의미 |
|---|---|---|
| R(리소스/제품) | **N(욕구)** + **R(대안)** | 욕구는 시장 출발점, R은 그걸 해소하는 도구 — 둘 분리 |
| C(채널) | C(채널/플랫폼) | 동일 |
| S(시스템) | S(시스템) | 동일 |

> "**마케팅은 욕망을 다루는 도구일 뿐이다.**"
>
> "마케팅축: **욕구, 대안, 접근**"
> "기획할 때 골조 → **NRCS**"

**왜 분리됐나**: "욕구는 같은데 R(대안)만 다름" 같은 정확한 진단이 가능. 예를 들어 "다이어트 욕구"라는 N에 한약·식욕억제제·운동기구·시술 등 다양한 R이 경쟁. R을 분석하려면 그 위의 N을 먼저 봐야.

## 3요소

- **R (리소스)** — 무엇을 팔 것인가. 제품 그 자체.
- **C (채널)** — 어디서 팔 것인가. (네이버·쿠팡·카페·지식인 등)
- **S (시스템)** — 어떻게 모으고 설득할 것인가. 매출까지의 운영 메커니즘.

## R(리소스)의 5가지 평가축

R이 좋은가의 판단 기준.

| 축 | 의미 |
|---|---|
| 시장성 | 검색량·수요 규모 |
| 접근성 | 타겟에 닿을 수 있는가 |
| 가치성 | 결핍을 해소할 수 있는가 |
| 희귀성 | 흔하지 않은가 |
| 모방성 | 카피가 어려운가 |

> "R의 가치를 알아주는 곳에서 물건 팔기 = 타겟"

## C(채널) 결정 — 접촉지점 거리

R마다 [[접촉지점]]이 멀어도 되는지·가까워야 하는지가 다르다. 그게 채널 전략을 좌우.

- 접촉지점 멀어도 OK인 R → **레드 전략** (노출 위주, 키워드 노출)
- 접촉지점 가까워야 하는 R → **블루 전략** (해당 타겟 플랫폼에서 데려오기)
- 타겟 좁히면 레드도 블루 됨.

## S(시스템) — 모으고 설득하기

[[선택제어]] · [[가치더하기]] · [[매몰비용]]을 결합해 구매로 연결.

> "광고는 클로징이 90%."

## 22기 — 재구매 RCS

22기 1주차에서 RCS에 **재구매 레이어** 추가: "재구매용 R과 재구매용 C와 재구매용 S를 돌려야겠다."

| 축 | 재구매 버전 |
|---|---|
| R | **재구매용 R** (소모품·라인업) · **카페활동용 R** · **팬덤 S용 R** — 예: 강아지 칫솔·치약 (재구매 필수 + 영상 정보 필요 + 종별 상이 + B&A 욕구 = 카페용 R로 최적) |
| C | [[가두리]] 채널 — 문자(4번)·카페(혜택·증정·지속활동)·카톡(깜짝세일·라이브) |
| S | 타이밍 설계 + 시간제한 클로징 |

**RCS 운영 순서** (박진영 패턴에서): 처음엔 C 신경 → C에서 답 나오면 R 손봄 → 다루기에서 수익 볼 땐 S로 돌림 = "RCS 밸런스".

**A→B→C 확장**: "A를 잘 판 이유는 B를 더 잘 팔기 위해서고 C를 출시하기 위함" (세스코: 벌레→위생). 사고력이 높아야 다음 카테고리가 보인다.

→ 22기 100억 강의는 **C를 시작점**으로 진행 (플랫폼 연결 방식부터).

## 22기 3주차 — R·C·S 재정의 + 라온의 생존 RCS

### M군의 재정의 (4강)

- **R = 가치 있는 모든 것** — 단 "R은 욕구가 만든 환상" → [[재구매 R]]. R 3요소 확정: **가치성(남나)·시장성(팔리나)·접근성(판매권)** — 순서는 시장성부터, **접근성의 끝은 제조** ("매출 높은 분은 다 제조로 간다, 위탁은 한계").
- **C = 전달하는 모든 것** — R이 태어나는 순간 채널은 존재한다. **좋은 R은 채널 노력이 적게 든다** — 채널에 집착하는 사람은 대부분 쓰레기 R을 다루는 사람 ("마케팅은 다 돈 아닙니까"라는 사람일수록 모름).
- **S = 조직·시스템** — "세상의 웅장한 건 다 S." 토스 대표가 직원 대상 발표를 많이 하는 이유 = 직원을 타겟으로 선택제어, 직원이 소비자를 타겟. AI로 S가 간편해졌지만 엑시트하려면 필수 (엑시트한 앱 = 직원 100명+).

### 라온 코치의 10년 생존 RCS (3주차 1강 — "0번 라온" 발표)

**생존 = 꾸준함 + 유지.** R 선정 안목의 진화 3단계:

| 단계 | 안목 | 한계/특징 |
|---|---|---|
| ① 키워드 사냥꾼 | 검색량만 보고 진입 (강아지 대리석) | 순위에 일희일비 — 가격경쟁뿐, 수익 유지 불가 |
| ② 욕구 사냥꾼 | **욕구 + 타겟** (여행용 압축기=식품용 재포장, 갤럭시버즈 외이도염 사태→이어팁 소분) | "욕구·타겟만 구분해도 시장은 아직 빈 곳 천지" |
| ③ 욕구술사 | + **포지셔닝·관여도** (리뷰·문의 분석 → 타겟이 원하는 R·프레임 분리가 자연히 나옴) | 시몬스 이천(가운+차트 신뢰 연출, 고관여 타겟은 1층 프리미엄으로 — **프리미엄 라인 1개로 객단가↑**) |

**채널 5법칙** (신규 채널 진입 시, 제품 연결 전 필수 1사이클): ①채널 특성 이해(스레드=반말·B급) ②타겟 분석 ③기존 욕구·물길 체크 ④목적 없이 콘텐츠 발행 ⑤반응 받기 — **이 사이클 완료 전 제품 연결 금지.**

**스레드 100개 판매 4방식**: ①정보성(타겟 좁히고 선택지 3개 미만 — 그중 2번이 내 것) ②컨셉(리뷰해줄게·공구 — 글 하나로 팔로워 3천) ③판매자 방식(기능·효과 무의미, **스토리텔링·연민**이 핵심 — 83건) ④**판매자 후기 방식**(판매자가 직접 후기 작성 + 프로필 판매자 인증 → 저격 회피). 실측 4.7만원 110개 / 2.4만원 72건.
