# 어뷰징과 리스크

## 한 줄 정의

노출·인기도 지표를 **인위적으로 조작**하는 수단들과 그 **법적·플랫폼 리스크**를 정리한 지도. ⚠️ **규율 변경 (2026-08-26, 사장님 지시)** — 기존엔 "무엇을·왜·리스크·합법 대안"만 적고 실행 방법을 뺐으나, **실행 방법까지 적는다.** 리스크를 모르고 하는 것보다 알고 판단하는 게 낫다는 판단.
> 단 **한 가지는 예외로 남긴다** — **PC·모바일 상페 이원화**(감독기관이 보는 화면과 소비자가 보는 화면을 다르게 만드는 설계)는 절차를 적지 않는다. 그 문서가 존재하는 것 자체가 §신고·수사 대응 실무의 **고의성 입증 재료**가 되어, 적어두면 방어가 아니라 무기를 쥐여주는 쪽이 된다. 관행·리스크 판정은 아래 §PC·모바일에 기록.

## 왜 생기나 (맥락)

[[네이버 쇼핑검색 SEO]] 인기도 = **판매량 + 클릭수**, [[바이럴]] 노출 = **검색 구좌 점유**. 이 지표를 **자연적으로 빨리 올리기 어렵기 때문에** 인위적으로 부풀리려는 시도가 생긴다. 네이버는 "어뷰즈 로직 비공개 + 정밀 필터링 + 부정거래 페널티"로 대응(공식 가이드 명시).

## 신고·수사 대응 실무 (1등급 — 2026-06-07 사장님 승격, 원출처: 22기 22번·전 경찰 13년)

> 법적·윤리 회색지대(진술 축소 등) 포함 — 실제 사건 시 변호사 확인 전제.

- **용어**: '벌금'=형사처벌 (전과 — 단 완납 2년 후 효력 상실, 경찰 전산에만 남고 타인 조회 불가. 동일 죄명 재범 시 가중) vs 범칙금·과태료=행정처분 (전과 X). 약식명령 vs 정식재판의 분기 = **매출** (1억↑이면 정식재판 확률↑ / 매출 적고 초기면 기소유예 가능, 최악 벌금 50만원선).
- **골든타임 = 행정기관(보건소·구청) 단계**: "언제부터 팔았냐"에 위반 상페의 게시 시점 기준으로 좁혀 진술 — 위반 기간이 좁혀지면 매출이 작게 잡힌다. 평소 **상페 변경 시 날짜+캡처 보관**이 안전책.
- **첫 전화 응대**: "혐의 인정하시죠?"에 "네" 금지 (수사기록에 남음) · 통화 녹취 · "확인 후 조사 때 말씀드리겠다"로 즉답 회피. 매출은 "직원·상품 여러 개라 확인 필요".
- **거짓말·책임 전가 금물**: "마케팅 업체가 했다" = 사건만 꼬임. 해당 부분만 솔직 인정 ("그건 제가 한 게 맞습니다") + **역접부사("근데") 금물** ([[마인드/역접부사 안쓰기]]의 수사 버전). 수사관은 자유진술로 모순을 만드는 선택제어를 건다 — 간략히만 답하라.
- **법령 읽기** (식품표시광고법 8조1항 기준): 동그라미=항, 숫자=호. **1~3호 (질병 예방·의약품 오인) = 주관적 조항** → 무죄 판례를 모아 "제 사건과 차이가 뭐냐" 의견서 제출 시 경찰 단계 불송치 가능. **4·5호 (성분·허위) = 객관적** → 빠져나가기 어려움: 기간·매출 축소 + 솔직 반성 + 쇼핑몰 즉시 삭제. 화장품법·표시광고법도 동일 구조.
- **도구**: 정보공개포털(open.go.kr)로 제기된 민원 내용 확인 → 로톡에서 관련 사건 경험 변호사 3명 비교 상담 (서울·30~40대 추천, 수사 단계 약 350만+재판 300만 / 지방 1,000만+).
- **예방이 본론**: **상페는 클린하게** (NPC 공무원은 상페만 본다) — 핵심가치는 후기·QnA·[[허브키워드]] 마킹에 (전환율 차이 없음). [[파워컨텐츠]](소비자 사칭)도 거짓·기만 광고라 경쟁사 신고 빌미 → 판매자 시점 스토리텔링으로 롱런.

## ⚠️ PC·모바일 상페 이원화 — 관행 기록 (2026-08-26)

> 사장님 구술: *"pc 상페랑 모바일 상페를 다른버전으로 설정하는거야. **pc 상페는 안전한, 삼삼한 버전, 모바일은 자극적인 버전.** 공무원은 과대광고 신고받아서 상페 확인할때 pc로 확인하니까"*

**본 위키는 이 방법의 실행을 기술하지 않는다** (§핵심 입장 규율). 관행 인지·리스크 판단용으로만 남긴다. 판정은 셋이다:

| 1 | **표시광고법 판단 기준은 콘텐츠지 디바이스가 아니다.** 신고자가 모바일 화면을 캡처해 제출하면 그게 증거다 — 조사 주체가 PC로 열었는지는 성립 요건과 무관 |
| 2 | **이중 운영 자체가 고의성 증거가 된다.** §신고·수사 대응 실무의 양형 분기(약식 vs 정식재판·기소유예)에서 고의성은 가장 불리한 변수다 |
| 3 | 🔴 **이 위키가 이미 적어둔 안전책과 정면 충돌한다** — *"상페 변경 시 날짜+캡처 보관이 안전책"*. 두 버전을 동시 운영하면 **어느 버전이 언제 걸려 있었는지를 우리가 증명할 수 없다.** 위반 기간을 좁혀 매출을 작게 잡는 **골든타임 방어가 그대로 무너진다** |

→ **효과와 리스크가 같은 방향이 아니라 반대 방향이다.** 통과 확률을 조금 올리는 대신, 걸렸을 때의 처벌 구간을 올린다.

### 그래서 실제로 리스크를 낮추는 것

| **실증자료 확보** | 표현을 지우는 게 아니라 **뒷받침**한다. 인체적용시험·시험성적서. 우리 기획의 저자극 시험 초기 진행 방침이 여기 해당 |
| **표현 수위를 한 벌로 낮춤** | 효능 단정 → 성분 사실 서술 + 체감 서술 + 리뷰 인용 (→ [[프레임 분리]] · [[DA 제품 소싱 기준]] §5-2 효능 아웃소싱) |
| **사전 검토** | 광고 심의·전문 검토를 런칭 전에 |
| **버전 이력 관리** | 상페 변경 시 날짜+캡처 보관 — 한 벌만 운영해야 이 방어가 성립한다 |

## 핵심 입장

- 위 수단들은 **현장에 존재하지만 공식 가이드상 페널티/서비스 중지 대상**이며, 가구매·가짜후기는 **위법** 소지가 크다.
- 본 위키는 이 수단들의 **운영 방법을 기술하지 않는다.** 인지·리스크 판단용 지도까지만.
- 같은 목표(상위노출·매출)는 **합법 루프**(실판매·실리뷰·실트래픽 + 페널티 안 맞는 [[네이버 쇼핑검색 SEO|상품명·이미지 최적화]])로 추구.

#### 자소 분리 표기 — 실행 상세 (2026-08-26 실측)

**원리**: 매체 자동심사는 금칙어를 **문자열 매칭**으로 잡는다. 한 글자를 초성·중성으로 쪼개면 유니코드상 다른 문자열이 되어 매칭을 빠져나가는데, 사람 눈은 여전히 원래 글자로 읽는다.

| 방식 | 예 | 비고 |
|---|---|---|
| **자소 분리** | 사구체 → `ㅅㅏ구체` · 콩팥 → `콩ㅍㅏㅌ` · 배출 → `ㅂㅐ출` · 신장 → `신ㅈㅏㅇ` | 이너젠 모어멜라인 영상 2편 전수 확인 |
| **X 마스킹** | 오줌 → `오X독` · 요독 → `요X독` | ⚠️ X는 비속어로 읽힐 수 있어 시술명엔 O 권장 |
| **O 마스킹** | 필러 → `필O` · 보톡스 → `보O스` | 기존 3법 |

**적용 규칙 3개**
1. **한 소재에 1~2개만.** 자막 전체를 쪼개면 읽는 속도가 떨어지고 신뢰가 깎인다 (모어멜라인은 과다 사용 사례로 본다)
2. **핵심 후킹 문장에는 쓰지 않는다** — 첫 3초는 가독성이 전부다. 마스킹은 본문 기전 설명 구간에
3. **자막에만.** 상페 본문·제품명·전성분에는 쓰지 않는다 — 그쪽은 사람이 읽는 영역이라 효과가 0이고 인상만 나빠진다

**한계 (중요)**: 아래 경고 그대로다. 이건 **반려율을 낮추는 기술**이지 위법을 합법으로 바꾸는 기술이 아니다.

> 🔴 **이 3법+1은 전부 "매체 자동심사" 대상이지 "법" 대상이 아니다.** 반려율은 낮출 수 있어도 **표시광고법 판단은 사람이 읽고 한다** — `ㅅㅏ구체`는 사람이 "사구체"로 읽는다. 마스킹이 많을수록 읽는 사람은 **회피 의도를 먼저 인지**한다. 매체 통과용과 법적 방어를 같은 칸에 두지 말 것.

> **"규제 카테고리일수록 '자극'이 막히는 대신 '공감과 위트'로 승부해야 한다. 반려를 피하려다 보면 오히려 더 사람 사는 이야기, 더 재밌는 카피가 나온다."** → [[공감의 마법]]

**매체별 엄격도**: 구글이 가장 엄격하다 — 뷰티·건기식·의료는 **랜딩페이지까지 검토**하고 비승인 사유를 명확히 안 알려주는 경우도 많다. 특히 **영상이 반려되면 노출 지면 자체가 제한**된다. 좋은 소재를 만들고도 반려로 지면을 못 받아 성과가 안 나는 일이 흔해서, **정책 검토와 반려 관리가 구글에선 실력의 큰 부분**이다. (71188:680-683)

### AI 대량 생성 = 구글 도메인 영구 사망 위험

AI로 콘텐츠를 대량 생성해 한 도메인에 쏟으면 **구글에서 그 도메인이 영구적으로 죽을 수 있다.** 처방은 **이원화** — 실험·대량 생성용 도메인과 본진 도메인을 분리해 운영하고, 본진에 실험을 섞지 않는다.

→ 이 페이지 §어뷰징 지형의 리스크 축에 같은 성격의 항목으로 추가해 읽는다: 효과는 있지만 **플랫폼 제재의 회복 불가능성**(도메인 영구 사망)이 다른 어뷰징보다 크다.
