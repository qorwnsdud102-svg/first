# 어뷰징과 리스크

## 한 줄 정의

노출·인기도 지표를 **인위적으로 조작**하는 수단들과 그 **법적·플랫폼 리스크**를 정리한 지도. ⚠️ **이 페이지는 "무엇을·왜·리스크·합법 대안"만 다룬다 — 실행 방법(계정 수·IP·캡차 우회·세팅·벤더 등)은 의도적으로 적지 않는다.**

## 왜 생기나 (맥락)

[[네이버 쇼핑검색 SEO]] 인기도 = **판매량 + 클릭수**, [[바이럴]] 노출 = **검색 구좌 점유**. 이 지표를 **자연적으로 빨리 올리기 어렵기 때문에** 인위적으로 부풀리려는 시도가 생긴다. 네이버는 "어뷰즈 로직 비공개 + 정밀 필터링 + 부정거래 페널티"로 대응(공식 가이드 명시).

## 어뷰징 지형 (수단 · 조작 대상 · 리스크 · 합법 대안)

| 수단 | 무엇을 조작 | 리스크 | 합법 대안 |
|---|---|---|---|
| **가구매** | 쇼핑 판매지수·판매량 | 부정거래 페널티·몰 단위 제재 / **전자상거래법·표시광고법 위반** | 실판매(광고·CPA로 진짜 전환), 객단가 묶음 |
| **리워드 클릭** | 쇼핑 클릭수 | 클릭 어뷰즈 필터·페널티 | 콘텐츠·광고로 실제 유입 |
| **가짜 후기 대량** | 구매평·신뢰 | 표시광고법(기만 광고) / **의료기기·건기식은 건강 판단 기만** | 실구매평 유도, 표시 지킨 체험단 |
| **카페 봇 자동화·안티캡차** | 대량 발행·계정 | 접근제한·영구정지 / **탐지 회피 = 악의 판정** | 수작업 누적·실명 운영·제휴 |
| **침투(운영진 회피)** | 카페 노출 자리 | 강퇴·신고·삭제 | 정상 제휴·협찬 |
| **경쟁사 대량 신고** | 경쟁사 글 제거 | 무고·업무방해 소지 | 자사 콘텐츠 경쟁력으로 이기기 |
| **DB 거래·공유·교차 발송** | 고객 DB 활용 | **개인정보보호법 — 징역** (서민대출 DB 4천건 거래 → 징역 8개월 실례) | **벤더 구조** — 내 고객에게 지인 제품을 내가 사서 보내는 건 합법 ([[부활]]·[[가두리]]) |
| **블랙마케팅** (악플 자작 → 삭제업체 영업) | 후기·평판 | 명예훼손·업무방해 — 위디스크/파일노리류 무한동력 구조 | "얄팍함을 통제하는 게 중요" — 사고력 낮을 때 욕심내면 안 된다 (22기) |

## 신고·수사 대응 실무 (정사 — 2026-06-07 사장님 승격, 원출처: 22기 22번·전 경찰 13년)

> 법적·윤리 회색지대(진술 축소 등) 포함 — 실제 사건 시 변호사 확인 전제.

- **용어**: '벌금'=형사처벌 (전과 — 단 완납 2년 후 효력 상실, 경찰 전산에만 남고 타인 조회 불가. 동일 죄명 재범 시 가중) vs 범칙금·과태료=행정처분 (전과 X). 약식명령 vs 정식재판의 분기 = **매출** (1억↑이면 정식재판 확률↑ / 매출 적고 초기면 기소유예 가능, 최악 벌금 50만원선).
- **골든타임 = 행정기관(보건소·구청) 단계**: "언제부터 팔았냐"에 위반 상페의 게시 시점 기준으로 좁혀 진술 — 위반 기간이 좁혀지면 매출이 작게 잡힌다. 평소 **상페 변경 시 날짜+캡처 보관**이 안전책.
- **첫 전화 응대**: "혐의 인정하시죠?"에 "네" 금지 (수사기록에 남음) · 통화 녹취 · "확인 후 조사 때 말씀드리겠다"로 즉답 회피. 매출은 "직원·상품 여러 개라 확인 필요".
- **거짓말·책임 전가 금물**: "마케팅 업체가 했다" = 사건만 꼬임. 해당 부분만 솔직 인정 ("그건 제가 한 게 맞습니다") + **역접부사("근데") 금물** ([[마인드/역접부사 안쓰기]]의 수사 버전). 수사관은 자유진술로 모순을 만드는 선택제어를 건다 — 간략히만 답하라.
- **법령 읽기** (식품표시광고법 8조1항 기준): 동그라미=항, 숫자=호. **1~3호 (질병 예방·의약품 오인) = 주관적 조항** → 무죄 판례를 모아 "제 사건과 차이가 뭐냐" 의견서 제출 시 경찰 단계 불송치 가능. **4·5호 (성분·허위) = 객관적** → 빠져나가기 어려움: 기간·매출 축소 + 솔직 반성 + 쇼핑몰 즉시 삭제. 화장품법·표시광고법도 동일 구조.
- **도구**: 정보공개포털(open.go.kr)로 제기된 민원 내용 확인 → 로톡에서 관련 사건 경험 변호사 3명 비교 상담 (서울·30~40대 추천, 수사 단계 약 350만+재판 300만 / 지방 1,000만+).
- **예방이 본론**: **상페는 클린하게** (NPC 공무원은 상페만 본다) — 핵심가치는 후기·QnA·[[허브키워드]] 마킹에 (전환율 차이 없음). [[파워컨텐츠]](소비자 사칭)도 거짓·기만 광고라 경쟁사 신고 빌미 → 판매자 시점 스토리텔링으로 롱런.

## 핵심 입장

- 위 수단들은 **현장에 존재하지만 공식 가이드상 페널티/서비스 중지 대상**이며, 가구매·가짜후기는 **위법** 소지가 크다.
- 본 위키는 이 수단들의 **운영 방법을 기술하지 않는다.** 인지·리스크 판단용 지도까지만.
- 같은 목표(상위노출·매출)는 **합법 루프**(실판매·실리뷰·실트래픽 + 페널티 안 맞는 [[네이버 쇼핑검색 SEO|상품명·이미지 최적화]])로 추구.

## 야사 — 법적 방어 실무 (수강생 74·42번)

> ⚠️ 야사: 수강생 실전 경험담 — 법률 자문 아님, 적용 전 전문가 확인. 출처: `sources/엠타트업/2026-06_엠타트업_22기-수강생노하우.md`

- **되팔이(무단 재판매) 퇴치 (74번)**: ①사진 도용이면 저작권 신고 (사업자등록증+원본사진 — 단 고객 후기 사진은 고객에게 **메일로 원본** 받아야, 카톡/문자는 원본 깨짐) ②도용 아니면 **개인정보보호법 59조** 논리로 압박 (되팔이→내 스토어로 고객정보가 무단 제3자 제공되는 구조). 적발: 내 구매자명에서 되팔이 스토어명 검색·수취인 불일치 추적. 증거는 **구매확정 전에** 캡처 ("DB는 신이다"). 단 되팔이 결투는 관여도를 뺏기니 꼭 필요할 때만.
- **변호사 선임 7원칙 (42번, 본인 피소 경험)**: 지방이어도 지역구 고집 말 것·네트워크(체인) 로펌 회피·**관련 사건 실적 필수**·경찰 출석부터 1심까지 커버 확인·사무장 아닌 변호사 1:1 소통·"징역 10년" 겁주기는 변호사의 제로마케팅(결핍 내리기)이니 현혹 금지·**듣고 싶은 말 해주는 변호사 경계** (방문 전 판례로 양형 수준 직접 인지). "보건소·경찰서는 잘 성장하고 있다는 극찬" 프레임.
