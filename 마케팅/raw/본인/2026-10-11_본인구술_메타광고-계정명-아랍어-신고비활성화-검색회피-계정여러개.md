# 2026-10-11 본인 구술 — 메타 광고 계정 이름을 아랍어로 정하는 경우가 많다(신고당해 비활성화되니까 + 남들이 검색하는 걸 막으려고), 메타 광고 계정을 여러 개 쓰는 경우가 많다

출처: Claude가 "디크솔 광고는 페이지 이름이 아랍어 'نور'라 남의 광고로 넘겼다, 제 실수"라고 보고하자 사장님이 보낸 채팅 한 통. 앞의 두 줄은 Claude 보고를 사장님이 붙여 넣은 것이고, 화살표 뒤가 사장님 말이다. 원문은 그대로다.

## 원문

```
* 디크솔 광고는 '디크솔'이 이미지 안에만 있습니다. 페이지 이름은 아랍어 'نور'이고, 본문은 "오직 해당 링크에서만!" 한 줄이라 빠졌습니다.
* 저는 빠진 목록에서 'نور' 페이지 광고 1건을 보고도 남의 광고로 넘겼습니다. 확인하지 않은 제 실수입니다.


-> 메타에서 신고당해서 계정에 비활성화 되니까 + 남들이 검색하는걸 방지하기위해 아랍어로 계정이름 정하는 경우 많음, 메타 광고 계정 여러개인경우 많음
```
