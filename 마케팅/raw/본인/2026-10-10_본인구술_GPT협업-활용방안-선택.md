# 2026-10-10 본인 구술 — GPT(Codex) 협업 활용 방안 선택

출처: 사장님이 Claude에게 보낸 채팅. 사장님이 "gpt와 연결통로도 만들었는데, 채점, 검토말고 좀 더 활용할 방안도 생각해줘"라고 묻자, Claude가 다섯 가지를 제안했다(1. 사장님 반응 예측, 2. 기초분석 조사 나눠 맡기, 3. 사실 수집을 따로 해서 맞춰 보기, 4. 기획 다음 단계 나눠 맡기, 5. 정기 감시). 아래 원문은 그에 대한 사장님 답이다. 각 항목 제목은 Claude가 쓴 것이고, 화살표 뒤가 사장님 말이다. 메시지 그대로다.

## 원문

```
1. 사장님 반응 예측 (가장 추천), 2. 기초분석 조사 나눠 맡기 -> 1,2번은 픽스로 진행

3. 사실 수집을 따로 해서 맞춰 보기 -> 이건 초반 몇개를 해보면서
누가 사실 수집을 잘하는지 서로 평가해서, 잘하는 ai가 사실 수집하는걸로
```

## Claude가 제안한 1~3번의 뜻 (Claude 기록, 원문 아님)

1. 사장님 반응 예측: 기획서를 내기 전에 Claude와 GPT가 각자 "사장님이 뭐라고 하실지"를 판례만 근거로 예측해 봉해 두고, 실제 오답노트와 맞춰 본다. 적중률이 규칙집이 사장님 판단을 얼마나 담았는지의 숫자가 되고, 빗나간 예측이 다음 규칙 후보가 된다.
2. 기초분석 조사 나눠 맡기: 한 결핍을 둘이 나눠 동시에 조사한다(예: Codex = 결핍 쪽 유튜브·나무위키·구글, Claude = 시장 쪽 메타 광고·네이버 검색량). 결과는 파일로 넘겨 시장 카드 하나로 합친다.
3. 사실 수집을 따로 해서 맞춰 보기: 판례 추출·결핍 증상 비중처럼 사실을 모으는 일을 둘이 따로 하고 대조한다.
