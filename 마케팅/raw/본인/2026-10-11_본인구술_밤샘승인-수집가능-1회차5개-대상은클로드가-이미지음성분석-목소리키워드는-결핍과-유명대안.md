# 2026-10-11 본인 구술 — 밤샘 작업 승인(수집 가능 · 기획 1회차 5개 · 대상은 Claude가) + 이미지·음성 분석 질문 + 목소리 키워드는 결핍과 결핍을 해소하는 유명한 대안

출처: 사장님이 곧 주무신다며 밤새 할 일을 물으셨고, Claude가 '자기 전에 답 주실 것 3개'와 '② 단계 도구가 어떻게 작동하나' 설명을 드렸다. 사장님은 그 줄들을 붙여 넣고 '->' 뒤에 답했다. 원문은 그대로다.

## 원문

```
1. 수집 허락: 밤새 필요할 때 네이버 검색량 조회(조회만)와 커뮤니티·유튜브 공개 글 수집을 해도 될까요? 유튜브가 막히면 멈추고 아침에 보고드립니다. -> 가능,
2. 기획 1회차를 오늘 밤 새 방식으로 5개 돌릴까요? -> 그래
3. 대상은 제가 고를까요? 아니면 지정하실 결핍이나 시술이 있나요? (예: 주름·탈모·관절통 + 피부과 시술 상징) -> 너가 골라


그리고 요즘 뜨는 제품들 급상승한 검색량으로 측정해서, 해당 제품이 왜 잘팔리는지, 어떤 상징재를 썼는지
분석 잘해서 정답지의 양을 늘리는 작업을 너 스스로 할수있게 하기로했는데 (물론 처음엔 내가 판단 도와줘야겠지만), 이건 어떻게 됐는지?


한 장에 모으기: 제품마다 대표 사진 1장(영상이면 첫 1초 장면)과 광고 문구를 한 장에 모읍니다. -> 전체 이미지, 음성 분석은 못하는지?


① 목소리 먼저: 출발점 정하기 전에 사람들 말부터
예시: 주름

1. 키워드 고르기: 결핍어·시술 이름·방법어 가운데 검색량 높은 것을 여러 개 고릅니다. 예를 들면 팔자주름, 울쎄라, 써마지, 목주름, 주름 없애는 법입니다. 한 키워드를 더 많이 긁는 대신 키워드 수를 늘립니다. -> 결핍에 대한 키워드, 결핍을 해소하는 유명한 대안들 키워드로 찾으란 의미임



1. 모으기: 키워드마다 유튜브 댓글과 커뮤니티 6곳(디시·에펨·네이트판·아카라이브·루리웹·엠팍)의 글·댓글을 모읍니다. 로그인이 필요한 곳은 뺍니다. 유튜브가 막히면 멈췄다가 나중에 이어서 받습니다.
2. 먼저 읽고 항목 정하기: 좋아요 많은 순으로 읽고 항목을 정합니다. 항목은 증상, 해결 행동, 불만, 대안 가격, 상징원 인식(받아 본 사람들 말)입니다. 결과에 끼워 맞추지 않도록 세기 전에 정합니다. -> 좋네
```
