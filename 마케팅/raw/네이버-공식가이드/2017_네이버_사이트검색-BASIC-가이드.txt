1.1 웹 사이트의 발견
넓디넓은 인터넷 공간에서 네이버 검색로봇이 사이트를 인지하여 수집하는 데에는 신뢰도, 활성도라는 요인이 작용합니다.
즉, 웹 표준을 준수하여 네이버 검색로봇이 방문, 수집하는 데 어려움이 없을 경우, 뉴스, 백과사전과 같이 신뢰도 있는 웹 페이지에 인용되었거나 사용자가 많이 검색하고 이용해서 사이트의 활성도가 높은 사이트면
네이버 검색로봇이 해당 사이트의 존재를 좀 더 빨리 알아차릴 수 있습니다.

1.2 웹 사이트의 수집
네이버 검색로봇이 사이트의 존재를 인지했다면, 사이트를 방문하여 해당 정보를 수집할지, 수집한다면 어느 정보를 수집할지, 검색에 노출이 가능할지를 파악합니다.
이때 전 세계적으로 합의된 컴퓨터 언어를 번역하여 기계적으로 수집, 반영하도록 하고 있어 웹 표준을 준수하는 것이 매우 중요합니다.

1.2 웹 사이트의 수집 - 로봇룰
잠깐! 네이버 검색로봇이 인지하고 수집할 수 있는 ‘웹표준을 준수’한 ‘컴퓨터 언어’란 무엇일까요?
1) 로봇룰 ‘로봇룰’ 이란, 웹 사이트에 로봇이 접근하는 것을 방지하기 위한 규약으로, 일반적으로 접근 허용 및 제한에 대한 설명을 ‘robots.txt’에 작성합니다.
로봇룰에 의해 웹 사이트에 접근 제한된 경우, 네이버 검색로봇이 사이트에 접근할 수 없으므 로 사이트 정보 수집 및 검색결과 노출이 불가합니다.
예) 웹마스터도구 robots.txt http://webmastertool.naver.com/robots.txt
User-agent: * Disallow:/ Allow:/$ Allow:/guide/ Allow:/sitemap.xml

1.2 웹 사이트의 수집 – HTML
잠깐! 네이버 검색로봇이 인지하고 수집할 수 있는 ‘웹표준을 준수’한 ‘컴퓨터 언어’란 무엇일까요?
2) HTML (hyper text markup language) ‘HTML’이란, 웹브라우저 상에 정보를 표시하기 위한 기계 언어로, 웹 상에서 문서를 만들기 위하여 사용하는 기본적인 프로그래밍 언어의 한 종류 입니다. HTML 마크업을 통해 웹 사이트 내 제목, 메뉴, 하이퍼링크 등 브라우저상에 표시되는 웹 사 이트의 모든 정보를 ‘태그’를 사용하여 입력합니다.
대표적으로 사이트 검색결과에 노출되는 ‘제목’은 ‘title’ 태그로, ‘설명문’은 ‘description’ 태 그로 입력합니다.
예) 웹마스터도구 제목/설명문에 대한 HTML
<head> <title>네이버 웹마스터도구</title> <meta name="description" lang="ko" content="웹마스터도구에서 내 사이트의 검색 반영 정보와 웹 표준 가이드를 확인하세요"> <meta property="og:title" content="네이버 웹마스터도구" /> <meta property="og:description" content="웹마스터도구에서 내 사이트의 검색 반영 정보와 웹 표준 가이드를 확인하세요" />

HTTP (Hyper Text Transfer Protocol) 이란? HTTP 란, 웹 브라우저상에서 텍스트, 그래픽이미지, 사운드, 비디오, 기타 멀티미디 어 파일 등을 송·수신하는 데 필요한 통신 규약으로 이용자가 웹 사이트를 접속 했을 때, 사전에 협의된 규약에 따라 정상적인 정보로 응답해야 합니다.
따라서 네이버 검색로봇이 웹 사이트를 방문했을 때 정상적인 정보가 수신되지 않 는 경우, HTTP 프로토콜을 준수하고 있는지 점검이 필요합니다.

현재 운영중인 사이트의 검색로봇 수집 허용 여부는 인터넷 주소 입력창에 사이트 URL + /robots.txt 를 입력, 접속하여 쉽게 확인할 수 있습니다.

사이트맵, RSS를 제출하기
: 사이트에서 생성되는 웹 페이지(콘텐츠)를 누락 없이 검색에 반영할 수 있습니다.
1) 사이트맵 (Sitemaps) 사이트맵은 웹 사이트의 웹 페이지를 계층적으로 분류한 목록으로, 해당 웹사이트를 구성하고 있는 전체 구조를 보여줍니다. 사이트맵 제출 시 네이버 검색로봇이 해당 사이트의 메뉴 및 콘텐츠를 쉽게 찾을 수 있도록 하여 검색 결과 반영에 도움이 됩니다.

2) RSS (Rich Site Summary/Really Simple Syndication) RSS는 업데이트가 빈번히 이루어지는 웹 사이트에서 업데이트된 정보를 사용자들에게 자동적으로 간편하게 제공하도록 적용된 시스템으로 RSS 제출 시 네이버 검색로봇이 해당 사이트의 업테이트된 최신정보를 쉽고 빠르게 인지/수집하여 검색결과 반영에 도움이 됩니다.
RSS는 네이버 웹마스터도구에 로그인 후 사이트 클릭, ‘요청 > RSS 제출’ 메뉴 에서 제출할 수 있습 니다.

5. FAQ

FAQ
Q. 동일한 키워드로 사이트가 나왔다가 안 나왔다 해요.
사이트 검색 노출에서 제외되는 경우는 다양한 원인이 있을 수 있습니다. 사이트 접속이 원활하지 않거나 일시적으로 접속 불가한 상태 등 검색로봇이 방문한 시점에 사이트 정 보가 정상적으로 수신되지 않는 경우, 사이트 검색 노출에서도 일시적으로 제외 될 수 있습니다.
따라서 정상적으로 사이트 정보 수집이 가능한지 여부는 사이트 간단체크를 통해 확인해주시면 좋겠 습니다. 만약 사이트 점검 시 문제가 없다면 정확한 사유확인을 위해서 기술적인 검토가 필요하므로 온라인 도 움말을 통해 접수해주세요.
Q. 사이트 제목/설명은 무엇이고 어떻게 확인하나요?
사이트의 제목과 설명은 업체명과 주요 콘텐츠에 대해 설명하는 문구로 검색결과에 보여지며 이용자 에게 이 사이트가 어떤 사이트인지 알려줄 수 있는 정보입니다.
현재 검색결과에 반영되어있는 사이트의 제목과 설명은 네이버 웹마스터도구의 '사이트 간단체크'를 이용하시거나 사이트 접속 시 '소스보기'를 통해 설정된 마크업 페이지 정보로 확인할 수 있습니다.

FAQ
Q. 네이버 웹마스터도구에 사이트를 등록하거나 사이트 내 제목/설명 태그를 수정한 경우, 검색 결과에 반영되는 데까지 얼마나 걸리나요?
사이트의 정보가 검색 결과에 반영되는 데에는 재수집과 색인 과정을 거치게 되며 최소 1일~ 수 주가 소요될 수 있습니다. 단, 검색 반영 주기는 사이트의 신뢰도/활성도에 따라 다르게 산정되므로, 일반화된 주기를 알려드리 기 어렵습니다.
이 경우, 수집요청’ 을 메뉴를 이용하여 1~2일 내에 재수집 진행하므로 수집주기를 줄일 수 있습니다.
Q. description에 작성한 키워드이나 검색결과에 다 반영되지 않는건 왜 그런가요?
작성하신 내용은 사이트와의 상관성, 키워드 간의 상관성, 검색형 키워드로서의 연관성 등 전체적인 연 관성을 고려하여 검색결과에 반영되며 연관성이 낮은 일부 키워드는 검색결과에 노출되지 않을 수 있 습니다.
반면에 연관성이 떨어지는 단어를 과도하게 입력하는 경우, 장기적인 관점에서 신뢰도나 활성도 측면 에서 불리하게 작용할 수 있으므로 제목, 설명문 등 내용을 작성하실 때는 브랜드와 연관성이 있고 우 리 업체를 대표할 수 있는 단어를 고려하여 키워드를 선택하시는 것이 좋습니다.

FAQ
Q. 메인 홈페이지 외에 다양한 채널 (블로그, 카페, 페이스북 등) 등을 활용하면 검색 노출에 유리한가요?
단순히 여러 채널을 운영하는 것은 사이트 검색에 영향이 없습니다. 단, 일관된 콘텐츠로 브랜드 홍보에 적절한 채널을 운영하시는 경우 이용자에게 유용한 정보로 판단되 어 검색에 유리하게 작용할 수 있습니다.
하지만 메인 홈페이지에서 홍보하려는 콘텐츠와 채널로 운영하는 사이트의 콘텐츠가 다른 경우, 오히 려 일관성이 떨어지며 검색 반영에 불리하게 작용할 수 있으므로 양질의 콘텐츠로 일관성있게 관리하 시는 것이 좋습니다.
예) 공기 청정기 판매 사이트에서 운영하는 블로그 채널에서 브랜드/제품과 관계없는 연예 뉴스로 도 배하는 경우 등

FAQ
Q. 네이버 검색에 잘 반영되거나 상위에 노출하기 위해서는 어떻게 하면 되나요?
기본적으로 웹표준을 준수하여 검색 반영에 최적화 시키는 것이 가장 중요합니다. 따라서 사이트 간단체크 등을 통해 정상적으로 반영이 가능한 상태인지 점검하는 것이 필요하며 그 외 시스템에 의해 실시간으로 수집된 정보를 기반으로 세부적으로 다양한 로직이 있으나 기본적으 로 신뢰도, 활성도 측면에서 이용자의 검색의도에 부합하는 사이트로 이용자에게 유용한 정보라고 판 단되는 경우 상위에 노출 될 수 있습니다.
신뢰도와 활성도는 사이트 내에서 생산되는 콘텐츠 관리가 중요합니다. 사이트 내 이용자에게 유용한 양질의 콘텐츠가 꾸준히 생산/관리된다면 해당 정보가 신뢰성 있는 사이 트에 인용될 확률이 높아지며, 이를 통해 해당 사이트 이용자가 증가하여 활성도 또한 향상될 수 있습 니다.
또한 이러한 꾸준한 사이트 관리는 스팸성 게시글 등 검색 반영에 불리하게 작용할 수 있는 요소를 빠 르게 감지하고 관리 할 수 있기 때문에 검색 결과 상위 노출에 도움이 될 수 있습니다.
