# 히토 온천크림 추가상품 선정

## 최신 소싱 방향 — 2026-10-04 사용자 보정

사용자가 구성의 결을 명시했다: 오십견은 스트레칭 도르래, 무릎은 무릎 보호대, 엘보는 엘보 보호대. 손가락 오프너는 생활 편의용품이라 이 구성과 맞지 않는다는 판정이다. 따라서 아래 초기 보고서의 오프너 1순위는 **현재 메인 추가상품 선택에서 해제**하고 생활보조 후보로만 보존한다. 오십견도 현재 구성에 다시 포함됐다.

현재 손가락 후보는 **부드러운 손가락 관절 보호장갑**과 **한 손가락용 조절 보호대**를 비교한다. 장갑은 여러 손가락을 한 번에 감싸는 제품이라는 구성 정합성에서 먼저 검토할 수 있지만, 기존 커뮤니티 분석의 직접 압박장갑 구매 신호가 약하다는 사실은 유지한다. 제품군이 어울린다는 판단과 판매성·치료효과는 분리한다. 개방형 장갑은 절단선이 실제 아픈 마디를 덮는지, 착탈·사이즈·봉제선·조임을 샘플로 확인한다. 한 손가락용 고정대는 특정 마디·진단에 따른 별도 후보이며 전체 고객 기본옵션으로 확정하지 않는다.

외부 근거 — 위키에 없음: [Dorset NHS 손 관절염 안내](https://www.mskdorset.nhs.uk/hand-and-wrist-pain/hand-and-wrist-pain-osteoarthritis-of-the-hand/)는 압박장갑의 보온·지지 용도를 설명한다. 그러나 [A-GLOVES 무작위시험](https://pmc.ncbi.nlm.nih.gov/articles/PMC7792116/)에서는 류마티스·미분화 염증성 관절염 환자에서 압박장갑이 느슨한 비교 장갑보다 통증·기능 개선에 우월하지 않았다. 이 시험을 손 골관절염 전체에 직접 일반화하지 않되, 압박이 강하면 치료효과가 커진다는 소구의 근거로 쓰지 않는다. 히토를 바른 직후 장갑으로 덮는 병용 역시 미검증이다.

아래 본문은 초기 분석·판매가 가설과 원문 근거를 보존한 기록이다. 현재 선택은 이 최신 소싱 방향을 우선한다.

### 사용자 제시 단일 손가락 압박 보호대 — 사진 평가

#### 최신 검색수요 보정 — 사용자 첨부 화면

최근 30일 표시 검색량은 압박장갑 140회(PC20/MO120), 손가락 보호대 14,360회(PC1,760/MO12,600), 손가락 마디 통증 30,110회(PC3,810/MO26,300)다. 압박장갑 검색자의 50대 이상 비중은 20.7%로 표시됐다. 이는 사용자 화면의 도구 표시값이며 네이버 원데이터·산출방식·실시간 값은 별도 검증하지 않았다. 검색 횟수를 사람 수·구매자 수로 바꾸지 않는다.

현재 판정은 **압박장갑은 판매 신호가 있는 틈새 제품군이며, 대중적 인지도를 확인한 것은 아니다**. 리뷰 1,650건은 기간 미상 누적치이고 검색량은 최근 30일이라 서로 충돌하지 않는다. 손가락 보호대라는 넓은 제품군은 검색 수요가 더 크지만 그 안에는 스포츠·부상·엄지·부목 목적도 섞일 수 있어 특정 1688 압박형의 수요로 직접 치환하지 않는다. 현재 소싱은 손가락 보호대 후보 비교를 먼저 진행하고 압박장갑은 보조 비교 후보로 유지한다. 익숙한 추가상품이라는 기준에서 압박장갑을 메인으로 우선할 근거는 약해졌다.

추가 시장 근거: 사용자 첨부 네이버 스마트스토어 `evmedtech/products/5511293602` 화면의 에버힐 에버그라운드 압박장갑은 판매가 29,800원, 플랫폼 리뷰 1,650건, 평점 4.65로 표시됐다. 플랫폼 화면에 최근 1주간 32명 구매, 최근 3개월간 35명 재구매도 표시됐다. 상단 확장프로그램의 예상 7일 판매량 39건·예상매출 116만원은 별도 추정치이므로 플랫폼 관측값과 합치지 않는다. 리뷰 진위·작성 기간·구매자의 연령·성별은 미검증이다. 사용자 화면을 근거로 기록했으며 실시간 사이트 재검증은 하지 않았다.

해석: 손가락 관절 불편을 소구하는 **반손가락 압박장갑**은 단순 상품 등록을 넘어 구매·리뷰 축적 신호가 있다. 이에 따라 앞선 장갑의 직접 수요 신호 부족 판정은 '기존 커뮤니티 표본에서는 약하나, 사용자 제공 시장 화면에서는 실제 판매 신호 확인'으로 보강한다. 한국 50대 여성의 전체 인지도·수용성이나 임상 실효성은 확정하지 않는다. 장갑과 한 손가락 스포츠 보호대는 형태와 구매상황이 달라 동일 SKU의 수요 증거로 치환하지 않는다. 현재 샘플 비교에 반손가락 장갑을 포함할 사업 근거는 강화됐다.

1688 사진의 제품은 농구·배구·피트니스용 손가락 보호대로 소개된다. 옵션 `加压款`은 압박형, `加压支撑款`은 압박+지지형, `单指`는 한 손가락형, `双指`는 두 손가락형, `单只装`은 낱개 포장이다. 사진상 S는 손가락 둘레 5.3~6.5cm, M은 6.6~7.7cm로 표기됐다. 지지판 유무·재질·탈착 여부·측정 위치는 사진으로 확정하지 못했다. 판매량 표시는 1688 공급자 판매 수치이며 국내 50대 여성의 인지도를 증명하지 않는다.

판정은 **카테고리 결이 맞는 샘플 후보, 효과·수용성 미검증**이다. [국내 벨크로 손가락 보호대 판매](https://www.10x10.co.kr/shopping/category_prd.asp?itemid=6578034)는 유통 존재만 확인하며 보급률로 읽지 않는다. 기존 정독에서 보호대·부목이 함께 언급된 5개 글도 이 압박형 SKU의 수요나 효과를 증명하지 않는다.

외부 1차 근거 — 위키에 없음: [2020년 여성 손 골관절염 52명 무작위시험](https://asht.org/sites/asht/files/images/Research/october_research_article_effectiveness_of_nighttime_orthoses_in_controlling_pain_for_women_with_hand_oa_silva_et_al_2020.pdf)은 맞춤 열가소성 손가락 보조기를 6개월 야간 착용한 연구다. 단순 천 압박 보호대에 결과를 직접 적용하지 않는다. 시각적 거부감은 낮을 가능성이 있지만, 검은 스포츠 디자인·착탈·손 씻기·요리·다수 손가락 착용·아픈 마디를 실제 덮는지가 사용 장벽이라는 추론이다.

샘플은 한 손가락형 압박형 S/M, 지지형 S/M을 비교한다. S를 여성 공통 사이즈로 지정하지 않는다. 통증 완화·치료 소구보다 확인된 착용 구조로 설명하고, 불편·저림이 생기는 조임을 제품의 강점으로 삼지 않는다. 히토 도포 후 덮는 병용은 여전히 미검증이다.

목적은 50대 이상 여성이 히토 온천크림과 같은 주문에서 부담 없이 추가하는 소형 제품을 찾는 것이다. 최신 요청에 따라 무릎 퇴행성 관절염, 테니스·골프 엘보, 손가락마디통증 세 타겟에 집중한다. 오십견은 이번 선정에서 제외한다.

전체 테스트 순서는 손가락 불편용 병뚜껑 오프너, 엘보용 패드 밴드, 무릎용 조절형 보호대다. 각 랜딩에는 해당 타겟의 상품만 제안한다. 오프너는 구매 부담·사용 시연·크림과의 결합 문제를 고려한 첫 테스트 후보이며, 전 고객에게 가장 많이 팔린다는 판정은 아니다. 세 타겟의 공통 상품은 확정하지 않는다. 소형 팩은 후순위 조건부 후보로 남긴다. 이는 사입 확정이나 치료효과 판정이 아니라 커뮤니티 불편과 구매 조건에 근거한 상품 테스트 제안이다.

## 2. 자료를 읽은 방법

8개 원본 엑셀에서 `전체` 시트가 있으면 이를, 없으면 `Sheet1`을 읽었다. `필터링` 시트를 다시 더하지 않았다. 헤더 제외 원본 127,335행, 제목·본문·댓글 중 텍스트가 있는 행 124,597행이다. 이는 사람 수나 구매자 수가 아니다.

통합 파일의 URL 없는 댓글은 바로 앞 게시글 URL에 연결했다. 네이버 카페의 동일 게시글 주소는 통합하고, 게시글 ID를 포함하는 다른 사이트의 쿼리 문자열은 유지했다. URL·행 유형·공백 제거 텍스트가 같은 행을 중복 처리한 검색용 텍스트 행은 78,044개다. 이 안에는 URL가 `{}`인 미식별 자료도 남아 있으므로 최종 고유 댓글 수로 사용하지 않는다. 유효 주소를 가진 게시글 묶음은 5,392개다. 이는 이번 주소 정규화 기준이며 URL의 모든 변형을 완전히 통합했다는 뜻이 아니다. 짧은 동일 댓글이 합쳐질 수 있으므로 사람 수 추정에 사용하지 않는다.

전수 텍스트 검색 후 관련 원문을 정독했다. 파일 간 중복, 광고와 체험단, 검색어 도배, 뉴스와 무관한 생활글이 섞여 있다. 같은 카페의 두 파일을 서로 독립된 표본으로 간주하지 않는다. 류마티스 자료는 손 사용 불편의 보조 근거로만 참고하며 퇴행성 관절염과 같은 질환으로 묶지 않는다. 골프엘보 전용 파일이 없으므로 테니스엘보 자료에서 관찰한 불편을 골프엘보 수요로 그대로 확정하지 않는다.

`콘드글리칸`, `소비자브랜드대상`, `전관제`, `손가락케어기` 등 반복 판촉 표현과 체험단 문구가 발견됐다. 자동 제외만으로 나머지 글이 자연 후기라는 보장은 없다. 핵심 추천은 짧고 구체적인 생활 불편과 실제 제품 사용·불만 문맥을 중심으로 판단했다.

## 3. 원문이 보여주는 구매 상황

정독 집계는 담당 파일·선택 범위에 따라 다르므로 합산하지 않는다. 무릎·엘보·관절염 3파일의 후보 매칭 부모 134개 중 질환 문맥을 확인한 73개 글에서는 무릎 보호대 22개, 엘보 보호대 23개 글이 확인됐다. 반복 홍보 의심 언급을 분리한 뒤 엘보 보호대는 14개 글, 팩 제품은 3개 글에 남았다. 반면 손가락·갱년기 담당의 정독 38개 글과 생활보완 3개 글에서는 직접 오프너 사용·구매 글이 확인됐다. 이는 탐색·정독 목록의 관찰 건수이며 전수 수요조사, 구매자 수, 긍정 후기 수가 아니다. 정확한 선정 목록은 담당 원문분석 문서에 보존했다.

## 6. 발열 본품과 사용을 엮는 범위

같은 주문으로 판매하는 것과 같은 피부에 동시에 사용하는 것은 별개다. 히토의 전성분·사용 주의사항·보호대와의 병용 시험을 이번 자료에서 확인하지 못했으므로, 크림을 바르고 바로 보호대·테이프·밀폐 장갑으로 덮거나 온열팩을 얹는 장면을 세트 사용법으로 만들지 않는다. 단순히 크림이 마른 뒤라는 조건만으로 안전성을 확정하지 않는다.

미국 국립의학도서관 DailyMed에 게재된 멘톨·살리실산메틸 외용 의약품 라벨은 꽉 감싸거나 가열 패드를 병용하지 말라고 안내한다. 히토는 이 의약품과 동일 제형이 아니므로 동일한 위험 수준을 단정할 수 없지만, 발열 제품과 덮개·추가 열원의 조합을 제조사 확인 없이 권장하지 않는 이유가 된다.

오프너는 피부에 덮거나 열을 더하지 않는 생활 도구라 이 병용 문제를 피하기 쉽다. 보호대와 냉팩은 본품 사용과 분리된 상황으로 안내할 수 있는지 제조사에 확인한다.

타겟별 랜딩에서는 해당 상품 하나를 먼저 보여준다. 여러 제품 중 고르게 만드는 부담을 줄이되 유료 옵션은 고객이 선택하도록 한다.

이 숫자는 실험 예시다. 원가와 실제 상품 규격 확인 전 확정하지 않는다. 2개 세트에 오프너 7,900원을 추가하면 상품 금액 72,520원이다. 3개 세트는 사용자가 정확한 금액을 주지 않았으므로 임의 합산하지 않는다.

공개 페이지의 무료배송 기준 36,000원이 추가상품에도 적용된다면 본품 1개 주문은 추가상품으로 무료배송 대상이 될 수 있다. 예를 들어 7,900원 추가상품에 배송비 3,000원이 사라지면 고객의 최종 결제 증가액은 4,900원이다. 이는 실제 합산·쿠폰·배송 정책이 확인됐을 때만 사용할 문구다. 판매자는 배송비 부담을 추가상품 이익에서 차감해야 한다.

예시 표현은 제품 기능과 생활상황 중심으로 잡는다. 무릎은 일상에서 착용하는 조절형 보호대, 엘보는 팔 사용 때 착용하는 간편 밴드, 손가락은 손힘으로 비틀기 불편할 때 사용하는 오프너를 보여준다. 화장품에 관절염 치료·연골 재생·염증 억제 효과를 부여하는 세트 문구로 연결하지 않는다.

2. 50대 이상 여성이 설명 없이 꺼내 쓰거나 한 번 안내로 사용할 수 있는지 확인한다. 손가락 불편 고객의 착탈·벨크로 당김·오프너 손잡이 쥐기까지 본다.
3. 원가·포장·배송 무게·불량·반품 조건과 필요한 표시·허가 서류를 공급사에 확인한다. 판매 시세만으로 도매가나 마진을 추정하지 않는다.
4. 타겟별 랜딩에서 추가상품 없음과 상품 1개 제안을 비교한다. 본품 전환율, 추가 구매율, 배송비 차감 후 주문당 기여이익, 반품·불만을 함께 본다.
5. 단품과 2개 이상 본품 세트를 분리해서 읽는다. 배송비 절약으로 늘어난 추가구매와 제품 매력으로 늘어난 추가구매를 구분한다.

간이 계산식: 추가 기여이익 = 추가상품 매출 - 사입·포장·결제수수료·추가 배송 부담·예상 반품 비용. 실제 계산은 부가세 포함/제외 기준을 맞춘다. 객단가 상승만으로 성공이라고 판단하지 않는다.
