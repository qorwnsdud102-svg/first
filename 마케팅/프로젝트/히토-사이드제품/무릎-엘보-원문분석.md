# 히토 사이드제품 — 무릎·엘보·관절염 원문 분석

## 판단

**부위별 옵션부터 검토하고, 범용 옵션은 보류한다.** 엘보는 크기 조절이 쉬운 보호대, 손가락은 병뚜껑 보조도구가 소형 추가옵션의 첫 검토 후보다. 무릎은 여성 고객이 혼자 착용하기 쉬운 보호대를 검토할 수 있으나, 자료의 러닝·운동 부상 경험을 퇴행성관절염의 효과 근거로 옮겨 쓰면 안 된다. 찜질팩은 가격 조건에 맞는 실물이 있지만 댓글 홍보 오염과 히토와의 사용 적합성을 먼저 확인해야 한다.

이 결론은 **상품 샘플을 선정하기 위한 가설**이다. 실제 치료 효과, 50대 여성의 구매 전환, 히토와의 병용 적합성은 이 엑셀에서 확인할 수 없다. 최신 지시에 따라 오십견은 분석·추천 대상에서 제외했다.

위키의 [[마케팅/사이드 R]]은 메인 구매 맥락에서 파생되는 보완 물건을 찾는 기획 원칙으로만 참고했다. **원문 관찰은 3등급**, 상품 연결과 목표 판매가는 **분석자 추론**이다. 기존 [[마케팅/히토 온천크림]] 페이지의 ‘관절통 치료 크림’ 표현은 이번 사용자가 명시한 **화장품 발열 마사지 크림**과 충돌한다. 이번 보고서는 사용자 설명을 우선하며 치료 표현을 채택하지 않는다. 이 충돌은 위키 보강 필요사항으로 보고만 남긴다. 지정 범위 밖 페이지는 수정하지 않았다.

## 2. thread와 중복 처리

1. 게시글 행을 새 부모로 설정한다. **댓글의 빈 URL은 바로 앞 게시글 URL을 상속**한다. 부모의 제목·본문·사이트와 댓글을 묶어 읽는다. 댓글 본문에 등장하는 외부 링크로 부모를 바꾸지 않는다.
2. MLB파크는 쿼리의 `id`를 게시글 식별자로 보존한다. `query`, `p`, 검색 설정이 달라도 같은 `id`면 같은 thread다. 쿼리 전체를 지우지 않았다. 다른 사이트는 이번 데이터의 원본 게시글 URL을 사용한다. 외부 모든 URL 형태에 적용할 범용 정규화라고 주장하지 않는다.
3. 원본 문자열 URL은 **1,003개**, MLB파크의 검색어만 다른 1쌍을 합치면 **1,002개 고유 thread**다. 게시글 1,057행과의 차이 55는 중복 출현이다. 각 파일 내부에는 게시글 URL 중복이 없고, 주로 파일 간 중복이다.
4. 행 중복은 `(타입, thread, 제목, 본문, 댓글, 작성자)`의 완전 일치로 확인한다. 파일 내부 중복 여분은 무릎 56행 / 엘보 84행 / 관절염 72행이다. 세 파일 전체를 합친 뒤 원본 URL 기준 고유 행은 11,296개, MLB파크 정규화 후 **11,294개**다. 원문은 버리지 않고 출처 좌표를 보존한다.
5. 내용 중복은 본문 또는 댓글의 공백을 제거한 문자열로 추가 확인했다. 정규화 후 60자 이상인 동일 텍스트가 서로 다른 thread에 나타나는 묶음은 **45개**다. 그중 게시글 본문 묶음은 8개다. 동일·준동일 후기를 여러 사람이 쓴 것처럼 보이는 경우는 독립 수요로 해석하지 않는다. 아래 후보 빈도는 URL thread 기준이며, 복붙 텍스트가 다른 URL에 게시된 것은 ‘전체 탐색’에 남기고 의심군 제외 집계에서 분리했다.

### 부모 글의 질환 관련성 확인

1,057개 게시글 행을 분리하고, 후보 물건을 언급한 댓글을 부모 글로 되돌렸다. **후보 매칭 부모 134개 thread**의 제목·본문 문맥을 확인하여 주 분석에 73개를 채택했다. 이는 전체 자료의 모든 질환 관련 글 수가 아니라 **후보 물건의 집계에 사용한 부모 글 수**다. 선택 목록은 부록에 남겼다. 나머지 61개 후보 부모는 주 분석 범위에서 제외했다. 관절염 전체 2703행의 관절염 종합 방송도 부위·퇴행성 여부가 특정되지 않아 제외했다.

- 무릎 29개: 퇴행성·골관절염 또는 실제 무릎 관절염 맥락을 확인한 부모. 러닝만으로 발생한 통증, 거위발건염·장경인대 부상, 족저근막염은 별도 보조자료다.
- 엘보 34개: 테니스·골프엘보 또는 해당 통증의 관리·구매 질문. 게임·헬스·골프 글도 질환 관련이면 포함하지만, **50대 여성에 맞는 표본이라고 간주하지 않는다.**
- 손가락 10개: 손가락 관절·마디 통증 또는 손 사용 불편을 확인한 부모. 진단되지 않은 손 증상과 43세 종사자도 보조 문맥으로 포함했음을 공개한다.
- 류마티스 전용 영상 5개는 손가락 증상과 상품 홍보를 살피는 **별도 질환군**으로 처리하고 아래 주 분석 수에 섞지 않았다. 류마티스와 무릎 퇴행성관절염을 같은 환자군으로 합치지 않는다.
- 일반 병뚜껑 도구 소개, 컴퓨터 건강 종합기사, 청원·키워드 나열, 사건글, 허구·스포츠 선수 이야기 등은 주 분석에서 제외했다. 예: 무릎 전체 1313·1314행은 ‘개구리소년 사건을종결한다’, 191·193·194행은 다량 키워드가 포함된 청원글이다. 관절염 전체 1290행의 훈련소가 등장하는 단편소설, 1495행의 AI 기업·공익기업 기사, 무릎 전체 715행의 공익·야구 선수 드래프트 이야기도 선택 목록에 넣지 않았다. 엘보 전체 181·183·184행의 동일 SEO형 키워드 도배도 제외했다.

따라서 아래 ‘질환 검증 후’ 숫자는 엄격한 부모 선택에 따른 분석 표본 수이며, 전체 질환 유병·수요를 추정하는 분모가 아니다. 이 제한으로 부모가 일반 무릎통증 영상인 경우 그 안의 관절염 경험 댓글도 주 집계에 들어가지 않을 수 있다.

## 3. 후보별 고유글 언급 건수

‘고유글 1건’ = 해당 제품군을 **제목·본문 또는 댓글에서 한 번 이상 언급한 서로 다른 부모 thread 1개**. 같은 댓글이 여러 번 있어도 그 thread 안에서는 1건이다. 긍정·부정·질문·교육자료를 모두 포함한 **관찰 빈도**다. 구매수요·구매자 수·효과의 크기가 아니다.

`본문 / 댓글`은 각각 본문 언급 thread, 댓글 언급 thread다. 양쪽에 함께 등장하면 중복되므로 더해서 전체를 만들면 안 된다. 파일별 수는 파일 간 중복이 있으므로 역시 합계로 더하지 않는다.

‘의심군 제외 후’는 반복 텍스트, 홍보 정황이 있는 상품 언급 행과 수작업으로 표시한 유도성 부모를 제외하고도 남는 thread 수다. **광고가 아니라고 인증한 수가 아니다.** 이 값에도 질문·영상 요약·브랜드 추천이 포함될 수 있다.

### 매칭 기준

- 무릎 보호대: `무릎 보호대 / 슬개골 보호대 / 슬개건 보호대`와 붙여 쓴 형태. **무릎 부모에만 적용**. 그냥 ‘보호대’는 자동으로 무릎 제품으로 세지 않았다.
- 엘보 보호대: `엘보 보호대 / 팔꿈치 보호대`. **엘보 부모에만 적용**.
- 손목 보호대: `손목 보호대`. 엘보·손가락 부모.
- 찜질팩: `찜질팩 / 아이스팩 / 냉팩 / 온팩 / 핫팩` 및 앞 수식어. 팩이 없는 일반 ‘찜질’은 제외. 냉온겸용 여부는 개별 제품을 따로 확인해야 한다.
- 테이핑: `테이핑 / 키네시오 / 스포츠 테이프`. 일반 밴드·밴드 음악 제외.
- 저항 밴드: `고무밴드 / 세라밴드 / 테라밴드 / 튜빙 / 밴드운동`. 플렉스바처럼 다른 형태도 포함하므로 동일 상품의 수요로 합치지 않는다.
- 마사지볼·폼롤러·깔창·악력기: 해당 명칭, 깔창에는 인솔, 악력기에는 자이로볼 포함. 부위와 일치하는 부모만 적용.
- 손가락 보호대: `손가락 보호대 / 엄지 손가락 보조기`. 특정 진단·손가락과 범용 마디통증은 구분해야 한다.
- 오프너: `병뚜껑 열어주는 도구 / 병따개 / 오프너`. 단순 ‘뚜껑’이나 슬개골을 뜻하는 ‘뚜껑뼈’는 상품 언급으로 세지 않았다.
- 생활 보조도구: `스프링 가위 / 볼펜 그립 / 손잡이 보조 도구`.

원문 맞춤법이나 띄어쓰기 때문에 검색에서 누락될 수 있고, 유사표현을 모두 수동 코딩한 완전한 제품사전은 아니다. 이 한계를 감춘 정밀 수요 추정은 하지 않는다.

## 4. 원하는 해결과 부정 문맥

## 9. 실행 결정

1. **엘보 옵션은 조절형 보호대부터 비교 샘플**. 소매 안 착용·타이핑·요리 중 간섭·혼자 조절·손세척 후 재착용을 비교한다. 원문에서 28,000원대 가격 고민이 보이지만 지불의사를 전체 고객으로 일반화하지 않는다.
2. **손가락 옵션은 오프너를 생활 시연으로 검증**. 원문에 없는 구매 수요를 확인하는 작은 실험이라는 위치다. 큰 소스병·유자차병·생수병에서 실제 손잡이가 도움이 되는지 확인한다. ‘관절염 효과’ 대신 ‘어떤 뚜껑을 어떻게 여는가’로 판단한다.
3. **무릎 옵션은 일상 착용형을 조건부 후보로 유지**. 운동 커뮤니티의 압박·슬개건 제품을 바로 가져오지 않는다. 50대 여성 고객의 체형·착용 편의·움직임·피부 불편을 먼저 실측한다.
4. 찜질팩은 예산 확인만 끝났다. 히토와 함께 쓰는 추가옵션으로 확정할 만큼 제품 설명서·사용 적합성이 확인되지 않았다.

여기서 확인한 것은 소비자가 말하는 불편, 사용·구매 탐색, 실패, 홍보 정황이다. **제품이 실제로 질환을 개선하는지, 어떤 SKU가 여성 타겟에게 가장 효과적인지는 미확인**이다. 이 구분을 유지한 채 전용 옵션 1~2개부터 검토하는 것이 이번 원문에서 할 수 있는 결정이다.
