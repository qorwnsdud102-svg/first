   (실후기 재료: "엄마가", "남편이", "재구매" — 선물·가족 구매가 많다는 관찰로)
   + 스티커 1장 교체

16 독자 호명 "4,700 조회수 뒤에는 읽어주신 시간 … 피부 고민으로 검색 / 구매 전 궁금해서 / '진짜 솔직한 후기 없을까?' … 저도 딱 그 마음"
   → 3종 독자를 히토로: 부모님 무릎·손마디 때문에 검색하신 분 / 사기 전에 궁금하신 분 / 광고 말고 진짜 후기 찾으신 분.
   (이 3줄이 검색 유입자 유형 = 사실상 타겟 정의. 유지)
   + 고양이 스티커 자리 → 다른 스티커

17 의심 쿼리 3개 "진짜 써보면 어땠을까? / 민감 피부도 괜찮을까? / 광고처럼 드라마틱하게 좋아질까?"
   → 히토 검색자가 실제로 칠 질문 3개로 교체 (따옴표 3줄 형식 유지):
      "진짜 바르면 뜨끈한가?" / "파스 냄새 나는 거 아냐?" / "광고처럼 확 좋아지나?"
      (대안: "엄마 피부 약한데 괜찮나?" / "얼마나 써야 느껴지나?")
   → 마지막 줄 "진정성이 조금은 전해진 걸까요~?" 역할의 반문 1줄, 새 문장.

18 블로그 철학 "블로그는 사람의 마음이 닿는 공간 … 공감·댓글·조용히 읽고 가신 이웃님들 덕분에 …"
   → 화자 본인 말로 새로. 여기부터 20까지는 제품 단어 0 — 광고 밀도 희석 구간.
   + 꽃 사진(장미) → 화자가 직접 찍은 다른 생활 사진 1장 (풍경·꽃·산책)

19 블로그 일상 "방문자 수에 마음이 흔들릴 때 … 아들이 권유해서 시작 … 새가슴이라 친구 추가도 못 하고 … 용기가 필요했답니다 … 경험의 글 하나가 더 오래 기억될 수도"
   → [슬롯] 화자 실제 블로그 이력 (시작 계기·소심했던 얘기·이번 일로 느낀 것). 원본의 '아들 권유·새가슴'은 이 화자 것이니 그대로 쓰지 말고 화자 본인 사연으로.
   + 캐릭터 그림 "감사해요" → 다른 그림

20 마무리 "느리더라도 서툴더라도 직접 느끼고 경험한 솔직한 이야기를 … 오늘도 감사합니다"
   → 같은 결의 마무리, 새 문장. 마지막 한 줄 인사 + 스티커 1장.

----------------------------------------------------------------
4. 어휘 치환표 (원문 → 히토)  — 실후기 어휘 우선, 지어낸 효능 금지
----------------------------------------------------------------
 피부염 치료 후 착색             → 설거지 뒤 손마디 주무르심 / 새벽에 손 저려 깸
 스테로이드 연고 이후 건조         → 파스 붙이면 피부 붉어짐(피부 약함) / 파스 냄새
 거울 볼 때마다 칙칙함            → 아침에 손가락 뻣뻣 / 계단 내려갈 때 무릎
 피부 결이 부드러워졌다           → 발림성 좋고 부드럽다
 화장이 잘 먹는다                → 파스보다 낫다 (남편이 그러더라)
 윤기가 도는 느낌                → 뜨끈한 기운이 마디 속까지
 민감 피부는 천천히 적응          → 뜨끈한 느낌은 호불호
 건조함이 느껴졌다               → (실제 부정 리뷰에서 가져올 것)
 용량이 아쉽다                   → 손가락엔 온기 덜함(실후기) / 2~3주는 지나야 안다(실후기) / 미끈함·소진 속도·가격(추정, 12번)
 드라마틱한 변화                 → 통증이 사라지는 것  ※ 부정문으로만 ("사라진 건 아니지만")
 피부 컨디션을 조금 끌어올려       → 바르고 나면 덜 신경 쓰임 / 파스 안 찾게 됨 / 엄마가 먼저 찾으심
 저속노화·피부 컨디션·안티에이징   → 부모님 무릎·손마디 / 파스 대신 / 부모님 선물
 피부 고민                      → 무릎·손마디 고민
 민감 피부도 괜찮을까?            → 엄마 피부 약한데 괜찮을까? / 파스 냄새 나나?
 한 병                          → 한 통
 올레놀샷 nmn                   → 히토 온천크림 (3단 표기 섞기: 히토 / 히토 온천크림 / 히토 온천크림 관절)

----------------------------------------------------------------
5. 표현 필터 (체감 + 행동변화 수위)
----------------------------------------------------------------
 금지 : 치료·치유·완치·통증 완화·관절염·염증·효능·효과 확실·주사보다·병원 대신·나았다·좋아졌다(통증에 대해)
 허용 : 뜨끈·시원·부드럽게 발림·파스 냄새 없음·파스 대신·덜 신경 쓰임·새벽에 깨는 일 줄었다·엄마가 먼저 찾는다·습관이 됐다·재구매했다
 필수 : 부정 단서 1문장 ("아픈 게 사라진 건 아니다" 류) — 13번 구간
 강조 : 빨간 글씨·형광펜은 감정 문장에만. 효능 문장엔 강조 금지.

6. 이미지 7장 지시 (원본 자리 → 히토)
----------------------------------------------------------------
 1) 카드 임베드 #1 — 히토 1탄 링크        4) 스티커(08 뒤) — 다른 캐릭터
 2) 카드 임베드 #2 — 같은 링크, 다른 날    5) 그림(13 뒤) — 다른 화풍·구도
 3) 카드 임베드 #3 — 2,000 넘던 날        6) 스티커(15·16 뒤) — 다른 것
                                        7) 생활 사진(18 뒤) — 화자가 찍은 것
 ※ 제품 사진은 이 글에 0장 (원본도 카드 썸네일 외 제품 사진 없음). 스튜디오 컷 넣지 말 것.

7. 발행 전 체크 (전부 O 여야 발행)
----------------------------------------------------------------
 [ ] 히토 1탄이 먼저 발행돼 있고 조회수 2,000 넘은 통계 캡처가 있다
 [ ] 원문 문장과 같은 줄 0개 (1장 원칙 1~8 전부)
 [ ] 숫자·날짜가 실제 통계와 일치
 [ ] 11번 유보 표현은 실후기 인용(곽·황), 12번 단점은 후보 중 화자가 실제로 느낀 것 1개로 확정 (추정 표시 ①~⑤ 중 택1 후 '추정' 딱지 제거)
 [ ] "아쉽다는 의견도 꽤 있었다"류 문장 없음 (3점 이하 후기 0건이라 허위가 됨)
 [ ] 5장 금지어 0개, 13번 부정 단서 1문장 있음
 [ ] 링크 = 1탄 임베드만, 태그 0 또는 원본과 다르게
 [ ] 발행 요일·시간대가 1탄·원본과 다름
 [ ] 발행 2주 후 "히토 온천크림 후기" 시크릿 검색 캡처 → 프로젝트 폴더에 보관

8. 남은 결정 (사장님)
----------------------------------------------------------------
 - 화자: 50대 본인 (확정)
 - 12번 아쉬운 점: 추정 후보 ①~⑤ 중 택1 (또는 직접 교체) — 사장님 "이상하면 바꿀게" 기준
 - 1탄이 아직 없으면: 1탄(퍼믹형 한달 후기) 구조표를 같은 형식으로 먼저 만들어야 함 → 요청 시 작성
