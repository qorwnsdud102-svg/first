# DA 기획 단계별 점검 — 한눈에

**한 줄**: 단계는 10개 다 있는데, 단계마다 일을 제대로 했는지 검사하는 사람이 없습니다. 그래서 문제가 사장님 최종 판정에서야 드러납니다.

## 단계별 신호등

| 단계 | 상태 | 한 줄 |
|---|---|---|
| ① 기초분석(시장조사) | 🔴 | 실제 사람 목소리를 기획을 정한 **뒤에** 모음. 제대로 모은 기획은 50개 중 5개 |
| ② 출발점 | 🟡 | 자료가 반대해도 출발점을 안 바꿈 |
| ③ 결핍 | 🟡 | 표본 거의 없이 추측으로 씀 |
| ④ 상징 → 제품 | 🔴 | **가장 약함.** 떨어진 22건 중 14건이 여기서. 작성자가 자기 시험에 스스로 '통과'를 줌 |
| ⑤ 참신함 | 🔴 | 같은 광고가 몇 개인지 거의 안 셈. '몇 개부터 흔한가' 기준이 없음 |
| ⑥ 사업성 | 🟡 | 만들 수 있나, 가장 싼 대안(다이소 2천원)을 안 봄 |
| ⑦ 기획서 | 🟡 | 검사기가 형식만 보고 내용은 안 봄 |
| ⑧ 현실 보정 · ⑨ 범위 | ⚪ | 이 단계 탓으로 떨어진 기획 없음. 아직 볼 거리가 적음 |
| ⑩ 학습 | 🔴 | 규칙은 176줄로 늘었는데 기획은 안 나아짐 → 자가학습으로 바꾸는 중 |

## 사장님이 드신 '시장조사' 예가 실제로 일어났습니다

팔자주름 당사자들 대화에서 해결책으로 **필러가 96번, 울쎄라가 11번** 나왔습니다. 그런데 이 자료는 출발점(울쎄라)을 정한 뒤에 들어와서, 기획은 그대로 울쎄라로 갔습니다.

## 고칠 것 3개 — 규칙은 안 늘림, 사장님 시간 0분

1. **④ 남이 검사**: 작성자가 아닌 다른 Claude가 상징 이름을 가린 설명만 보고 '무엇을 옮긴 제품인지' 맞히게 합니다.
2. **① 순서 고정**: 사람 목소리를 먼저 모으고, 그다음 출발점을 정합니다.
3. **⑤ 기준선을 숫자로**: 이미 판정하신 7건으로 '광고 몇 개부터 흔한 것인가'를 정합니다.

**사장님이 정하실 것**: 이 3개를 고칠까요? (예 / 아니오)
