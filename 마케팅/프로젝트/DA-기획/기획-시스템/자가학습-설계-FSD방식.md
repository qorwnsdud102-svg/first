# 자가학습 설계 — 손 규칙에서 E2E 데이터 학습으로 (테슬라 FSD v12 방식)

> 테슬라 FSD 설명은 위키에 없다. **(위키에 없음 — 일반 지식)**: 테슬라는 v11까지 사람이 조건 규칙 코드(약 30만 줄)를 짰고, v12부터 카메라 영상 → 운전 조작을 한 신경망이 잘 운전한 사람들의 대량 영상으로 직접 배우는 E2E(end-to-end) 방식으로 바꿨다. 이후 개선은 코드를 더 짜는 것이 아니라 **데이터를 더 많이, 더 잘 골라 넣는 것**으로 했다.

## 1. 한 줄 요약

지금 우리 시스템은 FSD v11이다. 사장님 첨삭 한 번이 규칙 한 줄이 되어 176줄이 쌓였다.
v12로 가려면 **메타 광고 라이브러리를 '도로 영상'으로 삼아, 실제로 팔린 제품 수천 개를 기획 카드로 거꾸로 풀어낸 데이터에서 AI가 직접 배우게** 한다. 사장님 첨삭은 규칙이 아니라 그 데이터의 정답표(무엇이 '잘 운전한 영상'인가)로 쓴다. 규칙은 안전 가드레일(법·의료기기·병원 결핍 같은 하드 규칙)만 남긴다.

## 2. 우리가 지금 v11인 증거

| v11의 증상 (테슬라) | 우리 시스템 |
|---|---|
| 새 상황마다 사람이 조건을 하나씩 추가 | 사장님 기각 1번 → 금지 규칙 1줄. 176줄, 하드 41 |
| 규칙끼리 충돌·예외가 늘어남 | 충돌표 32행, 대체 표시, 예외의 예외(④-04·④-16 유명 상징재 예외) |
| 규칙이 못 다루는 낯선 장면에서 실수 | 1~3차 26개 중 '진행' 0. 새 기획은 규칙에 안 걸리게만 써서 '겉핥기'가 됨 |
| 고칠수록 한쪽이 나빠짐 | 회귀 시험: 예전 규칙은 너무 너그럽고, 지금 규칙은 좋은 기획 11건 중 3~5건만 통과(과잉 엄격) |
| 사람이 말로 다 못 하는 감각은 규칙이 안 됨 | 사장님 '참신함·후킹 감'은 규칙 문장으로 옮겨도 채점자가 못 맞힘(3차 N01을 예측 6개가 모두 놓침) |

## 3. E2E로 바꾸면 무엇이 무엇이 되나

| FSD v12 | DA 기획 E2E |
|---|---|
| 입력: 카메라 영상 | 입력: 그 결핍의 **날것 시장 자료** — 메타 광고 묶음(문구·장면·게재일수), 네이버 검색량, 커뮤니티 목소리 |
| 출력: 핸들·페달 조작 | 출력: **기획 카드**(결핍 · 오해→정체 · 상징 · 핵심 코어 · 옮긴 칸 · 1초 장면 · 가격) |
| 학습 데이터: 전 세계 차의 주행 영상 | **메타 광고 라이브러리의 수천 개 상품** — 남의 돈으로 이미 시험된 기획들 |
| 정답 라벨: 잘 운전한 사람의 조작 | **팔린 기획**(오래 돌고 소재가 계속 늘고 브랜드 검색이 오른 상품) **중 사장님 취향에 맞는 것** |
| 나쁜 운전 영상은 걸러 냄 | 흔한 효능 직설 히트(보정팬츠 등)는 걸러 냄(P6223) — 사장님 정답표가 필터 |
| 개선 = 데이터 추가 | 개선 = **히트 카드를 더 모으고 더 잘 고르는 것**. 규칙을 늘리지 않는다 |
| 안전 규칙은 남음 | 🔒 하드 규칙 중 법·의료기기·병원 결핍·임산부 섭취 같은 가드레일만 남김 |

## 4. 데이터 엔진 — 사람 손이 거의 안 드는 수집·라벨 바퀴

```
① 플릿 수집 (스크립트, 토큰 0)          매주 결핍 키워드 100여 개 메타 첫 화면 → 광고 ID·시작일·소재 수 시계열
        ▼
② 결과 자동 라벨 (스크립트, 토큰 0)     같은 상품을 주마다 추적 → 히트(60일+·소재 증가·브랜드 검색 상승) / 실패(30일 안에 사라짐) / 보통
        ▼
③ 자동 해부 (값싼 모델)                히트·실패 상품마다 광고·상세를 읽고 '이 회사가 했을 기획'을 카드로 거꾸로 씀
        ▼
④ 사장님 정답표 (주 5분)               히트 카드 20장을 보고 "내가 했을 기획인가" O/X — 사장님 취향 필터의 라벨
        ▼
⑤ 학습 데이터 = (시장 자료 → 기획 카드 → 결과 · 사장님 O/X) 수천 쌍
```

- **①·②가 핵심이고 지금 시작해야 한다.** 테슬라 데이터가 차가 달린 시간만큼 쌓이듯, 우리 데이터도 주마다 쌓인다. 60일 라벨은 60일을 기다려야 한다. 이미 받아 둔 카드 8,486장(2026-10-10~11)이 0주차다.
  - 한국 광고 라이브러리는 꺼진 상업 광고를 보여 주지 않는다(⑩-10). 그래서 지금까지는 '실패'를 볼 수 없었다. 주마다 같은 ID를 추적하면 '사라짐 = 꺼짐'을 기록할 수 있다. 이게 실패 라벨이다.
  - 수집기는 Rate limit이 있다(1675004). 첫 화면 모드·간격으로 나눠 받는다.
- **③ 자동 해부**는 지금 시장 정답 39개를 사람처럼 해부한 일을 기계로 수백·수천 개로 늘리는 것이다. 값싼 모델로 돌리고, 일부를 비싼 모델로 검수한다.
- **④ 사장님 정답표**가 사장님 첨삭의 새 자리다. 우리 기획을 첨삭하는 대신 **이미 팔린 남의 상품을 보고 O/X만** 하신다. 장당 몇 초다. 같은 5분으로 얻는 라벨이 지금보다 많고, 시장 결과까지 붙어 있다.

## 5. 학습 — 두 단계

### 1단계: 문맥 학습 E2E (지금 모델 그대로, 바로 가능)
- 새 결핍을 기획할 때 규칙 176줄 대신 **가장 비슷한 히트 카드 20~30장(사장님 O 표시 우선)과 실패 카드·사장님 기각 카드 몇 장**을 넣어 주고, 시장 자료에서 기획 카드로 곧장 가게 한다. 10단계 규칙 파이프라인을 거치지 않는다.
- Claude·GPT 모두 문맥 창이 커서 카드 수백 장도 넣을 수 있다. 데이터가 늘면 같은 모델도 기획이 나아진다.
- 필요한 도구: **카드 검색기**(결핍·상징·제형이 비슷한 카드를 찾아 줌). 스크립트 하나다.

### 2단계: 가중치 학습 E2E (데이터가 수백 쌍 넘으면)
- (시장 자료 → 사장님 O 히트 카드) 쌍으로 모델을 직접 미세조정한다. 사장님 O/X와 히트/실패 쌍으로 '좋은 카드 vs 나쁜 카드' 선호 학습도 한다.
- **GPT 쪽이 현실적이다.** OpenAI는 미세조정 API를 공개하고 있다(위키에 없음 — 일반 지식). 사장님 API 키와 비용 결정이 필요하다. Claude는 데이터 엔진(수집·해부·검수·채점)을 맡는다. 사장님이 미뤄 두신 Claude·GPT 분업이 여기서 자연스럽게 나뉜다.
- 판정 모델도 같은 데이터로 배운다: 카드 → '팔릴까'(시장 라벨) + '사장님이 받을까'(정답표).

## 6. 규칙은 어떻게 되나

- **규칙집은 더 늘리지 않는다.** 사장님 새 판정은 규칙 한 줄이 아니라 **데이터 한 줄**(카드 + O/X + 사장님 말)로 들어간다.
- 🔒 하드 규칙 중 **가드레일**만 남긴다: 법적 표현·의료기기·의약품 소지, 병원 가야 하는 결핍(④-08), 임산부 섭취, 원가·용기처럼 바깥에서 정해지는 사업 조건. 나머지 경고 규칙은 '그 규칙을 만든 사장님 판정 카드'로 바꿔 데이터에 넣는다(판례 → 예시).
- 규칙집은 사람이 읽는 설명서로 남기되, 기획 모델의 입력에서 주연이 아니다.

## 7. E2E가 더 나은지 어떻게 아나 (시험)

| 시험 | 방법 | 사장님 시간 |
|---|---|---|
| 재현 시험 | 좋은 기획 4개(쏘모카·써모드·유쎄라블·GLP-1)의 '그때 시장 자료'만 주고 규칙 방식 vs E2E 방식으로 다시 기획 → 사장님 기획과 가까운 쪽 | 0 |
| A/B 라운드 | 같은 결핍 5개를 규칙 방식 5장 · E2E 방식 5장으로 → 작성 방식 가리고 사장님 판정 | 10장 |
| 시장 예측 | 새로 뜬 광고(게재 14일 이하)의 60일 생존을 예측해 봉인 → 60일 뒤 자동 채점 | 0 |
| 회귀 시험 | 지금 시험지(A·B·G·N)로 판정 모델 비교 | 0 |

E2E가 재현·A/B에서 이기면 기본 방식을 바꾼다.

## 8. 솔직한 한계

- **데이터 크기**: 테슬라는 수백만 영상, 우리는 몇 년 모아도 수천 상품이다. 처음부터 모델을 만드는 게 아니라 이미 똑똑한 모델(Claude·GPT)에 우리 데이터를 붙이는 방식이라 수천이면 의미가 있다.
- **라벨 잡음**: 오래 돈 광고 ≠ 돈 번 광고(①-04). 소재 수 증가·브랜드 검색 상승을 같이 봐서 줄인다. 진짜 정답은 출시한 제품의 매출이다 — 사장님 제품 성과가 생기면 가장 무거운 데이터로 넣는다.
- **거꾸로 쓴 기획은 추측이다**: 광고만 보고 회사의 기획 의도를 다 알 수 없다. 사장님 정답표와 검수로 보정한다.
- **시간**: 60일 라벨은 60일 걸린다. 그래서 수집을 오늘 시작하는 게 가장 중요하다.
- **토큰**: 수집·라벨(①②)은 토큰이 안 든다. 해부(③)는 값싼 모델로 돌리고, 기획 생성은 사장님이 토큰 여유가 있을 때만 한다.
