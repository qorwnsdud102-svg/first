# 자가학습 설계 — 테슬라 FSD 방식으로 DA 기획 모델 키우기

> 테슬라 FSD에 관한 설명은 위키에 없다. **(위키에 없음 — 일반 지식)**: 테슬라가 공개 발표(2019 Autonomy Day, 2021 AI Day, 2023~24 v12 발표)에서 밝힌 방식을 요약했다. 우리 쪽 숫자는 모두 이 저장소의 기록에서 왔다.

## 1. 한 줄 요약

사장님은 운전자이고 Claude·GPT는 옆에서 배우는 자율주행이다. 사장님의 판정 한 번 한 번이 '개입(핸들 잡기)'이고, 목표는 **사장님이 핸들을 잡는 횟수를 라운드마다 줄이는 것**이다.
이를 위해 세 가지를 붙인다. ① 사장님 판정을 미리 맞히는 '판정 모델' ② 메타 시장이 자동으로 정답을 다는 '시장 모델' ③ 사장님 좋은 기획을 같은 재료로 다시 만들어 보는 '재현 시험'. 사장님 시간은 두 모델이 서로 엇갈리는 카드에만 쓴다.

## 2. 지금 어디에 있나 (숫자)

| 항목 | 지금 | 뜻 |
|---|---|---|
| 기획 통과 | 1~3차 26개 중 '진행' 0 (1차 레드밤만 '괜찮은 기획') | 기획 모델이 아직 한 번도 합격작을 못 냈다 |
| 규칙 | 176개, 거의 다 사장님 첨삭에서 나온 금지 규칙 | 첨삭이 쌓일수록 '하지 마라'만 늘었다 |
| 판정 예측 (3차, 봉인) | Claude 8/10 · GPT 8/10 · 서로 본 뒤 8·7 | '전부 안 함'이라고만 찍어도 10/10이다. 합격작이 없어서 **합격을 알아보는 눈은 아직 검증된 적이 없다** |
| 좋은 기획 본보기 | 4개(쏘모카·써모드·유쎄라블·GLP-1 '지엘' 유산균) | 따라 할 '모범 운전 영상'이 너무 적다 |
| 시장 정답 | 메타 60일+ 상품 광고 33개 해부 | 팔리는 것 ≠ 사장님이 받는 것(P6223). 시장은 두 번째 선생님일 뿐이다 |

진단: 지금은 사장님이 매번 핸들을 잡고, 시스템은 '사고 난 장면'(기각)만 배운다. 합격 장면이 들어오지 않으니 금지 규칙만 늘어 과잉 엄격해진다. 회귀 시험에서 이미 한 번 확인했다(좋은 기획 11건 중 3~5건만 통과).

| **데이터 엔진** | 틀린 장면 하나를 찾으면 전 세계 차들에서 비슷한 장면을 수천 개 모아 정답을 달고, 다시 학습하고, 시험을 통과하면 배포한다. 이 바퀴를 계속 돌린다 |
| **사후 자동 라벨** | 운전 중엔 몰랐던 정답을 '나중 장면'을 보고 기계가 자동으로 단다. 사람이 일일이 정답을 달지 않아도 된다 |
| **회귀 시험** | 새 버전은 예전에 맞혔던 장면 수천 개를 다시 통과해야 배포된다 |

| **계기판** | '개입 없이 간 거리'(사람이 핸들을 잡기까지 몇 km 갔나)로 진척을 잰다 |

| 회귀 시험 | 규칙 고칠 때마다 과거 판정 다시 맞히기(A·B·G·N) | 있음 |

| v12 전환 | **규칙 위주 → 본보기 위주**: 새 기획마다 가장 비슷한 '사장님이 받은 기획'과 '기각한 기획'을 사장님 말과 함께 붙여 주고 따라 하게 함. 🔒 하드 규칙은 가드레일로만 | 없음 → 판례 검색기 신설 |
| 모범 운전 영상 | 사장님 좋은 기획 + 사장님 기획 과정(쏘모카 기획서 20단계) | 4개 + 1개 |

### 다른 점 (솔직하게)

- **Claude·GPT는 무게(가중치)를 스스로 바꾸지 못한다.** 우리 '기획 모델'은 파일이다 — 정본 규칙, 판례, 본보기, 쓰는 순서, 채점 지시문. 학습 = 이 파일들을 고치는 것이다. 그래서 FSD처럼 수백만 장면이 아니라 **수백 개 판정으로 배워야 한다** → 판정 하나하나를 최대한 아껴 쓰는 설계가 핵심이다.
- **선생님이 둘이다.** 시장은 '팔리나'를, 사장님은 '우리가 할 기획인가'(참신함·상징·우리 역량)를 가르친다. 시장만 따르면 보정팬츠가 나오고(P6223), 사장님만 따르면 판정 수가 너무 적다. 둘 다 통과해야 합격이다.
- **진짜 최종 정답은 출시 뒤 매출(ROAS)이다.** 느리고 수가 적지만, 나중에 이걸 붙이면 FSD의 '사고율'에 해당하는 지표가 생긴다.

## 5. 설계 — 모델 셋 + 데이터 엔진 한 바퀴

```
        ┌──────────── 기획 모델 (Claude · GPT 각자) ────────────┐
        │  카드 한 장짜리 후보 20개씩 → 판례 검색기로 본보기 붙임  │
        └───────────────────────┬──────────────────────────────┘
                                ▼
   판정 모델 (사장님 흉내)  ◀── 서로 채점 ──▶  시장 모델 (60일 생존 흉내)
                                ▼
     ① 둘 다 합격 상위 2~3장  +  ② 두 모델이 엇갈린 카드 2~3장
                                ▼
                  사장님 (두 장씩, 라운드당 5분 안쪽)
                                ▼
   판정 → raw 박제 → 판례·본보기 추가 → (같은 패턴 3번이면) 규칙 → 회귀 시험 → 새 버전
```

### 5-1. 기획 모델 (Claude·GPT 둘 다)
- 지금처럼 기획서 5개를 공들여 쓰는 대신, **카드 한 장짜리 후보를 20개씩** 만든다(결핍·오해→정체·상징 핵심 코어·고객이 보는 모습·옮긴 칸·1초 장면). 싸니까 많이 만든다 = 시뮬레이션.
- 카드마다 **판례 검색기**가 가장 비슷한 사장님 판정 3~5개(받은 것·기각한 것, 사장님 원문 한 줄)를 붙인다. 작성자는 "이 기각과 무엇이 다른가"를 한 줄로 답해야 한다. 규칙 176개를 다 외우게 하는 대신 가까운 본보기로 가르친다(v12 방식).
- 통과한 카드만 기획서로 키운다.

### 5-2. 판정 모델 (사장님 흉내 = 보상 모델)
- 지금의 '판정 예측 봉인'을 정식 모델로 본다. 입력은 카드, 출력은 판정·이유·확신이다.
- 재는 법: 라운드마다 봉인 → 사장님 판정 → 채점. 특히 **'진행' 예측의 적중**(합격을 알아보는 눈)을 따로 잰다. 지금은 합격 표본이 0이라 못 잰다.
- Claude 판정 모델과 GPT 판정 모델이 **엇갈리는 카드 = 우리가 모르는 곳**이다. 사장님께는 이런 카드를 먼저 올린다(능동 학습). 같은 5분으로 배우는 양이 가장 많다.

### 5-3. 시장 모델 (사후 자동 라벨 — 사장님 시간 0)
- **시장 타임캡슐**: 수집 때마다 '게재 14일 이하' 새 상품 광고를 골라, 판정 모델처럼 '60일 뒤에도 돌고 있을까'를 예측해 봉인한다. 60일 뒤 라이브러리 ID로 아직 게재 중인지 자동으로 확인한다.
  - 한국 광고 라이브러리는 꺼진 상업 광고를 보여 주지 않는다(⑩-10). 그래서 'ID가 더는 안 보이면 꺼짐'으로 채점할 수 있다(봉인 때 ID를 적어 두므로).
- 이 시험은 사장님 없이 매번 정답이 생긴다. 무엇이 팔리는지(출발점 고르기·시장성 판단)를 여기서 배운다.
- 시장 모델은 '팔리나'만 본다. 사장님 기준(참신함·흔한 효능 직설 거름 — P6223)은 판정 모델 몫이다.

### 5-4. 그림자 모드 — 사장님 기획을 몰래 따라 하기
- **재현 시험(지금 바로 가능)**: 사장님 좋은 기획 4개의 '그때 재료'(예: 2026-08 속모증 시장 — 쏙모팩·검색량·블랙헤드 히트)만 주고, 결과는 가린 채 Claude·GPT가 기획한다. 사장님 기획과 얼마나 가까운지, 무엇을 놓쳤는지 비교한다. 녹화해 둔 운전을 다시 틀어 보는 것과 같다. 사장님 시간 없이 **기획 모델의 실력**을 잰다.
- **앞으로 새 기획**: 사장님이 직접 기획을 시작하실 때 출발점만 알려 주시면, Claude·GPT가 같은 출발점으로 몰래 기획해 봉인한다. 사장님 기획이 나오면 비교해 '사장님은 했는데 우리는 안 한 단계'를 쓰는 순서에 더한다. 쏘모카 기획서에서 20단계를 뽑아 4차 순서로 쓴 것을 매번 자동으로 하는 셈이다.

### 5-5. 데이터 엔진 한 바퀴 (라운드)
1. 기획 모델이 카드 40장(Claude 20 · GPT 20)을 만든다.
2. 판정 모델(Claude·GPT)과 시장 모델이 채점한다. 결과를 봉인한다.
3. 사장님께 6장만 올린다: 둘 다 합격 상위 3장 + 두 판정 모델이 엇갈린 3장. 두 장씩, 작성자는 가린다.
4. 판정을 raw에 박제하고 판례에 넣는다. 같은 패턴이 3번 쌓이면 규칙으로 올리고, 회귀 시험을 통과하면 새 버전이 된다.
5. 계기판을 갱신한다.

## 6. 계기판 — '개입 없이 간 거리'

| 지표 | 무엇 | 지금 | 방향 |
|---|---|---|---|
| 기획 통과율 | 사장님이 본 카드 중 조건부 이상 | 0/26 | ↑ |
| 사장님 시간 | 라운드당 판정에 쓴 시간·장수 | 10장 | ↓ (6장 → 3장) |
| 합격 알아보는 눈 | 판정 모델이 '진행·조건부'라 한 카드 중 실제 조건부 이상 | 측정 불가(합격 0) | ↑ |
| 기각 알아보는 눈 | 판정 모델이 '기각·보류'라 한 카드 중 실제 기각·보류 | 3차 8/10 | 유지 |
| 시장 눈 | 타임캡슐 60일 생존 예측 적중 | 아직 없음 | ↑ |
| 재현 점수 | 좋은 기획 4개를 재료만 보고 얼마나 가깝게 다시 만드나 | 아직 없음 | ↑ |

### 자율 단계 (자동차 자율주행 단계처럼)

| 단계 | 사장님 역할 | 올라가는 조건 (제안) |
|---|---|---|
| L1 (지금) | 모든 기획을 판정·첨삭 | — |
| L2 | 거른 카드 6장만 판정 | 판정 모델 '진행' 적중 60% 이상 2라운드 연속 + 기획 통과율 20% 이상 |
| L3 | 주 1~2장 최종 확인 + 무작위 1장 점검 | '진행' 적중 80% 이상 + 통과율 30% 이상 + 재현 점수 기준 통과 |
| L4 | 출시·전략만. 출시 제품 매출이 학습으로 돌아옴 | 출시 기획 중 손익 맞은 비율로 정함 |

**솔직한 예상**: 라운드마다 사장님 판정이 6~10개 생긴다. L2까지 판정 30~50개, 3~5라운드는 걸릴 것으로 본다. 판정 수가 곧 학습 데이터라 이보다 빨라지기 어렵다. 그래서 사장님 판정 한 번의 가치를 최대로 쓰는 능동 학습(5-2)과, 사장님 시간이 들지 않는 시장 타임캡슐·재현 시험(5-3·5-4)이 중요하다.

## 7. Claude와 GPT의 역할

- **둘 다 기획한다(운전자 둘).** 같은 모델끼리는 같은 맹점을 가진다(3차 N01 '찌릿한 샷 = 울쎄라'를 예측 6개가 모두 조건부로 봤다). 다른 회사 모델 둘이 독립으로 만들고 채점해야 맹점이 드러난다.
- **서로의 거름망이 된다.** Claude 카드는 GPT 판정 모델이, GPT 카드는 Claude 판정 모델이 먼저 친다. 엇갈리면 사장님께 간다.
- **계기판을 모델별로 따로 잰다.** 기획 통과율·판정 적중·수집 품질을 Claude·GPT 따로 쌓아, 몇 라운드 뒤 분업을 숫자로 정한다(사장님이 미뤄 두신 분업 결정의 근거).
