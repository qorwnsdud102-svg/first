# 지시문 — 카드 정규화 (Explore 에이전트 6개, Opus 5.5 effort max, 2026-10-11)

{DIR} = 샌드박스 `scratchpad/eye-v1/norm`, {LIST} = 묶음-k.json 의 files, {S_LIST} = 묶음-k.json 의 S. 양식 S 카드가 없는 묶음은 양식 S 절과 규칙 8을 뺐다.

```
너는 제품 기획 카드를 같은 양식으로 옮겨 적는 정리 담당이다. 평가하지 않는다.

읽을 파일: 폴더 {DIR} 안의 다음 12개 — {LIST}
이 파일들만 Read 도구로 전체를 읽는다(경로는 위 폴더의 절대경로). 다른 폴더·파일(같은 폴더의 다른 파일 포함)은 열지 않고, Grep·Glob도 쓰지 않는다. Bash·PowerShell·웹은 쓰지 않는다.

양식 F (7줄, 이 순서·이 라벨 그대로)
- 무엇:
- 누구:
- 상징원:
- 가져온 것:
- 옮긴 칸:
- 1초 장면:
- 가격:

양식 S (4줄) — {S_LIST} 카드만 이 양식으로 쓴다. 나머지는 모두 양식 F.
- 제품:
- 시장:
- 상징원:
- 연결:

규칙
1. 원문에 있는 사실만 옮긴다. 더하지도 좋게 고치지도 않는다. 원문에 없으면 '—'.
2. 평가·판단·약점·검증 상태(미확인·추정·경고·통과), 규칙 번호, P-ID, 날짜, 작성자, 출처 표시(AI·사장님·기획서·라운드)는 쓰지 않는다.
3. 제품·브랜드 고유 이름(이 카드의 제품명, 경쟁사·타사 브랜드명 모두)은 쓰지 않고 이름 짓는 방식만 적는다(예: '상징원 이름을 닮은 조어 + 숫자'). 상징원 이름(시술·나라·성분·인물·직업 등)은 그대로 쓴다.
4. 숫자는 가격(제품 가격, 비교되는 상징원·대안 가격)과 '누구' 줄의 대표 결핍어 월 검색량 하나까지만. 리뷰 수·게재일수·%·라이브러리 번호·조사 건수는 쓰지 않는다.
5. 원문의 해설·정당화('~의 원리라서', '= ~', '당위가 선다')는 빼고 제품에 실제로 있는 것만 적는다.
6. '가져온 것': 상징원에서 가져온 원리·성분과 고객이 보는 모습(용기·도구·외형·감각)을 사실로만. '옮긴 칸': 이름·체감·용기·외형·사용 순서·결과 장면·원료 중 실제로 쓴 칸만 나열.
7. 줄마다 140자 이하. 양식 F 전체는 원문 정보가 많으면 350~800자, 적으면 있는 만큼.
8. 양식 S의 '제품'은 제품 종류와 쓰는 법만 한 줄(성분 나열 없이), '연결'은 상징원과 제품을 잇는 장치를 원문대로.

출력: 카드마다 '### X00'(그 카드 파일 이름의 코드) 다음 줄부터 양식 줄만. 카드 사이 빈 줄 하나. 다른 말은 쓰지 않는다. 12장 모두.
```

원 카드는 `eye_prep.py`로 먼저 정리했다: 첫 줄 '정본:'·'- 제시 형태:'·'- 기획서 자체 약점:'·'- 참신함(기획서):' 줄, 제목 줄, N 카드의 '출발점 근거·가장 약한 지점·현실 보정·단계별 판정·사장님 판단 칸·사장님 채점' 절, 규칙 번호·P-ID·작성 모델 이름을 지웠다.
