| 상징원 | 핵심 코어 한 줄 |
|---|---|
| 눈밑지방재배치 | 원리가 핵심: 불룩한 지방을 빼지 않고 꺼진 고랑으로 '옮겨' 그늘 경계를 지운다. 볼록한 곳은 눌러 넣고 고랑은 채워서, 꺼지거나 울퉁불퉁하지 않은 매끈한 눈밑으로 보여야 한다 |
| 다이어트 한약 | 작동과 그 체감이 핵심: 먹기만 해도 몸이 확 깨고 데워지며 입맛이 끊겨 살이 빨리 빠진다는 느낌. '내 체질에 맞춘 처방'이라는 틀은 살리고, 마황 때문에 생기는 두근거림·불면·간 부담은 뺀다 |
| 브이빔 | 원리: 붉은기(늘어난 혈관)만 골라 겨냥해 가라앉힌다. 그냥 진정이 아니라 '붉은 부위 전용'이어야 하고, 쌓아 쓸수록 붉은기와 열감이 빠지는 게 눈에 보여야 한다 |
| 아쿠아필 | 작동: 물(용액)로 모공 속에 쌓인 피지·각질을 씻어 빼내는 '정기 피부 스케일링'. 아프지 않게 물로 씻어내고, 모공이 비워지는 게 눈에 보여야 한다 |
| 스컬트라 | 원리+보이는 모습: 주입한 물질로 바로 채우는 게 아니라 '내 콜라겐이 서서히 차올라' 꺼진 볼·관자가 몇 주~몇 달에 걸쳐 필러 티 없이 채워지는 시간차 볼륨 |
| 써마지 | 작동+느낌: 고주파 '열'로 피부 속을 데워 조이는 탄력. 닿는 순간 뜨끈하게 조여 오고, 그 뒤 결·모공이 매끈하고 탱탱해지는 것 |
| 염증주사 | [작동+보이는 모습] 짤 수 없게 붉고 볼록한 여드름 '한 점'에 바늘처럼 속까지 바로 넣어, 다음날 아침 볼록함이 '들어가' 보이게 하는 것. 스테로이드 성분과 통증은 코어가 아니고, 함몰·자국은 빼야 할 그림자다 |
| 모발이식 | [작동+보이는 모습] 빈 M자·정수리에 '한 모씩 심어 자리 잡게(생착)' 해서 헤어라인이 다시 서는 모습을, 채운 양을 '○○모' 숫자로 보여 주는 것. 뒤통수 모낭을 옮기는 원리, 통증·절개·수백만 원은 코어가 아니다 |
| 울쎄라 | 핵심은 고객이 보는 모습, 곧 턱살·이중턱이 바로 촥 당겨 붙는 윤곽이다. 이것을 '깊은 층에 샷으로 점점이 쏘고 600샷처럼 세는' 방식으로 보여 줘야 울쎄라로 읽힌다(번개 통증·붓기·볼패임은 가져오지 않음). |
| 신경차단술 | 핵심은 작동 방식과 느낌이다. 아픈 신경 지점을 정확히 짚어 직접 넣고, '찌릿' 닿는 순간 통증이 바로 꺼지는 '차단'을 옮긴다. 극심한 통증·스테로이드는 빼고 '정확한 지점 → 찌릿 → 꺼짐'만 가져온다. |
