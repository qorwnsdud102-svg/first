# 해부를 더 잘하는 모델에서, 새 기획을 더 잘하는 모델로

2026-10-14 · GPT 독립 제안. Claude의 `학습-방식-v2.md`와 `자가학습-설계-요약.md`를 읽기 전에 작성했다. 아래 횟수·예산·성공선은 GPT의 실험 제안이며 확정 판례가 아니다. 이 문서는 저장 후 동결한다.

**추천: 정답지를 더 모으는 양을 줄이고, 피드백 하나로 선택 하나를 바꾼 뒤 새로운 결핍에서도 통하는지 시험하자. 학습 단위는 긴 규칙이 아니라 ‘틀린 선택 → 바꾼 선택 → 적용되는 조건’ 한 묶음이다.**

## 1. 지금 안 느는 이유 — 가설 세 가지

1. **훈련한 능력과 원하는 능력이 다르다.** 해부 점수는 6.1→7.75→6.7→9.0, GPT 새 기획은 4.1→4.1→3.1이다. 이미 있는 정답을 설명하는 능력이 낯선 결핍에서 새 짝을 만드는 능력으로 옮겨갔다는 증거가 없다. 다만 회차별 난도·선발자가 달라 점수 하락의 원인을 학습법 하나로 단정할 수는 없다. Claude 1회차 7.7도 같은 문제를 동시에 푼 모델 비교 결과가 아니다.
2. **회고가 ‘다음엔 조심’에서 끝난다.** 반복표의 가치 약함 33건, 구현 핵심 누락 23건, 익숙한 조합 19건은 여러 회차에 걸친 AI 분류다. 이미 좋은 회고·본보기가 있지만, 다음 카드에서 어떤 선택을 실제로 바꿨는지 통과 증거가 없다. 원료형·제품형·시술형 상징의 예외를 지우고 모든 안에 같은 금지문을 적용하면 후킹도 사라진다.
3. **못 믿을 채점기가 후보를 솎고 있다.** 눈 v6 오차 3.0은 전부 3점이라고 찍는 오차 2.1보다 크다. 예측 6.2, 실제 3.1인 채점기로 ‘30개 중 좋은 10개’를 고르면 생성 문제와 선발 문제를 구별할 수 없다. 당분간 AI 예상 점수는 선발 기준에서 빼고, 관찰 가능한 결함과 비교 근거만 쓰자.

## 2. 피드백 한 건을 다음 행동으로 바꾸는 법

기존 `경험/통합원장.json`을 원본 색인으로 사용한다. 새 장문의 규칙집은 만들지 않는다. 원문은 그대로 두고 별도 `학습실험/경험카드.jsonl`에 판정 ID당 한 건만 연결한다.

| 저장 칸 | 적을 내용 |
|---|---|
| 이전 선택 | 제출 전에 남긴 선택과 짧은 이유. 기록이 없으면 ‘당시 이유 미기록’; 과거 사고를 지어내지 않는다. |
| 대표 판정 | 원문 위치·점수·핵심 문장. 모델의 해석과 분리한다. |
| 바꿀 선택 1개 | 결핍 / 상징 / 몸 구현 / 살 이유 중 가장 먼저 잘못 고른 것 하나. |
| 적용 조건·예외 | 어떤 타겟·부위·상징 역할일 때 적용되는가. 알려진 좋은 예와 충돌하는가. |
| 다음 시험·결과 | 새 카드 ID, 실제 바뀐 부분, 대표 판정. 아직 미판정이면 ‘학습 효과 미확인’. |

예: P6426의 거북목×치아교정 실패에서 ‘다른 분야 상징 금지’를 배우면 오답이다. **방향을 바꾼다는 추상적 공통점 대신, 타겟이 알아보는 교정기 모양까지 제품에 남는 조합을 고르는 것**이 수정이다. 대표가 준 내성발톱 대안을 복사하면 연습에는 쓸 수 있지만 신규 기획 성과로 세지 않는다.

새 기획에는 결핍이 비슷한 성공·실패 각 1건, 구현 방식이 비슷한 성공·실패 각 1건만 가져온다. 최대 4건·본문 6천 토큰. 못 찾은 칸은 비워 두고 억지 사례로 채우지 않는다. 원물 상징에 시술의 작동을 요구하는 식의 역할 혼동도 여기서 막는다. **실제 선택을 바꾼 근거 1개와 예외 1개**를 짧게 남긴 뒤, 외부 판정용 카드는 기존대로 700~850자로 쓴다. 설명이 길어야 통과하는 안은 근거를 더 붙여 구제하지 않는다.

## 3. 대표 없이 하는 연습과 경험 누적

밤마다 새 해부 여러 장 대신 **고쳐쓰기 2건 + 다른 결핍에 옮기기 2건**만 한다. 고쳐쓰기는 한 요소만 바꾸고 나머지는 고정한다. 옮기기는 대표가 대안으로 준 결핍·상징 짝을 제외한다. 원문 판정과 직접 충돌하거나 기존 제품과 같은 안은 모델이 경고할 수 있지만, 모델끼리 동의했다고 대표의 합격을 대신하지 않는다.

정답지는 ‘처음 보는 광고를 설명하기’보다 **다음 설계를 예측하기**에 쓴다. 아직 안 읽은 제품의 결핍·제품 종류까지만 보고 상징 구현을 먼저 제안한 뒤 실제 제품을 연다. 이미 전체를 본 제품은 블라인드 연습이라고 부르지 않는다. 실제 히트와 다르다는 이유만으로 오답은 아니다. 고유한 구현 방법을 새로 얻었는지, 다음 독립 카드에 사용됐는지 기록한다.

밤에 새 조사하는 조건은 하나다. **이번 기획의 선택을 바꿀 수 있는 미확인 질문이 있을 때만** 기존 자료→공식 상세→광고 순으로 보강한다. 장기 광고는 생존 신호이며, 매출·효능·대표 취향의 정답이 아니다. 해부에서 얻은 방법이 이후 신규 카드 3건 안에 한 번도 쓰이지 않으면 같은 방식의 수집을 늘리지 않는다.

경험 원장은 쌓되 매번 전부 읽지 않는다. 조회 색인은 결핍·상징 역할·구현·실패 유형·판정일만 둔다. 규칙 정본과 원문은 별도로 보존한다. 이번 카드에서 회고를 인용했다는 사실보다 **이전과 다른 선택이 나왔고 대표가 그 부분을 다시 지적하지 않았는지**로 전이를 확인한다. 세션을 바꿔도 이 작은 입력 묶음으로 재개한다. 가중치 학습·파인튜닝은 지금 제안하지 않는다. 정리된 판정이 적고 목표도 변하는 단계여서 별도 학습을 해도 무엇이 개선됐는지 먼저 측정하기 어렵다.

## 4. 1주 실험 — 같은 문제에서 기존 방식과 비교

첫날, 이미 판정받은 사례는 학습 자료로 고정하고 **새 결핍·상징 조합 15개 과제**와 모델·설정·자료 접근 시점을 고정한다. 비슷한 분야 6개, 다른 분야 9개를 포함한다. 대표가 이미 고쳐 준 짝은 제외한다. A는 현재 기획 절차 그대로, B는 위 4개 대비 사례와 ‘선택 하나 수정’ 방식이다. 두 방식 모두 짧은 초안 3개에서 1개를 내며 조사·생성 예산은 같다. A도 새 짧은 문맥에서 시작해 ‘긴 옛 대화 대 짧은 새 대화’ 효과와 학습법 효과를 섞지 않는다.

2~6일: 하루 같은 과제 3쌍, 총 15쌍을 만든다. 기획자는 상대 안과 그날 대표 점수를 보지 않는다. 순서를 섞고 작성자·방법을 숨긴 한 화면에서 대표가 **각 카드 1~10점 + 더 나은 쪽 / 둘 다 별로 / 비슷함**을 고른다. 제일 걸리는 곳은 선택 1개, 이유 한 줄은 선택 사항이다. 6장×700~850자이며 **10분 타이머에서 중단**한다. 시간이 넘으면 2쌍으로 줄이고 미판정은 다음 날로 넘긴다. 15쌍을 못 채웠으면 미완료로 보고 숫자를 채워 넣지 않는다. 평가 중 피드백은 두 기획자 모두에게 보류했다가 측정 종료 후 경험 카드로 편입한다.

7일 판정: **B가 15쌍 중 10쌍 이상 우세하고, B의 7점 이상이 6/15 이상이면 채택 후보.** 동률·둘 다 별로는 승리로 세지 않는다. 대표 대안 재탕은 신규 성공에서 뺀다. 평균·7점 이상 비율·같은 오류 재발률·대표 소요시간·7점 이상 한 장당 토큰을 A/B로 함께 낸다. 합격 0개면 ‘합격당 비용 계산 불가’다. 이 숫자는 1주 시험의 목표이지 예상 성과나 통계적 입증이 아니다. 두 조건을 못 넘으면 해부 물량을 늘리지 말고 생성·선발 중 실패한 부분 하나만 다시 시험한다.

## 5. 지금 줄일 비용과 활동별 예산

11회차 3,334만·12회차 4,574만·재해부+역검증 보강 4,582만·전체 회고+눈 v6 2,186만 토큰 기록은 대부분 캐시 입력이다. **영상 자체가 그만큼 비쌌다는 뜻도, 그만큼 기획 실력이 오른다는 뜻도 아니다.** 재해부 단독 기록은 3,798만이고 역검증 조사자를 더해야 4,582만이다. 일부 회차 공유 구간도 있어 전체를 단순 합산하지 않는다.

다음은 짧은 새 문맥으로 실행할 때의 **시험용 상한**이다. 현재 긴 대화에 그대로 적용 가능한 비용 보장은 아니다. 도구의 입력·출력 제한과 원장 사후 계측으로 확인한다. 예산을 넘기기 전에 중간 결과를 저장하고 더 큰 조사를 그 회차에서 제외한다.

| 활동 | 총 토큰 상한(캐시 포함) | 새 입력+출력 상한 |
|---|---:|---:|
| 기존 경험 색인 1회 정리 | 25만 | 7.5만 |
| 피드백 1건 반영 | 1만 | 1만 |
| 초안 3개→최종 카드 1장 | 6만 | 2만 |
| 밤 연습 4건·짧은 검토 | 10만/밤 | 4만/밤 |
| 판정에 필요한 좁은 조사 | 30만/건 | 10만/건 |
| 완전 해부 1제품, 필요할 때만 | 100만 | 25만 |

이번 1주에는 카드 30장·밤 연습 최대 5회·초기 색인·측정까지 **총 300만 이내를 목표**, 선택을 바꿀 질문이 남을 때만 완전 해부 1제품을 별도 100만 한도로 둔다. 중복 장문 전달, 전체 이력 재독, 근거 없는 다인 합의, 30개를 무조건 채우는 후보 생성부터 줄인다. 사람의 요청 없이 ‘5개 광고 전체’ 같은 기존 해부 범위를 몰래 줄이지 않는다. 예산 때문에 미완료면 남은 영상·구간을 표시하며 표본 프레임을 전체 판독으로 부르지 않는다.

`실험.csv`에 과제·방식·모델·입력 묶음 해시·점수·선택·시간을, `사용량.jsonl`에 본체/에이전트·시작/끝 누적·캐시·새 입력·출력을 남긴다. 캐시·추론을 다시 더하지 않고 계정 공용 %는 보조 지표만 쓴다. 절감률은 **같은 산출 범위끼리** 비교한다. 위 예산을 실제로 지켰는지와 기획 점수가 올랐는지를 둘 다 확인해야 개선이다.
