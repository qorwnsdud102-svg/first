## 표본·정렬·신뢰 경계

P29 공개 위젯의 **포토탭 추천순30행**(reaction desc)이다. 브라우저에서 추천순 클릭 후 실제 GET을 확인했다. 상단고정10이 앞서고, 이후 반응수 순으로 이어진다. 이는 무작위표본이 아니다. 모두5점이고 작성자/구매 여부를 별도 인증하지 않았다. API source staff22/coupang5/npay3. staff라는 필드만으로 조작·가짜를 확정할 수 없지만, 독립 사용자30명이 직접 남긴 것처럼 서술해서는 안 된다.

날짜 꼬리표와 공백을 제외한 **22본문종**. 중복군은 R01/23, R03/12, R05/20, R06/14/26, R08/22, R09/15, R10/11이다. ID가 달라도 같은 효능경험을 여러 번 뒷받침한다고 세지 않는다. R06의본문2025-09-01/등록필드2026-09-01 등 날짜차이도 있다. 유사문장을 더 넓게 묶으면 독립경험 수는22보다 작을 수 있다.22는확인된독립구매자수아님.

BEST17은 별도 진열이며 추천30과14ID가 겹친다. 추가3행은 원문하단에 보존했다. 각각특가쟁임/아침안색/레이저의사추천재구매 내용이며,30분모에 덧붙이지 않았다.

## 산 이유와 타겟의 구조

1. **돈·시도 손실을 만회하려는 첫구매:** R05는레이저효과가잠깐이라‘마지막’으로광고를시도했다. R18은출산이후오랜기미·타인시선·여러시술비용을 자세히 썼다. ‘잠잘때편함’은 결핍의 원인이 아닌 대안을 지속하는 방법이다.
2. **추천이 마지막 불신을 넘김:** R07은딸추천만으로반신반의하다원장언급뒤사용. R21/R24/R27은방송다음날1회사용이므로 의사권위의구매전환은 보여도효능성공은 보여주지 않는다.
3. **첫구매와 재구매 동기가 다름:** R13은딸선물로시작했다가4개월후방송특가에4통을샀다. R03/R19는쟁여야마음편하거나특가종료때문이다. 할인·쟁임을 모든사람의최초구매이유로바꾸지 않는다.
4. **직접사용과 자녀선물을 분리:** 53/54세갱년기당사자,30대후반출산후극건성당사자,어머니에게주는자녀가존재한다. 상세의임신부인용은선택이미지이며30표본의임신부비율은 산출할수없다.
5. **효능기대와 감각만족은 다름:** 보습/속광/피부결/발림은즉시감각,기미경계·면적변화는자기주장이다. R28은기미는모른다고명시하고 R30도충분한개선미확인이다.

## 반대증거를 어떻게 반영했는가

- **현재효과미확인:** R21/R24/R27은첫1회기대평,R28은아직기미판단불가. 별점5라는이유로성공사례로세지않는다.
- **병용·원인혼합:** 바세린R01/R09/R10,누룩클렌징R28,추가보습R30. 피부결/톤/기미변화의원인을이단품으로고정할수없다.
- **체감의마찰:** 과량흡수/밀림R17,극건성당김R30. 제형이누구에게나완벽하다는광고확장을제한한다.
- **기간·결과차이:** 며칠만에싹R05와3달경계변화R18,서서히균일R29를동일효과로평균내지않는다.
- **상품정보와경험분리:** R28의84,000ppm/4%/특허설명은소개문이다. 현PDP146,500ppm을입증하거나현재성분함량으로쓰지않는다.
- **날짜/중복:** 같은본문이다른상품번호·source·날짜에반복된다. 복제이유는미확인이고가짜확정도하지않는다. 따라서‘독립30명의일치된효과’표현은사용하지않는다.
