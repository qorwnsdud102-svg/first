# 첫 화면 추가 검증

기존 모아보기는 첫 표본이 약2초라 시작 훅을 놓칠 수 있었다. 12개 영상 각각 **0.2초 프레임**을 추가 추출해 전부 판독했다. 이 검증은 시작 화면 보강이며 표본 사이의 전 프레임 판독은 아니다. 원본: `영상판독/각브랜드/첫화면-종합.jpg`와 개별 PNG.

| 브랜드·소재 | 0.2초 화면·자막 | 해석 보완 |
|---|---|---|
| 테토쿨1 | 수염 있는 남성의 면도, 안 없어지면 전 재산을 준다는 극단적 보증 | 제품 설명 전에 결과 확신·강한 보증을 놓는다. 실제 보증조건 확인 아님 |
| 테토쿨2 | 피부 속 두꺼운 털·초록 젤 CG, 철사같이 두꺼운 수염 | 문제를 눈에 보이는 구조로 만든다 |
| 테토쿨4 | 매끈해 보이는 턱·목, 놀라움과 욕설성 반응 | 끝난 결과를 먼저 제시한다 |
| 악타로스1 | 앉은 여성 옆에서 남성이 일어나며 '잠깐, 잠깐!' | 기존2초 표본의 여성 얼굴보다 앞에 급박한 행동이 있음 |
| 악타로스2 | 외국인처럼 연출된 여성 인터뷰, '먹고 다음 날' | 즉시 반응으로만 묶으면 틀림. 시작은 다음날 변화 |
| 악타로스3 | 키위와 빈 상자 모션, 약30개 농축 문구 | 핵심은 익숙한 원료 양의 시각화 |
| 악타로스4 | 모래에 새긴 상품, 여름한정·비밀링크·22,488원 | 가격·마감 훅 |
| 악타로스5 | 두 여성이 앉은 인터뷰, 한 명이 상품 듦, '그냥 변기에 앉고' | 배변 장면을 직접 보여 주기보다 말로 결과 상상 |
| NOCT1 | 슬립케어 병을 든 손, 멜라토닌이 하나도 안 들어갔다는 문구 | 성분 배제가 첫 구매 이유 |
| NOCT2 | 말하는 여성과 '수면 영…' 자막 | 화자 설명형 도입. 한 프레임만으로 역할/자격 확정 못함 |
| NOCT4 | 노트북 작업자, 뒤척임·걱정·각성·피곤함 4칸 | 증상별 성분 선택 안내 |
| NOCT5 | 침대에서 못 자는 사람의 만화, 잠이 들기만 하면 | 불면 공감형 도입 |

정적 소재 테토쿨3·5, NOCT3, K1은 원본 이미지 전체 판독으로 시작 화면까지 포함한다. 광고주의 주장·출연자 역할은 관찰된 연출이며 실제 효과·국적·보증을 확인한 사실이 아니다.
