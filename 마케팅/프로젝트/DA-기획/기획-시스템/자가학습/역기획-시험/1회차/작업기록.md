# 역기획 시험 1회차 출제

상태: in_progress. 1등급 전부를 출제하며 후킹 약함 2건은 제외. 해부·대표 원문 대조 후 문제/정답 분리. 응시·채점·커밋은 하지 않음.

출제대상 확정: 1등급 표 50행 중 후킹 약함 2행(P6461·P6462)을 제외한 48문제. 점수 없는 기존 1등급과 대표가 이유를 고친 저점수 사례는 유지. A=01~16, B=17~32, C=33~48로 별도 출처대조 중.

검수 계획: 48개 ID와 원표 대응, bridge 문자열 동일, 문제 필드 제한, 같은 문제의 브랜드/제품/상징/별칭 노출 검사, 사람 점수와 이유 원문 대조, concept 포함, 원문 미확인 구분. exam.py의 check만 실행하며 pack/answer/grade/sum은 실행하지 않는다. 기존 검사기는 부분 문자열 방식이므로 symbol_family와 띄어쓰기 제거 검사도 추가하고 마지막으로 문맥을 읽는다.

1등급에 든 이유와 해부 점수를 분리한다. 숫자 없는 기획을 임의로 7점으로 보정하지 않는다. 2등급은 추가하지 않으며 '후킹 약함' 제외 사유를 보존한다. 각 분담에서 읽은 해부·대표 원문과 한계는 검수용 근거 목록에 남긴다.

## 사용량 초과로 중단

전체 상한 3,000,000을 초과한 것을 자식 세션 계측에서 확인했다. 세 분담의 확인치만 A 1,293,887 + B 987,886 + C 1,216,842 = 3,498,615이며 여기에 부모 세션 사용량이 추가된다. 추가 조사를 중단하고 기존 조사 내용만 저장하도록 요청했다. 문제·정답을 완성/검증했다고 보고하지 않는다. 이 기록 뒤 마감 합산을 별도 남긴다.
