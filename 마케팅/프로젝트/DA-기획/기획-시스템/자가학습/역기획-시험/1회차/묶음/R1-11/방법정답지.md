# 방법 정답지 — 팔린 기획은 상징원을 제품 어디에 박았나

> 사장님: "급상승, 예전에 검색어 높았던 브랜드 -> 기획이 성공했다 가정해서 참고로 쓰기로했잖아"(2026-10-12, P6272). 급상승 브랜드와 지난 24개월 히트는 원가·광고비 대비 이익이 시장에서 검증된 정답지다(정본 ⑩-09, P6240·P6242~P6244). 우리는 그중 **상품의 컨셉·디자인·기획**을 참고한다.

**쓰는 법**
- 기획자는 출발점에서 후보를 비교하기 전에 이 장을 읽는다.
- 근거로 인용하는 것은 1등급(사장님이 이유를 확인한 것)뿐이다.
- 2등급(Claude 해부, 사장님 미확인)은 '이런 길도 있다'는 참고로만 쓴다.
- 같은 상징원·같은 이름을 그대로 다시 쓰지 않는다. 참신함은 ⑤ 매대 비율로 거른다.

**갱신**: 히트 해부가 사장님 감독을 받을 때마다 1등급을 늘린다. 카드·점수는 `원장.md`에, 해부 방법은 `README.md`에 있다.

## 한눈에 — 팔린 기획의 열여덟 길 (1등급에서 뽑음)

1. **상징원을 이름·숫자·용기에 한꺼번에 박는다.** 광고 문구가 아니라 제품을 만들 때부터 박았다.
   - 스피옥실: 스피큘을 이름 '스피'와 함량 400·600에, 리들샷 같은 은색 반짝 용기에 박았다.
   - 유쎄라블: 울쎄라와 비슷한 이름에 미세열감을 더했다.
   - 써모드: 써마지와 비슷한 소리에 시술 샷 수 '900샷', 피부과 바이알을 썼다.
   - 파라코펜: 노란 약통으로 의약품 느낌을 냈다.
   - 벨택 페니톡스(10점): 보톡스 → 이름 '페니톡스'와 '바르는 보톡스' 원료 아세틸헥사펩타이드-8(P6418).
   - 퓨리븐 퍼플 가루치약(7점): 화장품의 보색(보라가 노랑을 지운다) → 이름 '퍼플'·보라 가루·노랑/보라 겹친 원 — "보색 컨셉 좋네, 상세 보니까 미백 잘될것같음 가치가 느껴져"(P6460).
   - 닥터레이디 리쥬톡스(7점): 리쥬란 + 보톡스 = '리쥬톡스', 유명한 '전남친 토스트' 썰을 따라 '전남친 청결제' — "인상적임, 기억에 남네". 다만 제품 기획 자체의 후킹은 약하다(P6461).
2. **상징원이 낫게 하는 방식이 쓰는 순간 느껴진다.**
   - 비렌느·디크솔: 냉동치료 → 바르면 차갑고 얼어서 떨어진다. 직관적이고, 무의식에 걸리는 것이 없다.
   - 유쎄라블: 울쎄라의 열 → 미세열감.
   - 토르홉: 사우나 → 온열.
   - 이옴(7점): 붙였다 떼면 피지가 묻어나는 마스크 — '피지가 여드름 원인'은 다 아니까 흡착되는 순간 여드름도 사라질 것 같다. 뗀 시트에 피지가 우수수 붙거나 노랗게 물든 장면이 BNA다(P6282).
   - 비오티아에스(7점): 흔들어 뿌리면 두피에서 탄산 버블이 인다 — "논리적으론 별거없어보이는데 시각적인 임팩트가 있다보니 뭔가 있어보여 가치 느껴지는 기분"(P6404).
   - 웰247 페이스튠핏(8점): 경락 → 피부가 헤드에 빨려 붙어 위로 끌리는 장면(P6417).
3. **원료가 상징이면 원료가 보이게 한다.**
   - 씨스터앤: EGF·NMN·스피큘. 상세페이지가 EGF를 매우 강조한다.
   - 우리 무릎 '바르는 콘드로이친'(7점): 가루를 따로 두었다 섞어 '잔뜩 들었구나'가 보이게 했다.
   - 메디온(8점): 논문의 40:1 황금비율을 박스 정면 숫자(4,000mg:100mg)로 박았다(P6284).
   - 누룩밤(7점): 누룩(발효 원료)과 수면팩(바르고 자는 형태)이 메인 후킹이다. '매일 가능한 사용법'은 후킹이 아니다(P6465).
4. **유행하는 대안의 반대편에 선다.**
   - 사마킬: 쥐젖·사마귀에 냉동치료가 유행하자 '냉동치료 소용없다, 율무가 최고다'로 갔다.
   - 아이럭스뷰(7점): 공기압 안대가 많자 '공기압은 눈을 누른다, EMS 온열은 안 누른다'로 갔다(P6402).
5. **사람들이 아는 약·식단 이름을 다른 제형의 이름·원료로 판다.**
   - 지엘 GLP-1 유산균: 비만 약 GLP-1 → 이름 '지엘'.
   - 바르는 올레놀샷: 먹는 올레샷 → 바르는 주름앰플.
   - 둘 다 같은 방식이 많아져 지금은 참신함이 소진됐다.
   - 비오티아에스(7점): 영양제로 아는 비오틴 → 이름 '비오티아'. 사장님: "비오틴 상징재 쓴거 넌 몰랐지?"(P6404).
6. **그 타겟이 몸으로 믿는 권위를 고른다.**
   - 파라코펜: 다이어트에 서양 모델의 관리비법과 '미국 대란'을 썼다.
   - 비전넥신: 눈이 크고 맑기로 유명한 김민교를 모델로(모델의 유명한 특징 = 원하는 결과), 외국인 후기로 외국 상징, 한의사·의사 공동 개발(P6458).
7. **나라 세계관을 이름·라벨·원료에 한꺼번에 입힌다.**
   - 포뮬라인(8점): 일본 약국 먹는 미백약 → 판매명 '13호', 그 조합·함량 '그대로'. 단 서울대·밝아지는 GIF 같은 자극은 과대광고 위험이 크고 사장님도 납득하지 않았다 — 일본 컨셉만 참고한다(P6283).
   - 아시모토(6점): 특별한 원료가 아니라 일본 컨셉이 후킹했다 — 제품명, 상세 곳곳의 일본어, 일본 원료(P6281).
   - 쏘모카(사장님 기획): 핀란드 세계관을 외형·상세·이름에.
   - 에끌무아(7점): 프랑스 느낌을 내려고 이름을 '에끌무아'로. 탈모 초기·탈모가 불안한 사람이 좋은 향과 함께 쓰는 제품(P6468).
8. **결핍이 생기는 원인을 보여 주고, 제품이 그 원인을 막는다.**
   - 프렉탈 링클 필로우(9점): 목주름이 생기는 이유(자는 자세의 꺾임)를 C커브 높이·고개 돌림을 막는 날개가 막는다 — "주름 생기는 이유 진짜 당위성 느껴져"(P6285).
   - 헥사큐 아쿠아메딘(7점): 입냄새도 입이 말라서 → 진흙(마름)과 물속(촉촉) 사진을 대비, 호주 선진국 컨셉. 참치 회 2개 중 하나에만 가루를 뿌려 시간이 지난 뒤 어느 쪽이 더 마르는지 보여 준다 — "눈에 수분에 빠지고 안빠지는게 확실히 보이잖아"(P6459).

9. **다른 분야의 상위 상징을 낫게 하는 방식의 결로 가져온다.**
   - 트라센 케라소프트(9점): 피부 시술 프락셀(흉터·모공을 찔러 새살을 채움) → 반쯤 부서진 무좀 발톱을 복구. 스피큘 원료와 바이알로 당위를 만들었다 — "직접적인 상징재 말고 이렇게 다른 분야에서 상징재 가져올수있다면 기획할수있는게 무궁무진"(P6354·P6361).
   - 벨택 페니톡스(10점): 다한증·주름에 쓰던 보톡스를 남성 크기 크림으로 — "발기크림에 쓸생각은 못해봤네"(P6418).
10. **기존 제품과 딱 하나만 다르게 — 나라 상징 하나.**
   - 리노베라(8점): 흔한 피톤치드에 유럽(프랑스) 상징 하나를 이름·허브 배합·향·외형에 입혔다(P6359).
11. **누구나 귀찮아하는 단계를 없앤다 — 단 편의만으론 약하다(④-65).**
   - 그루밍랩(7점): 새치 염색의 1제·2제 섞기를 이중 토출 용기로 없앴다. 아비튜드(7점): 귀찮아서 안 하는 면도날 세척을 자동으로 했다(P6355·P6356).

12. **상위 권위(박사·나라·장인·기관)를 착용 위치·내부 구조·쓰는 감각에 같은 방향으로 붙인다.**
   - 슬리피솔플러스(9점): KAIST 박사의 '뇌를 쉬게 한다' → 양쪽 관자놀이 밴드, 어지러운 파형이 가지런해지는 그림, 하루 2번 30분 '1230'.
   - 포렌 경추베개(8점): 독일 125년 장인 → 머리는 부드럽고(SOFT) 목은 단단한(FIRM) 두 밀도, 7cm.
   - 고유지 소금치약(8점): 청와대 납품 소금·1,000℃ → 입에 남는 알갱이·짠맛·적은 거품이 원료 이야기를 입안에서 확인시킨다(P6370).
13. **병원 장비·시술·처방을 우리가 팔 수 있는 제품으로 당위 있게 옮긴다.**
   - 메라블 실프팅 4D(7점): 실리프팅 → 사방에 가시가 난 회오리 스피큘 원료로 '실처럼 잡아 올린다' — "실리프팅이란 상징재를 회오리 스피큘이란 원료로 당위성있게 가져오려는 시도가 우리가 배울점"(P6366·P6374).
   - 하엔 딥트릭스(7점): 병원 발톱 레이저 → 발톱에 끼우는 두 빛 클립 7분 — "병원 레이저를 우리가 팔수있는 제품으로 당위성 있게 가져온거야"(P6367).
   - 유어벳(8점): 동물병원 처방·스케일링 → 매일 뿌리는 스프레이. 타겟의 근본 걱정은 마취 위험보다 귀찮음·비쌈(P6369).
   - 뉴로덴트(7점): 치과 스케일링·미국·FDA → 구강세정기. 해부는 맞았지만 "전형적인 구강세정기, 참신한 기획은 없네" — 서브 상징만으로는 참신하지 않다(P6368).
   - 케라솔(7점): 두피 성장인자 주사 → 쓰던 샴푸에 펌핑해 더하는 성장인자 젤. 노벨상 받은 원료라는 상징도 함께(P6400).
   - 산타시트 메디온애니(7점): 병원 PBM 광선 장비 → 평소 앉는 좌판, '물 없는 좌욕'(P6405).
14. **경쟁 제품의 구매 기준을 바꾼다.**
   - 뉴티락(8점): 유산균에 실망한 사람에게 '균 수보다 장 끝까지 살아남는 균주'(P6370).
15. **대표 해결책의 유명한 단점을 해결한 '차세대 X'로 자리 잡는다.** 먼저 그 결핍의 대표 해결책과 단점을 알아야 보인다(P6445).
   - K바이오코드 드림포뮬러: 멜라토닌은 잠들기를 돕지만 중간에 깨는 건 어떻게 하나 → 베리토닌으로 해결 = '차세대 멜라토닌'. 일반의약품 같은 단상자, 미국에서 건너왔다는 상징, KAIST. 상단 후기도 '자주 깨는 게 줄었다'(P6445).
   - 악타로스-X(7점): 키위 = 소화에 좋다는 상징재 + 다른 변비 대안(푸룬·차전자피)의 단점을 해소한 제품, 대장으로 직행한다는 trimelt 기술 GIF가 '기술력 좋아 보인다'(P6443).
16. **메인 결핍(대표 부작용·원인)을 잡고, 그걸 낫게 할 것 같은 상징재를 여러 개 겹친다.**
   - 테토쿨 쉐이빙젤: 면도의 대표 부작용인 자극·피부 손상을 메인 결핍으로 → 병풀·진정·시카·차가운 느낌(멘톨 쿨링). 광고의 레이저 제모 상징은 당위 없이 썼다(P6442).
   - OLUP 블루 안티 에이 리프레셔: 안티에이징 → 노화를 일으키는 염증·산화를 없앤다 → 항염·항산화 성분·NMN, 여기에 NASA·할리우드·프랑스 상징(P6446).
17. **의심을 막는 증거를 겹친다.**
   - NOCT 슬립케어: 피부과·신세계 같은 네임드 백화점 입점, 입면 시간 감소·수면 시간 증가 시험 성적서 — "의심, 반박할수가없네"(P6444).
18. **처음 보는 제형·사용 방법 자체를 이름과 상세 맨 위에 박는다.**
   - 릴리이브 그로우턴(7점): 브러쉬로 바르는 앰플 — "1~2년전 처음 나왔을땐 이런 모양으로 사용하는 탈모제품이 없었음"(P6467).
   - 노일리: 슬라임처럼 찐득하게 늘어나는 제형이 핵심 → 이름도 '슬라임', 상세 맨 위에 찐득한 제형 GIF. 욕구는 사춘기 블랙헤드·여드름을 순하게 없애기(P6466).
   - 인버브(7점): 파스를 손가락 전용 모양으로 — "약간 참신?"(P6469).
**USP가 아닌 것**(P6259·P6260): 연예인, 올리브영 1등, 남편 얼굴 전후(BNA), 볼에 점 찍기, '시술 안 받아도 된다', 묶음 세일. 누구나 지금부터 할 수 있는 광고 집행이다.
