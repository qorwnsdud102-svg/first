# 원문 범위 — 독립 자료 점검

## 범위와 집계

사용자의 제한된 분담 지시에 따라 `히트본보기.json`과 이 파일만 작성한다. 실제 개별기획·공동기획·드릴 카드 회고는 다른 담당 범위다. 여기에는 일반 피드백의 설계 행동, 근거 위치, 누락·평가 구분만 남긴다. 정본·raw·P-ID 원장·작업기록은 수정하지 않으며 웹·브리지·커밋·다른 에이전트 호출은 하지 않는다.

- 원문 인벤토리: **108개**. 2026-10-10 27개, 10-11 52개, 10-12 12개, 10-13 17개. 요청한 판정·답·구술 106개와 같은 기간 승인·지시 2개(F098·F099)를 빠짐 확인용으로 포함했다.
- 주 분류: **일반피드백읽음 67개 / 카드담당대상 25개 / 운영지시로별도 16개**. 혼합 파일은 카드담당대상을 주 분류로 두고 읽은 일반 구간을 적었다. 분류는 파일 단위이므로 한 파일의 모든 문장을 같은 종류로 취급한다는 뜻이 아니다.
- 내용 열람: **전문 90개 / 지정 구간 11개 / 제목·출처·머리글만 7개**. 전문을 읽은 카드 파일도 개별 카드 회고는 재작성하지 않았다. 메타데이터 조회·해시 계산·원장 연결 조회를 본문 열람으로 세지 않았다.
- 방법정답지: **1등급 표 40행(78–117행) 전부 구조화**. `holdout_v6=false` 38개, `true` 2개(웰247·벨택, 원문 H10-01·H10-02). JSON ID `HIT-01`~`HIT-40`은 표 순번이며 원래 회차 카드 ID가 아니다.
- `lessons`는 자료에 기록된 제품 설계에서 다음 기획이 가져갈 행동을 요약한 것이다. 사장님의 내적 사고·미기록 결정·효능을 복원하거나 추정한 내용이 아니다.

## 통합할 때 반드시 분리할 것

1. **히트 해부 점수와 제품기획 점수는 별개다.** 히트 표 H2·H4~H10의 점수는 제출된 해부의 적중·설명에 대한 평가다. R·G·D 등 실제 기획/드릴 평가는 카드 담당 결과와 구분한다. 예: 스피옥실 H2-4는 해부 5점(P6259)이지만 사장님이 메인 상징을 보정해 준 설명은 방법정답지 1등급이다. 씨스터앤은 점수가 비어 있어도 이유 보정(P6260)이 있다. 따라서 1등급을 “제품기획 7점 이상” 또는 “해부점수 7점 이상”으로 환산하면 안 된다. 근거: [F088:3–18](<C:/claude/LLM-WIKI/마케팅/raw/본인/2026-10-12_본인판정_기획1회차-점수-이유_히트해부2회차-이유_매대보조지표.md:3>).
2. **점수만 있는 9개는 이유를 생성하지 않는다.** 넥필·바로랩·슬리피솔플러스·포렌·고유지·뉴티락·아이럭스뷰·산타시트·웰247. P6370은 H8 네 제품을 함께 가리키는 하나의 P-ID이며 네 개의 새 번호로 쪼개지 않았다. JSON의 상징·구현은 방법정답지 해부 내용, owner_reason의 점수는 사장님 판정 사실이다.
3. **승인·관찰·판매 검증을 나눈다.** 쏘모카는 기획 만족·승인(P6185·P6186)이며 이 자료만으로 판매 성공을 확인하지 않는다. 써모드의 정답 편입(P6187)도 매출 수치 증거가 아니다. P6240·P6272의 “기획이 성공했을 것이라는 가정”은 학습 대상 선정 방침이며 이번 점검에서 손익을 검증한 사실이 아니다.
4. **의료·원료 문구는 상징 관찰이다.** 냉동·성장인자·보톡스·GLP-1·주사·FDA·노벨상·기관·논문 비율과 효과 수치는 제품/광고가 내세운 의미와 소비자 인상을 기록한다. 성분 함유, 치료 효과, 법적 분류·권리·인증을 독립 검증한 기록으로 쓰지 않는다. 벨택 후기의 신체 변화 수치도 동일하다.
5. **H10 holdout은 38개와 섞지 않는다.** H10 두 장의 문서 근거와 lessons는 요청대로 JSON에 보존하되 v6 학습·조정용 본보기에는 합치지 않는다. H10 점수나 그 점수 이후의 보정으로 시험 성과를 다시 계산하지 않는다. 이 점검에서는 H10 원문을 자료 확인 목적으로 읽었다.
6. **“지금”은 기록 시점이다.** 참신함 필드는 방법정답지 표기를 보존했으며 현재 매대·광고·판매 상태를 재조회한 값이 아니다. GLP-1·올레놀샷의 “소진”, 파라코펜의 “확인 필요”, 메라블의 약한 판매 근거도 그대로 유지했다.
