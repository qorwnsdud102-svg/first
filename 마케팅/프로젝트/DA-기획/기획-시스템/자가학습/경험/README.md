## 한 바퀴
1. **기획:** 두 문서를 먼저 읽는다. 카드마다 생각 흐름(결핍 고르기 → 상징 떠올리기 → 상징 고르기 → 구현 → 걸림)을 남긴다.
2. **판정:** 사장님이 점수·걸리는 곳·이유 한 줄을 준다.
3. **회고:** 같은 기획자가 자기 흐름과 코멘트를 견줘, 틀린 단계와 '다음엔 이렇게'를 적고 두 문서를 고친다.
4. **다음 기획**은 고친 문서로 시작한다.

## 정본과 다른 점
- 정본은 판정 기준(무엇이 되고 안 되나)이다. 경험 문서는 생각하는 순서(어떻게 떠올리나)와 결핍별 기억이다.
- 생각 순서는 한 쪽을 넘기지 않는다. 새 질문을 넣으면 덜 쓰인 질문을 뺀다.
