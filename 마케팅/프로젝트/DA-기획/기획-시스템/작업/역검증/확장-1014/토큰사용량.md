# 역검증 확장·학습안 제안 사용량

측정: 2026-10-14T09:08:55.776660+09:00

역검증 확장 + 도중 신규 접수한 GPT 학습방식 제안·비교. 본체 시작기준 이후 차분+이번6개 분담 세션 누적을 각1회 합산. 실패 시도 포함.

| 범위 | 총 토큰 | 캐시 입력 | 새 입력 | 출력 |
|---|---:|---:|---:|---:|
| 본체 차분 | 17,324,313 | 16,775,808 | 473,682 | 74,823 |
| 분담6개 세션(실패·복구 포함) | 23,180,530 | 21,707,776 | 1,237,012 | 235,742 |
| 합계 | 40,504,843 | 38,483,584 | 1,710,694 | 310,565 |

캐시는 입력 부분집합, 추론은 출력 부분집합. 학습방식-GPT제안/사용량.json의 부분 구간은 여기 포함되어 재합산 금지. 이전 2등급 재해부 45,822,755토큰은 별도 회차이므로 불포함. 영상 단독 비용·제품 하나당 신규 분석 비용이 아니다. 기록 시점 이후 마감 답변과 브리지 전달의 소량은 미포함. 구독 사용량을 API 청구액으로 바꾸지 않는다.

총 토큰은 문맥을 반복 읽은 캐시 입력을 포함한다. 따라서 산출물 글자 수보다 크다. 실패한 분담을 2회 재개하고 새 분담으로 복구한 비용도 숨기지 않고 포함했다. 캐시가 항상 무료라는 뜻은 아니다.

계정 주간 시작 관찰은 25%. 마감 관찰은 별도 계정 스냅샷 참조. 같은 계정을 쓰는 다른 작업이 있어 비율 차이를 이 작업 고유 비용으로 단정하지 않는다. 5시간창은 제공되지 않았다.

검산: 입력+출력=총토큰. 캐시 입력과 추론 출력을 다시 더하지 않았다. 각 세션 종료 또는 최신 기록의 정확한 시각·누적값은 JSON에 있다.
