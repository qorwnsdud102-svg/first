# X12 흡착바이트 — 현행 규칙과의 충돌

89칸 개별 판정. H는 ④-22·④-58·④-59 세 칸이며 **제품 한 건**이다. 현재 정확 P218 제목에 ‘지방흡입캔디’가 있고, 본문은 식후 원료 포집·흡수 차단·배출로 설명한다. 현행 규칙은 결과만 다른 수단으로 흉내 내거나 수술 상징을 식품으로 옮기는 구조를 배제한다. 따라서 표본 82일 광고와 규칙 문언이 충돌하는 후보로 남긴다.

이는 규칙 오류의 확정도, 캔디의 의학적 효능 인정도 아니다. 광고의 주력 설명은 키친타올 비유이며, 지방흡입이라는 이름이 실제 판매를 얼마나 만들었는지 알 수 없다. 같은 제품의 세 규칙 충돌을 세 제품의 반례로 세지 않는다. 몸속 지방 제거 효능의 진위를 이 판정으로 결정하지 않는다.

재사용: 히트 해부 3회차에서 일부 광고 이미지·본문을 읽은 기록. 본체 추가 직접 확인: 저장된 현재 P218 HTML 제목·28,900원 옵션, 패키지 변경 안내 이미지 11, 후기/흡수 전 배출 이미지 14, 알파CD 흡착·차단 이미지 18. 현재 전체 상세나 모든 영상을 다시 완독한 것은 아니다. 그림은 원료의 기름 흡착 이미지라는 각주를 포함한다.
