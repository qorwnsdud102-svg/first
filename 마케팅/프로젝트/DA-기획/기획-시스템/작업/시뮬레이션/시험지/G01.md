# G01 — 핀란드 온열 필오프 팩
- 무엇: 바르고 20~30분 뒤 굳으면 떼어 내는 짙은 초록 필오프 팩 100g(범용 경질 자 + 스패츌러). 4단계 — 녹인다(BHA) → 연다(온감 원료, 바르면 따뜻해짐) → 뽑는다(브로멜라인 연육 효소 + 필오프) → 조이고 진정(나이아신아마이드 · 자작나무 수액). 제형은 찹쌀처럼 쫀득하게. 핀란드산 원료(베타인) 배합
- 누구에게: 소극성 속모증(가시털) 타겟 — 모공 하나에 솜털 여러 개가 뭉쳐 박혀 블랙헤드처럼 보이는 증상, 코·나비존·등. 20~30대 여성(본인 + 남자친구·남편 것까지). 시장성: 소극성 속모증 9,040 · 속모증 5,000 · 가시털 2,110 · 대안 레이저 제모(10회 100만원 안팎)와 속모증 필오프 팩 1곳(브랜드 검색 24,840, 50ml 39,900원)
- 어떻게: 코·나비존에 바르면 따뜻해지고, 굳으면 통째로 떼어 내 떼어 낸 면에 박혀 있던 털이 보인다
- 얼마에: 100g 35,900원(g당 가격이 기존 속모증 팩의 절반 이하)
- 상징원: 핀란드 스팀 사우나 — 나라(선진국 이미지)와 그 나라가 잘하는 것(사우나)
- 상징 구현: 핀란드 선진국 이미지 + 핀란드 사우나 + 스팀이 모공을 열어 털을 잘 뽑아 줄 것 같다는 원리(바르면 실제로 온열감) + 찹쌀 같은 찐득함을 보여 주는 장면(gif)으로 털을 꽉 잡아 뽑을 것 같은 느낌. 이름은 핀란드 어감의 조어, 라벨은 북유럽 목판 · 자작나무 · 핀란드어 병기, 내용물은 자작나무 잎색
- 광고 첫 화면: "블랙헤드인 줄 알았는데 사실 털이었다" — 코에 바른 초록 팩이 굳어 떼어지고, 떼어 낸 면에 박혀 있던 털이 보이는 장면
