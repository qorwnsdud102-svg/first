# H035 — 입냄새 제거 비건 치약
- 무엇: 비건 치약 100g, 구취용·잇몸용 2종. 판매 페이지 주장: 사용 후 8시간 이상 개운함 유지(임상), 입냄새 원인균 99.9% 항균, 편도결석 고민 케어. 광고 주장: 인체적용시험을 마친 특허 성분, 구강용 프리미엄 성분 7종(성분명 미확인)
- 누구에게: 양치해도 입냄새가 남고 편도결석이 신경 쓰이는 사람 — 시장성: 편도결석 월 37,050 · 입냄새제거 3,290 · 입냄새 2,380 · 구취치약 970 · 구취 760
- 어떻게: 하루 세 번 일반 치약 대신 양치
- 얼마에: 100g 1개 9,900원(정가 15,000원) · 치약 6개+칫솔 2개 옵션 추가금 +29,000원 · 치약 12개+칫솔 3개 추가금 +56,000원
- 상징원: 없음 — 제품 효능 직접 소구(약국·치과 입점, 인체적용시험, 특허 성분, 성분 7종 같은 판매처·시험 보증 문구 나열)
- 상징 구현: 해당 없음
