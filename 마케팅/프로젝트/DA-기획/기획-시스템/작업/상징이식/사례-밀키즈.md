# 사례 해부 — 밀키즈 (네덜란드 키 1위 × 유제품)

> 작성 2026-10-11 · 상징 이식 사례 6개 중 하나 (사장님 "밀키즈도 포함").
> 근거 순서: 위키·raw 먼저, 위키에 없는 제품 사실은 공식몰·블로그(2026-10-11 열람). 블로그는 제휴 링크가 있는 3자 글이라 **(3자 블로그)**로 표시한다. 내 해석은 **(해석)**으로 표시한다.

## 1. 한 줄

- **제품**: 키즈랩스 밀키즈(현재 상품명 '밀키즈 IGF complex™'). 어린이·청소년용 성장기 영양제, 코코아맛 츄어블, 1박스 30정, 판매가 33,900원(소비자가 55,000원). 운영사는 주식회사 넥스트플레이스.
- **타겟**: 키성장 타겟, 즉 또래보다 작은 아이를 둔 초등 학부모. 실측 검색량은 키성장영양제 2,390, 성장클리닉 4,730, 성장통 1,930이다(`프로젝트/DA-기획/공통-탐색/DA-무제약-기획-10분류.md:707`, 측정 도구·기간은 적혀 있지 않음). [[접촉지점]]에서 '키크는영양제'는 욕구를 가볍게 해소하고 싶은 사람이 검색하는 단어다.
- **상징원**: ① 네덜란드 = 전세계 키 1위(국가 상징, 우월형, 판정 룰 :847) ② 유제품 = 키에 대한 base 통념(키 → 우유·칼슘 ★★★, [[상징재 실측 데이터]] :195). 보조 상징으로 인물 '별(하하 와이프)'이 교안에 매칭돼 있는데, 실제로 기용했는지는 미확인이다.

## 2. 상징원 해부 — 네덜란드 키 1위

- **정체**: '네덜란드 사람은 세계에서 키가 제일 크다'는 대중 상식이다. 사장님 교안의 국가 클리셰 표에 "네덜란드 → 키큼"으로 올라 있다(raw:39).
- **타겟이 아는 이유, 원하는 이유**: 선진국이라 부럽고 따라 하고 싶은 나라다(국가 사대주의, raw:25-28). 키는 돈으로 바로 살 수 없다. 상위 해결책인 성장호르몬 주사는 연 1,000~2,000만원이고 소아과 성장클리닉에서만 맞는다(`DA-무제약-기획-10분류.md:708`). 그래서 '키 큰 나라 아이들이 먹는 것'을 따라 하고 싶은 욕구가 생긴다(해석).
- **핵심 장면 5칸** (대중이 떠올리는 장면. 위키에는 장면 묘사가 없어 일반 인식을 추정한 것이다):

| 칸 | 대중이 떠올리는 것 | 핵심 |
|---|---|---|
| 보이는 것 | 키 큰 네덜란드 사람들, 초원과 젖소, 우유·치즈 같은 낙농 이미지 (일반 인식) | |
| 느끼는 것 | 몸의 감각은 없다. 부러움, '우리 애도 저렇게' 하는 마음 (해석) | |
| 순서 | 어릴 때부터 매일 유제품을 먹으며 자란다. 시술처럼 한 번에 끝나지 않고 매일 이어지는 식습관이다 (교안 "비결은 네덜란드 유제품" raw:16) | ◎ |
| 마지막 장면 | 다 자라서 키가 큰 사람 | |
| 이름과 숫자 | "네덜란드", "전세계 키 1위" (raw:16·19) | ◎ |

→ 시술 상징원(써마지 = 열)은 '느끼는 것'이 핵심 칸이다. 국가 상징원은 **'이름·숫자'와 '비결(순서)'**이 핵심 칸이다. 그래서 체감을 재현할 필요가 없고, 비결 재료를 실제로 넣는 것이 구현의 전부가 된다(판정 룰 §2 통과유형 1, :503).

## 4. 당위성 사슬

1. **네덜란드는 선진국이다** → 따라 하고 싶은 나라라 믿음이 간다 (raw:19, 25-28)
2. **네덜란드는 전세계 키 1위다** → 키에 관해서는 세계 최고 권위다 (raw:16, 39)
3. **비결은 유제품이다** → 키 ← 우유·칼슘은 공부하지 않아도 아는 통념이다. 화살표 1개라 설명이 필요 없다 (raw:16 · 판정 룰 :808 · 실측 데이터 :195)
4. **그 나라 유제품 원료를 넣었다** → 국가와 재료가 이름표가 아니라 원료로 이어진다 (raw:17 · 판정 룰 :67·:503)
5. **그러니 이 영양제는 특별하고 키 크는 데 실제로 도움이 될 것 같다** (raw:22)
6. (2026년판에서 추가) **우유 속 성장인자 IGF-1을 '우유의 최대 500배'로 담았다** → '우유 마시면 되지'라는 반박을 농축 수치로 막는 층이다 (공식몰 메타, 해석)
7. (2026년판에서 추가) **네덜란드 본사 / 한국 본사 공식몰, 약국·성장클리닉 입점, 특허 원료** → 출신 국가와 전문 채널이 보증한다 (공식몰)

- 1~5번은 사장님 교안의 사슬이고, 6·7번은 현재 공식몰에서 확인되는 추가 층이다.
- ④-38 점검: 국가를 떼도 유제품이라는 base가 남는다. 국가 상징 단독이 아니다 (단계별 규칙 :144).
- 독일 맥주공장 효모와 비교하면 '공장·현장'이라는 구체성 층이 하나 적다 (판정 룰 :800).

## 5. 이미지 손실 방지

**값을 지킨 장치**
- 국가를 이름(겉 칸)에만 붙이지 않고 그 나라 유제품 원료(몸 칸)로 연결했다. 그래서 '네덜란드 이름만 빌렸다'는 인상이 생기지 않는다 (상징구현 초안 :162 "몸: 네덜란드 우유를 실제로 넣음. 겉: 국가").
- 비결 재료가 대중의 base 통념이라 2단계 추론이 없다. 석류·포도씨처럼 논리 퍼즐이 되지 않는다 (판정 룰 :808-818).
- 선진국 상징이라 '열등한 데서 온 것'이 될 위험이 없다 (판정 룰 :854).
- '네덜란드 본사 / 한국 본사 공식몰' 서사로 현지 브랜드라는 틀을 만들었다. 이는 국가 상징을 현지 원료·현지 판매·현지 상표로 수습하는 ④-ar 방식과 같다 (`작업/분류-④.md:49`).
- 가격대를 낮추지 않았다. 만 6세 이상은 한 달에 4박스가 필요해서, 박스당 26,900~33,900원 기준으로 월 약 10.8만~13.6만원이 든다(공식몰 FAQ·옵션에서 계산). 싸구려 우유정으로 보이지 않게 하는 장치로 읽힌다(해석).

**잃은 것, 약한 곳**
- 체감과 결과 장면이 비어 있다. 상징원의 마지막 장면(큰 키)을 제품이 바로 보여줄 수 없어서 후기 수, 품절 공지, '최소 6개월' 권장으로 메운다.
- 우유는 흔한 base다. '그냥 우유 마시면 되지'라는 반박 여지가 있고, base가 너무 흔하면 상징이 죽는다 (판정 룰 :825-830). 밀키즈는 국가 MSG와 2026년판의 'IGF-1 500배' 농축 수치로 이 반박을 막는 것으로 보인다(해석).
- 2026년판 공식몰 텍스트에서는 '키 1위'라는 문구가 확인되지 않았다. 남은 문구는 '네덜란드 성장기 영양 루틴'이다. 교안의 가장 센 문장이 공개 텍스트에서는 약해진 셈이다. 이유는 미확인이다.
- 우유칼슘 원산지가 블로그마다 다르다(네덜란드 vs 뉴질랜드). 뉴질랜드가 맞다면 '네덜란드산 유제품' 고리는 산양유에만 걸린다. 미확인.

## 7. 확인 못 한 것

- 용기·패키지의 색, 병 모양, 박스 디자인: 미확인. 상세 이미지는 텍스트로 읽을 수 없었고, 브라우저 패널이 숨겨져 있어 스크린샷도 찍지 못했다.
- 상세페이지 01-4~04-5의 내용과 실제 빌드업 순서: 미확인. 확인한 것은 01-3 한 장뿐이다.
- 실제 메타 광고 소재의 첫 1초와 카피: 미확인. 광고 라이브러리는 조회하지 않았다.
- 교안 문장(raw:16-17)이 실제 광고 문구인지, 사장님이 요약한 문장인지: 미확인.
- 별(하하 와이프)을 실제 모델로 기용했는지, 교안 속 매칭 예시인지: 미확인.
- 우유칼슘 원산지(네덜란드 vs 뉴질랜드), 제조원(한미양행이라는 블로그 주장 vs 다나와 '키즈랩스'), 건강기능식품 여부: 미확인.
- 'Milkids Netherlands headquarters'가 실재하는지: 미확인.
- 특허 원료 표기가 공식몰은 'YGF-215', 블로그는 'YGF-251'이다. 어느 쪽이 맞는지 미확인.
- 사장님 교안의 밀키즈가 2026년판(IGF complex™) 이전 버전인지: 미확인. 상세 폴더명 260626을 보면 2026-06에 리뉴얼한 것으로 추정된다.
