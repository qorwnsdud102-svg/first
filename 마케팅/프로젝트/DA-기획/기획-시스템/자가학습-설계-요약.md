# DA 기획 자가학습 — 사장님용 한 장

## 한 줄

규칙을 더 늘리지 않습니다. 사장님이 이미 하신 판정(판례 801줄, 판정받은 기획 61건)으로 **'사장님 눈'**을 만들고, 잘된 기획 본보기로 **'기획 손'**을 가르칩니다. 손이 많이 만들고 눈이 거른 뒤 사장님께는 1~2장만 드립니다. 사장님의 한 단어는 규칙 한 줄이 아니라 눈과 손의 **학습 데이터**가 됩니다.

## 테슬라처럼 바뀌는 것

> (위키에 없음 — 일반 지식) 테슬라 FSD는 v11까지 사람이 짠 조건 규칙 코드로 달렸고, v12부터 잘 운전한 영상을 보고 '카메라 → 조작'을 통째로 배웠습니다. 그 뒤 개선은 코드가 아니라 데이터를 더하고 골라서 나왔습니다.

| | 지금 (v11) | 바꾼 뒤 (v12) |
|---|---|---|
| 기획 쓰는 법 | 규칙 176줄을 읽고 피해서 씀 → 겉핥기 | 본보기(그때 재료 → 실제 결정) + 새 결핍 재료 → 곧장 기획 카드 |
| 규칙 | 기각 한 번 = 규칙 한 줄 | 동결. 안전선 6줄(의료기기·병원 결핍·임산부·법 표현·조달 불가·베끼기)만 |
| 나아지는 길 | 사장님 오답노트 | 본보기·판정 데이터를 더하고, 시험을 통과한 방법으로만 교체 |

## 사장님 없이 배우는 것 / 사장님만 주실 수 있는 것

| 사장님 없이 (매일 돌 수 있음) | 사장님만 |
|---|---|
| **사장님 눈**: 과거 판정으로 만들고, 과거 판정을 맞히는지 먼저 시험합니다. 같은 상징의 성공·실패(써모드 > 써멀 파우더팩, 유쎄라블 > 울쎄업)와 AI 기획끼리의 순위(레드밤·라밀필·스컬밀크가 위로 오나)를 맞혀야 씁니다. 통과하면 사장님 대신 후보를 거릅니다 | 처음 보는 카드에 대한 **최종 한 단어**(진행/조건부/보류/기각). 이유는 안 쓰셔도 됩니다 |
| **깊이(겉핥기 거르기)**: 상징의 핵심 코어를 옮겼나(신경차단술 = 성분 + 특정 지점), 고객이 보는 모습을 옮겼나(스컬트라 = 주사기·바이알), 겹이 한 방향으로 모이나(써모드). 위 눈 시험에 들어 있습니다 | 눈이 틀린 카드가 곧 다음 학습 거리입니다. 그래서 사장님께는 '눈이 제일 좋다는 것 1장 + Claude 눈과 GPT 눈이 가장 엇갈린 것 1장'을 드립니다 |
| **가치·참신**: 상징원 검색량 월 5,000 이상 + 같은 결핍에서 같은 상징 광고 0~2곳. 스크립트가 셉니다(토큰 0) | |
| **기본기**: 사장님 기획·시장 히트의 '그때 재료 → 결정'을 다시 찾아보는 연습 | |
| **시장 생존**: 지금 30~59일 된 광고 422묶음의 '60일 생존'을 미리 맞혀 봉인하고, 2026-11-10 뒤 자동 채점 | |

## Claude와 GPT

- 둘이 **서로 다른 본보기와 자료**로 따로 씁니다. 같은 자료를 보면 같이 틀립니다(3차 '찌릿한 샷 = 울쎄라'를 예측 6개가 모두 놓침).
- 서로의 카드를 **사실로 감사**합니다(가장 싼 대안 가격, 고객이 보는 모습, 원료 조달). 점수나 설득문은 보지 않습니다.
- GPT가 보탬이 되는지 숫자로 재고, 두 번 연속 보탬이 없으면 GPT를 끕니다.
- GPT 독립안에서 '한 번에 하나만 바꾸고, 고정 시험을 통과할 때만 새 방법으로 교체, 아니면 되돌림' 장치를 가져왔습니다.

## 접는 기준과 솔직한 한계

- 사장님 눈이 시험에 떨어지면: 눈 없이 서로 다른 결핍·상징이 되게 골라 드리고(1단계에 머묾), 왜 떨어졌는지 보고드립니다.
- 5회차(본보기 카드 10장 · 규칙집 카드 10장) 뒤 본보기 쪽 '보류 이상'이 3장 이상 많지 않으면 본보기 전환을 멈추고 보고드립니다. **가장 흔할 결과는 비김**(둘 다 1~2장)입니다. 그때 계속할지는 사장님이 정하십니다.
- 마음에 드는 기획이 언제 나올지는 약속드릴 수 없습니다. 지금까지 AI가 완성한 기획 23장 중 진행은 1장(레드밤)입니다.
- 지금 쓸 수 있는 좋은 본보기는 9개 남짓이고 대부분 사후 해부입니다. 본보기가 늘수록 나아지는 구조라, 사장님이 직접 기획하실 때 출발점만 알려 주시면(그림자 시험) 가장 값진 본보기가 하나씩 생깁니다.
