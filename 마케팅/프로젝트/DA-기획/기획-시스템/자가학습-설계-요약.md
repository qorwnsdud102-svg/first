# DA 기획 자가학습 — 사장님용 한 장

## 한 줄

규칙을 더 늘리지 않습니다. 사장님이 이미 하신 판정(판례 801줄, 판정받은 기획 61건)으로 **'사장님 눈'**을 만들고, 잘된 기획 본보기로 **'기획 손'**을 가르칩니다. 손이 많이 만들고 눈이 거른 뒤 사장님께는 1~2장만 드립니다. 사장님의 한 단어는 규칙 한 줄이 아니라 눈과 손의 **학습 데이터**가 됩니다.

## 맨몸에서 시작하지 않습니다

처음부터 다시 하는 것도, 규칙을 없애는 것도 아닙니다. 지금까지 쌓은 것이 전부 출발 재료입니다.

| 그대로 쓰는 것 | 새로 만드는 것 |
|---|---|
| 판례 801줄과 판정받은 기획 61건 → 사장님 눈의 재료이자 시험지 | 사장님 눈. 과거 판정을 맞히는 시험을 통과해야 씁니다 |
| 규칙 176줄 → 다 쓴 카드를 거르는 체, 그리고 지금 방식 카드 | 본보기 카드 7~10장. 이미 있는 해부 문서(사례-써모드 등)를 '그때 재료 → 결정' 한 장으로 줄입니다 |
| 사장님 기획·인정 히트 해부, 메타 광고 721묶음, 회귀 시험 장치 | 광고 수와 검색량을 세는 스크립트 몇 개 |

**규칙의 자리만 옮깁니다.** 지금은 쓰는 쪽이 규칙 176줄을 읽고 피해 가며 씁니다. 바꾼 뒤에는 쓰는 쪽이 본보기를 보고 쓰고(안전선 6줄은 지킴), 다 쓴 카드는 꼭 지킬 규칙 41줄로 거릅니다. 걸리면 사장님께 가기 전에 빼고, 나머지 규칙에 걸리면 표시만 해서 눈이 참고합니다. 규칙은 나쁜 기획 거르기를 잘합니다(판정 맞히기 시험에서 기각 23개를 전부 걸러 냄). 그런데 규칙을 보고 쓴 AI 기획은 23장 중 진행이 1장이었습니다. 그래서 거르기는 규칙에, 만들기는 본보기에 맡깁니다.

**지금 방식도 멈추지 않습니다.** 처음 5회차는 카드 4장 중 2장을 지금 규칙집 방식으로 씁니다. 본보기 쪽이 못하면 지금 방식 그대로 가므로 지금 수준 밑으로 떨어지지 않습니다.

## 테슬라처럼 바뀌는 것

> (위키에 없음 — 일반 지식) 테슬라 FSD는 v11까지 사람이 짠 조건 규칙 코드로 달렸고, v12부터 잘 운전한 영상을 보고 '카메라 → 조작'을 통째로 배웠습니다. 그 뒤 개선은 코드가 아니라 데이터를 더하고 골라서 나왔습니다. v12를 키우는 동안 v11은 계속 돌았고, v12가 낫다고 확인된 뒤에 바꿨습니다.

| | 지금 (v11) | 바꾼 뒤 (v12) |
|---|---|---|
| 기획 쓰는 법 | 규칙 176줄을 읽고 피해서 씀 → 겉핥기 | 본보기(그때 재료 → 실제 결정) + 새 결핍 재료 → 곧장 기획 카드 |
| 규칙 | 기각 한 번 = 규칙 한 줄 | 동결. 쓰는 쪽은 안전선 6줄(의료기기·병원 결핍·임산부·법 표현·조달 불가·베끼기)만 지키고, 다 쓴 카드는 하드 41줄로 거름 |
| 나아지는 길 | 사장님 오답노트 | 본보기·판정 데이터를 더하고, 시험을 통과한 방법으로만 교체 |

## 사장님 없이 배우는 것 / 사장님만 주실 수 있는 것

| 사장님 없이 (매일 돌 수 있음) | 사장님만 |
|---|---|
| **사장님 눈**: 과거 판정으로 만들고, 과거 판정을 맞히는지 먼저 시험합니다. 같은 상징의 성공·실패(써모드 > 써멀 파우더팩, 유쎄라블 > 울쎄업)와 AI 기획끼리의 순위(레드밤·라밀필·스컬밀크가 위로 오나)를 맞혀야 씁니다. 통과하면 사장님 대신 후보를 거릅니다 | 처음 보는 카드에 대한 **최종 한 단어**(진행/조건부/보류/기각). 이유는 안 쓰셔도 됩니다 |
| **깊이(겉핥기 거르기)**: 상징의 핵심 코어를 옮겼나(신경차단술 = 성분 + 특정 지점), 고객이 보는 모습을 옮겼나(스컬트라 = 주사기·바이알), 겹이 한 방향으로 모이나(써모드). 위 눈 시험에 들어 있습니다 | 눈이 틀린 카드가 곧 다음 학습 거리입니다. 그래서 사장님께는 '눈이 제일 좋다는 것 1장 + 판례를 나눠 만든 눈 둘이 가장 엇갈린 것 1장'을 드립니다 |
| **가치·참신**: 상징원 검색량 월 5,000 이상 + 같은 결핍에서 같은 상징 광고 0~2곳. 스크립트가 셉니다(토큰 0) | |
| **기본기**: 사장님 기획·시장 히트의 '그때 재료 → 결정'을 다시 찾아보는 연습 | |
| **시장 생존**: 지금 30~59일 된 광고 422묶음의 '60일 생존'을 미리 맞혀 봉인하고, 2026-12-01 뒤 다시 수집해 채점 | |

## Claude만 씁니다 (GPT는 일단 뺌)

- 사장님 지시(2026-10-11): "gpt 말고 일단 클로드로만 하자"(Max 20x로 Claude 토큰이 더 많음).
- 3차 때 Claude와 GPT 예측 6개가 '찌릿한 샷 = 울쎄라'를 똑같이 놓쳤습니다. 모델이 달라도 같은 자료를 보면 같이 틀립니다. 그래서 Claude 작성자 둘에게 **서로 다른 본보기와 자료**를 줍니다.
- 카드의 사실(가장 싼 대안 가격, 고객이 보는 모습, 원료 조달)은 작성자와 다른 Claude가 출처로 감사합니다. 점수나 설득문은 보지 않습니다.
- GPT 독립안에서 가져온 장치는 그대로 씁니다: 한 번에 하나만 바꾸고, 고정 시험을 통과할 때만 새 방법으로 교체, 아니면 되돌림.

- 사장님 눈이 시험에 떨어지면: 눈 없이 서로 다른 결핍·상징이 되게 골라 드리고(1단계에 머묾), 왜 떨어졌는지 보고드립니다.
