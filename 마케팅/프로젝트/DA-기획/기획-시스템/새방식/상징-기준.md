# 원리 상징 · 이미지 상징 — 상징을 고르고 옮기는 기준 (현행판 2026-10-16)

## 1. 상징은 두 가지다

| | 원리 상징 | 이미지 상징 |
|---|---|---|
| 뜻 | 제품이 그 상징이 **일하는 방식**(원리·성분)을 실제로 담는다 | 일하는 방식은 안 빌리고 **장면·느낌**만 빌린다 |
| 확인 질문 | 제품 안에 그 상징이 일하는 방식이 들어 있나? | 떠올리면 장면이 바로, 선명하게 그려지나? |
| 사장님이 나눈 예 | 히트텍(흡습발열) · 기넥신(은행잎) · 실리카겔(습기 흡수) · NMN 노화 영양제 · 녹는실 · 보톡스 · 프락셀 · 써마지 · 리투오 ECM | 핀란드 사우나 · 쿠사츠 유황온천 · 남미(가슴 영양제) · 다리미(목주름) · 핫팩(수족냉증) |

- **둘 다 많을수록 좋다.** 광고·상세페이지에서 한 번에 말할 수 있는 수는 정해져 있지만, A 소구가 안 통하면 같은 제품으로 B 소구로 간다. 예: 써모드 = 써마지 컨셉 + 리투오 ECM 컨셉(둘 다 원리 상징).
- **원리 상징은 1개 이상 반드시.** 원리 상징의 핵심 원리·성분이 빠지면 상징이 구현되지 않는다.
  - 트란시노인데 트라넥삼산이 빠짐(6)
  - 라미실 원스에서 '투명하게 굳는 막'만 가져옴(2) — "핵심 성분이 있어야지"
- 물건 비유(다리미·핫팩)는 장면이 선명해도 원리 상징이 못 되고 이미지 상징으로 쓴다 — "메인 상징성으로 쓸순없지만 이미지 상징성으로는 좋음".

## 2. 옮겨지는 조건 — 다른 결핍·다른 분야의 상징을 옮길 때

암묵지라 'A는 B다'로 딱 떨어지지 않는다. 아래로 걸러 보고, 애매하면 사장님 판정에 맡긴다.

1. **타겟이 그 상징이 하는 일을 한 마디로 안다.**
   - 보톡스 = 근육 마비 → 다한증 '땀톡스'(8) "직관적"
2. **그 한 마디를 내 결핍 부위에 대면 장면이 그려진다.**
   - 됨: 프락셀 = 새살을 채움 → 파이고 부서진 발톱을 스피큘로 강하게 침투해 채움(당위가 느껴짐)
   - 안 됨: 고어텍스는 옷감이라 피부에 대면 상상이 안 됨(1). 탈색으로 끊어진 머리(올라플렉스)와 튼살도 안 맞음(3)
3. **그 부위에서 실제로 일어날 법하다.**
   - 숯 탈취제 X: 밀착된 겨드랑이의 땀·냄새를 빨아들일 것 같지 않음
4. **원리·물성의 결이 맞는다.**
   - 이명래 고약은 고름(액체)을 빨아내는데, 티눈은 단단함(3)
   - 실크 베개는 목주름의 원인(자세)과 무관(2)
   - 교정 유지장치 × 기미는 조합이 별로(3)
5. **상징의 나쁜 느낌도 같이 옮겨진다.**
   - 코르셋 X: 억지로 꽉 조임
   - 치아미백 X: 독한 표백제를 피부에
   - 미녹시딜 '혈관에 피를 대준다'(3): 크리피함
   - 필러: 인위적 물질을 넣는다는 약간의 거부감(7)
6. **결핍이 원하는 동작과 같다.**
   - 소극성속모증은 '뽑기'를 원함 → 훼스탈(녹여서 소화) X
   - 다한증은 땀이 안 나길 원함 → 실리카겔(흡수)은 핀트가 약간 어긋남(6)
7. **곁가지가 아니라 핵심을 가져온다.**
   - 브이빔의 핵심은 레이저로 혈관을 파괴하는 것이고, 냉각은 통증을 줄이는 곁가지(2)
8. **제품으로 만들 수 있다.**
   - 레이저 제모 △: 좋은데 제품 구현이 힘듦
   - 핀포인트 레이저 → 바르는 발톱 레이저(2): 가정용 레이저 기기가 이미 있음
9. **타겟이 아는 이름이다.**
   - 요쿠이닌(4)·이보코로리(5): "잘 모르는 상징성"
   - 니조랄(5): 병원에서 쓰는 제품이었으면 더 강했음
10. **사용감에 걸림이 없다.**
    - 바르고 두는 하수오 두피 폼(2): "씻겨나가지 않으면 머리 더러운데"

## 3. 직관 감각 — 사람들의 직감과 같은 방향

- 사장님 목록: 열감 · 냉감 · 조여지는 느낌 · 화함(민트 같은 상쾌함) · 주무르는 느낌(괄사).
- 직감과 같은 방향으로 쓴다.
  - "미세열감으로 지방을 녹여준다"
  - "쿨링감이 모공을 작게 만들어준다"(실제로 안 줄어도, 처음 차가울 땐 일시적으로 줄어드는 것 같다)
  - 지방에 냉각(쿨스컬프팅 -11℃ 패치, 4점): "지방은 뜨겁게 녹인다가 더 직관적"
- 감각이 구현 당위를 준다.
  - 온다리프팅 → 미세열감 턱살 크림(8): "구현 당위성도 가져오고"
  - 윤곽주사(9): 지방분해 느낌의 USP를 열감으로 가져올 수 있나가 숙제

## 4. 응용 방식 — 교과서 다음 단계 (판정 K12)

교과서는 같은 결핍의 상위 상징(사람들이 말하는 대안)을 화장품으로 구현하는 것이다. 지금 이건 잘 하고 있다. 다음은 변형·응용이다.

| 방식 | 사장님 예 |
|---|---|
| 다른 결핍의 시술 옮기기 | 여드름흉터 프락셀 → 무좀 프락셀 |
| 다른 분야의 유명 조합·이름 비틀기 | 올리브+레몬 다이어트(올리브 레몬샷) → '올레놀샷' 주름 앰플 |
| 다른 카테고리의 성분 상징 | NMN 노화 영양제 → NMN 주름 앰플 |
| 나라·장소 이미지 | 남미(가슴 큼) → 남미 가슴 영양제 · 쿠사츠 유황온천 → 무좀 · 핀란드 사우나 → 속모증 |
| 직관 감각 | 열감 · 냉감 · 조임 · 화함 · 주무름 |

사장님 속모증 기획은 세 가지를 한 제품에 담았다.
- 이미지 상징: 핀란드 스팀사우나
- 감각: 바르면 온열감이 들고 모공이 쫙 열림
- 결핍이 원하는 동작: 필오프팩으로 무방비 상태의 털을 뽑음
