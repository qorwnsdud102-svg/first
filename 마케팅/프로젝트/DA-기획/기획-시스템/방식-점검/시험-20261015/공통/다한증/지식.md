# 결핍 지식 — 다한증

**무엇인가:** 몸을 식히는 데 필요한 양보다 땀이 많이 나서 손·발·겨드랑이·얼굴이 젖고 생활이 불편해지는 상태다. 땀을 내보내는 신경의 과한 반응과 관련되지만, 일차성 다한증의 정확한 원인은 밝혀지지 않았고 다른 질환 때문에 생기는 경우도 있다. 어릴 때부터 시작해 반복되는 경우가 있으며, 수집 목소리에도 학창 시절부터 겪고 겨울에도 땀이 난다는 말이 나온다. 의학 설명은 [분당서울대병원](https://snubh.org/dh/main/index.do?DP_CD=RC&MENU_ID=006018) 보충.

**타겟이 믿는 원인:** ‘원래 땀이 많은 체질’이라고 여기고, 긴장하거나 땀을 의식하면 더 난다고 느낀다. 이는 목소리에서 확인한 인식이며, 원인에 대한 믿음의 비중은 확인 못 함.

**장면**
- 학생이 시험을 볼 때 손땀으로 시험지·OMR이 젖고 펜이 번진다.
- 컴퓨터 작업이나 게임을 하는 사람이 마우스·키보드·폰을 잡으면 젖고 미끄러워진다.
- 다한증 당사자가 데이트에서 손을 잡거나 사람과 악수할 때 축축한 손 때문에 눈치를 보고 접촉을 피한다.

**목소리에서 많이 나온 것**
- 손에 땀 — 11.4%, 93건/813건 (예: ‘수족 다한증의 슬픔’)
- 여름이 지옥 — 6.9%, 56건/813건 (예시 요지: 여름에는 더 버티기 힘들다)
- 긴장하면 더 남·땀 생각만 해도 남 — 4.8%, 39건/813건 (예시 요지: 땀을 의식하면 더 난다)
- 악수·손잡기·스킨십을 피함 — 4.4%, 36건/813건 (예: ‘손잡고 데이트한게 손에 꼽힐 정도’)
- 시험지·종이·필기가 젖음 — 3.6%, 29건/813건 (예: ‘시험지도 다 젖을 정도’)
- 폰·마우스·키보드·게임이 젖고 미끄러움 — 3.4%, 28건/813건 (예시 요지: 잡고 쓰는 물건이 젖는다)
- 약국 땀 억제제 사용·추천 — 9.3%, 192건/2,056건 (예: ‘이런거 바르는게 훨 나음’)
- 데오드란트 사용·추천 — 3.7%, 77건/2,056건 (예: ‘니베아꺼 스프레이랑 고체 스틱 써보니 괜찮음요’)
- 손수건·수건·휴지·장갑으로 버팀 — 2.4%, 50건/2,056건 (예: ‘손수건은 하루에 5장은 기본’)
- 보톡스·땀 주사 — 0.9%, 19건/2,056건 (예: ‘주사바늘을 수십군데 찔러대니 얼마나 고통스럽던지’)
- 약국 땀약이 따갑고 가려워 잠 못 잠 — 2.5%, 51건/2,056건 (예: ‘손 간지럽거나 따가워지는 부작용’)
- 수술 뒤 다른 곳으로 땀이 옮겨감 — 2.3%, 47건/2,056건 (예: ‘다한증 수술하면 다른 곳에서 땀 난다는 얘기’)
- 착색·까매짐·옷 탈색 — 1.6%, 32건/2,056건 (예: ‘색소침착안되셧나여 10년썼는데 넘심해요’)
- 이온영동을 자주·계속 해야 하는 수고 — 0.2%, 4건/2,056건 (예시 요지: 귀찮고 계속 관리해야 한다)

**지금 많이 팔리는 것**
- 드리클로 — 최근 30일 검색량 7,060. 바르는 약국 땀약. 목소리 구매가 20ml 1만~1만5천 원이며 현재 약국 가격은 확인 못 함.
- 스웨트롤 — 최근 30일 검색량 3,760. 얼굴용 일반의약품 패드. 목소리 구매가 약 3,000원/매이며 현재 약국 가격은 확인 못 함.
- 백년뒤앤 스웨트린 정 — 시장카드에서 22일 게재된 먹는 땀 제품 광고 확인. 단품 44,900원. 비타민D3·감초를 내세움. [공식몰](https://100yerdn.com/product/detail.html?product_no=41)
- 더마드라이 — 시장카드에서 4일 게재된 광고 확인. 손·발·겨드랑이용 이온영동 기기 698,000원. [공식몰](https://dermadry.co.kr/category/더마드라이-토털/42/)
- 퓨어레비 프레톡 — 시장카드에서 27일 게재된 냄새 패드 광고 확인. 60매 26,800원. 땀 억제보다 냄새 관리를 내세움. [공식몰](https://purelevy.com/index.html)

**타겟이 꺼리는 것:** 따갑고 가려워 잠을 방해하는 바르는 약, 착색·옷 탈색, 밤마다 씻고 완전히 말려야 하는 사용 과정, 여러 번 찌르는 주사와 반복 시술비, 수술 뒤 다른 부위의 땀이 늘어나는 결과를 꺼린다. 특정 성분이나 스프레이·패드 형태 자체를 싫어하는지는 확인 못 함.

**확인 못 한 것:** 교감신경 수술의 실제 부담액, 먹는 처방약의 월 비용, 약국 제품의 현재 판매가, 스웨트린의 건강기능식품 분류·실제 복용 목소리·다한증 개선 효과·완제품 부작용은 확인 못 함. 대안사전.json·우리-자료.md·별도 교차표·검색량 파일은 이 폴더에 없으며 검색량은 시장카드를 사용했다. 판매량·판매 순위는 확인 못 했고 selling_now는 2026-10-12 수집 광고·검색량과 조회 판매가 기준이다. 비율은 다한증 키워드 813건 또는 전체 2,056건 중 언급 비율로, 항목이 중복되며 이용률·효과율을 뜻하지 않는다. ‘예시 요지’는 원문 항목을 요약한 말이다.
