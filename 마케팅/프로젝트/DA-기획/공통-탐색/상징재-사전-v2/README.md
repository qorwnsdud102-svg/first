사장님 지시(2026-10-11 밤, `raw/본인/2026-10-11_본인구술_카테고리별-유명상징재-최대한-많이-명확하고-직관적으로-핀란드치아-독일기술력-카이스트과학.md`)로 만들었다.

- 각 카테고리에서 유명한 상징재를 최대한 많이 뽑는다.
- 명확하고 직관적인 것으로만 넣는다. 사장님이 든 예: 핀란드 → 치아, 독일 → 기술력, 울쎄라 → 주름, 카이스트 → 과학, 실리콘밸리 개발자가 쓰는 발받침대 → 하루 종일 앉아 있을 것 같음.
- 나중에 DA 기획의 첫 시작 재료로 쓴다.

## 쓰는 법 — DA 기획 첫 시작

1. **결핍부터 고른다.** 결핍 메인 키워드의 목소리를 먼저 모은다(정본 ①-01). 사전은 출발점 후보를 넓게 볼 때 펼친다.
2. **결핍 칸으로 찾는다.** 그 결핍이 '어울리는 결핍·제품' 칸에 있는 상징재를 4편에서 모은다.
3. **세 가지를 거른다.**
   - **목소리에 나오나.** 그 상징원을 받아 본 사람들이 기억하는 감각·모습이 있어야 핵심 코어를 잡는다.
   - **매대에 흔한가.** ⑤ 매대 비율과 임시 보조 지표(상징+제품 검색량 8천, 선점 브랜드 1만)로 본다.
   - **'많이 씀'인가.** '많이 씀' 표시는 참신함 경고일 뿐 탈락 표시가 아니다.
4. **겹 상징을 만든다.** 나라·기관·인증 같은 보증형은 혼자 쓰면 약하다. 작동을 보여 주는 상징(시술·국민제품) 위에 한 겹으로 얹는다(④-39·④-52).

## 편마다 가장 강하다고 본 것

각 편 작성 Claude의 판단이다. 검증된 것이 아니다.

- **나라·전통:** 일본 온천 → 관절통 · 핀란드 자일리톨 → 충치·잇몸 · 동의보감·허준 → 관절·허리 · 네덜란드 키 1위 → 성장기 키 · 템플스테이 → 불면 · 진시황 불로초 → 노화
- **직업·기관:** 특수부대(천리 행군) → 발냄새·물집 · 승무원 → 다리 붓기 · 발레리나 → 하체 라인 · 실리콘밸리 개발자 → 오래 앉음(발받침대) · 축구선수 → 종아리 쥐 · 클라이밍 국가대표 → 손목 통증
- **시술·국민제품:** 울쎄라 · 보톡스 · 눈밑지방재배치 · 써마지 · 냉동치료 · 동전파스 · 호랑이연고 · 뜸 · 오쏘몰 이뮨 · 미녹시딜

## 알아 둘 것

- **법적 한계:** '의사·약사가 추천·사용'이라는 광고는 화장품·식품 모두 금지다. 직업 상징은 그 직업의 고생 장면(천리 행군, 10시간 수술)을 빌리고, '○○가 추천'이라고 쓰지 않는다(2편).
- **일화는 약하다:** 이야기가 유명해도 세부 일화는 거의 검색되지 않는다. 예: 클레오파트라 목욕 10, 당나귀 우유 20, 녹두 세안 10, 불가리아 요구르트 50. 일화를 기획 중심에 두지 않는다(1편).
- **표기가 검색량을 가른다:** 상어연골 1,610 대 '철갑상어 콘드로이친' 13,150, 시네이크 0 대 뱀독크림 630(4편).
- **편 사이 겹침:** 온천·핀란드 사우나·템플스테이·호랑이연고·실리콘밸리·카이스트·특수부대 등은 두 편 이상에 있다. 쓰임새(나라 이미지·장소 경험·직업 고생)가 달라 그대로 두었다. 합칠 때는 결핍 칸을 기준으로 묶는다.
- **판례 갱신 반영:** GLP-1 유산균은 2025년 히트였지만 지금은 참신함이 소진됐다(P6213~P6215). 물광·백옥 앰플은 8월 승인이 10월 보류로 바뀌었다(P6219·P6220). 상징재 지도 v1의 GLP-1 줄도 같은 날 고쳤다.
