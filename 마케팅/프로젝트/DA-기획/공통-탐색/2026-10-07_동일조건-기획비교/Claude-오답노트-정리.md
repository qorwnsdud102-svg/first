# DA 기획 오답노트 정리 — Claude 1·2차 (2026-10-10)

> 사장님이 1·2차로 적어 주신 오답노트와 채팅 지시를 주제별로 묶었다. 각 항목은 '사장님 말씀 → 내가 틀린 것 → 앞으로 규칙' 순서다.
> 원문: `마케팅/raw/본인/2026-10-10_본인구술_클로드DA기획-오답노트-1차.md`, `…-오답노트-2차-상징재먼저.md`

## 한 장 요약 — 앞으로의 기획 순서

1. **상징재 먼저.** 분야별로 대중이 이미 아는 유명 상징재(브랜드·나라·장소·사람·시술)를 먼저 꺼낸다. 예: 근육통 = 멘소래담·동전파스·온천, 독일 = 맥주, 오쏘몰 이뮨 = 영양제계의 에르메스, 스님·인센스 = 마음의 평화.
2. **벤치마킹이 가장 쉽다.** 남이 쓴 상징을 약간 다르게 쓰거나, 다른 시장으로 옮긴다(비렌느 냉동치료 → 다른 결핍).
3. **결핍 기초공사.** 구글·나무위키·유튜브로 결핍을 파악한다. 증상과 해결 행동을 비중순으로 정리하고, 메인 증상에 맞춘다.
4. **위화감 없이 제품으로.** 제품이 상징의 핵심 장면을 담아야 한다. 체감(열감·냉감)으로 옮기는 것도 실력이다.
5. **대중 결핍, 실제로 쓸 사람.** 마이너 타겟과 반려는 뒤로 미룬다. 타겟이 그 불편을 실제로 감수할지 본다.
6. **피할 것.** 의료기기, 임산부 대상 먹는 제품, 억지 세트.
7. **판단은 느슨하게, 결정은 사장님께.** 과거에 쓴 상징, 매대에 있는 원료, 마진 수치로 자동 탈락시키지 않는다. 마진은 대략선(원가율 약 10%, 통합 ROAS 200%)만 본다.
8. **기획서는 제품부터.** 첫 줄에 '무슨 제품을, 누구에게, 어떻게, 얼마에'를 쓴다.

## 주제별 오답

### A. 첫 접근 — 결핍이 아니라 상징재에서 시작한다

- 사장님: "일단 각 분야에서 유명한 상징재를 먼저 생각해봐 … 이런 상징성을 제품으로 위화감없게, 억지스럽지 않게 … 구현 가능한지? 이렇게 첫 접근하면 좋은 da 기획 만드는게 더 쉬워질듯"
- 내가 틀린 것: 결핍(또는 병원 처치)부터 찾고 상징을 나중에 붙였다. 그래서 마이너한 결핍과 억지 상징이 나왔다.
- 앞으로: 분야별 유명 상징재 지도 → 위화감 없는 제품 변환 가능성 → 결핍 확인 순서로 간다.

### B. 상징재 — 좁게 보지 말고, 직접적인 것을

| 사장님 말씀 (요지) | 내가 틀린 것 | 앞으로 |
|---|---|---|
| "구현가능함, 그게 실력임" — 비렌느(쥐젖 동결치료), 써모드(미세열감으로 울쎄라·써마지) | '병원 고가 상징은 화장품이 재현 못 한다'고 결론 냈다 | 체감(열감·냉감 등)으로 상징을 옮기는 길부터 찾는다 |
| "1000개 제품중에 1개가 … 사용하고있다고 … 절대 사용안할 이유는 아니니까" | '원료·상징이 매대에 있음'을 탈락 사유로 썼다 | 정말 많이 겹칠 때만 표시하고, 판단은 사장님께 넘긴다 |
| "과거에 사용한 상징재라고 배제하지마, 다른 방식으로 무한하게 사용 가능함" | 카탈로그·승인석·자사에 쓴 상징을 제외 목록으로 막았다 | 금지는 결핍·제형·상징이 다 같은 재제출뿐이다 |
| "새로운 상징재 찾는게 쉽지 않고 다른 브랜드 밴치마킹 + 약간 다르게 or 다른 시장" | (잘한 점) 비렌느 냉동치료를 노견 돌기에 붙인 시도는 "매우 좋았음" | 벤치마킹 + 변형, 다른 시장 이식을 기본 경로로 삼는다 |
| "의사가 쓰는, 국가대표가 쓰는 … 보단, 쥐젖 냉동치료 원리 비렌느 … 훨씬 더 직접적이고 강하게 와 닿음" | 보증형 상징(강남 조리원, 동물치과 원장)을 강하다고 봤다 | 기전이 직접 보이는 상징을 우선한다 |
| 강남 조리원: "무난한데 … 참신x, 남들 많이 사용 o, 상징성이 강하지 않음" | 조리원 상징을 '가장 깨끗한 상징원'으로 평가했다 | 흔한 상징은 강도가 낮다 |

### C. 결핍 이해 — 기초공사가 틀리면 다 무너진다

- 사장님(주사피부염): "메인 증상은 … 뺨, 코 등에 붉게 되는게 메인이고, 더 심해지면 … 뾰루지 … 너는 뾰루지, 모낭충을 없애는데 포커스가 맞춰져 있어서 … 아 얘 주사 피부염 잘 모르네"
- 내가 틀린 것: 네이버 담화와 검색량 위주로 결핍을 읽었고, 드문 증상(구진·농포)을 주 타겟의 증상처럼 썼다.
- 앞으로:
  - 조사는 구글·나무위키·유튜브(광고가 적다) 영상 여러 개로 한다.
  - 정리는 두 가지를 비중순으로 한다. ① 그 결핍의 증상 ② 해결하려고 사람들이 하는 것.
  - 기획은 메인 증상에 맞춘다. "A 질병 타겟은 드문 증상 c로 고생한다"는 식으로 쓰지 않는다.

### D. 타겟·시장 — 대중적인 것 먼저

- "애견쪽은 너무 시장이 마이너함, 더 대중적인거 먼저 기획해 … 왜 마이너의 마이너한 타겟 가져오냐" — 1부 1·3위와 2부 1·2위가 모두 반려였다.
- 1위 노견 치태: "너무 마이너한 타겟과 결핍임"
- 눈꺼풀 리프트 필름: "50~60대는 이런거 불편해서 안하지, 학생들이야 … 불편해도 쌍수 테이프 이런거 하는거지만" — 타겟에게 그 불편을 감수할 욕구가 있는지 본다.

### E. 제품 구성 — 상징의 핵심 장면, 시너지 있는 세트

- 1위 노견 치태: "마취 스케일링 … 움직이지 않게 만든 후, 전문 의료 스케일링 기기로 … 치석을 전부 제거 … 치실, 효소젤을 지금 판매한다는건가? … 스케일링의 상징성이 안가져와짐"
- 1위 세트 구성: "1가지 제품으로 해소가 안되면 여러 개 … 좋은 기획이지만, 이건 … 시너지 … 세트라기보단 억지 여러 개를 넣어놓은 듯한 느낌"
- 앞으로: 제품이 상징의 핵심 장면을 담는지 본다. 세트는 시너지로 하나의 완결된 해결이 될 때만 만든다.

### F. 사업 구조 — 대략선만

- 사장님: "마진율은 너무 디테일하게 안봐도 됨 … 엔드로아스 150% 이니까 da 제품 못함 이런식으로 … yes no로 판단 불가 … 참고만 해"
- 대략선:
  - 화장품·건기식은 원가율을 판매가의 약 10%로 맞춘다.
  - 모든 판매 채널을 합친 통합 ROAS가 200%를 넘으면 DA가 순조롭게 돈다.
  - 3~4만원 화장품에 원가 2만원이면 비정상이다.
  - 가전은 원가 2~3만원이면 판매가가 10만원 초중반은 돼야 한다.
- 내가 틀린 것: VAT·결제비까지 넣은 엔드로아스 표를 길게 만들고, 수치로 통과와 탈락을 갈랐다.

### G. 피할 영역

- 의료기기(날숨 코 밸브): "양압기가 … 완벽한 대안 … 근데 이건 의료기기 영역이라 … 몇 개월~몇 년, 수천만원 … 과대광고못함, 처벌 빡셈"
- 임산부 섭취(입덧 B6): "임산부한테 먹는 것 파는건 매우 조심해야함, 리스크 커서 패스"

### H. 기획서 작성

- 사장님: "너무 횡설수설하고 … 너의 메모들을 적은걸 내가 에너지 써서 해석하는건지 … 그래서 무슨 제품을 … 팔겠다는건지?"
- 앞으로: 첫 줄에 '무슨 제품을, 누구에게, 어떻게, 얼마에'를 쓴다. 근거와 계산은 뒤로 보낸다. 기호와 판례 번호 대신 말로 쓴다.
