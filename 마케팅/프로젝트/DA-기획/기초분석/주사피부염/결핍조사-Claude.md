## 4. 메인 증상과 드문 증상

**환자 중 몇 %가 어떤 증상을 겪는지 나눈 비중 수치는 출처에 없다.** 아래 구분은 출처의 서술(주 증상 / 간혹 / 소수 / 합병증)을 근거로 한 것이다. 수치가 있는 것만 수치를 적었다.

| 구분 | 증상 | 근거 |
|---|---|---|
| **메인** | 얼굴 중앙(코·뺨)이 붉어짐 — 처음엔 오락가락하는 홍조, 시간이 지나면 계속 붉음 | B 정의: "붉어진 얼굴과 혈관 확장이 주 증상". A·B·C 모두 초기 간헐적 홍조 → 지속적 홍반으로 진행한다고 씀 |
| **메인** | 실핏줄(모세혈관 확장) | B 정의(주 증상) + 치료 절: 늘어난 실핏줄은 "거의 모든 주사 환자"에게 나타난다 |
| 흔함 (비중 수치 없음) | 자극을 받으면 따갑거나 화끈거리며 붉어짐, 수 시간~수 일 지속 | A·B: "관찰되기도 한다"(일부라는 뜻). C: 건조함·가려움·얼굴 부기도 동반될 수 있다 |
| 중간 (비중 수치 없음) | 여드름처럼 보이는 구진·고름 뾰루지(농포), 모공이 두드러짐 | B 정의: "간혹" 관찰. A·B: 시일이 지나며 나타나는 단계. C는 특징 증상으로 함께 묶음. N: 여드름과 달리 면포(블랙·화이트헤드)는 없다 |
| **드묾** | 코가 두꺼워지고 울퉁불퉁 커짐(딸기코·비류), 큰 염증성 결절·조직 증식 | A·B: "소수의 환자"에서. C: "일부에서는". N: 심하면 |
| **드묾** | 두피까지 번짐 | A·B: 좀 더 진행된 상태에서 |
| 합병증 (범위가 넓음) | 눈 증상 — 눈꺼풀염·결막염·각막염 등. 심하면 시력 위험 | B: 환자의 **3~58%**에서 보고(출처 안에서도 범위가 매우 넓어 메인/드묾 판정에 쓰기 어렵다). A: 각막 천공으로 실명까지 갈 수 있음. B: 초기에 눈 증상만 있으면 진단이 늦어진다 |
| 합병증 | 이마·미간·눈꺼풀·코·뺨이 눌러도 들어가지 않게 붓는 부종 | A·B |

환자층 (A·B 같은 내용): 10대 이후 모든 연령, **30~50대에 가장 흔함**, 여자에게 더 자주 생기지만 **심한 증상은 주로 남자**. 비율 수치는 없다.

DA 쪽에서 읽으면: 대부분이 겪는 것은 "붉음 + 실핏줄"이고, 딸기코·눈 증상은 소수다. 다만 이건 의학 페이지의 서술이고, 환자가 실제로 무엇을 가장 괴로워하는지(체감 비중)는 유튜브 자막 실패로 재지 못했다.

## 5. 방법과 한계

**방법**
1. 유튜브: `프로그램/아웃풋/da-planning/scripts/yt_card.py`로 검색어 3개(`주사피부염`·`주사피부염 증상`·`주사피부염 관리`) → 후보 영상 34개 → 자막을 받아 증상·해결 행동 키워드를 언급한 영상 수를 세려 했다.
2. 나무위키: 「주사(질병)」 문서를 읽고 내 말로 요약. `주사(피부질환)`·`주사피부염` 문서는 없고, `딸기코`가 이 문서로 넘어간다.
3. 의학 페이지: 구글 `주사피부염 원인` 상위의 학회·대학병원 페이지 3개(A·B·C)를 열어 나무위키와 대조했다. 어긋난 점 3개(시술 LDM vs 레이저·IPL, 스테로이드 예외, 원인 서술)는 `나무위키-요약.md`에 있다.

**한계**
- **환경 사고**: 같은 시각에 Claude 쪽과 Codex 쪽이 같은 PC(같은 IP)에서 유튜브 자막을 요청해 둘 다 막혔다(Claude는 `IpBlocked`, Codex는 HTTP 429). 그래서 이번 회차의 핵심인 증상·해결 행동 비중(1·2절)이 비어 있다. 차단을 우회하는 시도(프록시 등)는 하지 않았다.
- 4절의 메인/드묾 구분은 의학 페이지의 서술 표현에 기댄 것이다. 환자 체감 비중이 아니다.
- A는 2012년 글이라 바르는 약에 이버멕틴이 없다(B·C·N에는 있음). 최신 치료는 B·C를 우선해 읽어야 한다.
- 나무위키는 누구나 고치는 문서다. 의학 출처와 어긋나는 부분(LDM 권장, 스테로이드 절대 금지)은 의학 출처 쪽을 우선한다.
- 네이버 검색량(2절 참고표)은 결핍 조사 경로가 아니라 시장 쪽 자료다.
- 구글 검색 화면에서 본 것(맨 위 광고 1개가 블로그 체험기형, 관련 검색어에 `완치 사례`·`완치 후기`·`디시`·`더쿠`)은 `나무위키-요약.md`에 남겼다. 완치를 찾는 수요와 커뮤니티 경험담 수요의 신호이지만 비중은 아니다.
