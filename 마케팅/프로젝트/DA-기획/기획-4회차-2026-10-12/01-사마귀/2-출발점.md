# ② 출발점 — 사마귀

- 목소리: `마케팅/프로젝트/DA-기획/기초분석/사마귀/목소리-비중표.md` (파일 20개, 피부 사마귀 단위 468개 — 출발점보다 먼저 셌다)
- 시장 카드: `마케팅/프로젝트/DA-기획/기초분석/사마귀/시장카드.md`

## 결론
- **출발점: 열린 시장 — '사마귀 전용 홈케어'**(사마킬 · 사마귀 전용 율무 크림 · 게재 310일 · 라이브러리 ID 2084336718636949 · 브랜드 검색 6,720, 2026-10-12).
- **상징원은 두지 않는다(④-01 상징 없는 기획).** 아래 세 후보가 모두 여덟 줄 중 하나 이상에서 걸렸다. 1초 장치는 원인 재정의('사마귀는 만지면 번진다 → 덮어서 가둔다')와 보이는 증거 장면('일주일 뒤 떼면 하얗게 들린 겉')이 맡는다.
- 당위: 덕테이프 요법 연구(덮기 85% · 냉동치료 60%, 2002)를 근거로 쓰고, 일반 테이프와 가르는 원료 겹(각질 녹이는 젤)을 더한다(사장님 파라핀 방식 — P6275).
- **범위 단계 1** — 같은 결핍(사마귀), 사마킬이 메타에서 연 '사마귀 전용 홈케어' 부류. 바꾼 축은 사용 장면(매일 바르는 크림 → 일주일에 한 장 덮개)과 당위(율무 → 덮기)다.

## 처음부터 뺀 것 (사장님 판정 · 정본)
- 냉동치료(목소리 1순위 40.2%) — 비렌느·디크솔 본진, 티눈 냉동 6점 '겹침'(P6273). 여덟 줄로 봐도 (사)에서 걸린다: 같은 '바르는 냉동'은 비렌느(7,440)를 사면 된다.
- 율무 — 사마킬(8점, P6257)이 냉동치료의 반대편으로 이미 쓴다.
- 레이저(19.9%) — 지지는 방식을 화장품이 거부감 없이 못 낸다(④-59, P6252).
- 가다실(3.6%) — 백신의 면역을 화장품이 못 낸다((나)).
- 뜸(2.4%) — 사마귀 전용 인식이 없다(④-21, 쑥뜸 12,010은 관절·냉증).

## 후보 A — 엔드와츠(EndWarts, 개미산 사마귀 펜·액)
| 줄 | 판정 | 내용 |
|---|---|---|
| (가) 낫게 하는 방식 | ○ | 개미산을 사마귀에 콕 묻히면 속부터 말라 하얘지고, **일주일에 한 번**씩 몇 번 하면 뚜껑처럼 떨어진다. 사마귀에 듣는다(판매처 설명 평균 4~5회, 포름산 사마귀 치료 소개 — 스위스 피부과지 2015). 목소리 "약국사마귀치료제 다해봤는데 실패했음. 그런데 엔드와츠쓰고 병원없이 바로 완치함" |
| (나) 화장품이 내나 | × | 개미산은 화장품에 보존제로만 낮은 농도가 허용된다(화장품 안전기준 — 한도 재확인 필요). 한 번 묻혀 말려 죽이는 일을 화장품 산으로는 못 낸다 |
| (다) 그 상징원만의 것 | ○ | '일주일에 한 번'은 엔드와츠만의 것(다른 사마귀약은 매일, 냉동치료는 병원 2~3주) |
| (라) 부류 vs 대표 | ○ | 대표 — 엔드와츠 6,450(자동완성 '직구·구매·뚜따·족저사마귀 엔드와츠'). 약국 거 다 실패한 사람이 직구하는 최상위 |
| (마) 원본 주인 | ○ | 스웨덴 특허 의료기기(CE), Meda 유통. 국내 정식 수입은 확인 못 함 — 자동완성 '직구' (https://www.rosenfluh.ch/media/dermatologie-aesthetische-medizin/2015/03/Ameisensaure_zur_Warzenbehandlung.pdf · https://www.gurkerl.at/en-AT/15546-endwarts-endwarts-solution-against-warts) |
| (바) 만드는 법 | × | 고농도 개미산은 화장품 OEM으로 못 만든다(의료기기·의약품 영역 — ⑥-08·⑥-25) |
| (사) 대표 대안보다 살 이유 | × | 엔드와츠는 직구하면 되고, 약국 티눈액(살리실산 약)이 더 세다 — 화장품판이 이길 줄이 없다 |
| (아) 원료·인증 | × | 핵심 원료(개미산 고농도)를 화장품 원료로 못 쓴다 |
- 닮은 길: 5(사람들이 아는 약 이름을 다른 제형으로 — 지엘·올레놀샷, 참신함 소진). 약 성분 없이 이름·바르는 법만 옮기면 쥬블린 1점(P6268) 함정이다.
- **버림** — (나)(바)(사)(아).

## 후보 B — 베루말(Verrumal, 피부과 처방 사마귀 물약)
| 줄 | 판정 | 내용 |
|---|---|---|
| (가) 낫게 하는 방식 | ○ | 하루 2~3번 붓으로 바르면 살리실산이 사마귀 각질을 녹이고 플루오로우라실(항암 성분)이 자라지 못하게 해, 겉이 하얗게 들떠 떨어진다. 목소리 "산성이 강한걸 매일 한번씩 발라주는건데 허옇게 뜨다가 몇달 지나면 씻다가 알아서 떨어질거임" |
| (나) 화장품이 내나 | △ | 각질 녹이는 산(락틱애씨드·우레아)으로 '하얗게 불어 벗겨짐'은 일부 낸다 |
| (다) 그 상징원만의 것 | × | 붓 달린 병·하얀 막·하얗게 떨어짐은 신신 티눈액·성광 티눈액과 같다(바꿔 넣기 실패 — 쥬블린 '붓 병 제품은 수없이 많다', P6268) |
| (라) 부류 vs 대표 | ○ | 대표 — 베루말 4,090(자동완성 '베루말 약국·족저사마귀 베루말' — 처방 없이 사려는 사람) |
| (마) 원본 주인 | ○ | 독일 Almirall Hermal GmbH(스페인 알미랄 계열), 1978년 허가 처방약. 국내 수입사 미확인 (https://medikamio.com/de-de/medikamente/verrumal-5-mgg-100-mgg-loesung-zur-anwendung-auf-der-haut/pil) |
| (바) 만드는 법 | ○ | 약 성분을 빼면 OEM 처방 가능 |
| (사) 대표 대안보다 살 이유 | × | 처방 "14,000원정도"(목소리)와 약국 티눈액(수천 원)이 있다 |
| (아) 원료·인증 | × | 플루오로우라실 0.5%·살리실산 10%는 의약품 성분이다 |
- 닮은 길: 5 · 쥬블린 함정.
- **버림** — (다)(사)(아).

## 후보 C — 덕테이프 요법(미국, 6일 덮었다 떼기)
| 줄 | 판정 | 내용 |
|---|---|---|
| (가) 낫게 하는 방식 | △ | 사마귀를 테이프로 6일 덮어 두고, 떼서 물에 불린 뒤 문질러 벗기고, 하룻밤 뒤 다시 붙이기를 최대 두 달. 대중어로 "덮어 두면 숨이 막혀 하얗게 불고 겉부터 떨어진다". 3~22세 51명 연구에서 85%가 없어졌고 냉동치료는 60%였다(Focht 2002, 미 육군 병원). 다만 뒤 연구 2건은 차이가 없었다 — 듣는지는 경고로 둔다. 목소리 "아예 테이프로 덮어버리니까 사마귀 본체가 잘 떨어져나감" |
| (나) 화장품·생활용품이 내나 | ○ | 약이 아니라 방법이라 덮기는 그대로 옮겨진다. 거부감 없음(아프지 않다) |
| (다) 그 상징원만의 것 | ○ | '6일 덮었다 떼기' 의식은 덕테이프 요법만의 것(냉동치료·율무·베루말을 넣으면 말이 안 된다). '붙여 두면 하얗게 분다'는 티눈밴드와 겹친다 |
| (라) 부류 vs 대표 | × | 덕테이프는 다이소에도 있는 공구 테이프 부류다(버티컬 마우스 1점과 같은 결 — P6265). '덕테이프 사마귀' 검색 0, 덕테이프 2,250(자동완성 '덕테이프 사마귀 원리'만) |
| (마) 원본 주인 | ○ | 미국 공개 연구 — 주인 없는 치료법(A급), 한국 총판 해당 없음 (https://www.aafp.org/pubs/afp/issues/2003/0201/p614.html) |
| (바) 만드는 법 | ○ | 패치 공장 기존 사양(원단·원형 타발) |
| (사) 대표 대안보다 살 이유 | × | 그대로 빌리면 다이소 덕테이프(2천 원대)·약국 신신티눈밴드(약)를 사면 된다 — 원료 겹 없이는 "그거 사지"(파라핀 3점, P6275) |
| (아) 원료·인증 | ○ | 원료가 필요 없다(원료 겹을 더하면 범용 화장품 원료) |
- 닮은 길: 4(유행하는 대안의 반대편 — 사마킬) · 8(원인을 막는다 — 프렉탈 9점).
- **상징원으로는 버림** — (라)(사). 비싸지도 유명하지도 않아 ④-04의 상징원 조건도 못 채운다. → **당위 장치로만 남긴다**(덮기 의식 + 연구 숫자 + 원료 겹으로 (사)를 다시 세운다).

## 왜 이 결핍엔 빌릴 새 상징이 없나 (되먹임)
사마귀에서 화장품이 그대로 낼 수 있는 방식은 '차갑게(냉동)'·'율무'·'덮기' 셋뿐이다. 앞의 둘은 비렌느·디크솔·사마킬이 쓰고, 산으로 녹이는 쪽(베루말·엔드와츠·티눈액)은 약국 약이 화장품보다 세고 싸다. 그래서 이번 기획은 상징 없이(④-01) '덮기'의 원인 재정의와 보이는 증거로 간다. 사장님 판단 칸에 '이번 회차 넘김'을 ○/×로 올린다.
