# 2회차 지시문 (2026-10-12)

1회차 지시문(`../../기획-1회차-2026-10-11/_지시문/`)을 고쳐 썼다. 바뀐 것은 1회차 사장님 판정(P6251~P6255)에서 나왔다.

- `planner-prompt.md` — 기획자 1단계 공통 틀(`planner-0N-*.md`는 결핍별로 채운 것). 핵심 코어 = 상징원이 낫게 하는 방식(④-59), 바꿔 넣기 시험(④-58), 출발점에서 후보 2~3개를 세 줄로 비교, 좋은 초기획 기준(1회차 탈모 오프로폼).
- `핵심옮김-검사.md` — 새 단계. 1단계 직후 다른 Claude 2명이 ④-58·④-59를 따로 판정한다. 탈락이면 기획자가 상징원을 바꾼다.
- `planner-phase2.md` — 2단계. 핵심 옮김 검사 결과를 붙이고, 판단 칸을 처음부터 두 부분으로 쓰고, `## 사장님 카드`(700~850자, P6263)를 `## 사장님 채점` 바로 앞에 쓴다.
- 남이 검사·매대 표시 지시는 1회차처럼 `프로그램/아웃풋/da-planning/references/남이검사-지시문.md`·`매대비율-지시문.md`를 쓴다.
