- 검사자 B(전문 `C:/claude/LLM-WIKI/마케팅/프로젝트/DA-기획/기획-2회차-2026-10-12/01-족저근막염\핵심옮김-B.md`)

   - 기준 예(무릎, 730자): `- 결핍: 계단·일어설 때 무릎이 시큰한 50~70대(검색 월 22,780). 운동 27% · 병원 22% · 관절 영양제 11% 순으로 해결하려 합니다.` / `- 제품: 콘드로이칠(가칭) — 무릎용 투명 온열 젤 100ml 펌프 병. 뚜껑 안 가루 칸의 콘드로이친이 처음 '딸깍' 누를 때 젤에 퍼져 '원료가 진짜 들었다'를 보여 줍니다. 바르고 1분 뒤 은은하게 따뜻해집니다. 하루 2번 무릎에 30초 문지르는 OEM 화장품이고, 철갑상어 원료는 직접 구해 대며 용기는 범용 가루 캡부터 찾습니다.`
5. `PYTHONIOENCODING=utf-8 python check_plan.py "<기획 폴더>\기획서.md"`를 돌려 위반 0이 될 때까지 고친다. 경고는 남아도 된다(사장님 판단 칸에 있으면).
6. 마지막 답은 이 형식 그대로:
```
- 한 줄: <…>
- 제품 이름(가칭): <…>
- 상징원 → 핵심 코어 → 옮긴 칸: <…>
- 사장님 판단 칸 경고: <개수와 한 줄씩>
- check_plan: 위반 0 / 경고 n
- 만든 파일: <경로들>
- 스스로 보는 약점 하나: <…>
```

지킬 것은 1단계와 같다(기획 폴더·기초분석 폴더·사전 파일만 쓴다, raw·정본·스크립트·다른 기획 폴더는 고치지 않는다, git 안 쓴다, API 키 파일은 열지 않는다).
