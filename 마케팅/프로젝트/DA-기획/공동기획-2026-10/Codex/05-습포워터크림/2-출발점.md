# 습포 워터크림 — 출발점

**결론: 통합 실측에서 확인된 민감·홍조 기초 화장품 시장 안의 1단계 후보다.** 얼굴 붉어짐을 중심으로, 기기와 쓰는 쿨링 겔에서 기기 없이 얹는 O/W 수분 크림으로 사용 장면과 제형을 바꾼다. 부위를 쪼개거나 새 질환 시장으로 건너뛰지 않는다. **현재 형식 검사 결과는 Codex/문서검사-결과.json 참조**다.

주 출발점은 **오래 돈 광고 하나**다. 온천수·아벤느 인지 자료는 제품의 상징 설계를 위한 보조로만 둔다.

## 통합 시장카드와 확인 범위

현재 근거는 실제 생성된 [홍조 시장카드](<C:/claude/LLM-WIKI/마케팅/프로젝트/DA-기획/공동기획-2026-10/Codex/시장카드/홍조/시장카드.md>)다. 통합 카드의 기존 공통 상품 조사·영상 분석과 새 Meta 수집·Naver 실측을 재사용했다. 이번 갱신에서 원자료를 새로 수집하거나 카드 밖 파일을 추가 열람하지 않았다.

광고 기간은 카드의 **2026-10-10 활성 광고 측정값**이다. 카드는 원자료의 시작일과 기준일 차이를 사용했다고 기록한다. 개별 시작일은 카드에 기재되어 있지 않아 날짜를 임의로 역산하지 않는다.

| 실제 기초 제품 | 활성 기간 | 라이브러리 ID | 쓰는 근거와 한계 |
|---|---:|---|---|
| 메디티엔 트루멜로디 크림·예뻐질시간 페이지 | 157일 | 2009813233156242 | 예민한 피부를 상대하는 인접 크림. 기간은 매출·ROAS 확인이 아님 |
| 레이어랩 판테놀 세럼 | 69일 | 28709824981951984 | 민감·홍조 기초 시장과 수분을 얹는 장면의 근거. 해당 세럼 매출은 미확인 |

통합 Meta 수집은 본 수집 5키워드 542장+추가 2키워드 200장이다. 다른 결핍·중복·무관·병원 광고가 섞였으므로 **742장을 홍조 경쟁상품 수로 쓰지 않는다.** 추가 수집은 code1675004·truncated=true로 첫 화면만 확보했다. 수집된 범위는 측정 완료, 전수 확보·새 영상 3~5편의 화면/음성 분석·국내 브랜드 제외 소비자 담화는 미완료다.

## 판매·인지의 통합 실측

**2026-10-10 Naver 검색광고 API 최근 30일, PC+모바일**의 측정 기록이다. 기존 문서의 21:00 수치와 통합 카드가 일치하는 값을 사용했다. 닥터콤마 추가 브랜드 검색은 카드에서도 미측정이다. 표기 변형 전수 중 최대값인지 추가 확인하지 않았다.

브랜드 검색량을 판매 판정의 자료로 사용하되, 매출·이익·재구매·특정 광고 성과는 계속 미확인이다. 통합 카드의 **레이어랩 연간 검색 묶음은 11월 24.12129에서 9월 13.10687로 45.7% 하락**했다. 브랜드·묶음의 하락 신호이며 특정 SKU의 수명 종료나 홍조 시장 전체 감소로 확정하지 않는다.

**연간 검색 추이는 측정 완료다. 관측 구간에서는 겨울·봄이 강하며 여름에도 지수가 남는다.** 반복되는 계절 패턴·질환 계절성·최적 런칭월·소비자 구매 강도는 미확인이다. 여러 단어 묶음은 같은 사람의 검색을 중복 포함할 수 있다. 쇼핑 클릭 지수와 평균하거나 서로 대체하지 않는다.

실제 런칭일·개발 기간은 미정이다. 겨울·봄 기회를 노릴 경우 공급·시제품·시험 소요로 역산하되, 검색 관측만으로 지금이 시즌 밖이라고 기각하지 않는다.

## 기존 영상에서 가져오는 것

통합 카드는 공통 14초 허브쿨 겔 영상의 프레임/OCR 분석과 공통 Gemini 5편 자료를 구분해 재사용했다. 투명 겔+홈 디바이스·특허성분·홍조열감 케어·할인과 패드 얹기 장면이 확인돼 있다. 패드 습포는 이미 경쟁사 장면에 있어 독점 틈새라고 부풀리지 않는다.

**11.04의 단위·시험 조건은 미확인**이고 상품 조사 4.04%와도 다르다. 11.04°C로 쓰거나 우리 제품의 임상으로 차용하지 않는다. 생산 차별은 [상징설계](<C:/claude/LLM-WIKI/마케팅/프로젝트/DA-기획/공동기획-2026-10/Codex/05-습포워터크림/4-상징설계.md>)의 실제 제형 비교가 성립해야 한다.

## 단계별 결론

- **기초분석:** 활성 광고·월 검색량·연간 검색 추이는 통합 실측 반영 완료. 새 영상 분석·소비자 행동·매출·효능은 미확인이다.
- **출발점:** 통과 이유는 **민감·홍조 기초 제품4개의 오래 돈 활성 광고** 하나다. 브랜드·상징 검색은 보조이며 시장의 존재와 이번 제품의 판매 성공을 구분한다.
- **범위:** 같은 시장의 얼굴 붉어짐에 제형·사용 장면을 바꾸는 1단계로 유지한다. 카드가 언급한 시술 후 민감 피부와 주사피부염을 같은 원인이라고 단정하거나 타 부위 시장으로 확장하지 않는다.
- **시점:** 검색 추이는 확보됐지만 개발 일정·실제 런칭 창은 미정이다. 다른 후보·전체 광고 수집 범위는 재조사하지 않는다.
