# 구강·치아미백 후보 — 공식 근거와 미확인 분리

## 1. 결론과 조사 경계

**노란 자연치·착색을 실제로 밝게 하는 산화 미백을 유지하면 구강 후보를 계속 조사할 근거가 있다.** 국내 저농도 의약외품과 치아미백 OEM은 실재한다. 다만 우리 신제형의 허가, 미백 효과, 저자극 우위, 3~5만원 구매 의향, 10% 원가, MOQ 1,000은 아직 확인되지 않았다.

제조 차별 제안은 **A: 사용 중 pH를 유지하는 완충 배합 산화 젤**, **B: 사용 직전에 서로 다른 두 제형을 혼합하는 산화 젤**이다. A부터 기술 가능성을 확인할 가치가 있고, B는 국내 저농도 제조·허가 근거가 더 부족한 예비 후보다. 기존 젤·패치에 이름만 붙여서 출시할 수 있다는 결론은 아니다.

- 읽은 내부 기준: [핵심-맥락](C:/claude/LLM-WIKI/핵심-맥락.md), [DA 기획 단계별 규칙](C:/claude/LLM-WIKI/마케팅/wiki/syntheses/DA%20기획%20단계별%20규칙.md)의 Git 동결본 c861d17, [DA 기획 사망 사례집](C:/claude/LLM-WIKI/마케팅/wiki/syntheses/DA%20기획%20사망%20사례집.md). 위키 검색은 마케팅 index·concepts·entities·syntheses와 별칭을 포함했다.
- 위키의 판단 규칙은 내부 1차 출처다. 아래 의학·규제·가격·제조 정보는 **(위키에 없음 — 외부 공식 근거)**로 보강한 조사이며, 검증된 우리 실전 노하우로 승격하지 않는다.
- 현행 독립 5안 중 구강 큰시장 후보만 조사했다. 시장이 열렸다는 정량 판정은 부모 조사에 남긴다. 공식 상품 존재는 매출·브랜드 검색량·시장 크기 증명이 아니다.
- Meta·NaverCLI·YouTube를 사용하지 않았다. 금지된 다른 조사자 폴더·광고소재 스크립트를 열지 않았다. 발주·견적 요청·외부 메시지는 하지 않았다.
- 가격은 공개 공식 페이지의 표시값이다. 측정일은 모두 **2026-10-10 KST**이며, 실제 주문·병원 결제·실험은 하지 않았다. 웹 캐시·추출값이므로 결제 시점 가격·재고까지 확인된 것은 아니다.

## 2. 강한 욕구와 마지막 장면

**주문제: 양치해도 노랗거나 착색돼 보이는 자연치의 색을 밝게 하고 싶다.** 시림·잇몸 자극은 미백을 지속하기 어렵게 만드는 부문제다. “순해서 좋다”만으로 주욕구를 바꾸지 않는다.

### 실제 작동 / 소비자 인식 / 원하는 결과

| 구분 | 확인된 근거 또는 조사 가설 |
|---|---|
| 실제 작동 — 확인 | 과산화수소 또는 카바마이드퍼옥사이드에서 생기는 산화 작용으로 착색 성분의 색을 변화시킨다. 생활 미백도 이 핵심을 사용할 수 있다. [식약처 자료 기반 정부 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148898995) |
| 소비자 인식 — 가설 | “치과 미백에서 쓰는 산화 젤을 집에서 쓴다”는 설명이 결과를 연상시킬 가능성. 상징의 국내 유명도·이해도는 정량 검증 미확인이다. “치과와 같은 효과·속도”라고 해석시키면 안 된다. |
| 마지막 장면 — 후보 평가 목표 | 정해진 사용 과정을 마치고 젤을 씻은 뒤, 같은 조명·촬영 조건에서 **자연치 색 자체가 전보다 밝아져 있음**. 새 제형에서 이 장면이 실제 달성되는지는 미확인이다. |
| 마지막 장면을 대체하지 못함 | 치태를 색으로 표시하기, 구취 줄이기, 거품·따끔함·기포, 흰색 막·보라색 보정으로 잠깐 하얗게 보이기. |

**스케일링→착색 표시 젤은 사망을 유지한다.** 치석·치태를 표시하거나 제거하는 것과 노란 치아 자체를 밝게 하는 것은 동일한 약속이 아니다. 내부 사망 사례의 마지막 장면 불일치를 그대로 적용한다.

외부 근거도 표면 세정과 산화 미백을 구분한다. ADA는 기계적 세정이 주로 표면 착색을 줄이고, 과산화물 미백은 치아 색에 화학적으로 작용한다고 설명한다. 보철물은 자연치와 같이 밝아지지 않는다. 따라서 모든 노란 치아, 크라운, 실활치까지 같은 결과를 약속할 수 없다. [ADA 공식 Whitening](https://www.ada.org/resources/ada-library/oral-health-topics/whitening)

### 문제 언급 N: 문서 수이지 유병률이 아니다

**(위키에 없음 — 외부 공식 근거에서의 추론)** 의약외품이라는 사실 자체가 치아미백 시장의 사망 근거는 아니다. 이미 국내 제조·상품이 존재한다. 반대로 해외 임상 제형·농도가 국내 허가와 동일하다는 보장은 없다. 내부 “의약외품 벽” 요약은 제품별 제조·허가 검토와 분리할 필요가 있다. 이번에는 위키를 수정하지 않았다.

**OEM 실재 확인 ≠ 우리 신제품 생산 확정.** 필코의 “소량 가능”을 1,000개 확약으로 읽을 수 없고, 2020년 공시를 2026년 견적으로 쓸 수 없다.

필코가 적은 “시리지 않음”, “과산화수소 부작용 없음”, “미백 효과 더욱 뛰어남”은 **제조사 주장**이다. CP도 과산화수소를 방출하므로 부작용이 원리상 없다는 결론은 성립하지 않는다. 새로운 우리 제형의 광고 근거로 쓰지 않는다.

### 순한 산화 미백: 직접 임상 근거와 적용 한계

[2025년 원저 무작위 임상시험](https://link.springer.com/article/10.1186/s12903-025-07026-7)은 **22명**, 2주, 매일 **6~8시간 트레이 사용**으로 3% 과산화수소(HP)와 8% CP 제품을 비교했다. 색 변화 ΔE00는 HP **5.39±2.50**, CP **4.75±2.25**였고 HP가 더 컸다(p<0.05). CP의 시림은 더 낮았지만 양쪽 모두 가벼운 시림이 있었다. 두 상품의 pH·배합도 달라 CP라는 원료 하나의 인과 효과로 분리할 수 없다.

- **확인:** 낮은 농도에서도 실제 산화 미백 효과를 보인 특정 사용 조건이 있다. 이 연구에서는 덜 시린 쪽의 색 변화가 조금 작았다.
- **미확인:** 우리 완충 젤을 30분 쓰면 같은 결과가 나오는지, CP가 항상 더 순한지, 빠른 미백과 낮은 자극을 동시에 달성하는지.
- **경고:** 접촉 시간을 늘리면 사용 부담·누적 노출도 커진다. 임상 연구의 6~8시간을 국내 생활 미백의 임의 사용법으로 옮기지 않는다. 용법은 최종 허가 제품 기준이다.
- **순함의 목표:** 산화 미백 효과를 유지하면서 자극을 낮추는 것. 무효과·표면 코팅을 “순한 미백”으로 포장하면 마지막 장면에서 실패한다.

## 6. 제품 후보 2안 — 제조 차별 제안, 검증 전 가설

둘 다 유명 상징 후보는 **치과 미백**이다. 공식 시술·가격·산화 장치의 존재는 확인했으나 국내 인지도·브랜드 검색량은 부모 조사 대기다. 다음 한 문장들은 설명 가설이며 최종 상품명·광고 카피가 아니다.

### A. 완충 배합 생활 미백 젤 — 우선 기술 검토

**상징+장치 한 문장:** “치과 미백의 산화 젤을, 사용 중 pH가 유지되도록 완충 배합한 생활 미백 젤로 옮긴다.”

## 7. 경제성·하드·경고를 분리한 인계

### 경제성 — 목표 수치와 실제 확인을 섞지 않음

| 항목 | 수치 | 상태 |
|---|---:|---|
| 목표 소비자가 | 30,000~50,000원 | 사용자 과제 조건. 소비자 수용 가격·매출 실증 **미확인** |
| 목표 원가율 | 판매가의 10% | 목표일 뿐. 제조사 견적 **미확인** |
| 목표 제품당 원가 | 3,000~5,000원 | 단순 산술. 실제 원료·충진·포장·검사·불량·허가 비용 배분 미확인 |
| 목표 MOQ | 1,000개 | 실제 수락 조건 **미확인** |
| 목표 수준의 제품 원가 합계 | 3,000,000~5,000,000원 | 1,000개×목표 원가 산술. 개발·허가·임상·배송·VAT·광고비 포함 총예산 아님 |
| A·B 견적, 납기 | 없음 | 연락·발주·견적 요청을 하지 않음 |

B는 두 제형의 제조·검사·충진 및 혼합 오류 관리가 필요하므로 비용 경고가 더 크다는 **추론**만 가능하다. 비용이 목표보다 높을 것이라고 이미 확인된 것처럼 쓰지 않는다.

### 하드: 성립하면 중단 / 현재 미확인과 구별

| 하드 게이트 | 적용 |
|---|---|
| 핵심·마지막 장면 불일치 | 스케일링→착색 표시 젤, 표면 보정만으로 실제 산화 미백을 약속하는 안은 **이미 탈락**. |
| 기존 제품 이름만 변경 | 기존 CP 젤·패치를 “치과 미백”으로 재명명하고 배합 차이가 없다면 **탈락**. A/B는 생산 차별 제안이며 실증 전에는 이 게이트를 통과했다고 표시하지 않는다. |
| 실제 불법·불가능이 확인됨 | 필요한 분류·허가를 충족할 수 없거나 허용 범위를 넘는 제품을 생활 의약외품으로 팔려는 안은 **탈락**. 현 단계 신제형 허가는 미확인이므로 그 자체를 불법 확정으로 처리하지 않는다. |
| 자체 의료기기 사업 의존 | LED·광선조사기 자체 개발·허가를 필수로 붙이는 방향은 내부 금지 기준에 걸림. 두 후보는 젤 제형으로 검토. |

### 경고·보완: 곧바로 사망 판정하지 않음

- **허가 경로·제조 차별·신제형 임상·시장 개방성 미확인:** 비교 선택 전에 보강해야 할 공백. 공식 제품·공시만으로 판매 성공을 선언하지 않는다.
- **효능/자극 tradeoff:** 저농도·CP·완충이라는 말만으로 동일 속도·무자극을 약속하지 않는다.
- **가격 프리미엄:** 공식 젤 24,900~29,800원 대비 3~5만원을 받을 이유가 실증돼야 한다.
- **10% 원가/MOQ 1,000:** 실제 견적 전 경고. 목표 이탈을 자동 하드 탈락으로 승격하지 않는다.
- **운영 부담:** 식약처 안내상 민감성·교정·연령·구강 상태 등의 사용 제한과 자극 대응이 존재한다. 새 제형의 허가 표시·사용 대상·중단 기준이 필요하다.
- **부모 인계 공백:** 국내 소비자 욕구 원문·시장/브랜드 정량·상징 유명도. 본 조사에는 광고·검색량·유병률 수치를 만들지 않았다.
