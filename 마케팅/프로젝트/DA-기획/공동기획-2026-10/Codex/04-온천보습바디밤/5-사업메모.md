# 온천 보습 바디밤 — ⑤ 사업메모

## 제품

- 무엇을: 프랑스 온천수를 넣고 펼칠 때 물방울이 드러나며 보습막을 남기는 워터브레이크 바디밤 200g. 온열 없음·에탄올 무첨가 설계 목표.
- 누구에게: 큰 바디보습 시장 안에서 건조 때문에 몸을 긁는 불편을 겪는 사람. KP를 겨울용으로 바꾼 기획이 아니다.
- 어떻게 쓰게 해서: 씻은 뒤 몸피부에 1회 4g을 펴 바르는 가정. 한 통 50회이며 실제 적정량·결과는 시제품 확인 전이다.
- 얼마에: 단품 39,000원＋배송비 3,000원. 2개 10% 할인 70,200원·무료배송. 판매 정책안이며 주문·성과 실측은 없다.

## 사업 결론

**판매 정책안은 단품 39,000원＋배송 3,000원, 2개 10% 할인 70,200원 무료배송이다.** 2개 구성은 가격을 올려 위험을 줄이는 안이 아니다. 할인·배송 부담을 실제 산식에 넣는다.

1회 4g이면 200g 한 통 50회, 2개 100회라는 가정이다. 1일 1회일 때 50일/100일로 환산할 수 있으나 실제 적정량·사용 주기·재구매는 미확인이므로 ‘2개월 세트’처럼 기간을 확정하지 않는다.

## 계산 입력 — 모두 견적전 민감도 가정

| 기호·항목 | 적용값 / 의미 |
|---|---|
| P | 부가세 포함 **상품가**. 단품 39,000원 / 2개 70,200원 |
| 고객 배송비 | 단품 3,000원 / 2개 0원 |
| C | 부가세 별도 제조 목표 원가. **개당 3,550 / 4,200 / 5,000원**, 2개 주문은 2배 |
| 출고 물류 | 주문당 3,000원. 제품 2개라고 2배 계산하지 않음 |
| 결제 비용 | 고객 결제액(P＋배송비)의 3.3% |
| 상품가 차감 | P의 3%. 공통 산식상의 비용 가정이며 실측 반품률 아님 |
| 광고 ROAS | **상품 매출 P만 / 광고비**. 배송비를 광고 매출에 넣지 않음 |
| 개발 고정비 D | 별도 지급 **80만원 목표 예시**. 확정 견적·인체적용 시험/허가 예산 아님 |

기존 보고서 금액을 이번 공통 계산에서는 **VAT 별도 C의 목표**로 놓았다. 공급사 세금계산서·단가가 확인됐다는 뜻이 아니다. 개발 고정비를 제조원가에 넣고 다시 더하지 않는다.

## 공통 산식

- 첫 주문 광고전 기여＝(P＋고객 배송비)/1.1－C－출고 물류 3,000－(P＋고객 배송비)×0.033－P×0.03.
- 광고전 손익분기 ROAS(BE)＝P/광고전 기여. 아래 표는 백분율로 표기한다.
- 광고 170% 시 광고비＝P/1.7, 광고후 기여＝광고전 기여－P/1.7.
- 광고 200% 시 광고비＝P/2, 광고후 기여＝광고전 기여－P/2.
- 고정비 회수 주문수＝80만원/광고후 기여를 올림. 광고후 기여가 0 이하이면 이 방식으로 회수 불가.

2개 주문은 주문당 기여가 커져도 **개당 기여는 낮고 BE ROAS는 높다**. 할인·무료배송의 비용을 반영한 결과다. 이것만으로 객단가 상승이 사업 위험을 해결했다고 보지 않는다. 170%·200%는 성과 예측·필수 통과선이 아닌 민감도 조건이며, 재구매·350% ROAS를 붙여 유리하게 만들지 않았다.

## 개발 고정비 회수 — 제조 재고비와 분리

| 중심 원가 4,200원 | 광고후 기여 / 주문 | D=80만원 회수 최소 주문 | 필요한 제품 수 |
|---|---:|---:|---:|
| 단품·170% | 5,485원 | 146주문 | 146개 |
| 단품·200% | 8,926원 | 90주문 | 90개 |
| 2개·170% | 6,701원 | 120주문 | 240개 |
| 2개·200% | 12,896원 | 63주문 | 126개 |

올림은 반올림 전 기여로 계산했다. 제조 재고비는 판매 때 C로 이미 차감되므로 이 표에서 다시 고정비에 더하지 않는다. **개발 고정비 회수 예시**이며 전체 창업비 회수·순이익·현금흐름 보증이 아니다.

## 초도·원가 목표와 현금 지급 한계

| 제조 구성 | 개당 목표, VAT 별도라는 이번 계산 가정 |
|---|---:|
| 온천수·보습 원료·유화 시스템 | 1,900~2,800원 |
| 기성 PP 단지·뚜껑 | 650~850원 |
| 라벨·기본 포장 | 250~350원 |

| 합계 목표 | **3,550~5,000원**, 공급 견적 미확인 |

- MOQ **1,000개 가정**, OEM 확정 MOQ 아님. C=4,200원 제조 공급가 420만원＋개발 D 목표 80만원＝500만원의 견적전 계획이다.
- 제조 공급가 VAT 42만원을 더하면 **542만원＋개발 고정비의 VAT 처리 차액**이라는 현금 지급 가정이다. 개발비 세금 조건은 미확인.
- 전체 C 범위에서는 제조 공급가＋D가 약 435~580만원, 제조 VAT를 포함한 현금 가정은 약 **470.5~630만원＋개발비 VAT 차액**이다. 상단은 600만원 목표를 넘을 수 있다.
- 기존 400~600만원은 **견적전 개발·제조 목표 예산**이다. 현금 지급이 반드시 이 안에 끝난다는 뜻이 아니다.
- **인체적용 임상·기능성 검토·허가/심사 예산과 일정은 미확인**이다. 80만원에 포함된 것으로 가정하지 않는다. 별도 고정 지출이면 회수표의 D를 늘려 재계산한다.
- 실제 공급가격·운임·개발비·법적 분류가 나오면 **통합 검산이 필요하다**. 광고·고객 대응 등 추가 비용도 이 단위기여표에 전부 포함된 것은 아니다.

## 사업 판정 — 경고·형식 검사 결과는 Codex/문서검사-결과.json 참조

## 현실보정 메모 — 광고 표현

**README P6101 반영:** 합법 광고 문구의 조정은 별도 현실보정으로 두고 **경고칸 수에 포함하지 않는다**. 치료·가려움 완화·유지기간 등 최종 카피는 실제 증빙과 분류에 맞춰 정리한다. 이 문구 조정으로 실제 제품의 인허가·임상/심사 비용이 확인되거나 초도 예산 안에 포함되는 것은 아니다.

원본 반격의 표현·인용 우려도 여기서 다룬다. ‘프랑스 온천’은 국가·분야 명칭 중심의 설계 의도이며 타사 상표·외형을 쓰지 않는다. 이 의도를 법적 면책 확인으로 읽지 않으며 광고 표현·인용 우려만으로 기획 경고 수를 늘리지 않는다.
