# 온천 보습 바디밤 — ④ 상징설계

## 제품

- 무엇을: 프랑스 온천수를 넣고 펼칠 때 물방울이 드러나며 보습막을 남기는 워터브레이크 바디밤 200g. 온열 없음·에탄올 무첨가 설계 목표.
- 누구에게: 큰 바디보습 시장 안에서 건조 때문에 몸을 긁는 불편을 겪는 사람. KP를 겨울용으로 바꾼 기획이 아니다.
- 어떻게 쓰게 해서: 씻은 뒤 몸피부에 1회 4g을 펴 바르는 가정. 한 통 50회이며 실제 적정량·결과는 시제품 확인 전이다.
- 얼마에: 단품 39,000원＋배송비 3,000원. 2개 10% 할인 70,200원·무료배송. 판매 정책안이며 주문·성과 실측은 없다.

## 설계 결론

**프랑스 온천 → 실제 온천수 → 펼칠 때 물방울 → 남는 보습막**을 한 제품에서 연결한다. 중심은 실제 물질과 도포 장면이다. 유명 브랜드·치료사의 손기술·의료 효능을 빌리지 않는다.

| 상징 층 | 맡기는 역할 | 현재 확인 상태 |
|---|---|---|
| 프랑스 온천 | Codex 선정 국가·분야 상징 | Codex의 설계 선택. 타겟의 직접 우월 인식은 미확인 |
| 실제 온천수 | 국가명만 붙이지 않게 원산지·원료 당위 연결 | Saubusse 공식 경로의 현재 공식 경로 존재는 기존 통합 확인. 생산용 벌크 원료는 미확보 |
| 워터브레이크 물방울 | ‘온천물로 적심’을 눈앞에서 보여 줌 | 제형 유형 선례 확인. 우리 무에탄올 온천수 처방은 미확인 |
| 남는 보습막 | 마지막 장면과 결핍 관리 당위 | 설계 목표. 시간 경과 후 보습 유지 결과는 미확인 |

**국가를 떼고 남는 물리 구조와 대중의 상징 통념은 별개다.** 프랑스를 떼도 실제 온천수와 물방울＋보습막 구조가 남아야 하지만, **그것만으로 상징 당위가 통과하지 않는다**. 정본의 국가명 제거 점검에는 대중통념 **‘온천수→건조 때문에 긁는 불편’**의 연결도 필요하며 **현재 미확인**이다. 분야 브랜드 검색이나 보습제 일반 권고는 이 통념을 직접 입증하지 않는다. 공급사 Saubusse를 소비자에게 공부시켜 유명 상징으로 만들지 않는다. 도구는 일반 도포 손동작뿐이며 치료사의 마사지 기술을 재현하는 안이 아니다.

## 1초 이유와 소재 카드 — 내부 후보

| 접근각 | 첫 장면 | 대본 한 줄 후보 | 공개 사용 전 조건 |
|---|---|---|---|
| 원료·상징형 | 도포하면서 맺히는 물방울 | “몸에 바르는 프랑스 온천.” | 실제 원료·원산지 증빙과 실제 시제품 시연 |
| 제형·동작형 | 밤→물방울→도포 마무리를 한 화면으로 | “펴 바르면 물방울, 마무리는 보습막.” | 두 장면의 실제 구현. 물방울이 피부 흡수·효능의 증거라는 연출 금지 |
| 불편·결과형 | 거칠고 각질이 일어나는 몸피부의 동일 조건 관찰 | “씻은 뒤에도 몸피부에 남는 촉촉함.” | 실제 반복 보습 결과 확인. 기간·수치·가려움 개선은 확인 전 약속하지 않음 |

소재는 장면을 먼저, 상세페이지는 원료·배합 목적·사용법을 그 뒤에 둔다. 위 문장은 판매 카피 확정본이 아니다. ‘온천 치료 대체’·‘긁음 즉시 해결’·‘모든 로션보다 낫다’는 주장은 하지 않는다.

## 생산 prototype — 확정 처방 아님

[Shin-Etsu 공식 제형 자료](https://www.shinetsusilicones.com/files/literature/Unique%20Materials%20Plus_0.pdf)의 인쇄 p.22 “W/O Cream (water break type)”를 기존 조사에서 확인했다. **선례에는 에틸알코올(EtOH)이 들어 있다.** 이를 빼고 실제 온천수로 바꿔도 같은 구조가 성립한다는 증거는 없다.

| 항목 | 시제품 목표 가설 | 확인할 결과 |
|---|---|---|
| 총 수상 | 70~75% 범위 가정 | 수상과 유상 균형·전해질 안정성 |
| 실제 온천수 | 총 처방의 50~60% 가정, 위 수상 안에 포함 | 취수원·원산지·성분 규격, 공급 가능성 |
| 글리세린 등 | 3~5% 범위 가정 | 보습감·끈적임·시간 경과 결과 |
| 디메치콘·에몰리언트 오일 | 10~15% 범위 가정 | 물방울 이후 남는 막과 옷 착용 사용감 |
| 유화·엘라스토머 | 3~5% 범위 가정 | 펼칠 때 물방울과 저장 중 분리 방지 |
| 보존·완충·기타 | OEM이 최종 100%로 조정 | 보존력·피부 자극·용기 호환 |
| 용기 | 기성 PP 단지 200g＋라벨 | 충진·보관·사용 중 오염과 제형 적합 |

각 범위의 상한을 더하는 처방이 아니다. **온열 없음·에탄올 무첨가**가 설계 조건이며, 조건을 충족한 새 제형의 성립은 미확인이다. 무향을 우선 검토하되 저자극·무자극 보증으로 쓰지 않는다. 에탄올을 빼는 것으로 제형 개발이 끝났다고 말하지 않는다.

## origin: 실제로 넣을 수 있는가

[Saubusse 공식 경로](https://eauthermale-saubusse.com/)는 자사 온천수 기반 화장품 개발과 한국 등을 포함한 제품·처방 파트너십을 설명한다. 현재 공식 경로 존재는 기존 통합 확인 범위다. 이번 시장카드는 벌크 공급이나 등록 종류·번호를 추가 입증하지 않는다. **국내 원료 적법성·우리 제품 허가 확인으로 읽지 않는다.**

| 조달 항목 | 상태 |
|---|---|
| 공식 온천수 개발 경로·존재 | 확인 |
| 생산용 벌크 판매·MOQ·단가·운송 | 미확인 |
| 취수원·원산지 증빙·COA·미생물 규격 | 미확인 |
| 실제 샘플·국내 OEM 호환 | 미확인 |
| 우리 발주·확보 | 미확보 |

200g×1,000개×온천수 60%＝약 120kg은 **산술 가정**이다. 소매 미스트를 원료로 쓰는 안, Avène·Uriage 물을 확보했다는 안이 아니다.

## 상징 판정과 실패 조건 — 형식 검사 결과는 Codex/문서검사-결과.json 참조

- **싸고 유명한 상징 예외는 경고다.** 온천이 저렴하거나 최고·1순위 대안이 아니라는 이유만으로 자동 탈락시키지 않는다. 예외 적용이 완료됐다고 쓰지 않는다.
- **가격·수고 비교는 하드조건 미확인, 총통과 아님.** 실제 가격 비대칭 또는 원본의 반복 빈도 조건이 확인되지 않았다. 앞의 유명 상징 예외로 이 관문까지 통과시키지 않는다.
- **상징 통념 연결 미확인.** 국가를 뗀 물리 재료가 남는다는 점검과 ‘온천수→건조 때문에 긁는 불편’이라는 대중통념 점검을 구별한다. 두 조건 중 물리 구조만으로 통과하지 않으며, 통념 미확인만으로 탈락을 확정하지도 않는다.
- **실제 작동·마지막 장면 미확인.** 물방울이 나오고 보습막이 남는지, 시간 뒤 결과까지 시제품으로 확인해야 한다.
- **선행제품과 차별 경고.** 같은 온천수 크림에 국적·함량·문구만 바꾸면 차별이 성립하지 않는다. 리스토피 활성 44일·공식 상세 확인은 기존 시장 근거이지 우리 차별의 검증이 아니다.
- **손기술 대체 구조가 아니다.** 실제 원료와 제형 구조가 중심이다.
- 물방울만 보이고 보습이 유지되지 않거나 에탄올·온열이 있어야만 구현된다면 현재 구조를 수정한다. 공급·법규상 실제 불가능이 확인되면 그 조합을 탈락시킨다. **효능 미확인과 실제 불가능을 섞지 않는다.**

## 현실보정 메모 — 광고 표현

**README P6101 반영:** 합법 광고 문구와 표현을 조정하는 일은 별도 현실보정이며 **기획 경고칸 수에 세지 않는다**. 위 내부 소재의 단어·문구는 실제 증빙과 출시 조건에 맞춰 다듬는다. 물방울 장면을 가려움 완화의 효능 증거로 바꾸지 않는다. 제품의 실제 분류·인허가·인체적용 시험과 비용 부담은 사업메모의 실행 조건으로 계속 남긴다.
