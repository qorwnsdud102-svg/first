# ④ 상징·당위 — 치과 미백의 산화와 사용 직전 혼합

입력: [3-결핍카드.md](3-결핍카드.md). **치과 미백의 산화 핵심을 유지하고, 두 제형의 분리 보관·사용 직전 혼합을 생산 차별로 제안한다.**

## 상징+장치 한 문장

**“치과 미백의 섞어 바르는 산화 젤을, 사용 직전에 서로 다른 두 저농도 제형을 혼합하는 생활 미백 젤로 옮긴다.”**

이 문장은 기획 설명이다. 실제 제품의 효과·즉효성·저자극은 미확인이다. 표현의 집행 검토는 아래 현실보정 메모에 분리한다.

## 3슬롯과 담당 칸

| 슬롯·요소 | 맡는 역할 | 확인 상태 |
|---|---|---|
| 결핍 | 노란 자연치·착색을 밝게 하고 싶은 욕구 | 공식 문제 존재·검색 관심 확인, 소비자 비중 미확인 |
| 상징원 | **치과 미백**이라는 해결 행위 | 시술 실재·공시 확인, 월검색 1,060은 통합 실측 |
| 당위 장치 | 저농도 산화 젤+별도 완충 젤의 **사용 직전 혼합** | 새 처방·장치 지표·허가 미확인 |
| base | 치과 미백을 치아 색을 밝히는 전문 해결책으로 연상 | 소비자 통념·1초 이해 확인 전 가설 |
| 기전 재현 부품 | 허용 처방 범위의 산화 성분, 배합이 다른 완충상 | OEM·허가 검토 전 |
| 외형 | 서로 구분되는 **기성 경질 용기 2개+라벨** | 보관 적합성·납품조건 미확인. 용기 자체는 상징·차별로 세지 않음 |
| 권위 | 식약처 안내·공식 제조사·향후 우리 시험자료 | 기존 자료는 원리 참고. 우리 성능 보증은 없음 |
| 분위기 | 정돈된 도포·혼합 장면 | 국가·의사 추천·치과 납품 인증을 꾸며 넣지 않음 |

**기전 한 단어: 산화.** 그것을 내는 수단은 저농도 허용 처방 범위의 과산화물 제형이다. 혼합은 보관 상태와 사용 상태를 다르게 설계하는 수단이며, 산화 능력이 커진다고 이미 확인된 장치가 아니다.

## 실제 작동·인식·결과

| 구분 | 계획 |
|---|---|
| 실제 작동 | 두 제형을 정해진 비율로 섞어 산화 미백에 사용. 분리 보관의 유효성분 안정성과 혼합 후 사용 pH는 검증할 개발 가설 |
| 소비자 인식 | “치과 미백처럼 쓰기 전에 섞는다”는 직관. 신선함·전문성 연상은 소비자 확인 전 |
| 원하는 결과 | 젤 제거 후 자연치의 실제 색 변화. 우리 제품의 미백 효과·자극은 인체적용 확인 전 |
| 쓰지 않을 인식 | “40% 치과 미백 그대로”, “섞으면 더 세고 더 빠르다”, “안 시리다”, “기존 제품은 변질된다” |

**직관 자기검증:** “치과 미백처럼 두 젤을 섞어 노란 치아를 밝히는 제품.” 설명 가설로는 연결되지만 대중의 1초 이해 테스트를 마친 것은 아니다.

## 옮기는 코어와 옮기지 않는 것

공식 제조사 [Ultradent 유럽 안내](https://infoneeu.ultradent.com/de/opalescence-boost)는 치과용 40% HP 젤의 사용 직전 2액 혼합을 설명한다. [공식 제품 설명](https://devglobal.ultradent.com/products/categories/whitening/in-office/opalescence-boost?sku=4754-US)은 화학 활성 방식이라고 명시한다. 이 제품은 **혼합 산화 장치의 원형 실재**를 뒷받침한다.

우리에게 옮기는 것은 **산화 미백+분리 배합 후 사용 직전 혼합이라는 설계 원리**다. 40% 농도·치과 처치 속도·동일 효과·해외 허가·제품 상표·고유 용기를 복제하지 않는다. LED 기기는 본품에 포함하지 않는다.

## 생산에 남는 차별 1개

**‘보관 제형과 사용 제형을 다르게 만드는 서로 다른 두 젤의 2액 처방’**을 차별로 제안한다.

- A상: 산화 성분을 담는 저농도 젤의 개발 방향.
- B상: A상과 배합이 다른 완충 젤의 개발 방향. 구체 성분·과산화물 함유 여부는 OEM 검토 전 미정.
- **소비자에게 제공되는 각 제형 자체가 저농도 허용 처방이어야 한다.** 개발상 과산화수소 환산 3% 이하를 각각의 상과 최종 혼합물에 적용하는 방향이며, 함량·방출·첨가제·분류는 OEM/허가 검토로 확정한다.
- **고농도 원액을 배포해 소비자가 희석하는 제품이 절대 아니다.** 혼합 후 농도만 낮다고 각 상의 허가를 대신할 수 없다.
- 기성 용기 2개에 각각 담고 합계 **20g 목표**. 상별 충전량·혼합비는 미정이다.
- 맞춤 듀얼펌프·맞춤 금형은 개발하지 않는다. 기성 용기라는 이유만으로 과산화물 보관 적합성·정량 혼합·누액·위생이 확보됐다고 쓰지 않는다.
- 같은 젤을 용기 두 개에 나눠 담거나 CP 젤 이름만 바꾸면 차별이 아니다.
- 실제 경쟁 제품과 나란히 놓았을 때 제형 구조·검증 지표가 달라야 한다. 국내 최초·특허 독점·모방 불가·경쟁보다 우수하다는 말은 현재 미확인이다.

## ‘왜 섞는 게 더 좋은가’ — 성립하지 않으면 폐기

**진행의 핵심 조건은 분리 보관의 안정성과 사용 시 pH를 동시에 보여 주는 실제 장치 지표다.** 한 통 제형 및 경쟁품 대비 우위는 아직 없다.

| 검증 질문 | 실제로 남겨야 할 지표 | 현재 상태 |
|---|---|---|
| 분리 보관이 필요한가 | 같은 개발 처방을 미리 혼합해 보관한 조건과 분리 보관 조건의 유효성분 유지·제형 변화 비교 | 미확인 |
| 사용 pH가 설계대로 나오는가 | 지정 혼합비에서 시간 경과 pH 곡선, 혼합비 오차를 포함한 규격 일관성 | 미확인 |
| 기존 제품보다 유용한가 | 화이트랩스·투스노트 등의 실물 비교에서 차이가 사용자의 수고를 정당화하는지 | 미확인 |
| 실제 색 변화가 남는가 | 최종 제품의 동일 조건 색 측정·전후 자료 | 미확인 |
| 순함이 유지되는가 | 우리 제형의 시림·잇몸 자극과 비교 결과 | 미확인 |

**안정성·사용 pH 장치 지표가 나오지 않거나, 분리·혼합이 필요한 이유를 실증하지 못하면 이 혼합안은 폐기한다.** pH 곡선 하나만으로 미백 효과·저자극을 확정하지 않는다. 수치 임계값·혼합비·사용 시간은 OEM 검토 전 임의로 확정하지 않는다.

## 가격·수고·저가 대안

공식 공시 22만원 VAT 별도 원데이 시술 및 대학병원 1악당 수가는 상품 39,900원+배송 3,000원보다 높다. 다만 실제 청구·같은 시술 범위는 미확인이고, 치과가 검사·보호·처치해 주는 수고를 생활 미백과 동등하게 둘 수 없다.

**가격 비대칭은 해당 공시에 대한 참고 판단이다.** [시장카드.md](마케팅/프로젝트/DA-기획/공동기획-2026-10/Codex/시장카드/치아미백/시장카드.md)에는 **40,000원 시술앱 이벤트 광고(ID 1315537013795206)**가 실제 기록돼 있다. 공식 수가·구성·조건은 미확인이므로 싼 대안 신호로 함께 비교한다. 우리 단품 총결제 42,900원이 광고가 4만원보다 높다는 점도 숨기지 않는다. 공식 7,700원 미백제·24,900원/29,800원 젤은 [사업 메모](5-사업메모.md)에 싼 대안으로 포함한다.

## DA 소재 카드 — 장면과 한 줄

| 접근각 | 첫 1초 장면 | 한 줄 후보 | 조건 |
|---|---|---|---|
| 혼합 동작형 | 두 기성 용기의 다른 젤을 합치는 손 동작 | “치과 미백, 쓰기 전에 섞는 두 젤.” | 실제 제품으로 촬영할 혼합 기획 소재 |
| 결과 욕구형 | 자연치의 노란 색이 보이는 근접 화면 | “노란 치아가 신경 쓰일 때, 혼합 미백 젤.” | 상황 가설이며 당사자 후기처럼 꾸미지 않음 |
| 마지막 장면형 | 젤을 씻은 뒤 같은 조건의 치아 색 비교 | “씻어낸 뒤의 치아 색까지 확인하세요.” | 우리 제품 결과 자료가 나와야 실제 BNA로 연결 |

소재는 욕구·동작을 보여 준다. 상세페이지 아래에는 최종 허가 스펙, 실제 안정성/pH 지표와 제품 시험을 넣는다. 인체적용 전 BNA·해외 제품 수치를 우리 결과처럼 쓰지 않는다. 흰 코팅·기포·따끔함은 성과 장면으로 쓰지 않는다.

## 단계 판정

**상징 설계 경고 — 미확인·보완 가능.** 산화 코어·3슬롯·마지막 장면의 방향은 맞췄다. 1초 직관, 실거래가 대조, 혼합의 필요·경쟁 우위는 검증 전이다.

하드 위험의 조건을 구분한다. 스케일링→착색 표시로 결과가 바뀌거나, 동일 젤을 나눈 재명명 구조라면 탈락 기준에 해당한다. **현재 미확인을 이미 하드 탈락이라고 선언하지 않는다.** 다음 입력: [5-사업메모.md](5-사업메모.md).
