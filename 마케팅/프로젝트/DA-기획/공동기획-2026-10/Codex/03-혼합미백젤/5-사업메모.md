# ⑤ 사업 메모 — 초도 600~800만원 가정, 허가·임상비 별도

입력: [4-상징설계.md](4-상징설계.md). **상품 39,900원·합계 20g, 원가 5,000원, MOQ 1,000은 목표다. 실제 견적·제형 허가·효과는 미확인이다.**

## 가격·구성

| 구성 | 상품가 P(VAT 포함) | 배송비 | 고객 결제 합계 | 제조원가 C(VAT 별도 목표) |
|---|---:|---:|---:|---:|
| 1개 본품(두 제형 합계 20g) | **39,900원** | **3,000원 별도** | **42,900원** | **5,000원** |
| 2개 본품, 상품가 10% 할인 | **71,820원** | **무료** | **71,820원** | **10,000원** |

제형 2개가 한 본품이다. 2개 세트는 **본품 2개 / 총 제형 용기 4개 / 합계 40g 목표**다. 단품의 20g·세트의 40g은 목표 총량이며 상별 혼합비와 사용 기간은 허가 전 미정이다. “2개월분” 같은 기간을 붙이지 않는다.

객단가는 2개 10% 할인 무료배송으로 설계한다. 할인·배송비를 실제 계산에 반영하며 **가격을 높여 위험을 덮는 논리로 사용하지 않는다.** 별도 사이드 상품은 현재 넣지 않는다.

## 제조·허가·용기 — 실제 존재와 우리 견적 구별

| 항목 | 확인 | 미확인·다음 검토 |
|---|---|---|
| 국내 미백 젤 제조 | [필코코스팜 공식 안내](https://pilkocospharm.co.kr/product/beauty/non-drug/)에 CP 제형/OEM/ODM/소량 생산 표시 | 우리 2액 처방·원가·MOQ·정확한 농도·현재 허가번호 |
| HP 젤 OEM 이력 | [케이엠제약 2020-10-15 KRX 공시](https://kind.krx.co.kr/external/2020/10/15/000121/20201015000324/10601.htm)에 치아미백 상용화·OEM/ODM 제품 명시 | 2026년 수탁·개발·납기와 국내 저농도 2액 제조 |
| 국내 분류 | [식약처 자료 기반 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148898995)에 생활 미백 의약외품·3% 이하 안내 | 각 상과 혼합 후 제형의 허용 처방·첨가제·방출 규격·품목 허가 |
| 화장품 우회 | [식약처 2017 고시](https://www.mfds.go.kr/brd/m_207/view.do?seq=11939)에 일시 치아 색보정도 의약외품 지정 | 화장품이라고 임의 분류하지 않음 |

| 기성 용기 | 기존 범용 경질 용기 2개+라벨로 개발하는 방향 | 과산화물 안정성·누액·밀봉·정량·라벨 적합성·부자재 MOQ |
| 금형·기기 | **맞춤 듀얼펌프 금형·LED 본품을 개발하지 않음** | 자체 의료기기가 필수로 바뀌면 실행 가능성을 재판정 |

각 제형 자체가 저농도 허용 처방이어야 한다. **고농도 희석 배포가 아니며 치과 원형 40% 농도를 재현하지 않는다.** 배합·혼합비·1회 도포량·접촉 시간·반복 횟수 등 최종 용법은 OEM·허가 검토 전 미확정이다.

## 첫 주문 계산 — 전부 민감도 가정

**확인된 매출·원가·ROAS가 아닌 공통 민감도 계산이다.** P는 VAT 포함 상품가, 배송비도 VAT 포함으로 가정한다. C는 주문당 VAT 별도 제조원가다.

- 광고 전 기여 = **(P+배송비)/1.1 − C − 출고물류 3,000 − (P+배송비)×0.033 − 상품가×0.03**.
- 광고 ROAS = **상품 매출 P / 광고비**. 배송비를 광고 매출에 포함하지 않는다.
- 손익분기 광고 ROAS BE = **P / 광고 전 기여**.
- 광고 후 단위 기여 = **광고 전 기여 − P/광고 ROAS**. 여기서 단위는 주문 1건이다.
- 출고물류 3,000원/주문, 결제수수료 3.3%, 환불·반품 충당 3%는 가정이며 실제 조건 미확인.
- 이하 수치는 원 단위 반올림. 개발 고정·허가·임상·인건비·기타 고정비 회수 전 기여다.

| 계산 항목 | 1개 주문 | 2개 할인 주문 |
|---|---:|---:|
| 상품가 P | 39,900 | 71,820 |
| 배송비 수입 | 3,000 | 0 |
| VAT 제외 유입 | 39,000 | 65,291 |
| 제조원가 C | 5,000 | 10,000 |
| 출고물류 | 3,000 | 3,000 |
| 결제수수료 | 1,416 | 2,370 |
| 상품가 3% 충당 | 1,197 | 2,155 |
| **첫 주문 광고 전 기여** | **28,387** | **47,766** |
| **BE 광고 ROAS** | **140.6%** | **150.4%** |

| 광고 ROAS 민감도 | 1개 주문 광고비 | 1개 주문 광고 후 기여 | 2개 주문 광고비 | 2개 주문 광고 후 기여 |
|---|---:|---:|---:|---:|
| **170% 가정** | 23,471 | **4,917** | 42,247 | **5,519** |
| **200% 가정** | 19,950 | **8,437** | 35,910 | **11,856** |

2개 세트는 주문당 기여가 커도, 170%에서 본품 1개당 약 **2,760원**, 200%에서 약 **5,928원**이다. 단품의 4,917원·8,437원보다 낮다. **할인 세트가 위험을 자동 완화한다고 판단하지 않는다.**

목표 원가 5,000원은 VAT 포함 상품가 39,900원 대비 단순비 **12.5%**다. VAT 제외 상품 매출 기준으로는 약 **13.8%**다. 정본의 약 10% 참고선과 다르지만 이것만으로 하드 탈락시키지 않는다. ROAS 170%·200%는 실측 성과·필수 통과선이 아니다.

## 개발 고정과 초도 투자 — 중복 합산 금지

| 항목 | 금액(VAT 별도 가정) | 범위·상태 |
|---|---:|---|
| 본품 제조원가 | **500만원** | 5,000원×MOQ 1,000. 내용물·기성 용기 2개·충진·라벨/상자·제조 검사 등을 담아야 하는 목표. 실견적 없음 |
| 별도 개발·초기 준비 고정 지급 | **100~300만원** | 일회성 처방 개발·초기 준비 등으로 별도 지급한다는 가정. 실제 항목·계약 미확인 |
| **기초 초도 합계** | **600~800만원** | 위 두 항목만 합산. VAT 별도. 제조원가에 개발 고정을 다시 넣지 않음 |
| **인체적용 임상·허가 비용** | **미견적 / 별도** | 위 합계에 들어 있지 않음. 일정·자료 요건도 미확인 |
| 광고·운영 자금 등 | 미산정 | 기초 초도 합계를 총사업 예산으로 읽지 않음 |

**강한 예산 경고: 평상시 400~600만원에서 이탈한다.** 600만원은 평상시 상단에 닿고, 800만원은 상단보다 200만원 높다. VAT와 **미견적 허가·인체적용 임상비를 더하면 600~800만원 가정조차 총액이 아니다.** 2,000만원 예외 상한·가격 인상·재구매 기대를 통과 근거로 쓰지 않는다.

고정 100~300만원은 C에 포함하지 않고 별도 회수한다. 내용물/포장 비용을 고정에도 다시 더하지 않으며, 업체가 개발비 포함 제조단가를 제시하면 포함분을 확인해 계산을 다시 통일해야 한다.

### 고정 100~300만원의 회수 — 첫 주문 기여만 사용

| 주문 구성·광고 ROAS 가정 | 주문당 광고 후 기여 | 고정 100만원 회수 주문 수 | 고정 300만원 회수 주문 수 |
|---|---:|---:|---:|
| 1개 / 170% | 4,917원 | **204건** | **611건** |
| 1개 / 200% | 8,437원 | **119건** | **356건** |
| 2개 / 170% | 5,519원 | **182건** | **544건** |
| 2개 / 200% | 11,856원 | **85건** | **254건** |

계산은 반올림 전 기여로 나누고 올림했다. 제조원가는 이미 주문 기여에서 차감했으며 이 표는 **별도 개발 고정만의 회수**다. 임상·허가·기타 고정비 회수는 포함하지 않는다. 재구매 매출도 넣지 않았다.

**2개 주문만 발생하고 광고 ROAS 170%인 가정이면, MOQ 1,000개는 최대 500건이다.** 고정 300만원 회수에 필요한 544건에 못 미친다. 초도 전체를 팔아도 광고 후 기여 약 276만원이라 고정 300만원 회수도 부족한 민감도다. 확정 적자 예측은 아니지만 위험을 숨기지 않는다.

## 운영·재구매·법적 등급·BNA·시즌

- BNA: **개선재**. 실제 자연치 색 측정·동일 조건 촬영과 우리 인체적용 자료가 필요하다. 혼합 pH 영상은 작동 설명이고 임상 결과가 아니다.
- 재구매: 소모품이라는 가능성만 있다. 허가된 주기·사용량·재구매율 미확인. 원가와 광고 손익을 재구매 기대에 기대어 통과시키지 않는다.
- 시즌: 통합 카드의 **2025-10-01~2026-09-30 DataLab 검색 API 추이 측정 완료**. 검색 묶음이 연중 유지·9월 상대 최고 43.57898로 기록돼 겨울 전용 제한 근거는 없다. 상대지수이며 실제 매출 시즌·런칭 최적일은 미확인이다.
- 실행 부담: 두 제형 안정성·혼합 오차·용기 적합성·허가 자료·사용 제한·자극 문의 대응. 수탁 공장과 조건은 미확인이다.
- 제품 자료: 공식 원리 자료와 별개로 우리 제형의 인체적용·시험자료 조달 가능성은 미확인이다.

## 현실보정 메모

[README P6101](../../README.md)에 따라 광고 표현·상표·표시·심의 우려는 집행 전 보정 메모로만 두며 **기획 경고·탈락 칸 수에 세지 않는다**. ‘치과 미백’ 행위명과 타사 상표·시험자료 표현을 그때 검토한다. 이 기준은 **실제 제품 인허가, 허가·인체적용 비용, 제조원가·MOQ 실행 부담을 면제하지 않는다**.

## 판정

**사업성 경고 — 미확인·보완 가능.** 경제성은 민감도에서 계산했으나 실원가·MOQ·허가/임상 예산이 없다. 특히 **600~800만원 VAT 별도+허가·임상비 미견적**과 혼합 장치 지표가 가장 약하다. 실제로 허가·조달이 불가능해지거나 자체 의료기기 의존 구조가 되면 하드 기준으로 재판정한다.
