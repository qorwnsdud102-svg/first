# 공동 기획 1차 결과 — 한 장

사장님께. Claude 5개와 Codex 5개를 서로 채점한 결과입니다. 아래 ①~⑤ 번호로 답해 주시면 됩니다.

## 1. 올리는 안 — 상위 5개

기계 순위로는 Claude 5개가 1~5위를 모두 차지했습니다. 그런데 그대로 올리지 않았습니다. 이유는 두 가지입니다.

- **채점자 차이**: Codex가 Claude 기획에 매긴 경고는 평균 4.0개, Claude가 Codex 기획에 매긴 경고는 평균 5.2개입니다. 이 차이는 거의 다 '결핍 카드'를 누가 채점했느냐에서 나왔습니다(3번 참고).
- **사장님 판정**: 이미 기각하신 Claude 02(아쿠아필링 홈키트)와 03(브루어리 폼)은 뺐습니다.

남은 8개 중 순위가 높은 5개입니다.

**① Claude 04 — NMN 파우더샷** (기계 1위)
- 제품: 첫날 뚜껑을 누르면 속에 든 NMN 가루가 앰플에 떨어져 녹습니다. 이것을 한 달 동안 쓰는 30ml 주름 앰플입니다. 대상은 NMN 영양제를 아는 40~60대 여성이고, 34,900원(6병 BEST 139,600원)입니다.
- 상징: NMN 영양제(올레놀샷 벤치마킹)
- 교차 채점(Codex): 탈락 0 · 경고 4 · 시장성 상
- 판단할 것: 사장님 판정은 "제형은 좋은데 가루가 무슨 역할을 하느냐"였습니다. 비렌느의 차가운 가루처럼 가루가 상징을 전달하도록 다시 설계해 2차에 올릴지, 접을지 정해 주세요.

**② Claude 01 — 쿨빔 홍조 젤크림** (기계 3위)
- 제품: 무멘톨 장벽 진정 젤크림 50ml에 냉장고에 넣어 두는 금속 쿨링 헤드를 함께 넣었습니다. 대상은 30~50대 주사피부염·홍조 피부이고, 36,900원(2개월 세트 BEST 64,900원)입니다.
- 상징: 브이빔. 피부과 홍조 혈관 레이저로, 한 번에 16.5만~33만 원입니다. 쏠 때마다 차가운 냉각 가스가 나와서 받아 본 사람은 '차가운 한 발'로 기억합니다.
- 교차 채점(Codex): 탈락 0 · 경고 4 · 시장성 중
- 판단할 것: 냉장 헤드의 '차가운 한 발'이 브이빔으로 느껴지는지, 아니면 냉장고 계란이나 다이소 아이스롤러로 보이는지 봐 주세요. Claude와 Codex 모두 이 상징 칸을 '틀림'으로 예측했습니다.

**③ Claude 05 — 레드밤 스틱** (기계 3위)
- 제품: 호랑이연고와 같은 계열 허브 원료(장뇌·멘톨 등)로 만든 빨간 고체 밤 40g입니다. 손에 묻지 않는 돔형 스틱이고, 대상은 몸이 결리고 쑤시는 50~60대와 부모님께 선물하는 자녀입니다. 24,900원(2개 BEST 39,900원)입니다.
- 상징: 호랑이연고. 사장님 판정은 "좋은 상징재, 이 컨셉으로 파는 곳이 없으면 매우 좋음"이었습니다.
- 교차 채점(Codex): 탈락 0 · 경고 4 · 시장성 중
- 판매처 확인(쿠팡·11번가·메타에서 47번 검색):
  - 이름에 '호랑이'만 붙인 통증 크림은 이미 흔합니다. 쿠팡에서 '호랑이 크림'을 검색하면 첫 화면 36개 중 16개가 이런 제품이고, 대부분 값싼 흰 크림입니다.
  - '그 빨간 호랑이연고'를 상징으로 내세운 국내 제품, 스틱형 제품, 메타 광고는 하나도 없었습니다.
  - 가장 센 상대는 원조 타이거밤입니다(쿠팡 25g 14,000원, 후기 2,750건).
  - 네이버 쇼핑은 확인하지 못했습니다.
- 판단할 것: 범위를 좁힌 컨셉('그 빨간 연고'의 기억·화끈함·스틱)으로 진행할지 정해 주세요. 진행하면 결핍을 '근육통' 대신 무릎·손가락 마디·오십견 같은 구체적인 질환으로 다시 잡겠습니다.

**④ Codex 01 — 캐비어 밀착 앰플** (기계 6위)
- 제품: 캐비어 원물이 들어 있고, 바르면 얇은 투명 피막이 남는 30ml 보습 앰플입니다. 대상은 잔주름과 거친 피부결이 신경 쓰이는 35~60대 여성이고, 39,900원(2개 71,820원)입니다.
- 상징: 백화점 고가 캐비어 관리(라프레리 리퀴드 리프트 905,000원)
- 교차 채점(Claude): 탈락 0 · 경고 5 · 시장성 상
- 판단할 것: '캐비어 = 고급'이라는 인식이 '주름 관리'로 바로 이어지는지 봐 주세요. 작성자도 대중 인지가 약할 수 있다고 적었습니다. 또 피막은 캐비어를 떠올리게 하지 않고, 캐비어 제품과 필름 크림은 이미 시중에 있습니다.

**⑤ Codex 03 — 혼합 미백젤** (기계 6위)
- 제품: 서로 다른 저농도 젤 2개를 쓰기 직전에 섞어 바르는 치아미백제 20g입니다. 대상은 양치해도 치아가 누렇게 보이는 사람이고, 39,900원(2개 71,820원)입니다.
- 상징: 치과 미백(섞어 바르는 산화 젤)
- 교차 채점(Claude): 탈락 0 · 경고 5 · 시장성 상(치아미백 검색 월 38,100회)
- 판단할 것: 대중이 '치과 미백은 섞어 쓴다'는 것을 아는지가 관건입니다. 섞으면 더 세다고 말할 수 없으면 참신하기만 하고 가치는 느껴지지 않을 수 있습니다(NMN 가루와 같은 문제). 임상·허가 비용 견적도 아직 없습니다.

빠진 3개는 Codex 02 숱 섬유 젤(8위), Codex 05 습포 워터크림(8위), Codex 04 온천 보습 바디밤(10위)입니다.

> 이 순위는 서로 다른 채점자가 매긴 점수를 섞은 것입니다. 그래서 Claude 기획 3개와 Codex 기획 2개 사이의 간격은 채점자 차이만큼 부풀려져 있습니다.

## 2. 사장님 판정과 반응 예측 비교 — 첫 적중률

- **Codex 예측만 측정할 수 있습니다.** Claude는 02~05 예측을 쓰기 전에 사장님 판정이 먼저 나와서 예측을 생략했습니다. Claude는 01만 예측했고, 01은 아직 사장님 판정 전입니다.
- Codex는 예측할 때 사장님이 02~05에 주신 피드백 파일을 읽지 못하게 막아 두었습니다. 다만 05의 ①·③은 독립 예측이 아닙니다. 사장님이 05를 보고 하신 말씀(근육통 한 키워드로 조사한 오류, 통증은 구체적인 질환으로 광고)이 이미 판례 P6103·P6104로 올라가 있었기 때문입니다(아래 표의 '노출').
- 사장님이 판정을 말씀하신 칸만 비교했습니다.

- **단계 칸**: 8칸 중 5칸을 맞혔습니다(틀림 2, 반쯤 1). 정답이 노출된 05의 ①·③을 빼면 6칸 중 3칸입니다.
- **전체 승인 가능성**: 02·03은 기각되었는데 둘 다 '중간'으로 예측했습니다. 기각을 0/2로 못 맞혔습니다. 04의 '중간'은 판정(제형은 좋고 가루는 역할 없음)과 맞습니다. 05는 최종 판정 전입니다.
- **'사장님이 가장 먼저 짚을 것'**: 4개 중 3개를 맞혔고 1개는 반쯤 맞혔습니다.
  - 03(흔한 시장)과 04(분말을 섞는 방식이 얼마나 더 가치 있게 느껴지나)는 맞혔습니다.
  - 05(구체 질환 키워드로 넓혀 보기)도 맞혔지만 정답이 노출된 경우입니다.
  - 02는 반쯤 맞혔습니다. 손 펜이 실제로 빨아들이는지는 짚었지만, 사장님의 핵심은 아쿠아필의 물 세척 느낌을 제품으로 못 낸다는 점과 아쿠아필이 싸다는 점이었습니다.
- **기각 이유를 잡았나**
  - 참신성(03): 잡았습니다.
  - 구현 불가(02): 놓쳤습니다.
  - 가루의 역할(04): 절반만 잡았습니다. '가장 먼저 짚을 것'에서는 맞혔는데 ④ 칸에는 통과로 적었습니다.
- **패턴**: Codex는 위험을 문장으로는 짚지만, 판정 칸에는 '통과, 추가 확인 필요'로 적습니다. 상징 구현 규칙(P6113)을 보고도 02·04의 ④를 통과로 예측했습니다. 교차 채점에서 Claude 기획에 너그러웠던 것과 같은 방향입니다.
- **다음**: 사장님이 01을 보시면 Claude 예측(승인 가능성 중간, ④ 틀림)과 Codex 예측(낮음, ④ 틀림)을 함께 맞춰 볼 수 있습니다. 양쪽 적중률을 처음으로 비교하게 됩니다.

## 3. 채점자 차이

| 단계 | Codex가 Claude 5개를 | Claude가 Codex 5개를 |
|---|---|---|
| ① 기초분석 | 경고 5 | 경고 5 |
| ② 출발점 | 경고 0 | 경고 1 |
| ③ 결핍 카드 | **경고 0** | **경고 5** |
| ④ 상징·당위 | 경고 5(규칙 평균 2.4개) | 경고 5(규칙 평균 6.6개) |
| ⑤ 사업성 | 경고 5 | 경고 5 |
| ⑥ 기획서 | 경고 5(4개는 절차 경고 ⑥-15만) | 경고 5(⑥-15는 세지 않음) |
| ⑦ 범위 확장 | 경고 0 | 경고 0 |
| 경고 평균 | 4.0 | 5.2 |
| ⑥-15를 빼면 | 3.2 | 5.2 |
| 걸린 규칙 수 평균 | 11.0개 | 19.8개 |
| 작성자 자기 판정과 다른 칸 | 7칸, 모두 작성자 '경고'를 '통과'로 | 2칸, 모두 작성자 '통과'를 '경고'로 |

- **경고 차이 6칸 중 5칸이 ③ 결핍 카드입니다**(나머지 1칸은 ②). Claude가 기계 순위 1~5위를 다 가져간 것은 대부분 ③을 누가 채점했느냐로 설명됩니다.
  - Codex는 출처별 빈도 비중만 있으면 ③을 통과시켰습니다.
  - Claude는 결핍 출처가 공식 문서 2~4개뿐이라 비중 순위가 서지 않는 것, 욕구 강도와 결핍을 가진 사람 수가 없는 것을 경고로 보았습니다.
- **⑥은 경고 수는 같지만 이유가 다릅니다.** Codex는 이번 라운드 순서(기획서를 먼저 쓰고 예측을 나중에)가 정본 ⑥-15와 어긋난 것을 경고로 셌습니다. Claude는 작성자 책임이 아니라며 세지 않았습니다. 기준을 맞추면 경고 차이는 1.2에서 2.0으로 더 벌어집니다.
- **불일치 9칸도 방향이 같습니다.** Claude는 자기 기획에도, 상대 기획에도 더 엄했습니다. 다만 Claude 쪽 7칸 중 ② 4칸은 Claude가 검색량 하락을 이유로 자기 기획에 경고를 단 것입니다. 이 항목은 이번 라운드에서 세지 않기로 했으므로(P6105) 실제 의견 차이는 ③ 3칸입니다.
- **정보 차이**: Claude는 채점할 때 P6113 이후의 사장님 판정(상징 구현·참신함)을 알고 있었습니다. 이것은 메모로만 적고 경고 수에는 넣지 않았습니다. Codex는 P6113 이후 판정을 읽지 않았습니다.
- **다음 라운드 제안**: 채점자별로 순위를 따로 내거나, 같은 채점자가 양쪽을 모두 채점해야 순위가 공정합니다.

## 4. 배운 것 3줄

1. **상징 구현** — Claude는 상징이 '어떻게 작동하는지'(녹이고 빨아낸다, NMN 가루)만 옮겼습니다. 받아 본 사람이 기억하는 느낌(아쿠아필의 물 세척)과 형태의 역할(가루가 왜 가루인가)은 놓쳤습니다. → 정본 v2 ④에 반영: 핵심 장면 해부(④-53), 핵심 느낌이나 대체 체감이 없으면 탈락(④-24), 형태가 상징을 전달하는 역할(④-55).
2. **참신성** — 상징이 좋아도 시중에 수백 개가 깔려 있으면 무뎌집니다(독일 맥주효모 샴푸). → 정본 v2에 ⑤ 참신함 단계 신설: 상징 × 카테고리로 상품 수·메타 광고 수 실측(⑤-02), 포화 유형에 독일 맥주효모 두피 샴푸 추가(⑤-03), 참신함과 가치가 둘 다 있어야 함(⑤-08), 넓은 컨셉과 좁은 컨셉 구분(⑤-07, 호랑이연고).
3. **키워드 하나로 조사** — '근육통' 한 단어로 메타를 보고 "바르는 제품 없음"이라고 결론 냈습니다. → 정본 v2 ①에 반영: 모든 검색은 여러 키워드로 하고, 없으면 본 키워드 목록과 함께 '못 찾음'으로 적음(①-24). 결핍과 키워드는 구체적인 질환 단위로 잡음(①-25).
