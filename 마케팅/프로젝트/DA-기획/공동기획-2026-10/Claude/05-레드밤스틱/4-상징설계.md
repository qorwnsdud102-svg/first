# ④ 상징 설계 — 레드밤 스틱

## 3슬롯 (④-01)

| 슬롯 | 내용 |
|---|---|
| 결핍 | 근육이 뻐근하게 결리고 뭉쳐 쑤시는 통증, 관절의 국소 통증(근육통·관절통의 메인 증상 — 3-결핍카드 1절) |
| 상징원 | **호랑이연고(타이거밤 레드)** — 동남아 여행 가면 꼭 사 오는 국민 근육통 연고. 1870년대 미얀마 랑군의 약방에서 시작해 싱가포르 회사(Haw Par)가 100년 넘게 판 허브 연고(tigerbalm.com 헤리티지·hawpar.com 헤리티지 — 연도는 출처마다 다름) |
| 당위 장치 | ① 원료 그대로: 호랑이연고 레드와 같은 계열 원료 — 장뇌(캠퍼)·멘톨·카유풋오일·정향오일(+계피오일). 원본 표시값: 캠퍼 11%·멘톨 10%·카유풋오일 7%·정향오일 5%(아일랜드 HPRA 허가 문서·영국 판매처 표기). ② 체감: 바르고 문지르면 곧 '화끈'해진다. ③ 도구: 돔형 스틱 머리로 뭉친 곳을 문지르며 누른다(지압) — 손에 안 묻는다 |

- 기전 한 단어: **화끈** — 내는 수단: 원료 그대로(캠퍼·계피오일·정향오일) + 체감 재현. 멘톨은 원본 향과 구성을 맞추는 성분으로만 넣고 '쿨링'을 내세우지 않는다(④-07, 냉·온 자기모순 방지).
- 직관 자기검증 한 줄: **"손에 안 묻는 스틱 호랑이연고로 결리고 쑤시는 곳을 화끈하게 푸세요."** — 설명 없이 1초에 성립한다(④-21·④-22). 단 실제 소재에서는 상표 때문에 '호랑이연고'라는 이름을 그대로 못 쓸 수 있다(⑤ 사업메모, 가장 약한 지점).

## 요소별 담당 칸 (④-02)

| 요소 | 맡은 칸 | 그 칸의 기준으로 본 판정 |
|---|---|---|
| 호랑이연고 | 상징원 | 1초 인지(검색 7,630 + 타이거밤 3,060, 자동완성 여행지 7곳). 비싼 1순위가 아님 → ④-04·④-08 경고 |
| 허브 밤(왁스·오일 바탕) | base | 연고를 대신하는 고체 밤. 차별을 요구하지 않음 |
| 캠퍼·멘톨·카유풋·정향(·계피) | 기전 재현 부품 | 원본과 같은 계열 원료 그대로 — '화끈'을 낸다 |
| 돔형 트위스트 스틱 | 사용 장면·도구(UI/UX) | 범용 용기라 외형 상징 겹으로 세지 않는다(④-46). 같은 결핍의 '바르기 + 누르기'를 한 동작으로 묶는 시너지(④-49) |
| 빨간 밤 색·제품명 '레드밤' | 분위기·이름 | '타이거밤 레드'를 연상시키는 이름(④-51). 상징 겹으로 세지 않음 |
| 권위 | 없음 | 보증형(의사·국가대표)은 쓰지 않는다(④-52). 원본 허가 문서는 우리 제품 근거로 붙이지 않는다(⑤-14) |

상징 겹(④-39): '무엇을 대체' = 호랑이연고 / '무엇으로' = 원본 계열 원료와 화끈한 체감. '어디 것'(국가)·'누구도'(인물)는 쓰지 않는다 — 2겹.

## 인식·작동·결과 (④-03, ⑥-06)

| 구분 | 내용 | 확인 상태 |
|---|---|---|
| 인식(설득력) | 50~60대가 "여행 가면 사 오던 그 빨간 연고"를 바로 떠올린다. 스틱이라 손에 안 묻는다는 차이가 한눈에 보인다 | 검색량·자동완성 확인. 타겟 반응은 미확인 |
| 작동(실제 작동) | 캠퍼·멘톨·계피·정향 같은 피부 감각 원료가 바른 곳에 화끈·화한 감각을 만든다(원본이 같은 원리의 외용 진통제). 화장품 배합 한도 안에서 같은 체감이 나는지는 시제품 전 | **미확인** — 캠퍼 화장품 배합 한도 미확인(⑤) |
| 결과(원하는 결과) | 결리고 쑤시는 곳이 풀린 느낌 | **미확인**. 화장품이라 '근육통 완화'를 약속할 수 없다(⑤) |

## 상징원 가격·수고 비교 (④-05)

| | 호랑이연고(원본) | 레드밤 스틱(우리) |
|---|---|---|
| 실거래가 | 현지 소매가 미확인. 해외 도매 19.4g US$0.48~0.50(Accio, 48개 이상). 국내 정식 수입품은 '현지보다 비싸다'는 리뷰(글로우픽 '타이거밤 릴리프 멀티밤' 19건), 국내가 미확인 | 40g 24,900원(계획) |
| 수고·빈도 | 아플 때마다 바름 — 자주 쓰는 약 대체 문법 | 같음 |
| 구하는 수고 | 여행 가서 사 오거나 직구·수입품을 찾는다 | 국내 자사몰에서 바로 |

- 판정: **가격 비대칭은 성립하지 않는다**(원본이 더 싸다). **편의성 동등은 성립한다** — 상징원도 아플 때마다 자주 바르는 제품이다. 정본 ④-05는 둘 중 하나면 통과이므로 **통과**. 다만 '원본이 더 싼데 왜 우리 것을 사나'가 이 기획의 가장 약한 지점이다(기획서 '가장 약한 지점').

## 상징원이 거절당하는 지점 (④-06)

- 손에 묻는다 — 연고를 손가락으로 떠서 발라 손에 냄새·화끈함이 남고, 그 손으로 눈을 만지면 따갑다. 근거: 글로우픽 리뷰 '손에 묻는 것이 번거로워 스파출라로 떠서 쓴다'(19건 중 일부 — 출처 검증 안 함, 3등급 수준). 원본 회사도 돔 도포기 제품('타이거밤 넥앤숄더' — 네이버 자동완성)을 따로 낸다.
- 혼자 등·어깨에 손이 잘 안 닿는다(AI 추정).
- 냄새 호불호(글로우픽 리뷰) — 우리도 상징 향을 지키므로 이 거절 지점은 풀지 않는다. 그대로 안고 간다(④-13 경고).
- 국내에서 사기 번거롭다(여행·직구) — 정식 수입이 시작됐다는 리뷰가 있어 약해지는 중.
- 이 인구(손에 묻는 게 싫어 연고를 안 쓰는 사람)의 크기는 미측정.

## 상징원의 대중 금기 (④-07)

- 원본 같은 외용 진통 연고의 표시 주의(일반 지식, 위키에 없음 — 라벨 확인 필요): 눈·점막·상처에 바르지 않는다, 찜질기·핫팩·꽉 조인 붕대와 함께 쓰지 않는다(화상 위험), 어린이 주의.
- 우리 사용 동작과 충돌 확인: 사용법이 '찜질 대신 문지르기'라 핫팩 병용을 권하지 않는다. 스틱이라 손으로 눈을 만질 일이 줄어든다 — 금기와 오히려 맞는다. 냉·온을 함께 내세우지 않는다(체감 단어는 '화끈' 하나).
