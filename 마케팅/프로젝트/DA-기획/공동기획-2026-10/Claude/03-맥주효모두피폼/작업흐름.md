## 규칙 제안

정본은 고치지 않는다. 쓰면서 문장이 애매하거나 빈칸이었던 곳.

1. **②-10 · ④-50 — '꺼진 유행'의 선이 없다.** 맥주효모는 24개월 새 −79%지만 지금도 월 16,860이고 '탈모엔 맥주효모' 통념은 남아 있다. 제안: '검색 유행의 소진'과 'base 통념의 소실'을 나눠 적게 하고, 소진은 예컨대 '24개월 최고 대비 −70% 이상이면서 최근 6개월도 하락'처럼 실측 기준선(📊)으로 정한다.
2. **④-04와 ④-08의 예외가 서로 다르다.** ④-04는 '국가·대중 인식 상징'을 예외로 두는데 ④-08에는 그 예외가 없고 '분야별 유명 상징재 → 경고'만 있다. 같은 맥주효모가 ④-04는 통과, ④-08은 경고가 된다. 제안: 재료 base 상징(맥주효모·호박)은 두 규칙에서 같은 예외로 다룬다.
3. **④-05 — 재료 상징의 '상징원 실거래가'를 무엇과 비교하나.** 맥주효모처럼 재료가 상징원이면, 비교 대상이 같은 재료의 먹는 제품(영양제)인지 그 결핍의 1순위 해결책(약·이식)인지 문장에 없다. 이번엔 영양제와 비교(편의성 동등)하고 1순위 대안은 ④-06 거절 지점으로 따로 봤다. 제안: 재료 base 상징은 '같은 재료의 다른 형태에서 우리 형태로 옮길 당위(전환)'로 보도록 문장을 나눈다.
4. **④-12 — 국가가 MSG일 때도 적용하나.** '그 국가 ↔ 이 결핍' 통념(독일 ↔ 탈모)은 없지만, 독일은 재료 base(맥주효모) 위의 MSG이고 ④-38이 '독일 맥주공장 효모'를 바른 예로 든다. 제안: ④-12는 국가가 상징원 자체일 때만 쓰고, 국가가 base 위 MSG면 ④-33·④-38로만 본다고 적는다.
5. **①-06 · ①-07 — 의약품 광고는 어디에 두나.** 로게인폼·판시딜은 메타에 광고하는 '제품'이지만 화장품·공산품이 아니다. 경쟁 상품도 시술 참고도 아니어서 칸이 없다. 제안: '의약품 — 경쟁 해결책(참고)' 줄을 시장 카드 ①에 따로 둔다.
6. **③-03 — 출처 수 비중이 별도 유형을 메인으로 올린다.** 원형 탈모는 7곳 중 4곳이 말해 '절반 이상'이지만 원인·유병률이 다른 별도 유형이다. 제안: 원인이 다른 하위 질환은 비중 계산에서 나눠 세고, 출처 수 비중은 '페이지 언급 비중'이라고 이름을 붙인다.
7. **④-36 — 네이버 상품 수를 잴 도구가 없다.** 검색 API 쇼핑 엔드포인트가 SE05를 돌려준다(2026-10-10). 제안: 측정 도구(ItemScout 상품 수 등)를 규칙이나 SKILL.md에 적고, 못 재면 메타 광고 밀도로 대신한다고 명시한다.
8. **⑥-15 — 라운드 순서와 맞지 않는다.** 정본은 반응 예측 2파일을 기획서보다 먼저 커밋하라는데, 공동 기획 README 순서는 기획서 봉인(1단계) 뒤 반응 예측(2단계)이다. 이번엔 ⑥을 '경고'로 적었다. 제안: 공동 라운드에서는 README 순서를 따른다는 단서를 넣거나 순서를 바꾼다.
