# 하룻밤 염증샷 패치 — 근거 (②~⑥)

## ② 출발점
- 출발점: 유명 상징재(시술) **여드름 염증주사**("하룻밤에 가라앉는 주사"). 인지 근거: 네이버 '여드름염증주사' 6,840 + '염증주사' 4,910 + '여드름주사' 900(2026-10-11). 자동완성 '여드름 염증주사 가격·효과·후기·통증·패임'.
- 붙는 열린 시장: 여드름 패치·스팟(여드름패치 17,060). 오래 돈 제품 광고 — 프롬갓 갓크림 T 887일(1345839789430911, 같은 제품 5개 페이지), 이옴 트러블 패치 265일(4176926245854029).
- 범위: 1단계 — 화농성 여드름 타겟·여드름 패치 카테고리는 그대로, 상징(염증주사)과 형태(누르면 터지는 '샷 캡슐')만 바꿨다.

## ③ 결핍 카드
- 메인 증상: **갑자기 붉게 부어오른 아픈 여드름 → 고름 잡힘**(구진·농포, 화농성). 기획은 이 '한 개의 붉은 혹'에 맞춘다. 좁쌀(면포)·결절은 겨냥하지 않는다.
- 해결 행동(검색량순): 먹는 약(이소티논 32,700) → 연고(여드름연고 20,600·아젤리아 28,700) → 패치(17,060) → 염증주사(6,840 + 4,910) → 압출(6,540).
- 감정: "곪았다고 짜면 큰일"(공포 — 이옴 광고), 흉터 걱정, 내일 약속인데(조급), 주사 '패임'(자동완성 — 공포).
- 욕구: 애정(외모) + 안전(통증·흉터). 강도: 연고·패치·주사·약을 번갈아 씀, 주사는 1개 1만원에도 병원을 감.
- 크기: 좁쌀여드름 15,600·화농성여드름 9,130(검색하는 사람). 결핍 가진 사람 수 미확인. 타겟은 15~35세라 고연령 선호(③-10)와는 반대다.
- 표본 한계: 결핍 출처는 WebSearch 요약 1회(③-03 경고), 유튜브 미측정.

## ④ 상징 설계
**3슬롯**: 붉게 부어오른 화농성 여드름 → 염증주사 → 정중앙 '샷 캡슐'을 눌러 터뜨리고 밤새 붙여 두는 패치

**요소별 칸**: 상징원 = 염증주사 / 기전 재현 부품 = 패치 정중앙의 밀봉 캡슐(0.05ml 앰플 — 누르면 터짐) / base = 하이드로콜로이드 원형 패치(흡수·보호 — 흔함, 차별로 세지 않음) / 앰플 성분 = 살리실산·나이아신아마이드·병풀·티트리(스테로이드 없음) / 외형 = 원형 패치(범용, 상징 아님).

**핵심 장면 해부(④-53)** — 받아 본 사람 후기 원문은 못 찾아 병원 안내·자동완성으로 재구성한 **가설**이다.
| 칸 | 받아 본 사람이 기억할 것 |
|---|---|
| 보이는 것 | 의사가 붉은 여드름 정중앙에 가는 바늘을 콕, 맞은 자리가 살짝 부풂 |
| 느끼는 것 | 따끔 한 번(1초), 뻐근 |
| 순서 | 한 개씩 짚어 주사 → 집에 감 → 자고 일어남 |
| **마지막 장면(핵심)** | **다음날 붉은 혹이 납작하게 가라앉아 있음** — 첫마디(가설) "하루 만에 가라앉았어" |
| 이름과 숫자 | 염증주사, 1개 1만원, '3일 안에 맞아야', 패임 2~6개월 |

**고른 신호(④-54)**: "정중앙에 한 방 → 자고 나면 납작". 대중이 '여드름 주사'라는 말에서 떠올리는 장면은 바늘보다 **'하룻밤에 가라앉는다'**다(가장 오래 돈 제품 광고들의 훅도 '3일 만에' — 속도).

**박은 칸과 수단**
- 몸 — 구조: 원형 패치 정중앙에 볼록한 캡슐 하나. 여드름 꼭대기에 캡슐이 오게 붙인다.
- 몸 — 동작·순서(④-56): 붙인다 → 캡슐을 손끝으로 '톡' 누른다(주사 놓는 순간) → 앰플이 정중앙으로 퍼짐 → 그대로 잔다 → 아침에 뗀다.
- 몸 — 체감(대체 감각, ④-23 가): 바늘 대신 앰플이 닿는 1~2초 '화끈·따끔'(살리실산) — 주사의 '콕'을 다른 감각으로.
- 몸 — 결과 장면: 아침에 하얗게 부푼 패치(고름·진물을 빨아들인 흔적)와 납작해진 여드름. 패치 흡수 장면은 실제로 찍을 수 있다.
- 겉 — 이름 '하룻밤 염증샷', 상자에 '1개 = 1샷'.

**당위**: 주사는 '정중앙에 직접 넣는다' → 바르는 스팟은 표면에 퍼지고, 패치는 덮기만 한다 → **누르면 정중앙에 쏟아지는 캡슐 + 밤새 덮는 패치**라야 '한 방'이다. 스테로이드가 없으니 **패임 걱정이 없다**(④-06 대체 당위).

**가격·수고(④-05)**: 염증주사 1개 1만원(병원 표기) + 진료·이동 시간, 생길 때마다 가야 함 vs 패치 1장 약 1,660원(12매 19,900원) → 개당 가격 비대칭 + 상징원도 생길 때마다 반복(편의성) → 통과.
**④-04**: 효과 좋은 병원 시술인데 못 하는 이유가 '비싸서'가 아니라 **여드름은 갑자기 나는데 병원은 예약·시간이 필요하고, 바늘·패임이 무섭다**는 쪽이다. 우리 제품은 집에서·더 싸게·바늘 없이 옮긴다 → 통과로 판정(단 상징원이 '비싼 것'은 아니라는 점은 사장님 판단 칸에).
**거절 지점(④-06)**: 바늘 공포, '염증주사 패임'(자동완성), 갑자기 난 여드름에 당일 진료가 안 됨, 개수만큼 비용.
**금기(④-07)**: 주사 뒤 '만지거나 뜯지 마라'·사우나 금지 → 우리도 '짜지 말고 붙여 두기'. 냉·온 섞지 않음.
**④-13**: '주사'의 바늘 연상 — 제품에 바늘이 없으므로 "바늘 없이 한 방"으로 뒤집는다(경고).
**④-46**: 주사기·바늘 외형은 쓰지 않는다(범용 의료 도구는 상징이 아님). 캡슐은 구조 부품이다.
**직관 한 줄**: "바르는 여드름 주사 — 정중앙에 톡, 자고 나면 납작."
