# C08 산사 침향 수면 미스트 — 근거 (②~⑥)

## ② 출발점
- 출발점: 유명 상징재(문화) **템플스테이·산사** — 산속 절에서 하룻밤, 9시 소등, 새벽 예불.
- 인지 근거: 템플스테이 네이버 월간 67,000 · 산사 4,130(2026-10-11, '산사'는 산사나무·산사열매가 섞임). 자동완성 '절 향 냄새'·'절 향 향수'·'절 향 디퓨저'·'절 향 냄새 향수'(절향 280) — 사람들이 '절 냄새'를 집에 들이고 싶어 한다.
- 열린 시장 근거(같은 결핍·같은 부류): 수면 향 제품이 메타에서 돈다 — 든향 잠뿌향수 164일(2501444933648023), Nozz 필로우미스트 40일(2260196021494690). 수면 차(연꽃배아 차 737일, 1178504033228297)도 돈다.
- 범위 단계 1(주장) — 수면 향(필로우미스트·수면 향수) 시장에서 **상징만** 라벤더·과학 향 → 산사 향으로 바꾼다. 배정 메모는 '향 단독 제품이면 3단계'로 경고했다 — 메타에서 수면 향 제품이 팔리는 근거로 1단계라고 보지만 사장님 판단에 올린다(⑨-06).

## ④ 상징 설계

### 3슬롯
- 결핍: 누우면 잡생각에 잠들지 못하는 밤.
- 상징원: 산사(템플스테이)의 밤 — 고요, 법당 향 냄새, 처마 풍경 소리, 9시 소등.
- 당위 장치: 법당에서 피우는 침향·백단 향을 불·연기 없이 베개에 뿌리는 미스트 + 병목에 단 작은 황동 풍경 — '풍경 한 번 → 두 번 뿌리고 → 소등'의 9시 의식.

### 요소별 담당 칸(④-02)
| 요소 | 칸 | 기준 |
|---|---|---|
| 침향(Aquilaria 추출물·오일 소량) + 백단·편백 노트 | 상징원 원료(원료 그대로) | 맡자마자 '절 냄새' — 연기·제사 향 노트는 줄인다 |
| 황동 미니 풍경 참 | 도구 동봉(소리·외형) | 처마 풍경 소리 = 산사의 밤 |
| 9시 소등 의식(사용법) | 사용 순서 | 템플스테이 소등 시간을 그대로 |
| 100ml 범용 미스트 병 | base | 상징 아님 |

### 핵심 장면 해부(④-53) — 산사의 하룻밤
| 칸 | 받아 본 사람이 기억하는 것(가설) |
|---|---|
| 보이는 것 | 산속 절, 단청 처마 끝 물고기 풍경, 법당 향로의 향 연기, 수련복 |
| **느끼는 것 ★** | 휴대폰 없는 고요, 법당 향 냄새, 새벽 공기 |
| 순서 | 저녁 공양 → 저녁 예불(종·목탁) → **9시 소등** → 새벽 3~4시 예불 |
| **마지막 장면 ★** | 마음이 비워지고 일찍 잠들어 개운하다 |
| 이름·숫자 | 템플스테이, 1박 2일, 9시 소등, 108배 |

첫마디(가설): "조용했다, 마음이 편해졌다." 외국인 참가자 설문에서 불안 감소 71.4%·스트레스 감소 74.2%(불교문화사업단·한국갤럽 2023, WebSearch 요약 — 수면을 따로 잰 조사는 아님). 국내 체험 담화 원문 표본은 미측정 — 가장 약한 근거다.

### 고른 신호와 박은 칸(④-54·④-22)
1. 법당 향 냄새 → **몸 칸(원료)** — 침향·백단. 대중이 '절' 하면 떠올리는 냄새다(자동완성 '절 향 냄새' 증거). 원료 자체가 상징이라 이름 지우기 면제 대상.
2. 처마 풍경 소리 + 9시 소등 → **몸 칸(사용 순서)** + **도구(풍경 참)**.
- 겉 칸: 이름 '산사의 밤', 먹색·단청 포인트 라벨.

### 직관 자기검증
"산사의 향으로 잡생각을 끄고 잠드세요" — 1초에 이해되는지는 경고(아래 ④-21).

### 실거래가·수고 비교(④-05)
- 템플스테이: 1박 2일 성인 약 6만원(청평사 블로그 기준, 사찰마다 다름), 지원 행사 때 3만원(현대불교신문 메타 광고 1094964482941920) + 왕복 이동·주말 하루·인기 사찰은 예약 3분 마감.
- 우리: 29,900원 / 약 60밤(1회 2번 분사). → 1회당 상징원이 훨씬 비싸고(가격 비대칭) 매일 밤 갈 수 없다 — 통과.
- 거절 지점(④-06): 수면제는 무섭고, 향은 라벤더가 질렸고, 산사는 매일 못 간다.

### 테스트 4종(④-57)
| 테스트 | 결과 |
|---|---|
| 1초 사진 | 통과(조건부) — 황동 물고기 풍경이 달린 병과 베개 사진은 '절·산사'를 떠올린다. 풍경이 없으면 흔한 미스트 병이다 |
| 이름 지우기 | 면제(원료 자체가 상징 — ④-22). 이름을 지워도 냄새가 '절'을 말한다(조향 확인 전 미확인) |
| 형태 역할 | 경고 — 미스트라는 형태 자체는 상징을 나르지 않는다(④-55). 상징은 향 원료와 풍경 부품이 나른다. 풍경을 빼면 '소등 종소리' 장면이 사라지니 부품 역할은 있다(④-49 통과) |
| 체험자 '그거네' | 조건부 — 핵심 느낌 중 '향 냄새'는 원료 그대로 낸다. '고요'는 소등 의식과 향으로 대체한다. 마지막 장면(푹 자고 개운함)은 체감 미확인 |

### 걸린 규칙
- ④-04: 국가·대중 인식 상징 예외 + 실제로도 '하고 싶지만 매일 못 하는 것' — 통과.
- ④-08 확인: 템플스테이는 불면의 1순위 치료(수면제·인지행동치료)가 아니다. 대중 인식 상징(④-04 예외 쪽)으로 보고 '산사 = 마음의 고요' 통념으로 판정했다 — 이 해석이 맞는지 사장님 판단.
- ④-21 확인: 템플스테이의 대표 용도는 '쉼·마음 비움'이지 '불면 치료'가 아니다. 결핍을 '잡생각 때문에 잠 못 드는 밤'으로 좁혀 연결했다 — 1초 이해 여부 사장님 판단.
- ④-34 경고: 산사 → 마음이 고요 → 잠이 온다, 두 걸음 통념. 끊김은 없다고 보지만 당위가 약하다.
- ④-13 경고(섞인 경우): 향 냄새가 제사·장례식장을 떠올릴 수 있다(다나와에서 '제사향 절향 사찰향'이 한 상품명에 같이 붙음). 불교 거부층도 있다.
- ④-55 경고: 위 형태 역할.
