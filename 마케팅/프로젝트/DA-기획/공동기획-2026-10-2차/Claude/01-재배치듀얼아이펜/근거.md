# 재배치 듀얼 아이펜 — 근거 (②~⑥)

## ② 출발점
- 출발점: 유명 상징재(시술) **눈밑지방재배치**. 인지 근거: 네이버 월 59,790(2026-10-11, PC 6,890 / MO 52,900), '눈밑지방재배치가격' 5,050, 자동완성 '눈밑지방재배치수술후·멍·통증'.
- 붙는 열린 시장: 아이크림·아이백 크림(아이크림 22,300). 오래 돈 제품 광고 — 플라링크 YC칼슘크림 178일(2211520092994713, 브랜드 'YC칼슘크림' 970), 아이본딩샷 124일(1919539152097296, '하안검? 눈밑지? 🚫'로 시술을 적으로 세움).
- 범위: 1단계 — 타겟·카테고리(눈밑 아이 제품)는 그대로, 상징(재배치)과 형태(양끝 두 제형)만 바꿨다. 부위를 쪼갠 재조준 아님(②-11).

## ③ 결핍 카드
- 메인 증상: 불룩한 눈밑 지방과 그 아래 꺼진 고랑의 **경계에 지는 그늘**(구조형·함몰형 다크서클, "가장 흔하다" — 시장 카드 ③). 기획은 이 그늘에 맞춘다. 색소형·혈관형은 겨냥하지 않는다.
- 해결 행동(검색량순): 재배치 수술 59,790 → 아이크림 22,300 → 필러(눈밑꺼짐 11,680) → 마사지 3,490.
- 감정: 피곤해 보인다는 말(수치), 수술 공포·멍 2주(공포), "눈밑지도 알아봤지만 다시 돌아온다는 후기"(뷰앤디 광고 1610892157103038 — 체념·불신).
- 욕구: 애정(외모). 강도 근거: 수십만~수백만 원 수술 검색이 월 6만, 필러·크림·기기를 번갈아 시도.
- 크기: 결핍 메인키워드 눈밑지방 6,160·눈밑꺼짐 11,680·다크서클 8,950(검색하는 사람). 결핍을 가진 사람 수는 미확인(나이 들면 대부분 겪는 구조 변화 — 일반 지식).
- 표본 한계: 결핍 출처는 기사 요약 1회뿐이다(③-03 경고). 유튜브 미측정.

## ④ 상징 설계
**3슬롯**: 볼록+꺼짐 경계의 그늘 → 눈밑지방재배치 → 양끝 듀얼 펜('위는 조이고 아래는 채운다')

**요소별 칸**: 상징원 = 재배치 / 기전 재현 부품 = 양끝 두 제형(조이는 세럼 끝·채우는 밤 끝) / base = 카페인·펩타이드 아이 케어 / 외형 = 범용 듀얼 펜(분위기, 상징 아님) / 이름 = '재배치'.

**핵심 장면 해부(④-53)**
| 칸 | 받아 본 사람이 기억하는 것 |
|---|---|
| 보이는 것 | 1~2주 붓기·멍 뒤, 볼록한 데가 꺼지고 아래 고랑이 차서 눈밑이 한 면으로 이어진다 |
| 느끼는 것 | 수술 공포·당김, 회복기 붓기. 끝나면 "피곤해 보인다"는 말이 사라짐 |
| 순서 | 유형 상담(지방 많음/꺼짐) → 결막 안쪽 절개 → 튀어나온 지방을 **버리지 않고 아래 꺼진 곳으로 옮김** → 회복 |
| **마지막 장면(핵심)** | **거울 속 그늘 선이 없어진 평평한 눈밑** — 첫마디 "그늘이 없어졌어" |
| 이름과 숫자 | '재배치'(빼는 게 아니라 옮긴다), 30분~1시간, 붓기 2주, 이벤트가 39만~69만원 |

**고른 신호(④-54)**: "볼록한 데는 꺼지고, 꺼진 데는 차서 그늘이 사라진다" — 두 방향이 동시에 일어나 평평해지는 장면. 대중은 이름만 들어도 '튀어나온 지방을 꺼진 데로 옮긴다'를 떠올린다(가격·후기 검색이 월 6만).

**박은 칸과 수단**
- 몸 — 구조: 한 펜의 양끝이 다른 제형. 위 끝(LIFT) = 바르면 2~3분 안에 마르며 당기는 즉각 타이트닝 세럼(필름 형성제 + 카페인). 아래 끝(FILL) = 꺼진 고랑에 톡톡 채우는 볼륨 밤(히알루론산 필링 스피어 + 빛을 퍼뜨리는 소프트포커스 파우더).
- 몸 — 사용 순서(④-56): 볼록한 곳 LIFT → 아래 고랑 FILL을 위에서 아래로 쓸어 '옮기듯' → 2분 뒤 그늘 선 확인. 재배치의 '위에서 빼서 아래로 옮긴다'를 손동작으로 따른다.
- 몸 — 결과 장면: 2분 뒤 경계 그늘이 옅어진 평평한 눈밑(일시적, 세안 전까지).
- 겉 — 이름 '재배치 듀얼 아이펜', 상자에 볼록·고랑 단면도.

**당위**: "빼기만 하면 꺼진다, 옮겨야 평평하다"(재배치가 지방 제거보다 낫다는 대중 통념) → 조이기만 하는 아이백 크림은 고랑이 남는다 → 그래서 두 끝.

**가격·수고 비교(④-05)**: 재배치 39만~69만원(이벤트가, 일반 절개형 가격 미확인) 1회 + 붓기 2주 vs 우리 34,900원(약 1.5개월). 가격 비대칭 → 통과.
**거절 지점(④-06)**: 수술 공포, 멍·붓기 2주(휴가 필요), "다시 돌아온다" 불신, 비대칭·꺼짐 부작용 걱정. 이 사람들이 우리 자리다.
**금기(④-07)**: 수술 뒤 비비기 금지 → 사용법은 '톡톡·쓸어내림', 문지르지 않음. 냉·온 섞지 않음.
**직관 한 줄**: "바르는 눈밑지방재배치 — 위는 조이고 아래는 채워 그늘을 지운다."

**검증 테스트 4종(④-57)**
| 테스트 | 결과 |
|---|---|
| 1초 사진 | 반쪽 얼굴(왼쪽 볼록+그늘 / 오른쪽 평평) + 양끝 펜 GIF → '눈밑지 한 얼굴' 연상은 된다. 다만 아이백 크림 BNA와 비슷하게 보일 위험(경고) |
| 이름 지우기 | 시술 상징원 — 신호가 몸 칸(양끝 구조·위→아래 순서·평평한 결과)에 있어 이름을 지워도 '빼고 채운다'가 남는다. 이름 없이 '재배치'까지 떠올릴지는 약함(경고) |
| 형태 역할 | LIFT 끝을 빼면 '볼록이 꺼지는' 장면이, FILL 끝을 빼면 '고랑이 차는' 장면이 사라진다 → 두 끝 모두 장면을 진다(④-49·④-55 통과) |
| 체험자 '그거네' | 받아 본 사람의 첫마디 '그늘이 없어졌다'를 2분 뒤 같은 그림으로 낸다. 단 하루짜리(세안까지)다 — 원본은 수년. 대체 체감 수준(④-24 통과, 지속 시간은 경고) |

**걸린 규칙**: ④-13 경고(‘수술’의 칼·멍 연상 — "수술 없이"로 씀) · ④-28 경고(결 일치 약 70% — 색소형·혈관형은 못 잡음) · ④-39 경고(겹 두 개: 무엇을 대체(재배치)·무엇으로(두 끝)) · 하드 없음.
