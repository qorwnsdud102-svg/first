- 저장소 선행 지식: `프로그램/wiki/entities/NAVER-API-HUB.md`와 `네이버-데이터랩-쇼핑인사이트-API.md`에 이미 쇼핑·책·전문자료 API의 2026-07-31 종료와 대체 API 없음이 기록돼 있었다. 본 야간 작업에서 이 환경 가정을 제때 반영하지 못한 것은 조사 운영 오류다.
- 최신 공식 공지 재확인: [네이버 개발자센터 종료 공지](https://developers.naver.com/notice/article/32564), [API HUB 이관 공지의 제외 API 안내](https://developers.naver.com/notice/article/32530). 기존 이용자도 종료 대상이며 별도 대체 API를 제공하지 않는다. 오래 남아 있는 API 레퍼런스의 예제 URL만 보고 사용 가능으로 판단하면 안 된다.
- 결론: 호출 URL 오타/단순 키 재발급으로 복구될 문제가 아니다. 동일 API 반복 호출·계정/권한 변경·추가 설치는 하지 않는다.
- 이번 15개 기획의 처리: 상품수는 **미측정**. 공식 제조사 상품 페이지와 복수 검색어로 확인한 구체 선례는 참신함의 정성 근거로 남기되, 검색 결과 개수나 선례 수를 네이버 전체 상품수로 바꾸지 않는다. 공개 쇼핑 페이지 접근이 막히면 우회하지 않는다. 메타 광고 수는 별도 수집 순서 승인 뒤 측정하며, 접근 실패는 0개가 아니다.

검색량(SearchAd)·검색 추이(DataLab)는 별도 API로 이번 작업에서 실제 응답을 받았다. 쇼핑 상품수 실패를 이 두 값의 실패로 일반화하지 않는다.
