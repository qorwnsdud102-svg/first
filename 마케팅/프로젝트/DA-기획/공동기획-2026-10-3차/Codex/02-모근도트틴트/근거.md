# 모근 도트 틴트 — 근거와 미확인

기획의 기준은 동결된 [단계별 규칙](<C:/claude/LLM-WIKI/마케팅/wiki/syntheses/DA 기획 단계별 규칙.md>) @ 4a0690a다. 이 문서의 상품·원료·가격 정보는 **위키에 없음 — 외부 공개자료**이며, 제품 구성·제조·경제성은 **Codex 가설**이다. 검색량은 API 실측, 제조사의 성능 설명은 그 제조사의 주장이다. 서로 섞지 않는다.

## ② 출발점 — 원본 가격과 이식할 것
**원본의 가격·수고부터 확인:** 다나성형외과 공개 안내는 두피문신 300,000원부터, VAT 별도이며 범위에 따라 다르다고 표시한다. 전체 두피의 평균가는 아니다. 틴트는 더 저렴하지만 매일 다시 바르고 지우는 추가 수고가 있다. [원본 가격 자료](https://www.danaps.com/pages/dana_m/hospitals/hospitals06.php)

**상징을 옮기는 근거:** SMP의 공개 설명은 모낭처럼 보이는 작은 점으로 밀도·색조를 보완하는 결과를 보여준다. 이 기획은 영구 색소 주입 대신 같은 점 그림을 피부 표면의 임시 화장으로 옮긴다. 아래 출처표는 사실별 확인 범위를 구별한다.

**가격 비대칭 / 편의성 판단:** 시술과 같은 성능·지속기간을 팔지 않는다. 화장품·식품의 반복 사용은 편리할 수도 있지만 매일 쓰는 추가 수고도 있다. 원본보다 싸다는 주장과 편의가 같다는 주장은 따로 확인한다. 특히 값싼 원본은 가격 역전 약점을 그대로 남겼다.

## ③ 결핍 카드 — 대표어와 표본
- 대표 수집어: **탈모**. 정보성·대안·브랜드의 범위를 구별했다.
- 타겟: 탈모 타겟 — 정보성 탈모 13,480회 · 대안 두피문신 11,120회 · 경쟁 브랜드 다슈 8,990회(전체)·다슈흑채 280회(세부 제품어).
- 결핍: 탈모 때문에 비쳐 보이는 두피를 덜 보이게 하고 싶은 결핍이다. 발모·탈모 예방 제품을 원하는 사람 전체와 일치하지 않는다. 흑채·커버를 고르는 비중은 조사 대기이며 시장 전체를 구매층으로 계산하지 않는다.
- 소비자 원문·댓글·자막 표본 0. 원인·증상·기존 행동 비중 계산 불가. 제조사 설명을 소비자의 목소리로 바꾸지 않았다.
- 원시 측정: [키워드-1.txt](../조사자료/키워드-1.txt), [키워드-2.txt](../조사자료/키워드-2.txt), [키워드-5.txt](../조사자료/키워드-5.txt), [키워드-6.txt](../조사자료/키워드-6.txt). [시장 카드](../시장카드/탈모/시장카드.md)에 PC·모바일·채택/제외 이유를 함께 적었다.
- 검색량을 고유 구매자·시장 매출로 환산하지 않는다. 정보성 대표어와 대안·브랜드 수요를 중복 합산하지 않는다.

## ④ 상징 설계 — 세 칸과 역할
### 원본 상징의 다섯 칸 — 공개자료 해부 가설
체험자 원문을 모으지 못했다. 아래는 공개 설명을 바탕으로 구별한 칸이며, **체험자가 기억하는 핵심·첫마디를 확인한 결과가 아니다.** 이는 정본 ④-53·④-54의 남은 확인이다.

| 칸 | 원본에서 확인한 것 / 미확인 |
|---|---|
| 보이는 것 | 두피에 모낭처럼 보이는 작은 점을 남긴다. |
| 느끼는 것 | 바늘 시술 감각은 재현하지 않는다. 시술 체험자의 기억·첫마디는 미수집이다. |
| 순서 | 색조·밀도 설계 → 점 시술 → 완성 패턴. 우리 제품은 표면에 임시 점을 찍고 세정한다. |
| 마지막 장면 | 작은 모근 점들이 비쳐 보이는 두피의 인상을 바꾼다. 같은 점 그림을 짧게 유지하는 것이 목표이며 시제품 미확인. |
| 이름·숫자 | 두피문신 11,120회 / 공개 게시가 300,000원부터(VAT·범위 별도). |

**선정 신호와 남은 반박:** 도트 결과가 핵심이다. 스탬프의 그림이 점이 아니라 검은 면이면 상징을 못 옮긴다. 영구 시술의 유지·관리 부담을 임시 화장의 편의로 혼동하지 않는다.


| 칸 | 내용 |
|---|---|
| 결핍 | 탈모 |
| 상징원 | 두피문신 — 월 11,120회, 분야 인지는 별도 확인 |
| 당위 장치 | 불규칙한 작은 원형 점이 남는 부드러운 다중 도트 팁과 세정 가능한 색소가 몸이다. 바른 뒤 실제 두피에 점 패턴이 보여야 한다. 통째로 검게 칠하거나 전사 필름을 붙이는 방식은 채택하지 않는다. |

**역할 분담:** 두피문신은 결과 그림, 도트 팁은 점 크기·배치, 잉크는 임시 유지·세정성을 맡는다. 바늘·피부 손상·영구 문신 색소는 쓰지 않는다.

**핵심 단어:** 모근 점.

**시작 → 사용 → 마지막 장면:** 같은 가르마를 같은 조명에서 찍는다 → 도트 팁으로 점 몇 개를 찍는다 → 근접에서 점 패턴·머리카락 묻음을 확인한다 → 물·땀·손 접촉·세정 후 모습을 함께 보여준다. 색 보정이나 발모 BNA는 쓰지 않는다.

### 네 테스트의 현재 결과
아래는 설계 검토이며 완료된 실험이나 소비자 채점이 아니다.
- 1초 사진: 사용 후 두피의 작은 점 패턴이 보이는지 확인한다. 이름 없는 제품 사진만으로는 화장품 팁이라는 정도만 전달될 수 있다.
- 이름 지우기: 두피문신 이름을 빼도 도트가 남는 구조·결과 그림은 남는다. 완성 시제품은 아직 없다.
- 형태 역할: 펜/병 통합 팁이 직접 점을 찍는다. 도구를 별도 동봉하는 다중 키트가 아니다.
- 체험자 ‘그거네’: 두피문신 경험자 비교 평가 0명. 비슷한 모근 그림인지, 그냥 검게 칠한 것인지 확인해야 한다.

### 설득력 / 실제 제형 / 결과
- 설득력: 머리카락을 길러낸다는 약속 대신, 두피문신의 ‘촘촘한 모근 점’을 바로 보이는 임시 화장으로 옮긴다. 이것은 구매 가설이며 인지 시험 전이다.
- 실제 제형: 화장품용 다중 팁 액상 펜을 만드는 제조사가 있다. 이는 액상·다중 팁 제조 경로의 근거일 뿐 불규칙 모근 스탬프의 제조·MOQ·전용 팁 공급 확인은 아니다. 가까운 도트 브러시 특허가 발견됐다.
- 결과: 시제품·대조 사용·표준 촬영 자료가 없어 광고 결과 및 체험자 만족을 확정할 수 없다.
- 핵심 경고: 머리카락이 많은 부분에도 도트만 찍히는지, 땀에 번지지 않고 세정되는지 미확인이다. 유사한 도트 브러시·잉크 특허가 있어 부품을 그대로 사는 방식의 권리 위험도 남는다.

## ⑤ 참신함 — 선례가 있다는 사실부터
다슈·노비어의 커버 완제품이 확인된다. 공식 페이지 게시가 참고는 다슈 24,800원·노비어 18,000원이며 옵션·변동 가능성이 있다. 재확인 시 다슈 페이지에는 품절 표시가 있어 현재 판매 성공의 근거로 보지 않는다. 다슈 전체 검색량 8,990회와 다슈흑채 280회는 서로 다른 범위라 합산하지 않는다.

다슈·노비어가 이미 일시적 두피 커버 제품을 판다. 커버 자체는 새롭지 않다. 새 구매 이유는 넓게 덮는 파우더 대신 모근 점을 찍는 일체형 사용과 가까이서의 마무리다. 이미 같은 구조가 선점됐는지는 Meta 확인 전이다.

- 1·2차와 **제품·상징 조합** 중복을 제외했다. 같은 넓은 결핍의 재사용은 이번 계약에서 허용된다.
- 생산에 들어가는 차별은 원료 정체·처방·사용 부품·제형의 설계다. 실제 배타적 공급·독점·특허·경쟁사 전환 비용은 확인하지 않았다.
- Meta 광고 수·오래 돈 소재·증가 시점을 미측정했다. 한국 쇼핑 상품 수는 정본에 따라 세지 않았다.
- ‘검색 결과에서 못 봄’이나 조사 빈칸을 기회·세계 최초·경쟁 없음의 근거로 쓰지 않는다.

## ⑥ 사업성·제조 — 목표와 확인을 분리
**제조 경로 가설:** ① 두피와 모발에 묻는 양을 구분할 다중 도트 팁 시안을 만든다. ② 점 지름·간격·유량을 조절한다. ③ 검정·짙은 갈색 색상부터 비교한다. ④ 땀·물·손 접촉 및 샴푸 세정을 확인한다. ⑤ 모발 끼임·두피 자극·누액을 점검한다. 금형 여부·팁 수명은 미정.

**진행을 바꾸는 조건:** 몇 번 찍으면 검은 면이 되거나 모발에만 묻으면 두피문신의 점 결과가 아니다. 영구 문신 기기나 문신 색소로 해결하지 않는다. 팁 권리·금형 비용이 안 맞으면 구조를 다시 설계한다.

### 목표 비용
| 항목 | 계획값 | 확인 상태 |
|---|---:|---|
| 단품 판매가 | 35,900원 | 목표; 판매 테스트 전 |
| 내용물·용기·라벨·상자 | 4,300원/개 | 원가 목표; 견적 없음 |
| MOQ | 1,000개 | 목표; 공장·용기·부품 MOQ 미확인 |
| 초도 생산 | 430만원 | 목표 원가×목표 수량 |
| 개발·시험·준비 | 250만원 | 예산 가설; 범위·견적 미확인 |
| 초도 합계 | 680만원 | 목표; 실제 견적에서 재판정 |

**마진 계산 가정:** 단품 주문 배송·출고 3,500원, 결제비 판매가 3%, 추가 할인·반품비는 미반영. 제품 원가 목표를 쓰는 계산이며 견적이나 실적이 아니다.

- 변동비: 4,300 + 3,500 + 1,077 = **8,877원**.
- 단순 손익분기 광고 ROAS: 100 ÷ (1 − 변동비/판매가) = **132.8%**.
- 광고 ROAS 170% 가정 시 단품 공헌액: **5,905원**.
- 광고 ROAS 200% 가정 시 단품 공헌액: **9,073원**.

부가세 정산·고정비·인건비·교환/반품·쿠폰은 빠졌다. 따라서 위 수치는 실제 순익·대표의 최종 엔드로아스가 아니다. 2개 세트는 객단가 가설만 두었고 별도 주문 수익을 확정하지 않았다. ROAS 350%나 재구매 수익을 전제로 높은 원가를 정당화하지 않는다.

**물류·반복성:** 작은 단일 병의 소모품으로 기획했다. 실제 용기 무게·파손·누액·사용기간·재구매율은 샘플 확인 전이다. 권리·원료·생산 조건이 목표를 깨면 예산을 재계산한다.

## ⑧ 현실 보정
‘두피문신’은 행위명 A급으로 잠정 분류했다(법률 판단 아님). 제품 자체는 바늘 없는 세정형 두피 메이크업으로 한정한다. 발모·탈모 치료·영구 유지 표현과 타사의 특허 보유 표시는 하지 않는다. 유사 특허의 현재 권리·관할·회피 가능성은 미확인.

1~2년 추세·광고 ROAS·재구매율은 미확인. 이번 테스트에서는 자사 겹침을 탈락으로 보지 않았으며 출시 결정 때 다시 본다. 이 문서가 안전성·효능·법적 적합성의 확인서가 되지는 않는다.
