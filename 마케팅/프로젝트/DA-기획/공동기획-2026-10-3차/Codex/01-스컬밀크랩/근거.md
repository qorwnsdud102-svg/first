# 스컬밀크 랩 — 근거와 미확인

기획의 기준은 동결된 [단계별 규칙](<C:/claude/LLM-WIKI/마케팅/wiki/syntheses/DA 기획 단계별 규칙.md>) @ 4a0690a다. 이 문서의 상품·원료·가격 정보는 **위키에 없음 — 외부 공개자료**이며, 제품 구성·제조·경제성은 **Codex 가설**이다. 검색량은 API 실측, 제조사의 성능 설명은 그 제조사의 주장이다. 서로 섞지 않는다.

## ② 출발점 — 원본 가격과 이식할 것
**원본의 가격·수고부터 확인:** 스컬트라 1회 1병 690,000원, VAT 10% 별도인 한 병원 게시가를 확인했다. 실제 결제·전국 평균은 아니다. 우리 팩의 가격은 낮지만 시술과 결과가 같다는 비교는 성립하지 않는다. [원본 가격 자료](https://www.toxnfill5.com/m/detail.php?c=&i=589)

**상징을 옮기는 근거:** 스컬트라 공식 자료는 PLLA와 재구성해 주입하는 입자 현탁 구조를 확인해 준다. 원료의 정체를 옮길 근거이며 외용 팩의 주입 효능 근거가 아니다. 아래 출처표는 사실별 확인 범위를 구별한다.

**가격 비대칭 / 편의성 판단:** 시술과 같은 성능·지속기간을 팔지 않는다. 화장품·식품의 반복 사용은 편리할 수도 있지만 매일 쓰는 추가 수고도 있다. 원본보다 싸다는 주장과 편의가 같다는 주장은 따로 확인한다. 특히 값싼 원본은 가격 역전 약점을 그대로 남겼다.

## ③ 결핍 카드 — 대표어와 표본
- 대표 수집어: **팔자주름없애기**. 정보성·대안·브랜드의 범위를 구별했다.
- 타겟: 팔자주름없애기 타겟 — 정보성 팔자주름없애기 12,350회 · 대안 스컬트라 22,740회 · 경쟁 브랜드 메디필 9,310회(브랜드 전체, 이 제품 판매량 아님).
- 결핍: 팔자주름을 덜 도드라져 보이게 하고 싶은 결핍이다. 꺼짐·건조·피부 처짐 중 어떤 불만이 큰지 소비자 담화로 확인하지 못했다. 이 세 원인에 하나의 효능을 약속하지 않는다.
- 소비자 원문·댓글·자막 표본 0. 원인·증상·기존 행동 비중 계산 불가. 제조사 설명을 소비자의 목소리로 바꾸지 않았다.
- 원시 측정: [키워드-2.txt](../조사자료/키워드-2.txt), [키워드-7.txt](../조사자료/키워드-7.txt). [시장 카드](../시장카드/팔자주름없애기/시장카드.md)에 PC·모바일·채택/제외 이유를 함께 적었다.
- 검색량을 고유 구매자·시장 매출로 환산하지 않는다. 정보성 대표어와 대안·브랜드 수요를 중복 합산하지 않는다.

## ④ 상징 설계 — 세 칸과 역할
### 원본 상징의 다섯 칸 — 공개자료 해부 가설
체험자 원문을 모으지 못했다. 아래는 공개 설명을 바탕으로 구별한 칸이며, **체험자가 기억하는 핵심·첫마디를 확인한 결과가 아니다.** 이는 정본 ④-53·④-54의 남은 확인이다.

| 칸 | 원본에서 확인한 것 / 미확인 |
|---|---|
| 보이는 것 | 공식 IFU상 재구성한 PLLA 입자 현탁액을 주입한다. 팩·랩핑은 원본에 없는 동작이다. |
| 느끼는 것 | 주입의 느낌과 시술 경험자의 첫마디는 미수집. 흰 밀크의 사용감이 이를 대신한다고 보지 않는다. |
| 순서 | 재구성 → 주입 → 시간 경과 후 결과 관찰. 우리 팩의 도포 → 건조 → 세안과 다르다. |
| 마지막 장면 | 원 시술은 시간 경과 후 볼륨·주름 변화가 가치다. 우리 피막의 일시적 매끈함은 같은 지속성과 조직 변화가 아니다. |
| 이름·숫자 | 스컬트라 22,740회 / PLLA / 한 병원 1회 1병 690,000원(VAT 별도). |

**선정 신호와 남은 반박:** 원료 정체가 이식의 중심이다. 밀크·피막이 실제 체험을 대체하는지는 시제품 전이며, 그저 하얀 팩으로 끝나면 시술 상징 연결은 약하다.


| 칸 | 내용 |
|---|---|
| 결핍 | 팔자주름없애기 |
| 상징원 | 스컬트라 — 월 22,740회, 분야 인지는 별도 확인 |
| 당위 장치 | L형 PLLA 입자 자체가 몸에 들어간다. 흰 입자 분산 밀크와 얇은 피막의 매끈한 마무리를 연결한다. 주사·진피 침투·콜라겐 생성·볼륨 복원을 재현한다는 기획은 아니다. |

**역할 분담:** PLLA는 원료 일치, 밀크는 입자 분산을 보여주는 제형, 피막은 일시적인 표면 마무리를 맡는다. 백색 병이나 의료 느낌 포장은 보조이며, 같은 원료를 대신하지 못한다.

**핵심 단어:** 같은 PLLA.

**시작 → 사용 → 마지막 장면:** 흰 입자가 균일한 밀크를 손등에 얇게 펼친다 → 같은 조명·각도에서 마른 피막의 표면을 비교한다 → 씻어 지워지는 장면까지 보여준다. 아직 촬영한 BNA가 아니라 시제품 촬영안이다.

### 네 테스트의 현재 결과
아래는 설계 검토이며 완료된 실험이나 소비자 채점이 아니다.
- 1초 사진: 흰 밀크만 보면 흔한 팩일 가능성이 크다. 실제 입자와 원료 표시를 함께 보여주는 시안부터 확인해야 한다.
- 이름 지우기: 원료 설명은 남기고 상표만 지운다. PLLA 원료 축은 남지만 스컬트라를 떠올리는지는 미확인이다.
- 형태 역할: 밀크는 입자 분산, 랩핑은 표면 마무리용이다. 주사기의 외형 흉내보다 한 병 사용에 집중한다.
- 체험자 ‘그거네’: 스컬트라 경험자의 시제품 평가는 0명이다. 같은 원료와 같은 효과를 혼동하는지도 확인한다.

### 설득력 / 실제 제형 / 결과
- 설득력: 스컬트라의 실제 PLLA를 바르는 팩으로. L형 PLLA의 정체·등급·화장품용 적합성은 공급사 자료로 확인한다. 피막의 일시적 표면 마무리는 별도 검증하며, 스컬트라 결과와의 유사성은 미확인이다. 이것은 구매 가설이며 인지 시험 전이다.
- 실제 제형: 대한화장품협회 성분사전에 폴리락틱애씨드·InCube 701과 국내 제조사 랩인큐브가 확인된다. LHALA Doctor 자료는 InCube 701의 외용 완제품 사용 경로를 확인해 준다. 성분사전 등재는 해당 등급의 승인·현재 재고·견적이 아니다.
- 결과: 시제품·대조 사용·표준 촬영 자료가 없어 광고 결과 및 체험자 만족을 확정할 수 없다.
- 핵심 경고: 진짜 L형 PLLA를 써도 바르는 팩에서 시술의 가치가 느껴지는지는 미확인이다. 이미 외용 PLLA 제품이 있어, 밀크팩이라는 변화만으로는 차별이 약할 수 있다.

## ⑤ 참신함 — 선례가 있다는 사실부터
메디필의 콜라겐 래핑 마스크와 HOP+의 PLLA 보습 제품, LHALA Doctor의 외용 솔루션이 존재한다. 메디필 브랜드 검색량은 9,310회이며 해당 래핑팩의 판매량이 아니다. HOP+/LHALA의 국내 브랜드 수요는 미측정.

HOP+와 LHALA Doctor에 이미 바르는 PLLA가 있다. 최초 주장은 쓰지 않는다. 새 구매 이유는 ‘PLLA 입자 밀크 → 얇게 랩핑 → 표면 마무리’의 한 병 사용이다. 이 조합의 국내 DA 선점 여부는 미확인.

- 1·2차와 **제품·상징 조합** 중복을 제외했다. 같은 넓은 결핍의 재사용은 이번 계약에서 허용된다.
- 생산에 들어가는 차별은 원료 정체·처방·사용 부품·제형의 설계다. 실제 배타적 공급·독점·특허·경쟁사 전환 비용은 확인하지 않았다.
- Meta 광고 수·오래 돈 소재·증가 시점을 미측정했다. 한국 쇼핑 상품 수는 정본에 따라 세지 않았다.
- ‘검색 결과에서 못 봄’이나 조사 빈칸을 기회·세계 최초·경쟁 없음의 근거로 쓰지 않는다.

## ⑥ 사업성·제조 — 목표와 확인을 분리
**제조 경로 가설:** ① 공급사에서 L형/PLLA 정체·입도·화장품용 자료를 확인한다. ② 입자를 젖게 하고 균일 분산한다. ③ 얇은 피막 제형과 결합한다. ④ 침강·응집·마찰감·백색 잔사·세안성을 확인한다. ⑤ 기성 펌프의 막힘을 확인한다. 함량과 피막 재료는 미정이다.

**진행을 바꾸는 조건:** PLA·PDLLA로 바꿔놓고 같은 원료라 부르면 핵심이 깨진다. 외용 적합 자료를 못 받거나 입자가 거칠고 침강하면 이 처방을 보류한다. 피막의 광학 효과를 PLLA 시술 효과로 바꾸어 말하지 않는다.

**물류·반복성:** 작은 단일 병의 소모품으로 기획했다. 실제 용기 무게·파손·누액·사용기간·재구매율은 샘플 확인 전이다. 권리·원료·생산 조건이 목표를 깨면 예산을 재계산한다.

## ⑧ 현실 보정
스컬트라라는 살아 있는 시술·제품 상표는 C급으로 잠정 분류했다(법률 판정 아님). 주입 시술과 같은 볼륨·지속기간·콜라겐 효과 광고, 타사 시험 수치 차용은 하지 않는다. 주름 기능성 표시와 원료 등급·제품 적합성은 별도 확인 전이다.
