# 블랙헤드 DA 주력 제품 — 소재 27편 + 상페 실측

> **전제**(사장님): *"업체들은 상세페이지보다 마케팅(소재)에서 더 적극적으로 USP를 자극적으로 말해 (상페는 심의에 많이 걸려서)"* → 소재 우선 판독.
> **방법**: 영상 27편 프레임 추출·자막 전수 판독 + 상페 3종 판독 + 배너 3종.
> **대상**: 메디큐브·메라블·노일리·오브제·에이프릴스킨·에스네이처·메디힐·마미케어·아렌시아·랑벨·INFOD+ 등

---

## 0. 두 줄 결론

> **① 카테고리 전체가 "짜지 마라 · 겉만 건드리지 마라"로 수렴하는데, 아무도 "그럼 뭘로 빼냐"에 물리적 답을 못 준다.** 클렌저·오일·패드·클레이는 전부 *녹이고 닦아낸다*뿐이다. **떼어내서 실물을 손에 쥐여주는 건 필오프뿐이다.**
>
> **② 개명 경쟁이 이미 진행 중이다** — 블랙헤드 → *피지 통로 · 피지 필라멘트 · 속피지*. 그런데 전부 **피지**다. 우리만 **털**이고, **눈으로 확인되는 유일한 개명**이다.

## 1. 소재 자막 전수 (핵심만)

### 1-A. 🔴 금지형 후킹이 카테고리 표준이다

| 50 | **"잠깐! 이거 짜면 피부 끝장나요"** → *"속피지부터 뿌리째 뽑아야함"* |
| 34·35 | 상단 고정 **"구멍난 모공 때문에 병X 오지마세요"** |
| 27 | *"짜면 안돼?"* → *"잘못 짜면 개기름 폭발하고"* |
| 51 | *"Pov. 피지 짜고 싶은 충동들면 일단 참고 ㅇㅇ쓰기"* |

→ **타겟이 지금 하고 있는 행동(짜기)을 금지하는 것**이 첫 3초의 표준 문법.

### 1-B. 🔴 정체 폭로는 쏙모팩 고유가 아니다 — 카테고리 문법이다

| 26 | *"블랙헤드인 줄 알고 / 짜다가 / 왕모공 / 딸기코마냥 / **막상 짜면 안 나옴ㅠ** / **사실 블랙헤드가 아니고** / **피지 통로임!**"* (`이게 블랙헤드` vs `이건 피지통로` 라벨 대조) |
| 51 | *"피지 블랙헤드 어떻게 없애는건데. / **사실 얘는 블랙헤드가 아니라** / 겉피지는 없어져도 / **왕모공 되기전에**"* |
| 27 | *"**피지 필라멘트**는"* + 모공 단면 일러스트 |

→ ⚠️ **함의**: 우리 후킹 1번(*"블랙헤드가 아니라 털입니다"*)은 **선점자 한 곳이 아니라 카테고리 전체와 경쟁**한다. 다행히 저쪽 개명은 전부 *피지*라 **육안 확인이 불가능**하다. 우리 개명만 증거가 실물로 나온다 → **개명 뒤에 반드시 "확대해서 보세요"를 붙여야 차별이 산다.**

### 1-C. 🔴 "뿌리째"는 이미 선점됐다

50번이 **"속피지부터 뿌리째 뽑아야함"**을 정면으로 쓴다.
→ 사장님이 어제 "뿌리째" 아이디어를 자기기각한 게 **결과적으로 정확했다.** 담화 근거 부재(§2.5)에 더해 **선점**까지 겹친다.

### 1-D. 깊이 프레임 — "겉만 건드리면 더 넓어진다"

34·35 (앰플):
> *"모공이 뻥 뚫렸다"* → *"셋째, 트러블로 인해"* → *"이 중 한 가지 이상"* → **"이건 겉문제가 아니라"** → **"절대 방치하시면 안돼요"**(진피 기둥 붕괴 일러스트) → *"크림만 바르시는데"* → **"겉만 건드려봤자"** → **"오히려 더 넓어지고"**

→ 우리 역공 프레임(*"안 뽑아서 넓어지는 겁니다"*)과 **같은 계열**인데 저쪽은 **진피 구조 일러스트**로 시각화한다. 우리도 그림이 필요하다.

### 1-E. 동사·네이밍 점유 현황

| 점유됨 | **뿌리째**(50) · **삭제**(36 "블랙헤드 삭제" / 49 "묵은 피지 삭제 크림") · **녹이는**(39 "블랙헤드 녹이는 당근 클렌징밤") · **우수수 뽑혀서**(30) · **박멸**(33) · **순삭**(31) · **쏙**(쏙모팩) |

### 🔴 탄닌은 이미 시장에 있다

메라블이 **"초저분자 탄닌샷"**으로 쓰고 있다. 사장님이 탄닌 축을 접은 게 §7 참신성 면에서 결과적으로 맞았다. 동시에 **"탄닌 = 모공 조임"이 시장 통용 논리**라는 증거이기도 하다 — 우리가 나이아신아마이드로 가면 참신성 손해 없이 안전하다.

### 상페 vs 소재 온도차 확인

사장님 전제가 실측으로 확인됐다. 상페는 **수치·특허·환불**로 얌전하게 가고, 소재는 **"짜면 피부 끝장" · "병X 오지마세요" · "박멸" · "삭제"**로 간다. 노일리는 상페에 효소 종류조차 안 쓰면서 소재·제품명에서 *"슬라임 효소"*를 판다.

## 3. 우리 기획에 반영할 것

### 3-A. 후킹 보강 (v7 목록에 추가)

| **금지형 신설** | *"코 짜지 마세요. 그거 짜서 나오는 게 아닙니다."* ← 카테고리 표준 문법 + 우리 결핍에서만 **사실**이다(털은 안 짜진다) |
| **개명 뒤에 증거를 붙인다** | *"블랙헤드가 아니라 털입니다"* 단독은 이제 경쟁 문장이다 → **"…확대해서 보세요. 피지는 안 보이지만 털은 보입니다."**로 닫아야 차별이 산다 |
| **저들의 개명을 되받는다** | *"피지 통로다, 피지 필라멘트다 하는데 — 짜도 안 나온 이유는 그게 **피지가 아니라 털**이라서입니다."* |

### 3-B. 소재 포맷 (제작 리스트)

1. **분할화면** — 좌 UGC / 우 고정 오퍼(150ml·가격) / 하단 증정 띠
2. 🔴 **"보정 없는 원본 영상입니다" 고지** — 우리 신뢰 축(어뷰징 안 함)과 한 몸
3. **코 모형 프롭** — 그로테스크 완충 + 심의 안전. AI 클레이 소재와 같은 역할
4. **손가락 위 실물** → 우리 버전은 **떼어낸 팩 뒷면 접사**
5. **남성용 별도 소재** — *"귀찮은 거 아는데, 20분 바르고 떼면 끝"*
6. UV 촬영 · 길거리 실증 — 예산 되면

### 3-C. 신뢰 장치 — 우리가 안 가진 칸 2개

| 🔴 **환불 보증** | 노일리가 *"2주 안에 효과 없으면 100% 책임 환불"*을 건다. 우리는 **떼어낸 면에 털이 보이는지**로 판정이 즉시 되므로 보증이 오히려 쉽다 — *"한 번 써보고 털이 안 나오면 환불"* |
| **품절·재입고 서사** | 쏙모팩도 *17차 소량입고*로 쓰는 중. 노일리는 **사과문 형식**까지 간다 |

### 3-D. 피할 것

| ✕ **뿌리째** | 50번 선점 |
| ✕ **삭제·박멸·순삭·쏙** | 동사 점유 완료 |
| ✕ **녹이는** | 39번 + 쏙모팩 Step1 + 타겟 처형 축 |
| ✕ 탄닌 | 메라블 "탄닌샷" 선점 → 나이아신아마이드 유지 |
| △ 쿨 타이트닝 | 오브제가 쓰지만 **씻어내는 클레이라 가능한 것**. 필오프+눈시림 리스크로 우리는 불가 |

## 4. 미확인

- 각 소재의 실제 성과(도달·전환) — 소재만 봤지 성과는 모름
- 상페 링크 14개 중 3개만 판독. 나머지(클럽클리오·풀리·인포디플러스·올리브영 3건 등) 미판독
- 노일리 "효소" 정체 — 상페에 미기재라 제품 실물·전성분 확인 필요
