# DA 속모증 — USP·상징재 재발굴 88건 판정

> **방법**: 6개 렌즈(물리 기전 / 생물·성분 / 인접 산업 이식 / 상징재 7+2 도구 전수 / 결핍 재정의 / 쏙모팩 구조적 빈칸)로 후보를 발굴하고, 각 후보를 [[DA 기획 판정 룰]] ⓪+14관문 · §2 기전 · §3 base×MSG · §7 참신성 · [[DA 제품 소싱 기준]] 게이트로 판정.
> **입력 제약**: 사장님 기각 11건 전부 학습 · 케라틴 환원제 계열 제외 · **유럽·중동 체모(취약형)는 확정 축**으로 고정 · 코+등+바디 전 부위 · 20~30대 여성 · 화장품 착지 · 원가율 30%.
> **판정 결과**: 88건 중 ★★★ 13 · ★★ 23 · ★ 20 · ✕ 32
> ⚠️ **미완 고지**: 적대적 반박(refute) 단계와 최종 종합은 **월 사용 한도로 실행되지 못했다.** 아래는 **판정 단계까지의 결과**이고, 사장님 기각 패턴으로 한 번 더 털지 않은 상태다.

---

## 0. 88건이 확증한 것 — 상징원 슬롯은 공집합이다

**거의 모든 후보가 `§1① 상징원 칸 못 채움`을 스스로 자인했다.** 전수 조사로 확인된 결론이다.

> 속모증은 [[DA 기획 판정 룰]] §0의 3슬롯 중 **상징원 칸을 채울 후보가 존재하지 않는 결핍**이다.
> 치료법 4개(용해제·트레티노인·핀셋·레이저제모)가 전부 관문에서 죽고, 밖에서 끌어온 것은 §1①(그 결핍의 치료법이 아님)에서 죽는다.

→ [[쏙모팩]]이 상징원 없이 파는 것은 게으름이 아니라 **카테고리의 구조**다. 이건 이제 추정이 아니라 88건 전수 근거가 있다.
→ 따라서 이 결핍의 승부는 **"상징원을 찾는다"가 아니라 "상징원 없이 이긴다"**로 전환해야 한다.

## 1. 🔴 최대 발견 — 쏙모팩의 처형 목록에 없는 동사

여러 렌즈가 **독립적으로 같은 지점**을 짚었다. 이번 라운드에서 가장 값나가는 발견이다.

쏙모팩 상페와 소재의 적 프레임 처형 문장은 정확히 이것이다:

> 상페: *"그동안 피지, 블랙헤드인 줄 알고 **녹이고 짜고 떼어내도** 소용 없던 당신을 위한"*
> 소재 v17 음성: *"피지가 아니니까 **녹여서 안 됐던 거고** / **뽑아줘야** 정리되는 건데"*

**그들은 광고비를 태워 "녹이는 건 실패한 방법"을 시장 상식으로 심어놨다.**

| 동사 | 상태 | 여기 들어가는 후보 |
|---|---|---|
| **녹인다** | 🔴 **처형됨** | 효소 · BHA · 클레이 · 온열('녹인다'로 말할 때) · 용해제 2제 키트 |
| **짠다** | 🔴 처형됨 | 압출 |
| **뗀다** | ⚠️ 그들 자신의 동사 | 필오프 (그들이 정당화해놓음 — 우리도 쓸 수 있으나 차별 아님) |
| **불린다** | ✅ **목록에 없음** | 폐색 하이드레이션 · 온열(불림으로 말할 때) |
| **뚫는다** | ✅ **목록에 없음** | 스피큘 |
| **밀어낸다** | ✅ **목록에 없음** | 탄산 발포 · 팽윤 압출 |
| **걷어낸다** | ✅ **목록에 없음** | 자석 인출 · 퍼티 |

> **효소·BHA로 들어가면 그들이 파놓은 무덤에 우리가 들어간다.** 타겟은 이미 *"그거 해봤는데 안 되던데"*로 반응하도록 학습돼 있다.
> **"안 불려서 안 나온 겁니다"** — 그들의 *"떼도 안 나온 이유"*를 다른 원인으로 재정의하면, 원인 규명형 문법을 **그들과 겹치지 않는 새 각도**로 다시 쓸 수 있다. 적 프레임 흡수가 아니라 **적 프레임 우회**다.

## 2. §1④ 직관성을 통과한 축 — "설명 0초"

성분·기술 후보를 가장 많이 죽인 관문이다. 이걸 통과한 것만 추렸다.

| base 통념 | 강도 | 붙는 후보 |
|---|---|---|
| **"때는 불려야 밀린다"** | **★★★★ 최강** | 폐색 하이드레이션 — **[[상징재 실측 데이터]] base 사전에 없는 신규 항목**. 직관성과 참신성이 동시에 최상인 유일 축 |
| **"막힌 길을 뚫어야 나온다"**(배수구) | ★★★ | 스피큘 |
| **"등은 손이 안 닿는다"** | ★★★ | 롱리치 어플리케이터 |
| **"자석이 끌어당긴다"** | ★★★ | 자성 겔 (⚠️ *"털은 쇠가 아닌데?"* 반문 있음) |
| **"틈에 눌렀다 떼면 먼지가 나온다"**(키보드) | ★★★ | 점탄성 퍼티 |
| **"털에는 왁스가 붙는다"** | ★★★ | 소수성 선택 코팅 (⚠️ '왁스' 단어는 기각②를 뒤집어씀 — 네이밍 회피 필수) |
| **"기포가 밀어올린다"**(사이다) | ★★★ | 탄산 발포 |
| **"돋보기로 보면 진짜가 보인다"** | ★★★ | 확대경·현미경 동봉 |
| **"약국 갈색병 액은 진짜 뭘 녹인다"** | ★★★ | 약 외형 차용 (⚠️ '녹인다'라 §1과 충돌) |

**전부 base다. 상징이 아니다.** [[DA 기획 판정 룰]] §3 경고 그대로 — base는 직관을, 상징재는 우월성을 담당한다. 우월성 칸은 여전히 비어 있다.

## 3. 게이트9를 진짜로 통과하는 것 — 생산에 박히는 USP

사장님 이번 라운드 요구에 직접 답하는 부분이다. **복제 장벽 순.**

| # | USP | 장벽의 정체 | 강도 | 자사 자산 |
|---|---|---|---|---|
| **1** | **부위별 3제형 키트** (코=인출 / 팔=용해 / 등=용해+인출) | 3처방·3용기·**3품목보고번호**. 쏙모팩이 따라오려면 **1SKU 회사가 3SKU 회사로** 바뀌어야 한다 — 재고·MOQ·CS·상페·세트가 전부 재설계 | **상** | — |
| **2** | **스피큘 분산 필오프** | 포렉셀™ 4종은 **전부 수상 추출물**이라 그 처방 체계 밖. 침전 방지·점도 설계로 처방을 통째로 다시 짜야 함 | **상** | 🔴 **자사 [[써모드 PLX]]·[[히토 온천크림]]에서 운용 중** — 조달선·분산 노하우 보유 |
| **3** | **무수 2제형** (파우더 + 활성화액) | **물리 법칙이 장벽** — 효소·불안정 성분은 물에 닿으면 실활. 50ml 수성 튜브 라인으로는 구조적 불가, OEM을 갈아야 함 | **상** | — |
| **4** | **점탄성 퍼티** (눌렀다 뗀다) | 혼련·숙성·덩어리 충전은 **튜브 충전 라인으로 물리적 불가** | 상 | — |
| **5** | **자성 겔 + 네오디뮴 스틱** | 요변성(자성분말 침강) 배합 노하우 + 부품 동봉 물류 | 중~상 | 🔴 **자사 [[한의비책]] 네오디뮴 조달선 보유** |
| **6** | **미세후크 부직포 시트** | 위생재 컨버팅 공급망·다이컷 금형·박리력 스펙을 새로 뚫어야 함 | 상 | — |
| **7** | **EU CPNP 등록** | 배합을 **EU 금지·제한 기준으로 재설계** → 규제가 실제로 배합에 박힌다 | 중 | — |
| **8** | **인체적용시험 수치 선점** | "모공당 함입 연모 감소율" 프로토콜을 **처음 설계하는 자리는 한 번뿐** | 중 | — |

> 🔴 **2번과 5번이 실무적으로 가장 값지다** — 이 목록에서 **자사가 이미 가진 자산으로 장벽을 세우는 유일한 후보**다. 조달선·운용 경험·원가 구조가 확보돼 있어 다른 후보의 "확인 필요"가 없다.

⚠️ **게이트9는 게이트6(원가율 30%)과 정면 충돌한다.** 위키 경고 그대로 — *"생산 장벽은 대개 돈이다."* 듀얼챔버 전용 금형(2,000~5,000만원)은 39,900 가격대와 충돌하므로 **스틱파우치로 내려야** 현실적이다.

## 4. 쏙모팩이 통째로 비워둔 칸 (실측 확인)

상징원이 없어도 **여기를 채우면 층이 갈린다.**

| 빈칸 | 쏙모팩 현황 | 우리가 채우는 법 |
|---|---|---|
| **체감 서사** | **0** — 상온 필오프라 아무 느낌이 없다 | 불림 온열 / 스피큘 따끔 / 탄산 청량 → **주의사항 01에 심기**([[한의비책]] 문법, 비용 0) |
| **효능 수치** | **0** — 유일한 숫자가 재구매 97%(자체 설문·출처 미표기) | 인체적용시험 "모공당 함입모 감소율" |
| **제3자 발행 문서** | **0** — 전부 자기가 만든 숫자(No.1·오늘 194명·재구매 97%) | 특허공보·원료사 시트·시험성적서·보험증서 ([[미녹산정]] 문법, 조달비 ≈ 0) |
| **외국·국가 상징** | **0** — 뱃지 4종에 외국 요소가 없다 | **EU CPNP + 유럽 역수출** |
| **도구 동봉** | **0** | 확대경 · 롱리치 어플리케이터 |

## 5. 승인축(유럽·중동 체모)의 물리 구현체

사장님이 *"좋음"*으로 승인한 유일한 축이고, 88건 중 **이걸 물리적으로 구현하는 후보는 하나뿐**이다.

### EU CPNP 등록 + 유럽 역수출 프레임

> 후킹: *"체모가 굵고 많은 유럽에서도 팝니다 — 거기서 되면 여기선 더 되죠."*

**§1④-b 신규 룰을 통과한다** — 일본 기각과 정확히 갈리는 지점:

| | 국가↔결핍 연결이 통념인가 |
|---|---|
| 일본 = 모공케어 | **✕** *"100명 중 1명 말할까"* → 기각 |
| **유럽 = 체모 굵고 많음** | **✅ 통념** → 통과 |

- §4 취약형 성립 3조건 전부 충족 (①통념 ②우월 집단 ③타겟이 자기를 더 가벼운 조건으로 인식)
- 역수출 프레임은 [[한의비책]] *"파스 강국 일본으로 역수출 대란"*으로 실측 검증된 문법 — 여기서는 **우월형이 아니라 취약형으로 변주**된다
- 부수 효과로 **현지어 원문 후기·수출가 병기**까지 §4 도구가 연쇄로 열린다
- ⚠️ **중동은 분리할 것** — 유럽은 MSG 풀 등재 우월 국가라 안전하지만 **중동은 MSG 풀에 없고** *"인도는 우월한 느낌 안 남"*과 같은 사인으로 흔들린다. 상페는 유럽 비중을 올리고 중동은 체모 통념 근거로만.
- ⚠️ **§5-B 하드** — 국가 단독은 실전 미달. **반드시 중심축 위에 얹어야 하는데, 그 중심축이 아직 없다.**

## 6. 추천 조합 2안

### A안 — "불림" 축 (적 프레임 우회 최대화)

```
서사      "녹여서 안 된 게 아니라, 안 불려서 안 나온 겁니다"
1단      불림 — 폐색 하이드레이션 (base ★★★★, 처형 목록 밖)
2단      뚫기 — 스피큘 (자사 기보유 · 포렉셀 처방 체계 밖)
3단      뽑기 — 필오프 인출 (①제거형 BNA 유지)
생산 USP  무수 2제형 + 스피큘 분산 (게이트9 상)
승인축    EU CPNP + 유럽 역수출 (4겹째)
도구      확대경 + 롱리치 어플리케이터
```
- **강점**: §1④ 최강 base 2개(불림·뚫기), 처형 목록 완전 회피, 자사 자산 활용, 체감 3중
- **약점**: 상징원 칸 여전히 공백. §5 다층은 채우지만 §0 3슬롯은 못 채운다

### B안 — "걷어냄" 축 (자극 0 + 시각 충격 최대화)

```
서사      "뜯지 않습니다. 걷어냅니다"
기전      소수성 선택 코팅(털에만 붙어 굳음) → 자석으로 겔막 인출
생산 USP  자성 겔 요변성 배합 + 네오디뮴 스틱 (자사 조달선 보유)
승인축    EU CPNP + 유럽 역수출
BNA      자석에 검은 겔이 딸려 올라오는 장면 = ①제거형 + ②장비 시각화 하이브리드
```
- **강점**: **§1⑤ 자극 최저** — 뜯지 않으므로 코·얼굴 하드 제약을 완전 통과. 기각②(왁싱 코 부담)를 정면 해소하는 유일 축. BNA가 동영상 친화적
- **약점**: §2 물리 모순 지적 있음 — *"굳혀야 뽑히는데 자석으로 걷으려면 안 굳어야 한다"*. 자석은 **떼는 방법**만 바꾸고 **잡는 방법**은 안 바꾼다. §7 마그네틱 클레이 마스크 선례
- ⚠️ 표시광고: *"자력으로 털을 뽑는다"*는 허위 소지. **"겔이 잡은 것을 자석이 걷어냅니다"** 선을 넘지 말 것

## 7. 정직한 빈칸

1. **상징원(우월성) 칸은 88건으로도 안 채워졌다.** 나온 것은 전부 base(직관) 또는 생산 USP(장벽)이고, *"나보다 우월한 존재"*는 없다.
2. **적대적 반박을 못 돌렸다.** 위 판정은 게이트 통과 여부까지이고, 사장님 기각 패턴으로 한 번 더 털면 상당수가 죽을 것이다.
3. **게이트0 시즌** — 바디·등 SKU는 노출 시즌 결핍이다(모공각화증·등드름·제모가 게이트0 예시로 등재). 오늘 8/24 = 노출 시즌 종료. **코 SKU는 시즌 무관이라 안전, 바디는 §5.5대로 폐기가 아니라 예약(역산 2~3월 착수).**
4. **게이트6 vs 게이트9 충돌** — 3SKU·듀얼챔버·부품 동봉은 전부 원가·재고를 올린다. DA는 소재를 돌려봐야 검증되는데(§7) 검증 전 3SKU 선지출은 게이트6.5가 경고한 *"검증 전 재고·시간 선지출"*과 같은 병이다.
