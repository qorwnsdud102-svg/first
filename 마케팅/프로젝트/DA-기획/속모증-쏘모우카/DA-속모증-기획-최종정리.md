## 1. 타겟과 결핍

### 1-1. 감정 구조 — "거리 조건부 수치심"

> *"멀리서보면 피부 완전깨끗하고 **가까이서봐야** 모공이 심한데"*
> *"다른사람들한테 물어봐도 거슬리지는 않는다는데 **내가 거울 볼때마다 거슬림**"*

- **"누가 볼까 봐"가 아니라 "나만 안다"** → **타인 시선 카피 금지**
- 욕망은 우월이 아니라 **평범** (*"다른 애들처럼 피부가 깔끔해졌으면"*) → **미백·광채·도자기 소구 금지**
- 자기혐오 어휘(역겹다·더럽다)는 **타겟이 자기에게 쓰는 말** → 리뷰 인용 형식으로만

### 1-2. 인지 여정 — ④와 ⑤ 사이가 우리 자리

| ① 모름 | *"평생 블랙헤드인줄 알고 살아왔었는데"* |
| ② 시도 | *"클렌징 오일, 밤, 밀크, 코팩 등등 좋다는건 다 써봤어요"* |
| ③ 실패 누적 | *"2년동안 오일 코팩 피지연화제 다 써봤는데 차도가 없더라"* |
| **④ 자각** | *"**어쩐지** ㅈㄴ 안지워지더라"* ← 구매 트리거 |
| **⑤ 견적 좌절** | *"거의 100만원이라 차마 시도를 못하겠고"* ← **DA 진입점** |

### 1-3. 타겟 4갈래 (인물 시나리오 카피용)

| A 학생(중2~대1) | **홈케어 수요가 구조적으로 남는 유일한 계층** — *"엄마가 죽어도 피부과는 안 보내줘서"* |
| B 20~30대 여성 | 주력. 나비존·미간이 코와 동급 — *"화장해도 잘 뭉치기 때문에"* |
| C 20~30대 남성 | 트리거는 성인 진입 — *"군대갔다와서 이제 이런것도 신경써야겠더라고"* |
| D 등·가슴 바디 | 옵션 세그먼트 |

### 1-4. 공통점 — 이미 확대해서 보고 온 사람

> *"**확대해보니까** 거의 다 가시털이더라고요"* · *"**후레시 키고** 자세히 보니"*

→ **진단 도구를 손에 쥔 상태로 상페에 들어온다.** 일반 거리 컷은 증거로 인정 안 된다.

## 3. 제품

### 3-1. 4단계

```
1  녹인다      BHA (살리실산)            각질 마개를 분해해 길을 낸다
2  연다        온감 원료                 모공을 열고 · 효소를 깨우고 · 붙잡는 힘을 푼다
3  뽑는다      브로멜라인 + 필오프        털을 무르게 → 굳으며 수축 → 통째로 인출
4  조인다·진정  나이아신아마이드 · 자작나무 수액
```

### 3-2. 성분 확정 5개

| 성분 | 역할 | 근거 |
|---|---|---|
| **BHA(살리실산)** | 각질 용해 | 지용성이라 **모공 안** 각질용 (AHA는 표면용) |
| **온감 원료** | 🔴 메인 USP | 인출력 = 접착력 vs 붙잡는 힘 → **온열이 유일한 물리적 개입** |
| **브로멜라인** | 연육 | 파인애플 효소. "고기 재우기" 통념 |
| **나이아신아마이드** | 조임 | 모공↔나이아신 화살표 1개. 쏙모팩 미사용 |
| **자작나무 수액** | 진정 + 원물 상징 | 공장 보유 (조달 0) |

**제외**
| ~~탄닌~~ | 자작나무가 원물 상징 칸에서 이탈 + 메라블 탄닌샷(300Da·임상3건)과 비교선상 → 지는 싸움 |
| ~~아데노신~~ | 인지도 화살표 2개 + **주름개선 기능성 고시성분**(표방하려면 심사) + 필오프는 체류 짧음 |
| 진정 예비 | **어성초**(쏙모팩 미사용) — 병풀은 쏙모팩 사용분이라 회피 |

🟢 **성분 수가 적은 것 자체가 소구다** — 랑벨 *"전성분 단 11가지"* 문법. 저자극 인증과 궁합.

### 3-3. 제형·용기

| 제형 | 1제 필오프. 짜서 바르면 20~30분 굳고 떼면 인출 |
| 색 | **짙은 초록** (자작나무 잎) |
| 용기 | 🔴 **범용 경질 자(jar) 100g + 한국 라벨 부착** (150g 라인업 없음) |
| 부속 | 이너캡 · **스패츌러**(위생) |

> **왜 자(jar)인가** — 인쇄 튜브는 MOQ 1만개. 민무늬 튜브는 라벨이 안 붙어 프린팅해야 하고, 그럼 어차피 1만개가 싸다. **경질 용기만 낱개 구매 + 라벨 부착으로 1,000개가 된다** (히토 온천크림 검증 경로).

**라벨 문법 — 히토 자산 재사용** (국가만 교체)
`북유럽 목판 프레임` · `인물/자작나무 판화` · `핀란드어 병기` · `"핀란드산 ○○ 함유"` · `☑온열 ☑연육효소 ☑자작나무` · `짙은 초록 배경`

### 3-4. 스펙 KPI

> **떼어낸 면에 털이 육안으로 보일 것.**

⚠️ 실측 확인: 솜털은 **무색소라 사진에서 거의 백색**(RGB 192~251). 검정 바탕이 대비 7.5~14:1로 최적이고 검증 구매평이 *"까매서 잘보이고"*라 말한다. **짙은 초록은 검정 대비 27~45% 손실** — 세계관을 위해 감수하는 것임을 인지하고 간다.
→ 보완: **매트(무광)** 마감 + 설명서 *"떼어낸 뒤 빛에 비춰보세요"*

## 4. 네이밍 · 가격

### 4-1. 네이밍

```
쏘모우카   ·   핀란드 온열 필오프 팩   ·   100g
 ↑조어(상표)      ↑성질표시(상표 불가, 설명용)
```

- 로마자 **SOMOUKKA** 권장 (핀란드 겹자음 `kk`)
- KIPRIS 국내 상표 `쏘모우카` **0건** (2026-08-26 자체 확인)
- ⚠️ **"핀란드"는 현저한 지리적 명칭이라 상표 불가** → 패키지·상페 문구로만. **제조국 한국 명시**
- 🔴 쏙모 출원→등록 **15개월** → 우리도 **미등록 상태로 런칭**하게 됨. 거절 시 전면 교체 리스크 → **변리사 유사판단 선행**(사장님 진행)

### 4-2. 가격

> **용기 확정: 100g** (범용 자 라인업에 150g이 없음 — 2026-08-26)

| | 쏙모팩 | **우리** |
|---|---|---|
| 가격 | 39,900 | **35,900** |
| 용량 | 50ml | **100g** |
| 단위당 | 798원/ml | **359원/g** |
| 배수 | 기준 | **1/2.2** |

```
단품   35,900          100g
1+1    55,900   개당 27,950   ← BEST
3개    75,900   개당 25,300
```

🟢 **두 축이 동시에 유리하다** — 용량은 2배, 가격은 더 싸다. 한쪽만 유리한 게 아니라 **양쪽 다**라는 점이 카피의 뼈대다.
🟢 **35,900은 "3만원대"로 읽힌다.** 쏙모팩 39,900은 "4만원"으로 읽히고 그게 불만 6.9%다.

⚠️ 🔴 **표기 단위를 ml로 맞춰라.** 쏙모팩이 `50ml`이라 우리가 `100g`이면 소비자가 1초에 비교를 못 한다. 필오프는 비중이 1에 가까우므로 **OEM에 실비중을 확인해 `100ml` 병기가 가능한지** 물을 것. 가능하면 `100ml`로 표기.
⚠️ 원가 미확인 → OEM 견적 후 원가율 30% 재계산.

## 5. USP — 전환 비용 기준

> 게이트9: *"복제 가능성은 **전환 비용**으로 판정한다."*

| # | USP | 경쟁사가 따라오려면 |
|---|---|---|
| **1** | **온열 체감** — 바르면 따뜻해짐 = "열렸다는 신호" | **제형 전면 재개발** (쏙모팩 체감 0) |
| **2** | **핀란드 세계관** | 이름·용기·상페 전량 + 쌓아둔 브랜드검색 27,740 포기 |
| **3** | **저자극 처방** | 불만 1위(자극·눈시림 11.1%)의 역설계 — 처방 재설계 |
| **4** | **100g 대용량(2배) + 자 용기** | 용량·용기·발주 전면 교체 |
| **5** | **어뷰징 안 함** | 이미 한 건 못 되돌린다 (연관검색어 1위가 *"쏙모팩 내돈내산"*) |

🔴 **후발주자의 이점 = 버릴 자산이 없다. 속도가 곧 방어다.**

## 6. 후킹 · 상페

### 6-1. 후킹 (우선순위)

| 1 | **"블랙헤드가 아니라 털입니다"** + 🔴 **"확대해서 보세요. 피지는 안 보이지만 털은 보입니다"** ← 개명 단독은 이제 경쟁 문장이라 증거로 닫아야 함 |
| 2 | **"코 짜지 마세요. 그거 짜서 나오는 게 아닙니다."** ← 금지형(카테고리 표준) + 우리 결핍에서만 사실 |
| 3 | **"짜서 비지가 나오면 블랙헤드. 딸기씨처럼 박혀 있으면 털입니다."** ← 셀프진단 |
| 4 | **"녹여서 빼는 게 아닙니다. 열어서 뽑는 겁니다."** ← 쏙모팩 Step1 정면 |
| 5 | **"고기도 연하게 만드는 효소입니다."** ← 연육 |
| 6 | **"모공 넓어질까 봐 안 뽑으셨죠. 안 뽑아서 넓어지는 겁니다."** ← 역공 |
| 7 | **"용량은 2배, 가격은 더 쌉니다."** ← 가격·용량 (50ml 39,900 vs 100g 35,900 병치) |
| 8 | **"기승전 피부과. 그 피부과를 못 가는 사람들을 위해 만들었습니다."** |

⑥  원리 — 사우나가 열고 · 효소가 무르게 하고 · 굳으며 뽑는다
⑦  🔴 필오프 방어 블록 (§7)
⑧  적 프레임 — 레이저 100만원 · 의사 캡처

### 6-3. 소재 포맷

| **분할화면** | 좌 UGC / 우 고정 오퍼 배너 / 하단 증정 띠 |

## 7. 🔴 방어 — 필오프 처형에 대한 반격

카테고리 상위 3곳이 **우리 제형을 정면 처형** 중이다.

| 풀리 | **"1세대 붙이고 떼는 코팩"** — *"억지로 뽑아내 점점 더 넓어지는 모공"* |
| 노일리 | *"**강제로 뽑아내는 코팩**은 되돌릴 수 없는 모공 확장과 색소침착"* |
| 풀리(그린토마토) | 3컷 처형 — **떼어내기** · 녹이기 · **말리기** (우리 두 축 동시) |

### 반격 3중 배치

```
1  4세대론      1세대 코팩(표면만) → 2세대 오일·연화제(털은 안 녹음)
               → 3세대 필오프(찬 피부에 억지로 뗌) → 4세대 온열 필오프
2  핵심 문장    "찬 피부에서 억지로 뜯는 것과,
                열어서 무르게 한 뒤 뽑는 것은 다릅니다."
3  물증         저자극 인체적용시험 + 자극도 스케일 도표
```

### 참신성 좌표 (정확히)

| 브로멜라인 **배합** | ❌ 풀리 선점 |
| 효소 **"연화"** 서사 | ❌ 노일리(파파인) 선점 |
| 🟢 **연육 비유** | **미선점** |
| 🟢 **털을 대상으로** | **미선점** — 저들은 전부 각질·피지 |

→ 우리 자리는 *"브로멜라인 넣은 최초"*가 아니라 **"연육으로 설명하는 최초"**.

### 규제 방어

| 금지 | "털을 분해한다"(제모 효능) · "모공 속 깊이"(모낭 침투) · 호르몬 표방 |
| 허용선 | 성분 사실 서술 + 체감 서술 + 리뷰 인용 |
| 문법 | 메라블처럼 기전 블록에 각주 — *"원료 고유의 특성에 대한 설명이며 제품 효능·효과를 의미하지 않습니다"* |
