# 휩드(WHIPPED) 상페 해부 — 질감 상징재가 브랜드가 된 사례

> **대상**: ①팩클렌저 단지(5종 세트, 정가 기준 개당 27,000→22,680) ②라보카도 비건 팩스크럽 210g (30,000)
> **방법**: 카페24 lazy-load 상세를 브라우저 렌더링으로 원본 경로 추출 → 이미지 33컷 전량 판독 (2026-08-27)
> **의의**: 질감 탐색 20라운드(음식 원형 접근)의 반성 — **시장 선례부터 검색**했어야 했다. 휩드는 "휘핑크림"이라는 질감 상징재 하나로 히트한 실증.

---

## 0. 성과 권위 (상페 기재)

- **"출시한지 한 달 만에 더현대서울 품절에 이어 성수 오픈런까지 화제성의 중심"**
- 성수 팝업 = 🔴 **핑크 휘핑크림 튜브 모양의 건물 외관** + 오픈런 대기줄 사진 — 질감 상징을 공간으로까지 확장
- 브랜드 정체성: **"비건 힐링 레시피"** · "EVOKE A MEMORY — 따스했던 추억 한 조각이 떠오르는 힐링 레시피" · **"베이커리에서 영감을 받은 레시피"**

## 1. 핵심 문법 8개

### 1-1. 🔴 휘핑 = 공정 수치이자 **기전 근거** (이중 작동)

> **"48시간 숙성, 500회 이상 휘핑"**
> **"500회 이상 휘핑한 포뮬러로 자극 Down, 세정력 Up"**
> *"더 정성스러운 마음으로 1.5배\* 업그레이드된 휘핑 공정으로 만들어진 미세 휘핑 입자가 피부를 깨끗하고 촉촉하게 케어합니다"* (각주: \*기존 팩클렌저 휘핑 300회 대비 1.5배)

떡솝 "1,000번 치댐"과 같은 공정 수치 문법인데 **한 단계 위다** — 휘핑 횟수가 ①정성(공정 서사) ②**자극↓·세정력↑의 기전 근거**(미세 입자)를 동시에 진다. 숫자의 근거(기존 300회 대비 1.5배)까지 각주로 박음.

### 1-2. 🔴 레시피 표기법 (브랜드 시그니처)

성분표를 요리 레시피 단위로 표기 — 박스 패키지에도 동일 인쇄:

```
½ patented        whipped base
1 teaspoon        vegetable glycerin
3 tablespoons     strawberry extract
7 drops           glutathione
3 drops           vitamin C
1 drop            gardenia extract
```

성분 나열이 "레시피"가 되는 순간 베이커리 세계관이 성분 블록까지 침투한다. **세계관을 정보 구획에까지 관철**시킨 사례.

### 1-3. 음식-제형 병치 비주얼

- 스테인리스 볼에 딸기+휘핑크림 (진짜 요리 장면) ↔ 제품 제형
- 🔴 **무화과 토스트에 팩을 버터처럼 바른 컷** · **젤라또 스쿠퍼로 뜬 제형** · 유리 디저트잔에 담은 제형+라임
- 아렌시아 "제형을 음식으로" 코어의 원조격 — 음식 병치가 프리미엄으로 통함을 실증

### 1-4. 🔴 제형 특허 2건

> "특허\* 휘핑크림 팩클렌저 제형 — \*특허 제10-2317773호, 제10-2313498호"

**질감 차별이 특허로 생산에 박힌** 사례 = 게이트9 실증. 텍스처 분해 라벨링(Soft texture=48시간 숙성 500회 휘핑 / Ingredients / Benefits)까지.

### 1-5. 피부고민별 레시피 라인 5종

딸바(생기)·머그트리(수부지 모공진정)·무화과버터(보습장벽)·호호벤더B5(수분장벽)·라보카도(보습탄력) — 각 라인에 주요 성분 3~4개 + **인체시험 이력을 라인별로 명기**. 부위 지도(T존/U존 조합 3안)로 크로스셀.

### 1-6. 수치 스택 (인체적용시험 각주 완비)

자극지수 **0.00**(30분·24시간, 48시간까지) · 세정력 99% · 보습 개선 95% · 수분 62% · 피부투명도 30.63% · 피지 61.89% · 블랙헤드 59.9% · 화이트헤드 57.96% · 탄력 12.29% — 전부 기관·기간·인원 각주.

### 1-7. 🔴 젤라또 텍스처 (라보카도 팩스크럽) — 두 번째 질감 라인

> "매끈한 피부를 위한 **쫀득한 젤라또 텍스처**" · "수분 충전을 위한 **쫀득한 젤라또 스크럽 워시**"

휩드는 질감을 **라인 아이덴티티로 복수 운영** — 휘핑크림(팩클렌저) + 젤라또(팩스크럽). 사장님이 후보로 꺼낸 "젤라또"가 시장에서 이미 "쫀득한 젤라또"로 통용됨을 실증.

### 1-8. 🔴 가문비나무 유래 스크럽제 (핀란드 수종의 화장품 실사용)

> "휩드는 **가문비 나무에서 유래한 평균 300μm 사이즈의 작은 스크럽제**(Microcrystalline Cellulose)를 사용합니다. 미세 플라스틱과 다르게 생분해성이며, 설탕과 소금입자와 다르게 물에 쉽게 녹지 않습니다."

**가문비(Picea) = 핀란드 대표 수종**이 셀룰로오스 형태로 국내 화장품에 실사용되는 실증. 우리가 수지(콜로포니움 알레르기)로 접었던 가문비를 **셀룰로오스 경로**로는 쓸 수 있다는 증거. (단 우리는 필오프라 스크럽제 불필요 — 경로만 기록)

### 기타

- 2모드 사용법(워시오프팩 도톰하게 1분 / 데일리 클렌저) — 떡솝·우리 설계와 동일 문법
- 미산성 pH 스케일 도표(오브제 자극도 도표 문법) · 피부반응도 화살표(0.0→0.0)
- 향 노트 표기(TOP/MIDDLE/BASE + SEASON) — 향수 문법 차용
- 기부 서사("매년 휩드의 생일 9.9 심리적 지원 기부")
- 비주얼 톤: 크림 배경+파스텔, **유럽 홈베이킹·피크닉 무드**, 외국인 모델 — 런베뮤류 "유럽 무드" 문법의 주방 버전

## 2. 우리(쏘모우카) 이식 판정

### 2-A. 가져올 것

| 1 | 🔴 **공정 수치 = 기전 문법** — "N회 치댄/휘핑한"이 정성+기전을 이중으로. 우리 버전: *"○회 치대어 — 치댈수록 찰기가 강해집니다"* (쫀득의 공정 근거). ⚠️ 숫자는 OEM 실공정에서 추출, 각주로 근거 명시 (휩드 문법) |
| 2 | **질감 분해 라벨링** — 제형 접사에 지시선(texture/ingredients/benefits) |
| 3 | **제형 특허 검토** — 텍스처 확정 후 출원하면 게이트9가 문서로 박힘 (휩드 2건 실증) |
| 4 | 음식-제형 병치의 수위 — 휩드가 증명한 것: 음식 연출은 "먹는 것 오인" 걱정보다 프리미엄 효과가 큼 |
| 5 | 자극지수 0.00 + 시간 경과 화살표(24h→48h) 표기법 |

### 2-B. 가져오면 안 되는 것

| 1 | 🔴 **레시피 표기법(teaspoon/drops)** — 휩드의 브랜드 시그니처. 그대로 쓰면 짭 프레임 (§7) |
| 2 | **"베이커리에서 영감받은" 자기소개** — 휩드가 브랜드 정의로 선점. ⚠️ **우리 쫀득 블록의 "중세 베이커리 무드"와 인접 경계**: 휩드=현대 홈베이킹·파스텔·레시피 / 우리=중세 화덕·목판화·사우나 온기. 톤을 이 대비로 유지해야 겹침 회피 |
| 3 | 휘핑크림·파스텔 핑크 톤 — 선점 |

### 2-C. 사장님 4후보 배치 (휩드 실증 기반)

| 후보 | 휩드 실증 | 우리 배치 |
|---|---|---|
| **찹쌀** | — | 🔴 **쫀득(잡는 힘) 축 유지** — 4후보 중 유일하게 "잡음" 직관 보유. 기확정(쫀득 블록) |
| **휘핑크림** | 휩드 본체 — 순함·부드러움·자극↓의 상징으로 작동 | **공정 문법만 차용** ("N회 치댐"). 질감 상징으론 선점 + 잡는 힘 없음 |
| **젤라또** | "쫀득한 젤라또 텍스처" 실사용 | 순함·유럽 무드 보조. 잡는 힘 없음 + 차가움(온열 충돌) |
| **머랭** | 머랭솝(에이프릴스킨) 기실증 | 기판정 유지 — "뿔이 설 때까지" 사용법 언어만 |

→ **순함/강함 분업 룰(§⑤-e) 그대로**: 휘핑·젤라또·머랭은 전부 "순함·부드러움" 계열이라 휩드(클렌저=순함이 본질)에서 작동한 것. 우리 본질은 "잡아서 뽑음"이므로 쫀득 축은 찹쌀 유지가 맞고, 나머지는 무드·공정·사용법 언어로 분업 배치.
