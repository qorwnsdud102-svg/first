# ④ 상징 설계 — 바르는 목 보톡스(가칭 넥톡스)

## 3슬롯
- 결핍: 목에 생긴 줄(가로가 주, 세로 띠·자글거림이 다음)이 고개를 숙일 때마다 접혀 깊어지고, 나이를 드러낸다.
- 상징원: 보톡스(목 보톡스·스킨보톡스) — 주름을 만드는 근육을 잠시 쉬게 해 피부가 접히지 않게 하는 '주름 펴는 주사'. 목주름 시술 2순위(목 이야기 6.2%, 1순위 필러는 사장님 기각 P1200).
- 당위 장치: 바르는 보톡스 성분(아세틸헥사펩타이드-8) + 냉찜질 같은 쿨링 + 1분 뒤 쫀쫀하게 잡아 주는 유연 필름(숙여도 덜 접힘).

## 요소별 담당 칸(④-02)
| 요소 | 칸 | 맡는 일 |
|---|---|---|
| 보톡스 | 상징원 | '주름 펴는 주사'의 이름과 결과 장면(움직여도 안 접힘) |
| 아세틸헥사펩타이드-8 | 기전 재현 부품(원료) | '바르는 보톡스' 성분 — 근육이 접히는 신호를 줄인다고 알려진 펩타이드(P1160·P2078) |
| 쿨링 | 기전 재현 부품(체감) | 보톡스 맞고 냉찜질 — 근육이 쉬는 효과를 오래 가게 한다(P2050) |
| 유연 탄력 필름 | 기전 재현 부품(결과 장면) | 1분 뒤 쫀쫀하게 잡아 고개를 숙여도 덜 접힘 |
| 아데노신(주름개선 기능성 고시 성분) | 권위 | '주름 개선' 기능성 표시 |
| 투명한 연푸른 젤·펌프 병 | 분위기 | 시원함을 눈으로 미리 보이게 — 상징 겹으로 세지 않는다 |

## 상징원의 핵심 장면 해부(④-53) — 받아 본 사람·대중이 기억하는 것
| 칸 | 보톡스 | 핵심 |
|---|---|---|
| 보이는 것 | 작은 주사기로 주름 위를 콕콕. 목은 띠·줄을 따라 점점이 | |
| 느끼는 것 | 작은 바늘 따끔 → 2주 뒤 그 자리가 안 움직이는 느낌. 맞고 나면 냉찜질 | |
| 순서 | 주름 위치 확인 → 콕콕 → 문지르지 말고 냉찜질 → 2주 뒤 효과 → 3~6개월 뒤 다시 | |
| 마지막 장면 | 표정을 짓거나 고개를 숙여도 주름이 안 생기는 매끈한 피부 | ★ 핵심 칸 |
| 이름과 숫자 | 보톡스·스킨보톡스, 1회 7.6만~20만 원(목), 3~6개월 | |

- '그거 어땠어?'에 나오는 첫마디: "주름이 안 생겨" — 목은 받아 본 사람보다 망설이는 사람이 많아 첫마디가 "목에 맞기 무섭다"다(목소리 12단위: "보톡스는 목에못맞는다구하던데요", "목에 필러 보톡스 위험하지 않을까요 무서워요 생긴대로 살래요").
- 고객이 보는 상징원의 모습(④-54): 작은 주사기·이마 콕콕·안 움직이는 이마. 동결건조 가루·바이알·유닛 수는 받아 본 사람만 안다 — 신호로 쓰지 않는다.

## 핵심 코어(④-59)
- 낫게 하는 방식(대중의 말): **주름을 만드는 근육을 쉬게 해서 피부가 접히지 않게 한다 → 주름이 펴진다.**
- 그 방식에서 나온 신호·체감
  - 알아보게 하는 신호: 이름 '넥톡스'(목 + 톡스, ④-51) · 라벨에 '바르는 보톡스 성분 아세틸헥사펩타이드-8'을 크게.
  - 원리와 이어지는 체감: 시원함(냉찜질 — 근육이 쉬는 효과를 오래, P2050) → 1분 뒤 쫀쫀함(접히지 않게 잡음).
  - 결과 장면: 바른 쪽만 고개를 숙여도 덜 접힌다 — 보톡스 마지막 장면과 같은 그림(④-24, 오래 가지 않는 같은 그림 — 시제품 확인 전).
- 상징원 인식 근거(목소리 15파일): 보톡스 — 목에 맞기 무섭다 12 · 효과는 있는데 금방 돌아옴·2~3개월마다 11("2~3개월에한번씩 보톡스가 적당하겄네요"). 받아 본 사람의 몸 기억(따끔·굳음·냉찜질)은 이 목소리에 거의 없다 — 쿨링의 근거는 사장님 판례(P2050)와 시술 뒤 처치 상식이다.

## 제품 설계 — 고객이 보는 모습을 옮긴다
- 제형: 투명한 연푸른 쿨링 젤 앰플. 바르면 시원하고, 1분 안에 얇고 유연한 막이 생겨 쫀쫀하게 잡힌다(갈라지거나 허옇게 일어나지 않는 유연 필름 — 시제품 확인 필요).
- 원료: 아세틸헥사펩타이드-8(바르는 보톡스 성분) · 아데노신(주름개선 기능성) · 유연 필름 원료(풀루란 등) · 쿨링 성분(약하게, 따갑지 않게). 온열 성분은 넣지 않는다(④-07, P2051).
- 용기: 50ml 에어리스 펌프 병(범용) + 라벨·단상자. 투명 몸체로 푸른 젤이 보인다.
- 이름(가칭): 넥톡스 — 써모드(써마지)·유쎄라블(울쎄라)처럼 이름에 시술을 박는다.
- 사용 순서(④-56 — 보톡스 순서를 따른다)
  1. 턱을 살짝 들어 목 줄을 편다(주름 자리 확인).
  2. 펌프 2번을 줄을 따라 얹는다(콕콕 대신 줄을 따라).
  3. 문지르지 말고 손바닥으로 덮어 1분(보톡스 뒤 '문지르지 말고 냉찜질'). 그 1분은 고개를 숙이지 않는다(보톡스 맞고 '바로 눕지 말라'는 수칙처럼 — 막이 잡히는 시간).
  4. 아침·밤 하루 2번.
- 아이코닉한 겉(④-47): 보톡스에는 대중이 아는 겉모습이 없다. 주사기·바이알은 범용 의료 도구라 상징이 아니다(④-46). 그래서 겉은 이름이 맡고, 용기는 범용 펌프 병으로 둔다.

## 옮긴 요소마다 바꿔 넣기(④-58)
| 옮긴 요소 | 다른 시술 이름을 넣으면 | 판정 |
|---|---|---|
| 바르는 보톡스 성분(아세틸헥사펩타이드-8) | '바르는 필러 성분'·'바르는 울쎄라 성분'은 말이 안 된다 | 보톡스만의 것 |
| 숙여도 덜 접힘(결과 장면) | 필러는 '채움', 울쎄라·써마지는 '당겨 올림' — '움직여도 안 접힘'은 보톡스 그림 | 보톡스만의 것 |
| 쿨링(냉찜질) | 울쎄라·써마지는 열이라 안 맞는다. 필러 뒤에도 냉찜질은 한다 | 절반만 고유(경고) |
| 줄을 따라 얹고 문지르지 않기 | 아이크림·앰플도 그렇게 바른다 | 공통 — 분위기로만 |
| '1분은 숙이지 않기·문지르지 않기'를 시술 뒤 수칙으로 부름 | 필러·울쎄라 뒤 수칙(붓기·사우나)과 다르다 — '문지르지 말고 바로 눕지 말라'는 보톡스 쪽 수칙 | 보톡스 쪽(받아 본 사람이 아는 말 — 대중 장면인지는 경고) |
| 이름 '-톡스' | 다른 시술 이름이 들어갈 자리가 아니다 | 겉 칸(이름) |
| 펌프 병·푸른 젤 | 아무 제품에나 쓴다 | 공통 — 분위기로만 |

## 체감마다 '무엇의 증거'인지 — 광고 한 문장
- 시원함 → "시원한 1분은 냉찜질 시간 — 보톡스 맞고 하던 그것."
- 1분 뒤 쫀쫀함 → "쫀쫀해지면, 고개를 숙여도 덜 접힙니다."
- (기획 언어 '근육을 쉬게'·'마비'는 광고에 쓰지 않는다 — ⑧ 현실 보정)

## DA 1초 장면
- 고개를 숙여 휴대폰을 보는 40대 여성의 목 — 가로줄 세 개. 자막 "목에 보톡스, 무서워서 못 맞았다면".
- 2~3초: 왼쪽 절반에만 푸른 젤을 줄을 따라 얹고 손바닥으로 덮는다(자막 "문지르지 말고 1분").
- 마지막: 다시 고개를 숙이면 바른 왼쪽만 줄이 얕다(반반 비교, 연출·개인차 표시 ⑦-12).

## 당위와 값·수고(④-05·④-06)
- 값: 목 보톡스 1회 16.5만~20만 원(보통 이벤트가)·7.6만 원(국산 최저 이벤트가), 3~6개월. 우리 3개월 79,000원 → 보통가의 절반 아래(가격 비대칭, 최저 이벤트가와는 비슷 — 경고).
- 거절 지점(④-06): '목에 주사는 무섭다'가 불만 1위(목 이야기 7.0% — 필러가 하얗게 비침·이동, 보톡스·레이저는 얇은 목·갑상선). 이 인구가 우리 자리다(P2045).
- 직관 자기검증 한 줄: "바르는 보톡스로 목주름 하세요" — 보톡스 = 주름 펴는 주사라 설명 없이 선다. 국가 상징은 쓰지 않아 떼어 낼 것이 없다(④-38 해당 없음).
- 결 일치(④-28): 세로 띠·자글거림·잔주름 100%, 깊은 가로줄 60%(의사들은 깊은 가로줄을 필러 쪽으로 본다).

## 테스트
- 남이 검사: 3회차 생략(④-57)
- 핵심 옮김 검사: 대기

## 걸린 규칙
- ④-08·②-02: 목주름 시술 1순위가 아닌 2순위를 상징원으로 썼다(1순위 필러는 사장님 기각) → 경고.
- ④-05: 최저 이벤트가와 견주면 가격 비대칭이 약하다 → 경고.
- ④-25: "목주름은 보톡스도 안됀다면서요" — 보톡스가 깊은 가로줄에 덜 맞는다는 말이 당사자에게 있다 → 경고.
- ④-54: 보톡스 몸 기억(냉찜질)은 이 목소리에 없고 판례·상식이 근거다 → 경고.
- ④-58: 쿨링은 절반만 고유하다(필러 뒤에도 냉찜질) → 경고.
- ④-24: '숙여도 덜 접힘'은 필름이 내는 오래 가지 않는 그림이다 — 시제품으로 보기 전까지 → 경고.
- ④-47: 따라 할 아이코닉한 겉이 없다(이름이 대신 맡음) → 경고.
- ④-13: 보톡스의 '표정이 굳는다' 연상이 목에서 '목이 굳는다'로 읽히지 않게 '쫀쫀'으로 쓴다 → 경고.
