# ④ 상징 설계 — 목에 붙이고 자는 메피폼(가칭 넥피폼)

## 3슬롯
- 결핍: 목 가로줄(주)·자글거림이 매일 같은 자리에서 접혀(폰 볼 때·베개에) 굳고 깊어져 나이를 드러낸다.
- 상징원: 메피폼 — 수술 흉터에 붙여 두면 덮인 자리가 촉촉하게 갇혀 흉이 부드럽고 납작해지는, 병원이 수술 뒤 붙이게 하는 실리콘 시트의 대표(12,500).
- 당위 장치: 의료용 등급 소프트 실리콘 시트(살색·얇음, 목 곡선) + 자는 동안 붙여 두기·아침에 떼어 헹궈 다시 붙이기 + 떼어 보는 아침 장면.

## 요소별 담당 칸(④-02)
| 요소 | 칸 | 맡는 일 |
|---|---|---|
| 메피폼 | 상징원 | '흉을 납작하게 펴는 병원 시트'의 이름과 마지막 장면 |
| 의료용 등급 소프트 실리콘 겔 시트(살색·얇음, 접착제 없이 붙음) | 기전 재현 부품(제형·도구) | 줄을 덮어 수분을 가두고, 덮인 자리를 접히지 않게 잡는다 |
| 자는 동안 붙여 두기 · 아침에 떼어 헹궈 말려 다시 붙이기 · 2주(14번)면 새 장 | 기전 재현 부품(사용 순서) | 흉터 시트의 '오래 붙여 둘수록' 규칙을 잠자는 시간에 싣는다 |
| 떼어 보는 아침 장면(덮였던 자리만 줄이 얕음) | 기전 재현 부품(결과 장면) | 흉이 납작해진 자리를 떼어 보는 그림 |
| 목 앞 곡선 재단(메피폼 대표 크기 10×18cm 기준)·살색 | 겉(형태) | 메피폼을 써 본 사람이 아는 크기·색 — 모르는 사람이 더 많아 상징 겹으로 세지 않는다 |
| 흰 드레싱 상자·투명 보관 필름·지퍼 파우치 | 분위기 | 병원 드레싱 느낌 — 상징 겹으로 세지 않는다(④-58 흰 의료기기풍) |

## 상징원의 핵심 장면 해부(④-53) — 써 본 사람·대중이 기억하는 것
| 칸 | 메피폼 | 핵심 |
|---|---|---|
| 보이는 것 | 수술 흉터(제왕절개 아랫배, 갑상선 목 가로줄) 위의 살색 얇은 시트. 크기에 맞춰 잘라 붙인다 | |
| 느끼는 것 | 쫀득하게 착 붙고, 떼어도 덜 아프다(제조사 '세이프택'). 땀이 차면 들뜬다 | |
| 순서 | 깨끗하고 마른 피부(연고·로션을 발랐으면 30분 뒤) → 붙인다 → 하루 한 번 떼어 피부와 시트를 씻고 다시 붙인다 → 접착이 떨어지면 새 장(보통 며칠~일주일) → 2~6개월 | |
| 마지막 장면 | 떼어 보면 흉이 부드럽고 납작해져 있다 | ★ 핵심 칸 |
| 이름과 숫자 | 메피폼, 10×18·4×30·5×7.5cm, '제왕절개 메피폼' | |

- '그거 어땠어?'에 나오는 첫마디: "붙여 뒀더니 흉이 덜 올라왔다"·"떼도 안 아프다". 국내 대중 후기 문장은 이번에 확보하지 못했다 — 검색 자동완성 '메피폼 효과 후기'(310)와 해외 환자 후기("흉이 훨씬 납작하고 옅어졌다", Breast Cancer Now 포럼 https://forum.breastcancernow.org/t/using-mepiform-to-reduce-scarring/19624)가 근거다.
- 고객이 보는 상징원의 모습(④-54): 수술 흉터 위의 살색 시트. 목 가로줄 위에 붙은 시트는 갑상선 수술을 겪은 사람과 그 가족이 본다(자동완성 '갑상선 흉터 밴드'·'갑상선 흉터 연고'). 제조사 기술 이름(세이프택)·두께는 써 본 사람만 안다 — 신호로 쓰지 않는다.

## 핵심 코어(④-59)
- 낫게 하는 방식(대중의 말): **흉 위에 실리콘 시트를 붙여 두면 덮인 자리가 촉촉하게 갇혀, 흉이 부드럽고 납작·매끈해진다(오래 붙여 둘수록).** 제조사 설명은 비대 흉터·켈로이드(솟은 흉)지만, 대중은 '흉이 덜 지고 옅고 매끈해진다'로 안다(제왕절개 뒤 예방으로 붙임).
  - 목주름으로: 매일 같은 자리에서 접혀 굳은 줄을 자는 동안 덮어 촉촉하게 가두고, 덮인 동안 접히지 않게 펴 둔다 — 아침에 떼면 매끈해진 그림이 흉터 시트의 마지막 장면과 같다.
  - 쓰는 순간 걸릴 수 있는 생각과 받는 법: "그냥 보습 패치 아냐, 떼면 돌아오잖아" → 메피폼도 하루 한 번 떼었다 다시 붙이며 몇 달을 쌓아 흉을 바꾼다는 기억(흉터 시트 규칙)으로 받는다. 사용 카드에 '8주 동안 매주 같은 각도로 목 사진 한 장' 칸을 둔다(종이 한 장, 부품 추가 없음).
- 그 방식에서 나온 신호·체감(쓰는 순간)
  - 붙이는 순간: 서늘하고 쫀득하게 착 붙어, 턱을 들어 편 줄이 편 그대로 잡힌다(덮음).
  - 누울 때·고개를 숙일 때: 시트 아래 줄이 접히지 않고 버틴다 — 살짝 당기는 느낌(펴 둠).
  - 아침에 뗄 때: 덜 아프게 떨어지고, 덮였던 자리가 촉촉하며 줄이 얕다(결과 장면 — 오래 가지 않는 같은 그림이라 시제품 전까지 경고, ④-24).
- 상징원 인식 근거: 검색(메피폼 12,500 · 제왕절개 메피폼 1,450 · 메피폼 사용법 830 · 메피폼 효과 310 · 흉터 실리콘 시트 350 · 갑상선수술흉터 1,000, 2026-10-12 14:47~14:50), 자동완성('실리콘 패치 흉터'·'목주름 실리콘 패치'·'갑상선 흉터 밴드'), 목소리 "가로 목주름을 흉터개념으로 치료😮"(유튜브 의학채널 비온뒤 목주름 영상 댓글). 목주름 목소리 15파일에서 메피폼·흉터 시트를 말한 단위는 0이다 — 몸 기억의 근거는 목소리가 아니라 검색이다(④-54).

## 제품 설계 — 고객이 보는 모습을 옮긴다
- 형태: 살색의 얇은 의료용 등급 소프트 실리콘 겔 시트. 접착제 없이 실리콘 자체로 붙고 떼어도 덜 아프다(메피폼의 특허 '세이프택'은 쓰지 않고 범용 소프트 실리콘). 메피폼 대표 크기 10×18cm를 목 앞 곡선으로 재단한 1종.
- 구성: 1상자 = 시트 2장(1장 14번 = 2주, 4주분) + 투명 보관 필름 2장 + 지퍼 파우치 + 사용 카드. 화장품 내용물은 넣지 않는다(실리콘은 크림 위에 붙지 않는다 — 메피폼 수칙).
- 이름(가칭): 넥피폼 — 목(넥) + 메피폼의 소리(④-51). 상표 확인은 ⑧.
- 사용 순서(메피폼 순서를 따른다)
  1. 밤에 씻고 목을 완전히 말린다. 시트 자리에는 크림을 바르지 않는다(바른 날은 30분 뒤).
  2. 턱을 들어 줄을 편 채, 시트 아래 가장자리부터 줄을 덮어 붙이고 손바닥으로 10초 눌러 체온으로 붙인다.
  3. 그대로 잔다.
  4. 아침에 떼어 미지근한 물로 헹궈 말리고, 보관 필름에 붙여 둔다.
  5. 14번 쓰면 새 장. 8주를 한 단계로 본다(메피폼 예방 2~6개월).
- 아이코닉한 겉(④-47): 메피폼의 겉은 살색 얇은 시트뿐이고 상자는 흔한 흰 드레싱 상자다. 시트의 색·얇음·크기를 따라 하고, 상자는 분위기로만 둔다(로고·상자 디자인은 따라 하지 않는다 ⑧-02).
- 금기(④-07 — 메피폼 수칙에서): 땀이 많이 차는 여름밤엔 들뜨거나 짓무를 수 있어 시간을 줄인다. 붉어짐·짓무름이 생기면 며칠 쉰다. 상처·염증 자리엔 쓰지 않는다. 냉·온 체감은 넣지 않는다.
- 쓰는 상황(④-60): 흉터엔 하루 12~24시간(샤워 빼고) → 목엔 자는 동안 7~8시간. 덮어 가두고 펴 두는 이유는 잠에서도 그대로 성립하고, 잠은 베개에 목이 접히는 시간이라 더 맞다(목소리 베개·자는 버릇 1.8%, 프렉탈 132일). 시간이 짧아지는 것은 약점 — 사용 카드에 "집에 있는 저녁부터 붙여도 됩니다"를 적는다.

## 옮긴 요소마다 바꿔 넣기(④-58)
| 옮긴 요소 | 다른 시술·약 이름을 넣으면 | 판정 |
|---|---|---|
| 의료용 실리콘 시트를 줄 위에 붙여 두기 | 보톡스·필러·울쎄라·써마지·리쥬란엔 붙여 둘 시트가 없다. 하이드로겔 넥 마스크(젖은 에센스 팩)와도 다르다 | 흉터 시트(대표 메피폼)만의 것 |
| 자는 동안 붙여 두기·오래 붙일수록 납작 | 크림은 하루 2번 바르고, 시술은 몇 달에 한 번이다 | 흉터 시트만의 사용 규칙 |
| 아침에 떼어 헹궈 말려 다시 붙이기·정한 날이 지나면 새 장 | 팩·크림·시술에는 없는 순서 | 실리콘 시트만의 것 |
| 떼어 보는 아침 장면(덮였던 자리만 줄이 얕음) | 보톡스('움직여도 안 접힘')·필러('채워짐')·울쎄라('당겨 올림')의 마지막 장면과 다르다 | 흉이 납작해진 자리를 떼어 보는 그림 — 메피폼 쪽 |
| 떼어도 덜 아픈 소프트 실리콘 | 다른 실리콘 시트에도 비슷한 것이 있다 | 부류 공통 — 체감 칸으로만 |
| 목 곡선 재단(10×18 기준)·살색 | 메피폼을 써 본 사람만 아는 크기·색 | 겉 칸 — 상징 겹으로 세지 않음 |
| 흰 드레싱 상자·손바닥으로 눌러 붙이기 | 아무 의료 제품에나 쓴다 | 공통 — 분위기로만 |

## 체감마다 '무엇의 증거'인지 — 광고 한 문장
- 붙이는 순간 착 잡힘 → "흉을 덮어 펴던 시트가, 지금 목 줄을 편 채로 잡고 있습니다."
- 누워도 시트 아래는 안 접힘 → "베개에 접히던 줄이, 시트 아래에선 접히지 않습니다."
- 아침에 떼면 얕음 → "아침에 떼면 줄이 얕다 — 밤새 덮어 펴 둔 증거입니다."(연출·개인차 표시 ⑦-12)
- ('흉터 치료'·'주름 개선'은 광고에 쓰지 않는다 — ⑧ 현실 보정)

## DA 1초 장면
- 첫 1초: 아침 거울 앞, 40대 여성이 목에서 살색 시트를 천천히 떼어 낸다 — 붙였던 왼쪽만 가로줄이 얕다(반쪽 비교, 연출·개인차 표시 ⑦-12). 자막 "수술 흉터에 붙이던 그 시트, 목에 붙이고 잤더니".
- 2~3초: 전날 밤 — 턱을 들고 줄 위에 시트를 붙여 손바닥으로 누른 뒤 눕는다(자막 "자는 동안 접히지 않게").
- 마지막: 떼어 낸 시트를 물에 헹궈 필름에 다시 붙인다(자막 "2주 다시 붙여 씁니다").

## 당위와 값·수고(④-05·④-06)
- 값: 목 필러 1회 44만 원(약 6개월)·목 보톡스 7.6만~20만 원(3~6개월) → 우리 8주 49,000원(가격 비대칭 통과). 메피폼 자체는 장당 약 44유로(독일 약국, 국내 값 미확인) — 우리 시트 2장 29,000원.
- 거절 지점(④-06): '목에 주사는 무섭다'(불만 1위 5.5~7.0%)·'크림은 효과를 못 믿겠다'("외용품 좀 발라서 주름 제거가 가능하면 노벨상 받을듯") — 바늘 없이, 아침에 눈으로 확인한다.
- 직관 자기검증 한 줄: "흉터를 납작하게 펴던 메피폼, 목주름에 붙이고 주무세요" — 메피폼을 아는 사람(제왕절개·갑상선 수술을 겪은 사람과 가족)에겐 설명 없이 선다. 모르는 사람에겐 '수술 흉터에 붙이는 실리콘 시트' 한 마디가 필요하다.
- 결 일치(④-28): 가로줄·자글거림 100%(덮어 펴는 자리), 세로 띠(근육) 50%.

- 핵심 옮김 검사: 대기

## 걸린 규칙
- ②-02·④-04·④-08·④-21·④-11: 메피폼은 흉터 분야의 유명 상징재이고 목주름 1순위 대안이 아니다. 원인 재정의(접혀 굳은 자국)와 유명 상징재 예외로 받는다. 수술을 겪지 않은 20~30대에겐 '메피폼으로 목주름'이 1초에 안 설 수 있다 → 경고(사장님 판단).
- ④-13: '흉터·수술' 연상이 섞인다("내 목이 흉터냐") — 섞인 경우라 → 경고(사장님 판단).
- ④-54: 메피폼의 몸 기억이 목주름 목소리에 없다(검색이 근거) → 경고.
- ④-24: 아침에 얕은 줄은 오래 가지 않는 같은 그림이다 — 시제품으로 보기 전까지 → 경고.
- ④-47: 따라 할 겉은 살색 시트뿐이다(상자는 흔함) → 경고.

## 통과로 본 것(근거 한 줄)
- ④-58 바꿔 넣기: 몸 칸 넷(시트·밤새 붙이기·헹궈 다시 붙이기·떼어 보는 아침 장면)이 다른 시술·약 이름으로는 말이 안 된다. 공통 요소(흰 상자·손바닥 누르기)는 분위기로만 둔다.
- ④-59 낫게 하는 방식: 덮어 가두고 펴 두는 방식을 시트가 그대로 내고, 붙이는 순간·아침에 뗄 때 느껴진다. 지지기·손상·바늘이 없다.
- ④-60 쓰는 상황: 이유가 잠에서도 성립한다(잠은 베개에 목이 접히는 시간). 붙이는 시간이 12~24시간에서 7~8시간으로 짧아지는 것은 약점으로 기획서 '가장 약한 지점'에 적는다.
- ④-25 담화와의 모순: 원인 믿음 1위는 유전(14.0%)이지만 '타고난 줄도 매일 접혀 깊어진다'는 말은 접힘 쪽 믿음(폰·베개 7.7%)과 함께 설 수 있어 모순으로 보지 않는다.
