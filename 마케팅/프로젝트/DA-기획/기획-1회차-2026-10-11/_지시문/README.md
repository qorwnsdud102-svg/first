# 1회차 지시문 사본 (2026-10-11~12 밤)

리드 세션이 기획자·비평가 에이전트에게 준 지시문 원본이다. 다음 회차는 이 파일을 고쳐 쓴다.

- `planner-prompt.md` — 기획자 1단계 공통 틀(`planner-0N-*.md`는 결핍별로 채운 것)
- `planner-phase2.md` — 2단계(남이 검사·매대 결과를 받아 ⑤~⑧·기획서). 2회차부터는 판단 칸을 처음부터 두 부분으로 쓰게 한다(05 여드름흉터에 쓴 판).
- `planner-2판.md` — 판례 비평을 받아 2판을 만드는 지시. `## 2판` 절은 `## 사장님 채점` 바로 앞에 둔다(채점표가 맨 끝이어야 검사기가 통과).
- `판례비평-지시.md` — 비평가(Explore) 지시. 재료는 기획서 + 사장님 말 모음 7개 + 판정 사례 65장(눈 v2 판정 재료와 같은 사본).
- 남이 검사·매대 표시 지시는 `프로그램/아웃풋/da-planning/references/남이검사-지시문.md`·`매대비율-지시문.md`를 그대로 썼다(매대 표시에는 '(대신)' 표시 한 줄을 더함).
