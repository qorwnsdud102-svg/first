# 바디필링로션 — 대안 카드
> 2026-10-17 집계 방식 소급(M4): 타겟 발화/지식인 답변 분리 — 경험 11건이 전부 지식인 답변이라 타겟 인식 비중은 없음(옛 효과 믿음 55% → 0건; 모공각화증 언급 11 → 2%).

> 근거 파일: `대안/바디필링로션/_재료.md`(정리 단위 14, **경험 발화 11건**, 영상 2/3 받아쓰기: Olive 방송·함익병 제철건강) + **묶음 영상 `묶음/사마귀돌기/_재료-영상.md`의 모공각화증 의사 설명**(세희쌤·제이나·언니네피부과·닥터윤·IM 피부닥터·신은재) + 결핍 재료의 대안 언급 표. 경험이 11건이라 비중은 건수(1건 ≈ 9%)로 읽는다. 비율은 정규식 추정이며 한 발화가 여러 칸에 들 수 있다. 의학 효능은 확정하지 않고 "~라고 설명/말함"으로 적는다. 원인 유형 번호는 `묶음/사마귀돌기/원인원리.md`와 같다.
> 이 대안 재료의 목소리 인용은 6개인데 같은 글이 3번 중복돼 있어(지식인 답변, 끝에 '채택' 글자가 붙은 템플릿형) 고유 인용은 4개뿐이다.

- **한 줄**: 몸에 바르는, 각질을 녹이는 성분(우레아·AHA(락틱·글라이콜릭)·BHA(살리실산)·LHA)이 든 로션. 보습과 각질 정리를 한 번에 하는 제형이다. 목소리에 제품명으로는 유세린 유레아 바디로션·세라비 SA 로션(지식인 답변)이 나오고, 영상에는 락틱애시드 7%·12%짜리 로션과 패드 형태가 나온다.
- **핵심 원리**: 모공각화증은 "녹여서 없애는 것이 가장 좋고 밀어서 없애거나 떼어내서 없애는 게 아니다"(영상: 제이나). AHA는 각질을 녹이는 동시에 수분 공급까지 한다고 설명하고, 락틱애시드 10%와 살리실산 5%를 비교한 논문에서 락틱애시드가 더 효과가 좋았다고 소개한다(영상: 제이나). 세희쌤은 AHA는 각질을 녹이고 BHA는 모공 속 피지를 녹이는 쪽이라 각질 용해는 AHA보다 약하다고 설명한다. 제형은 건조하면서 모공각화증이 있다면 로션이 낫고, 패드는 양이 적어 가성비가 낮아 팔에 한 번씩 슥슥 하기에 맞다고 설명(영상: 세희쌤).
- **맞는 원인 유형**: **⑥·⑦ 모공 각질 마개형**(모공각화증), 특히 건조 악화형. 레이저 제모 뒤 건조해져 오돌토돌이 더 눈에 띄는 경우도 있다는 답변이 있다(지식인 답변).
- **안 맞는 유형 / 확인 결과**
  - **① 편평사마귀(바이러스)**: 홈케어 AHA 필링이 과해 장벽이 무너지면 그 틈으로 바이러스가 번진다고 설명 (영상: 이주희). 셀프 각질 제거·스크럽이 자가접종으로 퍼뜨린다는 설명 (영상: 피부영 유앤영). **편평사마귀는 몸·목에도 있어(허준원·닥터S) 바디필링로션을 바르는 부위와 겹칠 수 있다 — 안내가 반드시 필요한 칸.**
  - ② 비립종: 눈가는 각질 제거가 습진을 악화시킬 수 있어 권하지 않는다고 설명 (영상: 서울대병원tv).
  - ④ 모낭염: 올라왔을 때는 각질제거제를 쉬라고 설명 (영상: 닥터블랑). 결핍 재료의 바디필링 언급은 모낭염 2건·비립종 2건·편평사마귀 0건뿐이다.
  - 염증이 있거나 붉고 까만 모공각화증: 스크럽을 쓰면 안 된다고 설명 (영상: 세희쌤, 로션 얘기는 아님).
  - 어린이: 초등학교 2~3학년은 아하를 아주 약하게, 보습제에 우레아를 섞어 쓰라고 설명 (영상: 언니네피부과).
  - **의사 안의 반대 의견**: 함익병은 일반 각질 제거 자체를 말린다 — "각질은 기와집에 기와장과 똑같다"며 제거하면 일주일 만에 불량 각질이 올라와 또 너덜너덜해지니 보습제로 얌전히 붙여 두라고 설명한다(영상: 함익병, 모공각화증 얘기는 아니고 일반 피부 맥락).
- **USP(받아 본 사람이 기억하는 것)** — 후기가 광고 냄새가 짙다.
  - "모공각화증은 며칠만에 없어지는건 아니고 그래도 한두달정도만 관리해도 없어지는게 눈에 보여요~"(지식인 답변, 위 중복 템플릿 글). 기억되는 건 **'한두 달'이라는 기간**과 순한 바디워시→물기 남았을 때→각질+보습 로션 순서.
  - "빨갛게 우들투들 한 게 항상 있어 왔는데요. 바디로션만 발랐는데도 확실히 까끌까끌 했던 것이 줄었고 피부가 훨씬 더 보들보들해졌습니다. 만졌을 때 확실하게 차이가 있어요"(영상: 제이나, 제품을 보내 2주 써 보게 한 지인 실험 후기 — 협찬 가능성). 기억되는 건 **'까끌 → 보들' 촉감 차이**.
- **타겟 인식(비중, 정규식 추정, 경험 발화 11건 → 타겟 발화 0개·지식인 답변 11개, 건수로 읽기, 옛 → 새)**: 안다 0 · 효과 믿음 55%(6건) → 0건 · 효과 없음 9%(1건) → 답변 1건 · 비싸다 9%(1건) → 답변 1건 · 아프다·마취 0 · 무섭다·부작용 27%(3건) → 답변 3건 · 연예인 0 · 유지·주기 27%(3건) → 답변 3건 · 다운타임 9%(1건) → 0건 · 셀프·집에서 9%(1건) → 답변 1건. **타겟 발화가 0개라 타겟 인식 비중은 낼 수 없다(자료 부족)**
  - **알고 믿는 것 / 못 하는 이유 (본보기 대조)**: 알고 믿는 것 = "아하·바하가 들어간 로션이 도움이 된다"(세희쌤은 유튜브에 그런 영상이 많다고 말함 — 타겟 발화로는 확인 안 됨, 영상 말뿐). 못 하는 이유 = **자극·악화 걱정(3건)과 얼마나·얼마나 자주(3건)** — 둘 다 지식인 답변 칸이다. 비싸서는 1건뿐이다. 모공각화증 결핍에서 바디필링로션 언급은 56건(11%) → 6건(2%)(지식인 답변 칸 50건(28%))으로 우레아크림(15 → 2%)과 같은 칸, 각질제거제(3%, 11건) 다음이다. 본보기(울쎄라)와 비교하면 무섭고 비싼 대안이 아니라 **'써 봐도 못 없앤다'는 한계가 가장 큰 벽**이다 — 세희쌤은 "없앨 수 있어요? 이건 안 되죠", 유전이라 원천 차단은 안 된다고 정리한다.
- **못 하는 이유 1~3순위**
  1. 자극·악화: 세희쌤은 스크럽을 치료제로 알고 매일 쓰면 "진짜 모공각화증에는 정말 독"이고 "싹 벗겨내 그러면 다음 주에 다시 그대로 더 많이 생겨"라고 설명. 닥터윤은 우레아·AHA·살리실산 제품을 보습제 대신 너무 자주·많이 쓰면 오히려 자극이 된다고 설명한다("과유불급"). 지식인 답변 쪽 경험: "때밀이하거나 스크럽으로 밀어내는 건 오히려 더 심해져서 아예 끊었어요".
  2. 못 없앤다·오래 걸린다: 위 세희쌤 설명, 닥터윤 "완치가 어렵다", 지식인 답변 "한두달정도". 사용 간격도 질문 대상이다 — 언니네피부과는 AHA·BHA 필링은 일주일에 두 번 정도로 하고 이후 보습제를 바르라고 설명.
  3. 무엇이 진짜인지 모르고 한 제품으로는 부족하다는 의심: 세희쌤은 한 제품의 살리실산이 "성분표 중에 제일 끝에 들어있는 거 이거 거의 안 들어있는 거예요 보습대다" 라고 판독한다. 지식인 답변은 "등드름과 팔·허벅지의 닭살처럼 오돌토돌한 피부는 원인이 서로 다를 수 있어서 한 가지 제품으로 모두 없애기는 어렵습니다"라고 한다.
  + 패드는 가성비가 낮다 (영상: 세희쌤).
- **가격·통증·지속·부작용 (재료에 있는 것만)**
  - 가격: **자료 부족**(비교용: 우레아 5천 원 · 피부과 회당 10~20만 원은 우레아크림 카드).
  - 통증: 해당 없음. 지속: 제이나 실험 2주 매일, 지식인 답변 한두 달, 필링은 주 2회(언니네피부과). 겨울에 더 심해지고 건조한 환경에서 퍼진다고 설명(영상: 제이나·신은재).
  - 부작용: 따가움·붉어짐(스크럽·과사용 설명 속), 어린이 반응 과할 수 있음(영상: 닥터윤·언니네피부과).
- **제품으로 옮길 수 있는 것** (P6522: USP를 제품에 입힌다)
  - **원리 상징 — 제품이 실제로 담을 수 있는 것**
    - 락틱애시드 숫자: 7%는 약하고 15%는 강할 수 있어 **12% 정도가 적당**(영상: 세희쌤), 10%가 논문 근거(영상: 제이나), 7% 제품은 나이아신아마이드를 함께 담아 거뭇함·색소침착 고민에 맞는다고 소개한다(영상: 제이나). 화장품으로 쓸 수 있는 산 농도 한도는 이 재료에 없다(자료 부족, 규제 확인 필요).
    - 조합: 우레아+AHA+BHA+LHA(지식인 답변), 각질+보습을 한 번에 잡는 로션(유세린 유레아 바디로션·세라비 SA 로션).
    - 쓰는 법: 순한 바디워시 → 물기 어느 정도 남았을 때 → 로션(지식인 답변), 필링은 주 2회 + 보습제(영상: 언니네피부과).
    - **성분 순서·함량 표시**: 세희쌤이 성분표 끝에 든 살리실산을 '거의 안 든 것'으로 읽는다 — 함량 숫자를 앞에 크게 쓰는 것이 신뢰 포인트가 된다.
  - **이미지 상징 — 장면·느낌만**: **"까끌 → 보들" 촉감**, "스크럽 대신 로션 · 밀지 말고 바르세요", "만졌을 때 확실한 차이". 샤워 후 한 번 슥슥 바르는 동작. 참고로 때처럼 밀려 나오는 쾌감을 내는 스크럽 시트가 있으나(검은깨·쌀·흑미강·검정콩이 든 제품, 영상: Olive) 방송에서도 그 부스러기는 제품 자체이지 100% 내 각질이 아니라고 설명했고, 의사들은 밀지 말라고 하므로 이 로션의 원리와 반대다.
  - **없애 줄 단점(기획 각)**: 바디필링로션의 좋은 점(바르기만 하고, 벗기지 않고, 보습과 같이)만 — 자극 → 저농도·장벽 성분 병행, 패드의 가성비 → 대용량 로션, '진짜 함량인가' 의심 → 함량·농도 공개.
  - **규제선**: '모공각화증이 없어진다' 약속 불가. 영상도 유전이라 원천 차단이 안 된다고 정리한다. 편평사마귀가 의심되는 얼굴·목에는 쓰지 말라는 안내가 필요하다.
- **자료 한계**: 경험 11건(타겟 발화 0 · 지식인 답변 11)·고유 인용 4개라 타겟 인식 비중은 낼 수 없다. 지식인 답변은 같은 글이 3번 중복되고 '피부면역앰플'을 끼워 넣어 광고성이 의심된다. 영상 2/3 중 Olive는 때 스크럽 시트, 함익병은 각질 제거 자체를 말리는 일반 피부 강의라 로션 근거가 아니다(반대 의견으로만 사용). 락틱 로션 근거는 이 계열 묶음 영상의 세희쌤·제이나에서 가져왔고 제이나 실험은 제품 제공 협찬일 수 있으며 브랜드명은 전사('엠 락틴')를 확인하지 못했다. 쿠팡 후기는 읽지 않았다.
