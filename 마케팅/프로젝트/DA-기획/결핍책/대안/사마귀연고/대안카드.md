# 사마귀연고 — 대안 카드
> 2026-10-17 집계 방식 소급(M4): 타겟 발화/지식인 답변 분리 — 타겟 인식을 타겟 발화 5개 기준 `옛 → 새`로(효과 믿음 22% → 0%, 아프다 4건은 전부 답변 칸).

> 근거 파일: `대안/사마귀연고/_재료.md`(정리 단위 26, **경험 발화 9건**, 영상 1/2 받아쓰기: 내귀에닥터 한 편) + 묶음 영상(이주희·피부영 유앤영·현무열) + 결핍 재료의 대안 언급 표. 경험이 9건이라 비중은 건수(1건 ≈ 11%)로만 읽는다. 목소리 인용은 6개뿐이고 전부 손·발 사마귀 이야기다. 비율은 정규식 추정이며 한 발화가 여러 칸에 들 수 있다. 의학 효능은 확정하지 않고 "~라고 설명/말함"으로 적는다. 원인 유형 번호는 `묶음/사마귀돌기/원인원리.md`와 같다.

- **한 줄**: 사마귀에 바르는 각질 용해 계열 연고·도포제. 지식인 답변은 "연고는 살리실산 성분이 주로 쓰인다"고 말한다. 한의원 연고와 "사마킬"이라는 제품명도 나온다. 쓰는 방식은 각질을 충분히 불려 뜯어낸 뒤 도포제를 바르고, 굳을 때까지 기다린 다음, 접착력 강한 테이프를 붙이는 것이라고 설명한다 (영상: 내귀에닥터).
- **핵심 원리**: 도포 약재가 사마귀 위에서 하얗게 변하며 딱딱해지는 과정으로 병변을 벗겨내는 쪽이고, 그냥 바르기만 해서는 효과가 없는 경우가 많다고 설명 (영상: 내귀에닥터). 의사는 사마귀가 바이러스 질환이라 면역이 좋아지면 자연 소실도 가능하다고 설명하고, 병원 치료도 결국 면역 반응을 유도하는 방법들을 함께 쓸 때 결과가 좋다고 말한다(영상: 내귀에닥터). 남은 바이러스가 눈에 안 보여 재발처럼 보일 수 있어 2~9개월은 계속 테이핑하고 의심되면 바르는 약으로 다시 시작하라고 권한다(영상: 내귀에닥터).
- **맞는 원인 유형**: **① 바이러스 감염형** 중 **손·발 사마귀**. 영상(세브란스 피부과 오병호)도 인용 6개도 전부 손가락·발바닥 사마귀다. 이 계열의 얼굴·목 **편평사마귀에 바르는 약이 맞다는 영상 근거는 없다.**
- **안 맞는 유형 / 확인 결과**
  - ① 얼굴 편평사마귀: 이주희는 "먹는 약이나 뭐 바르는 약으로는 절대 안 돼요 레이저로 하나 하나씩 다 지져야 됩니다"라고 설명, 피부영 유앤영은 "이 편평 사마귀는 홈케어로 좋아지지 않는다"고 설명. 현무열은 레이저로도 줄지 않는 경우 면역을 증강시키는 방법으로 가야 하며 가장 흔한 게 알다라 크림(이미퀴모드 성분, 처방약)이라고 설명(발췌에서 사용 횟수 앞에 잘림).
  - ② 비립종·④ 모낭염: 재료에 근거 없음(결핍 재료의 언급: 비립종 1%·2건, 모낭염 1건).
  - ⑥ 모공각화증: 결핍 재료에서 사마귀연고 언급이 5%(26건)로 나오지만 **이유를 확인하지 못했다** — 정규식이 '연고' 계열 단어를 넓게 잡았을 가능성이 있다(작성자 추정, 건별 확인 못 함). 모공각화증 의사 영상은 사마귀연고를 말하지 않는다.
  - 얇은 부위: 지식인 답변은 "주변 정상 피부에는 안 닿게 조심하라"고 한다. 얼굴·눈가 사용 안내는 재료에 없다(자료 부족).
- **USP(받아 본 사람이 기억하는 것)** — 후기 자체가 **자료 부족**. 기억되는 것은 효과보다 부작용 쪽이다.
  - "연고를 바르기 시작한 후부터 사마귀 부위 주변 각질이 하얗게 일어나고 밤에는 잠들기 힘들 정도로 가려움이 심해졌습니다. 이게 연고가 작용하는 과정에서 나타나는 자연스러운 현상인지 아니면 혹시 접촉성 피부염 같은 부작용일지 궁금합니다"(지식인 관련도, 30대 중반 남성·손가락 사마귀).
  - "저는 피부면역활성제 챙겨 먹고 운동 꾸준히 했더니 싹 없어졌어요"(지식인 답변, 발바닥 사마귀) — 연고가 아니라 면역 쪽 성공담이다. 광고성일 수 있다.
- **타겟 인식(비중, 정규식 추정, 경험 발화 9건 → 타겟 발화 5개·지식인 답변 4개, 건수로 읽기, 옛 → 새)**: 안다 0 · 효과 믿음 22%(2건) → 0건 · 효과 없음 0 · 비싸다 0 · 아프다·마취 44%(4건) → 타겟 0건 · 답변 4건 · 무섭다·부작용 33%(3건) → 타겟 1건(20%) · 답변 2건 · 연예인 0 · 유지·주기 11%(1건) → 타겟 0건 · 답변 1건 · 다운타임 0 · 셀프·집에서 11%(1건) → 타겟 1건(20%) · 답변 0건
  - **알고 믿는 것 / 못 하는 이유 (본보기 대조)**: 연고가 있다는 건 안다(질문 제목에 연고 이름이 나옴). 믿음은 2건뿐이다 → 0건(M4가 질문형 뺌). '아프다 4건'은 타겟 발화 0건·지식인 답변 4건(100%)으로 갈려 아래 추정이 숫자로 맞았다 — 연고 자체의 통증이 아니라 **연고를 권하는 답변이 병원 냉동치료의 아픔을 끌어와 대비시킨 말**일 가능성이 크다("발에 생긴 사마귀는 냉동치료도 많이 받지만 재발도 잘되고 치료기간도 1년 이상 걸려요. 너무 아파서 비추천하고요" 같은 문장이 사마킬을 권하는 지식인 답변에 들어 있음 — 작성자 추정, 건별 확인 못 함). 울쎄라 본보기와 비교하면 '병원 치료는 아프고 재발한다 → 셀프로 간다'는 구도지만, 셀프 쪽의 효과 믿음이 낮다(타겟 발화에서는 0건).
- **못 하는 이유 1~3순위**
  1. 자극·가려움: 위 지식인 관련도 인용. 답변도 "처음엔 따끔하거나 물집 생길 수 있으니"(지식인 답변).
  2. 오래 걸리고 재발: 테이핑 2~9개월(영상: 내귀에닥터), "사마귀는 hpv바이러스로 생기는거라 이렇게 없애도 면역력 떨어지면 재발할 수 있거든요"(지식인 답변). 번거로움도 있다 — 불리고(미온수 5~10분)·바르고(하루 1~2번)·덮는 3단계(지식인 답변·영상).
  3. 무엇을 써야 할지 혼란: "후시딘, 마데카솔, 사마귀 연고 등 말이 다 달라서 헷갈립니다"(지식인 관련도, 발바닥 사마귀 제거 후), "연고만 바르면 되는 건지, 율무 관리까지 같이 하는 이유가 뭔지 알고 싶습니다"(지식인 관련도).
- **가격·통증·지속·부작용 (재료에 있는 것만)**
  - 가격: **자료 부족**.
  - 통증: 의사 영상은 냉동·블레오마이신 주사처럼 굉장히 아픈 치료와 별로 아프지 않은 자가치료를 나누고, 통증 때문에 병원 치료를 못 하겠다는 사람에게 자가치료를 먼저 권하며 안 되면 아픈 치료로 단계적으로 넘어가자고 설명한다(영상: 내귀에닥터, 전사 '자가치료광고'는 자가치료법으로 보정).
  - 지속: 테이핑 2~9개월(영상). 사용 횟수는 하루 1~2번(지식인 답변).
  - 부작용: 각질 하얗게 일어남·가려움(지식인 관련도), 따끔·물집(지식인 답변).
  - 광고 의심: 지식인 답변에 "사마킬"을 "사마귀 바이러스 억제성분과 재생성분이 들어있어서 연고만 바르는 것보다" 낫다고 권하는 글이 있다(같은 문체의 상품 권유로 보여 걸러 읽음).
- **제품으로 옮길 수 있는 것** (P6522: USP를 제품에 입힌다)
  - **원리 상징 — 제품이 실제로 담을 수 있는 것**: 각질을 녹이는 성분 쪽(지식인 답변이 든 살리실산), **'불리기 → 바르기 → 덮기' 3단계 사용법**과 그것을 한 번에 묶는 **패치 형태**(접착력 강한 테이프 — 영상: 내귀에닥터). 단 사마귀 제거는 의약품 영역이다. 화장품이라면 '돌기 부위 거친 각질 정돈' 정도까지다. 가정용 냉동기(의료기기)가 화장품 대상이 아닌 것과 같은 선이다(냉동치료 카드).
  - **이미지 상징 — 장면·느낌만**: 바르면 하얗게 변해 굳는 시각 변화(영상), 테이프로 덮어 두는 밀봉 장면, "병원 오기 전에 셀프" 구도(영상 제목).
  - **없애 줄 단점(기획 각)**: 병원 치료의 아픔 → 안 아픈 셀프(영상: 내귀에닥터가 가장 먼저 권하는 이유), 자극·가려움, 어떤 연고를 쓸지 헷갈림.
  - **옮길 수 없는 것**: 얼굴 편평사마귀에 직접 쓰는 것(영상 근거 없음 — 의사는 레이저를 말함), '사마귀가 없어진다'는 약속.
- **자료 한계**: 경험 9건(타겟 발화 5 · 지식인 답변 4)이라 인식 비중은 쓸 수 없다. 영상은 1/2만 받아쓰기했고 내귀에닥터는 도포 약재 설명 중에 끊긴다. 인용 6개는 모두 손·발 사마귀이며 얼굴 편평사마귀 목소리는 없다. 지식인 답변에 제품 권유가 섞여 있다. 쿠팡 후기는 읽지 않았다. 가격 자료가 없다.
