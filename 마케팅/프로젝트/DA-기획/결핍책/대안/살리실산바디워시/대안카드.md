# 살리실산바디워시 — 대안 카드

> 2026-10-17 집계 방식 소급(M4): 타겟 발화/지식인 답변 분리 — 효과 믿음 65 → 3(1건), 효과 없음 23 → 17(5건)(타겟 발화 29개, 1건 = 3%포인트). 옛 믿음 65가 바이럴·답변이 부풀린 값이라는 추정이 확인됐고, 표본이 29개로 작아 건수로 읽는다. **16:50 정정(부분 자료 → 전체 자료)**: 16시 소급 때 타겟 발화를 19개로 읽어 '믿음 0건·효과 없음 11%(2건)'으로 적었으나 전체 자료는 29개(믿음 1건·효과 없음 5건)다. 효과 없음이 믿을 만한 신호라는 옛 읽기는 5건으로 방향이 더 받쳐진다(답변 칸에서도 효과 없음 30 > 믿음 25).

> 근거 파일: `대안/살리실산바디워시/_재료.md` (경험 발화 74건 → 76건[표 기준 타겟 발화 29 + 지식인 답변 40], 정리 단위 218 → 228, 재료에 실린 인용 25건, 영상 발췌 3편 — 이 중 등드름 근거로 약하게 쓸 수 있는 것은 1편). 비율은 정규식 추정이며 한 발화가 여러 칸에 들 수 있다. **경험 76건 중 타겟 발화 29개뿐이라 %는 건수로 읽는 편이 낫다**(예: 효과 없음 17% = 5건. 옛 믿음 65% = 48건 → 새 1건). 의학 효능은 확정하지 않고 "~라고 설명/말함"으로 적는다. 원인 유형 번호는 `묶음/모공여드름/원인원리.md`와 같다. **광고성 주의**: 지식인 답변·관련도의 상당수가 상품 순위·블로그 링크를 단 광고 문장이다.

- **한 줄**: 살리실산(BHA)·병풀 같은 각질·피지·진정 성분을 넣은 등·가슴 트러블용 바디워시. 제품 이름이 목소리에 많이 나온다 — 오프온, 일리윤, 다슈 데일리 아크네, 썸블라썸 시카케어 아크네, 셀라힐, 구스투스, 베이솔트, 파티온 노스카나인. 씻어내는 워시에서 패드·미스트로 이동하는 말도 따라 나온다 (아래).
- **핵심 원리**: 영상(루시파크, 등드름 재료)은 BHA가 지용성이라 표피 각질만이 아니라 모공 안쪽의 피지와 각질까지 녹여내고, 색소 침착 부위의 탈락도 부드럽게 유도한다고 설명 — 이 영상의 제품은 패드지만 성분 원리는 같다. 영상(닥터방, 등드름 재료)은 샴푸·헤어 제품·화장품 성분이 등에 남지 않게 약산성 세정제로 충분히 씻어내라고 설명하고, 등은 얼굴보다 피부가 두꺼워 치료에서도 화학적 필링제에 물리적 필링제를 섞어 쓰는 경우가 많다고 설명. 영상(디렉터파이)은 바디워시를 계면활성제 종류(음이온·양쪽성·비이온)와 pH로 나눠 세정력과 자극을 비교한다고 설명 — 등드름에 맞춘 비교는 아니다.
- **맞는 원인 유형**: **B1 두꺼운 각질층·막힘, B2 땀·마찰 뒤 세정, B3 샴푸 잔여물**
  - 심하지 않은 등드름: "살리실릭애씨드나 병풀추출물 등등 여드름 진정에 좋은 기능성분이 들어간 등드름바디워시들이 많이 … 심하지 않은 등드름은 등드름바디워시로도 충분히 케어할 수 있으니" (지식인 답변 — 상품 안내 문장이라 광고 의심).
  - 샤워 순서: "린스 다 하고 바디워시 가장 마지막에 쓰고 있긴 한거지? … 샤워 순서만 바꿔도 좋은뎅" (블라인드) — 제품보다 **순서**가 해법이라는 B3 목소리.
  - 대안 언급 비중: 등드름 45건(6%) → 타겟 발화 6건(1%)·지식인 답변 40건(16%) — 답변 칸에서는 각질제거제(109건, 14% → 타겟 26건, 3%·답변 97건 38%) 다음으로 많은 제품형 대안이나 타겟 발화로는 시카크림(9건)·아큐탄(8건) 다음 4위다. 넓은모공 1건 → 타겟 1건, 성인여드름 1건 → 타겟 1건이라 **등드름 전용 대안**이다(타겟이 직접 말한 건 6건뿐이고 답변자가 권한 이름이 더 많다).
- **안 맞는 유형 / 확인 결과**
  - **곰팡이성 모낭염(B4)**: 항진균제가 맞는 질환이라 바디워시로 풀리지 않는다고 설명 (영상: 세희쌤, 등드름 재료).
  - **염증이 심한 등드름**: 약(바르는 약·먹는 약)과 피지선 치료가 필요하다고 설명 (영상: 닥터방·심현철). 타겟도 "피부과에 가도 효과가없고 …"라며 병원을 거쳐 온 경우가 있다 (지식인 최신).
  - **민감·건조**: "각질 필링 성분이 포함된 바디워시라서 피부에 민감하신 분들은 격일로 사용하시는 것도 좋습니다. 몸에 너무 장시간 접촉하지 않는 것이 좋구요" (지식인 답변). 사용 뒤 "바디로션 필수" (같은 답변).
  - **유분 많은 보습**: 바디 오일은 쓰지 말고 수분 로션을 쓰라고 설명 (영상: 닥터방).
- **USP(받아 본 사람이 기억하는 것)** — 둘 다 바이럴·광고 의심이라 약하다.
  - "내가 등드름러인데 딴에는 이것저것 해봐도 효과 없었거든? 근데 … 걔네집 놀러갔다가 본 등드름 바디워시 똑같은거 사서 써봤더니 살면서 본 제등 중에 제일 매끈해짐ㅋㅋ 인생 등짝 됐다아!" (네이트판)
  - "살리실산 과 피지 조절 성분이 같이 있어 등·가슴 쪽 오돌토돌한 트러블이 정돈되는 느낌이 확실히" (지식인 관련도, 제품 후기 형식이라 광고 의심)
  - 기억되는 것 = **'인생 등짝'(매끈한 등)**, '정돈되는 느낌'.
- **타겟 인식(비중, 정규식 추정, 타겟 발화 29개 기준 — 옛: 경험 발화 74건)**: 안다 12 → 14 · 효과 믿음 65 → 3 · 효과 없음 23 → 17 · 비싸다 9 → 3 · 아프다 4 → 3 · 무섭다 1 → 0 · 연예인 3 → 3 · 유지·주기 5 → 3 · 다운타임 0 → 0 · 셀프 3 → 0
  - 지식인 답변 40개 칸(흔히 설명하는 쪽, 참고): 안다 15 · 효과 믿음 25 · 효과 없음 30 · 비싸다 15 · 아프다 5 · 무섭다 2 · 연예인 2 · 유지·주기 8 · 다운타임 0 · 셀프 5. 답변 칸에서도 효과 없음(30)이 믿음(25)보다 크다.
  - **한 줄 요약**: 믿음 65%(48건) → **3%(타겟 발화 1건)** — 바이럴·광고성 답변이 섞여 부풀려졌을 것이라는 옛 추정이 맞았다(답변 칸에는 25). **효과 없음 23%(17건) → 17%(5건)** 이 믿을 만한 신호라는 읽기는 건수가 5건이라 방향만 유지한다(답변 칸에서도 효과 없음 30 > 믿음 25). 장벽은 가격·무서움이 아니라 **'바꿔도 달라지는 게 없다 / 뭘 골라야 할지 모르겠다'** 이다. 누구인가: 여름에 나시·파인 옷을 못 입는 20·30대, 학생, 연인에게 등드름 얘기를 꺼냈다가 싸늘해진 남성 글(루리웹: "여친한테 등드름 얘기 꺼낸거 선넘음?" — 등드름이 친밀한 관계에서 부끄러움으로 드러나는 장면).
- **못 하는 이유 1~3순위**
  1. **효과 불신('바디워시는 다 비슷')** — "뭔 바디워시는 오프온같은거나 추천해주기만해서 좀 화나네 ㅠ" (DC인사이드). 등드름 재료의 같은 호소: "등전용 클렌저 따로 씀: 처음엔 좀 나아지나 했는데 한 달 지나니까 그냥 똑같음" (네이트판) · "여드름 전용 클렌져도 사용해봤는데 달라지는걸 모르겠네요ㅠ 그 와중에 몸은 더 건조해지는 느낌인데" (지식인 관련도).
  2. **뭘 고를지 모름(선택 피로)** — "등드름 바디워시 괜찮은 거 있을까요? … 고를 때 팁이나 괜찮은 성분 있으면 추천 좀 해주세요" (지식인 관련도) · "제가 찾아본게 일리윤 바이오가 오프온 이렇게 찾아봤는데 어떤게 좋을까요 … 바디미스트도 사용하는게 좋은지" (지식인 최신).
  3. **워시만으로 끝나지 않음 / 이것저것 사 모음** — 보습까지 이어져야 하고, 타겟은 워시 말고 패드·미스트로 옮겨 간다: "낫포유바디미스트 일본에서좋다는바디미스트 등드름바디워시 등등등" (지식인 최신), "낫포유 바디미스트, 플루 바디스크럽, 파티온 바디워시, 트리헛 바디스크럽 써봤는데 효과는 있었지만 아예 사라지지는 않았어요" (지식인 관련도, 등드름 재료). 영상(해피해은)은 스트라이덱스 패드로 샤워 후 닦고 바디미스트를 같이 쓰는 조합을 "효과 직빵"이라고 소개 — 제품 소개성 영상이라 걸러 읽는다.
- **가격·통증·지속·부작용 (재료에 있는 것만)**
  - 가격: 다슈 데일리 아크네 500g 14,950원, 썸블라썸 시카케어 아크네 1000g 17,580원 (지식인 답변의 순위 글 — 광고성, 시점 불명).
  - 통증: 해당 없음. 부작용: 건조(타겟 호소), 필링 성분이라 민감하면 격일.
  - 지속: 사용 기간 판단은 "지금 한달정도" 쓰는 후기 정도 (지식인 답변, 셀라힐 광고 의심). 효과가 보이기까지의 기간은 **자료 부족**.
- **산 사람이 실망한 것** — 쿠팡 후기는 이 재료에 없음(**쿠팡 후기 대기**). 위 '못 하는 이유'가 지식인·커뮤니티에서 모은 대체 신호.
- **제품으로 옮길 수 있는 것** (P6522: USP를 제품에 입힌다)
  - 이미 제품 카테고리다 — 옮긴다기보다 **무엇으로 차별하나**가 과제. 흔한 칸 여부는 결핍 책 매대 칸에서 확인한다.
  - **원리 상징(제품이 실제로 담는 것)**: 살리실산(BHA)의 지용성 모공 침투 설명(영상: 루시파크) + 약산성 세정 + 헹굼 때 잔여물 제거 + 세정 뒤 보습까지의 한 세트. 함량·표시 규제는 **규제 확인 필요**.
  - **형태 이동(타겟이 이미 한 일)**: 접촉 시간이 짧은 워시 → 샤워 직후 패드·미스트처럼 머무는 제형. 워시가 약하다는 불신(추정)이 이 이동의 배경으로 읽힌다 — 인용에서 확인한 것은 이동 자체이고 이유는 추정이다.
  - **이미지 상징**: '인생 등짝', 수영장·사우나·오프숄더 장면. 등드름 재료의 호소: "나도 수영장 가고싶고!!! 나도 사우나 가고싶다!!"(블라인드).
  - **사용법 언어**: "샤워 순서(샴푸·린스 뒤 맨 마지막)", "격일", "씻은 뒤 보습 필수".
  - **없애 줄 단점(기획 각)**: 효과 불신 + 건조 + 선택 피로 → '이것 하나'로 단계를 줄이는 구성.
  - **옮기기 어려운 것**: 곰팡이성 모낭염·심한 염증성 등드름을 낫게 한다는 약속.
- **자료 한계**: 인용 25건 중 무관 1건(에펨코리아 닐손쥬니어 글), 장면용으로만 유효한 글 1건(루리웹), 지식인 답변 약 6건은 상품 순위·블로그 링크가 달린 광고 문장이다. 영상 3편 중 2편이 무관하다(리뷰마스터는 일반 상품 순위를 읽는 영상, 삼진메디올은 의료기 매장의 물 없는 샴푸 소개) — 디렉터파이는 일반 바디워시 20여 종 비교라 등드름 근거가 약하고 썸블라썸 시카케어 아크네 소개 중간에서 끊김. 경험 76건(타겟 발화 29개)이라 대표성이 약하다. 연예인 인식 3%(2건) → 3%(1건)의 내용은 확인 못 함.
