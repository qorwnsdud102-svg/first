# 손톱영양제 — 대안 카드

> 2026-10-19 첫 작성(새 방식 M4·M8·M9·M11 처음부터): 근거 `대안/손톱영양제/_재료.md`(정리 단위 211 · 경험 34 = 타겟 발화 21 + 지식인 답변 13, 영상 5/6 받아쓰기 중 재료 발췌 3: 위드샨·YTN 사이언스·티나) + `묶음/발손톱/원인원리.md`(손발톱갈라짐 N1~N8) + `메타판매처/손발톱갈라짐-컨셉.md` + 손발톱갈라짐 쿠팡 후기(케라셀 네일 영양제 1,500개, 작성자가 후기 폴더 xlsx를 정규식으로 센 값은 '작성자 셈'으로 표시). **타겟 발화 21·지식인 답변 13이라 비중은 건수로만 읽는다**(M8, 100개 미만). 의학 효능은 확정하지 않는다.
> 인용은 16개만 실렸다(제목은 25). 16개 중 같은 글의 잡지형 복붙(네이트판 '귀티나는 손 만들기 TIP') 1, 사이트 링크가 붙은 광고성 답변(지식인 관련도 '비타민B7' 답) 1, 몸 관리 루틴 나열(루리웹) 1, 시험 모델 질문 1이 섞여 있어 손톱 영양제 직접 이야기는 12개 안팎이다. 거를 키워드(재료 글자 그대로): `귀티나는 손 만들기` `웹사이트 하나 남기고갈게요` `피부실기`.

- **한 줄**: 손톱에 바르는 영양제·강화제·큐티클 오일(다이소 3,000원짜리부터 OPI 세트 52,800원까지)과, 먹는 손톱 영양제(비오틴 계열 '케라네일', 네이트판 후기)를 함께 부르는 말. 제품명이 목소리에 많이 나온다: 웨이크메이크 스트롱 그로쓰·수운수·다이소 손톱영양제·큐티클 오일·핑크색 영양제(올리브영·다이소), 쿠팡의 케라셀 네일 영양제, 메타의 OPI 네일 엔비·데싱디바 스트로베리 앰플·우아넬 5솔루션 앰플.
- **핵심 원리(영상)**: 영상(위드샨)은 약한 손톱을 두 타입으로 나눈다 — **끝이 겹겹이 갈라지는 타입(손톱 케라틴 층 자체가 약함)은 손톱에 영향을 주는 '강화제', 층은 안 갈라지는데 충격을 받으면 통으로 부러지는 타입은 위에 단단한 막을 씌우는 '하드너'**가 맞고, 브랜드가 둘을 구분해 팔지 않아 사용자가 헷갈린다고 설명한다. 마이뷰티씨는 "영양제를 쓰면 손톱이 튼튼해지는 게 절대 아니고 얇은 손톱 위에 코팅이 되면서 일시적으로 강도가 세지는 것", 강화제는 끝에서부터 벗겨지므로 덧바르고 3~4번에 한 번쯤 지우고 다시 발라야 한다고 설명(뷰티 크리에이터). 파란빛은 영양제(코팅)+모이스처 세럼(보습)+스트렝스너(단단한 막)+비오틴을 같이 쓰라고 한다. 디렉터파이(경험·후기 영상)는 "이미 악화된 후에 영양제나 강화제로 해결하려고 하면 잘 되지 않는다". 박은서 풋클리닉은 샵에서 손톱 전체에 팩을 하고 수분·단백질·케라틴 세럼을 쓰는 프로그램을 10일 주기로 2~3번 한다고 설명(미용실 머리 클리닉처럼).
- **맞는 원인 유형**: N1 수분 부족, N2 네일 시술 뒤(표면 코팅·수분 유지 보조). 쿠팡 후기에서 가장 많은 맥락은 젤네일로 얇아진 손톱(작성자 셈 케라셀 후기 1,500 중 '젤·네일' 28%(424)).
- **안 맞는 유형 / 확인 결과**
  - **N4 전신 질환**: 지식인 답변은 "손톱 영양제 사용 중지하고 전문가 상담 바랍니다"(손톱영양제로 갈라진 틈에 머리카락이 낀 질문에 대한 답, 지식인 답변).
  - **상처·큐티클에 닿는 경우**: 쿠팡 2점 "손톱(살부분)에 자극이 있고 따끔했음 … 손톱살부분까지 발리면 여전히 쓰리고 살이 갈라지더군요"(케라셀).
  - **손톱 물어뜯기·바디 길이**: 인용의 고민이 갈라짐이 아니라 '바디가 짧다'(아래).
  - **'이미 손상된 손톱'**: "이미 손상된 손톱은 회복이 안되는 거고, 새로 나오는 손톱은 건강한 손톱 … 영양제가 크게 도움이 됐다고 생각이 안들어요"(케라셀 2점). 효과를 새 손톱이 나오는 시점으로 판단하는 사람이 있다.
- **USP(받아 본 사람이 기억하는 것)**
  - 쿠팡 케라셀 5점: "처음 며칠은 큰 변화는 없었지만 일주일 정도 지나면서 손톱 갈라짐이 덜해진 느낌이 들었습니다. 특히 끝부분이 자주 깨지던 게 줄어들어서 손톱을 기르기가 훨씬 수월해졌습니다"(2026.03). 기억되는 건 **'일주일 뒤 덜 갈라짐'과 '손톱을 기를 수 있게 됨'**.
  - 쿠팡 케라셀 4점: "대부분 바르고 말리고 지우는 과정이 너무 번거로웠어요 … 기존의 네일 강화제처럼 굳이 말릴 필요도 없고, 지우기 위해 아세톤을 사용할 필요도 없다"(2025.06). 기억되는 건 **번거로움이 없다**. 작성자 셈: 후기 1,500 중 '번들거림·끈적임' 6%(87), '말릴·마르는' 8%(121), '펜·브러시 타입' 6%(85).
  - 메타 영상 문구는 "노 냄새 노 기다림"(데싱디바), "7일 만에 본연의 건강하고 단단한 윤기"(OPI).
- **타겟 인식(비중, 정규식 추정 — 타겟 발화 21 · 지식인 답변 13 · 건수만, 괄호는 건수)**: 안다·들어봄 0 · 효과 믿음 0 · 효과 없음 5%(1) · 비싸다 5%(1) · 아프다 0 · 무섭다·부작용 5%(1) · 연예인 0 · 유지·주기 14%(3) · 다운타임 0 · 셀프·집에서 10%(2). 지식인 답변 13개 칸: 효과 믿음 8%(1) · 무섭다 23%(3) · 유지·주기 8%(1).

  - **결핍 쪽 대안 언급**: 손발톱갈라짐 타겟 발화 35 중 손톱영양제를 말한 글 2건(6%) · 지식인 답변 1건. 발뒤꿈치각질에서는 0건.
