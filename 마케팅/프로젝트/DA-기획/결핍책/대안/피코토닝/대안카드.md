> 근거 파일: `대안/피코토닝/_재료.md` (타겟 발화 139건 · 지식인 답변 42건 — 옛 경험 발화 68건, 재료에 실린 인용 25건, 받아쓴 영상 6/6이나 재료에 발췌가 실린 것은 3편). 비율은 정규식 추정이며 한 발화가 여러 칸에 들 수 있고, 경험 수는 정규식이 엄격해 적게 잡힌다. 의학 효능은 확정하지 않고 "~라고 설명/말함"으로 적는다.

- **한 줄**: 피코초(아주 짧은 펄스) 레이저로 색소를 잘게 부수고 몸이 치우게 하는 색소 토닝. 의사 영상은 "열이 생긴다기보다는 기계적으로 색소를 부수는 특징"이라고 설명하고 기존 토닝(나노초)보다 순간 파워가 세다고 한다 (영상: 닥터펠프스). 다른 의사는 "피코토닝도 결국 레이저 토닝인데 피코라는 장비 자랑"이라고 본다 (영상: 형닥터). 병원에서는 약하게 여러 번 받아 점점 옅게 하는 방식이라고 전해진다 — "IPL 같은 건 쇠망치, 피코는 고무망치"라는 의사 말을 후기자가 전함 (영상: 윰).
- **핵심 원리**: 짧은 펄스로 색소를 기계적으로 파쇄 → 잘게 쪼개진 색소가 시간을 두고 옅어짐. 토닝은 "색소를 죽이지 않고 기절만 시키는 레이저"라서 병변이 깊고 넓고 뭉치지 않은 기미류에 쓴다고 설명 (영상: 형닥터). 피코의 강점으로 "피부결과 모공이 같이 좋아진다"를 든다 (영상: 닥터펠프스). 효과가 나오는 시점·유지 개월은 **자료 부족**.
- **맞는 원인 유형**: **기미(호르몬·자외선) · 염증 후 색소침착(여드름 갈색 자국) · 일부 잡티**
  - 기미: "레이저 토닝은 기미의 교과서적 치료로 생각", 24편 논문 요약에서 기미 심각도 지표가 13.5에서 7.0으로 약 48% 감소 (영상: 형닥터 — 레이저 토닝 전반 수치, 피코 전용 아님).
  - 염증 후 색소침착: 진피성 염증 후 색소침착·오타모반 등에 주로 쓰고 흑자 같은 표피 색소에도 근거가 있다고 설명하지만, "염증 후 색소침착은 좋은 논문이 별로 없다 … 많은 경우 자연 호전돼서 비교도 어렵다" (영상: 형닥터). 목소리: "얼굴에 색소침착이 좀 있어요(여드름 홍조자국)" (에펨코리아).
  - 잡티·주근깨: "경계가 뚜렷한 점 형태라서 토닝만으로는 더디고 스팟 레이저나 피코를 함께 쓴다" (지식인 답변).
- **안 맞는 유형 / 확인 결과**
  - 패인 여드름 흉터 → 토닝이 아니라 피코 프락셀 쪽으로 안내됨: "여드름 시술은 mts 프락셀 피코토닝 이 세 개가 주로 한다던데 거기선 피코프락셀 권함, 의사 말로는 그게 제일 효과 좋다함" (아카라이브). 영상(닥터펠프스)도 피코 MLA 핸드피스를 흉터용으로 따로 설명.
  - 기미·염증성 색소가 섞인 경우 → 오히려 진해질 위험: "에너지가 닿는 순간 멜라닌이 자극받아 오히려 색소가 짙어질 위험" (지식인 답변).
  - 붉은 자국(혈관성)·튼살 → 이 재료에 직접 설명 **자료 부족**. (레이저토닝 재료의 영상은 홍조·모세혈관은 열을 넓게 주는 제네시스 몫이라고 설명.)

- **못 하는 이유 1~3순위**
  1. 오히려 진해질까 무서움(무섭다 14%, 옛 13) — "색소침착 때문에 피코토닝을 받고 싶은데 오히려 피부가 진해질까 걱정됩니다" (지식인 관련도). 답변은 "피코토닝 직후에는 부서진 색소가 표면으로 밀려나와 며칠간 일시적으로 진해 보일 수 있다 … 다만 염증 후 색소침착으로 깊게 굳어질 위험도 분명 존재" (지식인 답변, 대한피부과학회 자료를 들었다고 주장 — 확인 불가). 새 인용: "너무 세게 했는지 없던 기미가 올라왔어요" (82쿡, 삭제된댓글). 상담 현장의 겁주기도 보인다 — "피코토닝은 잡티제거 되지만 레이저토닝만 하면 더 까매질수 있으세요~ 그래도 레이저토닝으로 하고싶으세요?" (DC인사이드, 상담실장 말을 전한 글 — 비싼 쪽을 권하는 말로 읽힘, 추정).
  2. 비쌈·패키지 압박(비싸다 11%, 옛 13) — "듀얼토닝 5회 + 피코토닝 5회 결제 했는데 말하기가 좀 그럴정도로 생각보다 비싸서 환불 할까 고민중" (에펨코리아). "피코10회 / a 5회 … 얼추 100정도 나옴 … 100은 부담스러운데 6,70정도에 저렇게 받긴 힘들거 같고 애매하네" (에펨코리아, 단위 미표기 — 만원으로 읽힘). 새 인용: "지난 주까지 전문의한테 가서 165만원 10회 했으나 아주 살짝 옅어졌을 뿐 그대로여서 열받고 있는 1인으로.." (82쿡).
  3. 효과 불확실·재발·시술자 불신(효과 없음 7% + 유지 6%, 옛 6% + 9%) — 위 지식인 최신 인용. 의사도 "가장 효과가 긴가민가 의사도 환자도 효과를 잘 못 알아보는 데가 많다" (영상: 형닥터). 병원 불신도 있다: "공장에서 피코토닝 받았다가 만족스럽지가 않아서 전문 병원가서 결제한건데 너무 비싸다" (에펨코리아). 새 인용 셋: ① 횟수 말바꿈 — "피부과 전문의였는데 10회만 해도 된다더니 5회 넘서가니까 20,30번 해야 된다고 하더군요 … 피코토닝으로 기미,잡티제거는 사기라고 보시면 됩니다ㅡㅡ" (82쿡, 삭제된댓글). ② 담당 의사가 매번 바뀜 — "시술하는 의사(담당 의사가 따로 없음)가 매번 바뀌니 의사마다 시술 소요시간(그래봈자 몇분짜리임)도 제각각" · "저는 6번 받고 저 시술 중단 때리고 나머지 적립금(포인트)으로 환불받았고" (에펨코리아, 10회를 끊고 6회 받은 뒤). ③ 피코가 낫다는 말 자체를 못 믿음 — "기존 레블라이트보다 효과도 좋지 않으면서 부작용 확률이 높아서 선호하지 않는다고 전문의 몇 명에게 들었음" (82쿡, 삭제된댓글 — 작성자 확인 불가). 의사 영상끼리도 갈리는 곳이다(`묶음/색소흉터/원인원리.md` §5).
- **가격·통증·지속·부작용 (재료에 있는 것만)**
  - 가격: "기미잡티 레이저 10회 패키지는 보통 피코토닝 기준 30만~100만원, 1회당 3만~10만원" (지식인 답변 — 홈케어 블로그 링크가 붙은 광고성 답변이라 걸러 읽기). 에펨코리아 상담 후기는 위 2번 인용(100 안팎).
  - 통증: "제모랑 다른 색다른 따가움" (아카라이브) · "하나도 안아픈거" (에펨코리아). 마취 언급은 같은 글의 리쥬란 얘기라 피코토닝 마취는 **자료 부족**.
  - 지속: **자료 부족**. 10회 패키지에서 5회쯤이면 "주변에서 피부 좋아졌다는 소리 들을 수 있을까요?", 간격은 "일주일로 할지 이주일로 할지" 고민 (지식인 관련도) — 질문 수준.
  - 부작용·회복: 직후 붉은 기·건조는 "레이저 열 에너지로 피부 장벽의 수분이 일시적으로 증발하면서 나타나는 정상적인 반응", 재생 크림은 하루 3~4회 이상 얇게 덧바르고 외출 시 자외선 차단제 병행 (지식인 답변). 윰 영상은 딱지는 없었지만 혈관이 터진 듯한 빨간 점이 오래갔다고 말함(2회차).
- **제품으로 옮길 수 있는 것** (P6522: USP를 제품에 입힌다)
  - **이름·상징**: '토닝'은 타겟이 쓰는 일반명사, '피코'는 병원이 붙인 업그레이드 이름. 다만 장비명이 난립해 차이를 모르는 질문이 많고 연예인 연결도 1건(1%)뿐이라 상징의 힘은 울쎄라보다 약해 보임(추정).

  - **없애 줄 단점(기획 각)**: 비쌈·횟수 압박·진해질까 불안·햇빛 뒤 재발 → "토닝 사이·토닝 후 집에서" 구간. 재료상 병행 요건은 자외선 차단과 보습·재생 케어 (지식인 답변: "시술만 믿기보다는 … 홈케어가 반드시 받쳐줘야"), 새 인용에도 같은 수요가 보인다 — "피코토닝 받는 중인데 크림 병행해본 사람 있어?" (네이트판, 색소 옅어지게 하는 크림을 같이 쓰면 더 좋다고 해서 묻는 글). 
  - **옮기기 어려운 것**: 피코초 에너지로 색소를 부수는 작용 자체. 재료에서 홈케어로 제시된 것(글로스유 크림, medireturn 블로그 링크)은 지식인 광고성 답변이라 근거로 쓰지 않음.
- **자료 한계**: 새 재료 인용 25건 중 무관 1건(아카라이브 윗눈꺼풀·하안검 글), 광고 의심 1건(네이트판 '회사에서 사랑 받는 방법' — 특정 피부과를 칭찬하는 글), 토닝을 직접 말하지 않는 곁다리 2건(MLB파크 의사 실력 논쟁), 중복 1건(지식인 최신 같은 글)이다(수작업 셈). 에펨코리아 439/936으로 남성 피부관리 글에 치우침. 지식인 답변 42건은 n이 작아 방향만 보고, '셀프·집에서' 답변 31%는 홈케어 광고 문구가 걸린 값으로 읽어 실제 수요로 쓰지 않음(추정). 재료에 발췌가 실린 영상은 3편(받아쓴 6/6 중)이라 영상 내용은 옛 카드 그대로이고, 형닥터 영상은 '효과 편'만이라 지속·주기·피코 vs 나노는 이 재료에 없음. 연예인 인식·마취·유지 개월은 재료로 확인 못 함. 쿠팡 후기·메타 광고는 이 재료에 해당 없음.
