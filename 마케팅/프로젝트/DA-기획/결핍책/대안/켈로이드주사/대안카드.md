# 켈로이드주사 — 대안 카드

> 근거 파일: `대안/켈로이드주사/_재료.md` (경험 발화 **21건** = 타겟 발화 15 + 지식인 답변 6, 정리 단위 27, 재료 본문에 실린 인용 **11건**, 영상 1/1) + `묶음/흉터색소2/_재료-영상.md`의 켈로이드 영상 6편. 비율은 정규식 추정이며 경험 21건이라 1건이 약 4.8%p(타겟 발화 15개 기준으로는 약 6.7%p) — **방향만 읽는다.** 의학 효능은 확정하지 않고 "~라고 설명"으로 적는다. 쿠팡 후기는 이 대안에 해당 없음(주사는 병원 시술). '산 사람'은 루리웹·에펨코리아·지식인 질문 몇 건이 전부라 **자료가 얇다.**

- **한 줄**: 켈로이드(과증식 흉터) 병변 안에 스테로이드(트리암시놀론) 또는 항암제를 직접 주사해 단단하게 뭉친 섬유 조직을 줄이는 병원 시술. 신촌연세스타피부과 영상은 "스테로이드 중에서 굳이 트리암시놀론을 쓰는 이유는 주사 부위에 침전물이 생기고 그 침전물이 수개월에 걸쳐 소량씩 녹아 주변 조직에 영향을 미치기 때문에 전신 부작용이 적은 것 같다"고 설명한다. everclinic 영상(시술자)은 항암 계열 주사를 쓰면 볼륨이 줄고 재발이 적다고 말한다. 서울아산병원 영상은 병변내 주사요법을 **"가장 흔히 시행하는 치료, 효과가 우수하지만 통증이 심하다"**고 정리하고, 보통 주사·레이저·냉동·방사선 중 둘 이상을 섞는 복합 치료를 권한다고 설명.
- **핵심 원리**: 과하게 쌓인 콜라겐 섬유(실타래처럼 뭉침)와 염증을 병변 안에서 직접 줄임 → 높이·단단함·가려움이 내려감. 주사가 아픈 이유는 바늘이 아니라 **콜라겐 섬유가 빽빽해 약이 잘 안 들어가는데 억지로 넣을 때 섬유를 찢는 통증**이라고 신촌연세스타 의사가 설명하고, 천천히·젠틀하게 넣으면 통증이 줄 수 있다고 한다(구체 노하우는 영상에서 공개하지 않음).
- **맞는 원인 유형**: **K1 켈로이드(상처 밖으로 번지는 과증식) · K2 비대성 흉터(치료가 큰 틀에서 비슷하다는 설명, 서울아산병원) · K3 붉은기가 남은 활동기 흉터** (원인원리 참고).
  - 효과 쪽 설명(전부 시술하는 쪽 말, 걸러 읽기): "가려움 통증이 거의 80% 이상 경감되고 두세 번 맞으면 높이가 낮아진다"(everclinic). 치료 종료 기준은 **붉은기가 거의 없어질 때까지**이며, 붉은기가 남은 채 중단하면 80~90% 재발, 심한 사람은 10~20번 이상 간다고 설명(신촌연세스타).
  - 목소리의 효과 체감은 1건: "확실히 흉터가 들어갔는데 계속 주사 자국 따라서 빨갛고"(지식인 관련도).
- **안 맞는 유형 / 확인 결과**
  - **색소(갈색) 개선용이 아님** — 영상·인용 모두 높이·단단함·가려움·붉은기 이야기이고 색소를 옅게 한다는 설명은 없다. 검버섯·바디착색에는 해당 없음.
  - **주사 뒤 피부 얇아짐·살패임**: "주사를 맞았는데 살이 패인 것처럼 얇아졌더라구요. 흉터 없애볼려고 맞은 건데 흉터가 더 생겨서 너무 속상한데"(지식인 관련도). 세진성형외과 영상도 스테로이드를 반복 주사하면 **모세혈관이 심하게 비쳐 보이는 경우**가 생기고 부위가 평평해져 흉터처럼 보일 수 있다고 설명.
  - **호르몬 영향 의심**: 지식인 답변은 스테로이드가 소량 흡수돼 드물게 생리 주기 변화·부정출혈이 나타날 수 있다고 설명. 한 질문자는 5년 주사 뒤 여유증이 커진 것 같다고 의심하며 묻는다(인과는 확인되지 않은 타겟의 의심). 인과는 이 재료로 알 수 없다.
  - 주사 사용이 켈로이드 밖으로 번지는 사례: 지방흡입 뒤 턱 밑 뭉침·유착에 맞는 중(지식인 관련도 1건), 표피낭종 제거 뒤 흉터(지식인 관련도 1건). 1~2건이라 경향으로 읽지 않는다.
- **USP(받아 본 사람이 기억하는 것)** — 기억하는 건 효과가 아니라 **아픔**이다.
  - "켈로이드 주사 맞는데 죽는줄... 차라리 사랑니를 세 번 더 뽑을래요... 사랑니가 1이면 이건 한 6쯤 되는거 같음 주사맞은지 30분도 넘어가는데 아직도 다리가 후들거리고 식은땀이 나요"(에펨코리아)
  - "켈로이드 주사 너무 아퍼... 첫주사 맞고 조금밖에 안가라 앉아서 오늘 또 맞았는데 넘모 아퍼"(루리웹)
  - 효과를 기억하는 원문은 이 재료에 **자료 부족.**
- **타겟 인식(비중, 정규식 추정, 타겟 발화 15개; 옛 경험 21건 → 새)**: 안다 1(5%) → 0 · 효과 믿음 1(5%) → 0 · 효과 없음 0 · 비싸다 1(5%) → 0 · **아프다 5(24%) → 3(20%)** · 무섭다·부작용 2(10%) → 0 · 연예인 0 · **유지·주기 6(29%) → 2(13%)** · 다운타임·붓기·멍 1(5%) → 1(7%) · 셀프·집에서 0 (지식인 답변 6개 칸: 유지·주기 67% · 아프다 33% · 무섭다·부작용 33% · 비싸다 17%) — 인용 속 '유지·주기'는 "한달주기로 2회", "2주에 한번씩", "주사를 5년 정도 맞고"처럼 **여러 번·오래 맞는다**는 말이다.
  - 같은 결핍 재료에서 켈로이드 타겟 발화 272개 중 켈로이드주사를 말한 건 31건(11%)(옛 경험 305건 중 46건 15%; 지식인 답변 51개 중 17건 33%) — 켈로이드 타겟이 가장 많이 입에 올리는 대안(정규식 추정).
- **못 하는 이유 1~3순위**
  1. **아프다(24 → 20%)** — "차라리 사랑니를 세 번 더 뽑을래요"(에펨코리아). 시술 전에 이미 아는 사람도 있다: "예전에도 치료받아봐서 아픈 줄 잘 알아서 이 악물고..."(에펨코리아).
  2. **여러 번·오래 찔러야 한다(29 → 13%)** — "나도 이제 너무 커져서 치료할까 하고 동네 피부과에 물어봤는데... 여러번 찌를거라고 해서 쿨하게 포기함 ㅋㅋ"(루리웹). 시작도 못 하고 접는다.
  3. **부작용이 무섭다(10 → 0%, 정규식 0건이나 인용에 질문이 있고 지식인 답변 칸은 33%)** — 살 패임, 생리·여유증 의심 같은 질문이 지식인에 올라온다. 비싸다는 말은 타겟 발화에 없고(1건 5% → 0, 답변 칸 17%) 금액도 없다.
- **가격·통증·지속·부작용(재료에 있는 것만)**
  - 가격: **자료 부족**(금액 없음).
  - 통증: 위 인용 — 사랑니 발치보다 아프다는 표현, 맞은 뒤 30분 넘게 다리가 후들거림(에펨코리아 1건).
  - 지속: 약 효과가 한 달 정도(3~4주)라 다시 딱딱하고 붉어질 수 있고 반복해서 맞아야 한다는 설명(세진성형외과). 붉은기가 사라질 때까지 맞아야 재발이 준다는 설명(신촌연세스타).
  - 부작용: 모세혈관 확장(세진), 살 패임(지식인 질문), 호르몬 변화 가능성(지식인 답변).
- **제품으로 옮길 수 있는 것**
  - **원리 상징은 못 옮긴다**: 이 대안의 핵심은 의사가 주사로 넣는 스테로이드·항암제라서, 화장품·건기식으로 담을 수 있는 성분 근거가 재료에 없다. 켈로이드 개선을 약속하는 제품은 만들지 못한다고 보는 게 안전하다.
  - **옮길 수 있는 USP는 '못 하는 이유의 반대편'**: "그 대안의 좋은 점만, 집에서, 싸게, **아프지 않게**." 타겟이 시작을 접는 이유가 효과 의심이 아니라 아픔(24 → 20%)과 횟수(29 → 13%)이므로, '찌르지 않는 쪽'의 기획이 읽힌다(작성자 해석, 재료에 직접 없음).
  - **이미지 상징 후보**: 병변에 집중해서 천천히 작용한다는 비유(침전물이 수개월 조금씩 녹는다는 설명을 '한 곳에 오래 머무는 방식' 장면으로), '주사 같은 집중 케어' 이름·용기 연상. 성분이 주사약을 담지 않으므로 **원리 상징이 아니라 이미지 상징**이다 — 의약품으로 오인될 표현(주사·치료 효과 약속)은 주의.
  - **옮길 수 있는 감각**: 켈로이드는 가렵고 따끔한 두 증상이 같이 있다는 설명(안성열 영상) → 가려움·따끔함을 가라앉히는 진정 감각은 진정 성분으로 원리 상징이 될 수 있다(켈로이드 개선 약속 없이).
  - **숫자·이름**: 숫자는 '3~4주'(약 효과 설명), '붉은기가 사라질 때까지'(치료 종료 기준) — 체감 기준으로 참고. '켈로이드 주사'는 타겟이 아는 검색어지만 제품 이름에 쓰기는 부적절할 수 있다(의약품 연상).
