# 립밤 — 대안 카드

> 2026-10-17 집계 방식 소급(M4): 타겟 발화/지식인 답변 분리 — 타겟 인식 비중을 경험 발화 28건 기준에서 타겟 발화 12건 기준으로 바꿈(`옛 → 새`; n이 매우 작음). 효과 믿음 46% → 0%(넓게 잡혔다는 의심이 맞았음), 효과 없음 11% → 25%(3건)로 '써도 그때뿐' 1순위 판단은 그대로. 근거 머리말·자료 한계의 옛 n(28 등)은 그대로 둠.

> 근거 파일: `대안/립밤/_재료.md`(경험 발화 28건, 정리 단위 64, 영상 1/3 받아쓰기) + `결핍/구순염/_재료.md`·`결핍/구내염/_재료.md`의 '대안 언급' 표 + `묶음/입/_재료-영상.md`의 구순염 영상 4개(박치영·묘한의사·송현희 2편) + `묶음/입/원인원리.md`(유형 번호 ①~⑦). 비율은 정규식 추정이며 한 발화가 여러 칸에 들 수 있다. 의학 효능은 확정하지 않고 "~라고 설명/말함"으로 적는다. 립밤은 이미 화장품 영역이라 성분 이식 문제는 적고, 대신 **흔한 칸 여부**가 쟁점이다. 쿠팡 후기는 이 단계 입력이 아니다.
> **재료가 얇다**: 단위 64개·경험 28건·영상 1/3. 목소리 인용은 헤더상 25개이나 실제 실린 건 15개이고, 그중 9개는 *입술 색·발색·제품 고르기·각질제거제* 질문(니베아 입술 색 빠짐, 빨갛게 되는 립밤 등 연도 불명의 옛 지식인 글)이라 구순염 수요와 의도가 다르다. 구순염·구각염 직접 맥락은 2개(구각 답변, 티트로신 겔 질문), 건조·각질·트는 입술 맥락이 3개, 광고 복사문 1개(OMI 입술보호제 소개문)다(수작업 셈). 구순염 쪽 대안 중 가장 많이 거론되는데(30% → 32%) 정작 카드를 채울 직접 후기가 모자라다.

- **한 줄**: 입술에 바르는 보습·보호 스틱/튜브. 구순염 경험 발화 225건 중 67건(30%) → 타겟 발화 113개 중 36건(32%)이 립밤을 말해 구순염 대안 1위이고 구내염에서는 3건 1% → 0건 0%에 그친다(대안 언급 표). 종류가 섞여 나온다 — 약국 저가 스틱(챕스틱·니베아, "저렴"), 약국/해외 약용 느낌(블리스텍스, 카맥스 노란 튜브), 발색 립밤(리오엘리 01호 퓨어레드 등), 명품·고가(맥 글로우 플레이 3만원대, 바이레도; 영상: Yoo True 경험·후기), 더마 라인(유리아주 언급; 같은 영상). 약국 겔(티트로신 겔)은 구순염용으로 약사에게 추천받았다는 질문 1건뿐(지식인 최신, 성분 정보 없음).
- **핵심 원리**(작성자 정리 — 재료에 립밤의 작동을 직접 설명한 문장은 없다): 입술 위에 막을 만들어 수분이 날아가지 않게 보호한다. 가장 가까운 근거는 "상처 부위에 바세린이나 순한 입술 보호제를 덧발라 피부 장벽을 보호"(지식인 답변, 구각염 맥락)와 "보습제를 잘 사용하는 것이 정말 중요"(영상: 박치영). 의사 영상의 단서도 붙어 있다 — "평상시에 사용하시던 보습제와 립밤이 자극적이지 않고 알레르기 반응이 없다면 사용하셔도 괜찮습니다. 그런데 저희가 가장 추천해드리는 것은 자운고(전사 '자원고')입니다"(영상: 박치영). 보습에 너무 치중해 덧바르면 유화제가 쌓여 하얗게 부풀고 눅눅한 환경이 감염을 부를 수 있으니 얇게, 깨끗한 손에 묻혀 누르듯 쓰라고 설명(영상: 송현희).
- **맞는 원인 유형**: ① 건조·장벽 약함(단순 건조·각질 — 원인 단서 건조 32% → 19%·각질 30% → 26%와 대안 언급 30% → 32%가 짝으로 읽힘, 작성자 정리). ③ 접촉성은 *원인 물질을 뺀 뒤의 보습 단계*에서만. ④ 구각염 중 건조 방지 단계.
- **안 맞는 유형 / 확인 결과**
  - ③ 접촉성에서 *립밤·화장품 자체가 원인*일 때: 박치영은 접촉 구순염의 자극 물질로 화장품·치약·음식 등을 들고 원인 물질을 찾아 빼는 것이 가장 우선이라고 설명. 목소리에도 "니베아거 사서 며칠 사용해봤는데 입술이 더 트는거같은데"(에펨코리아).
  - ⑦ 진물·이차감염: 보습제나 바세린을 너무 두껍게 바르면 습하고 눅눅한 환경이 세균·곰팡이 증식을 돕고 진물이 심해질 수 있다고 설명. 노란 진물이면 2차 감염 가능성이라 항생제 연고가 필요하다고 설명(영상: 송현희). 자운고도 진물·이차감염이 심한 곳엔 주의(영상: 박치영).
  - ④ 감염성 구각염은 항진균제·항생제 연고가 겨냥(영상: 박치영), ⑥ 습진 바탕은 선행 질환부터(영상: 묘한의사), 헤르페스는 수포가 군집(영상: 송현희) — 모두 립밤 대상이 아님.
  - 구내염(입 안): 대안 언급 1% → 0%, 입 안 점막용 제품이 아니다.
- **USP(받아 본 사람이 기억하는 것)** — 직접 칭찬 후기가 매우 적다.
  - "별에 별거 다 써봤는데 성태가 쓰는 카맥스 노란색 튜브형 립밤있다 여태 인간각질 프로입술각질러 입술각질박사였는데 이거 쓴 뒤로 삭 사라졌다 진짜임"(에펨코리아) — 기억되는 건 *각질이 사라졌다*와 *다 써 본 끝의 정답*. 읽은 인용 중 구순염·각질 맥락의 유일한 분명한 칭찬.
  - "전 최근에 미국회사 blistex껄 쓰는데 반액체스타일에 치약냄새가 나고요 향은 별론데 효과는 만점이에요…가격은 제가쓰는건 2500원"(지식인 답변, 연도 불명의 옛 글) — 향은 별로여도 효과를 기억, 값이 싸다.
  - 영상(Yoo True): 립밤은 향 차이 정도로 생각했는데 "달라요, 달라. 역시 텍스처의 세계는…깊고도 깊어요", 30분 방치해 촉촉함·쫀쫀함이 유지되는지를 비교 — 질감 체감이 기억 포인트(쾌감 리뷰이지 구순염 맥락이 아님).
- **타겟 인식(비중, 정규식 추정, 경험 발화 28건 → 타겟 발화 12건)**: 안다 3(11%) → 0 · 효과 믿음 13(46%) → 0 · 효과 없음 3(11%) → 3(25%) · 비싸다 4(14%) → 1(8%) · 아프다·마취 1(4%) → 0 · 무섭다·부작용 3(11%) → 0 · 연예인 0 · 유지·주기 1(4%) → 1(8%) · 다운타임·붓기·멍 3(11%) → 2(17%) · 셀프·집에서 0
  - **한 줄**: 누구나 아는 값싼 기본템이라 구순염의 첫 대안으로 가장 많이 거론되지만, 써도 계속 트는 느낌과 향·색·값 호불호가 따라붙고, 의사 설명은 립밤이 해법이 아닌 경우(접촉·감염·습진·연고 반동)를 따로 둔다.
  - 주의: '효과 믿음 46% → 0%'는 정규식이 '추천·좋다' 같은 단어를 넓게 잡은 값일 가능성이 크다(읽은 인용에서 효과를 분명히 칭찬한 글은 카맥스·블리스텍스 정도). 경험 28건 중 상당수가 *입술 색/발색 제품 추천* 질문이라 '효과 믿음'이 보습 효과를 뜻하는지 불명(추정). '다운타임·붓기 11% → 17%(2건)'·'아프다 4% → 0%'는 의미 불명.
- **못 하는 이유 1~3순위**
  1. 써도 낫지 않거나 더 트는 느낌(효과 없음 11% → 25%, 3건) — "전 초등학교 들어가기전부터 수만은 입술보호제들을 발라왔는데요 아직도 입술이 트고있어요"(지식인 답변), "니베아거 사서 며칠 사용해봤는데 입술이 더 트는거같은데"(에펨코리아). 많이 바르면 오히려 입술에 안 좋다·"꼭 입술 트실때만 바르세요"는 의견도(지식인 답변, 근거 없는 개인 의견, 연도 불명).
  2. 입술 색 빠짐 불안 — "싸구려 입술보호제는 색을 빠지게합니다 예로는 쳅스틱과 니베아"(지식인 답변), "그게 입술 색을 뺏는다 그래서"(지식인 관련도). 연도 불명의 옛 글이고 **구순염이 아니라 발색 목적**이라 구순염 수요로 읽지 않는다. 니베아에 "암물질 진짜인가요?"라는 소문 질문 1건(답은 재료에 없음).
  3. 향·질감·값 호불호 — "향은 별론데"(블리스텍스), "니베아 체리…너무 화장품향도 많이 나는거같고 색도 별로"(지식인 관련도), 비싸다 14%(4건) → 8%(1건): 2,500원대와 3만원대 사이(영상: Yoo True). 약국에서 살 수 있는 것을 원하는 조건도 있음("약국 가튼 가까운 데에서 살수 있는걸루요", 지식인 관련도).
  - 구순염 맥락의 불만(예: 립밤을 발라도 그때뿐이라는 말)은 이 카드 입력 범위에서 확인하지 못했다 → 결핍 단계에서 보강.
- **가격·통증·지속·부작용 (재료에 있는 것만)**
  - 가격: 챕스틱·니베아 "저렴"(지식인 답변), 블리스텍스 2,500원(지식인 답변, 연도 불명), 맥 립밤 3만원대(영상). 구순염 맥락의 가격 불만은 자료 부족.
  - 통증: 해당 없음.
  - 지속: 지속 시간 숫자는 없음. 30분 방치 후 촉촉함·쫀쫀함 유지 여부를 비교한 영상 1개.
  - 부작용: 접촉 알레르기·자극(영상: 박치영), 덧바름·두껍게 바를 때 감염 환경(영상: 송현희), 위 "더 트는거같은데" 1건.
- **제품으로 옮길 수 있는 것** (P6522: USP를 제품에 입힌다)
  - 먼저 확인: 립밤은 *이미 화장품*이라 옮길 대상이 아니라 **경쟁 칸**이다. 구순염 대안 1위(30%)라 매대에는 흔한 칸일 가능성이 높다(매대 비율은 이 단계 입력이 아님 — 결핍 단계에서 확인).
  - **원리 상징 후보(제품이 실제로 담는 일)**: ① 한방 보습 원료 *자운고* — 의사 영상이 구순염에 "가장 추천"하고, 한방 보습제 중 가장 유명하며 일본에서 유일하게 보험제재로 등록된 한방 외용제라고 설명(영상: 박치영). 응용 범위가 넓어 아토피·건선·지루성 피부염·한포진·화상·동상·튼살 등에도 쓴다는 설명. 구성·화장품 사용 가능 여부·가격은 재료에 없음 → **자료 부족·규제 확인 필요**, 진물·이차감염이 심한 피부에는 주의라는 단서 있음. ② 사용법 — 얇게, 깨끗한 손에 묻혀 누르듯(영상: 송현희). ③ 저자극·무향 — 접촉성 불안에 대한 응답이나 의사 설명은 "자극 없다면 써도 된다"까지이고 낫게 한다는 근거는 없어 안심 상징 수준(작성자 추정).
  - **이미지 상징(장면·느낌)**: 질감(쫀쫀·쫀득·녹아나는 정도), 향(달달한 버터향 — 영상), 노란 튜브 같은 용기(카맥스 인용), 약국 감성 vs 명품·더마 라인 브랜드 이미지, 가격대 양극(2,500원 대 3만원대).
  - **없애 줄 단점(기획 각)**: ① 써도 계속 트는 느낌 ② 향·질감 호불호 ③ 덧바름으로 눅눅해지는 문제 → 얇게 쓰는 사용법 ④ 접촉 반응 불안. 다만 ①은 원인이 건조가 아닐 수 있다는 의사 설명과 닿아 있어 "더 촉촉하게"만으로는 풀리지 않는다.
  - **막힌 칸**: 구순염을 낫게 한다는 약속(감염·습진·연고 반동은 보습으로 풀리지 않는다는 설명), 박탈성 치료 표현.
- **자료 한계**: 위 재료 부족 외에 영상은 3개 중 1개(Yoo True)만 받아쓰기이고 구순염 맥락이 아니며 발췌가 맥·바이레도 앞부분에서 잘림. 의사 영상(박치영·송현희)은 립밤 *성분*이 아니라 사용 원칙만 말해 립밤 종류별 비교는 없다. 지식인 답변 일부(OMI 소개문, 리오엘리 사용기)는 제품 홍보 문체라 걸러 읽었다. 쿠팡 후기·메타 광고(매대 흔한 정도)·구순염 경험 후기는 확인 못 함. 1차 수집이며 깊이 채우기 수집이 들어오면 구순염 맥락의 립밤 후기(써도 그때뿐, 오히려 악화)와 자운고를 먼저 보강한다.
