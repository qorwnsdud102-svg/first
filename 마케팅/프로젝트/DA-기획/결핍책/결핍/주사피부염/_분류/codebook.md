# 주사피부염 글 분류 기준표 (코드북)

각 줄 `[uid] POST ...` 또는 `[uid] 댓글 | ...` 하나가 한 단위다. 댓글은 바로 위 POST에 달린 것이다(유튜브면 그 영상 댓글). 단위마다 아래 5칸을 정한다. **글쓴이가 그렇게 '믿는다/말한다'를 코딩한다 — 의학적으로 맞는지는 따지지 않는다.**

## 1. 말한 사람 (spk) — 하나
- `P` 환자 본인·가족 경험 ("저는", "제가 해봤는데", "~받았는데", 본인 증상 서술·질문 포함)
- `G` 일반인 의견·조언 (경험인지 불분명한 일반인 훈수·주장)
- `D` 공급자 — 의사·한의사·병원·채널 운영자의 영상 설명/답글 ("원장입니다", "내원해주세요", 병원·한의원 이름, 채널이 단 답글). 유튜브 POST(영상 제목·설명)는 거의 다 D.
- `A` 광고·바이럴 의심 — 특정 제품/병원을 노골적으로 띄우는 일반인 가장 글(제품명+과한 극찬+정리된 루틴 등)
- `X` 무관·잡담 — 감사·구독·주소문의·전화번호만·주사피부염/홍조와 무관한 내용(두피 비듬만, 엉덩이 발진, 비염 등)

## 2. 관련 (rel) — `1` 주사피부염·안면홍조·얼굴 붉음/열감 이야기 / `0` 아님. X면 보통 0.

## 3. 원인 (cause) — 해당하는 것 모두, 없으면 `-`
글쓴이가 원인이나 악화 요인(트리거)이라고 말·추정하는 것만. 질문형("카페인 먹어도 되나요?")도 원인 의심이면 코딩.
| 코드 | 원인 |
|---|---|
| C01 | 열·온도 (열감, 더위, 사우나·찜질, 난방, 뜨거운 물, 온도 변화) |
| C02 | 햇빛·자외선 |
| C03 | 음식·술 (술, 맵고 뜨거운 음식, 카페인, 밀가루·당·유제품·가공식품 등 식습관) |
| C04 | 스트레스·감정·긴장 |
| C05 | 수면부족·피로·과로·생활 리듬 |
| C06 | 호르몬 (생리, 임신, 출산, 갱년기, 피임약) |
| C07 | 장·소화·위장 (장누수, 변비, 헬리코박터, 속 건강) |
| C08 | 면역 이상·면역력 저하·만성 염증 |
| C09 | 타고난 체질·유전·원래 얇고 예민한 피부·가족력 |
| C10 | 몸속 열·한의학적 불균형 (열이 위로 뜸, 열 배출 안 됨, 땀구멍 막힘, 장부·순환 문제) |
| C11 | 스테로이드·약물 남용 (스테로이드 연고·주사, 엘리델 등 의존, 끊으면 리바운드 = 2차성 주사) |
| C12 | 피부장벽 손상 (과한 각질제거·스크럽·필링·과세안·많이 문지름·짜기) |
| C13 | 화장품·접촉 자극 (안 맞는 화장품·성분·향료, 과한 보습·기름진 제품, 색조) |
| C14 | 피부 시술·레이저 부작용 (레이저토닝·올리지오·필링 등 시술 후 생김/악화) |
| C15 | 모낭충(데모덱스)·세균·곰팡이(말라세지아)·모낭염 |
| C16 | 혈관·신경 문제 (혈관 확장·약한 혈관, 자율신경·신경성, 혈관 반응성) |
| C17 | 운동·땀·급격한 활동 |
| C18 | 계절·건조·찬바람·환절기 |
| C19 | 마스크 착용 |
| C20 | 원인 모름·이유 없음 ("원인 불명", "의사도 원인 모른대") |
| C21 | 기타 (비만, 다른 약 부작용, 노화, 환경 등 — 위에 없는 것) |

## 4. 해결 (sol) — 해당하는 것 모두 `코드+태도`, 없으면 `-`
태도: `+` 효과 봤다·추천한다 / `-` 효과 없음·악화·부작용·재발·불만 / `?` 질문·고민·써볼까 / `0` 언급만(쓰는 중·처방받음, 효과 언급 없음)
같은 해결에 좋고 나쁨이 섞이면 주된 쪽 하나. 예: "레이저 몇백 써도 안 되다가 로섹스겔로 좋아졌다" → `S10-,S03+`
| 코드 | 해결 방법 |
|---|---|
| S01 | 스테로이드 연고·주사 |
| S02 | 수란트라(이버멕틴) |
| S03 | 메트로니다졸 (로섹스겔·로제픽스 등) |
| S04 | 아젤라산 (피네아·아젤리아·스킨에이드 등) |
| S05 | 면역조절 연고 (엘리델·프로토픽) |
| S06 | 기타·이름 모를 바르는 약 ("연고", 비판텐, 니조랄 등) |
| S07 | 먹는 항생제 (독시사이클린·미노씬 등, "항생제") |
| S08 | 이소트레티노인 (로아큐탄·이소티논 등) |
| S09 | 기타·이름 모를 먹는 약 (항히스타민, 인데놀, "약 먹으면") |
| S10 | 혈관 레이저·IPL (브이빔·엑셀V·DDR·시너지·M22·IPL·"홍조 레이저") |
| S11 | 기타 피부과 시술 (LDM, 리쥬란, 스킨보톡스, 쥬베룩, 토닝, PTT, 고주파, 줄기세포 등) |
| S12 | 피부과·병원 진료 일반 ("피부과 가봐라", "대학병원", 진단 받으라) |
| S13 | 한의원·한약·침·한방 치료 |
| S14 | 열 식히기·쿨링 (냉찜질, 얼굴 차갑게, 차가운 앰플, 미온수, 시원한 환경) |
| S15 | 음식·식단 조절 (술·매운 것·카페인 끊기, 식단, 한식, 비건) |
| S16 | 생활습관 (수면, 스트레스 관리, 운동, 반신욕·족욕·땀 내기, 휴식) |
| S17 | 덜 바르기·자극 피하기 (화장품 줄이기·끊기, 물세안, 각질제거 중단, 색조 중단, 손 안 대기, 노보습) |
| S18 | 보습·장벽·진정 화장품 (장벽크림, 시카, 알로에, 진정 앰플, 특정 크림·브랜드) |
| S19 | 세안법·세안제 바꾸기 (약산성, 순한 세안제, 특정 비누, 세안 순서) |
| S20 | 자외선 차단 (선크림, 양산, 물리적 차단) |
| S21 | 영양제·건강식품·차 (유산균, 오메가3, 비타민, 여성호르몬 영양제, 차) |
| S22 | 모낭충·균 관리 화장품·샴푸 (티트리, 모낭충 케어 등 비처방) |
| S23 | 홈 디바이스 (가정용 LDM·LED 등) |
| S24 | 장·내과 치료 (위장 치료, 헬리코박터 제균) |
| S25 | 시간·자연 호전·평생 관리 체념 ("이유 없이 낫더라", "완치 없다", "그냥 산다") |
| S26 | 커버 메이크업 (그린 베이스, 파운데이션으로 가림) |
| S27 | 기타 (위에 없는 해결 — 이민, 민간요법 등) |

## 출력 형식
단위마다 한 줄, 탭 구분, 입력 순서대로. 건너뛰지 말 것(무관이어도 X로 한 줄).
```
uid<TAB>spk<TAB>rel<TAB>cause<TAB>sol
```
예:
```
11	P	1	-	S18-,S22+,S21?
20	P	1	C01	S14+
4341	D	1	C11	S01-,S02-,S05-,S08-,S13+
3906	X	0	-	-
```
