# 인구통계·상황 기준표 (나이·성별·상황)

**글 안의 단서로만** 정한다. 단서가 없으면 `-`. 직접 말했으면 그대로, 단서로 강하게 추정되면 앞에 `~`를 붙인다.
사이트 이름(맘카페·남초 사이트)으로는 추정하지 않는다(집계 때 따로 본다).

## 나이 (age) — 하나
`10대` `20대` `30대` `40대` `50대` `60대+` `-`
- 직접: "27살", "30대 직장인", "45세" → `20대` `30대` `40대`
- 추정(`~`): 중·고등학생·수능·고딩 → `~10대` / 대학생·군인·취준·신입 → `~20대` / 갱년기·폐경 → `~50대` / 자녀가 초등학생·중학생 → `~40대`
- 남(자녀·부모)에 대한 글이면 **걸린 사람**의 나이를 쓴다.

## 성별 (sex) — 하나
`F` `M` `-`
- 직접: "여자인데", "남자인데", "아내/남편이 ~"(글쓴이 반대 성별 추정 X, 걸린 사람 기준)
- 추정(`~`): 생리·임신·출산·수유·갱년기·여성호르몬·남자친구가 → `~F` / 군대·면도·여자친구가 → `~M`
- 화장한다는 말만으로는 정하지 않는다.
