# 빈혈 — 기획 카드

- **타겟·장면**: 건강검진 수치나 어지러움·피로로 빈혈이 아닌가 의심하고 철분제를 찾는 사람. 옛 36%(202)였던 어지럼증만 글은 거름(356 중 빈혈·철분 낱말 글 354개). 빈혈 글 중 생리·근종 25%(89) · 수치 숫자 35%(125) · 건강검진·피검사 21%(73) → 20%(72). 예: "제가 헤모글로빈치수 5 였던 사람인데 … 5라는 수치를 몰라서 몸이 거기에 적응을 하고 살았던 거죠"(82쿡), "피검사에서 빈혈수치가 9.4로 낮게나와"(지식인 관련도).
- **원인 유형(비중)**: 월경·자궁근종 16%(89) → 25%(89) 1순위 · 스트레스·과로 낱말 15%(85) → 16%(57) · 섭취 부족 7%(41) → 7%(26) · 소화기 출혈 6%(35) → 10%(34) · 흡수 5%(28) → 7%(24) · 임신 3%(17) → 4%(14). 영상: 철결핍이 가장 흔하나 어지럼≠빈혈, 남성·폐경 후 빈혈은 출혈(암 포함) 확인이 먼저.
- **대안 상위 5 — 원리 · USP · 못 하는 이유**:
 1. 철분제 15%(83) → 26%(91)(답변 18% → 27%) — 철 보충 · "철분주사 1회 맞고 볼그레 액상 1일2회 1년 되니 정상수치 나왔어요"(82쿡) · 위 부담(변비·구토) 21%(51, 철분제 폴더 목소리 기준)·먹는 법 헷갈림·끊으면 뚝 떨어짐
 2. 병원 처방 철분(훼로바·볼그레) 13%(71) → 21%(74) — 구토 나서 액상으로 바꿈
 3. 음식으로 채우기 11%(63) → 15%(54) — 고기·간·미역 · 수치엔 부족하다는 말
 4. 철분 주사·수액 4%(22) → 6%(23) · 수혈 6%(33) → 9%(32) — 병원, 중증("수혈은 하고 싶지 않아서")
