# 요실금 — 기획 카드
> 10-19 M21(지식인 '지역·나이/성별' 홍보 형식 질문 뺌): 오늘 정제 기준 타겟 발화 152 → 151(−0.7%) · 인식 칸 1위 그대로, 판단 변화 없음 — 책 숫자는 다음 보충 prep 때 소급.

> 10-17 집계 소급(M4): 숫자 `옛 → 새`.

(타겟 발화 156(옛 경험 210)·메타 광고 28·쿠팡 후기: 메타 판매 2제품 616개 + 밤 일반 8제품 8,903개. 비중은 정규식 추정. 근거: 결핍책.md)

- **타겟·장면 한 줄**: 출산 후 30~40대(갱년기 50대가 두 번째). 웃음·재채기·계단에 찔끔, "밖에 나가는 게 두려워질 정도"인데 "수술이 무서워서 계속 참고" 산다. 쿠팡 구매자는 부모를 위해 사는 딸·며느리가 많다. 심함: 우울 21 → 20%·오래됨 20 → 17%.
- **원인 유형(비중)**: 출산·갱년기 골반저근 약화 = 호르몬·임신 31 → 22% / 복압성 = 노화 22 → 16%·근육 22 → 13%·살 10 → 4%(단독 비중 구분 불가) / 절박성·넘침성 자료 부족. 스트레스·생활은 무게 안 둠. 타겟 믿음과 의사 설명은 거의 같고, 어긋남은 "출산하면 다 그렇다" 당연시와 수술 공포.
- **대안 상위 5**(케겔 외엔 1% 이하):
  1. 케겔운동 13 → 8% — 골반저근 조이기·못 하는 이유: 맞게 하는지 모름, "몇 개월 해봤는데 … 명기처럼 되진 않네요"
  2. 크랜베리 2 → 1% — 방광염용, 요실금엔 원리 안 닿음(추정)
  3~5. 질정 1%·여성청결제 1%·질유산균 0% — 해당 낮음
  표에 없는 실제 대안: 수술·시술("엄청 무서움")·속옷/패드("통풍이 안되서 소변냄새가 더 심하고")
- **매대**: 메타 28개 — 크랜베리 7%·케겔 7%·콜라겐 4%·EGF 4% / 요밸런스(128일)·케겔릿(116일)·newt365(31일). 쿠팡 일반 8개 구성 — 팬티 5·라이너 1·패드 1·건기식 1(검색어로 고른 8개, 비율 아님)
- **메타에서 이미 쓰인 기획 3**: ① 크랜베리·호박씨 건기식(요밸런스·liveforest·newt365) ② 케겔 기기 "앉아만 있어도 요실금 완화"(케겔릿, 30Hz) ③ "잠근다·조인다·꽉 잡는다" 이미지(3곳)
- **메타에 아직 없는 각도**: ① 부부 사이·산후 회복(**쿠팡에만**, 케겔릿 구매층 한정) ② 요실금과 사는 불편(냄새·축축함) 속옷·패드 — 메타엔 없으나 **쿠팡엔 이미 가득**(8개 중 7개, 후기 553~1500개) ③ 시술 상징을 제품으로 옮긴 기획 — 병원 광고는 진료 안내뿐
- **기회 칸 3(+쿠팡 후기로 새로 보임 2)**:
  1. 요실금 말고 "애 낳고도 남편이랑 잘 지내고 싶다"를 약속으로 [쿠팡만]. 케겔릿 후기 6건 중 4건이 부부 사이·질 이완. 주의: 후기 1제품·체험단 가능성, 일반 8개엔 이 말이 없음
  2. 수술 무서운 타협층 — "효과가 좀 떨어져도 조금이라도 개선만 되면". 걸림: 원리 상징 후보 없음. 쿠팡 후기: 수술을 미루거나 수술 뒤에도 새는 층이 속옷·라이너를 삼
  3. 케겔 피드백 부재 메우기 — 컨셉 지도에 이 약속 없음. 걸림: 기기·가이드 형태
  4. 배뇨 건강 건기식의 실제 구매 이유 — 방광염 재발·잔뇨감·야간뇨, 부모 선물 [요밸런스·그린스토어 YO 요 둘 다 요실금 아님]
  5. **부모의 새는 것을 알아채고 사 주는 딸·며느리, 기저귀 아닌 "티 안 나는" 선물** [쿠팡 후기로 새로 보임: 8개 중 7개, 라엘은 체험단]. 건기식·화장품으로는 선물 구조·톤만 옮겨짐
- **흔한 칸 3(피할 것)**: 크랜베리·호박씨 건기식(요밸런스 576·YO 요 1500개가 이미 자리, 구매 이유는 배뇨 건강) / 케겔 기기(케겔릿 40개 3.95, 양극) / "잠근다·조인다"·한정할인·의사 임상 문구. 쿠팡에선 요실금 팬티·라이너·패드도 흔한 칸
- **산 사람 후기·빈틈(쿠팡)**: 요밸런스(4.66) 만족 = 병원·항생제 안 가는 기간·잔뇨감·밤에 깨는 횟수, 부모 선물, 구매 이유는 방광염 재발·야간뇨 / 불만 = "소변 줄여주는 약같고 … 밤에는 원점으로". 케겔릿(3.95) 만족 = "시술이나 약은 좀 무섭더라구요"·부부 사이 / 1~2점 본문 없음. 일반 8개: 팬티 만족 = 부모가 "일반팬티는 안입으시는데 이건 입으시네요"·"티가 거의 안 나", 불만 = 흡수·사이즈·뜯어짐. 라엘 패드 도움순은 전부 체험단.
- **쿠팡 후기로 본 빈틈**: ① 팬티 5개 중 3개가 "일반 팬티랑 별반차이가 없는것"·흡수 안 됨, 기저귀는 부모 자존심을 건드림("마음에 큰 상처와 분노까지") ② 건기식 2개 모두 요실금 호소가 아님
- 주의: 진단·치료 주장 불가, 패드가 계속 필요할 만큼 샘·소변이 안 나오며 샘은 병원 안내. 옮길 원리가 약한 결핍(케겔은 화장품·건기식 이식 거의 불가).
