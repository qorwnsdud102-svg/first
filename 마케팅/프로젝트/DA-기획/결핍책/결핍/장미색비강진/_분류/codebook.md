# 장미색 비강진 글 분류 기준표 (코드북)

각 줄 `[uid] POST ...` 또는 `[uid] 댓글 | ...` 하나가 한 단위다. 댓글은 바로 위 POST에 달린 것이다(유튜브면 그 영상 댓글). **글쓴이가 그렇게 '믿는다/말한다'를 코딩한다 — 의학적으로 맞는지는 따지지 않는다.** 영어·힌디어 등 외국어 글도 똑같이 분류하고 언어 칸만 다르게 적는다.

## 1. 언어 (lang) — `K` 한국어 / `E` 외국어

## 2. 말한 사람 (spk) — 하나
- `P` 환자 본인·가족 경험 (본인 증상 서술·질문 포함, "I have PR", "제가 걸렸는데")
- `G` 일반인 의견·조언 (경험인지 불분명한 일반인 주장)
- `D` 공급자 — 의사·한의사·병원·채널 운영자의 영상 설명/답글. 유튜브 POST(영상 제목·설명)는 거의 다 D.
- `A` 광고·바이럴·스팸 — 제품·병원 홍보, "Dr ○○ herbal cured me" 류 주술사·약초 스팸, 링크 스팸
- `X` 무관·잡담 — 감사·구독·연락처 문의, 장미색 비강진과 무관(건선·자반증·대상포진·주사피부염만 다룸 등)

## 3. 관련 (rel) — `1` 장미색 비강진(Pityriasis rosea, PR) 이야기 또는 "장미색 비강진인가?" 의심 / `0` 아님.
모공성 홍색 비강진(PRP)·건선만 다루면 0.

## 4. 원인 (cause) — 해당하는 것 모두, 없으면 `-`
글쓴이가 원인이나 계기·악화 요인이라고 말·추정하는 것만.
| 코드 | 원인 |
|---|---|
| C01 | 면역력 저하 (일반적인 "면역력 떨어져서") |
| C02 | 바이러스 (헤르페스 6·7형, "바이러스성") |
| C03 | 스트레스·정신적 긴장 |
| C04 | 피로·과로·수면 부족 |
| C05 | 감기·독감·다른 감염 뒤 |
| C06 | 코로나 감염·롱코비드 |
| C07 | 백신 접종 (코로나 백신 등) |
| C08 | 약물 부작용 (다이어트약 등 특정 약을 먹고 생김) |
| C09 | 호르몬·임신·출산 |
| C10 | 계절·환절기·날씨·건조 |
| C11 | 곰팡이·세균·진드기·옴·반려동물 (균이라고 오해·의심 포함) |
| C12 | 성접촉·성병 의심 |
| C13 | 음식·술 |
| C14 | 몸속 열·체질·한의학적 불균형 (심부온도, 열 대사, 체질) |
| C15 | 피부 자극·접촉 (세제, 옷, 스크럽, 뜨거운 물) |
| C16 | 햇빛 부족·실내 생활 |
| C17 | 땀·운동·더위 |
| C18 | 원인 모름 ("원인 불명", "의사도 모른대") |
| C19 | 기타 (위에 없는 것) |

## 5. 해결 (sol) — 해당하는 것 모두 `코드+태도`, 없으면 `-`
태도: `+` 효과 봤다·추천한다 / `-` 효과 없음·악화·부작용·재발·불만 / `?` 질문·고민·써볼까 / `0` 언급만(쓰는 중·처방받음, 효과 언급 없음)
| 코드 | 해결 방법 |
|---|---|
| S01 | 그냥 기다림·자연 치유 (6~8주면 낫는다, 시간이 약) |
| S02 | 피부과·병원 진료 일반 ("병원 가라", 진단 받기, 큰 병원) |
| S03 | 스테로이드 연고·크림 |
| S04 | 먹는 약 — 항히스타민·가려움약 |
| S05 | 먹는 약 — 스테로이드·주사 (먹는 스테로이드, 스테로이드 주사) |
| S06 | 항바이러스제 (아시클로버 등) |
| S07 | 기타·이름 모를 약 ("약 먹고", 항생제·항진균제 포함) |
| S08 | 광선치료 (UVB, 엑시머, 병원 자외선 치료) |
| S09 | 햇빛 쬐기·태닝·일광욕 ("광합성") |
| S10 | 한의원·한약·침·한방 치료 (심부온도 치료 포함) |
| S11 | 면역 주사·면역 치료 (싸이모신 알파 등) |
| S12 | 휴식·잠·스트레스 줄이기 |
| S13 | 보습 (로션·크림·바디오일, 특정 보습제 브랜드) |
| S14 | 샤워·목욕 조절 (미지근한 물, 짧게, 때 밀지 않기, 오트밀 목욕) |
| S15 | 자극 피하기 (긁지 않기, 스크럽 금지, 땀·운동·뜨거운 것 피하기, 헐렁한 옷) |
| S16 | 음식 조절·식단 |
| S17 | 영양제·건강식품 (비타민D, 라이신, 아연 등) |
| S18 | 민간요법·천연물 (님 오일, 코코넛 오일, 알로에, 식초, 표백제 목욕, 칼라민 로션) |
| S19 | 기타 (위에 없는 것) |

## 6. 나이·성별·상황
같은 폴더의 `../demo_codebook.md` 규칙을 따른다. **P(환자 본인·가족)일 때만** 채우고, 나머지는 `-` `-` `-`.

## 출력 형식
단위마다 한 줄, 탭 구분, 입력 순서대로. 건너뛰지 말 것(무관이어도 X로 한 줄).
```
uid<TAB>lang<TAB>spk<TAB>rel<TAB>cause<TAB>sol<TAB>age<TAB>sex<TAB>sit
```
예:
```
59	K	P	1	C01,C16	S01+	-	-	H99:히키코모리
1444	K	P	1	C01,C08,C09	S07-	~30대	~F	H02,H12
1216	E	P	1	-	S02+,S17+	-	-	-
1177	E	A	0	-	-	-	-	-
```
