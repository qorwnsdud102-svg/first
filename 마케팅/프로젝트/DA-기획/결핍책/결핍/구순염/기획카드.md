# 구순염 — 기획 카드

> 2026-10-17 집계 방식 소급(M4): 비중을 타겟 발화 113개 기준으로 정정(옛→새). 원인 1위가 건조에서 각질로 바뀌었으나 판단 바뀐 칸 없음.

(1차 수집 경험 225건, 비율은 정규식 추정. 근거는 결핍책.md · 쿠팡 후기 10-17 대조)

- **타겟·장면 한 줄:** 립밤을 달고 살아도 되풀이되는 입술 쪼임·따가움·각질, 입꼬리 짓무름. '오래됨' 31→27%, 거울·사진 18→15%. 틴트·립을 못 바르는 사람("적색104호를 쓰면 크게 아파요")과 연고를 끊으면 재발하는 사람이 중심. 단순 건조·립밤 추천 질문이 많이 섞임.
- **원인 유형(비중):** ① 건조 32→19%·각질 30→26%(각질이 1위) / ② 뜯기 16→6% / ③ 접촉성(틴트·립 제품) 칸 없음, 인용 40개 중 약 11개 / ④ 구각염 세균·염증 21→11%(넓게 잡힘) / ⑤ 영양 칸 없음(비타민 B 3건) / ⑥ 아토피·습진 바탕 칸 없음(3~4건) / ⑦ 연고 반동 7→4%. 헤르페스와 혼동 있음. '스트레스·생활' 21→12%는 무게 안 둠. 지식인 답변은 건조 78%·각질 58%로 부풀어 있어 흔히 설명하는 원인.
- **대안 상위 5 — 원리 · USP · 못 하는 이유:**
  1. 립밤(30→32%) — 막으로 수분 차단 · 직접 칭찬 후기 거의 없음 · 그때뿐, "바르면 염증반응이 더 심해지는거 같아요", 덧바르면 눅눅
  2. 스테로이드연고(7→4%) — 염증 억제 · "직빵"과 남발 경고가 한 문장 · 무서움 21%·언제까지 14%(연고 전반, 분리 전 값), 끊으면 이틀 뒤 재발
  3. 바세린(표 밖, 답변 3건) — 폐쇄막 · "가장 적절한 선택"(답변자 말) · 두껍게 바르면 눅눅
  4. 자운고(영상만, 카드 없음) — 한방 보습, 의사가 "가장 추천" · 목소리엔 언급 없음, 규제 확인 필요
  5. 토파 연고(DC 2글) — 직구 외용제(성분 불명) · 괜찮아지다 다시 갈라짐
- **매대(메타 광고 3개뿐):** 상징 립밤 67%·PDRN 33% / 제형 오일·밤 67%·크림 33% / 판매처 플로위·시오리스·뷰티연구소. 쿠팡 매대 비율 자료 없음. 가격대: 립밤 2,500~3만원대, 시오리스 19,000원, 플로위 22,500원(할인가).
- **메타에서 이미 쓰인 기획 3:** 플로위(연어 PDRN+비타민 F 원리 상징, 진정·각질·탄력 토탈케어, 8~9일) · 시오리스(독한 성분 뺀 유기농 컬러밤, 원리 상징 없음, 33명 자극 시험, 3~4일) · 뷰티연구소(입술 자외선 차단, 3일, 해부 안 함)
- **메타에 아직 없는 각도(공급 부재일 뿐 수요 증거 아님):** ① 구순염을 직접 말하고 왜 반복되는지 짚기 ② "아무거나 바를 수 없는 입술" 장면(쿠팡 후기·블라인드만) ③ 립마스크 제형(쿠팡 핫딜 1건만)
- **기회 칸 3:**
  1. 립밤이 해법이자 원인 후보라는 어긋남 → 원인 후보를 뺀 단순 처방 + 얇게·누르듯 쓰는 법. 원리 상징 후보 자운고(규제 확인 필요). 낫는다는 약속 금지 (쿠팡: 시오리스가 "성분 안심"은 이미 함)
  2. 연고를 끊은 뒤·사이사이 공백기 루틴(이미지 상징 수준, 연고 대체·박탈성 치료 약속 금지)
  3. 입꼬리 짓무름 + 비타민 B(타겟과 의사가 같은 말, 건기식 표현 규제 확인, 작은 갈래일 수 있음)
- **흔한 칸(피할 것) 3:** 그냥 보습 립밤 / 독한 성분 뺀 유기농 컬러립밤(시오리스, 쿠팡 135개·4.51·5점 99개) / 연어 PDRN 복합 안티에이징 립밤(플로위)
