# 속눈썹 — 기획 카드
(1차 수집 경험 187 기준, 깊이 채우기 수집 후 갱신 · 쿠팡 후기 대기 · 비율은 정규식 추정)

- 타겟·장면 한 줄: 펌·연장·비비기 뒤 끊기고 빠져 듬성해진 속눈썹을 걱정하는 여성. "펌 연달아 했더니 다 끊어짐 … 반토막난 눈썹 안자라니까 걱정돼"(블라인드), "하루에 4가닥은 빠지는거같아요"(지식인). '짧음' 호소는 이 재료에 드묾.
- 원인 유형(비중): 짧음·숱 없음 / 빠짐 / 펌·연장 손상 / 방향·눈꺼풀(찌름). 유형별 비중은 자료 부족. 단서: 건조·피부 18% · 스트레스·생활 17% · 세균·염증 13%(연장 염증·다래끼 글 섞임) · 타고남 11%. 타겟은 펌·비비기·화장 자극을 탓함. 의사 영상은 사실상 안과 1건, 나머지는 샵·판매 채널.
- 대안 상위 5 — 원리 · USP · 못 하는 이유:
  1. 영양제(대안 목록 밖, 비중 없음): 성장기 모근에 바름, 3~4개월(샵·판매 말) · "효과 짱 … 면봉 올릴 수 있겠어" · "별 효과 못 봤어요", 선택 피로, 홍보 의심, 렌즈·눈시림
  2. 라티쎄(0%): 성장주기 연장 처방약 · "영양제 쓰다 갈아탄" · 비쌈 41% · 무섭다 29%(착색) · 15만원/3ml · 후기 없음 (n=17, 효과 믿음 53%)
  3. 속눈썹펌(7%): 컬 고정 · 눈이 커 보임 · 효과 없음 0%, 내 눈에 안 맞음·주기 비용, 반복하면 끊김(블라인드 2건)
  4. 노글루·연장(대안 카드 없음, 메타 주력): 붙여서 즉시 · 5초 · 글루 번거로움, 접착제 염증
  5. 마스카라·컬링 영양제(카드 없음): 막 + 영양 · 마스카라 대체 · 번짐·클렌징
- 매대(메타 270개): 상징 속눈썹펌 20%(샵 시술 광고 몫 큼) · EMS 2% · 콜라겐 1% · LED 1% · 펩타이드 0%. 제형 먹는 것 31%(이름 오염 의심) · 앰플·세럼 12% · 마스크 1% · 디바이스 1%. 메타 상위 판매처: hyes02 키보 삐삐래쉬(50개, 907일) · keybo 같은 제품(24개, 858일) · 마르시끄 영양제(21개, 14일).
- 메타에서 이미 쓰인 기획(같은 기획이면 후킹 떨어짐) 3:
  ① 노글루 "붙이기 쉬움·5초·인형눈" — 키보 포함 5곳, 글루 일체형 구조 / 이미지 인형눈 / "5초 부착"
  ② 마스카라 대체 영양제 — 마르시끄·뮤드, 마스카라 막 + 영양 / 팬더눈 NO·깃털 / "미온수 세정·24시간 컬링"
  ③ "바르면 길어진다" 단순 약속 — 젬소·tmjm, 숫자 증거 없음
- 메타에 아직 없는 각도 3 (쿠팡에만 있는 각도는 판정 불가): 숱·빠짐 직접 호명 0회 / 눈꺼풀·렌즈·눈 민감 타겟 없음 / 의사·약사 증거 0건·원인 지목 없음
- 기회 칸 3:
  1. 숱·빠짐·끊김을 제품 이름으로 직접 부르기 — 메타 0회인데 타겟은 "대머리 수준"·"반토막"을 호소 [규제 확인: 빠짐·발모 표시]
  2. 눈에 닿아도 안심 — 렌즈 낀 채·눈시림·가임기 걱정 (메타에 이 타겟 없음)
  3. 라티쎄 쓰려던 사람의 다음 칸(비싸고 무섭고 후기 없음) — 원리를 화장품이 담는지 규제 확인 최우선, **착색이 다크서클과 충돌**
- 흔한 칸(피할 것) 3: 노글루 붙이기 · 마스카라 대체/컬링 영양제 · 길이 단순 약속(사진 후기식)
- 산 사람 후기 한 줄: 후기 대기. 참고로 영양제 쪽 실패 인용 "별 효과 못 봤어요", 체감 인용 "튼튼해진 느낌"(YOOTRUE 영상).
