# 셀룰라이트 — 기획 카드
(바디라인 · 1차 수집 경험 187개 = 타겟 발화 134 + 답변 52 · 비율은 정규식 추정 · 쿠팡 후기 10-17 반영)
> 2026-10-17 집계 방식 소급(M4): 타겟 발화/지식인 답변 분리 — 원인 1순위 살·지방 43% → 25%(그대로 1위, 답변 88%), 지방분해주사 못 하는 이유 1위 가격 → 무서움. 기회 1 방향 유지.

- **타겟·장면**: 살을 빼고 운동해도 허벅지 뒤·엉덩이 울퉁불퉁한 결이 남아 짧은 바지·치마·목욕탕을 피하는 사람(여성 중심). "남들처럼 핫팬츠도 입고 다니고 그러고 싶은데"(지식인)
- **원인 유형(비중)**: 살·지방 43% → 25% · 근육·표정 16% → 8%(표정 섞임) · 타고남·구조 10% → 7% · 노화·처짐 9% → 5% · 습관·자세 9% → 5% · 호르몬 3% → 4% · 세균·염증 7% → 1%. 순환·붓기 칸 없음. 믿음은 '살이면 빠진다'인데 "살은 좀 빠졌지만 셀룰라이트제거는 거의 안되더라구요"가 반복. 스트레스·생활 13% → 7%는 넓어 제외.
- **대안 상위 5** (원리 · USP · 못 하는 이유):
  1. 지방분해주사 3% → 1% — 지방세포 파괴 / "피멍이나 부종발생이 일반적인 부작용" / 무서움 15%·무슨 약인지 모름, 아픔 10%, 가격 18% → 8%
  2. 고주파마사지기 4% → 1% — 속에서 뜨끈한 열감 / 팔 아파 꾸준히 못 함, 출력 낮음 (얼굴 중심 자료)
  3. 괄사 5% → 0%(답변 17%) — 밀어 순환·붓기 / "빠지는 건 대부분 붓기" / 세게 하다 탈, 방치
  4. 셀룰라이트크림 1% → 0% — 바르고 운동하면 열·땀(업체 주장) / "2-3개 사봤는데 정말 효과가 없었", 광고 불신(인용 다수 광고 의심)
  5. 보정속옷 1% → 0% — 압박 / KBS: 조이면 악화 가능 / 싸면 효과 없고 불편 (부유방 재료 기반)
  (운동·식단은 목소리 최다인데 집계 칸 없음. 카복시·인모드 0%)
- **매대**(광고 223개): 상징 EMS 23%(매장 프로그램 섞임) · 셀룰라이트크림 6% · 리프팅 6% · 괄사 6% · 지방분해주사 3% / 제형 기기 12% · 크림 8% · 패치 4% · 밴드 3% · 오일·밤 2% / 상위 판매처 토르홉 30개 · 리무브 28개 · 발란스핏 14개 (오래 돈 12개 중 제품은 2개뿐)
- **메타에서 이미 쓰인 기획 3**: ① 온열 — 토르홉(핀란드 사우나)·팻랩(브로멜라인+그래핀)·슈엘로 ② 압박+림프 — 리무브("입기만 해도 삭제")·솔리디아 ③ 괄사·흡입 크림 일체형 — 마벨리오·슈엘로·웰247 (입기만·붙이기만, 연예인 이미지도 흔함)
- **메타에 아직 없는 각도**: ① 이름 있는 시술(리포사지 등)을 제품 원리로 — 제품 12곳 0 ② 체감(저녁 무거움→아침 붓기)을 약속 중심에 — 쿠팡 후기 단서③ 냉감 — 없으나 지방엔 열이 더 직관적이라 후순위. 쿠팡에만 있는 기획은 판단 보류.
- **기회 칸 3**:
  1. 시술 이름의 방식을 제품 원리·사용법으로: 시술을 알아보다 부작용·효과를 의심하는 사람 3건(무서움·아픔이 벽, 비싸다 18% → 8%). 리포사지는 림프 마사지 동작을 돕는 오일·밤+사용법이면 원리 상징 후보, 이름만이면 이미지 상징. **타겟 인지 미확인(목소리 0건)**
  2. 체감 약속 중심(자기 전 붙이고 아침 확인): 울퉁불퉁 약속의 불신 벽을 비껴감(해석) (쿠팡: 리무브도 "효과가 있는지 모르겠어요" — 울퉁불퉁 약속을 구매자도 확인 못 함 / 팻랩은 제품으론 붓기 체감을 이미 줌, 광고 약속만 울퉁불퉁)
  3. 운동을 거드는 쪽: 메타는 운동 대체(입기만)뿐, 타겟은 "운동하면 부스터". 온열이면 흔한 칸과 겹침(해석) (쿠팡: 발란스핏 대체 약속은 234개·4.69점 만족 우세 — 받치지 않음)
- **흔한 칸(피할 것) 3**: 온열(사우나·그래핀·볼케이노) · 압박+림프 드로즈·스타킹 · 괄사·흡입 크림 일체형 (쿠팡: 입기만·붙이기만은 만족 우세)
- **쿠팡 후기로 본 빈틈 1~2**: ① 리무브 압박 드로즈는 착용감·잡아줌만 칭찬, 셀룰라이트는 "그건몰겠으요"(3점)·"효과가 있는지 모르겠어요"(4점) — 광고의 "삭제"를 구매자가 확인 못 함 ② 발란스핏은 셀룰라이트가 아니라 운동 시간이 없어서·하체 보정으로 삼, 불만은 고장·교환
