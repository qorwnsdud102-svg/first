# 입냄새 — 기획 카드
> 2026-10-19 보충: 메타 화면 분석·컨셉 지도(M17) 반영(§5·§6·§7)
(타겟 발화 970 · 지식인 답변 361은 참고만 · 비율은 정규식 추정 · 쿠팡 후기 10-19 채움: 일반 8개·11,100개, 메타 0/3)

- **타겟·장면**: 본인형 — 양치·치실·스케일링을 다 해도 불안해 마스크·가글로 사는 신입 직장인·학생("말하는 사람들마다 입 가리고 말해서"). 곁사람형 — 동료·친구·남편·엄마의 입냄새를 말 못 하고 숨 참는 사람("누가 말해주면 좋겠다 싶다가도 그게 나는 아니었으면"), 구매자가 본인이 아닐 수 있다(인용 52 손집계 곁사람 15·본인 17). 본인은 못 맡는 결핍이라 효과 기준은 타인 반응·직접 확인. 오래됨 14%(133)·스트레스 13%(130)·만남·일 9%(83).
- **원인 유형(비중)**: 편도결석 21%(200) · 치과적 19%(189) · 위장·역류 19%(182) · 음식·흡연·공복 17%(161) · 혀·설태 11%(106) · 비염 7%(70) · 구강건조 5%(45). 의사 영상은 입 안 85~90% 이상, 편도 약 10%라고 설명 — 타겟은 위장을 크게, 혀·구강건조를 작게 본다.
- **대안 상위 5** — 원리 · USP · 못 하는 이유:
 1. 가글 12%(112) — 헹궈 세균·냄새 줄임 · 불안 달래는 상황 의식 · 그때뿐·알코올 건조·소독약 냄새
 2. 치간칫솔 7%(71) — 틈새 기계적 제거 · 빼낸 것 냄새 확인 · 굵기 모름·피
 3. 스케일링 4%(42) — 초음파 치석 제거 · 개운·시원 · 아픔·치과 공포
 4. 혀클리너 3%(27) — 설태 긁기 · "왜 이제 알았나" · 구역질
 5. 워터픽 2%(17) — 물살 세정 · 안 나오던 찌꺼기가 나옴 · 20만 원·치실 대체 못 함
 (표 밖) 구강유산균 1%(10) 광고 불신 / 편도결석제거 직접 빼기 구역질·피, 수술 회복 3주
- **매대**(광고 424, 치약·캔디 칸 없음): 상징 유산균 8% · 가글 7% · 치간칫솔 4% · 구강유산균 4% · 스케일링 3% / 제형 먹는 것 18% · 스프레이 5% / 상위 판매처 hetras(39개) · 리스테린(24) · 브리쎄 oy.run(22)
- **메타에서 이미 쓰인 기획 3**: ① hetras 등 7곳 이상 — 자일리톨·고불소 · 임상 94%(광고함, 화면 3편 전부 「94%」) ② 닥터숨(133일) — 분자 포집 "향으로 덮지 않음"(영상 음성엔 원리 안 나옴) ③ 입 속 세균 캐릭터 3곳(덴핏 괴물·효소 치약·루치펠로) · 브리쎄 필름(70만 장)
- **메타에 아직 없는 각도**: ① 편도·목 안쪽 냄새(받아쓰기 13편·쿠팡 일반 8개에도 없음) ② 양치했는데 왜 냄새나?의 답이 안 닿는 곳 ③ 깊은 가글 쓰는 법. 쿠팡에만: 사람용 구강유산균(리본핏). 공급 부재일 뿐 수요 증거 아님.
- **기회 칸 3**:
 1. 편도·목 안쪽까지 닿는 깊은 세정 — 원리 후보 소금물 삼투(3%, 타겟 인지 확인 필요) · 이미지 '개시원' 석션 · 구역질·피·수술 장벽 없앰
 2. "속이 아니라 안 닿는 곳" 오해 뒤집기 + 자가 확인 장면 — 의사끼리 갈려 단정 금지. (쿠팡 후기: 잇퓸이 "속에서 나는 냄새" 소구를 이미 함)
 3. 곁사람에게 말없이 건네기 — 메타는 차콜 치약 선물 337일·닥터숨 지인 사탕 1편(식후 일상)·헤트라스 아이 코 막기, 직장 동료·부모는 없음. (쿠팡 후기: 8개 중 3개에 가족 구매)
 새 후보(쿠팡 후기로 새로 보임): 맛·식감 장벽 없는 먹는 제형 · 맵지 않은 구강제품
- **흔한 칸(피할 것) 4**: ① 고불소·수치 임상 치약(7곳 이상, 쿠팡 센토 4.99점·1~2점 0) ② 가글·구강유산균(쿠팡 가그린 제로 4.95점·무알콜 이미 함) ③ 녹이는 캔디·필름, 휴대 스프레이(쿠팡 덴티스테 4.77·로로벨 4.99) ④ 입 속 세균 캐릭터 3곳
- **쿠팡 후기로 본 빈틈 1~2**: ① 혀클리너 낮은 점수 4건 = 구역질·상처 불안·백태 안 닦임 → 기회 4(구역질·피 없이)를 쿠팡 후기로 확인 ② 잇퓸 캡슐 1~2점 9.2%(8개 중 최고) = 맛·식감, 냄새는 "싹 잡아주는 것 같슴니다". 메타 판매처 후기는 0/3
- **산 사람 후기 한 줄(만족/불만)**: 만족 — 효과를 "입냄새가 한방에 없어짐"보다 상쾌·개운·화함으로 말함 / 불만 — "마라탕 1단계 … 엄청 매워"(덴티스테)·"하자마자 우웩하고 나옴"(혀클리너)·센토는 협찬 표시.
- **주의**: 위장·편도 수술은 병원 영역. 가글·필름·스프레이의 화장품·건기식 분류는 재료에 없음.
