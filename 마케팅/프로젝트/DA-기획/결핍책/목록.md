# 결핍 책 — 결핍 목록 (사장님 확정)

근거: P6524(결핍 목록을 명확하게 고정), P6527(결핍 책이 있어야만 기획 시작), P6528(뺄 것·넣을 것).
- 이 목록에 있는 결핍만 결핍 책을 만들고, 결핍 책이 '완료'인 결핍만 기획을 시작한다.
- 뺀 것: 손가락마디통증·손목터널증후군·무릎통증·오십견. 히토온천크림으로 이미 팔고 있어서 기획할 필요가 없다(P6528).
- 같은 계열은 대안을 한 번만 모은다(`대안/`). 원인 유형·원리는 계열 묶음 책에 한 번 쓴다(`묶음/`).

| 계열 | 결핍 | 지금 자료 |
|---|---|---|
| 얼굴 주름·윤곽 | 팔자주름 (시범) · 목주름 · 볼패임 · 이중턱 | 목주름만 지식 카드 있음 |
| 색소·흉터 | 기미 · 여드름흉터 · 튼살 | 기미만 지식 카드 있음 |

| 두피 | 탈모 | 지식 카드 있음 |
| 발 | 티눈 · 무좀 | 티눈 지식 카드 + v2 |
| 바디 | 부유방 · 하지정맥류 · 수족냉증 | 하지정맥류·수족냉증 지식 카드 있음 |

모두 25개다. 그중 새로 시작하는 결핍은 9개(팔자주름·볼패임·이중턱·여드름흉터·튼살·소극성 속모증·무좀·부유방·비염)다.
