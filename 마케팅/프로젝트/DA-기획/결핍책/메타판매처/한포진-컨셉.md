## 상위 5곳 해부
### doctorbio.kr — 센시티브 로션&오일
- 타겟·장면 / 메인 결핍: 밤마다 가려워 깨는 아기, 건조한 임산부 피부 / 가려움·건조
- 컨셉: 로션+오일 대용량 브랜드데이 특가(단독 상세 아님)
- 상징재 역할: 원리 상징이 약하다(로션+오일 조합·인증뿐)
- 의심 막는 증거: 식약처 가려움 개선 기능성, 리뷰 50만·4.9점(자사 표기), 환불
- 쿠팡 실제 후기: 쿠팡 후기 대기
- 근거: "로션&오일의 막강한 보습력으로 한번에 해결"(한포진 단어 없음)

### lesstopy.com — 리스토피 아토크림
- 타겟·장면 / 메인 결핍: 침독·기저귀 마찰·열감에 붉어진 아기 / 건조·붉어짐
- 컨셉: 해부학자 제작, 습진협회 인증 아기 크림
- 상징재 역할: 쉽싸리 추출물이 원리 상징(염증 신호 논문 인용), 해부학자·한가인은 이미지 상징
- 의심 막는 증거: NEA 인증, 특허 10-2144566, 더마테스트, 100% 환불
- 쿠팡 실제 후기: 198개·4.68점(5점 166). 만족 = 열감·붉어짐 진정, 무향 무색소. 불만 = "홍조·건조증에 도움 안 됨", 용량 대비 비쌈. 한포진 후기는 없다
- 근거: "연약한 아기 피부에는 순한 자연의 힘이 필요합니다"

### fb.com — 리스토피 FB 페이지
- 타겟·장면 / 메인 결핍: 엄마들 / 붉게 올라와 만지기 조심스러운 피부
- 컨셉: 같은 제품을 후기 인용으로 광고
- 상징재 역할·증거: lesstopy.com과 같다(인증 3줄 반복)
- 쿠팡 실제 후기: 위 리스토피와 같은 브랜드
- 근거: "붉게 올라와 만지기도 조심스러웠던 피부"

### hyfer.co.kr — 헤르논
- 타겟·장면 / 메인 결핍: 무좀약을 써도 그대로인 발 물집 / 한포진을 무좀으로 오인
- 컨셉: 무좀이 아니라 한포진, 의료기기로 보호막
- 상징재 역할: 투명 보호막이 원리 상징(품목명 점착성투명창상피복재), 의료기기 인증은 이미지
- 의심 막는 증거: 식약처 인증·FDA 등록, 43종 스테로이드 불검출 성적서, 광고심의필
- 쿠팡 실제 후기: 378개·4.43점. 쿠팡 제품명이 입술포진용이라 후기 대부분 입술 포진. 만족 = 연고는 겉돌고 끈적이는데 투명·간편. 손가락 물집에 쓴 5점 1건. 불만 = 가라앉지 않음, 젤이 흘러내림, 약국 연고보다 비쌈
- 근거: "무좀약을 오래 써도 그대로라면 한 번 살펴보세요"

### housweet.kr — 오트맘 핸드 트리트먼트
- 타겟·장면 / 메인 결핍: 물 마를 날 없는 주부·셰프·간호사·미용사 / 핸드크림 안 먹는 습진
- 컨셉: 손 씻고 바로 바르고 헹구는 24시간 보습
- 상징재 역할: 아베난쓰라마이드·콜로이달 오트밀이 원리 상징, 연예인 PICK은 이미지 상징
- 의심 막는 증거: 논문 입증 성분, 9차 완판, 14일 환불
- 쿠팡 실제 후기: 쿠팡 후기 대기
- 근거: "습진엔 핸드크림, 쥐약이라구요"

## 메타에서 이미 쓰인 기획 — 우리가 같은 기획으로 내면 후킹이 떨어진다
- 보습·장벽+인증·환불 6곳(doctorbio·리스토피 2·앙쥬나나·락토이치·오트맘), 그중 아기도 쓴다는 4곳
- 스테로이드 공포·대체 3곳(앙쥬나나·헤르논 불검출·락토이치 음성)
- 직업 장면(요식업·주부·셰프·미용사) 2곳 / 씻어내는 핸드 트리트먼트 2곳 / 연예인 2곳
- 유산균 2곳, 온천수 1곳
- 한포진 단어를 쓰는 곳은 3곳(헤르논·앙쥬나나·락토이치), 나머지는 습진·아토피

## 메타에 아직 없는 각도
이 12곳 문구 기준이다(전체 메타 확인 아님). 쿠팡에만 있는 각도는 확인 못 했다.
- 바르는 것이 아닌 방식: 12곳 모두 크림·로션·보호막이다. 슬로큐어 소재에 "고무장갑 한 번 썼다고 알러지가 확 올라왔다"는 장면이 있어도 물 접촉을 줄이는 쪽은 없다.
- 원인 설명: 왜 생기는지 짚는 광고가 없다(정약사는 '새 원인'만 예고, 내용은 DM 뒤).
- 발 한포진: 헤르논 문구 하나뿐.
- 재발 끊기: 락토이치가 "반복"을 말할 뿐 재발 루틴을 약속하는 곳은 없다.
