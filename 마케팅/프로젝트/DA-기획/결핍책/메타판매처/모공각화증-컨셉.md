## 상위 5곳 해부
### meditold — 퍼시닌 단감 바디워시
- 타겟·장면 러너·오프숄더 입는 여성의 가슴·등·팔 / 메인 결핍 닭살·등드름 / 컨셉 단감 탄닌이 피지·각질과 결합해 씻어냄 / 상징재 원리(탄닌 4단계: 결합→중화→모공 수렴) / 증거 임상 6종, 개봉해도 1개월 전액 환불, 누적 100만개
- 쿠팡 실제 후기: 600개·4.69점. 만족 세정력·기름기·체취 정리. 불만 펌프 새어나옴, 묽음, "체취 안 잡힘" 과장광고 지적. 도움 많은 후기에 닭살 언급 없음 → 닭살로 광고하고 체취로 팔린다.
- 근거: 광고는 "피지 각질 72% 개선"이나 상세 임상표는 "사용 직후 피지량 72.36% 감소"이라 모공각화증 임상이 아님.

### theforment — 포맨트 코튼허그/코튼베이비 아크네 바디워시
- 타겟·장면 아이돌 팬, 등드름+닭살 / 컨셉 향수 브랜드의 아이돌 Pick 바디워시+샤워볼 / 상징재 이미지 중심(아이돌 피부), 원리는 살리실산 표기뿐 / 증거 최유정·박지훈 Pick
- 쿠팡 후기 대기.
- 근거: "오돌토돌 닭살피부는 매끈하게, 베이비파우더 향으로 살냄새는 오래가게". 광고 중 메타몽 콜라보는 닭살 무관.

### drkera — 닥터케라 우레아 90000ppm 크림
- 타겟·장면 반팔 입기 전 팔 / 메인 결핍 모공각화증 / 컨셉 기존 대안(스크럽·로션) 실패를 먼저 부르고 전용 크림 제시 / 상징재 원리(우레아 고함량+세라마이드·나이아신아마이드) / 증거 환불보장, 저자극 테스트, 자사몰 리뷰 2,428건
- 쿠팡 실제 후기: 76개·4.61점(1~2점 4개). 만족 바디로션·스크럽은 안 됐는데 3주~2개월에 가라앉음, 병원 비용·시간 부담에서 옮김, 아이 팔에도 순함. 불만 한쪽 팔만 바르니 차이 없음, "병원 처방이 더 저렴".
- 근거: "모공각화증 전용 바디크림 불만족시 100% 환불보장"

### vivcell — 비브셀 우레마이드 바디로션
- 타겟·장면 웨딩·반바지 앞둔 악건성 / 메인 결핍 닭살+색소침착 / 컨셉 "닭살 전용, 향만 강조한 저가형은 보지 마세요"로 선별 / 상징재 원리(고함량 우레아+나이아신) / 증거 20명 임상(보습 128.5%·각질 92.2%·색소침착 6.22%), 창업자 닭살 스토리
- 쿠팡 후기 대기.
- 근거: "닭살피부 전용 바디로션입니다". 영상 받아쓰기 2편은 짝이 틀려 버림.

### mommy-care — 애사비 마데카나 스크럽워시 (상세 재료 없음, 소재만)
- 타겟·장면 등·가슴·팔 요철 / 컨셉 스크럽+바디워시 하나로, 주 2~3회 / 상징재 원리(산성분 3종)·이미지(애사비) / 증거 협찬 후기, 비밀링크 가격
- 쿠팡 후기 대기.
- 근거: "네. 더러운 팔 끝장 봤습니다."(98일 게재)

## 메타에서 이미 쓰인 기획 — 같은 기획이면 후킹이 떨어진다
- 우레아 ppm 숫자 경쟁 "전용 크림·로션": 닥터케라 90,000 · 비브셀 80,000 · 닥사렌 100,000 · 스무디솝 (4곳)
- "스크럽·로션은 안 된다 → 전용": 닥터케라, 비브셀, 닥사렌, 스무디솝 (4곳)
- 씻어내는 산성분·탄닌 바디워시/비누: 메디톨드, 포맨트, 마미케어, 스무디솝, 퍼레비 (5곳)
- 인플루언서·아이돌 협찬+댓글 이벤트: 메디톨드, 포맨트, 마미케어, 셀라힐 (4곳)
- 임상 숫자+환불·무료체험: 메디톨드, 닥터케라, 비브셀, 스무디솝 (4곳)

- 아이(영유아) 팔 모공각화증, 부모 타겟: 닥터케라 쿠팡 도움 많은 후기(돌 지난 아이)와 자사몰 후기(2살)에만 보임. 메타 소재 0건(쿠팡 쪽 각도).
- 피부과 대신(비용·시간): 쿠팡 후기("피부과 다니다 비용 부담")에만 있음. 메타 소재에는 안 보임.
- 피부과 시술의 원리를 가져온 상징: 재료에는 seapuri의 "박피" 한 마디뿐.
