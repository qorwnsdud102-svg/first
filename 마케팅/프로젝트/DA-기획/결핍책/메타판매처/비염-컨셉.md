# 비염 — 메타 판매 컨셉 지도
(재료: 광고 120개 중 상위 12곳 41개 · 판매처 12곳 · 영상 받아쓰기 11편 · 상세페이지 2곳(읽힘: 하우스윗·리더뮨) · 쿠팡 실제 후기 1곳 / 2026-10-19 (M17))
- 10-19 새벽 메타 주말 줄이 소재 재료에 영상 음성 받아쓰기를 새로 넣어 다시 씀: 받아쓰기 5 → 11편(하우스윗 3·한의비책 3·리더뮨 2·bifigen·위프·토퍼 각 1). 음악만 나오는 영상 2편(보넬라·네츄레메디)은 받아쓰기 수에 안 넣음.
- **광고 수 120개는 옛 지도와 같다.** 상위 12곳 합은 44 → 41(소재.md와 같은 기준): vigloo(숏드라마 앱, 5개)가 새 제품 판매처 목록에서 빠지고 tempo.ne.kr(티슈, 2개·92일)이 12위로 들어왔다. 상위 5곳은 하우스윗·한의비책·리더뮨까지 같고 4·5위가 vigloo·보넬라 → 보넬라·bifigen으로 바뀜.
- 후킹 표기: 문 = 광고 문구 첫 줄, 음 = 받아쓰기 첫머리, 화 = 화면 자막·장면(10-17 화면 분석). 받아쓰기가 깨진 곳은 뜻을 '추정'이라고 적음. 쿠팡 후기는 10-17 수집분.
