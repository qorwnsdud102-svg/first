## 2. 채널별 문법 — 사장님 가설 검증

**가설**: 메타 파컨 = 짧고 후킹 위주 / 네이버 파컨 = 장문 논리.

**실측 결과 — 절반 맞고, 핵심은 자수가 아니라 리듬**:

- 메타랜딩 4건 = 3,024~5,578자. 셀로비스·리페아(자사)는 3천자 초반으로 가설대로 짧다. 그런데 **덴바디 쌍은 5.5천자로 네이버 장문급**이다.
- 덴바디가 5.5천자인데도 라이트하게 읽히는 이유 = **문단-사진 리듬**. 이미지 53~55장, 문단 2~4줄, 사진 1장당 텍스트 3~5줄 → 릴스 넘기듯 스크롤됨. 메타의 라이트함은 글자수 절대치가 아니라 **텍스트 밀도(자수/이미지 비율)**가 만든다.
  - 덴바디 101자/장 · 셀로비스 88자/장 · 리페아 97자/장 ↔ 네이버 장문형: 큐보젠 299자/장 · 리커버젠 445자/장 · 메디라온 305자/장
  - **메타용 기준선: 이미지 1장당 100자 내외, 문단 2~4줄** (네이버형은 300~450자/장까지 허용)
- 네이버 장문형 = 4.2~8.7천자 + 논문·법령·비교표 밀도. 검색으로 "공부하러 온" 독자 전제.
- 메타 전용 톤: 셀로비스는 밈·이모티콘·짤 섞음 (인스타 감성), 목차 없이 선형 진행. 네이버형의 목차·챕터 넘버링은 메타에서 오히려 무거움.

**히토 적용**: 3,000~3,500자 + 이미지 30~40장 (100자/장) + 문단 2~3줄 + 밈 톤. 목차 생략, 선형 서사.

## 3. 공통 골격 — [[파워컨텐츠]] 7단의 실측 변형

21표본 전부 7단 골격(소비자 위장→고생담→대안 까기→원인+권위→해결책을 내 카테고리로→N가지 기준→어쩔 수 없이 링크)의 변형이다. 실측에서 확인된 변형 축 4개:

1. **기준 개수**: 2개(덴바디)~5개(가디브·큐보젠). 메타형은 2~3개가 상한 (라이트함 유지).
2. **제품 도달 경로 2형**:
   - **연역형** (지식→기준→유일 통과): 네이버 장문형 전부. "기준 역설계" — 기준을 자사 스펙에 맞춰 설계.
   - **우연형** (생활 사건→발견): 덴바디 시누이, 루씨드 유튜브 율무팩, 리더뮨 한의원. 메타형·라이트형에 적합 — 독자가 "스스로 발견한 척" 하게 만든다.
3. **익명화 수위**: 실명 직영(미베러) < 고지+익명(유랄 "U사") < 무고지+익명+말미 실명(덴바디·바디슈) < 시리즈 내내 무명(리더뮨).
4. **노출 타이밍**: 중반 1회(셀로비스) / 말미 1회(대부분) / 댓글로만(바이러셋·머슬아머) / 최종화에만(리더뮨).

## 4. 신뢰 장치 카탈로그 (실측 종합)

사장님 2축 정의: **설득력**(원인→기준→우리 제품뿐 논리) + **신뢰성**(광고로 안 보이게). 신뢰성 장치를 7군으로 분류:

**A. 화자 자격** — ①직업 증빙 컷(사원증·명찰·현장·손 사진) ②전문가 위장(12년차 미용사 자격증, "의사 FAQ" 이중화자) ③무해 위장(평범한 아줌마·엄마) ④계정 이력 자산(연재 6편, 생활 잡글 사이 배치)
**B. 광고 부인** — ①명시 부인("광고 절.대 안 받음") ②고지 달고도 순수후기 화법(유랄 모순형·자사 리페아) ③한시 공개("일주일만") ④제품명 은폐 연기+모자이크(루씨드) ⑤타 제품만 실명, 자사는 익명(리더뮨이 극단)
**C. 박해·희소** — ①게시중단·삭제 재업 서사("9차 재업로드") ②쪽지함 폭주 캡처 ③품절·쟁여두기 ④해외직구 80만원 대비 희소
**D. 증거 연출** — ①카톡 캡처(타임스탬프·배터리·호칭 디테일) ②검사지·수치 아크(65→49→11.9) ③영수증·결제내역 ④비포애프터·GIF(움직임=생동감) ⑤**그림판 그림**(촬영 불가 알리바이 — 머슬아머 수영장) ⑥열화상·임상 그래프
**E. 겸손·자인** — ①단점 자백(비쌈·품절·맛없음) ②교란변수 자인("마스크 덕일 수도") ③"플라시보일 수도 있지만" ④효과 한계 인정("완치는 안 됨") ⑤오타·입말 방치
**F. 댓글 연극** — ①역할 분담(소개자/희소성/잔소리꾼/격하꾼/사회적증거) ②**링크는 작성자가 게시**(추천자는 제품명만 — 신고 회피) ③댓글 차단(연출 붕괴 방지) — 개방(장문 정성글) vs 차단(단문 위장글)의 선택 논리
**G. 형식 위장** — ①카페 단문(카페에서 몇천자 안 씀) ②질문글(파는 글이 아니라 묻는 글) ③반말 일기 독백 ④무관 잡담 삽입(사위 신발·소주·동태찌개)

**얼굴 노출**: 사장님 언급(모자이크 안 하면 신뢰↑)과 달리 21표본 전원 모자이크 처리. 무모자이크는 차별화 여지 — 단 초상권·재사용성 트레이드오프.

**GIF**: 사장님 언급대로 유랄(5건+)·머슬아머가 사용 — 손목 굽히기 비교, 착용 장면. 크림 제형은 "바르는 동작·발림성·온열 붉어짐"이 GIF 최적 소재.

## 5. 제형별 효능 논리 — 히토가 훔칠 것

| 제형 | 논리 패턴 | 표본 |
|---|---|---|
| 기기 | 스펙 기준 역설계 (100Hz 논문·40도·40kpa·5면 용해) | 미베러·리커버젠·가디브 |
| 영양제 | 성분 쪼개기 격하(C4S 노화형 vs C6S 재생형)·자체 조어("염증방어체")·2성분 분업(재생+염증) | 포켓잇·큐보젠·피지스랩 |
| **크림** | **MSM 4중 권위**(동의보감+칼 파이퍼+SCI 경구+**경피 도포 논문**)·함량 ppm 앞자리·피부보호 성분·부작용 겁주기 | **바디슈·유랄** |
| 패치 | 2단계론(①염증 제거 ②노폐물 배출)·물리 조건 2개(0.7cm·재사용) | 덴바디 |

공통 대전제 (4개 브랜드가 반복): **"통증의 원인은 연골이 아니라 염증"** — 이 프레임은 시장에 이미 깔려 있어 히토도 무임승차 가능.

## 6. 덴바디 "1코어 + N인트로" 해부 (법의학 수준 확인)

같은 블로그명("수영이 일기장") 다른 계정 2개, 5일 간격 발행, 코어는 문장 단위 동일. **교체 슬롯 6개만 갈아끼움**:

| 슬롯 | 손가락 편 | 무릎 편 |
|---|---|---|
| ①직업 증빙 | 디자이너 (사무실·사원증) | 이마트 6년차 50대 (명찰·재고) |
| ②결핍 장면 2개 | 컵 못 잡음·타자 불가 | 계단·재고 쌓기 |
| ③진단명 | 손가락 관절염→퇴행성 초기 | 무릎 관절염→퇴행성 초기 |
| ④실패 치료 3종 | 영양제·파라핀·스테로이드 | 영양제·침술·찜질 |
| ⑤부위 인포그래픽 | 염증 띠(Inflammation Band) | 3단 인포그래픽+전문가 1인 추가 |
| ⑥카톡 증언 호칭 | "팀장님" (김영지 대리) | "미경언니" (김희영) |

공용 코어: 사직서 소품 → "욱신·뻣뻣·시큰" 트리오 → 의사 인용 → 변형 공포 → 일본 시누이 씬 → "연골보다 염증" 원리부 → 2단계론 → 구매 조건 2개 → 쪽지 폭주 → "일주일만" 링크.

**양산 결함 2건** (우리가 피할 것): 무릎 편에 "굳은 **손가락** 조직"·"뭔가를 **집는** 일조차" 잔존. 부위 치환 후 전수 검수 필수. 목차 번호(3)와 본문 번호(4) 불일치도 동일 유형.

## 7. 히토온천크림 설계도 (오십견·무릎·팔꿈치 1코어 3인트로)

**제품 자산** (raw/본인/2026-08-26 용기MOQ-히토사례): 홋카이도 카를루스 온천수 함유 · 일본산 PDRN·MSM·보스웰리아 체크 성분 · 라벨 6요소(장식 프레임·노인 초상·일본어 병기 ヒートコインクリーム·산지·체크 성분·풍경 판화) · 100ml 병.

**코어 논리 초안** (첨삭 대상):
> 부위는 달라도(어깨·무릎·팔꿈치) 원인은 하나 — 관절 주변에 **굳은 염증**. (시장 공통 프레임 무임승차)
> 풀리려면 2박자: ①염증 진정 ②굳은 조직을 데워 혈류로 배출. (덴바디 2단계론 동형 — 온열이 "배출 스위치"라는 기전은 덴바디 원적외선 파트와 동일 문법)
> 일본 온천 마을 노인들이 관절 튼튼한 이유 = 매일 온천 (카를루스 온천수 세계관 — 덴바디 "일본 시누이" 슬롯을 **온천 여행/탕치(湯治) 씬**으로 치환. 라벨 노인 초상과 세계관 일치)
> 그걸 바르는 걸로 재현: 온천수 + MSM(경피 논문 — 유랄이 깔아둔 문법 재활용) + 보스웰리아.
> 구매 기준 2~3개 (예: ①온천수 함유량/진짜 산지 ②MSM 함량 앞자리 ③피부보호 성분) — 기준 역설계, 메타형이므로 3개 이하.
