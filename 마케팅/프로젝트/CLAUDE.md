# 프로젝트/ — 작업장 (도서관 아님)

진행 중인 **제품·캠페인 실무 문서**의 자리. 도서관(wiki)과 분리된 작업장(workshop)이다.
2026-08-27 신설 — 사장님 지시: "위키의 원 컨셉은 정돈된 도서관인데 DA 기획하면서 지저분해짐, 해결해."

## 무엇이 여기 오는가

- 제품 기획서·기획 라운드 기록·판정 기록 (예: 상징재 130건 판정)
- 경쟁사·리뷰·커뮤니티 **실측 덤프** (예: 리뷰 1,002건 실측, 담화 2만건)
- 상페 설계 초안·벤치마킹 해부 등 **그 제품에만 쓰이는** 작업 문서

## 무엇이 여기 오면 안 되는가 (→ 각자 제자리로)

| 재사용 가능한 룰·판정 기준 | → `wiki/syntheses/` ([[DA 기획 판정 룰]] 등) |
| 개념·사례 (제품 무관하게 통용) | → `wiki/concepts/` ([[상징재]]의 휩드 사례 등) |
| 경쟁사·브랜드 엔티티 | → `wiki/entities/` ([[쏙모팩]] 등) |
| 사장님 구술 원문 박제 | → `raw/본인/` (강화학습 루프 그대로) |
| 발행되는 최종 산출물 (상세페이지 최종본·광고 카피 발행본) | → `아웃풋/` |

## 운영 규칙

1. **위키에는 증류물만** — 프로젝트에서 배운 것은 룰·사례·개념으로 증류해서 wiki에 올린다. 실측 덤프·제품 상태는 올리지 않는다. wiki 페이지가 프로젝트 문서를 근거로 쓸 때는 경로로 참조 (`프로젝트/DA-기획/…`).
2. **폴더 = 프로젝트 단위** — `DA-기획/` 아래 제품별 하위 폴더. 새 프로젝트는 새 폴더.
3. **종료 시** — 교훈이 wiki로 증류됐는지 확인 후 폴더는 그대로 보존 (git이 이력). 폐기 기획은 `…-폐기/` 접미로 표시하고 부검은 [[DA 기획 사망 사례집]]에.
4. frontmatter·인용 규칙은 아웃풋과 동일 (based_on으로 wiki 근거 명시).

## 현재 구조

```
프로젝트/
  DA-기획/
    공통-탐색/        ← 제품 미정 단계의 탐색·카탈로그 (무제약 10분류, 유효기획 192 등)
    속모증-쏘모우카/   ← 진행 중 (필오프 팩, 핀란드 사우나)
    자갈턱-폐기/      ← 폐기 (부검: DA 기획 사망 사례집 사례 1)
```
