## 0. 최대 발견 — 카테고리 상위 3곳이 "떼어내기"를 처형하고 있다

우리 제품이 **필오프**인데, 광고비를 태우는 상위 브랜드들이 정확히 그 제형을 적으로 지목한다.

| 브랜드 | 원문 |
|---|---|
| **풀리** (포어펩타이드) | **"1세대 — 붙이고 떼는 코팩"** · *"피부 장벽을 무너뜨리는 강한 물리적 자극 / **억지로 뽑아내 점점 더 넓어지는 모공** / 피지가 더 빨리 쌓이는 악순환의 반복"* |
| **노일리** | *"검게 박힌 블랙헤드 뜯어내면 끝?"* → ⚠️ *"**강제로 뽑아내는 코팩**이나 화학적 제거는 과도한 자극으로 **되돌릴 수 없는 모공 확장과 색소침착**을 유발합니다"* |
| **풀리** (그린토마토) | *"모공 관리, 그동안 어떻게 했나요?"* → 3컷 처형: **떼어내기(피부 장벽 손상 유발)** · 녹이기(피부 자극) · **말리기(피부가 건조한)** |

🔴 **풀리 그린토마토는 우리 제품의 두 축(떼어내기 + 20~30분 말리기)을 동시에 친다.**

**함의**: 쏙모팩이 이미 이 역풍을 맞고 있고 우리도 똑같이 맞는다. 상페에 **선제 방어 블록이 필수**다.
→ 방어 재료는 이미 있다: ①저자극 인체적용시험 ②*"안 뽑아서 넓어지는 겁니다"* 역공 프레임 ③**온열로 무르게 해서 뽑으니 물리적 자극이 낮다** — 저들의 "억지로 뽑아내"와 정면으로 갈라지는 지점.

## 1. 세대론이 카테고리 표준 문법이다

두 브랜드가 독립적으로 같은 구조를 쓴다.

**풀리 — "1·2·3세대의 단점을 극복한 #4세대 크림 투 오일"**

```
1세대 붙이고 떼는 코팩        → 장벽 손상·모공 확장·악순환
2세대 흘러내리는 클렌징 오일   → 문질러야 함·옷 적심·딱딱한 피지엔 애매
3세대 도구로 긁어내는 피지연화제 → 화장솜·도구 번거로움·붉게 달아오른 코
4세대 (자기) "자극 없이 쏙 뽑는 #4세대 / 5분이면 묵은 피지 OUT"
```

**메라블 — "3세대 탄닌샷"**

```
1세대 반복된 자극으로 오히려 모공 조직을 늘어나게 함
2세대 저자극 탄닌이나 모공 깊숙이 침투 어려움
3세대 탄닌샷 — 모공벽 단백질을 단단하고 강하게 밀착
```

→ **우리도 세대론을 쓸 수 있고, 안 쓰면 1세대로 분류당한다.** 우리 버전 초안:
> 1세대 코팩(표면만 붙어 안 나옴) → 2세대 오일·연화제(녹여도 털은 안 녹음) → 3세대 필오프(찬 피부에 억지로 뗌) → **4세대 온열 필오프(열어서 무르게 한 뒤 뽑음)**
