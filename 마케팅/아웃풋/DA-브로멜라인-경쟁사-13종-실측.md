# 브로멜라인 경쟁사 실측 — 상페 7종 + DA 영상 6편

> **방법**: 자사몰 상세 이미지 전량 다운로드 후 판독(붓톡·악타멜라인·앗차차·파인톡·슬리아·팻랩·마이디데이) + DA 영상 6편 프레임 추출 판독(붓톡 2 · 브로멜라인 안티 1 · 모어멜라인 3).
> **목적**: 속모증 필오프 팩의 2단계("무르게 한다") 축으로 브로멜라인을 이식할 수 있는지 판정.

---

## 0. 한 줄 결론

> **경구 브로멜라인 시장 전체가 "연육"이라는 최강 통념을 갖고도 못 쓰고 있다. 몸속 장면을 보여줄 수 없어서다. 우리는 20~30분 뒤 손 위에 결과가 나오는 유일한 제형이다.**

그리고 두 번째 발견:
> **경구 카테고리 전체가 "위산에서 살아남았느냐"로 싸운다. 바르는 브로멜라인은 위산을 안 만난다.**

## 1. 상페 7종

| 브랜드 | 제품 | 가격 | 결핍 | 주 문법 |
|---|---|---|---|---|
| 테트라큐어 | 붓톡 브로멜라인-X | 37,200 (소비자가 63,000) | 부종 | 특허 TriMelt™ · 92% 재구매 · 5억 제조사 |
| 모어트루 | 악타멜라인 | 29,800 (54,900) | 체중 | 🔴 **"해외에서 난리난 연육 주스 레시피를 그대로"** · "키위와 파인애플 2중 연육" |
| 앗차차 | 알파CD와 브로멜라인 | 26,800 | **혈당→체지방** | 100만포 · 축을 알파CD로 이동 · 타사 14포 vs 30포 비교 |
| 루틴톡 | 파인톡 | 박스당 ~23,260 | 가벼움 | **"파인애플 약 180개 분량"** · "커피 한 잔보다 저렴" |
| 슬리아 | 슬리아 | 박스당 20,940~32,900 | 체중 | **파인애플 32개 = 1BOX** 아이콘 그리드 · **PubMed 2,316건 + 논문 스캔 + 금색 검증완료 배지** · 흰 가운 "전문 배합사" 친필서명 · 필리핀산 |
| 팻랩 | (프리바이오틱스 젤리) | — | 배변 | 브로멜라인 아님 — 리뷰 전면 배치 |
| 마이디데이 | 마이디데이 | **박스당 8,600** (20BOX) | 붓기·체중 | 🔴 **"21,000시간 레시피"** · **"카피 제품으로부터 보호하기 위해 주 원료 구성만 공개"** · 인물 시나리오 4칸 · 해외수출 100억 |

### 공통 문법 8개

| 1 | **원물 환산** — 파인애플 N개 = 1박스 (슬리아 32 · 파인톡 180) ← 카테고리 대표 |
| 2 | **함량 mg 경쟁** — 20,000 / 18,000 / 90,000 |
| 3 | **논문·검색량 권위** — PubMed·구글·인스타 건수 + 논문 스캔 + 월계관 배지 |
| 4 | **가운 인물** — 전문 배합사 + 서명 (→ [[상징재]] 직업 권위) |
| 5 | **비공개를 자산으로** — "카피 방지 위해 주 원료만 공개" |
| 6 | **인물 시나리오 N칸** — 경락샵 지수씨 / 출산 후 소영씨 / 배달음식 신애씨 / 다리 무거운 혜경씨 |
| 7 | **산지** — 필리핀산 |
| 8 | **다회차 대량 할인** — 20BOX·11BOX 단위 |

### 🔴 그런데 7개 중 "연육"을 쓴 건 악타멜라인 하나

앗차차는 혈당으로 도망갔고, 팻랩은 유산균으로 갈아탔고, 나머지는 mg·논문·수출로 싸운다.
→ **통념을 갖고도 못 쓰는 이유 = 먹는 제품은 몸속 연육 장면을 못 보여준다.**

## 2. DA 영상 6편

### 2-A. 붓톡 2편

**영상 A — 금지형 후킹 (상단 고정 자막)**
> **"얼굴에 붓기 없으신 분들은 함부로 드시면 안 됩니다"**

흐름: *"초고함량 단백질 효소가"* → 파인애플 진열·농축 → **인체 3D 단면** *"지방 사이에 꽉 막힌"* → **노폐물 클로즈업** *"고여 있던 수분 노폐물을"* → 하수구 물 *"소변으로 빠져나가며"* → 🔴 **"단 20분 만에"** · *"안쪽부터 싹 정리됩니다"*
권위: *"괜히 아이돌이나 청담샵에서 촬영 전 필수템으로"* · 옥외 대형광고 + 군중 컷
마감: *"재구매율 압도적 1위"* · *"지금 72% 시크릿 특가"* · 자물쇠

**영상 B**
*"고농축 단백질 / 분해효소가 / 배출시키면서 / 붓기를 쭈아악 빼준대요"* + 🔴 **"구강점막으로 → 효과가 10배"**
*"런칭 68일만에 168,358포 완판 · 국내 붓기템 1등"* · *"1초에 2포씩 판매"*

### 2-B. 🔴 안티 영상 — "대국민 사기극 (7편) 브로멜라인"

전문가(안경) 등장. **결핍 리스트를 광고주 대신 정리해준다**: 염증 · 다이어트 · 비염 · **비문증**
> *"단백질 분해효소 브로멜라인"* → *"몇몇 의사 약사 분들도"* → **"사기니까"**
> 🔴 **"브로멜라인은 위산을 만나면"** — 기사(위산)에게 무릎 꿇고 전멸한 병사 일러스트
> → *"위가 아닌 장에서 녹게끔"* (장용성) · *"국내에서 만들어지는"*

**함의 2개**
1. **경구의 아킬레스건이 공개 공격당하고 있다.** 붓톡의 "구강점막 10배"도 같은 방어다
2. **비문증이 결정적 선례** — 눈 속에 뭉친 단백질을 녹인다는 논리. 속모증은 모공 속에 박힌 단백질(케라틴). **구조가 같다** → 우리는 새 통념을 만드는 게 아니라 **리스트의 다음 칸**에 들어간다 ([[DA 기획 판정 룰]] §3 화살표 1개 통과)

### 2-C. 모어멜라인 3편 — "콩팥 스케일링"

| 22 | 실사 + 의학 3D · 64초 — 본편 |
| 24 | AI 클레이 애니 · 55초 — 같은 논리를 캐릭터로 |
| 23 | 정지컷 + 자막 · 17초 — *"와이프도 첨엔 안 믿더니 몰래 내꺼 까먹고 있더라"* |

**5단 구조**
```
① 부품 지목    "문제는 이 ㅅㅏ구체 통로가"
② 물리적 불가  "워낙 좁고 미로처럼 얽혀있어서
               그 어떤 물리적인 방법으로도 진입이 정말 어렵다는 거죠"   ← 심장
③ 시술명 이식  "요즘 신ㅈㅏㅇ파에서 콩ㅍㅏㅌ 스케일링이라고 하죠"
④ 내부 투시    혈관 3D — 노란 찌꺼기 → 뚫림
⑤ 체감 증거    양말 자국 · 변기 거품 · 아침 가벼움
```
→ 자소 분리 표기 전수는 [[어뷰징과 리스크]]에 기록.

## 3. 속모증 이식안

### 3-A. 왜 우리 칸인가

| 그들 | 우리 |
|---|---|
| 몸속 연육 장면을 못 보여줌 | **20~30분 뒤 팩 뒷면에 실물** |
| 위산에서 죽음 (안티 영상이 공격) | **얼굴에 직접 얹음 — 위산을 안 만남** |
| "20분 만에"를 주장 | **20~30분이 실제 사용시간** |
| ②"물리적으로 진입 불가"를 **주장해야 함** | **타겟이 이미 몸으로 겪음** (핀셋 처형·압출 실패) |

### 3-B. 4단계

```
1  데운다      온열(사우나)     → 효소 활성 + 모공 열림
2  무르게 한다  브로멜라인(연육)  ← 신규. 털 자체
3  뽑는다      필오프 수축·접착
4  진정        미정
```

**후킹 후보**
- *"고기도 연하게 만드는 효소입니다."*
- *"뻣뻣한 털은 안 뽑힙니다. 연하게 만든 다음에 뽑는 겁니다."*
- *"다들 털 **주변**만 녹였습니다. 우리는 털을 뭅니다."* ← 쏙모팩 Step1과 목적어 분리
- *"먹는 브로멜라인은 위산에서 대부분 죽습니다. 우리는 얼굴에 직접 얹습니다."*
- *"모공 하나가 0.2mm입니다. 핀셋이 들어갈 크기가 아니에요."*

### 3-C. 가져올 것 / 안 가져갈 것

| ✅ 원물 환산 | *"1통에 파인애플 ○개 분량"* — 화장품엔 0건 |
| ✅ 연육 시각화 | 고기 재우기 컷 ↔ 팩 뒷면 접사. **경구가 못 하는 자리** |
| ✅ 논문 권위 | PubMed 2,316건은 공공재 |
| ✅ 비공개 자산화 | "21,000시간" 문법 |
| ✅ 인물 시나리오 4칸 | 속모증 4갈래(학생·20~30 여성·군필·등바디)에 그대로 |
| ✅ 금지형 후킹 | *"블랙헤드이신 분들은 쓰지 마세요"* |
| ✅ "물리적 불가" 선언 | 담화가 이미 증명 |
| ✅ AI 클레이 소재 · 정지컷 리타겟 | 저비용 + 그로테스크 완충 |
| ✕ 구강점막 10배 | 제형 무관 |
| ✕ 아이돌·청담샵 | 조달 불가 |
| ✕ "쭈아악" | 의성어는 쏙모팩 선점 구역 |
| ✕ 자소 분리 | 우리는 정공법 |
| △ 시술명 이식("모공 스케일링") | 선점 미확인 + **스케일링=긁는다**라 §2 마지막 장면 룰 위반 소지 |

## 4. 정직한 빈칸 (리스크 4개)

| 1 물리 | 털 케라틴은 이황화결합 때문에 프로테아제로 잘 안 분해된다(제모크림이 환원제 쓰는 이유). **20~30분 내 실제 연화 미검증** — §2상 배합만으로 통과(써모드 자리)지만 **프로토타입 실측 필수** |
| 2 규제 | "털을 분해한다" = 제모 효능 표방 소지 |
| 🔴 3 자극 | **브로멜라인은 단백질 분해효소라 피부 자극·알레르기 소지.** 얼굴 20~30분 밀착 + 저자극 인증 방침과 충돌 가능 — **OEM에 얼굴용 상한 농도 확인이 선행** |
| 4 세계관 | 파인애플은 핀란드 밖. 토르홉 문법(배경=핀란드, 후킹=주방 상식)으로 관리하되 **원물 사진을 크게 깔면 세계관이 흔들린다** |

## 5. 미결 (사장님 판정 대기)

1. 브로멜라인 = 2단계 확정 여부
2. 파인애플 노출 수위 — 원물 전면 / 성분 블록만 / 성분명만
3. 크림 색 — 검정(대비 실측 우위) vs 짙은 초록(세계관)
4. 위산 적 프레임 채택 여부
5. "물리적 불가" 후킹 채택 여부
