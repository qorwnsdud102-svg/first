# 소극성 속모증 — 타겟 확정 (검색량 × 담화 × 후기 교차)

> **재료 3종**: ①네이버 검색량 실측(속모증·쏙모팩, 2026-08 캡처) ②커뮤니티 담화 2만건 ③쏙모팩 네이버페이 검증 구매평 727건
> **방법**: 세 소스가 같은 방향을 가리키는 것만 결론으로 채택. 한 소스만 말하는 건 가설로 표시.

---

## 0. 결론 3줄

1. 🔴 **브랜드 검색이 결핍 검색의 10배다.** 이 시장은 검색으로 찾아오는 시장이 아니라 **광고로 만들어 브랜드 검색으로 회수하는 시장**이다.
2. 🔴 **결핍을 자각한 건 30대(46%), 실제로 산 건 20대(44%)다.** 이 역전이 우리 자리다 — **30대는 아프다고 검색하는데 아직 안 샀다.**
3. **여성 88~93%. 모바일 81.5%.** 이건 세 소스가 전부 일치한다.

## 1. 검색량 실측 (2026-08)

| | **속모증** (결핍어) | **쏙모팩** (브랜드어) |
|---|---|---|
| 월간 검색 | **2,710** (PC 500 / MO 2,210) | **약 24,000** (26-07 그래프) · 앞선 실측 27,740 |
| 여성 | **87.8%** | **92.8%** |
| 남성 | 12.2% | 7.2% |
| 10대 | 4.5% | **11.7%** |
| 20대 | 26.9% | **44.1%** |
| **30대** | **46.0%** | 29.2% |
| 40대 | 19.6% | 11.9% |
| 50대+ | 3.0% | 3.1% |

### 1-1. 🔴 브랜드어가 결핍어의 **약 10배**

> 속모증 2,710 vs 쏙모팩 24,000 = **8.9배** (27,740 기준이면 10.2배)

**이 시장의 성질을 규정하는 숫자다.**

| 함의 1 | **결핍 키워드로 먹을 게 없다.** 2,710을 다 먹어도 월 2,710이다. SEO·검색광고 중심 전략은 성립 안 함 |
| 함의 2 | **DA로 인지를 만들고 브랜드 검색으로 회수하는 구조**가 유일한 경로 — 우리가 DA 기획으로 접근한 게 맞았다 |
| 함의 3 | 🔴 **쏙모팩 브랜드 키워드 자체가 시장이다.** 월 24,000이 "쏙모팩"을 검색한다. 지금 그 자리에 붙어 있는 건 **G마켓과 자사몰뿐**이다 |

### 1-2. DA가 질병 검색량을 끌어올린다 — 실측 확증

**속모증 월별 추이**: 25-08 약 2,000 → 26-03 약 1,000(최저) → **26-07 약 5,000**
**쏙모팩 월별 추이**: 25-08 약 2,000 → 26-05 약 10,000 → **26-06 약 26,000 폭등**

두 곡선이 **26-04부터 같이 올라간다.** 브랜드가 먼저 튀고 결핍어가 따라온다.

> [[DA 제품 소싱 기준]] *"DA가 질병 검색량을 끌어올린다"* 명제의 **실측 표본**.
> → **함의**: 쏙모팩이 광고비로 시장을 키워놨고, 우리는 그 확대된 결핍 인지에 **무임승차**할 수 있다. 선점자가 시장을 만드는 비용을 이미 냈다.

## 2. 🔴 연령 역전 — 이번 분석의 핵심 발견

```
결핍 자각(속모증)      30대 46%  >  20대 26.9%
실제 구매(쏙모팩)      20대 44.1% >  30대 29.2%
```

**아픈 사람과 산 사람이 다르다.** 30대는 자기 증상을 가장 많이 검색하는데 쏙모팩으로는 덜 넘어갔다.

### 왜 30대가 안 샀나 — 세 소스가 같은 답을 준다

| 근거 | 내용 |
|---|---|
| **연관검색어** | `쏙모팩 다이소`(2회) · `가격비교` · `구매처` · `올리브영` → **저가·오프라인 지향** = 10~20대 소비 패턴 |
| **구매평 불만 1위** | **자극·눈시림 11.1%** — *"바를 때 눈이 시리고 뗄 때 아프고"*. 30대는 자극 내성이 낮다 |
| **구매평 불만 3위** | **비싸다 6.9%** — *"4만원 돈하는 가격 때문에 몇 달 고민"* |
| **10대 비중 급증** | 4.5% → **11.7%(2.6배)**. 쏙모팩 DA가 도달한 곳이 어디인지 보여준다 |

→ **가설**: 쏙모팩의 도달 채널·가격·자극 프로필이 **10~20대에 최적화**돼 있고, 30대는 결핍만 자각한 채 남아 있다.

⚠️ **경쟁 해석**: "30대는 검색만 하고 피부과·레이저로 간다"도 가능하다. 다만 담화가 그 경로를 처형한다 — *"거의 100만원이라 차마 시도를 못하겠고"* · *"무조건 재발함"*. **간 게 아니라 못 간 것**에 가깝다.

### 🔴 그런데 우리 제품 스펙이 30대에 정확히 맞는다

| 우리 스펙 | 30대와의 정합 |
|---|---|
| **저자극 인체적용시험** | 불만 1위(자극 11.1%)의 정면 해소 |
| **온열 체감** | 자극이 아니라 **쾌적한 감각**. "뜯긴다"의 반대편 |
| **35,900 (3만원대)** | 4만원 벽 회피 |
| **핀란드 세계관·북유럽 디자인** | 다이소·저가 지향과 반대편의 프리미엄 감성 — 30대 소구 |
| **100g 대용량** | 등·바디까지. 실용 구매 |

> **우연이 아니라, 우리가 쏙모팩 불만을 역설계해서 그렇게 됐다.**

## 3. 성별 — 여성 88~93%, 세 소스 일치

| 검색(결핍어) | 여 87.8% |
| 검색(브랜드어) | 여 **92.8%** |
| 실구매(구매평) | 여 **92.8%** |

→ **메인 화자는 여성으로 고정.** 남성은 별도 소재로만.

**다만 남성 수요는 실재한다**
- 연관검색어에 **`쏙모팩 남성용`**이 독립 항목으로 뜬다 (7.2%인데도)
- 담화 C갈래 — *"군대갔다와서 이제 이런것도 신경써야겠더라고"*
- 블랙헤드 DA 소재에서 남성 타겟 소재가 별도로 돈다 — *"남자들 귀찮은거 딱 질색인거 아는데"*

→ **남성용 SKU가 아니라 남성용 소재.** 제품은 같고 카피만 분리.

## 4. 연관검색어가 말하는 것

### 4-1. 속모증 (결핍어) — 아직 답을 못 찾은 상태

```
소극성 속모증 · 속모증 팩 · 속모증 레이저 · 미간 속모증
소극성 속모증 제모 · 소극성 속모증 피부과 · 속모증 등 · 등 속모증
소극성 속모증 제거 · 코 소극성 속모증 · 소극성속모증 코팩 · 속모증 치료
```

| **레이저·제모·피부과·치료** | 시술 경로를 먼저 찾는다 → **적 프레임 자리 확증** |
| **팩·코팩** | 홈케어로 내려온다 |
| 🔴 **미간 속모증 · 등 속모증** | **부위가 검색어로 분화돼 있다** — 우리 부위 다이어그램(코·나비존·미간·등)이 실수요와 일치 |

### 4-2. 쏙모팩 (브랜드어) — 저항과 재구매가 다 보인다

| 🔴 **`쏙모팩 내돈내산`** | **연관 1위.** 신뢰 저항이 최대 장벽 → 우리 "어뷰징 안 함" 축의 근거 |
| `가격비교` · `구매처` | 가격 저항 |
| `다이소`(2회) · `올리브영` · `약국` | 🔴 **오프라인에서 찾는다.** 온라인 광고를 보고 오프라인에서 사려는 수요 — 아직 미충족 |
| `사용법` · `사용방법` · `주기` | **사용 후 재방문** = 재구매 신호. *"완치가 아니라 주기 관리"* 서사 확증 |
| `후기` | 검증 동선 |
| `남성용` | 남성 수요 |
| `쏙모팩 등` | 등 부위 수요 |

## 5. 시즌 — 여름 결핍이다

**속모증 추이**: 25-08 약 2,000 → 25-11~26-03 하락(최저 약 1,000) → **26-04부터 급등 → 26-07 약 5,000**

- 겨울 대비 여름 **약 5배**
- 전년 동월(25-08 2,000) 대비 26-07 5,000 = **2.5배 성장** (시즌 + 쏙모팩 DA 효과 중첩)

→ **런칭 타이밍**: 4~5월에 태워서 6~8월 피크를 먹는 구조. 지금(8월)은 이번 시즌 끝물이라, **준비 기간을 겨울에 쓰고 내년 봄에 붙는 게 맞다.**
→ 겨울 대응: 풀리가 쓰는 **계절별 사용 TIP**(가을·겨울엔 주 1회, 1분) 문법으로 비수기 이탈 방어.

## 7. 타겟 최종 확정

### 7-1. 우선순위 재정의

| 순위 | 타겟 | 근거 | 우리 정합 |
|---|---|---|---|
| 🔴 **1** | **30대 여성** | 결핍 자각 **46%**(최대) · 구매 전환은 29.2%로 낮음 = **미개척** · 구매력 · 화장 뭉침이라는 실용 동기 | 저자극·온열·3만원대·북유럽 감성이 전부 여기 맞음 |
| **2** | **20대 여성** | 실구매 주력 44.1% · 시장이 이미 검증됨 | 가격·SNS 확산 |
| 3 | 40대 여성 | 결핍 19.6% / 구매 11.9% — 30대와 같은 패턴(자각>구매) | 저자극 소구 강함 |
| 4 | 10대 | 브랜드검색 11.7%로 실재하나 결제권이 부모 · 다이소 지향 | 가격 저항 |
| 5 | 20~30대 남성 | 7~12% · `남성용` 검색어 실재 | **별도 소재만** |

> **기존 기획서의 "20~30대 여성 주력"에서 → "30대 여성 1순위, 20대 여성 2순위"로 조정한다.**
> 이유: 20대는 이미 쏙모팩이 먹었고, 30대는 아프다고 검색하는데 아직 안 샀다. **후발주자는 선점자가 못 먹은 층을 먹는 게 싸다.**

### 7-2. 구매 상황 (담화 기반)

```
① 확대해서 보고 온다      "확대해보니까 거의 다 가시털이더라고요"
② 이름을 알게 된다        "어쩐지 ㅈㄴ 안지워지더라"        ← 감정 폭발
③ 시술을 알아본다         레이저·피부과·제모 검색
④ 견적에 좌절한다         "거의 100만원이라 차마"          ← 🔴 우리 자리
⑤ 홈케어로 내려온다       속모증 팩 · 코팩 검색
⑥ 브랜드를 검증한다       "쏙모팩 내돈내산"               ← 🔴 우리 자리 2
```

**진입점 2개**
- **④~⑤ 사이 = DA 후킹** (자각시키는 광고가 시장을 만든다)
- **⑥ = 신뢰 축** (어뷰징 안 함 · 보정 없는 원본 · 환불 보장)

## 8. 실행 함의 4개

| 1 🔴 **쏙모팩 브랜드 키워드에 붙는다** | 월 24,000이 그 이름을 검색한다. 현재 G마켓과 자사몰뿐 — **검색광고로 즉시 진입 가능한 최대 트래픽 풀** |
| 2 🔴 **소재·상페는 모바일 우선** | 결핍어 모바일 비중 **81.5%**(2,210/2,710) |
| 3 **30대 채널로 소재를 태운다** | 20대 채널(쏙모팩이 먹은 곳)이 아니라 30대 도달 채널 |
| 4 **런칭은 4~5월** | 여름 결핍(겨울 대비 5배). 겨울은 준비 기간 |

## 9. 미확인

- 30대 미개척 가설의 **직접 증거 없음** (검색량 간접 추론) → 소재 A/B로 연령 타겟 테스트해서 검증할 것
- 쏙모팩 실판매의 연령 구성 (브랜드 검색 ≈ 구매 의향으로 근사했을 뿐)
- 오프라인(다이소·올리브영) 수요 크기 — 연관검색어로만 확인
- 결핍어 2,710은 '속모증' 단일. `가시털`·`코 털 박힘` 등 **유사 결핍어 미실측**
