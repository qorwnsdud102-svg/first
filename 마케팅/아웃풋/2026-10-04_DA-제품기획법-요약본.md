# DA 제품 기획법 — 요약본

> **Claude에게**: 이 문서는 DA(메타·GFA 등 디스플레이 광고)로 팔 이커머스 제품을 **고르고 기획하고 판정하는 규칙**이다. 실제 DA 사업자가 기획 약 770개를 직접 정답/오답 판정한 결과를 압축했다. 사용자가 "DA 제품 기획해줘"라고 하면 **아이디어를 낸 뒤 반드시 아래 판정 순서로 스스로 걸러서**, 통과한 것만 제출하라. 걸러지지 않은 기획은 예외 없이 반려됐다.

---

## 0. DA 제품의 본질 — 검색 상품과 다르다

| | 검색(네이버) 상품 | **DA 상품** |
|---|---|---|
| 수요 | 이미 있음 (사람들이 검색함) | **만들어냄** (스크롤하다 몰랐던 결핍이 깨어남) |
| 1순위 | 논리·비교 우위 | **1초 후킹 — 상징 + 눈에 보이는 변화(BNA)** |
| 논리 | 핵심 | **최소 통과만** — 충동구매라 "사고 싶다"가 먼저, 논리는 산 다음 자기 정당화용 |
| 실패 모드 | 아무도 검색 안 함 | 스크롤로 넘어감 |

> 원칙: 논리는 설득 도구가 아니라 **변명거리**다. 상세페이지 아래쪽에 있으면 되고, 광고 소재(1초)에 넣으면 오히려 죽는다.

## 1. 핵심 공식

> **"병원에서 하는 그것을, 집에서, 더 싸게, 무섭지 않게."**

잘 팔리는 DA 제품 13개를 뜯어보니 12개가 이 뼈대였다.

| 제품 예 | 빌려온 원본 | 대체 논리 |
|---|---|---|
| 쥐젖 제거제 | 냉동치료(액체질소) | 바르면 차갑고, 굳으면 떨어짐 |
| 주름 앰플 | 써마지(고주파 열) | 바르면 미세 열감 |
| 관절 크림 | 연골주사 | 연골 성분(PDRN) 실배합 + 온열감 |
| 관절 패치 | 한의학 뜸·혈자리 | 자석·원적외선을 혈자리에 |
| 탈모 영양제 | 미녹시딜(의약품) | 먹는 형태 + "부작용 없음" |

- 원본 풀 = **서양 시술 + 한의학(뜸·부항·침) + 의약품 자체**. 서양 시술이 포화된 카테고리에 한의학 원본이 비어 있을 수 있다.
- 약을 빌리면 반박이 "그럼 그냥 약 먹지?"로 오고, 차단 장치는 **"부작용·복용 제약 없음"**이다.

## 2. 기획의 3슬롯 — 하나라도 비면 기획이 아니다

> **결핍** → **상징원**(그 결핍의 최상위 해결책) → **당위성 장치**(그 상징을 제품이 물리적으로 구현하는 수단)

| 결핍 | 상징원 | 당위성 장치 |
|---|---|---|
| 주름 | 써마지 | 미세열감 성분 + 피부과 용기 외형 |
| 쥐젖 | 냉동치료 | 바르면 차가운 성분 |
| 키 | 네덜란드(키 1위 국가) | 네덜란드 우유 실배합 |

---

## 3. 마스터 원칙 — 모든 판정의 상위

> 상징원은 **"비싸고 효과가 좋아서, 타겟이 하고 싶지만 잘 못하는 것"**이어야 한다.
> 예: 울쎄라(주름에 확실한데 비싸서 못 함) → "울쎄라 원리로 만든 주름앰플".

**자기검증 한 줄**: *"타겟이 돈만 있으면 당장 하러 갈까? 그런데 지금 못 하고 있나?"* — 둘 중 하나라도 아니면 상징이 아니다. **하고 싶음과 못 함 사이의 갭이 곧 제품이 설 자리**다.

예외: 국가·인식 상징(독일=기술력, 일본=온천)은 이 원칙 밖이지만, **예외라서 단독으로는 약하다** (§7).

## 4. 소싱 게이트 — "무엇을 팔 것인가" (위에서 죽으면 아래는 안 본다)

| # | 게이트 | 기준 | 성격 |
|---|---|---|---|
| 0 | **시즌** | 노출·기온이 만드는 결핍(제모·등드름·땀)은 판매 시즌 밖이면 못 판다. **폐기가 아니라 예약** — 판매월에서 리드타임 2~3개월 역산해 착수일 기록 | 하드 |
| 0.5 | **DA용 결핍인가** | 뷰티·질병 / 충동구매 가능 / 시장 크기 / 눈에 보임. **돈 안 쓰고 해결되는 결핍 탈락**("목 잠김은 따뜻한 물 마시면 되잖아"). 직업은 상징이지 타겟이 아니다(소방관 전용 클렌저 X) | 하드 |
| 1 | **BNA(전후 비교)가 나오는가** | ①제거형(떨어져 나감) ★★★ > ②장비 시각화(열화상·현미경으로 작동을 보이게) ★★ > ③후기 축적 ★★ > ④문서 권위(먹는 것 — 특허공보·논문·원료사 시트) ★. **예방재(충치·면역·항산화)는 보여줄 게 없어서 구조적 불가** | 하드 |
| 2 | **상징재가 붙는가** | 시술·의약품 원본이 존재 + 결이 60% 이상 일치 | 하드 |
| 3 | **원본이 법적으로 안전한가** | A급=시술 행위명·성분명·국가 클리셰(소유자 없음) / B급=전문의약품·국내 진출 약한 해외 브랜드 / C급=일반명사화된 등록상표(써마지·보톡스 — 우회 표현 권장) / **D급=국내 중소·중견 브랜드 → 탈락** | 하드 |
| 4 | 외국 상징 | 원산지·영문명·해외 실적·인증 중 2개 이상 | 점수 |
| 5 | **체감이 있는가** | 차가움·뜨거움·따끔 = 효과의 증거. ⚠️ 결핍마다 체감 채널이 다르다 — 근육 결핍(사각턱 등)은 피부 감각이 아니라 **동작**("입을 다물어 보세요")으로 판정한다 | 점수 |
| 6 | **원가율 30% 이하** | DA 광고비를 버티는 선 | 하드 |
| 6.5 | **화장품으로 착지하는가** | 무거운 데(병원·의약품)서 상징을 빌리고 **가장 가벼운 분류(화장품·일반식품)로 착지**. 의약외품·의료기기는 허가·MOQ·표현 제한으로 DA 속도와 충돌 | 하드 |
| 7 | 논리가 말이 되는가 | 통과만 하면 됨 | 최소 |
| 8 | 결핍이 여러 개로 갈라지는가 | 한 제품=여러 부위·결핍이면 위닝 소재 확률 배가 | 가점 |
| 9 | **(선점자가 있을 때만) 차별이 생산에 박히는가** | 후킹·BNA·상페·외형은 다 복제된다. 배합·구조·원료·공정 중 하나 필요. 단 판정은 **전환 비용**으로 — 선점자가 쌓은 브랜드명·용기·상페를 버려야 따라올 수 있는 차별(세계관·네이밍)은 실질적으로 복제 불가 | 선점 시장만 하드 |

**제품 유형 감각**: 제거재(쥐젖·티눈·블랙헤드·각질) **최상** > 개선재(주름·통증 — 열화상 같은 시각화 필수) **중** > 예방재 **하**.

## 5. 상징원 판정 — 14관문 (AI가 반복해서 틀린 곳)

| # | 관문 | 대표 오답 |
|---|---|---|
| ① | 그 결핍의 **최상위** 해결책인가 (2순위 X, 질환명·진단 X) | "수면다원검사"(진단이지 해결책 아님) |
| ①-b | **관념·비유 금지** — 기전이 닮아도 그 결핍의 실제 치료법이 아니면 가치 0 | 모공 털 뽑기 × "치과 본뜨기"(동작은 닮았지만 상징 가치 0) |
| ② | **나보다 우월한 존재**인가 | "일반 석류가 피부에 좋다" → 거들떠도 안 봄 / 수영선수(그 일을 많이 할 뿐 우월하진 않음) |
| ③ | **타겟이 그 상징을 인정**하는가 | 30~40대 직장인 안구건조 × 프로게이머(게임에 부정적인 사람 많음) |
| ④ | **공부 안 한 대중도 아는가** | 인도 아유르베다 오일풀링(모르는 사람이 대부분) / 우월하지 않은 국가 |
| ⑤ | 부정 연상이 없는가 (부위마다 다름, 묘사가 이물감을 만들 수도) | |
| ⑥ | 제품 카테고리가 그 상징을 받을 수 있는가 | |
| ⑦ | 병원 상징은 3조건: **비싸다·효과 확실·병원에서만** | 피부과 압출(사람이 바늘로 짜는 것 — 집에서도 됨) |
| ⑧ | 손기술이 본질인 시술은 이식 불가 | |
| ⑨ | 시술 자체가 마이너하면 X | |
| ⑩ | 병원 아닌 상업 시설은 약함 | |
| ⑪ | 실제로 만들 수 있나 (조달·법규) | |
| ⑫ | **고유명사**인가 — 범주 금지 ("콜라겐 생성 시술"·"스킨부스터"는 그림이 안 그려짐) | |
| ⑬ | 집에서 공짜로 되면 X | |
| ⑭ | **그 결핍 전용**으로 인식되나 — "바르는 [상징원]으로 [결핍] 하세요"가 1초에 이해되나 | |

## 6. 당위성 — 기전 한 단어 테스트 (가장 많이 틀리는 곳)

상징과 제품을 정한 뒤 둘을 잇는 문장을 지어내면 그건 당위성이 아니라 **사후 합리화**다.

> **상징의 작동 원리를 한 단어로 적고, 제품이 그 단어를 물리적으로 낼 수 있는지 본다. 못 내면 즉시 폐기.**

| 상징 | 한 단어 | 제품이 낼 수 있나 |
|---|---|---|
| 써마지 | 열 | 미세열감 앰플 ✅ |
| 냉동치료 | 냉 | 차가운 크림 ✅ |
| 다한증 보톡스 | 수렴/억제 | 바르는 보톡스 펩타이드(아세틸헥사펩타이드-8) ✅ |
| 레이저 제모 | 모근 파괴 | 크림으로 **불가** ❌ |
| LED 마스크 | 광원 | 앰플로 **불가** ❌ |

**통과 유형은 딱 3개**: ①원료를 그대로 넣는다(온천수·PDRN·우유) ②기전을 체감으로 재현한다(열감·냉감·따끔) ③도구를 동봉한다(괄사·부항컵).

⚠️ **"결핍에 맞는 상징"과 "구현 가능한 상징"은 별개 조건이고 둘 다 필요하다.** 기각 대부분이 결은 맞는데 구현이 안 돼서 죽었다(레이저 제모·문신제거 레이저·종아리 보톡스).
⚠️ 이건 **효능 검증이 아니다** — 질문은 "타겟이 원하고 납득하나"지 "의학적으로 맞나"가 아니다.

## 7. 겹 쌓기 — 한 겹으로는 실전에서 약하다

**국가 상징은 이제 차별이 아니라 기본값이다.** 그 위에 시술·성분·체감을 겹쳐야 한다.

**완성형 표본 — 겨드랑이 다한증 (1겹 → 4겹)**

| 겹 | 축 | 내용 |
|---|---|---|
| 1 | 시술 상징 | 다한증 보톡스(30만원 — 하고 싶지만 못 함) |
| 2 | 성분 base | 아세틸헥사펩타이드-8 = "바르는 보톡스"로 이미 통용 |
| 3 | 국가 | 미국 |
| 4 | 취약형 | "체취가 더 심한 사람들이 쓰는 제품이면 나한텐 차고 넘치겠지" (a fortiori) |

네 칸이 서로 다른 질문에 답해서 곱셈이 된다 — 무엇을 대체 × 무엇으로 × 어디 것 × 누구도 되니까.

- 자기검증: **"국가를 떼도 남는 축이 있나?"** 없으면 "아무 제품에나 독일산 붙이기" — 실전 미달.
- 3겹 이상 권장.

### 나라·재료 상징의 구조 — base 통념 × MSG

- **base 통념** = 공부 안 한 사람도 아는 결핍↔재료 연결 ("탈모엔 맥주효모"). **없으면 끝.**
- **MSG** = 우월 국가·현장 ("독일 맥주공장 효모"). base가 있을 때만 맛을 낸다.
- ⚠️ **통념 체인은 화살표 1개까지.** "석류→여성호르몬→털 억제"처럼 개별 통념을 이어 붙이면 논리 퍼즐이 된다. 타겟은 퍼즐을 풀어주지 않는다.

### 취약형 상징 (a fortiori)

"그 조건이 더 심한 사람들도 이걸로 해결했다 → 나는 당연히 된다." 단, 그 집단이 **실제로** 더 심하다는 걸 통념이 아니라 **유병률 데이터로** 확인하라 (통념과 사실이 반대인 경우가 있다).

## 8. 참신성 · 선례 검증

- **이미 수백 곳이 하는 문법은 반려** (연어 PDRN 앰플, 스피큘 세럼, 홈 제모기). base가 유명할수록 이미 연결됐을 확률이 높다.
- **선례 실패는 참신성보다 강한 신호** — 같은 조합이 이미 출시됐다가 죽었으면, 특히 자원이 더 많은 회사가 실패했으면 이길 이유를 따로 대야 한다.
- 🔴 **선례가 팔렸는지는 브랜드 키워드 월 검색량 + 1년 추이로만 판정한다.** 리뷰 수·"N명 구매"는 어뷰징이 가능해서 증거가 아니다. 검색량 = 광고 노출의 흔적 = 큰 광고비 = 적자면 못 버틸 지출 = 팔리고 있다. (사람들이 실제로 치는 표기 변형을 여러 개 재서 최댓값을 쓴다.)
- **선점자의 틀 안에서 의미만 바꾸는 건 차별이 아니다.** 자기검증: "두 제품을 나란히 놓고 소비자가 10초 안에 차이를 알아보나?"

## 9. 외형 상징

1. 외형이 독특해서 **보면 이름이 떠오른다** (오쏘몰 병+앰플, 다이슨 스틱, 동전파스)
2. 그 분야에서 우월하다
3. 인접 카테고리로 이식한다 (파스 외형 → 관절 크림)

- **위에서 가져와라** — 주름앰플에 다른 크림 용기(수평 이동 = 짝퉁)가 아니라 **피부과 스킨부스터 용기**(상향 이동 = 우월성 전이).
- 시린지·바이알 같은 **범용 의료 도구는 분위기일 뿐 상징이 아니다** — 겹으로 세지 마라.
- 안전선: 색·실루엣·구조만 가져가고 로고·서체·명칭은 완전히 다르게.

## 10. 실행 단계 노하우

- **소재 ↔ 상세페이지 톤 분리**: 소재는 노골적·구체적("쥐젖이 얼어 떨어진다"), 상세페이지는 두루뭉실 + 제3자 권위(임상 수치·인증·논문). 소재는 갈아끼우면 끝이지만 상페에서 걸리면 몰 전체가 다친다.
- **권위는 "내가 아닌 제3자"에게서**: 전통·고전 인용, 특허공보 스캔, 원료사 기술 시트, 보험 가입증서 — 조달 비용이 거의 0이다. 단 **인용 문헌의 대상·용량·성분이 우리 제품과 일치하는지 먼저 확인**하라.
- **USP는 복수 트랙**: 하나로 수렴하지 말고 소재 테스트에 태울 카드를 여러 장 쥐어라. 어떤 카드가 터질지는 시장이 정한다. 리스크가 보이면 폐기 대신 표현을 바꿔 카드로 남겨라.
- **용기 질문 하나**: "이 용기에 라벨을 붙일 수 있나?" — 붙으면(경질 병·자) 1,000개 소량 검증 가능, 안 붙으면(튜브) 인쇄 때문에 MOQ 1만 개.
- **온열·순환 제품은 열화상이 기본 BNA**다 (작동을 눈에 보이게 만든다).
- **질감도 상징이 된다**: 제형 질감(쫀득·휘핑)이 "잘 될 것 같음"을 직접 전달할 수 있다. 질감 상징을 찾을 땐 음식 이름부터 떠올리지 말고 **그 질감으로 히트한 브랜드 선례부터 검색**하라.

## 11. 제출 전 자기검증 체크리스트

- [ ] 3슬롯(결핍·상징원·당위 장치)이 다 찼나
- [ ] **돈만 있으면 당장 하러 갈까? 그런데 못 하고 있나?**
- [ ] 집에서 공짜로 똑같이 할 수 있나 → 예면 폐기
- [ ] 상징원이 결핍의 **1순위 해결책**이고 **고유명사**인가 (질환명·진단·범주 X)
- [ ] 관념·비유가 아니라 **실제 치료법**인가
- [ ] 나보다 우월하고, 타겟이 인정하고, **공부 안 한 사람도** 아는가
- [ ] **기전 한 단어**를 제품이 물리적으로 낼 수 있나 (결 일치 + 구현 가능 둘 다)
- [ ] (재료·나라 상징이면) **base 통념**이 화살표 1개로 있나
- [ ] **국가를 떼도 남는 축**이 있나 / 3겹 이상인가
- [ ] DA용 결핍인가 (충동구매·시장·BNA) / 예방재 아닌가
- [ ] 원본이 A~B급인가 / 원가율 30% 이하 / 화장품·일반식품으로 착지하나
- [ ] 이미 남들이 하는 문법 아닌가 / 선례가 죽지 않았나 (**브랜드 검색량으로** 확인)
- [ ] 선점자가 있으면 따라 하기 어려운(전환 비용 큰) 차별이 있나
- [ ] 시즌에 걸리면 폐기 말고 **예약** + 부위·타겟 전환 검토

> 기획을 낼 때 각 항목의 통과 근거를 함께 적어라. 근거 없이 "통과"라고만 적은 기획은 걸러지지 않은 것으로 본다.
