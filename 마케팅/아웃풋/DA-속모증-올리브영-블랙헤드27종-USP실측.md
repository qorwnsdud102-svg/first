## 2. 🔴 이미지에서만 읽히는 것 — 외형 상징 6문법

상품명만 봐서는 안 보이고 **썸네일을 봐야** 잡히는 것들이다.

### ① 제형을 음식으로 보이게 한다 (= "있어 보임"의 정체)

> 사장님: *"아렌시아 떡솝은 **휘핑크림, 떡 느낌으로 쫀득한**? 뭔가 논리적이지 않지만 다른 제품 대비 **있어보이는 느낌을 외형적으로** 주기도 해"*

| 제품 | 무엇처럼 보이게 했나 |
|---|---|
| **아렌시아 떡솝** | **휘핑크림을 짜올린 3색 통** (그린·핑크·블루) |
| 스킨시그널 **머랭솝** | **머랭 쿠키** |
| 한율 **쑥떡**팩폼 | 떡 |
| 토르홉 미온스팀 젤밤 | **손가락으로 늘어뜨린 컷** — 쫀득함을 동작으로 |
| 토르홉 사우난지앙 | 청록 **소용돌이** |
| 토르홉 무스타 콩테 | 회색 클레이 **소용돌이** |

**공통 코어**: 효능이 아니라 **질감의 식욕**으로 프리미엄을 만든다. 논리 0인데 **단가가 올라간다**(떡솝 23,000 · 머랭솝 25,000 정가).

### ② 세계관을 외국어로 구축한다 (토르홉 단독)

**토르홉 3종이 전부 핀란드어 브랜드 세계관**이다.

| 라인 | 뜻 |
|---|---|
| **KAAMOS 카모스** | 핀란드어 **극야(極夜)** |
| **MUSTA CONTA** | *musta* = 검정 |
| **Hiden Naamio** | 숨겨진 가면 |
| *Puhdistava vaahto* | 정화하는 거품 |

+ **설원 배경 · 북유럽 캐릭터 일러스트 · 무민 증정품**.
→ 실재 지명이 아니라 **조어로 국가 상징을 짓는다.** [[상징재]] §2에 없던 문법.

### ③ 시술을 이미지로 넣는다

🔴 **샤이샤이샤이 알로에 PDRN 쿨링머드 — 썸네일에 주사기 2개를 박았다.** 화장품인데 주사기를 보여준다.
→ [[써모드 PLX]]가 피부과 용기를 쓴 것의 **시각판**. 성분명(PDRN)만 쓰는 게 아니라 **시술 도구를 그림으로** 건다.

### ④ base 재료를 실물로 깐다

녹두(비플레인) · 소나무(라운드랩) · **화산송이 현무암**(이니스프리) · 쑥잎(한율) · 소금 결정(토르홉)
→ 성분명을 글자로 쓰는 게 아니라 **원물을 사진으로** 보여준다.

### ⑤ 도구 증정이 표준이다

**스패츌러**(메디힐) · **모공브러쉬**(한율) · **팩브러쉬**(스킨시그널) · **착붙솜 40매+모공팩**(일소)
→ 27종 중 4종이 도구를 동봉하고, 전부 **썸네일 우측에 크게** 박는다.

### ⑥ 어워드 배지를 도배한다

**일소 노우즈팩이 4개**(2023 올리브영 어워즈 WINNER · 화해 명예의전당 · 어워즈 1위 · 2022 글로우픽 1위), **일소 세범 소프트너 3개**(2025 올영 어워즈 MD'S PICK · 화해 1위 ×2).
→ 조달비 대비 시각 점유율이 가장 큰 장치.

## 5. 속모증 이식 판정

| 재료 | 속모증에 맞나 | 판정 |
|---|---|---|
| **수치 USP** | 쏙모팩이 통째로 비운 칸. *"모공당 함입 연모 −○개"* | **★★★ 최우선** |
| **핀란드 세계관 조어**(토르홉) | 사우나=모공 연다 base와 결합 | **★★★** |
| **도구 증정** | 스패츌러·브러쉬 = 필오프와 결이 맞음 | **★★★** |
| **어워드 배지** | 조달비 대비 효율 최상 | ★★ (시간 필요) |
| **제형을 음식으로**(떡·머랭) | 필오프는 굳는 제형이라 **떡·젤리 질감 연출 가능** | **★★★** |
| **시술을 이미지로**(주사기) | 레이저 제모를 **그림으로** 거는 방법 — 기전 이식 없이 시각만 | **★★** |
| **2단계 구성**(일소·라운드랩) | 우리 온열 프리스텝 + 필오프와 동형 | **★★★** |
| **base 원물 사진** | 자작나무·소금·소나무 | ★★ |
| **인물 PICK** | 우월 집단 | ★ |
| EGF·PDRN | 재생 소구라 제거 결핍과 결이 안 맞음 | ✕ |

### 🔴 이번 실측의 최대 수확 3개

1. **수치 USP가 이 카테고리의 기본값이다** — 147%·99%·49.7%·54%·-53%… **쏙모팩만 없다.** 인체적용시험 수치 하나가 곧 격차가 된다.
2. **"시술을 이미지로 거는" 문법이 존재한다**(샤이샤이샤이 주사기). 레이저 제모의 기전 이식이 불가능해도 **비주얼로는 걸 수 있다.**
3. **제형을 음식처럼 보이게 하면 단가가 올라간다** — 논리 없이 외형만으로. 필오프도 **떡·젤리 질감**으로 연출 가능하다.
