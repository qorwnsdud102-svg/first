# 쏘모우카 상페 설계 — 떡솝 문법의 핀란드 변환

> **원본**: 아렌시아 떡솝 비밀링크 상페 (이미지 33장 + GIF 11종 전량 판독, 2026-08-26)
> **과제**(사장님): *"떡같은 쫀득한 제형, 방아찧는 상페 gif 등이 전통의 상징성이 느껴지면서, 쫀득한 느낌이 털도 잘 뽑아줄것같은 느낌을 줌 — 이걸 필란드식으로 바꿔봐"*

## 1. 떡솝 상페 해부 (실측)

### 1-1. 블록 순서 (위→아래)

```
①  희소 오프닝     "이 페이지를 나가면 비밀 특가가 사라집니다" (빨강 풀배너)
②  환불 보장       "효과 없다면? 불만족 시 100% 무료 환불 보장" + 1회 사용 B/A + 14일 조건
③  후기 말풍선 3개  제품 접사 배경 위 채팅버블
④  문제 제기       코 모공 접사 (손가락으로 누르는 컷)
⑤  공정 서사       "170시간의 공정, 1,000번 넘게 치대어 완성한 프레시 포뮬라"
                  + 🔴 GIF: 절구에 가루 재료 붓기 → 절굿공이로 치대기 (방아 의식)
⑥  권위           "서울 대학교 박사 출신 연구원 개발 참여" + "강남피부과 화제의 품절템"
                  (피부과 기기 옆 제품 실사 3컷 GIF) + "프랑스 에스테틱 품절템" + "올영 클렌징 1등"
⑦  개명 선언       "대한민국을 뒤흔든 화제의 1등 국.민.떡.솝" (크림 웨이브 접사)
⑧  판매 권위       "5,000,000개 판매 돌파" + 품절대란 + 1위 3관왕 배지
⑨  🔴 정체성 선언   "피부가 기억하는 쫀득한 클렌징, 아렌시아 떡솝
                  — 떡처럼 쫀득한 제형이 노폐물을 말끔하게! 자연유래 성분으로 순하고 강력한 클렌징"
                  + 🔴 GIF: 손가락으로 크림을 떡처럼 쭉— 늘어뜨리는 텍스처 시연
⑩  기전 금지형     "억지로 짜지 마세요. 모공 속 피지만 끌어당겨 부드럽게 비워냅니다"
                  + 논문 스캔 3장 + 카올린 다공성 설명 + "*원료적 특성에 한함"
⑪  POINT 01       "모공은 비우고, 피부결은 매끈하게" + 수치 카운트업 GIF (00.00%→32.65/48.09/9.28%)
⑫  성분 라벨링     스푼 위 제형 접사에 지시선 — 카올린 · 쌀가루 · 녹차추출물
⑬  POINT 02       진정 성분 (병풀 · 티트리 · 사철쑥가루)
⑭  POINT 03       보습 (글리세린 · 무화과 · 바오밥 · 귀리커넬)
⑮  진정 B/A       붉은기 개선 (임상기관·기간·인원 각주)
⑯  HOW TO USE     2모드 — 데일리 클렌저 / 클렌징 팩(1~2분)
⑰  가격 4단        풀케어 46,000(60%) → 밸런싱 39,000 → 딥클렌징 29,900 → 단품 19,550(15%)
```

### 1-2. 문법 8개 (추출)

| # | 문법 | 실물 |
|---|---|---|

| 2 | 🔴 **전통 제조 의식 GIF** | 절구 + 절굿공이 치대기 — 공장이 아니라 **손과 도구의 의식**으로 연출 |

| 5 | **개명** | "국민떡솝" — 질감을 이름으로 |

## 2. 핀란드 변환 — 블록별 매핑

### 2-1. 핵심 치환표

| 떡솝 | → 쏘모우카 |
|---|---|
| 떡처럼 쫀득한 제형 | 🔴 **쫀득 블록 3층** — 중세 베이커리 무드 + "찹쌀의 쫀쫀한 찰기" + 늘어나는 GIF (2026-08-26 확정) |
| 절구·절굿공이 치대기 GIF | 🔴 **① 비흐타 묶기**(자작 가지 다발을 손으로 묶는 전통 수공) **② 자작 수액 채취**(나무에 관, 수액 방울) **③ 뢰일리**(달군 돌에 물 한 국자 → 김 확—) |
| 국민떡솝 | 별명 미정 — 「쏘모우카 쫀득 사우나팩」 제안 (판정 대기) |
| 170시간·1,000번 | 공정 수치 — ⚠️ OEM 확정 후 (예: 자작 수액은 1년에 초봄 몇 주만 채취 — 사실 확인 후 사용) |
| 카올린·쌀가루·녹차 라벨 | **자일리톨 · 자작나무 수액 · BHA · 나이아신아마이드** 라벨 |
| 병풀·티트리·사철쑥 | **자작나무 수액 · 어성초** (쏙모팩 회피 성분) |
| 서울대 박사·강남피부과 | 저자극 인체적용시험 + 자극도 스케일 도표 (권위는 인증으로 대체) |
| 2모드 (클렌저/팩) | **2모드 — 코 스팟 20분 / 풀존(코·나비존·미간) 20분** + 등·바디 확장 |
| 붉은기 진정 B/A | **떼어낸 필름 접사** (털 육안 KPI) |

### 2-2. 변환 상페 (블록별 카피 초안)

```
①  희소 오프닝     (동일 문법) "이 페이지를 나가면 런칭 특가가 사라집니다"
②  환불 보장       "떼어보고 털이 안 보이면, 100% 환불합니다"
                  ← 우리는 판정이 14일도 필요 없다. 첫 사용 20분이면 끝 — 떡솝보다 강한 보장
③  후기 말풍선     (런칭 후 실후기로. 초기엔 생략 또는 체험단)
④  문제 제기       "블랙헤드가 아니라, 모공에 박힌 털입니다" + 확대 접사
                  "확대해서 보세요. 피지는 안 보이지만 털은 보입니다"
⑤  🔴 의식 GIF 3종  (절구 자리)
                  a. 자작나무 숲 — 가지를 묶어 비흐타를 만드는 손
                  b. 수액 채취 — 자작나무에서 수액이 떨어지는 접사
                  c. 사우나 뢰일리 — 달군 돌에 물 붓자 김이 확— 오르는 컷
                  카피: "핀란드 사람들은 데운 다음에 시작합니다"
⑥  정체성 선언     "핀란드 온열 사우나 팩, 쏘모우카" (핀란드 먼저 선언)
⑥-b 🔴 쫀득 블록    [2026-08-26 확정 — 3층 분리]
                  a. 무드 비주얼: 유럽 중세 베이커리 (목판화·화덕·런던베이글뮤지엄 톤)
                  b. 카피: "찹쌀의 놀랍도록 쫀쫀한 찰기" — 떡·한국 언급 0회
                  c. 실물: 내용물을 손으로 만지면 쭉쭉— 늘어나는 텍스처 GIF (떡솝 ⑨ 등가)
                  보조(선택): "지금 유럽 파티스리는 쫀득에 빠졌습니다 — 스위트 라이스" 트렌드 한 줄
⑦  기전 금지형     "핀셋으로 파지 마세요. 그 털은 짜서도, 파서도 안 나옵니다"
                  → 3단 원리: 사우나 열기가 모공을 열고 → 쫀득한 제형이 틈으로 스며 털을 감싸고
                  → 굳은 한 장이 끊기지 않고 통째로 데리고 나옵니다
                  (동사 규율: 녹인다·불린다 금지 / 연다·감싼다·데리고 나온다)
⑧  POINT 01 온열   "바르면 따뜻해집니다 — 열렸다는 신호예요" (사우나 세계관 비주얼)
    POINT 02 쫀득   "늘어나되 끊어지지 않아야, 끝까지 뽑습니다" (텍스처 접사)
    POINT 03 진정   "떼어낸 순간이 얼음 호수입니다" (아반토) — 자작 수액 · 어성초 · 나이아신
⑨  성분 라벨링     스푼 접사 + 지시선: 찹쌀추출물("쫀득의 원료") · 자작나무 수액 · BHA · 나이아신아마이드
⑩  수치            "효능 아닌 수치"만 — 도포 후 표면온도 +○.○℃ · 떼어낸 팩에서 관찰된 털 ○○개 ·
                  박리 필름 무게 시연 (⚠️ 전부 실측 후)
⑪  저자극          인체적용시험 + 자극도 스케일 도표 (오브제 문법) + "살은 안 잡습니다. 털만 잡습니다"
⑫  필오프 방어     4세대론 — "찬 피부에서 억지로 뜯는 것과, 열어서 잡은 뒤 떼는 것은 다릅니다"
⑬  HOW TO USE     코 스팟 / 풀존 2모드 + "아끼지 말고 도톰하게. 그래서 100g입니다"
⑭  가격 4단        (떡솝 구조 재사용) 풀케어 세트 → 1+1 → 단품 35,900
```

### 2-3. 제작 과제 (신규)

| 1 | 🔴 **텍스처가 진짜여야 한다** — "쭉쭉 늘어나는 고점탄성 + 20~30분 후 필름 경화"가 한 제형에서 성립하는지 **바이오시엠 확인이 최우선** (쫀득 블록 전체가 질감 실물 위에 서 있음) |
| 2 | 의식 GIF 소스 — 비흐타·수액·뢰일리 촬영 or 스톡. 절구 GIF의 등가 퀄리티 필요 |
| 3 | 공정 수치 — OEM 공정에서 사실 기반으로 추출 (숙성 시간·배합 횟수 등). 창작 금지 |
| 4 | 쫀득 블록용 중세 베이커리 비주얼 소싱 — 목판화·화덕 톤 (런던베이글뮤지엄 레퍼런스) |
| 5 | 찹쌀추출물 배합 + 자일리톨 습윤성 상한 (기존 질문 유지) |

## 3. 떡솝에서 가져오지 않는 것

| ✕ 서울대 박사·강남피부과 | 조달 불가 + 우리는 인증(저자극)으로 대체 |
| ✕ "국민" 접두 | 후발이라 거짓 |
| ✕ 5,000,000개·1위 3관왕 | 진입 시점 불가 |
| ✕ 00.00% 카운트업 효능 수치 | 털 인출은 실증 항목 부재 — "효능 아닌 수치"로 대체 |
| ✕ 프랑스 에스테틱 | 세계관 충돌 (핀란드 단일) |
