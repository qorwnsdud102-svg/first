# 쏙모팩(SSOKMO) 실측 — 속모증 카테고리 선점자

> **실측일** 2026-08-24 · ssokmo.com 상세페이지 전량(이미지 20장 / 73,681px) + **메타 영상 소재 4편**(프레임 118컷 + 음성 전사)
> **판정 도구**: [[DA 제품 소싱 기준]] 8개사 실측 문법 · [[DA 기획 판정 룰]] 14관문
> **결론 한 줄**: **상징재가 없다. 상징재 대신 "결핍 개명"으로 카테고리를 통째로 소유했다.**

---

## 0. 사장님 가설 검증

> *"내가 봤을 때는 별거 없어. 어떤 상징재, 후킹 이런 것보다는 — 코팩은 많아도 속모증 제품이 없고 마케팅도 안 하다 보니까, 그냥 코팩 가지고 속모증 털 빼는 거밖에 없는데 후킹 잘돼서 잘 팔리는 느낌이야."*

**맞다. 다만 "별거 없다"가 아니라 "한 가지를 극단적으로 잘한다"에 가깝다.**

| 사장님 관찰 | 실측 결과 |
|---|---|
| 상징재가 없다 | **✅ 정확.** 시술·의약품 상징원 슬롯이 **비어 있음** (아래 §3) |
| 그냥 코팩이다 | **✅ 정확.** 필오프 블랙 코팩 50ml 단품 하나. 2단도 도구 동봉도 없음 |
| 속모증 제품이 없어서 | **✅ 정확.** 카테고리 자체를 새로 만들고 **상표까지 선점** |
| 후킹이 잘돼서 잘 팔린다 | **✅ 정확.** 후킹 = **결핍 개명 한 문장** + **①제거형 BNA 최강** |

## 1. 실측 숫자

| 항목 | 값 |
|---|---|
| 제품 | `[공식몰] 쏙모팩 속모 코팩 SSOKMO` · 필오프 젤 **50ml** |
| 가격 | 69,000 → **39,900** (42%↓) |
| 세트 | **3단** — 단품 39,900 / **🥇BEST 2+1 = 3개 79,800**(개당 26,600) / 최대할인 6개 144,900(개당 24,150, 40%↓) |
| 리뷰 | **5,732건** (별점 4.9 · 포토/영상 327) |
| Q&A | **2,190건** |
| 실시간 | *"오늘 194명이 구매했어요"* |
| 품절 서사 | **1~13차 완판 + 17차 소량 입고** + *"특허 원료 수급이 어려워 이후 생산일 미정"* |
| 브랜드 검색량 | **쏙모팩 27,740/월** (26-06) · 여성 92.8% · **20대 44.1% / 30대 29.2%** |
| 연관 검색 | 쏙모팩 내돈내산 2,320 · **소극성 속모증 팩 1,230** · 쏙모팩 올리브영 170 · 쏙모팩 남성용 20 |

> 🔴 **가장 중요한 숫자**: **브랜드(27,740) > 결핍 본명(속모증 6,900)의 4배.**
> 결핍보다 브랜드가 커졌다 = **카테고리를 완전히 소유했다.** [[상징재]] "온라인의 상징재 = 상위노출·많이 팔린 것"이 이제 **자기 자신**이 됐다.

## 2. USP — 상페가 파는 것

상단 4줄 뱃지가 USP 전부다.

| # | 뱃지 | 정체 | 조달 비용 |
|---|---|---|---|
| 1 | **국내 유일 속모 상표 보유** | **상표 선점 = 카테고리 소유권 주장** ★핵심 | 출원비 |
| 2 | **국내 특허 성분 포렉셀™** | **자작 성분 브랜드** (비누풀·멜리사·편백수·세라마이드NP 4종 복합) | 배합 + 출원 |
| 3 | 전문기관 저자극 인증 | 제3자 문서 권위 | 낮음 |
| 4 | 재구매 의사 **97%** | 자체 설문 수치 | 0 |

+ 상페 중반 **`No.1 쏙모팩 SSOKMO — "유명한 제품은 그 이유가 있습니다"`** (자기 권위 선언)
+ **약국/피부과 입점 안내** — *"최근 주문량 급증으로 당분간 입점이 어렵습니다"* → **채널 권위 + 품절 서사를 한 장에 합침**
+ **7일 무료 체험** — *"정말 나한테 효과가 있을까? 먼저 써보고 결정하세요!"*

## 3. 🔴 상징재 판정 — 슬롯이 비어 있다

[[DA 기획 판정 룰]] §0 기획의 3슬롯에 대입:

| 슬롯 | 표준(써모드·히토·한의비책) | **쏙모팩** |
|---|---|---|
| **결핍** | 주름 / 관절통 | **속모증(모공에 박힌 털)** ✅ |
| **상징원** | 써마지 / 연골주사 / 뜸 | **없음** ❌ |
| **당위성 장치** | 미세열감 / PDRN / 네오디뮴 | 필오프 접착 + 포렉셀™ △ |

**레이저 제모는 상징원으로 안 쓰인다.** 소재 v18에 등장하지만 역할이 다르다.

> *"이걸 레이저 받아야 한대요 → **100만원 나왔어요** → 그치만 나 텅장인데요? → 상담만 받고 집 왔어요"*

→ 레이저 제모는 **"우리가 그 원리를 옮겨온 상위 해결책"**(써모드가 써마지를 쓴 방식)이 아니라 **단순 가격 공포 장치**다.
→ [[DA 기획 판정 룰]] ⓪ 마스터 원칙의 *"하고 싶지만 못하는 것"*을 **상징 이식 없이 좌절 서사로만** 소비한다. 기전 재현(§2)을 아예 시도하지 않는다.

### 그 빈자리를 채운 것 = 결핍 개명

상페 논증 순서가 그대로 답이다.

```
① 문제 환기  "진짜 문제를 몰랐던 결과, 이것저것 시도해봐도 더 도드라지는 모공…"
② 적 지정    "그동안 피지, 블랙헤드인 줄 알고 / 녹이고 짜고 떼어내도"
③ 원인 재정의 "속모는 블랙헤드가 아닌 [모공에 박힌 털]이라는 것"
④ 적 처형    "녹이고 짜도 떼어내도 효과가 없었던 이유? → 털이기 때문에!"
⑤ 유일 해법  "이젠, 쏙모팩"
⑥ 증거       팩에 박힌 털 다발 9컷 그리드 → "단 1회 사용만으로 해결한 피부 고민"
⑦ 권위       상표·특허·인증·재구매 97% → No.1
⑧ 리스크 제거 7일 무료 체험 · 100% 환불
```

**②~④가 [[적 프레임]] 교과서다.** 경쟁 브랜드를 한 번도 안 때리고 **고객이 이미 하던 행동 전체**(녹이기·짜기·떼기)를 한 문장으로 무효화한다. [[한의비책]]의 *"물리치료·파스·스트레칭으로는 어혈을 해결할 수 없기에"*와 완전 동형.

### v17 (30초) · 대인관계 수치심형

*"이게 다 코에서 나온 거라고?"* → *"가까이서 얘기할 때 코만 보일까 봐 신경 쓰이는 사람?"* → *"가리려고 화장 두껍게 할수록 뜨고 지저분해져서 계속 건드리게 되는데"* → **"제발 피부 그만 망쳐!"**
→ **"블랙헤드 없으려고 안 해본 거 없는데"** ← **경쟁 제품 실물 무더기 컷**(CNP·POINT 블랙헤드 필오프팩·isoi·3 years old 블랙파 등)
→ **"알고 보니 내 코에 있는 건 피지가 아니라 털이었음"** (원형 확대 렌즈 오버레이)
→ **"피지가 아니니까 녹여서 안 됐던 거고 / 뽑아줘야 정리되는 건데"** ← **기전 재정의 정면 문장**
→ *"떼면 잔털까지 싹 같이 뽑혀나옴 / 쓸 때마다 이만큼씩 나오는데 / 안 할 수가 없지"*

### v15 (38초) · **등·남편 확장 라인** (아내 화자)

*"아니 오빠, 등에 이게 뭐야? 때 낀 거야?"* → *"저희 남편만 이런가요?"* → *"블랙헤드인가 싶었는데 자세히 보니 뾰족하게 뭐가 박혀있는 거 있죠?"* → 핀셋으로 뽑아 흰 천에 모음 → **네이버 "남자 등 털" 실검색 화면 삽입** → *"모공 안에 털이 엉켜있는 거라고 하더라고요"* → *"헐 잠깐만… 미쳤다… 진짜 많이 나왔어"* → **빨간 점선 BNA 비교** → *"저 남편 등이 이렇게 매끈한 거 결혼하고 처음 봐요"*

> 📌 **네이버 실검색 화면 삽입** = [[DA 제품 소싱 기준]] §5-2 *"검색창에 검색해 보세요"*(미녹산정)와 같은 **외부 검증 유도** 장치. 자발적으로 납득했다는 착시.

자막·음성 없음. **모공 접사 → 도포 → 떼기 → 팩에 박힌 털** 만으로 구성. 소재 톤 스펙트럼의 반대 끝(감정 0, 증거 100).

## 5. 이 제품이 잘 팔리는 진짜 이유 4가지

| # | 이유 | 위키 대응 |
|---|---|---|
| 1 | **자각이 0인 결핍** — 타겟은 문제의 이름을 모르고 10년째 오진 상태 | [[자각]] · [[DA 제품 소싱 기준]] §7 *"DA는 수요를 만들어낸다"* · *"검색량 0에 가까운 결핍이 오히려 DA 최적"* |
| 2 | **BNA ①제거형 최강** — 팩에 박힌 털 다발이 곧 증거. 창조할 필요가 없다 | §2 게이트1 *"제거재 = DA 적합 최상"* |
| 3 | **적 프레임이 완벽** — 코팩·압출·필오프 전부를 "털이니까"로 한 번에 무효화, 반격 주체 0 | [[적 프레임]] |
| 4 | **개명이 곧 독점** — 새 이름을 지었더니 그 이름의 유일한 제품이 됨 (+상표 선점) | [[가치더하기]] · 미개척 |

**후킹의 정체는 상징재가 아니라 "오진 교정"이다.** 소비자가 *"어? 그럼 내가 10년 헛짓한 거야?"* 하는 순간이 곧 전환이다.

## 6. 🔴 우리 기획에 대한 판정 — 정면 진입은 반려

`DA-속모증-상징재-기획.md`에서 **참신성 미검증**을 최대 리스크로 걸어뒀는데, **실측으로 확정됐다.**

| 우리가 설계한 것 | 쏙모팩 현황 | 판정 |
|---|---|---|
| *"블랙헤드가 아니라 털입니다"* 원인 규명 후킹 | **동일 문장을 상페·소재 전부에서 사용 중** | **선점** ❌ |
| 레이저 제모 가격 정면 비교 | v18이 피부과 가격표 실물로 이미 함 | **선점** ❌ |
| 팩에 박힌 털 = ①제거형 BNA | 9컷 그리드로 상페 중앙 배치 | **선점** ❌ |
| "녹여서 안 되고 뽑아야 한다" 기전 재정의 | v17 음성에 그대로 있음 | **선점** ❌ |
| 등·어깨 확장 | 소재(v15)는 돌리는데 **제품은 코 튜브 하나** | **빈칸** ⚠️ |
| 남성 직접 타겟 | 검색 성별 **여성 92.8%**, 남성용 검색 20 | **빈칸** ⚠️ |
| 2단 키트(용해→인출) | **1단 필오프만** | **빈칸** ⚠️ |
| 확대경 동봉 진단 | 없음 | **빈칸** ⚠️ |

> [[DA 기획 판정 룰]] §7: *"이미 남들이 하는 문법은 반려"* — **코 정면 진입은 이 조항에 정확히 걸린다.**
> 리뷰 5,732 · 브랜드 검색 27,740의 선점자를 같은 문법으로 뒤에서 치는 건 [[상징재]] §근육돌이 *"업계 1위 전략은 완성된 브랜드의 전략"*에도 어긋난다.

### 남은 진입로 3개 (실측 근거 있음)

1. **등·바디 전용** — 고객이 직접 요구 중.
   > 실제 리뷰: *"등에 효과 개쩌네요. 다들 코에 쓰시는 것 같은데 전 ★등★에 썼음요 … **바를 때 주걱 같은 걸로 바르면 더 쉽습니다. 이런 걸 설명서에 넣어주면 더 좋지 않을까요 담당자님?!!?**"*
   → 50ml 코 튜브로 등을 바르는 건 **용량·도포도구·리치가 전부 안 맞는다.** 대용량 + 롱리치 어플리케이터 + 등 전용 시트 = 제품 갭.
   → **부위를 바꾸면 규제도 풀린다**: 치오글리콜산계 제모 성분은 얼굴 사용이 금지지만 **등·팔·다리는 가능** *(위키에 없음 — 일반 지식, 식약처 고시 확인 필요)*. 즉 **등에서는 "진짜 제모 기전"을 쓸 수 있어 레이저 제모 상징이 100% 이식된다.**
2. **남성 직접 타겟** — 쏙모팩 타겟은 여성(20~30대), 남성 소재도 **아내 화자**다. 남성 본인 그루밍 프레임은 비어 있음.
3. **진단 도구 동봉(확대경)** — 아무도 안 함. [[자각]] 생성을 소재가 아니라 **제품 안에** 넣는 방식.
