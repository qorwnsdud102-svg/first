# 메타 대시보드

## 한 줄 정의

메타 광고 성과(10분마다)와 판매 채널 매출(카페24 자사몰 2곳·네이버·쿠팡·문자주문 시트)을 한곳에 모아, 초보 마케터가 **「지출한 만큼 팔리고 있나」**를 한 화면에서 보게 하는 로컬 웹 도구. 2026-09-22~23 이틀 동안 Claude 세션 3개(화면·수집·마진율)가 나눠 만들고, 23일 밤부터 한 세션이 이어받았다.

- **2026-09-24 운영 PC 가동** — 아래 「운영 PC 가동」 절. 개발 PC 수집은 꺼 두었다.
- 저장소 `C:\claude\메타 관리프로그램`, 브랜치 `feat/skeleton-and-probe`. 테스트 `pytest -W error` 649개(2026-09-24).
- 화면 6개: 현황 · 소재 · 확인 필요 · 매출 · 내역 · 설정. 형제 도구(8004 부스터·8005 댓글 관리)와 같은 겉모양([[형제-도구-화면-공통규칙]]).

## 대표 결정(2026-09-23, 바뀌면 여기 갱신)

- 메타 지표 이름은 광고관리자 낱말 그대로, 우리 숫자는 우리 말(순매출·ROAS·광고 후 이익). 「MER」「속보」 같은 설명 못 하는 말은 뺀다. ROAS는 모두 %.
- 광고용 영상·이미지 = 「소재」. 소재 이름은 광고관리자 그대로.
- 쿠팡 윙 정산 비용·하온 공통 비용은 메타 대시보드가 아니라 **성과측정 대시보드(회사 전체 순익) 몫** — 코드·데이터(1,927파일·134,769줄)는 남겨 두고 메타에선 끔.
- 외주 영상 제작비(운영 시트 구분 DA)는 **이익에서 빼지 않고** 현황 카드 「외주 제작비 · 이번 달」로 나란히.
- 거부·문제 광고는 거르지 않고 전부 보이되 **경고는 켜진 소재만**, 꺼진 옛 것은 접어 둔다.
- 수집은 PC 한 대에서만(카페24 refresh 토큰 회전). 운영 PC 이관은 대표가 이 PC에서 검증을 끝낸 뒤.
- (2026-09-24) 히토 재고를 확인 필요 옆에. 로켓그로스는 API 우선, 하온 입력은 설정에서. 1세트 = 1개. 품절 예상은 **7일 평균 유지** — 추석에 광고비를 낮춰 판매가 준 건 일시적이고, 경고는 비관적인 쪽이 안전.
- (2026-09-24) 외주 제작비 시트는 「구분 DA」 + 따로 「제품」 칸(DA 제품이 늘 것 대비). 제품이 다른 줄(써모드)은 히토 비용에서 뺀다. 써모드 비용을 따로 보이게 하는 건 첫 줄이 생길 때.

## 만들며 겪은 함정

- 앱 안 브라우저 창이 가려지면 캡처가 시간 초과 → 「소재 탭이 멈춘다」 오진. 그리기 확인은 헤드리스 엣지(Playwright `channel="msedge"`).
- 셸 heredoc 안 파이썬에서 `\\v`·`\\b`가 제어 문자로 바뀌어 파일·경로가 깨짐 → 백슬래시가 있으면 스크립트 파일로.
- DB 판을 올린 뒤 옛 코드로 켜 둔 수집 창·서버 창이 새 DB를 거부 → 코드 바꾸면 창을 다시 켠다(DbTooNew).
- 운영 시트 탭 이름은 그대로인데 내용 양식이 바뀜(가로형 마진표) → 이름으로 탭을 찾고 **고정 열 번호**로 읽는 코드는 오류 없이 틀린 값을 읽는다([[네이버-SA-성과측정-툴]]이 이 위험에 있다).
- 광고관리자 「후크 비율·지속 비율」은 API 필드로 재현이 안 됐다 → 우리 식(3초 재생률·ThruPlay율)으로 이름을 바꿔 보였다.
- 외주 제작비 시트 구분이 「DA」 → 「DA, 히토」 → 「DA」 + 제품 칸으로 하루에 두 번 바뀌었다. 「정확히 DA」만 찾던 코드가 0줄을 읽었지만 **경고 + 이전 값 유지**라 화면 숫자는 안 틀렸다 → [[시트-칸-골라읽기]] §양식이 바뀔 때.
- 하온 재고 차감을 「16시 뒤 결제분」으로 어림했다가 연휴·목록 시각 오차로 두 번 고쳤다 → 주문별 배송 상태([[재고-품절-예측]]).
- 광고 한 줄의 `recommendations`는 비어 온다 — 광고관리자 「행동(권장 사항)」은 계정 `act_x/recommendations`에서 캠페인·세트 id로 맞춘다.
- Git Bash의 `sed -i`가 CRLF 파일의 줄 끝을 LF로 바꿔 버렸다 → 고친 뒤 바이트로 `\r\n` 개수를 세어 확인하고 되돌린다(`grep -c $'\r$'`는 Git Bash에서 0으로 나와 믿을 수 없었다).
- 테스트 데이터의 광고 이름을 실제 규칙(`Y26_W37_온천크림_OS_…`, 만든 사람 칸 포함)과 다르게 쓰면 제품이 안 매겨져 「광고비 0」으로 실패한다 — 실패 원인을 코드에서 찾다가 한 번 잘못 고쳤다(광고 쪽 제품 칸이 키인지 낱말인지 착각). **가짜 데이터부터 실제 모양인지 의심한다.**
- 운영 PC 업데이트 안내문(파이썬 문자열 속 Windows 경로)을 셸 heredoc으로 넘기자 `\b`가 백스페이스로 들어갔다 — 경로가 든 스크립트는 파일로 만들고 r-문자열 + 제어 문자 검사. 이미 보낸 업데이트 7 안내문도 깨져 있었다.
- 개발 PC 도구 셸에서 하위 프로세스를 띄우는 잠금 시험이 코드 변경 없이도 가끔 `WinError 6`(Popen 핸들)으로 떨어졌다. 운영 PC에선 매번 통과 → 이번 변경을 뺀 상태(`git stash`)로도 떨어지는지 먼저 확인해 **환경 문제와 회귀를 가른다.**
