# 매대 비율 표시 지시문 (⑤ 참신함, 정본 ⑤-02)

흔한 상징인지는 광고 수로 보지 않는다. 같은 결핍 메인 키워드로 메타에서 팔리는 제품들 가운데 그 상징·외형을 쓰는 제품의 비율로 본다(사장님 예: 오십견 파스·크림 10개 중 동전파스 외형이 3개면 진부, P6227).

## 준비

```bash
cd "$CF" && python scrape_meta.py --title "<이름>" --keywords "<결핍 메인 키워드들>" --first-screen --no-variants --pause 20
cd "$DP/scripts" && python shelf_share.py build "$CF/<이름>_메타광고소재" --keywords "<같은 키워드들>" --out "<매대 폴더>" --frames --asr
```

- `--frames`: 영상은 앞(0.5~18.5초)·뒤 6장면 모아보기로 만든다.
- `--asr`: 영상 음성을 받아쓴다. 이 PC 안에서 하며 밖으로 보내지 않는다(사장님 2026-10-11 "전체 이미지, 음성 분석은 못하는지?" P6237).
- `<매대 폴더>/보기/`만 표시 에이전트에게 준다. 폴더 이름에는 상징 이름을 넣지 않는다.

## 표시 에이전트 (Explore 1개, Opus 5.5 effort max)

{DIR} = `<매대 폴더>\보기`, {SYMBOL} = 찾는 상징, {TERMS} = 글자로 찾을 말, {LOOK} = 사진으로 볼 외형(없으면 '없음').

```
너는 메타 광고에 나온 제품 목록을 보고 표시만 하는 사람이다. 제품을 평가하지 않는다.
읽을 파일: 폴더 {DIR} 안의 매대.md와, 매대.md에 적힌 그림 파일들. 이것만 Read 도구로 읽는다. 다른 폴더·파일·Grep·Glob·Bash·PowerShell·웹은 쓰지 않는다.
찾는 상징: {SYMBOL}. 글자로는 {TERMS}. 외형으로는 {LOOK}.
그림은 제품마다 여러 장일 수 있다(영상은 앞·뒤 장면 6개씩 모아보기). '음성' 줄이 있으면 광고에서 들린 말이다.
제품마다 하나를 고른다.
- 예: 광고 문구·제목·음성에 그 말이나 같은 뜻의 말이 나오거나, 그림에서 그 외형이 보인다.
- 아니오: 글·음성·그림을 다 봤는데 없다.
- 모름: 그림도 음성도 없고 글로도 알 수 없다.
- 병원: 파는 물건이 아니다 — 병원·의원·시술·센터·교육·서비스 광고(2026-10-11 관절 매대에 물리치료 센터·자격증 과정이 섞임).
출력(이 표만, 제품 수만큼): | 제품 | 표시 | 근거 한 줄(문구·음성 일부 또는 그림에서 본 것) |
```

## 셈

```bash
python shelf_share.py score "<매대 폴더>" "<표시 답.md>" --symbol "<상징>"
```

- 30% 이상이면 '진부'다. 이 줄은 ⑤ 경고로 `## 사장님 판단 칸`에 올린다.
- 출력 절은 `5-참신함.md`에 그대로 붙인다(쓰는 제품·시작 달·먼저 쓴 곳 포함).
- 기준(30%)은 사장님 예에서 시작했다. 이미 판정하신 사례로 다시 재서 고친다(`자가학습/시험/매대-v1/`).
