# 남이 검사 지시문 (④ 상징·당위, 정본 ④-57)

상징 테스트 4종은 작성자가 아닌 Claude가 돌린다. 작성자의 자기 채점은 참고로만 둔다. 에이전트는 Explore로 띄운다(Opus 5.5, effort max). 각 에이전트는 서로 모르게 띄운다. 끝나면 `agent_audit.py --allow <샌드박스>`로 샌드박스 밖을 읽었는지 본다.

## 준비

```bash
cd "$DP/scripts" && python blind_symbol.py prep "<기획서.md>" --terms "<상징원 이름>,<별칭>,<이름을 떠올리게 하는 제품명 조각>" --out "<샌드박스>" --full "<샌드박스>-전체"
```

- `--terms`에는 상징원 이름·영문·흔한 오기와 제품명 가운데 상징원을 떠올리게 하는 조각(예: 울쎄업의 '울쎄', '300샷')을 넣는다.
- 제품 설계 자체(정량 펌프의 '샷', 빨간 밤)는 가리지 않는다. 그것이 상징을 떠올리게 하는지가 이 시험의 물음이다.
- 이름이 남거나 절이 비면 prep이 멈춘다. 그러면 `--terms`나 `--scene`·`--desc`를 고친다.
- **샌드박스 폴더 이름은 무작위 코드로 한다**(예: `blind/Q4M8`).
  - 판정 에이전트는 파일 경로를 본다. 2026-10-11 시험 운전에서 폴더 이름 '울쎄업'이 정답을 흘렸고, 판정자 3명이 그렇게 밝혔다.
  - 경로에 `--terms`가 보이면 prep이 멈춘다.

## ① 1초 사진·이름 지우기 (3개)

```
너는 처음 보는 제품 설명을 읽고 떠오르는 것을 말하는 사람이다. 평가하지 않는다.
이 제품을 만든 사람은 사람들이 잘 아는 무언가(시술·약·제품·장소·사람·나라·직업 등)를 떠올리게 하려고 했다. 설명에서 그 이름과 제품 이름은 ○○로 가렸다.
1) 먼저 {DIR}\장면.md 만 Read 도구로 읽고, 떠오르는 것 하나를 정한다.
2) 그다음 {DIR}\설명.md 를 읽고, 가장 그럴듯한 것 하나를 정한다.
이 두 파일 말고는 아무것도 열지 않는다. Grep·Glob·Bash·PowerShell·웹은 쓰지 않는다.
출력(이 네 줄만):
- 1초 상징원: <장면.md만 보고 떠오른 이름 하나. 없으면 없음>
- 상징원: <설명.md까지 보고 가장 그럴듯한 이름 하나>
- 옮겨 온 것: <그것의 무엇을 옮겼다고 보는지 한 줄>
- 다른 후보: <두 개까지, 없으면 —>
```

채점은 아래 명령으로 한다.

```bash
python blind_symbol.py score 답-1.md 답-2.md 답-3.md --answer "<상징원>" --aliases "<별칭>"
```

## ② 형태 역할·체험자 '그거네' (1개)

{FILE}은 `<샌드박스>-전체/상징.md`다. 목소리 비중표에 '상징원 인식' 절이 있으면 이 파일 끝에 붙여 둔다.

```
너는 다른 사람이 쓴 제품 기획을 검사하는 사람이다. 작성자의 판정은 믿지 말고 네가 본다.
읽을 파일: {FILE} — 이것만 Read 도구로 읽는다. 다른 파일·폴더·Grep·Glob·Bash·PowerShell·웹은 쓰지 않는다.
1) 형태 역할: 이 제품의 형태·부품(용기·도구·모양·제형)을 하나씩 빼 보라. 빼면 사라지는 '상징 장면'(상징원을 떠올리게 하는 장면)이 있나? 있으면 어느 부품이 어떤 장면을 맡나.
2) 체험자 '그거네': 상징원을 실제로 받아 본 사람이 이 제품을 쓰면, 핵심 느낌과 마지막 장면에서 '그거네'라고 할까? 파일에 '상징원 인식'(받아 본 사람들의 말)이 있으면 그것과 맞춰 본다.
출력(이 두 줄만):
- 형태 역할: <통과/경고> — <한 줄>
- 그거네: <통과/경고> — <한 줄>
```

## 결과를 붙이는 곳

- ①의 score 두 줄과 ②의 두 줄, 모두 네 줄을 상징 설계 메모(`4-상징설계.md` 또는 근거.md)와 기획서 `## 상징·당위`에 그대로 붙인다.
- 경고 줄은 `## 사장님 판단 칸`에도 옮긴다.
- 근거에서 경고인 것을 기획서에서 '통과'로 바꾸면 `check_plan.py` ⑦이 잡는다.
