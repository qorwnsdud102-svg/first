# 리뷰 요약·통계 요약 기준

사용자가 리뷰 요약이나 통계를 요청했을 때만 이 기준을 따른다. 파일 확인 규칙과 분석 규칙(analysis.md)은 그대로 적용한다.

## 공통 원칙

- 실제로 읽은 고유 리뷰만 센다. A 분석 범위의 "분석 리뷰 수"가 모든 통계의 분모다. 읽지 못한 행을 추정해 채우지 않는다.
- 파일에 있는 열만 집계한다. 별점·작성일·옵션·상품 열이 없으면 해당 통계는 "열 없음"으로 적고 텍스트에서 추측해 만들지 않는다.
- 코드 실행이 가능하면 코드로 집계하고 "코드로 집계"라고 적는다. 코드를 쓸 수 없으면 직접 세고 "직접 셈"이라고 적는다. 각 표의 건수 합계가 분모와 맞는지 확인하고, 맞지 않으면 차이와 이유를 적는다.
- 비율은 "읽은 N건 중 n건(x%)"으로만 쓴다. 전체 고객의 만족도·선호 비율로 표현하지 않는다. 분석 리뷰가 30건 미만이면 비율보다 건수를 앞에 두고 "표본이 작아 비율 해석에 주의"라고 한 줄 적는다.
- 통계적 유의성, 추세, 원인을 단정하지 않는다. 기간별 건수가 달라도 판매량이나 인기 변화로 해석하지 않는다.
- 여러 상품·옵션이 섞여 있으면 전체 집계와 상품·옵션별 집계를 나눈다.
- 요약에 쓰는 인용은 원문 그대로 짧게 옮기고 리뷰 ID를 붙인다. 작성자 이름·연락처는 넣지 않는다.

## 출력 형식

### S1. 리뷰 요약

- 한눈에 보기: 3~5문장. 고객이 많이 말한 내용, 엇갈린 내용, 근거가 약한 리뷰의 비중을 담는다.
- 좋았다고 말한 점: 내용 | 리뷰 수 | 근거 ID | 대표 원문 1개
- 아쉽다고 말한 점: 내용 | 리뷰 수 | 근거 ID | 대표 원문 1개
- 엇갈리는 의견: 서로 다른 경험을 말한 리뷰 ID와 차이를 한 줄로 설명한다.

좋은 점과 아쉬운 점의 건수를 맞추려고 억지로 항목을 만들지 않는다.

### S2. 통계 요약

해당 열이 있는 표만 만든다. 없는 표는 "열 없음" 한 줄로 대신한다.

1. 기본 집계: 파일 전체 행 수 / 제외 행 수(이유) / 중복 제외 수 / 분석 리뷰 수 / 미열람 범위
2. 상품·옵션별 리뷰 수: 상품·옵션 | 건수 | 비율
3. 별점 분포: 점수 | 건수 | 비율. 아래에 평균 별점(소수점 첫째 자리), 별점이 비어 있는 리뷰 수를 적는다. 평균은 별점이 있는 리뷰만으로 계산했다고 밝힌다.
4. 작성 기간: 가장 이른 날짜 ~ 가장 늦은 날짜, 월별 건수. 날짜 형식이 섞여 있으면 해석한 방식과 해석하지 못한 건수를 적는다.
5. 내용 성격: 긍정 / 불만 / 긍정·불만 함께 / 근거 약함(배송·단순 호감) | 건수 | 근거 ID. AI가 원문을 읽고 분류한 결과임을 표 위에 밝힌다. 별점과 분류가 어긋나는 리뷰(예: 별점 5점인데 불만 내용)가 있으면 ID를 따로 적는다.
6. 주제별 언급 수: 주제 | 고유 리뷰 수 | 근거 ID. 많은 순서로 최대 10개. 한 리뷰가 여러 주제에 들어가므로 합계가 분석 리뷰 수와 다를 수 있다고 표 아래에 적는다.
7. 구매 이유를 직접 밝힌 리뷰 수: 산 이유를 명시한 리뷰만 센다. 세는 기준은 아래와 같고, 표 아래에 경계 사례로 넣거나 뺀 리뷰 ID를 적는다.
   - 센다: "~해서 샀어요", "~하려고 샀어요", "~용으로 샀어요", "~라서 골랐어요"처럼 구매·선택 동사와 이유가 함께 있는 리뷰
   - 센다: "~가 필요했어요", "~를 찾다가"처럼 구매 전 필요를 밝힌 리뷰. 구매 동사가 없어도 구매 전 상황이므로 넣는다
   - 세지 않는다: "할인할 때 샀어요"처럼 시점·경로만 말한 리뷰. 단 "할인해서 샀어요"처럼 할인을 이유로 밝히면 센다
   - 세지 않는다: 사용 후 장점, 현재 쓰는 용도("~용으로 써요")

### 내보내기 전 숫자 대조

계산은 S2 표부터 확정하고, S1의 건수는 S2의 같은 주제 숫자를 옮겨 쓴다. 출력 순서는 S1 → S2 → S3 그대로 둔다. 내보내기 전에 S1 문장·S1 표·S2 표에 나온 같은 주제의 건수와 리뷰 ID가 모두 같은지 대조한다. 다르면 S2 기준으로 고친다. S1에서 주제를 S2와 다르게 묶었다면 이름을 다르게 붙이고 어떤 ID를 묶었는지 적는다.

### S3. 숫자를 읽을 때 주의할 점

1~3줄. 선정 방식(예: 최근순, 좋은 리뷰만), 표본 크기, 열 누락 등 이 숫자의 한계를 적는다.

## 하지 않는 것

- 별점 열이 없는데 원문으로 별점이나 만족도 점수를 만들지 않는다.
- AI가 분류한 "내용 성격" 비율을 만족도나 NPS로 부르지 않는다.
- 다른 상품·경쟁사·업계 평균과 비교하지 않는다. 그런 자료는 제공되지 않았다.
- 요약을 광고 문구로 바꾸지 않는다. 광고 메시지는 analysis.md의 D 단계에서만 만든다.
