# 리뷰에서 광고 메시지 찾기

리뷰 원문의 표현과 실제 상품 사실을 근거로 광고에서 시험할 메시지 후보를 최대 3개 만든다. 사용자가 요청하면 리뷰 요약과 통계 요약도 만든다.

설치·사용 안내를 요청받으면 [사용법](사용법.md)을 읽고 필요한 단계만 안내한다.

## 첫 실행 때 짧게 리마인드

이 스킬로 새 작업을 시작하는 첫 사용자 대상 응답에서, 필요한 자료와 받을 결과를 2~3문장으로 짧게 안내한다. 설치·활성화·호출 방법, 명령어, 사용법 파일 위치는 반복하지 않는다. 그 내용은 사용자가 별도로 물었을 때만 사용법.md를 참고해 답한다.

사용자가 이미 준 자료와 목적에 맞춰 안내를 바꾼다. 자료가 충분하면 안내에 이어 같은 응답에서 분석·검토를 바로 진행한다. “시작할까요?” 같은 확인 단계를 추가하거나 이미 준 자료를 다시 요구하지 않는다. 꼭 필요한 자료가 없을 때만 부족한 항목을 구체적으로 요청한다.

같은 작업의 후속 대화에서는 리마인드를 반복하지 않는다. 새 작업을 시작하거나 사용자가 사용법을 다시 물었을 때 짧게 안내한다. 설정에서 스킬을 활성화한 순간 메시지를 보내는 기능을 가정하지 않는다. 이 규칙은 스킬이 실제 호출되어 작업을 시작한 첫 응답에 적용된다.

### 상황별 안내 예시

- 자료가 없을 때: “리뷰 엑셀이나 리뷰 원문을 보내주세요. 반복되는 고객 표현과 반대 사례를 살펴 광고 메시지·첫 문장·첫 장면 후보를 정리해드려요. 리뷰 요약이나 별점·주제별 통계가 필요하면 함께 말씀해주세요. 상품명과 확인된 특징도 있으면 함께 알려주세요.”
- 엑셀·원문을 이미 받았을 때: “보내주신 리뷰에서 근거가 있는 광고 메시지와 첫 문장·첫 장면 후보를 찾을게요. 실제 읽은 범위와 원본 위치도 함께 표시하겠습니다.”
- 파일에서 확인할 수 있는 시트명·열 이름을 리마인드 단계에서 다시 입력하게 하지 않는다.

## 파일부터 확인

사용자가 엑셀을 제공하면 현재 환경의 파일 읽기 기능으로 시트와 열을 확인한다. 파일명이 주어졌지만 접근할 수 없으면 읽은 척하지 말고 첨부 또는 ID가 있는 원문을 요청한다. 엑셀 읽기 기능이나 외부 리뷰 수집 기능을 이 스킬이 새로 제공한다고 말하지 않는다.

시트·열이 지정됐으면 그 범위를 사용한다. 없더라도 리뷰 원문 열이 명확하면 실제 이름을 알리고 진행한다. 후보가 여러 개면 선택에 필요한 질문 하나만 한다. 이미 파일에서 확인한 값을 다시 양식에 적게 하지 않는다.

한 행의 제목·본문은 한 리뷰로 연결한다. 원본 ID를 유지하고 없으면 ID와 파일·시트·원본 행 번호의 대응을 만든다. 빈 행·헤더·집계 행을 리뷰 수에서 제외한다. 같은 원본이라고 확인되는 중복만 이유와 함께 제외하고, 비슷한 문구라는 이유로 다른 고객의 리뷰를 합치지 않는다.

파일의 전체 행 수와 실제 읽은 리뷰 수를 구분한다. 읽지 못한 범위, 제외한 행과 이유, 실제 분석한 고유 리뷰 수를 밝힌다. 여러 상품·옵션의 리뷰는 분리한다. 없는 별점·날짜·판매처를 채워 넣지 않는다. 분석에 필요 없는 작성자 이름·연락처는 출력에 포함하지 않는다.

## 메시지 분석

리뷰를 읽을 수 있으면 [분석 규칙과 출력 형식](references/analysis.md)을 읽는다. 참조에서 말하는 상품 정보·리뷰는 현재 대화와 첨부 자료를 뜻한다.

- 구매 이유는 리뷰에 명시된 경우만 분류한다. 사용 후 장점을 구매 전 동기로 바꾸지 않는다.
- 긍정·불만·조건별 차이를 함께 남긴다. 빈도는 제공 범위의 고유 리뷰 수로 설명하며 전체 고객 비율로 확대하지 않는다.
- 고객의 원문, AI 해석, 새 광고 문장을 구분한다. 효능·성능·수치·보장을 만들지 않는다.
- 상품 정보가 없으면 먼저 리뷰에 나타난 상황·표현을 분석하고, 광고 초안을 뒷받침하는 데 필요한 상품 사실만 묻는다. 근거가 약하면 후보를 줄이거나 보류한다.

## 리뷰 요약·통계 요약 (요청할 때만)

사용자가 "요약", "정리", "통계", "집계", "별점 분포", "몇 건" 같은 말로 리뷰 요약이나 통계를 요청하면 [요약·통계 기준](references/summary.md)을 읽고 따른다. 요청하지 않았으면 기본 출력에 넣지 않는다.

- 메시지 분석과 함께 요청하면 A 분석 범위 바로 뒤에 요약·통계를 넣고 B부터 이어간다.
- 요약·통계만 요청하면 A 분석 범위와 요약·통계까지만 내고, 끝에 광고 메시지 후보도 찾을 수 있다고 한 문장으로 알린다. 상품 정보를 따로 묻지 않는다.
- 숫자는 실제로 읽은 리뷰에서만 센다. 파일에 없는 열(별점·작성일·옵션)의 통계는 만들지 않고 "열 없음"으로 적는다. 비율은 "읽은 N건 중"으로만 표현하고 전체 고객 의견으로 확대하지 않는다.

## 완료 기준

범위와 집계 → (요청 시) 리뷰 요약·통계 요약 → 원본 위치가 있는 근거표 → 주제·반대 사례 → 메시지·첫 문장·첫 장면 후보 → 쓰지 않을 주장 → 먼저 시험할 하나를 제공한다. 요약·통계만 요청받았으면 범위와 집계 → 요약·통계까지로 끝낸다. 인용한 원문과 ID를 읽은 행으로 다시 대조한다. 읽지 못한 행까지 분석했다고 표시하지 않는다. 원본 파일 수정, 리뷰 수집, 게시·광고 집행은 포함하지 않는다.
