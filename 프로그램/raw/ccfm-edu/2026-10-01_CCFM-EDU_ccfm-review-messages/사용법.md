# 사용법 · 리뷰에서 광고 메시지 찾기

CCFM EDU · 리뷰 스킬 v1.0 · 2026-10-01
스킬을 호출해 작업을 시작하면 필요한 자료와 받을 결과를 짧게 다시 안내합니다. 자료를 이미 보냈다면 바로 분석·검토로 이어지고, 같은 작업의 후속 대화에서는 반복하지 않습니다. 설치·호출 방법은 이 문서에 두고 시작 안내에서는 반복하지 않습니다.

## 준비할 자료

한 행에 리뷰 1개가 들어 있는 엑셀(.xlsx)을 준비합니다. 리뷰 원문 열은 필요하며 ID·상품·옵션·별점·작성일은 있는 항목만 둡니다. 작성자 이름·연락처 등 불필요한 정보는 제외합니다.

## 설치 후 이렇게 요청하세요

엑셀 파일을 읽을 수 있는 대화에 파일을 첨부한 뒤 요청합니다.

```text
리뷰 분석 스킬로 첨부 엑셀에서 광고 메시지를 찾아줘.
상품명: 내 상품명
확인된 특징: 실제 확인한 내용
시트명: 알면 입력, 모르면 파일에서 확인해줘
리뷰 원문 열: 알면 입력, 모르면 파일에서 확인해줘
```

## 받을 결과

실제 읽은 파일·시트·행·리뷰 수, 원본 위치가 있는 근거표, 반복되는 주제와 반대 사례, 메시지·첫 문장·장면 후보 최대 3개를 받습니다. 요청하면 리뷰 요약과 통계 요약도 받습니다. 인용문은 원본 행과 대조하고 일부만 읽었으면 전체 고객 의견으로 확대하지 않습니다.

## 리뷰 요약·통계가 필요할 때

요청할 때만 만듭니다. 위 요청에 한 줄을 덧붙이거나 요약만 따로 요청하세요.

```text
리뷰 분석 스킬로 첨부 엑셀의 리뷰를 요약하고 통계도 정리해줘.
```

좋았다는 점·아쉬웠다는 점 요약과 함께 리뷰 수, 상품·옵션별 건수, 별점 분포와 평균, 작성 기간, 주제별 언급 수를 표로 받습니다. 파일에 없는 열(예: 별점)은 집계하지 않고 "열 없음"으로 표시합니다. 비율은 읽은 리뷰 안에서의 비율이며 전체 고객 의견이 아닙니다.

## 설치나 파일 읽기가 어려울 때

같은 ZIP의 `프롬프트대안.txt`를 사용합니다. 엑셀을 읽을 수 있는 AI에 파일을 업로드하고 프롬프트 앞부분을 채워 실행합니다. 파일을 못 읽으면 리뷰 ID와 원문을 붙여넣습니다. 파일과 같은 리뷰를 다시 중복해서 넣을 필요는 없습니다.

## Claude에 설치하는 방법

사용법을 읽으려고 ZIP을 풀어도 괜찮습니다. 설치할 때는 받은 원본 개별 ZIP을 사용합니다.

1. Claude의 Customize → Skills에서 추가(+) → Create skill → Upload a skill을 엽니다.
2. `ccfm-review-messages.zip`을 업로드하고 활성화합니다. 전체 배포 묶음 ZIP이나 사용법 파일만 올리지 않습니다.
3. 새 대화에서 위 예시처럼 요청하고 자료를 첨부합니다. 메뉴가 없다면 계정의 코드 실행·파일 생성 설정과 조직 권한을 확인하거나 프롬프트 대안을 사용합니다.

공식 안내: https://support.claude.com/en/articles/12512180-use-skills-in-claude

## Claude Code·Codex에서 설치하는 방법

ZIP을 풀어 `ccfm-review-messages` 폴더 전체를 해당 위치에 복사합니다. SKILL.md와 references를 함께 유지하세요. `~`는 본인 사용자 폴더입니다.

- Claude Code: `~/.claude/skills/ccfm-review-messages/SKILL.md`, 호출은 `/ccfm-review-messages` 뒤에 요청을 입력합니다.
- Codex: `~/.agents/skills/ccfm-review-messages/SKILL.md`, 호출은 `$ccfm-review-messages` 뒤에 요청을 입력합니다. 표시되지 않으면 새 세션이나 재시작 후 확인합니다.
- Windows 예시: `C:\Users\본인계정\.agents\skills\ccfm-review-messages\SKILL.md`. 본인계정은 실제 사용자 폴더명으로 바꾸세요.

공식 안내: https://code.claude.com/docs/en/skills

공식 안내: https://learn.chatgpt.com/docs/build-skills

## 검증 범위

검증 범위(2026-10-01): 가상 상품의 가상 리뷰 엑셀로 요약·통계만, 광고 메시지만, 둘 다, 별점 열 없는 파일 네 가지 요청을 Claude Code에서 시험했습니다. 중복·빈 행·합계 행 제외, 별점 평균, 별점 없는 파일의 "열 없음" 처리, 리뷰 속 지시문 무시를 확인했습니다. 앞서 Codex에서 첫 안내와 후속 대화 동작도 확인했습니다. Claude 웹 업로드 후 실행과 실제 판매처 리뷰 파일은 아직 확인하지 않았습니다. 메뉴와 이용 가능 여부는 계정·환경에 따라 다를 수 있습니다.
