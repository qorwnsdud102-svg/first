# 경쟁사 영상 분석 스킬 — 처음 받은 분의 사용법

CCFM EDU · 영상 스킬 v1.0 · 2026-09-22

이 스킬은 Gemini에서 경쟁사 영상을 분석하도록 안내하고, 분석 결과를 검토해 우리 상품 광고에 적용할 아이디어를 정리합니다.

기본 순서: 스킬 설치 → Claude/Codex에서 사용법 질문 → Gemini용 프롬프트 받기 → Gemini에 영상 업로드 및 분석 → 원래 대화에 결과 붙여넣기 → 검토 및 상품 적용안.

## 1. 준비하기

PC에서 받은 `ccfm-video-appeal.zip`을 저장하세요. Claude 또는 Codex 사용 환경, Gemini 계정, 분석할 경쟁사 영상 파일 1개가 필요합니다.
전체 배포 묶음 ZIP을 받았다면 먼저 풀고, 그 안의 `설치파일/ccfm-video-appeal.zip`을 찾으세요. 이 개별 ZIP을 기준으로 설명합니다.

## 2. 스킬 설치 — 사용하는 프로그램 하나만 선택

### Claude 웹

1. https://claude.ai 에 로그인합니다.
2. Customize → Skills → + → Create skill → Upload a skill을 엽니다. 언어에 따라 메뉴 이름이 다를 수 있습니다.
3. 개별 `ccfm-video-appeal.zip`을 압축을 풀지 않고 업로드합니다.
4. 스킬 목록에서 추가된 스킬을 켭니다.
5. 새 대화를 엽니다.

Skills 메뉴가 없으면 Settings → Capabilities의 코드 실행 설정을 확인하세요. 조직 계정은 관리자가 스킬 생성·업로드를 허용해야 할 수 있습니다.
ZIP을 일반 채팅창에 첨부하는 것과 스킬로 설치하는 것은 다릅니다.

### Codex — Windows

1. ZIP을 마우스 오른쪽 버튼으로 눌러 “모두 압축 풀기”를 선택합니다.
2. 압축을 푼 폴더에서 `SKILL.md`와 `references`가 바로 들어 있는 `ccfm-video-appeal` 폴더를 찾습니다.
3. 파일 탐색기 주소창에 `%USERPROFILE%`을 입력해 본인 사용자 폴더를 엽니다.
4. 그 안에 `.agents` 폴더를 만들고, 그 안에 `skills` 폴더를 만듭니다. 이미 있으면 그대로 사용합니다.
5. 2번의 폴더 전체를 `skills` 안에 복사합니다. SKILL.md만 복사하지 마세요.
6. Codex를 다시 열고 새 대화를 시작합니다.

최종 위치 예시:

```text
C:\Users\본인계정\.agents\skills\ccfm-video-appeal\SKILL.md
C:\Users\본인계정\.agents\skills\ccfm-video-appeal\references\gemini-prompt.txt
```

“본인계정”은 예시이며 실제 사용자 폴더명을 뜻합니다. `ccfm-video-appeal` 폴더가 두 번 중첩되지 않도록 확인하세요.
macOS/Linux의 Codex는 본인 홈 폴더의 `.agents/skills/ccfm-video-appeal`에 폴더 전체를 넣습니다.

### Claude Code

압축을 푼 스킬 폴더 전체를 본인 홈 폴더의 `.claude/skills/ccfm-video-appeal`에 넣습니다.
새 세션에서 `/ccfm-video-appeal 처음 쓰는데 어떻게 하면 돼?`라고 입력합니다.

## 3. 스킬부터 실행하기

Claude 또는 Codex의 새 대화에 다음 문장을 입력합니다.

```text
ccfm-video-appeal 스킬을 사용해줘. 이거 어떻게 써?
```

Codex가 스킬을 찾지 못하면 `$ccfm-video-appeal 처음 쓰는데 어떻게 하면 돼?`로 호출해 보세요. 그래도 찾지 못하면 2번의 설치 위치와 재시작 여부를 확인하세요.

정상 응답은 “Gemini에 영상 업로드” 안내, 복사할 분석 프롬프트, “결과를 이 대화에 붙여넣기” 안내를 포함합니다.

이미 이 스킬을 선택했거나 대화에서 이 스킬을 이야기하고 있다면 “이거 어떻게 써?”라고만 물어도 됩니다. 새 대화에서는 위처럼 스킬 이름을 함께 적으면 어떤 스킬인지 명확해집니다.

## 4. Gemini에서 영상 분석하기

1. https://gemini.google.com 에 로그인해 새 대화를 엽니다.
2. 경쟁사 영상 파일 1개를 첨부하고 업로드가 끝날 때까지 기다립니다.
3. Claude/Codex가 준 프롬프트를 같은 Gemini 대화에 붙여넣고 전송합니다.
4. Gemini 분석 답변을 받습니다. 영상을 읽지 못했다고 하면 첨부 상태와 계정의 파일 제한을 확인하세요.

## 5. 결과를 원래 대화로 가져오기

Gemini 답변 전체를 복사한 뒤, 스킬을 실행했던 Claude/Codex 대화로 돌아와 아래 문장과 함께 붙여넣습니다.

```text
아래는 Gemini 영상 분석 결과야. 스킬 기준으로 검토해줘.

[여기에 Gemini 답변 전체 붙여넣기]
```

우리 상품 적용안도 원하면 상품명·확인된 특징·가능한 촬영 방식을 함께 적어주세요.
상품 정보가 없더라도 경쟁사 분석 검토는 받을 수 있습니다.

AI는 경쟁사의 주장·화면·순서가 어떻게 고객을 설득하는지 분석합니다. 입증 자료가 없다는 이유로 경쟁사의 주장을 삭제하지 않고 광고가 내세우는 주장으로 다룹니다. 상품 정보가 충분하면 광고 첫 문장·첫 장면·구성 또는 시험할 아이디어와 먼저 할 작업을 제안합니다.
원본을 대조하지 않았다면 “Gemini 출력 검토, 원본 영상 미대조”라고 표시합니다.

## 공식 설치 안내

Claude: https://support.claude.com/en/articles/12512180-use-skills-in-claude

Codex: https://learn.chatgpt.com/docs/build-skills

Claude Code: https://code.claude.com/docs/en/skills

이 스킬은 Gemini 자동 실행·영상 자동 업로드를 하지 않습니다. 사용자가 Gemini에 영상을 올리고, 받은 결과를 Claude/Codex로 가져오는 방식입니다.

검증 범위(2026-09-22): Codex 첫 사용 안내와 결과 검토 동작, 실제 광고 영상의 사용자 직접 Gemini 분석 결과를 Codex로 가져와 추가 분석하는 흐름을 확인했습니다. 자동 브라우저 테스트에서는 Gemini 거절 응답도 발생했으므로 항상 성공한다고 보장하지 않습니다. Claude 웹·Claude Code 실제 실행과 초보자의 신규 설치는 미검증입니다. 메뉴와 이용 가능 여부는 계정·환경에 따라 다를 수 있습니다.
