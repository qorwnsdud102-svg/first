- 핵심 · 내 컴퓨터에서 실제로 일하는 동료

02 · WHAT IS CLI
그 검은 창, CLI입니다
Command Line Interface — 키보드로 명령어를 쳐서 컴퓨터를 조작하는 방식
- 우리에게 익숙한 — GUI: 마우스로 클릭, 드래그. 아이콘 클릭, 버튼 누르기, 창 드래그

=== PAGE 12 ===
02 · WHY CLI
왜 클로드 코드는 CLI에서 돌아갈까?
웹 채팅이 익숙한 우리에게 굳이 검은 창을 쓰는 이유
- REASON 01 · 파일을 직접 건드린다 — 웹 채팅은 답변을 복사하고 붙여넣는 건 내 몫. 클로드 코드는 직접 파일 열고, 수정하고, 저장.
- REASON 02 · 입출력 제한이 없다 — 웹 채팅은 긴 코드 잘리고, 응답 끊김. 클로드 코드는 프로젝트 폴더 통째로 읽고, 수십 개 파일을 한 번에 다룸.
- REASON 03 · 내 PC의 모든 도구를 쓴다 — 파일 검색, 소프트웨어 설치, 자동화. 단순 답변 도구가 아니라 내 PC에서 일하는 동료처럼 작동한다.
CLI = AI에게 가장 넓은 권한과 자유도를 주는 환경

**MD 파일 — 클로드의 행동 지시서**

CLAUDE.MD 예시:
```
# 데이터 정리 작업 지시서
```

03-2 · LEARNINGS ENGINE · SKILL OF 5
