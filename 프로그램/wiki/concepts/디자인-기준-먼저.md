# 디자인 기준 먼저 — Claude에게 "만들게" 말고 "고르게"

## 한 줄 정의

화면을 그리기 전에 **색·글자·간격·둥글기·그림자·컴포넌트 상태를 몇 개의 단계로 못 박아 두고**, Claude(AI)는 그 안에서만 고르게 하는 것. 화면마다 즉흥 값이 생기는 게 "어딘가 지저분한" 느낌의 대부분이다.

## 왜 — 결과를 좌우하는 건 긴 프롬프트가 아니라 미리 정한 기준

- AI는 매번 "적당한" 값을 새로 만든다 → 제목이 24/22/20px로, 버튼 둥글기가 10/14/12로 흔들린다 (와니 A, 3등급).
- 디자인 시스템을 쓴 참가자가 목표를 34% 빨리 끝냈다 (Figma 자체 데이터, 1등급 출처의 자체 수치).
- 김경환(110): 색과 타이포만 코드로 정리해도 효과가 크다 (2등급).
- 우리 경험: 두 도구를 "같은 색·같은 글꼴"로 만들었는데도 대표가 통일감이 없다고 했다 → 자리·글자·버튼 위치까지 기준이어야 한다 ([[형제-도구-화면-공통규칙]], 1등급).

## 정할 것 6가지

| 항목 | 규칙 | 기본값 (프로젝트에 기준 없을 때) |
|---|---|---|
| **색** | 값이 아니라 **역할**로 이름 짓는다. 브랜드색이 바뀌어도 역할은 그대로 | `primary`·`bg`·`surface`·`text`·`text-muted`·`border`·`danger`·`success`·`warning` |
| **글자** | 역할별로 크기/줄간격/굵기를 고정 | Title 24/34 700 · Subtitle 18/28 600 · Body 15/24 400 · Label 13/20 500 · Caption 12/18 400 (데스크톱 관리 화면 기준) |
| **간격** | 정해진 단계 밖 숫자 금지 (12·15·18·21 같은 즉흥값 X) | 4 · 8 · 12 · 16 · 24 · 32 · 48 |
| **둥글기** | 단계로 | 4(입력·칩) · 8(버튼·카드) · 999(알약·배지) |
| **그림자** | 3단계만, 중요도로 고른다 | sm(카드) · md(드롭다운) · lg(모달) |
| **상태** | 컴포넌트마다 상태를 먼저 정의 | 버튼: default·hover·pressed·disabled·loading / 입력: default·focus·filled·error·disabled |

기본값은 출발점이다. 대표 프로그램에 이미 쓰는 값이 있으면 **그걸 토큰으로 옮기는 게 먼저**다.

## 컴포넌트 이름은 역할로 (와니 D, 3등급)

- `BlueButton`·`LoginButton` 금지 — 색이 바뀌면 이름이 틀리고, 화면마다 버튼이 복제된다.
- 이름은 `Button` 하나, 차이는 속성으로: **hierarchy**(primary/secondary/tertiary) · **tone**(brand/neutral/danger) · **size**(s/m/l) · **state**.
- "구매하기" 같은 글자는 이름이 아니라 라벨이다.

## Claude 작업 절차

1. 프로젝트에 `tokens.css`(또는 상단 `:root` 블록)가 있는지 확인. 없으면 **첫 커밋에서 만든다.**
2. 화면 코드에는 **토큰만 쓴다** — `#3182F6`, `margin: 13px` 같은 날값이 보이면 위반.
3. 새 컴포넌트가 필요하면 기존 것으로 되는지 먼저 본다. 진짜 새것이면 상태 5종까지 같이 만든다.
4. 다 만든 뒤 grep으로 날값 검사: `grep -nE "#[0-9a-fA-F]{3,6}|[0-9]+px" *.css`에서 토큰 파일 외 결과는 하나씩 정당화하거나 토큰으로 바꾼다.

```css
:root {
  /* 색 — 역할 */
  --primary: #2563eb; --primary-weak: #dbeafe;
  --bg: #f7f8fa; --surface: #ffffff; --border: #e5e7eb;
  --text: #111827; --text-muted: #6b7280;
  --danger: #dc2626; --success: #16a34a; --warning: #d97706;
  /* 간격 */
  --s1: 4px; --s2: 8px; --s3: 12px; --s4: 16px; --s5: 24px; --s6: 32px; --s7: 48px;
  /* 둥글기·그림자 */
  --r-sm: 4px; --r-md: 8px; --r-full: 999px;
  --shadow-sm: 0 1px 2px rgb(0 0 0 / .06);
  --shadow-md: 0 4px 12px rgb(0 0 0 / .08);
  --shadow-lg: 0 12px 32px rgb(0 0 0 / .12);
}
```
