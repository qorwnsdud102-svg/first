# 자동입찰 존중 판단 규칙

## 한 줄 정의

자동입찰 프로그램을 쓰는 계정에서 **입찰가·CPC는 결과값이지 조정 대상이 아니다** — 그래서 CPC는 어떤 규칙의 조건도 아니고, 판단은 운영자가 실제로 취하는 조치 5개(OFF 검토 / 소재 점검 / 랜딩 점검 / 확대 검토 / 유지)로만 내며, 사유는 "지금 수치 → 비교 대상 → 결론" 순서의 증명 문장으로 쓴다.

## 왜 이렇게 됐나 — v1의 실패

v1은 고정 목표 CPC(500·700원)와 비교해 "입찰가를 내려라"를 냈고, 열린 추천 53건 중 24건이 그것이었다. '허리협착증' 모바일 3위 유지가 1,050원인데 500원 인하를 제안 — 적용하면 노출이 사라진다. **운영 방식(자동입찰)을 모르면 규칙이 틀린 조치를 권고한다.** → v2: 입찰 액션 삭제, 비교 기준을 고정값에서 또래·자기 매출 근거로.

## 구조

- **또래** = 같은 유형·같은 브랜드, 추세창(28일) 클릭 5회 이상 키워드의 CTR 중앙값. 표본 5 미만이면 유형 전체, 그것도 부족하면 또래 없음. 중앙값 0은 "표본은 있는데 값 없음". 비용 0 표본(보고서 결손)은 CPC 중앙값에서 뺀다.
- **표본 하한**: CTR 판단은 노출 2,000 이상(500회로는 클릭 몇 개가 CTR을 좌우 — 실데이터 튜닝). 유지 표시는 클릭 10 이상(적은 표본은 "이상 없음"으로도 표시하지 않는다). 판단 보류: 7일 노출 500 미만이고 실제 광고비 2만 원 미만.
- **규칙**: K1 노출은 많은데 클릭 0 → OFF 검토 / K2 CTR < 또래 절반 → 소재 점검(또래 CTR이었다면 클릭이 몇 회였을지까지 계산) / K2b 파워컨텐츠 노출 3,000↑ CTR 0.3%↓ → 소재 점검 / K4 CTR ≥ 또래 1.5배 & 순위 3위 밖 → 확대 검토 / B1g·B2g 그룹(NT) ROAS < 목표 절반 & 그룹 비용 비중 20%↑ → CTR ≤ 또래면 OFF 검토, CTR ≥ 또래이고 구매 0이면 랜딩 점검 / C1 파워컨텐츠 콘텐츠 유입률 < 또래 절반 → 랜딩 점검 / S1~S5 전환 추적 대상의 구매·ROAS·CPA 규칙.
- **유지도 근거를 쓴다**: "7일 실제 비용 → 클릭 N회, CTR(또래의 x배), 그룹 근거, 상위노출 유지 비용 CPC".
- **생명주기**: (entity, action)당 open 하나 · 처리하면 14일 스누즈(생성만 억제, 열린 건 갱신) · 조건이 사라지면 expired · **대량 만료 가드**(판단 대상이 직전의 절반 미만이면 건너뜀, 연속 3회까지만 — 정상 축소가 영구히 만료를 막지 않게) · 옛 액션은 허용 목록으로만 삭제 · `RULES_VERSION`을 올리면 서버 시작 시 한 번 재판단 · 기준일·기간(7/14/28일)을 바꾼 **미리보기는 DB에 쓰지 않고**, 문턱은 창 길이에 비례.

## 구조적 한계 — 판단 규칙을 짤 때 빠뜨리기 쉬운 것

1. **"돈이 되나"를 묻는 규칙이 있어야 한다.** 소재(CTR)와 랜딩(구매 0)만 물으면 **그룹이 적자인데 CTR이 좋은 키워드**는 "유지"로 통과한다. [[마케팅/광고 지표 판독]] "CTR만 보면 후퇴한 성과를 자랑한다"의 규칙판.
2. **목표 ROAS를 단일 설정 상수로 두지 않는다.** 실제 광고비 계수를 넣으면 같은 숫자의 뜻이 바뀌고([[실제-광고비-계수]]), 툴이 이미 계산하는 브랜드별 손익분기를 규칙이 안 쓰면 [[단일-진실-원천]] 위반이다. 사장님 기준은 [[마케팅/통합 로아스]] 200%+.
3. **키워드 단위만으로는 큰 그룹의 적자를 못 잡는다.** 「그룹 비용의 20% 이상인 키워드」 조건은 키워드가 많은 큰 그룹에서 아무것도 안 걸린다 → 그룹·광고그룹·캠페인 단위 "줄여라"가 필요하다.
4. **절감액 0원짜리가 목록 꼭대기를 차지하면 노이즈다.** 노출만 있고 클릭·비용 0인 K1이 OFF 검토 대부분을 채우면 아침에 볼 목록이 흐려진다.
5. 전환추적 여부를 캠페인 단위 "90일 내 구매 1건"으로 판정하면 우연한 전환 1건이 캠페인 전체에 S1·S3를 발동시킨다(추정).
6. 그룹 유입 문턱 → [[NT-파라미터-매출-귀속]].

## 사례

- SA 툴 검수에서 유지 72건 중 44건(주 159만 원)이 손익분기 미만 그룹에 있었고, ROAS 73% 큰 그룹에서 아무 키워드도 안 걸렸다 — 위 1·3의 출처(2026-09-15).

## 내 생각 / 미해결 질문

- 다음 규칙 후보 **G0 그룹 적자**: 그룹 ROAS < 브랜드 손익분기 × 안전계수이고 그룹 비용 ≥ 문턱이면 그룹 단위 "예산 축소 검토" 1건(키워드 나열 대신). 목표는 설정 상수가 아니라 브랜드별 손익분기(또는 사장님 200%)에서 유도한다.
- K1은 별도 섹션("정리 후보")으로 내리고 절감액 있는 OFF만 위로.
- 낙수 논리와의 충돌: 그룹 ROAS(마지막 클릭)로 OFF를 권하면 낙수 매출을 죽일 수 있다 — [[마케팅/통합 로아스]]의 "접는 선을 미리 긋는다"처럼 광고 ON/OFF 델타 실험을 기록하는 칸이 툴에 필요하다.
