# Figma — 필수 UI 디자인 원칙 7가지 + 그 사용 방법

- 디자인 툴 회사 Figma의 한국어 입문 글. 게슈탈트 지각 원리를 바탕으로 한 **7원칙 + 프로 팁 4개**. 새 주장보다 표준 원칙을 짧게 정리한 것이라 **체크리스트 용도**로 쓴다.
- 위치 표기는 원칙 번호.

## 7원칙 — 한 줄 규칙

1. **계층 구조** — 무엇을 먼저 보고 무엇을 스크롤해야 보는지 의도적으로 정한다. 수단은 글자 크기·굵기, 대비, 간격. 계층은 사용자가 가장 중요하게 여기는 것을 반영해야 한다.
2. **점진적 공개** — 여러 단계로 나눠 단계마다 필요한 정보만. 온보딩에서 이름·연락처·역할·업종·관심사를 한 화면에 다 물으면 시작 전에 포기한다. 단, **현재 위치와 남은 단계를 알려 줘라** (→ [[김경환_디자인-독학하기-브런치북|김경환 93]]이 진행 막대를 일부러 뺀 것과 충돌 — 미해결 쟁점).
3. **일관성** — 버튼 모양·동작이 제품 전체에서 같아야 사용자가 인터페이스를 생각하지 않고 일에 집중한다. 기존 패턴에서 벗어날 땐 타당한 근거가 필요.
4. **대비** — 중요한 것엔 강한 대비. 예: 흰 배경 빨간 '계정 삭제', 보조 동작('계정 유지')은 회색.
5. **접근성** — 색·명도 대비 조정. WCAG 핵심: 대체 텍스트, 올바른 제목 구조, 보조기술 호환, 키보드 탐색, 전경·배경 충분한 대비. (본문 수치 "세계 사용자 4명 중 1명 이상이 시각 장애"는 출처 미표기 — 인용 주의.)
6. **근접성** — 관련 요소는 붙인다. 예: 재생·빨리감기·되감기는 한 줄, **종료 버튼은 실수로 누르지 않게 따로** (와니 C '위험한 행동 분리'와 같은 취지).
7. **정렬** — 그리드로 질서. 일관된 정렬이 가독성·예측 가능성을 높인다.

## 프로 팁 4개

- 사용자 흐름을 먼저 정하고 그 순서대로 요소 배치 / 화면 간 탐색 일관 + 상호작용마다 시각 피드백 / 단축 기능(검색·단축키) / **정기적으로 실제 사용 테스트**.

## 수치·주의

- "디자인 시스템을 쓴 참가자가 디자인 목표를 **34% 더 빨리** 완료" — Figma 데이터 분석가 자체 연구, 실험 조건 미공개. 디자인 시스템 효과의 방향 근거로만, 크기는 인용 자제.
- 글 후반은 Figma 제품 홍보.
