# Claude Code 기본 교육 교안

- [[강동이]]가 작성한 [[CCFM-AX-TEAM]] 내부 입문 교안 (34페이지). 개발자 없이 [[바이브-코딩]]으로 자동화 만드는 첫걸음.
- 핵심 4축: **MD 파일** (가게 매뉴얼) · **[[Claude-Skill|스킬]]** (직원 5명) · **[[Hook|훅]]** (위생 게이트) · **WIKI** (비법 노트). [[클로드-베이커리-비유]] 한 장으로 통합.
- **스킬 5인 사이클** = bob (큰 그림) → dd (단계 쪼개기) → harness (룰 강제) → eval (시식 평가) → learnings engine (교훈 누적) → 다음 사이클 bob에 자동 반영. 이름은 비유, 실제 사장님 환경의 매핑은 [[Claude-Skill]] 참고.
- WIKI 원칙: **Gold In, Gold Out** — 맥락 없는 자료는 트래쉬, 사전 작성된 핵심 맥락 MD가 골드. 이 vault 자체가 그 원칙으로 운영 중.
