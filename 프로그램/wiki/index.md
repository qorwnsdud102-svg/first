## 운영 인프라 — 프로그램 격벽 원칙

> **모든 프로그램은 독립된 Git 리포, 독립된 포트, 독립된 데이터로 운영한다.**

- 프로그램 간 코드 import 금지. 통신은 HTTP API로만.
- 프로그램 간 파일 수정 금지. 작업 중 다른 리포 파일을 건드리면 안 된다.
- 공유 자원(DB, 쿠키, 설정) 금지. 각자 자체 폴더에 보관.
- 한 프로그램 장애가 다른 프로그램에 전파되지 않아야 한다.

## 첫 ingest 후보 (마케팅 자동화 도구 — 향후 ingest 대상)

### 강사가 실제 사용하는 AI·자동화 도구

> 출처: [[마케팅/그로스짐]] entity §AI 활용 (Claude · Gemini · MCP)

- **Claude (메인)** — 강사의 메인 도구. MCP로 데스크탑 파일·폴더 자동 정리.
- **MCP (Model Context Protocol)** — 크롬 자동화로 i-boss·유튜브·커뮤니티 자동 분석.
- **ChatGPT** — 보조.
- **Gemini** — 보조.

### 자동화 가능한 마케팅 작업 후보

- **시장조사 자동화** — i-boss 168글 + 그로스짐 39자료 자동 분석.
- **리뷰 만 개 분석** — 자사몰·쿠팡·네이버 리뷰 추출 + 재미있는 리뷰 자동 추출.
- **유튜브 자동 분석** — 썸네일 30개 + 댓글 자동 정리.
- **퍼포먼스 캔버스 자동 채움** — 그로스짐 캔버스를 LLM으로 1차 채우기 (사장님 SKU별).
