## 운영 — 이관·인프라

- [[프로그램-운영PC-이관]] — 개발 PC → 운영 PC로 넘기는 꾸러미와 순서

**프로그램 격벽 원칙** — 모든 프로그램은 독립된 Git 리포, 독립된 포트, 독립된 데이터로 운영한다.
- 프로그램 간 코드 import 금지. 통신은 HTTP API로만.
- 프로그램 간 파일 수정 금지. 작업 중 다른 리포 파일을 건드리지 않는다.
- 공유 자원(DB, 쿠키, 설정) 금지. 각자 자체 폴더에 보관.
- 한 프로그램 장애가 다른 프로그램에 전파되지 않아야 한다.

| 프로그램 | 리포 | 포트 | 경로 |
|---------|------|------|------|
| 포탈 | tools-portal | 8000 | `/` |
| 입찰가 관리 | naver-biding | 8001 | `/bid/*` |
| 커뮤니티 크롤러 | community-crawler | 8002 | `/crawl/*` |
| 카페 바이럴 관리 | 카페 바이럴 관리프로그램2 | 8003 | `/cafe/*` |
| 광고 반응 부스터 | snskit-booster | 8004 | `/boost/*` |
| 메타 댓글 자동관리 | meta-comment-guard | 8005 | `/comment/*` |
| 메타 대시보드 | 메타 관리프로그램 | 8006 | `/meta/*` |
| 성과측정 대시보드 | 직원 리포 | 8010 | `/` (독립 실행, 포탈 미연결) |

새 프로그램은 별도 리포 + 빈 포트 + `/(이름)/*`. 외부 접속: Cloudflare Tunnel → 포탈(8000) → 리버스 프록시 → 각 프로그램.
