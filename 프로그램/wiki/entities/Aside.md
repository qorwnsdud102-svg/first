# Aside (AI 에이전트 브라우저)

## 한 줄 정의

**AI에게 일을 시킬 수 있는 웹브라우저.** 웹페이지를 읽고·비교하고·여러 단계 작업을 대신 진행하며, 설정에 따라 로그인된 계정·방문 기록·파일·저장된 비밀번호까지 쓴다. (p3)

## 핵심 속성 (2026-09-21 기준)

### 요금 — 공식 요금표 [S6]

| 플랜 | 월 | 연 | 내용 |
|---|---|---|---|
| Free | $0 | $0 | 월 500크레딧, 활성 루틴 3개 |
| Pro | $20 | $200 | 사용량↑, Ultrabrowse, 루틴 무제한 |
| Max | $200 | $2,000 | Pro 기능 + Free 대비 40배 사용량 |

- 크레딧 ≠ 질문 횟수. 잔여량: Settings > Plan & Usage.
- **기존 구독 연결이 Free에서 된다** — ChatGPT Plus/Pro, **Claude Pro/Max**. 경로: Settings > Models > Providers > Connect > **Subscription**. Pro·Max 따로 살 필요 없음. 단 Aside 유료 전용 기능(Ultrabrowse 등)은 딸려오지 않는다. (p4~5)
- **API 키 연결은 별개** — 제공자 쪽에 API 사용료가 붙는다. 월 구독 연결과 헷갈리지 말 것. (p5)

### 쓰는 곳

- 새 탭 **Ask** (Ctrl+E) / 페이지 옆 **Ask Aside 사이드 패널** — 열어 둔 페이지가 자동 첨부된다. `@`로 참고 자료 첨부. (p8~9)
- 진행 중 지시: **Steer**(지금 작업 조정) vs **Queue**(끝난 뒤 적용). (p16)
- **Routines** — 일정 반복 작업 (겹치면 건너뜀, 대상 대화 없으면 일시정지). 절전·종료 중 동작은 미검증. (p17)
- **Memory** — 방문 기록·대화 맥락 저장. 끄기 ≠ 이미 저장된 것 지우기. (p17)

### 권한·보안

| 파일 모드 | 뜻 |
|---|---|
| Read only | 안 바꾸고 보기만 |
| **Guard (기본값)** | 허용 폴더에서만, 다른 폴더는 확인 |
| Full access | 컴퓨터 어디든 읽고 쓰기 |

- 도구 권한 Allow / Ask / Deny — **충돌 시 Deny가 이긴다.** Read only라는 이름만으로 웹사이트에서의 행동까지 막힌다고 보장 못 함. (p18)
- 비밀번호 관리자 **Aside Vault** — 자동 로그인은 되지만 추가 인증·CAPTCHA는 사람. AI 접근 정책: Settings > Passwords > Access policy for AI agents. (p18)
- **"브라우저 안에서 처리하니 밖으로 안 나간다"는 틀림** — 작업 기록은 로컬이지만 요청문·도구 결과·선택한 화면·파일은 호스팅 AI 모델로 전달될 수 있다. (p19)

## 안내서가 보여 준 교훈 — "찾지 못함 ≠ 공개되지 않음"

비교표 실습에서 AI가 처음엔 **"연 결제 금액은 공개되지 않았다"** 고 답했다. 사람이 요금표의 **Yearly 탭을 직접 누르자** 연 금액이 나왔다. (p13~14)
→ 표가 그럴듯해도 **다른 탭·접힌 설명·결제 주기**를 확인해야 한다. 우리 볼트의 [[모름-vs-0-표시-규약]]·[[주문-전달-실물-대조]] ("API 0 = 미전달이 아니라 못 읽음일 수 있다")와 같은 계열의 실수.

요청문 쓰는 틀 (p15):
> 사용할 자료는 [URL 또는 파일]이야. [작업]을 하고, 결과는 [표/글/파일]로 만들어줘. 꼭 포함할 항목은 [항목]이야. 확인되지 않은 내용은 표시하고, [멈출 지점]에서 멈춰줘.

## 내 생각 / 미해결 질문

- 사장님이 이미 Claude 구독이 있으면 **Free + 구독 연결**로 비용 0에 시험 가능 — 다만 Claude Max 사용량을 같이 깎는지는 확인 필요 (안내서: "외부 구독의 사용량·접근 조건을 따른다").
- 쓸 자리 후보: 경쟁사 상세페이지 여러 개 조건 비교, 공급사 포털 청구서 수집(공식 사례, p16). **로그인·결제 페이지를 AI에게 맡기는 건 우리 보안 규칙과 충돌** — 공개 페이지 읽기부터.
- 실제 도입 여부 미결정. 써 보면 이 페이지를 실측으로 갱신.
