# snskit-API

## 한 줄 정의

SNS 좋아요·댓글·팔로워를 파는 SMM 패널 snskit(SNS키트, 계정 `backstore1`)의 주문 API. Perfect Panel 계열 표준 규약이라 다른 패널도 거의 같다.

## 규약 (실측 2026-09-16)

- `POST https://snskit.co.kr/api/v2`, 본문 `key`(계정설정 → API 키 "새로 생성")·`action`. 응답 JSON. 키는 **본문에만** 넣는다(URL 금지).
- `action=balance` → `{"balance":"84392.0000000","currency":"KRW"}`.
- `action=services` → 242개. **`rate`는 1,000개당 원화** (`"10000.00"` = 1개 10원). `min`·`max`·`type`(Default / Custom Comments).
- `action=add`: `service, link, quantity`, 커스텀 댓글은 `comments`(`\n` 구분, 줄 수 = quantity). 응답 `{"order": 23501}`. **네트워크 오류에 재시도 금지** — 이미 접수됐을 수 있어 이중 주문.
- `action=status&orders=1,2,…`(100개까지) → `status`(Pending / In progress / Completed / Partial / Canceled), `charge`, `remains`, `start_count`.
- FAQ 규칙: 같은 링크 중복 주문은 앞 주문 완료 후에만(진행 중 추가하면 새 주문 취소될 수 있음). 시작 시각 조정 불가.

## 첫 실주문에서 드러난 것 (2026-09-20, 실주문 12건 ₩7,790)

**접수 ≠ 전달.** 주문번호를 받아도 작업이 도는지는 별개다. 그날 IG 는 몇 분 만에 끝났고 FB 는 상품에 따라 갈렸다.

| 서비스 | 결과 |
|---|---|
| IG 좋아요 406 · IG 커스텀 댓글 231 | 몇 분 만에 완료 (한국인 계정) |
| FB **여성** 좋아요 (60원) | 완료 — 게시물 좋아요 1 → 10 실제 증가 확인 |
| FB **여성** 랜덤 댓글 (420원) | 진행중 |
| FB 커스텀 댓글 494 (220원) | **4~5시간 미전달** (시작 카운터 0) |
| FB 게시물 좋아요 431 (35원)·40원 | 1시간 반 미전달 |

- **링크 형식은 무관**하다. 페이지 번호 두 형식(`facebook.com/586083164589708/posts/…` = `effective_object_story_id` 에서 조립한 것, `facebook.com/61574054860277/posts/…` = 브라우저가 보여 주는 새 페이지 ID)과 **릴스 주소**(`facebook.com/reel/{video_id}/`) 전부 접수되고, 셋 다 같은 상품에서 같은 결과였다. 우리가 만드는 링크는 무죄다.
- **공개 범위도 무관**하다. 광고 전용(타임라인 미게시) 릴스는 **전체 공개**다 — snskit 상품 설명의 "전체공개만 가능" 조건을 충족한다.
- **`start_count`·`remains` 는 믿을 게 못 된다.** 좋아요는 `남음 4` 인데 실제로 +4 가 반영됐고, 랜덤 댓글은 "2개 처리" 인데 게시물엔 0건이었다. 8월 주문도 `start_count` 가 공백인 채 완료됐고 댓글은 실제로 달렸다. → [[주문-전달-실물-대조]]
- 한국인 **FB 댓글**은 두 패널 모두 느리다([[smmkings]] 의 한국인 랜덤 댓글도 30분 대기). 한국인 작업자가 인스타에 몰려 있는 것으로 보인다. **IG 를 주력으로, FB 는 좋아요 위주로** 짜는 편이 현실적이다.
