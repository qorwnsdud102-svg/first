# snskit-booster (광고 반응 부스터)

## 한 줄 정의

메타 광고 소재마다 FB·IG 게시물 링크를 API로 뽑아, 프리셋(1차·2차·3차 회차)대로 [[snskit-API]]에 좋아요·댓글을 자동/수동 주문하는 포탈 웹앱. 브라우저 자동화 없이 **API 두 개**(메타 Marketing API 조회 + snskit api/v2)로만 돈다.

## 왜 만들었나

대표가 광고관리자에서 소재 수정 화면을 열어 링크 두 개를 복사하고, snskit 주문 화면에서 게시물마다 좋아요·커스텀 댓글을 넣어 접수하고, 같은 게시물에 D0→D+1→D+4로 세 번 반복하던 수작업. 주문내역을 뜯어보니 IG 좋아요 20~57 + 커스텀 댓글 3~23, FB 커스텀 댓글 4~5가 패턴이었다. [[마케팅/DA 광고]]의 "광고 댓글 작업"(3등급 수강생 노하우) 실행 도구.

## 구조 (2026-09-16 Plan 1)

- 포탈 `bid.100storeee.kr/boost/` → `127.0.0.1:8004`, FastAPI + SQLite + 순수 HTML/JS 단일 페이지. 격벽 원칙대로 독립 리포·독립 키·독립 DB.
- 링크는 크리에이티브 필드로 조립한다: FB `https://www.facebook.com/{page_id}/posts/{post_id}/` (`effective_object_story_id`), IG는 `instagram_permalink_url`의 숏코드로 `/p/{code}/` 재조립. 게시물 `permalink_url` 조회는 페이지 권한 오류(#10)라 쓰지 않는다.
- 판단 단위는 게시물(FB post id). 소재가 여럿이 한 게시물을 써도 1번.
- 회차는 프리셋 JSON(시점 offset·몇 시 이후·항목·댓글 출처 풀/AI/직접·승인 필요). 댓글 풀은 소재 이름 토큰(`Y26_W38_온천크림_SB_손가락_…`)의 제품·부위로 매칭, 같은 게시물엔 같은 문구 재사용 없음(FB·IG 통틀어).
- 안전장치 8종(자동모드·송출중 소재·전송 시간대·미완료 주문·min/max·일일 상한·잔액 하한·시뮬레이션) + 돈 안전 패턴은 [[유료-주문-이중결제-방지-패턴]].

## 실측 (2026-09-16)

- 계정 소재 **312개**(송출중 11, 나머지 중지). 메타 `limit=500` + 중첩 필드(campaign{}·adset{}·creative{})는 **500/code 1 "reduce the amount of data"** → 페이지 100, code 1이면 반으로 줄여 같은 페이지 재요청.
- 시뮬레이션 사이클: 9게시물 27건 29,340원, 10번째부터 일일 상한(30,000원) 보류. 22시 이후 스캔은 전송 시간대 보류. 옛 중지 게시물까지 회차를 계획하면 로그가 넘쳐 **송출중 게시물만 계획**으로 바꿈.
- 서버 PC 배포·실주문 전환은 대표 결정 대기 (`docs/내일-할-일.md`).

## 안정성 보강 (2026-09-17)

- 대표가 실사용 테스트를 시작하기 전, 별도 worktree 에서 감사 4갈래(백엔드 장애·동시성/배포·데이터/돈 경로·운영자 UX)를 동시에 돌려 **재현 프로브로 확인된** 결함만 명세(H1~H43)로 묶고 3갈래(엔진·API/프로세스·화면) 동시 구현 → 통합 리뷰 2갈래 → 장애 주입 장기 소크(가상 7,800일) → 최종 리뷰 → `main` 머지·재기동. 테스트 223 → 410.
- 돈 쪽 교훈은 [[유료-주문-이중결제-방지-패턴]] §2026-09-17 보강. 운영 쪽: 사이클 스레드는 죽지 않게 + 생존 상태를 화면 배너로, API 는 사이클이 락을 쥐면 3초 뒤 409(요청이 줄서다 나중에 몰래 실행되지 않게), 변경 요청엔 커스텀 헤더(`X-Booster`) 필수, 설정은 **바뀐 칸만** 저장(열어 둔 옛 화면이 비상정지를 되돌리지 않게).
- 운영자 관점 기능 제안(확인 필요 센터·주문 예보·새 소재 규칙·댓글 로테이션·회차 직접 조작·작업자 기록 등, 명세 §6) → 2026-09-19 전부 반영(아래 Plan 3).

## 화면 (2026-09-17)

- **메타 광고관리자 스타일** — 대표 요청 "광고관리자가 익숙하니 비슷하게". 좌측 레일(대시보드·소재·승인·설정·로그) · 상단바(계정·잔액·지출/상한·자동모드·시뮬레이션/실주문 배지) · 소재는 캠페인/광고 세트/광고 3탭 평면 표 + 우측 상세 패널 + 체크박스 일괄 작업. 대표 승인, 이후는 실사용 피드백으로 보완.
- 만드는 법: 대표가 광고관리자 스크린샷 3장 + 영문 프롬프트로 **Variant**(variant.com)에서 HTML 시안을 뽑고, 그 마크업을 템플릿으로 삼아 데이터 바인딩만 붙였다(Tailwind CDN·Phosphor 아이콘 그대로). 시안 한 장이 설계 논의를 대부분 대신했다.
- 리뷰가 잡은 화면 쪽 함정: 캠페인 **이름**으로 드릴다운하면 `- 사본` 캠페인이 섞인다(→ id로) · 게시물을 공유하는 소재의 지출을 합치면 중복(→ 게시물 dedupe) · 비동기로 여는 모달은 늦게 끝난 요청이 다른 소재 창을 덮는다(→ 토큰 가드) · 트리+단일 편집기 배치는 저장 안 한 입력을 조용히 버린다(→ dirty 확인).

## 운영 기능 묶음 (2026-09-19 Plan 3)

- 대표 결정 "운영자 관점 기능 다 넣고 이 PC에서 실 테스트". F1~F17: 확인 필요 센터(13가지)·24시간 주문 예보·스캔 미리보기·잔액 n일분 · 새 소재 규칙 · 댓글 로테이션·풀 편집기 · 회차 직접 조작(지금 실행·건너뛰기·다시 시도·일정 변경) · 회차 기준 '시작 후/직전 회차 후' · 작업자 이름+활동 기록 · 주문 조회·CSV · 프리셋 이력·영향 미리보기·적용 범위 · 딥링크·정렬·되돌리기 · 실주문 전환 마법사 · 텔레그램 · AI 댓글(키 잔액 0이라 꺼 둠) · 포탈 게이트 보안(포탈 리포 별도 브랜치).
- 진행: 토대 1명(스키마 v3·라우터 분리·확장 지점·화면 파일 분리) → **파일 소유를 나눈 7갈래 동시** → 통합 리뷰 3회(돈 경로·화면 계약·수정분 최종) → 결함 30여 건 수정 → 소크 40시드×60일(주문 약 7,400건, 이중 접수·상한·가드·중복 댓글·대기열 정지 0) → `main` 빨리감기 머지·DB 백업·8004 재기동(DB v2→v4 자동 이행). 테스트 410 → 838.
- 돈 쪽 교훈은 [[유료-주문-이중결제-방지-패턴]] §2026-09-19(사람 승인 경계).

## 만들며 배운 것 (전이 가능)

- 계획 코드를 서브에이전트가 그대로 옮겨도 **리뷰가 매 Task마다 실제 돈 새는 경로를 잡았다** — 타임아웃 뒤 재주문, 공유 커넥션의 트랜잭션 오염, 클라이언트 댓글 줄 수로 상한 우회. 2단계 리뷰(스펙→품질) 비용은 컸지만 첫 실주문 전에 알았다는 게 값이다.
- Windows 함정 셋: `.bat`는 CRLF여야 다중행 `if (...)`가 파싱됨 / 새 venv엔 `tzdata`가 없어 `ZoneInfo("Asia/Seoul")`가 죽음(개발 PC 전역 파이썬이 가리고 있었다) / 확장자 숨김 때문에 키 파일이 `snskit_key.txt.txt`.
- Claude Code 자동 모드 분류기는 **키 파일 쓰기와 로컬 API의 설정 PUT**을 막는다(자격증명·실거래 오탐). 키는 사람이 넣고, 화면 조작은 브라우저로.
- **병렬 갈래는 각자 테스트 통과해도 이음매에서 깨진다** — 7갈래가 전부 초록이었는데 통합 리뷰가 갈래 사이 계약(예보↔엔진 필터, 승인 대기열↔실주문 전환, 적용 범위↔승인 요구) 결함 30여 건을 찾았다. 갈래 수만큼 통합 리뷰를 따로 잡아야 한다.
- **소크 하네스도 새 상태를 배워야 한다** — 새 헤더(`X-Operator`)를 안 보낸 하네스는 400만 받으며 "위반 0"을 냈고(주문 0건 — 지표로 알아챔), 새 상태(`queued`)를 모르는 불변식은 정상 대기를 "영구 정지"로 불렀다. 결과가 너무 깨끗하면 주문 건수부터 본다.
- **UTF-8 배치의 `'xist' is not recognized`** — `chcp 65001` 뒤 한글 줄이 섞인 .bat 는 cmd 가 줄 경계를 잘못 읽어 `if not exist` 조각을 명령으로 실행하는 잡음이 난다(기동은 정상). 무해하지만 보이면 놀라니 알아 둘 것.
