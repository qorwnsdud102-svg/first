# snskit-booster (광고 반응 부스터)

## 한 줄 정의

메타 광고 소재마다 FB·IG 게시물 링크를 API로 뽑아, 프리셋 회차대로 [[snskit-API]]에 좋아요·댓글을 자동/수동 주문하는 포탈 웹앱. 브라우저 자동화 없이 **API 두 개**(메타 Marketing API 조회 + snskit api/v2)로만 돈다. [[마케팅/DA 광고]]의 "광고 댓글 작업"(3등급 수강생 노하우) 실행 도구.

## 무엇·어디

- 운영 PC `C:\Users\pc\Desktop\클로드\메타댓글 부스터` · 포탈 `/boost/` → `127.0.0.1:8004`. FastAPI + SQLite + 단일 페이지. 원격 저장소 없음(이관은 폴더 복사).
- 개발 저장소 `C:\claude\snskit-booster` — 스펙·계획은 `docs/superpowers/`.

## 핵심 설계 결정

- 판단·주문 단위는 **게시물**(FB post id). 링크는 크리에이티브 필드로 조립(`effective_object_story_id`, IG는 `instagram_permalink_url` 숏코드) — 게시물 `permalink_url`은 권한 오류(#10).
- **소재 1개 ≠ 게시물 1개** — 메타가 노출 위치·비율마다 게시물을 쪼갠다. 변형 목록은 [[메타-댓글-자동관리]] 창구(`/api/targets`, 8005)에 묻고 직접 찾지 않는다. 변형은 기본 꺼짐, 사람이 켠다.
- 회차는 프리셋(한 게시물 5회차 드립, 기한은 직전 회차 실제 주문 시각 기준). 구좌별 프리셋 분리 근거는 [[광고-구좌별-노출-쏠림]].
- 안전장치 8종(자동모드·송출중 소재·전송 시간대·미완료 주문·min/max·일일 상한·잔액 하한·시뮬레이션) — 돈 안전 패턴은 [[유료-주문-이중결제-방지-패턴]].
- 메타 호출은 사용량 머리글을 읽어 80%에서 쉬고, 송출중만 받는다 → [[메타-API-호출-한도-주머니]].
- 화면은 메타 광고관리자 모양 + 형제 도구와 같은 말·레일 → [[형제-도구-화면-공통규칙]].
- 저장된 댓글은 **진짜 댓글 말투**(붙여쓰기·오타·짧게 끊기)로, 금지어 필터는 따로.

## 만들며 배운 것

- 돈이 갈라지는 길은 "회차 하나 놓치기"로 막는다(링크가 바뀐 변형은 끄고, 한 링크 두 단위는 거울이 양보) → [[유료-주문-이중결제-방지-패턴]].
- 새 칸·새 판정의 기본값은 **사람이 켜기 전 상태** — 기존 소재의 새 게시물이 자동으로 켜져 돈이 나갔다.
- 같은 광고를 두 프로그램이 건드리면 우리가 산 댓글이 형제의 "구매 문의"가 된다 → [[산-댓글-가려내기]].
- 이관 때 DB를 가져가면 그날 지출(일일 상한)도 따라오고, 되돌리기는 이중 주문을 부른다 → [[중복방지의-DB-경계]] · [[프로그램-운영PC-이관]].
- 소크가 새 기능·새 헤더를 모르면 "위반 0"으로 거짓 통과한다. 결과가 너무 깨끗하면 주문 건수부터 본다 → [[소크-하네스-거짓통과]].
- 병렬 갈래는 각자 초록이어도 이음매(갈래 사이 계약)에서 깨진다 — 갈래 수만큼 통합 리뷰를 따로 잡는다.
- 단계마다 리뷰가 실제 돈 새는 경로(타임아웃 뒤 재주문·공유 커넥션 트랜잭션 오염·상한 우회)를 잡았다 — 첫 실주문 전 2단계 리뷰는 값을 한다.
- 실패한 스레드가 쓰기 트랜잭션을 쥔 채 남으면 이후 모든 쓰기가 `database is locked` — `finally` 롤백. 화면은 "사이클 실패" 한 줄뿐인 조용한 정지였다.
- 첫 자동 사이클 **주문 0건**(회차가 다 끝난 상태)은 돈 안 쓰고 전 구간을 검증하는 이관 점검 수법이다.
- Windows 함정: `.bat`는 CRLF여야 다중행 `if` 파싱 / 새 venv엔 `tzdata`가 없어 `ZoneInfo` 실패 / 확장자 숨김으로 `키.txt.txt` / `chcp 65001` 뒤 한글 줄이 든 .bat의 `'xist' is not recognized`는 무해한 잡음.
- Claude Code 자동 모드는 키 파일 쓰기·로컬 API 설정 PUT을 막는다 — 키는 사람이, 화면 조작은 브라우저로.
- 메타 Graph `limit=500` + 중첩 필드는 500/code 1 "reduce the amount of data" → 페이지 100, 또 나면 반으로 줄여 재요청 → [[메타-API-호출-한도-주머니]].
- 화면 함정 4: 캠페인 **이름**으로 드릴다운하면 `- 사본` 캠페인이 섞인다(→ id로) · 게시물을 공유하는 소재의 지출을 합치면 중복(→ 게시물 dedupe) · 비동기 모달은 늦게 끝난 응답이 다른 창을 덮는다(→ 토큰 가드) · 트리+단일 편집기는 저장 안 한 입력을 조용히 버린다(→ dirty 확인).
- 사이클이 락을 쥐고 있으면 API는 3초 뒤 409 — 요청이 줄 서 있다 나중에 몰래 실행되지 않게.
- 설정은 **바뀐 칸만** 저장 — 열어 둔 옛 탭이 비상정지를 되돌리지 않게.
- 상태를 바꾸는 요청엔 커스텀 헤더(`X-Booster`) 필수 — 다른 출처가 못 부르게 → [[유료-주문-이중결제-방지-패턴]].
- 같은 서비스를 연이은 회차에 두지 않는다 — "앞 주문 미완료" 보류가 드립을 잡아먹는다.

## 다른 엔티티와의 관계

- [[메타-댓글-자동관리]] — 형제 프로그램(같은 메타 앱·같은 PC). 부스터가 댓글을 늘리고, 자동관리가 부정 댓글을 숨기고 구매 문의를 회수한다.
- [[snskit-API]] — 주문 채널. 대안 패널 [[smmkings]]는 한국인 랜덤 댓글만이라 문구 지정 불가.
- [[주문-전달-실물-대조]] — 패널 말 대신 메타에서 직접 확인. [[라이브-검증-프로토콜]] — 시뮬레이션 + 브라우저 실측. [[수집-파이프라인-안전장치]] — 동기화 실패 시 롤백·중단의 선례.
