# 전체 대시보드 (회사 손익 대시보드)

## 한 줄 정의

## 구성 (2026-09-28)

- 스택은 SA 툴 그대로(FastAPI·SQLite·바닐라 JS, 포트 8010). 저장소는 GitHub 비공개 저장소, 작업 폴더 `C:\claude\전체 대시보드-M`(main).
- 규칙의 최상위는 `docs/헌법.md` + 부록(대표 결정 누적). 핵심: **매출은 부가세 포함, 비용·이익은 공급가** · 짐작 금지 — 모르면 「미확정 + 이유」.

- 직원용 화면 `staff_app.py`(8020): 읽기 전용 DB 연결(`mode=ro` + `query_only`), 필드 화이트리스트, 공통비용·회사 이익 없음, 민감 비용은 「기타 브랜드 비용(비공개)」로 합침, **비밀번호 파일이 없으면 켜지지 않음**(fail-closed).
- 테스트 3,303개(2026-09-27).

## 교훈 — 계산

- **월 청구서가 이기고, 일별 자료는 나누는 비율로만 쓴다.** 쿠팡 광고는 달마다 청구된 캠페인 파일이 정답이고, 일별 보고서(pa_daily)는 그 달 금액을 날짜에 나누는 가중치(최대 나머지 방식)로만 쓴다. 일별 파일만 있는 달은 일별 값 그대로. 일별이 그 달 **일부만** 덮으면 알림 — 다 덮으면 알림 없음. 이렇게 하니 1~8월 월 합계는 한 푼도 안 바뀌고(구글 −2,642원 제외) 일별 브랜드 이익이 생겼다.
- **보고서 파일은 모양이 여러 개다.** 구글 애즈는 「캠페인 보고서」(상태·합계 줄 있음 → 검산)와 보고서 편집기 「제목 없는 보고서」(날짜 줄만 → 검산 없음) 둘 다 온다. 필수 칸만 요구하고, 검산은 **검산할 재료가 있을 때만**.
- **파일 이름 규칙은 사람이 늘 조금씩 바꾼다.** ESM이 `_지마켓_`, `_YY.MM.DD-YY.MM.DD` 이름으로 오자 「확인 필요」가 떴다. 별칭 표 + 기간 이름 허용으로 풀었고, 같은 정규식이 원본 격자에서 `09.01-26.09`를 **2009-01~2026-09**로 읽는 버그도 같이 나왔다 — 이름 해석은 한 함수로.
- **원가에 이미 든 비용은 또 빼면 이중 차감.** 제품 원가(실마진 시트)에 넣은 알바비가 프리랜서 탭에도 있었다 → 프리랜서 탭 「비용처리필요」 칸 X = 비용 아님, 지출 탭 유형 「제품 제작 인건비」 = 비용 아님. 8·9월 공통비용이 60.9만 원 줄었다. 모르는 값(O/X 아님)은 비용으로 두고 알림 → [[실마진-공헌이익-모델]].
- **부가세 칸이 비면 짐작하지 않고 보류.** 지출 탭: 빈칸 → 보류, `x` → 부가세 없음, 숫자 → 비용 = 지출 − 부가세. 9월 급여가 「아직 안 들어감」으로 보인 원인이 이것(대표가 x를 넣자 해결).
- **「진행 중인 달」 안내는 데이터로 켠다.** 「월말 급여 아직」 문구를 늘 띄우니 대표가 오류로 읽었다 → 진행 중인 달 인건비가 지난달의 절반 미만일 때만.

## 교훈 — 빈 자료 판정

- **빈 날은 「수집 기록」으로 판정한다.** 광고비가 0인 날이 「안 썼음」인지 「못 받음」인지는 금액으로 모른다. 네이버·메타는 수집 기록(ok/no_data)이 있는 날만 「받았음」으로 보고, 나머지를 「광고비 자료 없음: 메타(9/16~9/25 없음)」처럼 **날짜로** 알린다 → [[모름-vs-0-표시-규약]].
- **API 가게의 빈 날은 표시하고 사람이 누른다.** 주문을 API로 받는 가게(스마트스토어·카페24·쿠팡·11번가)의 주문 없는 날은 누락보다 「진짜 주문 없음」일 가능성이 크다 → 「API로 받음」 배지를 달고, 「정상(원래 없음)」은 **대표가 누른다**(자동으로 정상 처리하지 않음). 건마다 체크 칸 + 한 번에 누르기.

## 교훈 — 운영

- **배포 순서 고정**: 예약 작업 끄기 → DB 백업 → `git pull` → 전체 테스트 → 서버 재시작 → 화면 확인 → 예약 작업 켜기. 코드만 바꿔도 서버는 다시 켜야 새 코드가 돈다.
- **버튼 이름과 실제 범위를 확인한다.** 「엑셀만 다시 읽기」는 원본 폴더 엑셀만 읽고 **운영시트(구글)는 안 읽는다.** 운영시트 변경 확인은 「매출·비용 동기화」(= 매일 수집)로.
- **상태를 바꾸는 POST는 `X-SA-Client: dashboard` 헤더가 있어야** 한다(다른 출처 폼 차단). 스크립트로 부를 때도 같은 헤더.
- **실제 화면 점검은 헤드리스로** — 앱 창이 뒤에 있으면 내장 브라우저 캡처가 실패한다 → [[라이브-검증-프로토콜]].
- 클라우드 세션에 큰 화면 작업을 맡기고 보고 파일로 받았다 → [[여러-클로드-세션-협업]].
