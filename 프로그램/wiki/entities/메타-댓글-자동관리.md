# 메타 댓글 자동관리

## 한 줄 정의

메타 광고(FB·IG) 소재 댓글에서 **구매 문의는 매출로 회수하고, 부정 댓글만 숨기는** 윈도우 상시 프로그램. 메타가 FB 댓글 44%를 이미 스스로 숨기므로([[메타-맞춤광고-댓글-API-한계|메타-광고-댓글-자동숨김]]) **주력은 구매 문의 회수, 부정 숨김은 안전망**이다. 댓글 수가 소재를 인기 있어 보이게 하므로 남길 댓글을 지우는 실수가 가장 비싸다.

## 무엇·어디

- 저장소 `C:\claude\메타 댓글 자동삭제`(GitHub 비공개 `meta-comment-guard`). 운영 PC 포탈 `/comment/` → `127.0.0.1:8005`, 60분 회차.
- Python `.venv` · FastAPI · SQLite(WAL) · anthropic SDK(재판매 프록시, claude-sonnet-5 — [[AI-리셀러-프록시-비용과-지연]]).
- 다른 프로그램용 읽기 창구 `GET /api/targets` · `POST /api/targets/refresh`(같은 PC에서만) — [[snskit-booster]]가 변형 게시물 목록을 여기서 받는다.

## 핵심 설계 결정

- **숨김 우선, FB 삭제는 어떤 경로로도 안 함**(작성자 항의). IG도 숨김 먼저, 숨김이 구조적으로 불가능할 때만 확실한 부정 삭제. 이미 숨겨진 댓글은 건너뜀.
- 판단 경계: **궁금해서 묻는 질문은 유지, 단정·비난은 부정.** 문의 단어(물음형)가 AI보다 먼저 판단하고, 애매한 부정도 숨김(대표 선택) → [[LLM-의미분류-필터링]].
- 맞춤 광고 댓글은 조회로 안 보여 형태별 게시물을 따로 찾는다(미리보기 `videoID`·소재 문구) → [[메타-맞춤광고-댓글-API-한계]]. 회차 댓글을 모아 AI에 한 번에.
- 구매 문의 답장: IG는 **사진 카드**(DM 글 속 주소가 안 눌림), FB는 글. 계좌·업체 이름 안 씀, 문자 주문 안내 사진, 링크는 제품 상세 하나. 파컨 광고 제외. 공개 답글에 계좌 금지.
- 산 댓글 거르기는 항상 자동, 보내기는 자동을 켠 뒤 등록된 소재만.

## 만들며 배운 것

- 셋업: 토큰 권한은 앱 **이용 사례**를 추가해야 고를 수 있고, 권한 추가 = 새 토큰 발급(기존 토큰 유효). 시스템 사용자 토큰은 생성 창에서 한 번만 보인다. 앱 라이브는 개인정보처리방침 URL이면 충분.
- 가짜 객체만 주입하는 테스트는 설치 환경(SDK 버전 충돌)을 못 잡는다 — 실제 클라이언트를 생성만 하는 테스트를 둔다.
- 가짜 자료 테스트는 **저장한 실제 응답**으로 만든다(따옴표 없는 `videoID`에서 정규식 0개).
- 실데이터 첫 회차(시험 DB·자동 끔)가 설계의 "되겠지"를 가장 싸게 깬다 — 계획에 넣는다.
- 조용한 멈춤이 가장 비싸다 — 상태 판정은 서버가 계산해 사람 말로, 건너뛴 사유·건수도 회차마다 한 줄로. 오래 걸리는 버튼은 진행을 보인다.
- 느린 원인은 모델이 아니라 재 보면 나온다(프록시 줄서기) → [[AI-리셀러-프록시-비용과-지연]].
- 메타가 작성자(`from`)를 안 줄 수 있다 — 되돌릴 수 있는 숨김은 하고 삭제만 막는다.
- 남이 읽을 주석은 관찰한 사실 그대로("비공개" 오기가 형제 세션 진단을 틀리게 했다).
- 테스트는 문구가 아니라 **규칙**으로(번호 자리·계좌 없음·업체 이름 없음).
- "구매 절차가 어렵다"는 불평도 구매 의향 — 대표의 한 줄이 판단 기준의 빈칸을 드러낸다.
- 메시지는 "나갔다"와 "읽힌다"가 다르다 — 받는 쪽 화면을 보기 전엔 끝난 게 아니다.
- 같은 광고를 두 프로그램이 건드리면 한쪽 산출물이 다른 쪽 입력이 된다(대기 문의 43%가 산 댓글) → [[산-댓글-가려내기]].
- 새 칸 기본값은 "사람이 켜기 전 상태" — 스키마를 올릴 때 옛 행을 '꺼짐'으로 채운다.
- 빈 응답은 '없음'이 아니라 '못 읽었을 수도 있음' — "폴더는 있는데 0건"이면 경보 → [[모름-vs-0-표시-규약]].
- 문의 단어를 부분 일치로 찾으면 오탐한다("얼마나 사람을 속여야"가 문의로 남음) → 문의 단어는 "얼마에요"처럼 물음형으로 좁힌다.
- 쓰기 쪽 API 사실(IG `hide=true` 숨김 · 비공개 답장은 FB·IG 모두 `/{page}/messages` · 댓글당 1통·첨부 하나 · 표준 권한으로 DM · 「토큰 취소」·탐색기 토큰 주의) → [[메타-맞춤광고-댓글-API-한계]] §쓰기 쪽.
