# 메타 대시보드

## 한 줄 정의

메타 광고 성과(10분마다)와 판매 채널 매출(카페24 자사몰 2곳·네이버·쿠팡·문자주문 시트)을 한곳에 모아, 초보 마케터가 **「지출한 만큼 팔리고 있나」**를 한 화면에서 보게 하는 로컬 웹 도구. 메타를 읽기만 하다가 하루 예산을 바꾸는 쓰기까지 열었다.

## 무엇·어디

- 저장소 `C:\claude\메타 관리프로그램`. FastAPI(`app/server.py`, 8006, 포탈 `/meta`) + 한 파일 화면 + 수집기(`scripts/collect.py`, 작업 스케줄러 10분마다) + SQLite(`data/meta_dash.sqlite`).
- 운영 PC `C:\Users\pc\Desktop\클로드\메타 관리프로그램`(git 아님, zip 설치)에서 수집. 수집은 **PC 한 대에서만**(카페24 refresh 토큰 회전).
- 화면 6개(현황·소재·확인 필요·매출·내역·설정), 형제 도구와 같은 겉모양([[형제-도구-화면-공통규칙]]). 정본은 `docs/인수인계-화면.md`·`인수인계-수집기.md`·`마진표-작성법.md`.

## 핵심 설계 결정

- 이익 = [[실마진-공헌이익-모델]](제품×세트×채널×기간마다 실마진 한 숫자). 광고비 = [[실제-광고비-계수]](메타 카드 캐시백 2.8%).
- 카드 = 큰 숫자 + 세 줄 + 7일 추세선, 경고는 무엇·왜·어디서 → [[대시보드-추세-카드-원칙]].
- 메타 지표 이름은 광고관리자 낱말 그대로, 우리 숫자는 우리 말(순매출·ROAS·광고 후 이익). ROAS는 모두 %.
- 쿠팡 윙 정산 비용·하온 공통 비용은 이 도구가 아니라 **성과측정 대시보드(회사 전체 순익, → 후속 [[전체-대시보드]]) 몫**(대표 결정) — 코드·데이터는 남겨 두고 메타에선 끔. 외주 제작비는 이익에서 빼지 않고 나란히 보인다.
- 경고는 켜진 소재만, 꺼진 옛 것은 접어 둔다. 재고·품절 예상은 확인 필요 옆 → [[재고-품절-예측]].
- 같은 원본(운영 시트 현금매출)을 읽는 두 도구는 같은 규칙으로 — 다르면 숫자가 어긋나 둘 다 못 믿는다. 이익 칸이 비면 보류, 설명서·포장용품은 산 달 비용 → [[실마진-공헌이익-모델]].
- 예산 쓰기는 한 번에 절반~2배, 메타 현재 값이 화면과 다르면 거절. 시간대 자동 조절은 기본 꺼짐 → [[메타-예산-자동-조절]] · [[시간대별-광고-효율-분석]].
- 키 파일 한 줄 = 광고계정 하나(토큰은 줄마다 달라도 됨). 광고계정이 둘 이상이면 맨 위 「광고계정」 선택 — **메타 숫자만** 그 계정, 매출 카드는 「제품 전체 기준」(나눌 수 없는 숫자는 거르지 않는다 → [[모름-vs-0-표시-규약]]). 토큰이 어떤 광고계정을 보는지 → [[메타-토큰과-광고계정-권한]].

## 만들며 배운 것

- 개인정보가 섞인 시트는 고른 칸만 받는다, 양식·기준 칸이 바뀌면 경고 + 이전 값 유지 → [[시트-칸-골라읽기]].
- 이름으로 탭을 찾고 고정 열 번호로 읽는 코드는 양식이 바뀌면 오류 없이 틀린 값을 읽는다.
- 결측은 0이 아니다(첫 수집 이전 매출) → [[모름-vs-0-표시-규약]]. 수집 잠금·판 번호 → [[수집-파이프라인-안전장치]].
- 시각 규칙으로 어림한 재고 차감은 연휴·경계에서 틀린다 — 상태 데이터를 쓴다 → [[재고-품절-예측]]. 로켓 환불은 정산 엑셀로만 → [[쿠팡-로켓그로스-환불]].
- 그리기 확인은 헤드리스 엣지(앱 창이 가려지면 캡처 시간 초과로 오진) → [[라이브-검증-프로토콜]].
- DB 판을 올리면 옛 코드로 켜 둔 수집·서버 창이 새 DB를 거부한다(DbTooNew) — 코드 바꾸면 창을 다시 켠다.
- 셸 heredoc 안 파이썬·Windows 경로의 `\b`·`\v`가 제어 문자로 바뀐다 — 백슬래시가 있으면 스크립트 파일 + r-문자열 + 제어 문자 검사.
- Git Bash `sed -i`가 CRLF를 LF로 바꾼다 — 바이트로 `\r\n` 개수를 세어 확인(`grep -c $'\r$'`는 Git Bash에서 못 믿음).
- 가짜 테스트 데이터부터 실제 모양(광고 이름 규칙)인지 의심한다 — 실패 원인을 코드에서 찾다 잘못 고쳤다.
- 가끔 떨어지는 시험은 `git stash`로 변경을 뺀 상태에서도 떨어지는지 보고 환경 문제와 회귀를 가른다.
- API로 재현 안 되는 광고관리자 지표(후크 비율)는 우리 식 이름으로 바꿔 보인다. 광고 한 줄의 `recommendations`는 비어 오고 계정 `act_x/recommendations`에서 맞춘다.
