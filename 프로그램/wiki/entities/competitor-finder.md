# competitor-finder (네이버 급상승 키워드 기반 경쟁사 발굴 스킬)

## 한 줄 정의

네이버 쇼핑인사이트 **급상승 키워드 → 신규 브랜드 TOP30 발굴 → 메타(Facebook) 광고 소재 크롤링 → 경쟁사 분석 보고서**를 자동으로 만드는 4-STEP 파이프라인 스킬. 대표님이 공유한, [[파이프라인-스킬-패키지]] 해부도의 잘 짜인 **표본**.

## 핵심 속성

### 4-STEP 파이프라인 (각 STEP = 독립 CLI)

| STEP | 스크립트 | 하는 일 | 산출물 |
|---|---|---|---|
| 1 | `surge_trend.py` (2026-08-19, 구 `scan_surge.py` 대체) | ItemScout 전수 후보 + 데이터랩 공식API 월별 트렌드 → 급등/신규/브랜드묶음 판정 | 브랜드묶음·신규브랜드·급등키워드·쳐낸키워드 4시트 xlsx + 보고서.md |
| 2 | `scrape_meta.py` | 발굴 브랜드를 메타 광고 라이브러리에서 Playwright 크롤링 | 브랜드별 mp4/jpg/`_ads.json` |
| 3 | `collect_text.py` | 빠진 광고 카피 보완 수집 | `_ads.json` ad_texts 갱신 |
| 4 | `analyze_pattern.py` | 모은 데이터로 경쟁사 패턴 분석 | 최종 분석 보고서.md |

일괄 실행: `bash hooks/run-pipeline.sh 탈모 "탈모케어:50000304,두피케어:50000303"`

### 판정 로직 (도메인 지식 = 데이터로 분리)
- **신규 브랜드**: 6개월 전 추정 검색량 0 → 최근 완전월 300 이상 ("갑자기 튀어나온 신생 브랜드"만).
- **급등**: 3개월 전 대비 3배+ & 최근 완전월 500+. 정렬은 배수가 아니라 **절대 증가량**.
- 설화수·샤넬 등 **대형 브랜드 자동 제외**(`EXCLUDE_BRANDS` 약 40개 리스트) + 플랫폼 키워드 제외.
- 임계값·리스트·접미사가 모두 코드 상수/리스트라 카테고리 교체 시 본문 안 건드림.
- 상세 노하우(소스 3종 분업·결측 함정·브랜드 묶음)는 [[네이버-급등-신규브랜드-탐지-노하우]].

### 데이터 소스 변천 (2026)
- 6월: 데이터랩 웹 엔드포인트 IP 차단 → 키워드 전수는 [[ItemScout-API]] 로 전환.
- 8월: 시간축은 데이터랩 **공식** 오픈API → [[NAVER-API-HUB]] (키 감지 시 자동 전환, config.apihub_headers).
- 트렌드 응답은 디스크 캐시 + `rawdata/{카테고리}_{수집월}/` 원본 보관 → 기준 바꿔 재판정이 공짜.

### 인증·환경
- 네이버 검색광고 API HMAC-SHA256 서명 + **서버 시간차 자동 보정**(`config.calc_time_diff`) — 로컬 시계 60초+ 차이 시 에러 회피.
- 데이터랩 Client ID **라운드로빈** + **429 응답 기반 키 로테이션**(로컬 카운터는 새 프로세스에서 거짓말한다 — [[API-쿼터-경제학]]).
- 키 파일 탐색: 프로젝트 루트 → scripts/ fallback. (주의: config는 `api_keys.txt`만 인식 — 폴더의 `api.txt`는 이름 변경 필요.)
